# Lean Math Lab

> 智能派民科正在隐秘地批量研制民造核弹

经费是智能派民科的 token，研究员是 Agent。至于“隐秘”——想法、代码、失败记录都在这里公开。🤣

让 Agent 查文献、提猜想、互相质疑、尝试证明，再把精确命题交给 Lean 检查。想看看这些 token 能不能给数学留下点东西。

也许产出大半是“学术垃圾”：重复发明、错误猜想、走到一半才发现断掉的证明。但每次尝试都可以留下一张路标：想法从哪里来，为什么值得试，哪里失败了，还有什么没试。让后来的人和 Agent 少绕一圈，或者看见我们没看见的出口。

我愿意押注，Agent 能从使用数学工具走到创造数学工具，也能形成自己的数学审美：发现值得追问的问题，辨认值得提炼的结构。人类现有知识里的那点“凸包”，未必就是它的边界。

能走多远，就用研究来回答。证明交给 Lean，没走通的路也留下。
