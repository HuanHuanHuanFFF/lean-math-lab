## LI1：有限对数凹序列的卷积闭包

### 准确目标

以 `a b : ℤ → ℝ` 表示有限支撑序列，区间以外自然取零。要求：

1. 非负：对所有 `i`，`0 ≤ a i`、`0 ≤ b i`。
2. 无内部零点：若 `i < j < k` 且两端严格为正，则中间也严格为正；等价地，正值支撑是整数区间。全零序列允许存在，其支撑为空。
3. 对数凹：对所有整数 `i`，`a i * a i ≥ a (i - 1) * a (i + 1)`，`b` 同理。

令 `c n = ∑ i ∈ a.support, a i * b (n - i)`，这里的 `support` 是拟采用的有限支撑表示中的有限集合，并非声称当前函数已有此 Lean 字段。目标证明 `c` 非负、有限支撑、无内部零点且对数凹。最终类型可改用有限支撑函数或有限序列，但应保持同一数学命题和零延拓约定。

第一阶段不引入无限和、连续分布、测度论或超对数凹。无内部零点是关键条件，不能仅保留相邻三项不等式，也不能用有限数值案例代替任意有限支撑的定理。

数学结论是经典卷积闭包；[Preservation of log-concavity on summation](https://arxiv.org/abs/math/0502548) 研究其推广，并给出独立离散随机变量之和的解释。

### 已有实现与缺口

本地 mathlib 全文检索没有定位离散序列对数凹定义和一般卷积闭包；在线主分支目录没有对应命名模块。公开 PR 中 `log-concave` 的命中涉及算子对数凹与二元熵，未覆盖这里的有限序列目标。这里的缺口结论仅限所查范围。

必须承认已有的相邻成果：

- [`godsil-gutman-lean/Newton.lean`](https://github.com/karlesmarin/godsil-gutman-lean/blob/73eb9c0c01c8317ad4bcd23e70d9e289e61753c0/Newton.lean) 已有 `newton_inequality_coeff`、`newton_inequality`、`newton_logConcave` 的声明和证明体，从实根多项式得到系数／归一化对称均值的不等式。不能把 Newton 不等式列作未形式化。
- [`balanced-vectors-blueprint/BalancedVectors.lean`](https://github.com/schmittj/balanced-vectors-blueprint/blob/13de9eeda635bc388e4dba68f514e3b42d339ae7/BalancedVectors.lean) 定义 `LogConcaveOn`、`IsPositiveOn`、`IsPalindromicOn`，并证明 `unimodal_of_logconcave_palindromic`；其单峰引理针对整数区间上的严格正值有理数回文序列。项目进一步处理弱合成的平衡极值，并未给出这里的一般有限卷积接口。

### 复用场景和潜在消费者

- 组合计数：两个计数问题的生成多项式相乘时，乘积系数是原系数卷积；可直接转移对数凹性质。
- 有限离散概率：两个独立随机变量之和的质量函数是卷积；可先完成纯有限代数版本，再由概率 API 调用。
- 计数序列形状：匹配数、生成多项式及已有 Newton 形式化项目可使用统一的零点、对数凹、单峰接口。

一般对数凹序列不必来自实根多项式，因此“把两个实根多项式相乘，再套 Newton”不能覆盖整个目标。

### 最小阶段成果与障碍

1. 固定索引、零延拓、支撑和全零序列约定；证明定义的等价形式。
2. 先在严格正值区间证明比值单调和跨项不等式，再处理一般无内部零点情况。
3. 得到不要求回文的一般有限单峰结论，以及非负两项序列卷积的封闭性；每项作为独立检查点。
4. 完成任意两个有限支撑序列的卷积闭包，并给出多项式乘积系数或离散概率的一个真实调用例子。

主要障碍是零点和端点、有限双重求和重排以及表示之间的转换，不是无限分析。第 3 步的两项卷积并不自动归纳出所有对数凹序列的卷积闭包，不能将其误当完整证明。第一次努力检查点建议止于“定义边界核对＋跨项不等式”，再据实际 Lean 成本决定后续范围。

**接续第一步：** 刷新外部对数凹与卷积实现查重；核对上述两个项目可参考和可直接复用的边界；随后选择一种有限支撑表示，手写完整的无内部零点卷积证明路线。

## LI2：主序关系与双随机矩阵作用的桥梁

### 准确目标

对同一有限索引集上的实向量 `x y`，`x ≺ y` 表示降序排列后，`x` 的每个前缀和不超过 `y`，且两向量总和相等。目标补齐：

\[
x\prec y\quad\Longleftrightarrow\quad
\exists D,\; D\text{ 每项非负、各行和及各列和均为 }1,\quad Dy=x.
\]

随后可给任意适当凸函数 `f` 的有限求和接口 `∑ i, f (x i) ≤ ∑ i, f (y i)`。最初可取 `f : ℝ → ℝ` 在整个实轴上凸，之后再推广到包含向量坐标的凸区间。

此处主序符号方向按上述数学定义固定；现有 PR 中名称 `Majorizes a b` 配 notation `a ≺ b`，不能仅凭英文名称猜参数方向。它也不是概率中的一阶随机占优。

### 已有实现与缺口

- [`Birkhoff.lean` 在线快照](https://github.com/leanprover-community/mathlib4/blob/5aedf732b6987e8c26ab3c9ebc855314f82b045f/Mathlib/Analysis/Convex/Birkhoff.lean) 明确将上述双随机矩阵等价列为 TODO。Birkhoff 分解、双随机矩阵与排列矩阵凸包的关系已实现，应直接沿用。
- 开放 [PR #41898](https://github.com/leanprover-community/mathlib4/pull/41898)（本次所见更新日期为 2026-09-02）已经建设主序预序、排序前缀和刻画、T-transform 分解及具体步骤列表。本次读取了其 head [`d73fe83b53748697e7068a471d8ff2e923e36903` 的 `Majorization.lean`](https://github.com/marcinbugaj/mathlib4/blob/d73fe83b53748697e7068a471d8ff2e923e36903/Mathlib/Analysis/Convex/Majorization.lean)，其声明包括 `majorizes_iff_descPrefixSum`、`majorizes_iff_reflTransGen_relatedByTTransform`、`majorizes_exists_tStepList`，没有找到双随机矩阵等价或一般凸函数 Karamata 接口。
- 另有开放 [PR #33406](https://github.com/leanprover-community/mathlib4/pull/33406)，其说明以酉不变范数、特别是 Schatten 范数为主序理论的消费者。这意味着不能另起整套不兼容的主序定义；正式推进前应刷新两个 PR 的关系、审阅状态和当前实现。
- [`Negative-Power-Means/HiaiLimPowerMeans/Majorization.lean`](https://github.com/marcotom/Negative-Power-Means/blob/8d9452844a62864ff6fc54ee6f11473fde6d98cd/HiaiLimPowerMeans/Majorization.lean) 已定义排序前缀和版本的 `Majorized`，并有 `Majorized.sum_exp_le_sum_exp`：对 `t > 0`，比较 `∑ exp (t*x_i)` 与 `∑ exp (t*y_i)`。这是指数函数特例，不是任意凸函数的通用接口。
- [`Zeta23/LinAlg/SchurHorn.lean`](https://github.com/Volkopat/zeta-23-lean-cubic-bridge/blob/d852551343d5238c399588d11c143a9271c283e0/Zeta23/LinAlg/SchurHorn.lean) 对特定三次函数的凸包络，使用酉矩阵元素平方模作为双随机权重，再逐行调用 Jensen 并求和。源码说明绕开一般主序理论；不能把已有的 Schur–Horn 型应用说成全无形式化。

### 复用场景和潜在消费者

- 矩阵不等式：将“对角元由特征值双随机加权得到”接到统一主序和凸函数比较接口，减少每个特殊函数重复展开 Jensen 的工作。上述 Zeta23 项目提供了具体使用形态。
- Schatten 范数、酉不变范数：这是 #33406 作者直接列出的下游需求。
- 有限概率向量的熵与凸函数和：例如从概率向量主序推出相应凹函数和反向不等式。这里只列潜在调用，不声称已完成与概率库连接。

### 最小阶段成果与障碍

1. 独立完成双随机矩阵上的一般 Jensen 求和引理；只需已有矩阵与凸函数库即可得到可调用的小成果。
2. 沿已接受或明确选定的主序 API，将一次 T-transform 写成双随机矩阵作用，处理退化参数。
3. 用有限 T-transform 链与双随机矩阵乘法闭包得到 `x ≺ y → ∃ D, Dy=x`。
4. 证明另一个方向，连接排序前缀和／最大子集和，再把一般凸函数接口接到主序关系上。

主要障碍是排序、排列、矩阵作用与类型转换，以及待合并 PR 接口仍可能变化。第 1 步不等于完成经典等价桥梁；沿 T-transform 证明的方向也不能冒充双向结果。第一次努力检查点建议止于第 1 步和一次 T-transform 的矩阵表达。

**接续第一步：** 刷新 #41898 与 #33406 的状态、实际头提交和后续分支，确认双随机矩阵桥仍未被接续实现；再决定以哪个主序 API 为依托。在当前用户授权以外，不联系贡献者、不自行升级本仓库固定依赖。

## LI3：一般次模函数贪心近似接口——待查

### 准确目标与潜在用途

有限地面集 `V`、集合函数 `f : Finset V → ℝ` 满足 `f ∅ = 0`、单调性和次模性；取 `1 ≤ k ≤ card V`。从空集开始，每步在尚未选择的元素中选边际收益最大者，进行 `k` 步得到 `S_k`。令 `OPT` 是大小至多 `k` 的子集上的最大值，目标为：

\[
f(S_k)\ge \left[1-\left(1-\frac1k\right)^k\right]\mathrm{OPT},
\]

再推出 `1 - 1/e` 界。单调性和 `f ∅ = 0` 已蕴含非负性。必须从实际贪心选择条件证明单步差距收缩，不能把收缩不等式直接列作假设后就称为完整贪心保证。

可服务于有限覆盖选择、传感器布点、测试集或候选子集选择的算法验证；这些是数学模型中的潜在消费者，具体产品仍需独立证明其目标函数和选择过程满足假设。

### 现有覆盖、疑点及暂缓原因

- mathlib 已有 matroid 秩的次模性等特定结果；本次未定位一般集合函数的完整贪心近似接口。
- [Isabelle AFP 的 Submodular_Greedy](https://devel.isa-afp.org/entries/Submodular_Greedy.html) 已有一般有限步保证和 lazy greedy 实现。已读 [Submodular_Base 源码页面](https://isa-afp.org/browser_info/current/AFP/Submodular_Greedy/Submodular_Base.html)；这是其他证明助手的先例，可以参考证明组织，不能称作 Lean 实现。
- [Wesker 固定 README](https://github.com/rohanvinaik/Wesker/blob/b81f2c4fc9992cd56cba98242a7b511101595cd5/README.md) 宣称已在 Lean 证明 `coverage_submodular`、`marginal_antitone`、`greedy_coverage_bound`。本次检查的该仓库树没有定位 Lean 文件；在相关 [LintGate 固定树](https://github.com/rohanvinaik/LintGate/tree/ef6636dfa1fa3fc772f5c29e70008ae393957de8) 中找到并读了 `docs/mutation/Aristotle/Mutation_Theory/MutationTheory/Phase7/GreedyConvergence.lean`，该文件没有上述三个声明。没有全文审计 LintGate 的全部 Lean 文件，因此只能记录“相应证明尚未定位”，不能认定宣称错误或成果不存在。

最小阶段成果可为：次模性与边际收益递减的等价；覆盖函数实例；由真实选择条件导出的单步收缩；有限步归纳界。主要障碍是找齐已有成果、分清覆盖特例与一般函数、将算法选择接到数学规格，以及避免把待证结论藏进假设。

**接续第一步：** 先定位 Wesker 所称三项 Lean 定理的准确源码、固定提交及假设，确认是否覆盖完整贪心过程；查重未闭合前不把 LI3 列为正式空白或开始重复实现。
