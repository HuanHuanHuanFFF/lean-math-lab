# 实验与复现

本目录所有脚本仅用 Python 标准库，无网络调用，无 Lean、符号计算库或概率素性测试。
文件中的时间是该次实际脚本运行时间，不是未来工作时间估计。重新运行会更新 JSON 中的运行时间。

## 运行顺序

```sh
python experiments/probes.py
python experiments/certificate_probe.py
python experiments/falsify_automatic_shape.py
python experiments/verify_certificates.py
```

## 参数、用途与覆盖边界

### probes.py → probes.json

实际进行两类失败诊断及 4 个前区间结构探测。
匹配例 (109281,114533,10) 说明 q,r>k 本身不足以保证任意匹配刚性。
修正例 (100002,100105,3) 说明小素数最大指数相等不足以强制 G 相等。
它们都不是原题反例；JSON 记录实际不相等的 LCM。
四个窗口只用于检查公式与比较判据，不是范围证明。

### certificate_probe.py → certificate_results.json

77 个前区间：基数 {10^5,10^6,10^8,10^10,10^12}，长度 {8,16,32,64,128}，偏移 {0,137,1009} 的 75 个组合，加上 (370261,100)、(100002,3)。
每个 n≥100000、n>369k。总计处理 3823 个前段元素。

生成器筛出不超过 1000000 的素数，对短整数段作完整试除分解；任何剩余因子为素数的依据是所有不超过原数平方根的素数均已试过。
保存完整因子分解、最大素数幂、平方标记和锚点支持，以及可独立检查的两点/锚点证书。

结果：锚点证书 77/77；平方阈值跨度判据 71/77；多数判据 28/77；端点乘积判据 32/77。
该样本不是随机样本，不可据此估计原题中各类参数的比例。

单独的 (n,m,k)=(370261,492113,100) 两段均无素数；保存两个精确 LCM 大整数及后段全部因子分解。
没有遍历 m，也没有重跑 m<89693。

### falsify_automatic_shape.py → automatic_shape_failures.json

目的仅为推翻“新的结构证书对所有剩余输入都自动成立”。
预先完整分解了从 1000001 到 1005008 的 5008 个整数。
然后对 k=3、8 分别最多尝试 5000 个前起点；实际在第 6、第 372 个起点即停止。
没有枚举两个区间 LCM 的相等关系，也没有将未通过证书视为碰撞。

独立验证器进一步检查失败输入的全部可能锚点，并核实没有任一锚点支持通过同一 gcd/跨度条件。

### verify_certificates.py → verification.json、abundance_constants.json

不导入生成器及其素数筛。用独立的逐奇数试除判定所有出现的素因子，核验完整乘积、素数幂、整除和证书整数不等式。
77 个前段证书全部通过；另核验 100 个后段元素。
对说明三元组分别以 math.lcm 的 gcd 递推和因子最大指数重算，两种方法一致。
还精确验证了无界 k 计数证明里的有理数常数。

这些是算术运行证据，不是纸面主定理的 Lean 形式化，也不是全题有限证书。
