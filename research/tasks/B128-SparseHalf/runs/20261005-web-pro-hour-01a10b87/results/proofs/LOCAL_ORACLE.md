# 邻接签名模板的精确优化与完整性

## 模板合同

固定一个三角形自由图及有序根集合 \(R\)。对全部顶点——包括根自身——按其对 \(R\) 的邻接位串分块。相同位串的顶点必须同权重；不额外给根顶点单独身份。每个权重在 [0,1]，顶点加权总数恰为 \(n/2\)。目标是无序边二次和。这个模板合同对结论至关重要。

非零签名块一定独立，因为其顶点拥有至少一个共同根邻点。只有零签名块可能有内部边。

设各块大小为 \(s_i\)，上三角边数为 \(E_{ij}\)，则

\[
 Q(x)=\sum_{i\le j}E_{ij}x_ix_j,\qquad\sum_i s_ix_i=n/2.
\]

## 为什么只需枚举少量分数坐标

固定零签名块的权重。若两个非零签名块 \(j,k\) 的权重都为分数，沿
\(x_j\mapsto x_j+t/s_j,\ x_k\mapsto x_k-t/s_k\)
保持质量。二次项系数为 \(-E_{jk}/(s_js_k)\le0\)，所以一个可行端点不会增加目标，并使至少一个权重成为整数。反复操作后，至少有一个全局最优点只有**至多一个非零签名块**仍为分数；零块的权重允许也是分数。

于是枚举可能的那个非零块 \(j\)，把其他非零块固定为 0/1。若没有零块，质量直接唯一决定 \(x_j\)。若有零块 \(z\)，设选中整数块总质量为 \(m_U\)，余量 \(r=n/2-m_U\)，用 \(t=x_z\) 表示：

\[
 x_j=(r-s_zt)/s_j,
\quad
 \max(0,(r-s_j)/s_z)\le t\le\min(1,r/s_z).
\]

把它代入目标，得到单变量有理二次式。记 \(L_z,L_j\) 是它们到选中整数块的边数和，其二次及一次系数为

\[
 a=E_{zz}-E_{zj}s_z/s_j,
\quad b=L_z-L_js_z/s_j+E_{zj}r/s_j.
\]

若 \(a\le0\)，只需检查两端；若 \(a>0\)，还检查落在区间内的 \(-b/(2a)\)。所有计算由 Python `Fraction` 完成。这是完整枚举公式，不是浮点优化结果。
