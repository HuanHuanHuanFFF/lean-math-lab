# 完整推导：平方行上的素数幂约分分子

日期：2026-09-11。所有新无限推导是本会话纸面证明。计算仅核验明确的有限部分；没有 Lean、人审或另一独立研究者验收。

## 0. 最强命题、增量和限制

令 Common(n,j) 表示存在同一个奇素数 p≥3 整除 C(n,3)、C(n,j)。

**定理 A。** 对所有自然数 n,j,X，若 n=X²、4≤j≤floor(n/2)，且
β=j/gcd(n,j)=q^r，其中 q 为任意素数、1≤r≤7，则 Common(n,j)。

q、X、n、j 在原命题中都无上界。r=1 采用旧任意素数 β 的结论；新增消费者是 r=2,…,7，并没有把 r 的有界范围冒充任意指数。

**定理 B（规范平方行的结构筛选）。** 令 d=gcd(β,n−1)。若 n=X² 且 d|(X−1) 或 d|(X+1)，则下列任一条件足以推出 Common：
1. β|d²；
2. β=d³。

**定理 C（有用的必要估计）。** 假定合法 noCommon、n=X²、d≥33、d|(X−ε)，ε∈{−1,1}。若 β=m d²、m 为正整数，则

    d²g < 9000m³，g=gcd(n,j)。

**大素数幂缺口收缩。** 若还有 β=q^r、q≥9000 为素数，并写 d=q^t，则

    8t≤3r<9t。

在首个允许的指数 r=8 中，必有 t=3、g<9000。这不是整个 i3 的绝对有限性。

新定理不覆盖所有非平方行，也不覆盖平方行的一般合数 β。R8={3,4,5,6,7,8,9,14} 不变。

## 1. 固定输入和最短依赖链

只采用 sources/pro-b/notes/PROOFS.md 中已交付的下列纸面/精确证书结论。记

    g=gcd(n,j), α=n/g, β=j/g, d=gcd(β,n−1), e=β/d, h=(n−1)/d。

合法 noCommon 蕴含：

(P1) 4|n，α=c2^s，c∈{1,3}，s≥1；若 c=3 则3∤g；gcd(α,β)=1。
(P2) c^4 n²g<108β³。因此也有 n²g<108β³。
(P3) n−1|3j(j−1)，n−2|6j(j−1)(j−2)。
(P4) 4(n−2)<243d³。
(P5) β≤2^20、d≤32 或 e≤7 中任一条件均已有完整子族证明。

P2 的原链是实际三次内容 H、L=C(n,3)/H、L|实际 gcd、实际判别式，再在 noCommon 下令 L 为2幂。它不需要 L 等于实际 gcd。P4 已准确处理两条完整幂整除的清分母。P5 的旧有限核验本轮不重跑、不重新计功。

C 第二轮的 sources/pro-c/notes/PROOFS.md H/L 段给相容的全层表达：

    v_p L = Σ_h [3 mod p^h > n mod p^h] [j mod p^h > n mod p^h]。

这是“同一层同时进位”的和，不是两总赋值之 min。本轮用它核对依赖边界和回归；新主证明不需要把所有运输表/Padé G 缺陷阶梯再形式化。C 的 G/C_t 整除界针对其实际反射三参数，不可直接把某个参数命名成 n−1 就当作 i3 新高度。

本轮没有新 BFT、Padé、Matveev、BEG、Dusart 或解析数论假设。Legendre/Kummer 只作完整赋值的基础核对；由逐层阶乘计数就可自证，不增加出版输入。

## 2. 一个必要商与平方行的奇偶性

由定义 n−1=dh、j=gde。gcd(g,n−1)=1、gcd(e,h)=1；因此 P3 的第一式给

    h | 3(j−1)。                                            (2.1)

这里取消的是完整 gcd 后的互素因子 ge，不取消 d 与 e 的可能共同素数。

中心 n=2j 不满足 P3 第一式：2j−1|3(j−1)，而 j≥4 时商严格介于1与2。因此 noCommon 中 n>2j，即 α>2β。

若 n=X²，则 P1 强迫 X 偶，β、d、e、h 都奇。c=3 不可能：P1 给 v_3(n)=1，但平方数的该赋值为偶数。因此平方行反例满足

    α=2^s，c=1。                                           (2.2)

假定 d|(X−ε)，ε=±1，令

    X=du+ε，v=X+ε=du+2ε，h=uv。

因为 X 偶、d 奇，u 也是正奇数；v 正奇。d≥33 保证各量远离零端点。由 (2.1)，v|3(j−1)。

## 3. 平方缺陷的两个整除式：零因子由奇偶性消掉

### 3.1 β|d²：覆盖较大的共同幂部分

写 m=d²/β，为正奇整数。整数恒等式

    m u²(j−1) − (4g−m u²)
       = g(du+2ε)(du−2ε)

给出

    v | 3(4g−m u²)。                                       (3.1)

4g−m u² 为奇数，绝不为零。n>2gβ 推出

    0<4g<2m(u+ε/d)²。

当 ε=−1，|4g−m u²|<m u²，故 du−2<3m u²。d、3mu 均奇，d<3mu+2/u≤3mu+2，故 d≤3mu<4mu。

当 ε=1，

    du+2<3m u²+12m u/d+6m/d²，
    d<3mu+m(12/d+6/d²)<3mu+m≤4mu，

其中 d≥33 保证 12/d+6/d²<1。因此两分支都有 d<4mu。又 X≥du−1>du/2，故

    X > d²/(8m)=β/8。

接 P2：X^4 g<108β³，推出

    βg<108·8^4=442368<2^20。                              (3.2)

于是 β<2^20，由旧完整基例矛盾。d≤32 已由 P5 处理，定理 B 的第一部分成立。

### 3.2 β=m d²：控制较小的共同幂部分

此时 m 为正奇整数，恒等式改为

    u²(j−1) − (4gm−u²)
       = gm(du+2ε)(du−2ε)，

所以

    v|3(4gm−u²)。                                         (3.3)

零因子同样由奇偶性排除。合法性给 0<4gm<2(u+ε/d)²。

ε=−1 时 du−2<3u²；d、3u 奇，故 d≤3u。
ε=1 时 d<3u+12/d+6/d²<3u+1，亦有 d≤3u。
因此

    3X≥d²−3。

P2 给 (d²−3)^4 g<8748m³d^6。由

    (1−z)^4≥1−4z (0≤z≤1),
    1−12/d²≥359/363>49/50 (d≥33),

可得

    49d²g<437400m³<49·9000m³。

这就是定理 C。计算只需核验固定整数余量；没有浮点边界。

## 4. 立方分拆 β=d³：把全部无界参数送入小的有限商盒

仍假定 d≥33、n=X²、d|(X−ε)，但现在 β=d³。

P4 与合法性给

    2gd³<n<61d³，故 1≤g≤30。                            (4.1)

n<61d³ 用的是 2<d³/4，d≥33 足够。
由 X=du+ε，有

    u²≤2X²/d²+2/d²<123d。

v|3(gd³−1)。乘 u³ 并用 du≡−2ε mod v，得到

    v | 3(u³+8εg)。

定义有符号整数 T=3(u³+8εg)/v。分子和分母都是奇数，所以 T 是非零奇整数。这里不假设 T 为正。

因为 v≥du−2>du/2，

    |T|<6u²/d+48g/(du)
       <738+1440/33<1000。

从定义精确变形：

    u(Td−3u²)=2ε(12g−T)。                                (4.2)

u 为奇数，故 u|(12g−T)。后者非零，因为 T 奇、12g 偶。于是

    1≤u≤1359，u 奇；−999≤T≤999，T 奇。

写 k=(T−12g)/u（k 奇），则

    d=(3u²−2εk)/T。                                       (4.3)

至此 g,u,T,ε,d,n,j 全部受到明确界定，不再有隐藏指数或 j 参数。

### 4.1 完备有限检查

只需恢复 (4.3) 的全部整数 d≥33，并核对原始规范关系、合法性、P2（放宽去掉 c^4）、P4 及 β>2^20。生成器按 g,u,k 次序；独立检查器按 g,T 枚举 |T−12g| 的全部正奇因子 u，不导入生成器。

该宽松候选域只有以下三项；本表不是原题反例：

|g|u|T|ε|d|n|j|
|--:|--:|--:|--:|--:|--:|--:|
|2|149|173|−1|385|3290628496|114133250|
|8|79|175|−1|107|71436304|9800344|
|16|71|121|1|125|78783376|31250000|

三项全部违反 P3 的第一整除。检查器直接计算原整数余数，故不需要猜最终共同素数。没有使用 α=2^s 作筛选，候选域故意更宽。

以上完成定理 B 第二部分。有限性来自 (4.1)—(4.3) 的证明，不能仅凭三项列表或程序 PASS 推出无限结论。

## 5. β=q^r 的完整分支分类

若 q=2，β 偶，与 P1 冲突。以下 q 奇。写 d=q^t，0≤t≤r；这是精确 gcd 的完整指数，不是根基。

若 β≤2^20，使用旧基例；若 t=0 则 d=1，已闭合。
若 2t≥r，则 β|d²。由于 q 奇，gcd(X−1,X+1)=2，整个 q^t 只能在一侧，故可用定理 B 第一部分。
若 r=3t，则 β=d³，同样整个 d 在一侧，可用定理 B 第二部分。

若 r>3t，由 P4、n>2gq^r 和 d≥33，

    2gq^(r−3t)<61，故 q^(r−3t)g<31。                    (5.1)

若 2t<r，写 β=q^(r−2t)d²。定理 C 给

    q^(8t−3r)g<9000，                                    (5.2)

当指数为正时是新的有效约束；指数为零只约束 g，不得当作 q 界。负指数不作整数清零。

### 5.1 指数1…7的逐类完备连接

- r=1：旧素数 β 消费者。
- r=2：t=0 或2t≥r，全部闭合。
- r=3：t=1 为立方分拆，其余由上一类。
- r=4：仅 t=1 尚需检查；(5.1) 给 qg<31，q 奇故 q≤29，β≤29^4=707281<2^20。
- r=5：t=1 给 q²g<31，q≤5，落入旧基例；只余 t=2，由(5.2)得 qg<9000。
- r=6：t=1 给 q³g<31，q≤3，落入旧基例；t=2 为立方分拆；其余闭合。
- r=7：t=1 给 q^4g<31，不可能有 q≥3；t=2 给 qg<31；t=3 给 q³g<9000；其余闭合。

所以只剩三个全参数有界域：

    (r,t,q^w g<K)=(5,2,qg<9000),(7,2,qg<31),(7,3,q³g<9000)。

### 5.2 三个尾域的完整有限算法

枚举所有奇整数 q≥3（连合数也保留，因此不需要证明有限素数表完整），β=q^r>2^20，g≥1，q^w g<K。平方行下 c=1，所以 α=2^s。

完整幂指数区间由

    2β<2^s， (2^s)²g³<108β³

确定。区间之外已被合法性或 P2 排除。检查 n=g2^s 是否为平方、d=gcd(β,n−1) 是否恰等于 q^t，以及 d 是否完整落在 X−1 或 X+1。一旦任何条件失败，该参数即不能来自目标反例。

生成器：按 q,g 枚举全部2幂。
独立检查器：按 q,2幂求解 g≡(2^s)^{-1} mod q^t，再枚举这个同余类在 q^w g<K 中的全部 g。因 q 奇，逆元对合数 q 同样存在。

三个尾域中没有任何一项通过以上联合必要条件；因此没有残留 j 或未界定指数。这里检查的是小的证明导出域，不是将有限 q 扫描外推到全部 q。

## 6. 任意大指数保留下来的新限制

令 q≥9000 为素数。t=0、2t≥r 和 r=3t 已被排除；r>3t 被 (5.1) 排除。如果 8t>3r，(5.2) 左侧至少 q≥9000，与严格小于9000矛盾。因此

    8t≤3r<9t。

首个整数解是 r=8,t=3；这时 (5.2) 只给 g<9000。q 仍无界，不能把它称为高度。一般合数 β 还可能把 d 的不同素数幂分到 X±1 两侧，这一“跨侧分拆”也没有被消掉。

## 7. C 的同层公式、跨层误读与新证明的边界

在 n=30,i=3,j=10 中，实际四系数内容 H=20，L=203，实际 gcd=1015。奇素数5只出现在实际 gcd 而不在 L，分别是 C(30,3) 的5层与 C(30,10) 的25层。因此 L 不能替成完整 gcd，也不能从 L 的光滑性反推 noCommon。

所有新证明只使用 noCommon⇒P1—P4 及旧完整基例；没有采用逆向错误推论。不同素数可使用不同极小系数，本轮从未要求一条系数同时最优。

非平方行仍是实质缺口。例如 n=2^25、j=1801²，有 g=1、β=1801²、d=e=1801、n=2·4096²，但1801不整除4096±1。平方分解不能原样搬来。实际共同素数31可由 n mod31=1、j mod31=9 证明；这个点不是反例。
