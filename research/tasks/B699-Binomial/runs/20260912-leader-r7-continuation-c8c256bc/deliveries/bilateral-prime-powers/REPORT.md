# B699 Pro B：一般行素数平方闭合与双侧缺陷二次界

## 最强结论与 R

**对全部合法 i=3 的 n,j，只要 β=j/gcd(n,j) 或 γ=(n−j)/gcd(n,j) 是素数的平方，原题成立。n 不要求平方。** 这是对上一轮“一般非平方 β=q²”缺口的完整子族闭合，而不是提高 q 或 β 的扫描终点。

还得到：**n 为平方数时，只要 β 或 γ 是任意素数幂 q^r，r≥1，全部原题成立。** 原 β 侧 r≤7 的限制取消，补上 γ 侧，素数和指数都无上界。

没有完成整个 i3，没有得到一般 n 的绝对高度；R7={3,4,5,6,7,8,9} 不变。i14 按接收快照保留作者纸面＋精确证书、未 Lean 的标签。

新结论是完整纸面推导＋必要的新精确有限证书；没有新 Lean、第二研究者审读、人类审稿或新颖性认证。

## 最有价值的连接

设 g=gcd(n,j)、M=(n−2)/2，并定义完整 gcd

    F=gcd(βγ,M),  η=2 (j奇) 或1 (j偶)。

本轮把 D 的 n−1 双侧分拆接到 n−2 的三位置分拆，证明每个 noCommon 必须满足

    η²(n−1)<τσ²F²≤9F²，  τ,σ∈{1,3}且不能同时为3。

特别是 **n≤9F²**。新引理只用两条完整幂必要整除、4|n、合法性和 gcd；不需要判别式或新的出版定理。F 是实际输入的规范函数，仍可无界，因此这不是全题有限化。

一侧 ζ=q^r 且 d=gcd(ζ,n−1)=q^t、t≥1 时，其对 M 的共同部分为1。进一步得到

    β侧：4ηg²β≤στ²d₋²≤9d₋²；
    γ侧：2ηg²γ<στ²d₊²≤9d₊²。

r>2t 立即矛盾；r=2t 迫使 g=1（β侧）或g≤2（γ侧）、τ=3，继而 n 为平方。这个中间分支再由本轮的平方位置消费者排除。t=0和t=r接冻结的小 d/e 消费者。

所以一般反例的一侧若为素数幂，必须 **r/2<t<r**，且 n 非平方。r=2 已没有可能的 t。这就是一般行素数平方闭合的来源，**不需要本轮新的四行有限证书**。

## 平方行的任意指数如何接完

D 的实际内容求值，保留尖锐常数与公因子 g 后给出

    8cg(n−2)<81d₋³， 2cg(n−2)<21d₊³。

平方行 c=1。若 d|X−ε（n=X²，ε=±1），X=du+ε，则旧分母恒等式在 ζ=md² 分支给 d≤3u（β侧）或d≤9u（γ侧）。合并新求值界后得到

## 额外的双侧统一消费者

若 β=aP^r、γ=bQ^s（a,b≥1，P,Q素数，r,s≥1），不要求 a 与 P 或 b 与 Q 互素，则

    noCommon ⇒ n≤max(9a²b², ceil(81a³/8)+1, ceil(21b³/2)+1)。

这个高度消去 P,Q,r,s,g,j 的无界量词，但 a,b 仍为参数。a,b≤21 时右边≤1,750,329，直接接旧基例，全域子族闭合，**不增加新的枚举**。特别包括两侧同时为任意素数幂的全部行（不要求平方行）。
