# 最小依赖与形式化切口

当前都是纸面／普通程序证据；没有运行 Lean，也没有核查 mathlib 是否已有下面的出版接口。不要把程序的秒级核验时间换算成 Lean 工期。

## 先接完全初等的闭环

1. 完整 noCommon ⇒ 4|n、j≤(n−2)/2、α=c2^s，以及删除**仅一次** 3 后的 N|j(j−1)、K|j(j−1)(j−2)。这些前置在本轮 PROOFS.md §1 全部重写，不需要旧百万枚举或三次内容。
2. N 两因子非空；K 的 C₁、C₂ 非空。直接给 ω(N)≤1、ω(K)≤1 的整行消费者。
3. 三个位置的精确平方 gcd 界，接到完整奇素数幂 Q²≥6n 的整行消费者。此闭环不等待本轮任何出版对数定理。
4. 通用同素数转移，显式排除将 p=3 当成 i=4 合法见证的错误。8→9 是旧归约，只复核，不重复计功。

## 三因子非空的最小剩余接口

C₀=1 原题分支归约到 n=2^v、v≥3、ℓ=3 和两个指数方程。a=2 分支由模9、7、13完全排除；a=1 分支由模27、13、37归约为 v≡2 mod36。

此后可采用以下任一种准确接口，但不能把未形式化的接口隐藏为 axiom 后宣布全题验收：

- 最小消费者高度：若 v≥3、u∈ℕ，且 3u²=4(2^v−1)(2^v−2)+3，则 v<10^22。
- 本轮实际证明该接口的方法：Pell 正解的完全下降参数化，η=2+√3；[S1] Proposition3.10 的 d=2、t=2、实位特化，ξ=(η,2)，得到 log|η^q 2^(−p)−1|>−10^18 log B。

两个指数 q,p 并不预先有界；高度界先来自出版下界，之后才用一个有理数证书压成 v<96。`minimal-log-certificate.json` 只有一个 D=3 的 r/s。

最终只剩 v=38、74，分别模17、11排除。可避免形式化 D=6 对数和两方程的186格平方测试；后者保留为本轮更强的独立备用定理，不是最小消费者依赖。

## 为什么不继续只扩固定模数

PROOFS.md §12 证明：对任意固定模数 L，任意大的 v≡2 mod36 都有可构造的局部同余见证。因此任何有限组固定模数不能替代上面的高度步骤。这个边界仅针对孤立 a=1 方程的固定模数筛，不是对所有初等方法的不可能性声明。
