# B699 · Pro D：三分配非空与平方根整行排除

**结论：本轮新增两个完整的无界整行消费者，并把它们接到跨指标同素数转移。R7={3,4,5,6,7,8,9}不变，没有新增整指标闭合。**

证据等级为作者纸面证明＋一个明确出版对数输入＋精确完备小证书。未Lean、未人审、未由第二研究者独立全篇审稿。不作全球新颖性声明。

## 1. 新闭合：M=(n−2)/2至多有两个不同素因子的全部行

对4|n、n≥8，若

    ω((n−2)/2)≤2，

则对**每个**4≤j≤⌊n/2⌋，都存在同一个奇素数p（允许p=3）同时整除C(n,3)、C(n,j)。素数大小、幂指数、n和j没有预先上界。

因此所有

    n=2p^a q^b+2，p,q为奇素数，a,b≥0，n≥8

都进入整行消费者。更强版本：M仅在v₃(M)=1时除去一个3，所得K只要ω(K)≤2即可；包括M=3p^a q^b、p,q≠3的相应行。不是把3^a统一删成3，也不是取radical。

关键结构是：设λ=3当且仅当v₃(n−1)=1，否则λ=1；μ对M作同样定义，N=(n−1)/λ、K=M/μ。每个完整noCommon输入都必须有

    gcd(N,j)>1，gcd(N,j−1)>1，
    gcd(K,j)>1，gcd(K,j−1)>1，gcd(K,j−2)>1。

这五个整数两两互素；前两个乘积为N，后三个乘积为K。故反例至少需要ω(N)≥2、ω(K)≥3。ω(N)≤1也给出一个完全初等的整行排除。

## 2. 新初等排除：完整奇素数幂的门槛降到平方根级

每个noCommon输入对s=0,1,2都必须满足

    (n−1)gcd(n−2,j−s)² < 2λ(n−2)²。

所以，只要某个完整奇素数幂Q|n−2满足

    (n−1)Q²≥2λ(n−2)²，

这一行的所有合法j便全部闭合。可用更简洁的充分条件Q²≥6n。此项**完全不依赖出版对数定理、Pell或有限扫描**，把旧r=2消费者约n^(2/3)的门槛改为约√(6n)。有限小n仍应核对常数。

它与第一项不是互相重复：n=30172有N=89·113、K=5·7·431，未被ω(N)≤1或ω(K)≤2排除，也不满足旧三个立方门槛；但431²=185761≥6n=181032，故新平方根消费者覆盖整行。

431不必是实际见证。例如j=15086时v₄₃₁C(n,j)=0，真正共同素数5的两项指数为1、3。完整核验覆盖该行15083个合法j。

## 3. 没有靠扩大扫描：困难分支已接完整有限化

三分配中的两个缺位由初等整除、奇偶性、模8和α约束排除。最后一个缺位强迫n=2^v及两个固定二次方程。

保留原题λμ=3后，第二个方程可直接用模9、7、13排除；第一个方程先被模27、13、37限制为v≡2mod36。出版输入采用Bérczes–Evertse–Győry(2013) Proposition3.10的固定d=2,t=2实位特化，原文定义和常数已核对。它**不是**E报告的争议S-unit常数接口。

最小接受链为

    原题缺位 → n=2^v → v<10^22
      → 一个严格有理逼近证书 → v<96
      → v∈{38,74} → 分别模17、11排除。

另保留更强的备用成果：不附加λμ=3时，两个固定指数方程对全部v≥3也都无解；其完整域为2×93=186格，有另一套整数算法接受。

## 4. 跨指标消费者与方法上限

同素数转移已接通。λμ=3时3∤C(n,3)，故上述整行见证自动≥5，可覆盖全部合法i=4。更一般地，只需增加gcd(C(n,3),105)=1，同一个见证就至少11，可服务R7所有合法指标。这给出条件由行本身决定的跨指标整行消费者，而不只是某一次j命中。

明确例族n=2(PQ)^(12t)+2、P,Q≥11为素数、t≥1，覆盖每行全部合法j，并对固定j给同一个p≥11。一般m版本也已写出。例族只是通用消费者的展示，不作为主推进，也不冒充全R7闭合。

另证明了一条严格边界：对最后a=1指数方程，任意固定有限组模数仍允许无穷多个v≡2mod36的局部解。因而仅增加固定模数不能替代高度界；该结论不否定自适应模数、无限下降或其他原题约束。
