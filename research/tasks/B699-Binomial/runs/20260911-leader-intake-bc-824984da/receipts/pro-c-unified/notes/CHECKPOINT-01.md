# 检查点 01：完整系数内容与高位进位

已读冻结导航，不更新其 R9 状态。以下为本轮纸面推导，非独立审计或 Lean 验收。

1. 对 F(X)=Σ_r C(j,r)C(n−j,i−r) X^r，令 H=系数 gcd，C=C(n,i)，L=C/H。
   Vandermonde 给 H|C；阶乘恒等式 C C(i,r) C(n−i,j−r)=C(n,j) f_r，配合 Bézout 给 L|C(n,j)。因此 L 是一个规范的实际共有因子。
2. F(1+X) 的第 s 项为 C(j,s)C(n−s,i−s)。整数平移保持内容。因此 L 等于这些系数除 C 后的既约分母的 lcm。
3. 对 p≥i，e=v_p C>0，ε=[p=i]，Q=p^(e+ε)，a=n mod Q<i：
   p^e|H 当且仅当 j mod Q≤a；通过时 v_p H=e。
   因而“L 的全部素因子<i”等价于所有这些有限低位条件同时通过，不等于 noCommon。
4. 通过低位条件且 b=j mod Q≤a 时，v_p C(n,j)=v_p C(floor(n/Q),floor(j/Q))。其余高位信息必须保留。
5. 对任意 p≥max(i,3)、h≥1+[p=i]，n=(p+1)p^h,j=2p^h：
   v_p C(n,i)=h−[p=i]=v_p H；p不整除 L；但 v_p C(n,j)=1。
   这是系数内容商漏掉一个实际共有素数的无限族，不是原题反例，也不证明内容路线必然失败（它仍可能发现另一个共有素数）。
6. i=3、4|n 时，v_2 H=min(v_2 n,v_2 j)。完整内容条件把 noCommon 下 L=2^ell 中的 ell 精确固定，而非仅有 U≤n。
