# 主定理：全指标、任意有理斜率的偏差整除核

这是本轮最后形成的统一核心。它把原先的“中心奇数行”和“固定比例非零行列式”合为一个定理；零格点由模q的非零条件直接排除。所有针对原题反例的结论都只在完整noCommon前提下使用；支撑选择引理本身无条件。这里D是下标集合的直径，与旧材料中的D=V不是同一个对象；本轮新证明不调用D=V。

## 1. 参数与完全有限的常数

设i≥2，1≤i<j≤floor(n/2)。取互素正整数A,B，B≥2，取任意素因子q|B。定义有符号整数

    h=An−Bj。

固定(i,A,B,h,q)后，以下量都是明确有限整数，不再含n或j。

    E={a:0≤a<i，q∤(h−Aa)}；
    D=max(E)−min(E)；
    s_q=#{p:p为素数，p<i，p≠q}；
    r=|E|−s_q；
    W= lcm(1,2,…,D) 的完整q-free部分，空lcm取1。

对a∈E、0≤b≤a，列出

    δ(a,b)=h−Aa+Bb。

它模q等于h−Aa，不为0，故δ≠0。令ε_i=i（i为素数），否则ε_i=1，并定义

    K=P_i(lcm({ε_i}∪{|δ(a,b)|:a∈E，0≤b≤a}))，
    P_i(M)=∏_{p≥i} p^{v_p(M)}。

再对每个p<i、p≠q，令

    e_p=Σ_{ell≥1} ( max_{u mod p^ell} #{a∈E:a≡u(mod p^ell)} −1 )；
    F=∏_{p<i,p≠q}p^{e_p}。

当p^ell>D时，所有a的余数不同，最大计数为1，所以和实际上有限。可按p^ell≤D计算；E非空，最大计数至少1。

### r为何严格为正

E恰好删除一个模q余数类，故|E|≥i−ceil(i/q)。若q<i，则s_q=π(i−1)−1≤floor(i/2)−1，而|E|≥floor(i/2)，所以r≥1。若q≥i，则|E|≥i−1，s_q=π(i−1)≤i−2（i=2直接成立），同样r≥1。这里只用了素数2以外均为奇数。

## 2. 无条件的小素数支撑选择

由于h≡An(mod q)，且q∤A，a∈E等价于q∤(n−a)。把这些行N_a=n−a写成

    N_a=S_a T_a，S_a=P_{<i}(N_a)，T_a=P_i(N_a)。

对每个p<i、p≠q，从E中选择一个v_p(N_a)最大的行。删除被选中的行，允许不同p选中同一行；剩余集合R至少有r项。

对任何剩余行a及小素数p，取其选中行a_p。a≠a_p且v_p(N_{a_p})≥v_p(N_a)，故

    p^{v_p(N_a)} | a_p−a，0<|a_p−a|≤D。

因此每个剩余行的S_a都整除W。

进一步，在层p^ell上，被选中行若存在任何可整除行，就必可整除。去掉它以后，剩余可整除行数最多为该层最大余数类计数减1。逐层相加、逐p相乘，得到

    ∏_{a∈R} S_a | F。

选择R中S_a最小的一行。因|R|≥r、S_a≥1，有

    S_a | W， S_a^r ≤ F。                              (M1)

这是对原始整数窗口的无条件结论，不假设这些数是光滑数，不要求不同小素数定位不同，也没有把完整幂压成支撑集合。

## 3. noCommon下转移同一行的完整大素数部分

对任意a∈E，设p≥i整除N_a，v=v_p(N_a)>0。

如果p=i且v=1，i!可能完全取消这层p，因此不调用noCommon；ε_i已把这层p放入K。

其余情形，p在长度i窗口中只有这一行，e=v_pC(n,i)=v−[p=i]>0，Q=p^v>i。由noCommon与逐层阶乘赋值非负性，b=j modQ≤n modQ=a。因此

    Q | h−Aa+Bb=δ(a,b)。

该δ属于构造列表且非零，所以p^v|K。逐素数合并，得到每个a∈E都有T_a|K。

与(M1)选出的同一行结合，即为主定理：

    noCommon ⇒ ∃a∈E，
       n−a=S_aT_a，S_a|W，S_a^r≤F，T_a|K。             (M2)

特别地，

    n−a | WK；
    n ≤ i−1+K floorRoot(F,r)。                          (M3)

floorRoot为纯整数r次根。固定(i,A,B,h)后，选择一个q|B即可有效有限化；若B有多个素因子，可同时消费每个q所得的必要条件，所选a不必相同。

**不能反向使用：**满足(M2)/(M3)只是通过必要筛选，不等于noCommon，更不是原题反例。

## 4. 与两条消费者的统一关系

### 中心偏差

取A=1、B=2、q=2、h=d=n−2j。E是原窗口中奇数行的下标，δ列表的q-free元素就是[d−i+1,d+i−1]中的奇数。K与CENTRAL_KERNEL_PROOF.md中的中心核相同。低指标支撑引理还能把S|W强化为S|c_i、c_i∈{1,3}，得到807点除数消费者。

### 固定比例

取h=0，n=Bt、j=At。现在E={a:0≤a<i，q∤a}，零格点a=Bu永远不在E。主定理直接给所有固定比例的有效有限化，不需要讨论次数E是否为0。

RATIONAL_CANCELLATION_PROOF.md保留另一条更紧的高度：它利用所有行并精确消去C(t,ceil(i/B))，在已核验范围内常比(M3)小得多。因此本轮采用“精确阶乘高度 + 主定理必要筛选”的组合，而不是强行只留一种较松估计。

### 任意固定有理偏差

B不必是偶数，h可以为负。任意既约斜率A/B、任意固定h都由(M2)处理。有限化参数是(i,A,B,h)，它们共同无界时不产生全题的绝对高度。

## 5. 比例族的7391点优化消费者

对2≤i≤14、3≤B≤8、1≤A≤B/2、gcd(A,B)=1，先使用精确阶乘高度得到原来的50330个t，再要求每个q|B都满足(M2)的同一行约束。q=2时使用更强的S|c_i；本轮h=0的全部这些格点都精确满足c_i^r≤F，所以该强化与S^r≤F可由同一行同时满足，不混用两个“存在行”结论。
