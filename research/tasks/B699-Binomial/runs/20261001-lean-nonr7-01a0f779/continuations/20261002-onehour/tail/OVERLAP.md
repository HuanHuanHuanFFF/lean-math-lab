# 新消费者区域与旧覆盖的比较

新验收消费者区域 C：`i≥131072,4096*i≤n,i<j≤n/2`。这里只讨论原题已验覆盖集合；不把纸面结论或有未证输入的条件定理算作旧无条件覆盖。

旧完整指标≤4882、旧有限n输入≤20000000均与 C 不重叠，因为 C 强制n≥536870912。但这只是两类局部比较，**不能声称 C 的每个输入均是新增**。

旧一般消费者还覆盖 `n>effectiveHeight(i)` 和 `j^4<n^3`。C 与它们均可重叠：非常大的n已在旧高度区域；固定C中的n时，足够小的合法j可以落入旧j区域。相对这两类一般区域的精确集合差是：

`C ∩ {n≤effectiveHeight(i)} ∩ {n^3≤j^4}`。

确有无限个不在这两类旧区域内的输入。取任意i≥131072，`n=4096*i,j=2048*i`。合法j在半范围端点，且

`j^4/n^3=256*i≥1`，故不满足旧严格条件`j^4<n^3`。

固定旧源 `20260909-discriminant-height-9d40056a/lean/HeightArithmetic.lean:12–21` 定义 `s=i−4*piBelow(i)` 与

`effectiveHeight(i)=2^(4*i/s+1)*i^((i+3)/s+1)`，除法为自然数除法。旧 `OriginalHeight.lean:four_mul_primesBelow_lt` 对i≥185已给0<s≤i。因此4*i/s≥4、(i+3)/s≥1，得到 `effectiveHeight(i)≥32*i^2≥4096*i=n`，所选无限线也不在旧严格高度区域。

上述集合差和无限线是执行者对固定旧定义/已验正slack消费者的纸面代数核对，不另外冒称本轮Lean重验了旧高度模块或这条集合差。新 C 消费者本身有真实Lean exit0/两项标准三公理和固定源绑定。其他已存在的条件型证书接口未穷举为覆盖集合；累计“净新增”表述限于以上明确采用的旧无条件区域。新增完整指标仍为空。
