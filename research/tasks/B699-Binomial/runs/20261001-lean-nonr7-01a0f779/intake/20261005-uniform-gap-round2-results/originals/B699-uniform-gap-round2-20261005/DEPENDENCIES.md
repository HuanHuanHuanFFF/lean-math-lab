## 1. 四种状态

**已证（纸面）**：本轮提供完整推导，仍未 Lean 化。
**可引用但待形式化**：已核对公开论文的所用声明或证明段，可作发表结果引用，不能当成 Lean 公理。
**缺原件**：没有取得指定上游全文或原始数值证书；取得题录不算取得正文。
**缺证明**：尚无独立可检查实现、证书或解析根证明。某项可以同时属于“可引用”与“缺原始证书”。

没有任何一项因 Python 标量计算或文件哈希而变为新 kernel 验收。

## 4. 已删除而非转移到别处的依赖

不再需要 Logan1988 变换定理、Bessel I0 的变换库或其特殊恒等式；本轮给出正项级数及积分恒等式。基础复分析、积分/无穷级数互换仍需要形式化，不宣称零成本。

R1 的全实数 \(|\psi(t)-t|\le3t/25000\ (t\ge10^8)\) 不再是无界输入。有限 F2 保留相同宽松精度，新无界 DB 直接针对需要的短区间。没有声称 DB 与 G 或原 U/L 逻辑等价。

## 6. 可独立证书的最小内容

**F2：** 无需证明更尖锐 .81√t，目标仅3t/25000。证书须有完整素数/素数幂覆盖，log 的有理定向包围，前缀 ψ 的累计误差，以及跳点两侧/段间单调性以覆盖所有实数。不是只核对若干整数、浮点最大误差或作者 PASS。原 I0 不能直接提供 F2。

**FH：** 只需到294912，但必须有严格 ζ/Hardy-Z 求值误差、符号区间与总数完整性（如 Turing 法或论辩原理）。N(H)≤464733 是此路线可给的保守正 ordinate 数量上界，不是已检测数。端点是否为零点也必须被完整性机制覆盖。

**标量证书：** 已交16行函数区间包围、统一48阶余项方案及精确输出。不是在每行取一个 γ 当作样本；核的单调性和 N 的部分求和使每行覆盖整个高度区间。

## 7. 独立验收停止点

从 G 的 finite/tail 拼接顺序看，第一项新缺口是 F2 的全区间证书；后续 FH、WB、N 等缺口仍真实存在。从解析依赖树根部看，WB/N 的形式化也未交。两种顺序不要混同为“只差一个小证书”。

本轮实质减少了专门数学输入与必要计算域，但未测总实现工时、总内存或核检查耗时。所有“减半”“端点下降”只针对明确的高度/范围，而不是性能外推。
