## 2. 引理实现顺序与目标类型

### 阶段A：纯实数核和真实算术对象

先从七项式证明 `spline6_nonneg`、右支撑、C⁴、积分质量1、sup界，并接 `localWeight` 的log支撑。一个建议的量词形态：

```lean
-- Specification, not a declaration supplied by this package:
∀ x : ℝ, 16000000000 ≤ x →
  ∀ p : ℕ, p.Prime → (p : ℝ) ≤ x →
    B699LocalSpline6R2.localWeight x p = 0
```

可选择先建立一般n重均匀卷积再实例化n=6，或只证明固定七项式和六次积分等价。后者规模固定，但不能只验证有限矩代替整个函数恒等式。需注意Real.log在零点的Lean约定、Nat.floor端点、sqrt分母正性，及全域C⁴不是只在结点外光滑。

随后定义真实Λ有限加权和，并证明其拆成primeMass和properPowerMass。依据唯一素底分解，不要把任意整数k次幂的多重计数等同于Λ；任意整数底只能用于后续上界。

### 阶段B：局部整数幂和全尾部单调性

首个对本轮区别有检验力的初等代表义务是 PROOF §7.2–7.3：

\[
\forall x\ge T,\quad Q_x/\sqrt{x\sqrt c}<11/1000.
\]

需要整数区间计数≤长度+1、实数1/k次幂凹性、k≤log(cx)/log2以及log²(cx)/sqrtx与log²(cx)/x的单调性。所有幂指数、严格开区间、端点零权和多重计数必须保留。

这一步不调用任何ζ或素数分布定理，适合作为下一轮真正压测形式化难度的独立模块。不建议再生成prime链替代它。

证明全实sinc有理不等式，0点用连续延拓；固定u²=3/2拼接点，给E的非负、单调、可积及两个矩。采用文中的log切线避免一般Jensen。数值常数可以由内核检查有理区间和级数尾，不允许把Python PASS作为外部预言机。

### 阶段D：实际ζ零点对象、显式公式和两个无界和
