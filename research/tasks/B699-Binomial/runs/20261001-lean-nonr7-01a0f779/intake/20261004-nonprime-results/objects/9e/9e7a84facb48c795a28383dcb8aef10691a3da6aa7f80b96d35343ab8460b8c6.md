## 最小核心审计命令

在解压后的包目录下，使用真正已经安装的 toolchain 二进制，不用 `.elan/bin/lean` shim：

```bash
LEAN="$HOME/.elan/toolchains/leanprover--lean4---v4.33.1/bin/lean"
test -x "$LEAN" || { printf '%s\n' '缺少指定 Lean；未安装、未验证。' >&2; exit 2; }
"$LEAN" --version
# 上行必须确认为 4.33.1；不匹配则停止。
env -u LEAN_SYSROOT -u LEAN_SRC_PATH LEAN_PATH= "$LEAN" AuditCoreOnly.lean
```

`AuditCoreOnly.lean` 是 core 声明全文加审计命令，可直接作为输入；无需 Lake、Mathlib 或本包的 `.olean`。
其中包含五个自定义谓词否定的 `#print axioms` 和各个整除/真因子义务。

`AuditCoreOnly.lean` → `AuditNonprimeCertificates.lean` → `AuditDefsOnlyDirect.lean` → `AuditCoreBridge.lean`。

前三个 audit 文件自包含；bridge audit 需要上述两个模块的本次独立构建对象。

脚本绑定输入与日志 SHA-256，保留退出码、实际版本输出和真实 stdout/stderr；不会填入预计的公理名单，也不会自动把任何未知公理白名单化。
