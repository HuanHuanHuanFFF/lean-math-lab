# 完整性报告的口径

SHA256SUMS.txt 覆盖最终解压目录内每一个普通文件，唯独不包含该清单自身；文件名和计数以最终回执为准。

evidence/PAYLOAD-UNPACK-RECEIPT.json 是形成最终清单前，把当时的载荷压缩到一次性 ZIP、重新解压并逐项比对的真实记录。该载荷不含此回执自身或最终 SHA256SUMS.txt，避免循环自引用。不要把载荷 ZIP 的哈希误认成最终发布 ZIP 哈希。

最终发布 ZIP 的 SHA-256、CRC、最终成员数量、全部文件哈希及实际 `sha256sum -c SHA256SUMS.txt` 的输出记在包外同名 `.zip.UNPACK-RECEIPT.json`。同名 `.zip.sha256` 用于在解压前验证整个 ZIP。最终 ZIP 回执必须外置，否则把含最终 ZIP 哈希的回执再塞进该 ZIP 会形成自引用。

`repro/package_verify.py --verify /path/to/final.zip` 可重做只读解压检查，默认不修改包或仓库。完整性通过只说明字节和打包一致，不是 Lean、axioms、normal checker 或数学验收。
