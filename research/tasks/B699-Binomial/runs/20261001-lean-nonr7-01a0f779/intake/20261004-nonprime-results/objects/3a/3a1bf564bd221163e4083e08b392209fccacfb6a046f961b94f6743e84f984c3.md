# 接口来源交叉核对

主要设计依据是先按 START-HERE 顺序读取的附件内容，而不是替换成其他 mathlib 版本。

## mathlib 固定提交

附件原字节：`input/reference/Prime-Basic.lean`；其原字节校验见附件清单及本交付静态检查记录。

公开固定提交的同名接口也经网页工具读取：

```text
https://raw.githubusercontent.com/leanprover-community/mathlib4/0df444a360eaa60ab8c11dca51a86af692955474/Mathlib/Data/Nat/Prime/Basic.lean
```

使用的 `Nat.not_prime_of_mul_eq` 接收乘法等式和两个非 1 证明，无需余因子素性。该源码也使用了 `Nat.succ_succ_ne_one`。

## Lean 固定版本的辅助引理

网页读取的固定标签源：

```text
https://raw.githubusercontent.com/leanprover/lean4/v4.33.1/src/Init/Data/Nat/Basic.lean
```

在 `Nat` 命名空间有如下声明：

```lean
theorem succ_succ_ne_one (a : Nat) : succ (succ a) ≠ 1 := nofun
```

因此主文件用 `ka = a - 2`、`kb = b - 2` 实例化该引理，避免连非 1 条件也调用判定器。

## 内核中的闭合自然数算术

Lean 官方语言手册的 Natural Numbers 章节说明 `Nat` 字面量及乘法在内核内有高效实现：

```text
https://lean-lang.org/doc/reference/latest/Basic-Types/Natural-Numbers/
```

这是选择内置 Nat 乘法的结构性依据，不是本次运行时间记录。手册 latest 页面只作机制说明，不当作 v4.33.1 的编译证据。

## 工具链可见性不等于已安装

网页工具可以读取 Lean `v4.33.1` 的 release 页面；运行容器的 `curl` 请求则实际因 DNS 失败返回 6。没有把“网页可读”说成“编译器下载、安装或执行成功”，也没有由容器获取失败推断该发布不存在。

```text
https://github.com/leanprover/lean4/releases/tag/v4.33.1
```
