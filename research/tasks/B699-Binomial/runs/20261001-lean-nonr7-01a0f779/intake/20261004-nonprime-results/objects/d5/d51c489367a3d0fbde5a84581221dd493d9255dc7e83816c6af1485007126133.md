# 失败边界

- 本轮不是 Lean 运行结果；源码级定义相等审查不等于指定工具链执行。
- 固定 Lean 核心签名已取得，不能继续沿用 R2 “未取得核心源码”作为本轮结论；但取得源码不等于安装工具链。
- 原件与上游 mathlib 的 CRLF/LF 比较必须明确规范化规则；原始字节哈希不相同，不能写成原样全部相同。
- 禁用 token 扫描只针对五个新证书的主文件，不对导入库或历史消费者作“全依赖无 by/decide”承诺。
- 不存在新用户假设或显式新增 axiom；实际依赖 axioms 仍须由 Lean 输出，不能由文字推断冒充。
- 元变量已通过显式因子固定，数值转换有冻结实现支持；但没有最大递归深度/耗时证明或实测。
- 主源码通过也不意味着完整 consumers、原 witness 链、B699 或任何数学指标新增通过。
- 环境缺失时不安装，不把网络取源码说成执行 Lean，不猜 checker 命令。
- patch 只应用于临时目录；未操作仓库。重放脚本的固定工具链分支尚未实测。
- SHA-256/解压回执只核对完整性，不能当作形式证明证书。
