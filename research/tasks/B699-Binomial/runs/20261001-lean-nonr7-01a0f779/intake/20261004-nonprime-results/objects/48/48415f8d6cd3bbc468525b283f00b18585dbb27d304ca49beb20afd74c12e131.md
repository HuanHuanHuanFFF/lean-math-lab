## 采用的证明

使用附件 `reference/Prime-Basic.lean` 第 31–32 行的实际声明：

```lean
theorem not_prime_of_mul_eq {a b n : ℕ}
    (h : a * b = n) (h₁ : a ≠ 1) (h₂ : b ≠ 1) : ¬Prime n
```

五个证书分别为：

|目标|乘法证书|两个附带子目标|
|---|---|---|
|`¬ Nat.Prime 4884`|`2 * 2442 = 4884`|`2 ≠ 1`、`2442 ≠ 1`|
|`¬ Nat.Prime 4885`|`5 * 977 = 4885`|`5 ≠ 1`、`977 ≠ 1`|
|`¬ Nat.Prime 4886`|`2 * 2443 = 4886`|`2 ≠ 1`、`2443 ≠ 1`|
|`¬ Nat.Prime 4887`|`3 * 1629 = 4887`|`3 ≠ 1`、`1629 ≠ 1`|
|`¬ Nat.Prime 4888`|`2 * 2444 = 4888`|`2 ≠ 1`、`2444 ≠ 1`|

每个结论只应用一次上述库定理。乘法等式用 `rfl`；`by decide` 仅用于明确的自然数“不等于 1”子目标，不再用于任何 `Nat.Prime` 目标。不需要证明余因子为素数，也不需要完整分解。

选择依据是证明结构，而非未取得的性能数据：只需一个库定理应用、一个闭合乘法等式和两个简单不等式；无需新增辅助引理、`norm_num` tactic import、素性搜索或提高资源限制。`Nat.not_prime_of_dvd_of_lt` 也是合理路线，但这里无需构造额外的整除存在证书和上下界。尚未在同环境比较两种成功方案，因此不宣称此实现实测最快。

Lean 官方语言参考说明，闭合 `Nat` 数值及 `Nat.mul` 在内核中有高效算术实现；普通 `decide` 使用归约，不能与引入额外信任的 `native_decide` 混同。这支持这里选取小型算术子目标的设计，但不替代本任务固定版本的编译和 checker 记录。
