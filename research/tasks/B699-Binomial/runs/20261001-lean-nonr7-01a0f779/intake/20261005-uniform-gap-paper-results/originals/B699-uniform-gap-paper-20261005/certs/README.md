# 精确算术与输入绑定的重放

Python 3.9 或更新版本，仅标准库。无需网络、Lean、素数库或 ζ 库。

在解压后的结果目录执行：

```sh
python3 certs/verify_constants.py --output certs/CONSTANTS.replayed.json
```

输出的 JSON 应与本包 `certs/CONSTANTS.json` 内容一致。它检查 46 个有理关系及 2 个额外整数幂比较；不计算 θ、ψ、素数链或 ζ 零点。全部运算由整数和 `fractions.Fraction` 完成。

指数包围：N=96，对 0≤q<N+2，S_N≤exp(q)≤S_N+[q^(N+1)/(N+1)!]/[1−q/(N+2)]。从第一个遗漏项起的后继比值均≤q/(N+2)，因此这是几何尾和上界。对 q=0 允许等号；用于严格对数/双曲函数界的所有最终分离均由严格有理关系保证。`CONSTANTS.json` 保存每个 q、N、完整分子/分母上下界，不依赖机器浮点输出。

π 下界的 26 项有限和来自 ∫₀¹ 1/(1+t²)dt 的偶数项几何截断：部分和≤被积函数，并在 t>0 严格小于它，故积分给严格下界。解析恒等式 π/4=该积分仍须在 Lean 中引用或证明；Python 只检查有理部分大于 31/10。

可选有限链的两项纯整数比较验证

```text
4096^24618 * 122568684 < 4095^24618 * 50000000000
4096^24619 * 122568684 >= 4095^24619 * 50000000000
```

它们只给备选覆盖方案至少 24,619 段的必要尺度，不证明存在这样的素数链，不是证书体积上界，也不进入主路线的数学依赖。没有生成任何 prime witness。

输入 ZIP 身份核对可单独重放：

```sh
python3 certs/verify_input.py /path/to/B699-20261004-uniform-gap-paper-1c862c44.zip \
  --output INPUT-BINDING.replayed.json
```

该脚本检查整个 ZIP 固定 SHA256、CONTENTS.json 中的全部 25 个声明成员及每项字节/SHA，拒绝多出的未列成员。`/path/to/` 由执行者替换为唯一原附件的实际路径。不要将文件身份核对称为独立数学验收；I0 仍 pending。

错误处理：不匹配或不等式失败会抛出异常并以失败退出，而不是继续输出全通过。脚本没有外部进程、下载或隐式数学数据库。
