## 2. 第一项具有新数学收益的 Lean 义务：LP

紧接消费者检查，优先形式化本轮的纯初等 LP，而不是马上部署解析全链。目标恰为：

```lean
B699UniformGapPaper20261005.LocalPowerIncrement
```

展开后为：

```lean
∀ x : ℝ, 100000000 ≤ x →
  (Chebyshev.psi (x + x / 4095) - Chebyshev.theta (x + x / 4095)) -
    (Chebyshev.psi x - Chebyshev.theta x) ≤ x / 300000
```

推荐按以下有限个通用引理分层实现，而不对 x 或素数进行展开枚举。

| 次序 | 引理类型与输出 | 关键 API / 风险 |
|---|---|---|
| LP1 | 两端使用同一自然数 K 的 ψ−θ 有限和差 | 冻结 `Chebyshev.psi_eq_theta_add_sum_theta'`；其 hx 要求 2≤x。一般 x≥1 的 K<2 零分支另处理 |
| LP2 | θ(b)−θ(a)≤(b−a+1)log b，1≤a≤b | `theta_eq_sum_primesLE`、集合差、floor/card 界；严格左端与包含右端必须对应 |
| LP3 | (rx)^(1/k)−x^(1/k)≤x^(1/k)/(4095k)，k≥2 | Bernoulli 的有限幂、正根单调、Real.rpow；不用逐次计算实根 |
| LP4 | log((rx)^(1/k))=log(rx)/k，及 x^(1/k)≤√x | 固定 mathlib 实幂与 log 的正性门；0 和 k=0 不允许隐式通过 |
| LP5 | Σk=2..K 1/k²≤1，Σk=2..K 1/k≤(K−1)/2 | 以 1/[k(k−1)] 望远镜为主；无需无限调和级数或 Basel 求和 |
| LP6 | 得到 PROOF (2.2) 的一般局部界 | 有限和单调性和有限求和代数；K 只作为变量 |
| LP7 | x≥A 时 log(rx)/√x、log²(rx)/x 递减 | 导数与半线单调性；正性条件 log(rx)>2 |
| LP8 | A=10⁸ 端点及 log(rA)<19、log2>2/3 | 通用 exp Taylor 上下界 + 证书中的有理数，不用浮点决策 |
| LP9 | LP6+LP7+LP8 ⇒ LocalPowerIncrement | 一次标量界合并 |

已有快照给出可用的共同 K 恒等式，不需要扩完整 mathlib 清单或自造新 Chebyshev 函数。最容易出现真正错误的是 LP2 的 floor/区间差、LP3 的实根正性及 LP7 的“端点够用”单调性；代表性测试先围绕这三处。

**预期规模说明：**这是约 9 个通用引理，不是 10⁸ 个实例。没有新增素数证书字节，也没有全域扫描。具体代码行数、elaboration 内存、kernel 时间尚无实测，不作保证。

## 3. 常数证书的 Lean 落地

Python 的 `Fraction` 检查结果不是内核证明。可以先实现一个通用 Taylor 定理：q≥0、q<N+2 时

\[
\sum_{j=0}^{N}q^j/j!\le e^q
\le\sum_{j=0}^{N}q^j/j!+
\frac{q^{N+1}/(N+1)!}{1-q/(N+2)}.
\]

本包统一 N=96。每个余项采用正数项的几何级数上界；将分子、分母写作显式整数，由 kernel 检查有理运算。π 的下界可从 26 项偶数几何截断的积分得到；上界 π<4 是同一积分的简单结论。

46 项关系中只有一部分用于 LP，其他用于解析尾；两项约 30 万 bit 的纯整数幂比较只为“可选有限链”的规模下界，**不进入 G 的证明依赖**，不必在主 Lean 目标中重放。

## 4. 最有价值的解析代表义务：直接高零点核界

在暂不涉及 ζ 的独立复分析模块里先证明以下形式的通用核界，避免把风险一次推给 ζ 全链：

若 c>0、a≥c、|b|≤ε/2，W²=c²−(a+ib)²，则

\[
|\Re W|^2\le c|b|+b^2.
\]

再用 sinh W/W=∫₀¹ cosh(tW)dt、复数模三角不等式取得 PROOF (7.3)/(7.4)。W=0 用 entire power-series 定义处理，不能用未证明的复平方根主值规则忽略分支。令 c=18、ε=1/32768 后常数都回到已有证书。

这一代表义务成功后，Büthe Proposition3、专门零点截断论文/博士证明便确实不再需要形式化。它仍不证明显式公式 EF；其分析底座应另行记账。

## 5. 零点计数、低零点和与有限 RH 证书

推荐将零点索引按重数实现，并明确 γ>0，分别建立：

- Z1 的半开区间 [a,b) 倒数和；本轮用 b=s+1、H+1、2H+1 覆盖闭右端，避免依赖“端点不是零点”的数值假设。
- 对包括右端的 N(t)，分部求和给 Σγ>L γ⁻² 的精确 −N(L)/L² 边界项。N 的误差若先只在非零点高度证明，可取右极限继承。
- 相同正 γ 上 β↔1−β 以及正负 γ 配对，保留重数。高处贡献系数是 (v+1) 乘正 γ 和，而不是漏一半或重复一倍。

本路线仅需 0<γ≤H=589824 在线上的有限事实。由引用的 N 估计可得到

\[
N(H)<\frac H6(\log(H/6)-1)+1+\log H
 <\frac H6\frac{21}{2}+15=1032207.
\]

因此正高度零点条目数的一个严格粗上界是 **1,032,207（计重数）**。这是条目数上界，不是证书大小或求值次数、运行时保证。每条还需要严格符号/误差区间，且完整性证明需额外内容，不能把“约百万零点”当作“小型常数表”。

小倒数和 Σ0<γ<5000 1/γ<3.54 可共享这一前缀证书，但仍必须验证 γ=5000 的边界处理与重数。公开 Platt–Trudgian 定理足以纸面引用，不自动提供已可导入 Lean 的符号表；原文说明其大计算没有储存全部高精度零点数组。

## 6. 平滑显式公式 EF 的独立工程风险

POS 的核积分身份、ζ 的基本解析性质、Weil–Barner 显式公式、零点求和的收敛和常数≤2，是主路线最重的解析基础。附件只含单个 mathlib Chebyshev 文件，不能据此宣布 mathlib 已有或没有所有所需 ζ API。

在锁定完整 mathlib 中先查可复用的函数方程、解析延拓、零点索引/计重数、积分变换和显式公式实现。缺什么就明确列什么；不通过新增 `axiom EF`、`axiom partialRH` 或证明反射信任外部程序填空。没有充分基础时先止于 LP 与条件消费者，不应因为后者编译快就预计整条解析链同样快。

## 7. 有限 ψ 桥：真正尚缺的有限工作

所需最弱有限类型是

```lean
∀ x : ℝ, 100000000 ≤ x → x ≤ 50000000000 →
  |Chebyshev.psi x - x| ≤ (3 / 25000 : ℝ) * x
```

不必为了这个目标复验论文更强的 0.81√x、[100,A) 或 [B,10¹⁹]。

若选择筛法证书：需将全部素数幂跳点和有理 log 上下界绑定。跳点之间 ψ(x)=C≥0 固定，ψ(x)/x 单调不增；因此 ψ(x)/x−1 的上下极值出现在该段的两端极限。若复验原 F，则

\[
\frac{d}{dx}\frac{x-C}{\sqrt x}=\frac{x+C}{2x^{3/2}}>0,
\]

同样只需检查所有完整分段的端点两侧。两者都是**已证明的区间覆盖机制**，而不是抽样。但必须真的取得完整跳点/前缀或足够粗而严谨的段界，不能只列一些测试值。

B−A=49,900,000,000。若暴力使用每整数一 bit 的全域位图，仅 [A,B] 的 bit 数就对应 6,237,500,000 字节，未含辅助证书。分段和压缩可大幅改变存储形态，但不会自行消去数学完备性义务；没有实测时不能断言新证书很小。

另一选择是不用 F 而改在 B 才接 G，此时新增 [T₀,B) 有限自然数段。其“每素数一个覆盖区间”链至少 24,619 段的下界已算出，但本轮没有实施，也不推荐在未比较证书路线前直接扩有限 K。这只是暴露代价，不是把任务转成扫描。
