# 标量证书的范围

输入固定为 m=8、H=1000000、T=800000000000、A=122568684、h=x/80000。

`constants.json` 中所有带分子/分母的数都来自精确有理运算；`replay.txt` 是本轮真实 Python 运行输出。51 项检查包括常数大小、最终预算和差分整数矩，不包括任何真实素数或 ζ 零点的检查。

对数使用 16 项 atanh 级数加显式几何余项；π 使用 Machin 恒等式和两个 12 项交错 arctan 包围；Euler 常数使用精确 H_200 与 log200 下界。数学依据逐项见 PROOF §10。程序只判断这些包围产生的分数比较，不能单独证明 Real.log、Real.pi、Euler 常数、ζ/ψ 与这些形式表达式一致。

重放命令（工作目录为结果包根）：

```sh
python3 src/check_constants.py --output certificates/constants.json
```

没有第三方包，不需要网络。JSON 的标量结论应与已有文件完全一致；日志中的输出路径随命令参数变化不影响检查结果。

`structural_cost_only` 的三个规模数字含义必须保留：35974 是逐 prime 覆盖模型的见证下界；73746 是条件网格的格子数上界，不是实际素数见证数或存在性证明；2000000 是由有效 N(t) 包络得到的正零点数量上界，不是已验证零点数。所有 prime/zero 原始数值证书均未提供。

本轮没有运行 Lean。Python 中出现 `passed: true` 仅表示相关整数/有理比较成功，不能当作 kernel 或独立数学验收状态。
