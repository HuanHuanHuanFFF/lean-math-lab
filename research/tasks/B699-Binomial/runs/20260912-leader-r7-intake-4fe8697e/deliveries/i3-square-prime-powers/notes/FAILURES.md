# 能力边界与未采用路线

## C 的完整内容不能逆向认证反例
C 的 L 只按同层共同进位计数。实际(n,i,j)=(30,3,10)有 L=203、gcd=1015，遗漏5。新推导没有用 L=实际gcd，没有要求一个系数对所有素数同时极小。C 缺陷商控制 Padé 反射参数的损失；它本身没有给 d/e 或 β 一个新全域高度。

## β=q² 的一般 n 仍未消去
发现性 q≤20000 检查没有找到符合完整弱投影的点，但 q 和 n 的平方自由部分仍无界。有限零残余不是绝对有限性。

## 平方分解不能套在二倍平方上
n=2^25、j=1801² 实际有 g=1,d=e=1801，n=2·4096²，但1801∤4096±1。q|2X²−1不意味着q|X±1。该点由素数31证明 Common，不是反例。

## 零因子必须有奇偶依据
若删掉 noCommon⇒4|n 的处理，n=121,j=25,d=5,u=2 可使4g−u²=0。不能把“整数整除”直接升级为非零数值界。

## 新主定理没有覆盖任意指数
对 q≥9000，余下指数必须满足8t≤3r<9t。首个未关闭方向 r=8,t=3 仅有 g<9000，q仍无界。不能把 g 有界称为完整高度。多素因子β还可能在 X−1 和 X+1 两侧分拆；本轮没有去掉这种可能性。

## 证据层次
新独立检查器是作者第二算法，不是独立研究者、Lean或人审。本轮程序是确定性的有限域检查；无限归约仍由 notes/PROOFS.md 的纸面逻辑承担。没有新增全i3/全R8闭合，没有人类审稿或新颖性检索认证。
