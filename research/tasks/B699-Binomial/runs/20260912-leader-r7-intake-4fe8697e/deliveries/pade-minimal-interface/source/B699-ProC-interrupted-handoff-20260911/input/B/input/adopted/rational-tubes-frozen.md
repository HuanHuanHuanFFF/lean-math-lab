# i=3 的统一有理斜率排除带：补齐零因子分支

## 0. 完整命题与增量

**定理 T。** 对自然数 n,j,a,b，若

\[
4\le j\le\lfloor n/2\rfloor,\quad0<2a<b,\quad
n\ge512b^6,\quad8|bj-a(n-1)|^3\le n^2,
\]

则存在素数 p≥3，同时整除 C(n,3)、C(n,j)。不要求 gcd(a,b)=1。

等价地，原题反例对每一对满足 0<2a<b、512b⁶≤n 的整数 a,b，必须满足

\[
8|bj-a(n-1)|^3>n^2.\tag{T}
\]

这是全部内部有理方向的一条带有**显式、统一**阈值的原题排除定理。旧稿 `input/previous/notes/QUOTIENT_PROOF.md` §5 已有一般有理方向商整除式，但明确留下三个零因子分支。本轮不把该整除式重新计为发现；新增是统一处理全部零分支、完整的常数估计与原题消费者。

本定理**不是**一般 i=3 的绝对有限性。a,b 可变，且未被这些带覆盖的 n,j 仍无界。它也不替代旧的边缘/中央 n^(3/4) 带；这些新带位于所有内部有理斜率附近。本文不用出版数论定理或 BFT。

旧shifted-slope报告（input/shifted/REPORT.md）另有对所有整数m的n≤33(n−1−mj)²必要条件，即平方根量级邻域，以及固定移位分子b₀或b₁≤32的整族。对a=1,b=m，本轮将该方向的大n带宽提升到n^(2/3)量级；a>1的方向也有同一个显式阈值。旧精确中心线、固定偏移与小移位分子族不重复计为新增。

## 1. 采用的完整赋值接口

反设原始 noCommon。冻结旧稿 §1 的完整证明给出

\[
4\mid n,\quad L=n-1\text{ 奇},\quad N=n-2\equiv2\pmod4,
\]
\[
L\mid3j(j-1),\qquad N\mid6j(j-1)(j-2).\tag{1}
\]

该旧稿以阶乘赋值重建无进位条件：对全部素数幂 p^e，若 p 不整除 C(n,j)，则 j mod p^e≤n mod p^e。对 p>3 使用所在窗口项的完整 p 幂；对 p=3，分母3!消去一次3，在需要时使用完整分子幂补偿。旧稿再用 n/gcd(n,j) 的素因子约束排除 n 奇和 n≡2 mod4。

因此(1)保留 p=i=3、完整幂及 n 的所有奇偶分支。原件随包保留，未重跑旧三元组扫描。(1)只为 noCommon 的必要条件，绝不声称充分。L、N也不是实际 avoidingPart D。

## 2. 一般商及精确 /4 消去

固定0<2a<b，定义

\[
h=bj-aL,\quad q=3h(h-b)/L\in\mathbb Z,
\quad r_s=sb-a,\quad C_s=r_s(r_s-b),\quad s=0,1,2.
\]

q 的整数性来自第一条(1)：h≡bj mod L。

设

\[
g(h)=\prod_{s=0}^2(h-r_s),\quad
 g^*(h)=\prod_{s=0}^2(h+r_s-b),\quad R_0=3h(h-b).
\]

因L≡1 mod N，有 q≡R₀ mod N；第二条(1)乘以 b³给 N|6g(h)。逐因子恒等式

\[
R_0-3C_s=3(h-r_s)(h+r_s-b)
\]

说明

\[
\prod_s(q-3C_s)\equiv27g(h)g^*(h)\pmod N.
\]

令 v=N/2（奇数）。由 v|3g 知 v 整除左端。另一方面，三个 q−3C_s 均为偶数：b奇时 h(h−b) 与 C_s 均偶；b偶时 h≡a mod2，q≡a≡C_s mod2。故左端被8整除。因为 gcd(v,4)=1，最终得到

\[
\boxed{N\mid Z:=\frac14\prod_{s=0}^2(q-3C_s).}\tag{2}
\]

Z是偶整数。这里消去的是准确的2赋值，不是删除素数集合中的2。

可直接检查的完整多项式身份为：令 σ=ΣC_s、σ₂=Σ_{s<t}C_sC_t，则

\[
\prod(q-3C_s)-27gg^*=(q-R_0)
[q^2+qR_0+R_0^2-3\sigma(q+R_0)+9\sigma_2].\tag{3}
\]

第一实现逐系数展开(3)；第二实现按每变量次数≤(6,6,6,3)，在7×7×7×4个整点上插值核对。(3)的无界身份来自完整展开/次数加插值，不是随机测试。

## 3. 三个零因子统一变为有界分支

假设某个 q=3C_s。内部斜率条件确保 C_s≠0。记 r=r_s、r*=b−r、C=C_s，则

\[
N=\frac{(h-r)(h-r^*)}{C}>0.\tag{4}
\]

因此 h不等于r或r*。回到原始 N|6g，而不是停留在Z=0。从(4)消去非零因子 h−r，再模 h−r*，得到

\[
h-r^*\mid6C\prod_{t\ne s}(r^*-r_t).\tag{5}
\]

右端不为零，因为 r*−r_t=(1−s−t)b+2a，而0<2a/b<1。记 D为其中两个差的乘积绝对值。有

\[
|C|\le2b^2,\quad D\le2b^2,\quad|r-r^*|\le3b.
\]

三个D可分别写成

\[
|(2a)(2a-b)|,\quad |(2a)(2a-2b)|,\quad |(2a-b)(2a-2b)|.
\]

由(5)，|h−r*|≤6|C|D；代回(4)，

\[
N\le36|C|D^2+18bD
\le288b^6+36b^3.\tag{6}
\]

若n≥512b⁶，则N≥512b⁶−2>(288b⁶+36b³)，矛盾。最后的差至少为(512−288−36)b⁶−2≥186。故**三个零因子全部被排除**，没有留下依赖 a,b 的未处理异常。

a=0和2a=b明确不在此证明内；它们已由旧边缘与中央定理另行处理。不能把(5)中零常数当成有限候选。

## 4. 非零时的完全显式大小矛盾

令T=n^(1/3)>0。由n≥512b⁶，

\[
b^2\le T/8,\quad n\ge512,\quad b\le T^2/64.
\]

最后一式由 b≤sqrt(T/8) 和 T³≥512推出。带宽条件给 |h|≤T²/2。于是

\[
|q|\le\frac{3|h|(|h|+b)}{n-1}
\le\frac{396}{511}T<\frac45T.
\]

同时 |3C_s|≤6b²≤3T/4。因此由(2)及Z≠0，

\[
N\le|Z|<\frac14(31T/20)^3
=\frac{29791}{32000}n.
\]

但N=n−2≥255n/256，且

\[
\frac{255}{256}-\frac{29791}{32000}=\frac{521}{8000}>0.
\]

矛盾，定理T证毕。所有根和除数为正；最终定理可以完全写成整数三次幂条件。

## 5. 新覆盖的含义、实际异常核验和仍无界的参数

例如a=1,b=3时，n≥373248且8|3j−n+1|³≤n²已被本定理排除。n=3j本身已有旧证明，不计新增；新增包括偏移随n增长、大小约n^(2/3)的整个邻域。所有b满足512b⁶≤n时可同时使用，并非预先固定b后才有定性有限性。

辅助核验对3≤b≤8的所有既约内部斜率、全部三个s进行了完整(5)除数恢复，共30个有限辅助族；再保留原式(1)及合法性后只剩三个不同(n,j)：

|n|j|共同素数p|v_p C(n,3)|v_p C(n,j)|
|---:|---:|---:|---:|---:|
|56|11|3|2|1|
|2072|437|3|1|2|
|11432|2415|3|1|4|

独立实现不取除数，而逐一枚举(5)给出的有限h范围，共290238个h，恢复同样结果，并直接计算实际二项式模3。此小核验不是证明所有b零分支有界的依据——后者已由(6)统一证明；也不构成任何新的全题n扫描覆盖。

**未完成：**上述带没有覆盖全部j/n。普通Dirichlet近似若仅允许b=O(n^(1/6))，清分母误差只有O(n^(5/6))保证，不够达到这里O(n^(2/3))的要求。因此不能用“有理数稠密”宣布i=3有限，也没有整个R的有效有限化。

本定理未Lean化、无人审，不主张相对所有文献的新颖性。
