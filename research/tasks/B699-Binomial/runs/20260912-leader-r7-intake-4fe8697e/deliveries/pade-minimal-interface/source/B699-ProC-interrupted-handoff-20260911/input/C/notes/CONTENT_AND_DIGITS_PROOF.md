# 系数内容、一个保证存在的公因子，以及它遗漏的高位进位

本文件给所有合法n,i,j适用的无条件代数引理，以及完整的p≥i判别。这里不是把“系数内容”首次提出作为成果；已有包中的多项式/不变量材料是相关背景。本文把它写成明确可消费的整除接口，并证明不能把低位内容当成全部公因子。

## 1. 保证存在的公因子

记k=n−j≥j>i，C=C(n,i)，并令

    f_r=C(j,r)C(k,i−r)，0≤r≤i；
    F(X)=Σ f_r X^r；H=gcd(f_0,…,f_i)；L=C/H。

所有f_r都是正整数。Vandermonde恒等式F(1)=C给H|C。又有逐项恒等式

    C(n,j)f_r=C(n,i)C(i,r)C(n−i,j−r)。                 (P1)

约去H后，L整除C(n,j)·(f_r/H)；而gcd_r(f_r/H)=1。用Bézout线性组合得

    L | C(n,j)，故 L | gcd(C(n,i),C(n,j))。             (P2)

特别地，因为每个f_r≥H，C≥(i+1)H，所以L≥i+1。因此gcd(C(n,i),C(n,j))≥i+1。它不推出最大公因子有一个≥i的素因子：整数L仍可能由小于i的素数生成。

i=1、2已经因此直接闭合：L>1且任何素因子分别≥1或≥2。这没有处理i≥3的小素数幂障碍。

## 2. Taylor系数与最小公共分母

展开F(1+X)，利用C(j,r)C(r,s)=C(j,s)C(j−s,r−s)和Vandermonde，得

    [X^s]F(1+X)=C(j,s)C(n−s,i−s)=g_s。                (P3)

整数平移X↦1+X的逆是X↦X−1，所以gcd(g_0,…,g_i)=H。因每个分数g_s/C约分后的分母为C/gcd(C,g_s)，逐素数取最大赋值得

    L = lcm_{0≤s≤i} den(g_s/C)。                       (P4)

这给一个精确整数接口，而不是仅仅使用首个分母n/gcd(n,ij)。后者是必要条件但可能丢失其余系数信息。

## 3. 内容恰好记录到哪个p进制位置

设p≥i是素数，e=v_p C(n,i)>0，ε=[p=i]，h=e+ε，Q=p^h。窗口长度i≤p，分子中至多有一个p倍数。因e>0，Q>i，且

    a=n modQ<i，v_p(n−a)=h。

**定理P。**

    p^e | H  ⇔  j modQ≤a；                             (P5)

若成立，则v_p(H)=e。

证明如下。令b=j modp、c=k modp。

若b+c≥i，由e>0已知n modp<i，所以实际上b+c≥p。存在0≤r≤i使r≤b且i−r≤c；当p=i时可选1≤r≤p−1。该项两个二项式系数均为p单位，故v_p(H)=0。并且j modp>n modp，因而j modQ>a，双方都不成立。

若b+c<i，写u=v_p(j−b)、v=v_p(k−c)，它们都是正整数。端点f_i、f_0的赋值分别为u−ε、v−ε；每个中间项至少有一个因子跨过j或k的末位余数，其赋值至少min(u,v)。因此

    v_p(H)=min(u,v)−ε。                                (P6)

另一方面a=b+c，v_p((j−b)+(k−c))=h。若min(u,v)≥h，和的赋值迫使min(u,v)=h，且j modQ=b≤a，所以v_pH=e。若min(u,v)<h，则必须u=v<h，j modQ至少p^u+b≥p>a；同时v_pH<e。得到(P5)。

p=i的ε从e到h始终保留；没有把窗口分子中的一次取消当成不存在。

## 4. 商坐标准确保留剩余全部高位

若(P5)成立，写

    n=a+QN，j=b+QJ，0≤b≤a<i，k=(a−b)+Q(N−J)。

对r≤h，j modp^r≤n modp^r，故阶乘赋值和的这些项都是0。对r>h，除以Q后的三个整数部分恰为N、J、N−J对应的整数部分。因此

    v_p C(n,j)=v_p C(N,J)。                             (P7)

这不是只检查一位；右边保留所有剩余高位。

于是，若L已经有p≥i的素因子，(P2)立刻给原题见证。若L只有小于i的素因子，则对每个p≥i整除C(n,i)都必须进入(P5)的低位通过分支；但原题是否仍有公共p，取决于(P7)右边是否正。把L当成完整gcd、或把低位通过当成p∤C(n,j)，都不正确。

## 5. 无限的高位遗漏族：不是原题反例

任取素数p≥max(i,3)，h≥1+[p=i]，令

    n=(p+1)p^h，j=2p^h。

这些输入全部合法。设e=h−[p=i]>0，则v_pC(n,i)=e。低位余数n modp^h=j modp^h=0，所以v_pH=e，p∤L。但

    v_pC(n,j)=v_pC(p+1,2)=1，

故p是一个真实的原题公共素数，只是没有出现在L中。

两个精确例子：

- (n,i,j,p)=(30,3,10,5)：C=4060，H=20，L=203，gcd(C(n,3),C(n,10))=1015。公共素数5被内容商漏掉。
- (36,3,18,3)：C=7140，H=102，L=70，实际gcd=420。这里漏掉的正是端点p=i=3。

这些例子不反驳“L总有某个≥i素因子”的更强猜想；它们只反驳“L记录所有公共大素数”和“通过低位就没有高位进位”。

## 6. i=3时的2赋值与未闭合的内容猜想

若4|n，则

    v_2 H_3(n,j)=min(v_2 n,v_2 j)。                      (P8)

证明：j奇时k也奇且j,k模4相反，所以两个端点C(j,3)、C(k,3)至少一个为奇数。若v_2j=1，k亦如此，中间两项的2赋值等于1而端点不更小。其余情况下j,k均被4整除，两个端点的赋值分别等于v_2j、v_2k，中间项不更小；它们最小值就是min(v_2n,v_2j)。

因4|n时v_2C(n,3)=v_2n，若内容商L只含素数2，则

    L=2^{v_2n−min(v_2n,v_2j)}。

这限制了L，但没有界住n或j的既约分母。本轮尚未证明所有合法i=3输入的L均有奇素因子。

精确探索：对8≤n≤10^6，首个Taylor分母3j/n迫使

    oddpart(n)/gcd(oddpart(n),3) | j。

全部满足这一必要条件的合法j共有8046635个，逐个计算四个整数系数的gcd，没有发现L为2幂者。候选过滤只是该**有界区间**中的完备过滤；它没有给出n>10^6的任何排除，不能当成全题或i=3证明。
