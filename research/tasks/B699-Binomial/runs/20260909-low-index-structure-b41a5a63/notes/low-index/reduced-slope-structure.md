## 完整目标与成果范围

原题合法输入为自然数 `1≤i<j≤floor(n/2)`，`Common` 表示存在素数 `p≥i` 同时整除 `C(n,i)` 和 `C(n,j)`。令

`g=gcd(n,j)`, `n=ga`, `j=gb`, `gcd(a,b)=1`。

于是 `g,b≥1`，`a≥2b≥2`。本路线不会把 `a,b` 的额外性质假定为原题输入；所有限制都从完整 `noCommon` 推出。

纸面得到：

1. `i=3` 的任何反例必须 `4|n`，并有
   `n−1 | 3b(a−b)`，`a≤3b²−1`，`g≤3b−1`，故 `n<9b³`。
2. `i=4` 的任何反例满足下述两个明确整除分支之一，进而在固定既约分子 `b` 时有显式高度。记
   `A(b)=4b⁴+2b³−6b²+2`，则对 `b≥2` 可取
   `n≤b A(b)²+2`。
3. 对 `i∈{3,4}`，如果 `j|n`，则完整原题成立。这一次性覆盖所有整数比例 `n=mj`，`m≥2` 无界。

这些结论不证明 `i=3,4` 的全合法输入。反例的既约分子 `b` 仍无界，故上述相对高度不能冒充绝对 n 上界。无效 S-part 有限性仅解决 `i≥5`，详见 [另记](s-part-finiteness.md)。

## 一般机制：分母支撑和行列式

### 1. 既约分母的素因子

恒等式 `j C(n,j)=n C(n−1,j−1)` 与 `gcd(a,b)=1` 给 `a|C(n,j)`。

若素数 `p>i` 整除 `a`，则它整除 `n`，且在 `(n)_i/i!` 中只有 n 这一项贡献它，所以 `p|C(n,i)`，与 noCommon 矛盾。若 `i=p` 本身为素数，`p|a` 仅可能发生在 `v_p(n)=1`；否则 `v_p C(n,i)=v_p(n)−1≥1`，同样矛盾。

因此 `a` 只含素数 `<i`，外加可能的一次幂 i（仅当 i 为素数）。特别是：

- `i=3`：`a=2^α 3^ε`，`ε∈{0,1}`；若 `ε=1`，还必须 `v_3(n)=1`。
- `i=4`：`a=2^α3^β`。

### 2. 完整素数幂的移位整除

固定 `0≤r<i`，并设 `a∤r`。定义整数

`R_r(a,b)=∏_{s=0}^r(as−br)`。

每项非零：若 `as=br`，由 `gcd(a,b)=1` 得 `a|r`，矛盾。

令 `p>i` 且 `q=p^{v_p(n−r)}`。如果该指数为正，则 `q` 是 `C(n,i)` 中的完整 p 幂。noCommon 给 `p∤C(n,j)`。现有 Kummer 模余数判据于是给

`j mod q = s ≤ n mod q = r`。

所以 `q|(j−s)` 且 `q|(n−r)`。将两式分别乘 a、b 后相减，得 `q|(as−br)`，故 `q|R_r(a,b)`。各素数幂互素，因而 `(n−r)` 的完整 `p>i` 部分整除 `R_r`。

`p=i` 为素数时必须单列：若 `v_p(n−r)≥2`，完整无进位条件仍给完整 `p^{v_p(n−r)}|R_r`；若指数恰为 1，i! 会取消这个 p，故 noCommon 不约束它。由此 `(n−r)` 的完整 `p≥i` 部分总整除 `i R_r`，不能无条件删除该 i。若 `i∤n−r` 则没有该成本。

于是：如果 `n−r` 与所有 `<i` 的素数互素，便有 `n−r|iR_r`（i 为素数），或 `n−r|R_r`（i 为合数）。这是真正的必要整除条件，不是原题同义改写。

## i=3：奇 n 和 n≡2 mod 4 的全域排除

### 奇 n

由分母支撑，a 为奇数且 `a≥2`，故 `a=3,b=1`。因此 `3|n`。取 `r=2`，有

`R_2(3,1)=(-2)·1·4=-8`。

`n−2` 为奇数且不被 3 整除，所以它的所有素因子均 `>3`。完整幂结论给 `n−2|8`，但 `n−2` 为奇数且合法范围使其大于 1，矛盾。故所有奇 n 的原题 i=3 情形成立。

### 偶 n 的基本整除

`n−1` 为奇数。取 `r=1`（因 `a≥2`，必有 `a∤1`），得到

`n−1 | 3b(a−b)`.                                        (I3)

这里保留 3 正是原题 p=i 的一次取消边界。

若 `n≡2 mod4`，a 的 2 幂至多一次，因此 `a∈{2,3,6}`。合法 `1≤b≤a/2` 与互素条件在这三个情形都迫使 `b=1`。于是 `j=g>3`，所以 `n=ga≥4a`；但 (I3) 给 `n≤3(a−1)+1=3a−2`，矛盾。这统一排除整个 `n≡2 mod4` 家族，不是有限 n 扫描。

### 固定既约分子的显式高度

对其余反例，令正整数 c 满足

`c(ga−1)=3b(a−b)`。

因 `gb=j>3`，有 `c<3b/g`，所以 `3b−cg` 是正整数。精确重排为

`a(3b−cg)=3b²−c`。

因此 `a≤3b²−1` 且 `g≤3b−1`，进而 `n≤(3b−1)(3b²−1)<9b³`。

当 `b=1` 时，`g≤2` 与 `j=g>3` 矛盾。这连同奇 n 分支证明：i=3 时所有 `j|n` 的输入都满足 Common。

## i=4：两种可计算的整数分支

现在 `a=2^α3^β`。由于 i 合数，无 p=i 取消成本。记

`P_2=b(a−b)(a−2b)`。

先排除 `a=2,b=1`，即中心比例：

- n 偶且 `n≢1 mod3` 时，n−1 互素 6；r=1 给 `n−1|1`，不合法。
- n 偶且 `n≡1 mod3` 时，n−3 互素 6；r=3 给 `n−3|R_3(2,1)=9`。由于 n−3 不含 3，只能 n−3=1，同样不合法。

之后均有 `a>2b`，所以 `P_2>0`。任何反例进入以下两支之一：

### Q 分支：n 偶且 n≢1 mod3

n−1 互素 6；r=1 直接给

`n−1 | b(a−b)`.                                         (Q)

正商 c 满足 `c(ga−1)=b(a−b)`。因为 `j>4`，有 `c<b/g`，且

`a(b−cg)=b²−c`。

故 `a≤b²−1`，`g≤b−1`，`n<b³`。当 b=1 立即矛盾。

### C 分支：n 奇，或 n 偶且 n≡1 mod3

结论为

`n−2 | b(a−b)(a−2b)=P_2`.                               (C)

分支证明：

- 若 n 奇，a 只能是正次 3 幂，所以 `3|n`。于是 n−2 互素 6，r=2 给 `n−2|4P_2`。因 n−2 奇，可以约掉 4。
- 若 n 偶且 n≡1 mod3，a 只能是正次 2 幂。a=2 已排除，故 `4|a`，也有 `4|n`。写 `n−2=2M`，则 M 为奇数且不含 3。r=2 给 `M|4P_2`，可约掉 4。又 b 与 a 互素，所以 b、a−b 为奇数，`a−2b` 恰含一次 2。于是 `v_2(P_2)=1`，奇数 M 实际整除 `P_2/2`，从而 `n−2|P_2`。

这两支覆盖所有 n，不依赖未证的比例族结论。

## C 分支的固定 b 高度与全部整数比例

由 (C)，取正整数 c，使

`c(ga−2)=b(a−b)(a−2b)`。

模 a 得 `a|2(c+b³)`；定义正整数 `h=2(c+b³)/a`。代入并展开、取消常数项，得到精确恒等式

`(gh−2b)a=2h+2gb³−6b²`.                                 (E)

右侧为 `2h+2b²(j−3)>0`，因为 `j>4`，故整数 `w=gh` 满足 `w≥2b+1`。另一方面

`h+g b³ ≤ w b³+1`，

因为差恰为 `(h−1)(g b³−1)≥0`。因此

`a≤[2w b³+2−6b²]/(w−2b)`
` =2b³+[4b⁴−6b²+2]/(w−2b)`。

若 `b≥2`，方括号非负，分母至少 1，得到

`a≤A(b)=4b⁴+2b³−6b²+2`。

再由 `n−2≤P_2<b a²` 得 `n≤b A(b)²+2`。Q 分支的更小界也被该界覆盖。这个式子不含未经界定的 a、g、h，只保留既约分子 b。

若 `b=1`，方括号为 0，从而 `a≤2`，与已排除中心比例及 `a>2b` 矛盾。因此 i=4 时所有 `j|n` 的输入也满足 Common。
