## 2. 两个大幂给非零固定差

三个 `i(i−1)` 都小于4096。对反例 n>4096，证书给两个不同素数 p,q<i，且完整二项式幂均至少 n/64。

定位时保留完整指数

`x=v_p C(n,i)+v_p(i)`，`y=v_q C(n,i)+v_q(i)`。

于是存在 `0≤a,b<i` 满足

`p^x | n−a`，`q^y | n−b`，`p^x,q^y≥n/64`。

两个指数均正，且 `p^x,q^y≤n`。如果 a=b，互素的两个幂之积整除 n−a，但

`p^x q^y≥n²/64²>n≥n−a`，

矛盾。因此 a≠b。令

`A=(n−a)/p^x`，`B=(n−b)/q^y`，`h=b−a`。

得到完整范围

`A p^x−B q^y=h`，

`1≤A,B≤64`，`p≠q` 为素数且 `p,q≤31`，`x,y≥1`，`1≤|h|≤33`。

这是有限个固定系数方程类型；p、q不同本身不保证带系数的线性形式非零，真正保证是 a≠b 与 h≠0。此处没有丢弃 h=0 分支：它已经在大 n 的同位置论证中排除，n≤4096另作有限分支。

## 3. PRIMARY Matveev 来源与精确采用方式

直接来源：E. M. Matveev, *An explicit lower bound for a homogeneous rational linear form in the logarithms of algebraic numbers. II*, Izvestiya: Mathematics 64:6 (2000), 1217–1269，DOI [10.1070/IM2000v064n06ABEH000314](https://doi.org/10.1070/IM2000v064n06ABEH000314)。已读取 [Math-Net 原文英文PDF](https://www.mathnet.ru/php/getFT.phtml?jrnid=im&option_lang=eng&paperid=314&what=fullteng) 的印刷页1218–1219，式(1.3)、(2.4)、Corollary 2.3/(2.6)。

原文对象是**对数的线性和**，不是乘积减1。用 m 表示对数项数，避免与本题 n 混用。该推论对非零线性式给

`log|L| > −C1(m) D² (A1⋯Am) log(eD) log(e B_log)`，

其中 `C1(m)≤2^(6m+20)`，`Aj≥max(D h(γj),|logγj|,0.16)`，`B_log=max(1,max |bj|Aj/Am)`。原文Corollary不要求所有对数线性独立；不能改用要求独立性的Theorem2.1来略过退化。

亦核准 Bugeaud–Mignotte–Siksek [arXiv:math/0403046，Theorem9.4](https://arxiv.org/pdf/math/0403046) 的乘积减1版本及其到 Matveev Cor2.3 的推导，作为记号交叉检查；这里的最终数值界直接使用原版 Cor2.3 的二次幂常数，不依赖记忆中的1.4公式。

## 4. 三对数与两对数退化均被覆盖

设

`L=log(A/B)+x log p−y log q`。

因为 h≠0，L≠0。全部数在实数域 Q 内，D=1。

若 A≠B，采用三个非零实对数：p、q、A/B，系数x、−y、1。即使A/B只由p、q组成而造成线性相关，Cor2.3仍适用。对既约正有理数A/B，高度至多log64，绝对对数也至多log64；p、q≤31。因此可统一取每个Aj=5。

若 A=B，实对数log(A/B)=0，不把它硬塞入原文的“非零log值”约定；直接改用两项 `x log p−y log q`。p≠q、x,y>0保证非零，取A1=A2=5即可。

三项时 `C1(3)·5³≤2^38·125<2^45`；两项时 `C1(2)·5²≤2^32·25<2^45`。由于所有Aj相同，两支都有

`B_log=max(1,x,y)`，

从而得到统一安全界

`log|L| > −2^45(1+log B_log)`。                           (M)

这里使用的是对数和L。若写 `Δ=(A/B)p^x q^(−y)−1`，则 `L=log(1+Δ)`；不能把二者直接视作同一实数。

## 5. 显式绝对 n 界

两个正整数分别是 n−a 和 n−b，差的绝对值≤33。由log导数或其定积分，

`0<|L|≤33/(n−33)<128/n`，                                (U)

因为 n>4096。令T=log n。又 p^x,q^y≤n，且log2>1/2，所以

`B_log<2T`。

将(M)、(U)结合，并用 `7log2<2^45`，有

`T < 2^45(2+log(2T))`。                                 (H)

若 T≥2^51，写T=2^51 u、u≥1。用log2<1及logu≤u−1，(H)会推出

`64u < 2+52log2+logu < u+53`，

与u≥1矛盾。因此

`log n<2^51`，`x,y<2^52`。

再用e<4，得

`n<exp(2^51)<2^(2^52)`。

n≤4096分支显然也在这个共同界内。于是三个指标的所有合法反例都有同一个明确绝对上界，j同时由j≤n/2界住。

使用的粗初等常数可不作浮点计算：`exp(3/4)>1+3/4+9/32+27/384>2`，所以log64=6log2<9/2<5；通常的指数级数给e<3<4，所以log2>1/2。本次机器运算仍仅是第1节的三个固定整数证书。
