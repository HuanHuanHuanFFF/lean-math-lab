## 锁定目标与采用事实

原题：对所有自然数 `1 ≤ i < j ≤ floor(n/2)`，存在素数 `p ≥ i` 同时整除 `C(n,i), C(n,j)`。以下必要不等式只用于假定没有这种素数的合法三元组。设 `k=n-j`、`t=π(i−1)`，`C(n,i)=UV` 为完整的小/大素数部分，阈值素数 `p=i` 保留。

采用旧纸面判别式给出的

`(n)_i^(2i−2) ≤ U^(2i−2) H_i P_i(n,j)`，

其中 `H_i=∏(ν=1..i)ν^ν`，并采用已 Lean 验证的 `U≤n^t`。已有百万指标排除仅用于说明剩余指标有界，不重新降低其阈值。

## 本轮三个候选

1. **精确常数与单调高度消费者。** 对每个 `i≥2` 且 `δ=i/4−t>0`，用精确 `H_i` 和下降乘积替代粗常数。记 `C_i=H_i^(1/(2i−2))/2^(i/2)`，则反例必须满足 `n^δ ∏(a=0..i−1)(1−a/n)≤C_i`。左侧对 `n>i−1` 严格递增。若一个整数 `N≥2i+2` 使左侧大于 `C_i`，则排除所有 `n≥N`、全部合法 `j`。预期将固定 i 的形式高度显著压低；剩余 i 在正指数集合内有界，n、j 同时有限，但数量是否实用另判。最小实验是 i=97,101,121 和其后若干点的对数高度。若仍超过可覆盖规模，不继续优化 O(i/n) 的偏移常数。

2. **小素数幂断点消费者。** Kummer 逐层给出 `v_p(C(n,i))≤floor(log_p n)−v_p(i)`，故 `U≤L_i(n)/s_i`，`L_i(n)=∏(p<i)p^floor(log_p n)`、`s_i=∏(p<i)p^v_p(i)`。这个上界只在小素数幂处跳变。固定上一步有限高度 `N_0` 后，只需检查 `O(Σ(p<i)log_p N_0)` 个断点即可严格核对所有 `N≤n<N_0` 的同一大小障碍；不枚举 n、j。预期是压缩高度上界与给出可证的有限化判据；并不自动解决低于最后断点的原题。最小实验先只作少量代表指标的浮点诊断，若高度仍极大，则把断点消费者保留为工具而不发起原题扫描。

3. **分段权重支撑乘积（新候选，待详细核验）。** 无公共素数时，每个完整大素数幂 `q=p^v_p(C(n,i))` 可定位到 `q|(n−a), q|(j−b), q|(k−c)`，其中 `0≤b,c≤a<i` 且 `a=b+c`。取整数 `1≤m<i`，权重 `A_a=max(a−m,0)`、`B_b=max(m−b,0)`、`C_c=max(m−c,0)` 满足 `A_a+B_b+C_c≥m`。因此预期 `V^m` 整除相应三组移位乘积；可消去由 `∏r!` 给出的、素数均小于 i 的固定分母。其总次数为 `E=m(m+1)+(i−m−1)(i−m)/2`，在 `m≈i/√3` 时 `E/m≈(√3−1)i<3i/4`。这可把正指数门槛从 `t<i/4` 移至 `t<(2−√3)i+O(1)`，且无需假装单侧 V 转移为充分条件。剩余障碍是完整幂定位的严密消费者及常数是否抵消指数收益。先核验 p=i、量词和固定分母，再给小范围对数诊断；若常数仍产生巨大高度，交付精确障碍与转向条件。
