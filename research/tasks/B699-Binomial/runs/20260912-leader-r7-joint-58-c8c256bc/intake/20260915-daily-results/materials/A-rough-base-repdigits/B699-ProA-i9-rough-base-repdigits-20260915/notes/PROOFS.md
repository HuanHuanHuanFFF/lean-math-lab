## 5. 等比和的完整2/5赋值：合数底也成立

置x=B^k、R_t(x)=(x^t−1)/(x−1)。B与210互素，所以B为奇数且5∤B。

### 5.1 使用的初等提升公式

对奇数u：若t奇，v2(R_t(u))=0；若t偶，

    v2(R_t(u))=v2(u+1)+v2(t)−1。                  (5.1)

对5∤B，令f=ord_5(B)∈{1,2,4}。则

    v5(R_t(B^k)) =
      v5(t)                         若f|k；
      0                             若f∤kt；
      v5(B^f−1)+v5(kt)              若f|kt而f∤k。 (5.2)

没有丢失v5(k)或v5(t)。公式(5.2)中的f与5互素。其证明只需：5|y−1时，用二项式展开逐次证明v5(y^m−1)=v5(y−1)+v5(m)，再取y=B^f。2的公式先分离奇数指数，反复因式分解y^{2m}−1=(y^m−1)(y^m+1)；当m偶、y奇时y^m+1恰有一个2因子。均不要求B为素数。

### 5.2 四种完备类型

记S25(z)=2^{v2(z)}5^{v5(z)}。定义d=d(k,t)：

| 条件 | d | S25(R_t(B^k))的上界 |

| t奇，或4|k | 0 | S25(kt) |
| t≡2 mod4且k奇 | 1 | (B+1) S25(kt) |
| t偶且k≡2 mod4 | 2 | (B²+1) S25(kt) |
| 4|t且k奇 | 3 | (B+1)(B²+1) S25(kt) |

表按行的条件构成不交完备划分，等价地先判断t奇/4|k，其次k偶，最后t mod4。证明：2的初始因子只在k奇时来自B+1；5的非平凡初始因子在f=2来自B+1，在f=4来自B²+1。f|k时初始因子已被分母消去，不得重新保留B^f−1。所有指数都由(5.1)–(5.2)控制。
