## 最重要的变化

**一般 NC5 的约分分母 α=n/gcd(n,j) 现在落入8个单高幂族；一般 NC7 落入28个单高幂族。** 这是对相应全部合法反例的必要归约，不是只覆盖某个有限n范围，也不是全域闭合。

|目标|α=c p^a 中的 p、a|允许的系数c|
|---|---|---|
|i5|p=2，a≥3|1,3,5,15|
|i5|p=3，a≥2|1,2,5,10|
|i7|p=2，a≥3|1,3,5,7,21,35|
|i7|p=3，a≥2|1,2,4,5,7,10,14,28,35,70|
|i7|p=5，a≥2|1,2,3,4,6,7,12,14,21,28,42,84|

α中若含目标端点5或7，还必须保持 v_m(n)=1、m∤g；不能因为表中出现端点因子就忽略这一限制。表是必要上包络，不保证每族或每指数真的可实现反例；部分小段可能已有旧覆盖。

采用旧FREE+/NORM原理的明确特化给

    NC5 ⇒ n<2^12 α^4； NC7 ⇒ n<2^23 α^6。

因此固定上表的指数a后，n、j、g、β和其他幂指数全有显式界；**a本身仍无统一上界**。固定α有限化是旧成果，本轮新增的是把一般α限制到这些单高幂形状。下一闭合缺口现在是这些族的统一指数界或严格下降，而不是继续增加无依据的扫描上限。

## 完整闭合的无限行区域

位置r指n−r；以下“最大幂”均指目标自己的完整源窗口。允许并列最大、不限制其他素因子或任何指数。

- i5：完整五窗口最大2/3幂由任意一个位置或H04覆盖，整行成立；min(Q2,Q3)≤4也整行成立。
- i7：完整七窗口最大2/3/5幂由任意两位置覆盖，整行成立；三位置H035、036、045、046、056也成立；min(Q2,Q3,Q5)≤6也整行成立。
- i8：完整八窗口H0357覆盖最大2/3/5/7幂时，整行成立。对合法j≥10，同一个p≥11安全转到i9。

最小幂条件等价于以下无需分解的充分行条件：

    i5: n mod8∈{5,6,7} 或 n mod9∈{5,6,7,8}；
    i7: n mod8=7 或 n mod9∈{7,8} 或 n mod25∈{7,…,24}。

这些条件全参数成立，是经过高度与有限末端接合的定理；不是观察有限同余图样再外推。

**新旧窗口不能混淆。** 新i7用到了n−6，新i5用到了n−4。新七窗口两位置结论并不无条件覆盖所有旧六窗口的同名两位置行：末项可能含新的更大幂。i5/i7分别从自己的NC出发，不直接升级为i4/i6；i8→i9保留了见证阈值与合法j。全部旧QIG/SIXG/EIGHTG、位置、LCM、α≤9、TW等继续取并集。

## 新机制与无限尾部

旧证书把j−k一类在中心为零的多项式排除在外。本轮先将其唯一合法零分支接到冻结LCM的α=2消费者，再使用完整幂格整除。同时补回奇目标源窗口的末项：p=i仍按源分母恰取消一次处理，高次完整幂没有降级。

只使用一次/二次多项式，没有提高次数。33份精确权证书给各位置结构绝对高度；从同一组证书得到统一相对界

    NC5, min Q≤B ⇒ n<2^24 B^7；
    NC7, min Q≤B ⇒ n<2^211 B^47。

B仍无界。对B=4、6，本轮进一步排空了全部末端；其中七窗口高段最终只恢复出8388608、8388609，两行都被正确目标的旧QIG排除。

八窗口新H0357取得n<2^145；高段两最大幂CRT候选域为空，低段3行完成。不是把“给定剖面一个候选”本身当作有限性。

可构造四种最大幂指数独立任意大的H0357无限行族；也可构造七窗口H01族和Q2=4但3/5幂任意大的H013族。后者的H013不是本轮已闭合三位置模式，依靠新的最小幂消费者完成。指定j后可避开旧α≤9及LCM分母域。
