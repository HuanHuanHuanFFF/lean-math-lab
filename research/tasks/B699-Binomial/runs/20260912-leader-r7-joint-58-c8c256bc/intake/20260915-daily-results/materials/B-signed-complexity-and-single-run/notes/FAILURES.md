# 失败记录与能力边界

## 已实际发现并修补的错误

单段第一窗口的初拟分类仅含平方族和(64,7)。实际探针在(v,a,b)=(6,0,4)发现(64,15)：63|3·15·14，初拟谓词返回False，程序抛出Exception并停止，未记录成功。手推中把x|8写成x=8是根因；另外检查x|16分支时也必须保留x=8。最终证明逐一处理全部二幂除子，加入(64,15)，且证明剩余小分支不可能。

最终分类在v≤180诊断及另一v≤96冻结回归均一致；二者都不是无限分类的证明来源。完整分类在PROOFS §5，不依赖扫描到某个v以后外推。

## 不是错误但被移除的限制

旧A>1时二项式可能都可约，不能伪用Eisenstein；新T1没有尝试证明不可约，而通过两圈上实际整数值的共轭关系绕过。非负系数不再需要。

## 三个不能扩大解释的边界

1. 只用第一窗口不够。A=4,k=2,f=X+1/2使第一多项式窗口成立，第二不成立。
2. 两个半径之比的具体作用不能忽略。若把移位1/2改为1/4，f=(X²+3X+2)/6是含中次数的非退化模板，取值仍在相应小整数集合。原T1没有作这种替换。
3. deg f≤k不可省略。k=1,A=1,f=X²−2X+2在X=1,2处分别取1,2，两个窗口都成立，却不属于六个线性模板。

## 一般问题仍未解决

SH只是固定符号项数／连续段数及奇部后的有效高度。r可以随v增长，m可以无界；任意实际输入不保证具有小系数且大基数的模板。不能宣称所有二幂行或一般i3绝对有限，也不能把r=2的粗界直接称为已可扫描。

新混合实例通过的是Common消费者，事实上违反W1；不是Π解，不是NC3模型。未审计它们与全部旧条带、内容、规范缺陷等消费者的并集。不同实现是作者第二实现，不能称为独立研究者、Lean或人审。
