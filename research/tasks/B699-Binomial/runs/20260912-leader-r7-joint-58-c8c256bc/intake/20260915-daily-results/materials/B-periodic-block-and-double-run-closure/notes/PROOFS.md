# 完整证明：任意重复字块、近周期整数带与两次重复的单段字块

研究对象：自然数 `4≤j≤⌊n/2⌋`，目标是存在同一个奇素数 p（包括 p=3）整除 C(n,3)、C(n,j)。NC3 为否定。证据等级：作者纸面推导＋本包精确有限证书；未 Lean、未第二独立研究者或人类审稿。

以下 W1/W2 只是必要投影；从未把它们当成 NC3 的等价定义。本轮不使用 D=V。字块系数 a、长度 d、重复数 k 与旧规范分配块 C_s 没有混用。

## 0. 最强结论

令 x≥2、k≥3 为整数，S=(x^k−1)/(x−1)。

**T1（任意字块，任意重复次数≥3）。** 若 n=x^k、输入合法，且 j 或 n−j 等于 aS，a 为整数，则 Common。非平凡的系数自动满足 1≤a≤x−2。a 的数字复杂度完全不设界。

**T2（近周期带）。** 同样 n=x^k、k≥3。若存在整数 a,e，j=aS+e 且
`3e(e−1)<S`，则 Common。e 可为负，且可以随 n 增长；不是固定误差后的相对高度。

**T3（二次重复，字块只有一个连续1段）。** n=2^(2d)，d≥1。若
`j` 或 `n−j` 等于 2^a(2^b−1)(2^d+1)`，其中 a≥0,b≥1,a+b≤d，且原输入合法，则 Common。d,a,b 全部无界。

结合已交付单段结论，二幂行中“由同一个单段字块重复任意次数”全部闭合；重复≥3时则根本不限制字块内部结构。

R7不变。一般二次重复、任意错位的两个连续段、一般非周期词及一般奇部/规范缺陷仍未闭合。没有新的全指标绝对高度。

## 1. 完整估值前置与可直接计算的共同除子

对素数 p 和 0≤u≤n，阶乘逐层相减给
`v_p C(n,u)=Σ_{h≥1}[u mod p^h > n mod p^h]`。
这是精确整数公式；本轮同时核对官方 mathlib 文档的同一 Kummer/Legendre 表述，但不从当前文档推断本项目的 Lean 验收。

### 1.1 采用并重写 NC3 的基本分支

令 g=gcd(n,j)、α=n/g、β=j/g。恒等式 `j C(n,j)=n C(n−1,j−1)` 给 α|C(n,j)。
NC3 下，α 的奇素因子只能是3，而且至多一次；出现时 v₃(n)=1。否则该奇素数也整除 C(n,3)。

n奇时 α=3、β=1，所以 n=3j。n−2>1且与6互素。取其素因子 p≥5；NC3 要求 j modp≤2，但3j≡2(modp)使p整除−2、1或4，不可能。

n偶时 n−1的每个完整奇素数幂迫使 `n−1|3j(j−1)`。对p=3，只在分子恰有一个3时由外部3补偿；有两个或更多3时该素数已在C(n,3)出现，必须保留整个分子幂。若v₂(n)=1，则α∈{2,3,6}，合法性和互素性给β=1，n=αj。取消gcd(j,n−1)=1后需n−1|3(j−1)，其正比值或小于1，或严格在1与2之间，矛盾。中心n=2j也以同式排除。

因此
`NC3 ⇒ 4|n, 4≤j<n/2`。

进一步，n−2的唯一2因子由6支付，奇素数按同一完整幂推理，得到：
```
W1: n−1 | 3j(j−1)
W2: n−2 | 6j(j−1)(j−2).
```
对ζ=n−j，两式也成立：模n−1有ζ≡1−j，模n−2有ζ≡2−j。

这里采用的旧完整证明及单段分类在 `sources/previous/notes/PROOFS.md` §1、§5—6；原ZIP和逐成员哈希随包保留。未重跑旧全链。

### 1.2 共同除子证人（用于新消费者，不主张它是另一独立发现）

对4|n，定义
```
Z₁=(n−1)/gcd(n−1,3j(j−1)),
Z₂=(n−2)/gcd(n−2,6j(j−1)(j−2)),   Z=Z₁Z₂.
```
则无条件有
`Z为奇数，Z | gcd(C(n,3),C(n,j))`。

证明：设奇素数p^e||(n−r)，r=1或2，B=v_p(∏_{s=0}^r(j−s))，δ=[p=3]。
Z_r中指数为max(0,e−δ−B)。它不超过C(n,3)中的e−δ。若h>B且h≤e，j modp^h≤r将使p^h整除乘积，矛盾；故这些层全部进位，C(n,j)中的指数至少e−B。p=2在Z₁中不出现，在Z₂中被6和v₂(n−2)=1完全取消。n−1、n−2互素，故两个除子可相乘。

所以，对本轮偶数行，排除W1/W2的同时，就得到可以仅用整数gcd计算的完整Z>1。Z不等于全部实际gcd；例如(56,11)给Z=1，但实际gcd=840。

## 2. 任意重复字块：消掉底数和重复数的大尾部

本节甚至证明纯整数命题：x≥2,k≥3,1≤a≤x−2，ζ=aS，S=1+x+⋯+x^(k−1)，则W1/W2不可能同时成立。无需假定x为二幂，也无需数字稀疏性。

置D=x−1，n=x^k，n−1=DS，Dζ=a(n−1)。若W2成立，乘D³并模n−2约化，得到
```
n−2 | F_D(a),   F_D(a)=6a(a−D)(a−2D).
```
只是乘法，未假设D与n−2互素，更未擅自取消分母。

1≤a<D时，F_D(a)>0。由 a(D−a)≤D²/4 及2D−a<2D，
`F_D(a)<3D³`。

当k≥4，
```
x^k−2 ≥ x^4−2 >3(x−1)³,
```
因为 `(D+1)^4−2−3D³=D⁴+D³+6D²+4D−1>0` 对D≥1成立；平移D=1+z后系数为[11,23,15,5,1]全部正。

所以k≥4的全部a、x一次排除。字块内部可以任意复杂，k也可以无界。本段没有有限表。

## 3. 三次重复：商只有1或2，底部只有七项

现在k=3。由0<F<3D³<3(n−2)，W2迫使
`F=q(n−2), q∈{1,2}`。

W1取消S后等价于D|3a(aS−1)，而S≡3(modD)，故
`D|f=3a(3a−1)`。
上式F=q((D+1)³−2)模D给
`D|g₀=6a³+q`。

精确消元：
```
h=9g₀−(6a+2)f=6a+9q,
h(9q−6a+2)+4f=9q(9q+2).
```
因此
```
q=1 ⇒ D|99,
q=2 ⇒ D|360.
```
这是完整、可计算的范围，不含未知高度或指数。枚举两个常数的全部正除子及1≤a<D，并保留f≡g₀≡0(modD)，恰得：

|q|D|a|F−q((D+1)³−2)|
|---:|---:|---:|---:|
|1|11|4|1298|
|2|2|1|−32|
|2|4|3|−156|
|2|5|2|−140|
|2|10|2|−930|
|2|10|7|−1020|
|2|20|7|−500|

全不为零，全部排除。

`generate.py`从平方根配对生成除子；`check_certificate.py`从1到常数逐整数重建除子，并反向枚举x,a核对精确集合。它还在已证明的整个2≤x≤361、1≤a≤x−2范围直接检验原始两个投影。这个直接检查有64620个(a,x)，其中1564项通过W1，无项同时通过W2；它不是扫描任意原题高度盒。

七行证书是有限证明的组成部分；两种实现在同一会话编写，不冒充外部独立审稿或Lean。

## 4. 接回全部合法n,j及近周期带

若n=x^k且j=aS合法，则1≤a≤D−1。若n−j=aS也合法，同样1≤a≤D−1。两投影对补指标对称，§2—3给出矛盾。x奇的输入也可先用§1的奇行排除。T1得证。

若j=aS+e、a,e∈Z，W1意味着 `S|3e(e−1)`。
每个整数e都满足e(e−1)≥0。若3e(e−1)<S，只能e=0或1：
- e=0，T1直接排除；
- e=1，n−j=(D−a)S，T1处理补指标。
原合法性排除a=0、D等端点，不需事先猜a的范围。T2得证。

该带允许|e|达到常数乘√S，故误差无界。大多数非零误差被W1直接排除；这里新接通的是原来e=0、1的整族零残量，不把每个推论分别累计为独立突破。

对二幂n=2^v，任一NC3输入j（或n−j）的v位二进制字串（允许前导零）若是某字块重复k次，k必须≤2。这一次排除了任意字块、任意k≥3，而不是下一档1的个数或连续段数。

## 5. 两次重复的单段字块：严格使用旧W1分类，不伪称NC3下降

令x=2^d、u=2^a(2^b−1)、a+b≤d，ζ=u(x+1)，n=x²。
取合法j，使ζ等于j或n−j。因此0<u<x且min(ζ,n−ζ)≥4。
W1等价于
```
x−1 | 3u(2u−1)
```
（先取消x+1，再模x−1）。
由于x−1奇，置J=2u，等价于
`x−1|3J(J−1)`。

注意：没有证明(x,J)为NC3，甚至J未必合法。本节只在明确合法分支使用旧**第一窗口**单段分类，然后回到原n,j使用W2。

### 5.1 u<x/2

J是单段，2≤J<x。
若J≤x/2：
- J=2时x−1|6，只能x=2或4；x=2不合法，x=4给(n,j)=(16,5)。
- J≥4时旧单段W1分类只可能给
  `x=y²,J=y(y−1)/2,y=2^b≥4`，
  或(x,J)=(64,7),(64,15)。后两项因J偶排除。
  故得到
  `n=y⁴,j=y(y−1)(y²+1)/4`。

若J>x/2，则单段形状强迫J=x−2^(a+1)。补值x−J是单个位。其W1成立；若至少4，旧分类无任何这样的解。若等于2，x−1|6只可能x≤4，与本分支矛盾。因此无新增情形。

### 5.2 u≥x/2

单段形状给u=x−2^a，0≤a≤d−1。
- a=0给ζ=n−1，原输入不合法。
- a=d−1给j=x(x−1)/2，属于旧已闭合平方单段族。
- 1≤a≤d−2时，J≡2−2^(a+1) mod(x−1)。置V=2^(a+1)−1，W1等价于(x−1)|3V(V−1)，且3≤V≤x/2−1。
  V=3强迫x−1|18，在二幂x及本分支范围中无解。
  V≥7时V奇；旧平方单段族的合法V都为偶数，故只剩
  `(x,V)=(64,7),(64,15)`。
  回到原输入，分别给(n,j)=(4096,196),(4096,456)。

因此原W1在该整个双字块子域恰好只留下：
1. 旧族n=x²,j=x(x−1)/2；
2. 新待处理族n=y⁴,j=y(y−1)(y²+1)/4，y为至少4的二幂；
3. (16,5),(4096,196),(4096,456)。

没有把有限探针的模式当成这一分类的证明。

## 6. 在同一个原n,j上消掉第二窗口

旧族第1类的原W2乘8后模x²−2给 `x²−2|12x`。
M=(x²−2)/2为奇数且与x互素，故M|6；x≥4给M≥7，矛盾。

新族第2类置P=y(y−1)(y²+1)，4j=P。W2乘64并模y⁴−2，有精确余式
```
6P(P−4)(P−8) ≡ 6T(y),
T(y)=3y³−8y²+12y+6.
```
M=(y⁴−2)/2奇；y为二幂使y⁴≡1(mod3)，所以gcd(M,3)=1。由2M|6T得到M|T。
然而y≥4时0<T<M，因为
```
2(M−T)=y⁴−6y³+16y²−24y−14
       =(y−4)⁴+10(y−4)³+40(y−4)²+72(y−4)+18>0.
```
严格矛盾，整个y尾部一次闭合，没有枚举粗高度。

三个小例原W2余数分别为10、2676、2914。T3得证。
此分类的两个无限幸存族其实分别有β=x−1、β=(y−1)(y²+1)，均整除n−1，因此与历史e=1消费者重叠。本节登记的是完整形状分类和更短末端，不重复登记这些旧子族为新的残余核心排除。§5—6也处理了补指标的单段字块，不擅自把j的形状推广成所有j。

## 7. 核验用途、能力边界及真正剩余

- 新有限证明底部：7个立方状态＋3个低例；完整范围的来源在§3、§5。
- 精确代数：稀疏整系数展开、另一稠密长除法，以及带明确双次数界的15点身份核验。不是浮点近似。
- 3720项重复字块、5952项双单段字块、6016项近周期带均是实现回归，不承担无限论证。
- 3969个实际二项式对核验完整共同除子Z；(56,11)保留Z=1、gcd=840及3的高层进位，说明投影弱解不是反例。
- 非对齐等长双段只在v≤64诊断；两次任意字块只在2≤x≤2000诊断。都没有范围外的完备性结论。
- 两次任意字块的W2商不再有统一常数上界。已通过W1的新族第2类有x=y²、u=y(y−1)/4，F/(x²−2)>x，随x无界。这明确指出§3的七状态机制不能直接移植；并不否定其他方法。
- 一般反例仍可由不可约的长字块组成，或恰好重复两次但字块内部复杂。一般奇部、运行段数、规范缺陷、F、min C_s仍无界。R7不变。
