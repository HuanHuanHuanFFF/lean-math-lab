# 完整证明：平方行的两邻分配、任意双字块与素数幂邻平方整行

日期：2026-09-15。所有自然数输入满足 4≤j≤⌊n/2⌋，Common 指同一个奇素数 p≥3 同时整除 C(n,3)、C(n,j)，NC3 是其否定。本轮作者纸面证明与有限整数证书分开；未 Lean，未外部独立研究者或人类审稿。

## 0. 最强结论

**SQ（本轮主定理）。** n=x²、x≥2 时，只要 x−1 或 x+1 中有一个整除 j 或 n−j，就有 Common。x、字块系数、n、j 全部无界。

**PPROW（新的整行消费者）。** 对每个奇素数 P、每个整数 a≥1、任一符号，n=(P^a±1)² 的全部合法 j 满足 Common。P、a 均未固定。若取减号得到 n=4，则合法输入为空。

**平方行必要条件。** 任何 NC3 平方行 n=x² 都有偶数 x，并且 x−1、x+1 各至少含两个不同素因子。因此 ω(n−1)≥4。没有推出任一因子或素数数目有上界。孤立的一次3从N中取消时，不得无条件将ω(n−1)≥4改成ω(N)≥4。

**PERIODIC（合并旧已证结果）。** n=x^k、x≥2、k≥2，S=1+x+…+x^(k−1)；若 S 整除 j 或 n−j，则 Common。k≥3 是上轮已交付；本轮补齐 k=2 的任意字块，不限位数、段数或素因子形状。

**ALTERNATING（本轮完整形状消费者）。** x≥2、k≥2、0≤A<x，令 ζ 的 x 进制 k 个数字交替为 A、x−1−A，最低位为 A。若 j=ζ 或 j=n−ζ 合法，其中 n=x^k，则 Common。偶数 k≥4 使用 PERIODIC，k=2 使用 SQ 的 x−1 分支；奇数 k 的新尾部及有限底部见§8。

R7仍为{3,4,5,6,7,8,9}。没有整个 i3 的绝对高度；非周期词、一般平方行、一般奇部及规范缺陷仍可能无界。

## 1. 原题前置：完整素数幂和孤立3的精确取消

令 ζ 为 j 或 n−j，g=gcd(n,ζ)，α=n/g。阶乘恒等式

    ζ C(n,ζ)=n C(n−1,ζ−1)

给 α|C(n,ζ)。这是无条件结论。素数 p 的阶乘估值精确给出

    v_p C(n,ζ)=Σ_(h≥1)[ζ mod p^h > n mod p^h]。

证明可由三个阶乘的逐层地板差得到；所有项非负。官方 mathlib 的 Nat.factorization_choose/Legendre 文档另作出处核对，不把文档存在当成本轮 Lean 验收。

NC3 下 α 的奇素因子只可能为3，且出现时必须 v₃(n)=1、其在 α 中的指数为1；否则该素数同时整除 C(n,3)。

### 1.1 非4倍数及中心

n 奇时，α 只能为3，合法性和 gcd(α,ζ/g)=1 强迫 n=3j（取原来的较小 j）。取 n−2 的素因子 p≥5，NC3 迫使 j modp∈{0,1,2}，但 3j≡2 modp 使 p 分别整除2、1或4，矛盾。

n 偶时，完整奇素数幂首先给 n−1|3j(j−1)。若 n=tj、t≥2，取消 gcd(n−1,j)=1 后要求 n−1|3(j−1)。t≥3时正比值小于1；t=2、j≥4时严格在1和2之间，均矛盾。若 v₂(n)=1，则 α∈{2,3,6}，互素合法约分分子只能为1，恰属该整数比例。因此

    NC3 ⇒ 4|n，4≤j<n/2。

这些前置在 sources/PERIODIC_PROOFS.md §1已有完整证明，这里展开以使新主链独立可读。

### 1.2 两个实际规范窗口

在4|n时，令

    λ=3 若 v₃(n−1)=1，否则1； N=(n−1)/λ；
    M=(n−2)/2； μ=3 若 v₃(M)=1，否则1； K=M/μ。

则 NC3 蕴含

    N|ζ(ζ−1)，K|ζ(ζ−1)(ζ−2)。                         (NW)

p≥5 时，p^h|n−r（r=1或2）使 p 出现在 C(n,3)，故 NC3 要求 ζ modp^h≤r。p=3 时，分子窗口只出现一次3会被3!取消；至少出现两次时 p=3 已出现在 C(n,3)，因此仍须使用分子窗口的**整个**3幂。不能把27降成9。

由(NW)总能得到弱窗口

    n−1|3ζ(ζ−1)，n−2|6ζ(ζ−1)(ζ−2)。                    (W)

若9|n−1，则λ=1，必须保留更强的 n−1|ζ(ζ−1)。本轮在消除二进制指数的3倍数时，实质使用了这一加强。

对平方 n=x²，每个奇素数 p|n 都出现在 C(n,3)：p=3也有 v₃(n)≥2。因此 NC3 平方行进一步满足

    α 为2的幂；x奇时立即矛盾。

以后只需 x偶。这个平方行结论不是对一般 n 无条件断言 α 为2幂。

## 2. 一个统一的相关商：q无界，但ρ只能取有限值

令 ε∈{1,−1}，并设

    n=x²，D=x−ε，ζ=a(x+ε)，1≤a≤D−1。

合法的 j 或 n−j 若是 x+ε 的倍数，系数自动在此范围，因为 ζ≥4 且 ζ≤n−4。

由 Dζ=a(n−1)，第二弱窗口与 gcd(D,n−2)=1 给

    n−2 | F_D(a)， F_D(a)=6a(a−D)(a−2D)。

只乘 D³ 先得到必要整除；由于 (x−ε) 与 x²−2 的 gcd 为1，这一步也可以安全反向取消。因0<a<D，F_D(a)>0，所以定义正整数

    q=F_D(a)/(x²−2)。

q本身不作任何固定上界假设。第一弱窗口取消 x+ε 后给

    D|3a(2εa−1)。

由于 n−2≡−1 modD、2F_D(a)≡12a³ modD，且

    12a³−3a = 3a(2εa−1)(2εa+1)，

得到 D|2q+3a。因此

    ρ=(2q+3a)/D ∈ Z_(>0)。                              (RHO)

两个窗口已变成同一组原参数的精确三次式

    P_(ρ,ε)(x,a)=12a(a−D)(a−2D)−(ρD−3a)(x²−2)=0。        (P)

没有独立选择另一个x、另一个j或另一个商。

### 2.1 ε=1：1≤ρ≤5

有 x²−2=D²+2D−1>D²，且

    6D³−2F_D(a)−3aD²=3(2D−a)(2a−D)²≥0。

所以 ρD³<2F_D(a)+3aD²≤6D³，故0<ρ<6。

### 2.2 ε=−1：x≥14时1≤ρ≤6

此时 x²−2=D²−2D−1，D≥15，并有

    ρ < 6D²/(D²−2D−1) <7，

因为 D²−14D−7=(D−15)²+16(D−15)+8>0。所有小偶数x≤12在§5完整单列；绝不把高端ρ≤6用于低端。

## 3. 完整α形状消去底数的奇部，再消去两个商值

写 x=m2^s，m奇。平方NC3的α为2幂，故m²|g|ζ。又gcd(m²,x+ε)=1，得到m²|a。

由m²|F_D(a)、gcd(m²,x²−2)=1，得到m²|q。因gcd(m²,D)=1，(RHO)给

    m²|ρ。

前述ρ≤5或6使奇数m只能为1。因此所有高端反例底数都必须

    x=2^s。

这个消元正是原NC3比两个弱窗口额外提供的信息。没有证明任意偶x的弱窗口单独永无解。

(P)在ρ=3、6时分别精确分解为

    P_(3,ε)=3(a−D)(4a²−8Da+x²−2)，
    P_(6,ε)=3(a−2D)(4a²−4Da+x²−2)。

0<a<D保证线因子均非零；两个二次因子对偶x都为2 mod4，不可能为0。因此ρ≠3,6。两符号最终共同只剩

    ρ∈{1,2,4,5}。

## 4. 完整3幂把指数限制到准确余数类

x²−2不被3整除，所以3|q。由ρD=2q+3a，如果3∤D，则3|ρ，与上节矛盾。故3|D，即

    ε=1 ⇒ s偶； ε=−1 ⇒ s奇。

若3|s，则9|2^(2s)−1=n−1，规范窗口必须保留整个3幂：n−1|ζ(ζ−1)。消去 x+ε 后有 D|a(2εa−1)。

令Q=q/3。模D有 Q≡−2a³，故

    2Q+a ≡ −a(2εa−1)(2εa+1) ≡0 modD。

于是ρ=3(2Q+a)/D为3倍数，再次矛盾。因此全部无界指数只可能

    ε=1：s≡2或4 (mod6)；
    ε=−1：s≡1或5 (mod6)。                               (EXP)

这里没有用对数、素数分布或逐指数扫描。

## 6. 继续接到整行：n=(P^a±1)²

设x+ε=P^a，P为奇素数。除(P,a)=(3,1)外，P一定整除C(x²,3)：P≥5时不受3!影响；P=3,a≥2时分子至少两个3，仅取消一个。

若NC3，完整的模数P^a仍必须满足 j modP^a≤1。于是P^a|j或P^a|j−1。第二种情况下，因为P^a|n−1，有P^a|n−j。两种都与SQ矛盾。

(P,a)=(3,1)只给x=2或4。x=2无合法输入；n=16的j=4,…,8分别有奇gcd 35、7、7、5、5，`finite_bottom.json`保存并由原始整数二项式重算。（完整gcd可含2幂，此处只列奇部。）

所以PPROW覆盖全部无界P、a、j。特别地，NC3平方行必须使x−1和x+1均非素数幂。它们为大于1的互素奇数，因此各至少两种素因子，ω(n−1)≥4。

本定理不要求P就是最终共同素数；它可能由与P不同的奇素数排除。没有把此整行族当成整个i3。

## 7. 不分解大数即可输出完整共同奇除子

对任意4|n的合法输入，按§1定义N,K，令

    E0=oddpart(gcd(C(n,3),n/gcd(n,j)))；
    E1=N/gcd(N,j(j−1))；
    E2=K/gcd(K,j(j−1)(j−2))；
    W=E0·gcd(C(n,3),E1)·gcd(C(n,3),E2)。

无条件有W为正奇数且W|gcd(C(n,3),C(n,j))。

证明：α|C(n,j)给E0；若p^e||N、B=v_p(j(j−1))<e，则每层h=B+1,…,e都有j modp^h>1，故E1|C(n,j)。K同理，使用三个相邻因子和n modp^h=2，得E2|C(n,j)。三个块的奇素数支持分别位于n、n−1、n−2，互不相交，因此可保留完整指数相乘。与C(n,3)取gcd实质限制了p=3的分母取消。

若n为平方且W=1，则α无奇素因子，并且E1=E2=1，因为N,K的每个素数均已出现在C(n,3)。所以W=1会进入本轮已排空的规范参数系统；小底部也逐项检查W>1。因此SQ和PPROW的偶数行均实际得到一个不依赖因数分解的W>1。

不能省略与C(n,3)的gcd：n=28,j=5时E1=27，但v₃C(28,3)=2。n=28,j=9又说明孤立取消与高层补偿不同：E1=3，弱式27|3j(j−1)成立，完整27|j(j−1)不成立。

W也不等于全部奇gcd：(56,11)给W=21，实际gcd=840、奇部105。它是充分的共同除子证人，不是NC3的等价判别式。

## 8. 全部重复次数与互补交替字块

### 8.1 普通重复的最后缺口

上轮已对全部x≥2、k≥3证明：S=(x^k−1)/(x−1)整除j或n−j即Common，含完备7项底部。本文不重跑那条冻结接受链。k=2有S=x+1，正是SQ。

因此n=b^v的任何NC3，j及n−j的v位b进制字串（允许前导0）都不能是短字块重复两次或更多次。它们必须是不可再完整重复的词；这不限制其总长度或复杂度。

对全部k≥2还可接近周期带：若j=aS+e，a,e任意整数，3e(e−1)<S，则第一窗口使S|3e(e−1)，从而e=0或1。e=0用普通重复；e=1使n−j为S的倍数。误差可增长；不要把本来就被第一窗口删除的各个e重复计为独立成果。

### 8.2 任意互补交替字块

令A∈{0,…,x−1}，ζ的k个数字从低位起为A,x−1−A,A,…。

k=2时ζ=(x−A)(x−1)，由SQ。偶k≥4时，每两个字块作为一个新字块，完整重复k/2次，由§8.1。

现在k奇且≥3。令a=A+1、D=x+1、n=x^k，则精确等比身份为

    D(ζ+1)=a(n+1)。

若NC3则x偶。乘第一窗口以D²并模n−1约化，得到

    n−1 | 3(2a−D)(2a−2D)。

1≤a≤x=D−1，且D奇，两个因子都非零，绝对值严格小于6D²。

当x≥8时，x³−1>6(x+1)²，因为差值为

    (x−8)³+18(x−8)²+84(x−8)+25>0。

故全部k≥3一次结束。x=2且k≥7、x=4或6且k≥5，也分别由整数端点127>54、1023>150、7775>294和幂单调性结束。

唯一剩余的底数/次数对为(2,3),(2,5),(4,3),(6,3)。完整展开全部0≤A<x，14个模式中12个合法，第一窗口余数全部非零。生成器用等比式，独立检查器直接按每个数字重建ζ，范围与值逐条相同。因此全部奇k也闭合。

一般非周期、非互补字块之间没有得到下降。以上模式可能与其他已证明子域重叠；未做全部历史消费者并集的差集审计。
