# 失败、边界与执行记录

## 数学路线没有完成的部分

最初按上一轮建议探测任意位置的两条等长连续1段。v≤64的精确探针只恢复16个第一窗口候选，都无第二窗口解；但缺乏所有指数的模板覆盖证明。故改选“任意复杂字块的完整重复”而不报告全体两段闭合。

一般双重复x≤2000，共3776个W1候选且双窗口0。这是路线诊断，不是反例高度或闭合。

三次重复的商q只取1、2；双次重复则不能这样做。令y=2^b≥4，x=y²，u=y(y−1)/4；本包证明这是W1兼容的完整族。由于u≥3x/16、x−1−u≥11x/16、2(x−1)−u≥13x/8，
`6u(u−D)(u−2D)/(x²−2) > (1287/1024)x > x`。
所以大小法允许的商无界。该族本身已由新的原W2余式排除；它不是Π模型。

近周期带不意味着覆盖全部残差，完整重复限制也不意味着任意输入必须周期化。反例仍可以是长非周期字串。R7未减少。
