# Pro B：任意重复字块闭合与两段的一个完整子域

## 最强结论与前沿

本轮没有新增整指标；R7={3,4,5,6,7,8,9}不变。新增的是不限制字块内部复杂度的完整周期子族，以及两次重复的单段字块。全部结论为作者纸面证明＋精确证书，未Lean、未独立研究者或人类审稿。

令x≥2,k≥3，S=(x^k−1)/(x−1)。对所有合法n=x^k、4≤j≤n/2：

**若j或n−j是S的整数倍，则原题i3成立。**

字块系数可以是任意整数；非平凡合法范围自动为1,…,x−2。不固定x、k或字块中1/连续段的数量。这不是把上一轮复杂度表扩到下一档。

另有两个完整连接：
- 任意整数a,e，j=aS+e且3e(e−1)<S时，同样成立。误差e可以为负，也可随n增长。
- n=2^(2d)，若j或n−j等于2^a(2^b−1)(2^d+1)，a≥0,b≥1,a+b≤d，则成立。全部段长和位置无界。

因此：二幂行的假定反例，v位字串的完整重复次数只能为1或2；两次重复中，“字块本身只有一个连续1段”也已排除。一般两次任意字块和非周期字串未解决。

## 1. 最有价值的改动：把复杂字块当作一个任意整数，而不是展开它的每个位

设D=x−1，j=aS。第二窗口乘D³后给
`n−2 | 6a(a−D)(a−2D)`。
合法非退化系数满足0<a<D，故右边为正且小于3D³。

- k≥4：x^k−2>3(x−1)³，一次排除全部x,a,k，无有限表。
- k=3：完整商只能为q=1或2。第一窗口又给D|3a(3a−1)，第二窗口模D给D|6a³+q。
  一个整系数消元身份迫使D|9q(9q+2)，即D|99或D|360。
  完整恢复只剩7个状态，原整数方程全部不成立。

原先CYCLIC只是a=x/k的一种特殊选法。本轮去掉了a的这种规定和k|x，并统一包含三次重复。对一个任意复杂字块，旧固定段数高度仍可能很大；本轮不需要知道其段数或提高任何指数上限。未声称这些子族与所有历史消费者的并集完全不重叠。

## 2. 两次重复的单段字块也已经接完

令x=2^d、u=2^a(2^b−1)，原j或补指标为u(x+1)。第一窗口化为
`x−1|3u(2u−1)`。
置J=2u，只在明确合法的分支使用上一轮已证明的单段**W1分类**；没有把较小行(x,J)当成NC3下降。

整个第一窗口只剩：
1. 旧平方单段族n=x²,j=x(x−1)/2；
2. n=y⁴,j=y(y−1)(y²+1)/4，y为至少4的二幂；
3. 三个小例(16,5)、(4096,196)、(4096,456)。

第二类的原W2迫使
`(y⁴−2)/2 | 3y³−8y²+12y+6`。
但右边严格介于0和左边之间，差值的平移多项式系数全正。全部y被排除，不枚举段数粗高度。
三个小例原W2余数是10、2676、2914，全部非零。旧族的短证明也随新证明重写。

这是两个连续段的一个完整无界子域；没有完成两段长度任意、间隔任意与原n任意配合的分类。

### 与历史覆盖的交叉检查

上面两次重复分类的两个无限幸存族都满足β|n−1：分别β=x−1和β=(y−1)(y²+1)，所以也落在此前e=1的已闭合范围；三个小例亦在旧有限基例内。本轮不把这些旧子族再次记作独立未知域减少。这里的增量是补出整个输入形状的完备分类，并给出不依赖旧大基例的短初等消费者。

主要研究结论仍是三次重复的任意字块通过七个常数状态整体闭合，连同所有更高重复次数形成统一规范限制。对任意字块与全部历史消费者并集的严格差集没有完整审计。

## 3. 可直接计算完整共同除子

当4|n时，定义
```
Z₁=(n−1)/gcd(n−1,3j(j−1)),
Z₂=(n−2)/gcd(n−2,6j(j−1)(j−2)), Z=Z₁Z₂。
```
完整逐层赋值证明Z是奇数，且Z整除两个实际二项式。新周期消费者保证Z>1，所以不需要分解巨大C(n,j)才能使用结论。这是已有窗口/共同进位机制的显式消费者，不额外主张为另一独立发现。

Z=1并非NC3。例如(56,11)同时通过两个窗口，实际gcd为840。专项检查保留p=3、模27与错误降成模9的差异。

## 5. 失败边界及下一判别

一般等长但错位的双段在v≤64只看到一个模式；没有证明模式覆盖，未登记其全域闭合。
两次任意字块在x≤2000的3776个W1候选中未发现双窗口解；这同样不是绝对有限性。

对k=2，第二窗口商随底数可以无界。已经通过W1的显式族有F/(x²−2)>x，因此“三次时商只有1/2”的七状态方法不能直接搬用。这是确切的强度障碍，不是原题反例。

下一判别点：一般n=x²、j=u(x+1)，联立
```
x−1 | 3u(2u−1),
x²−2 | 6u[(5u²−6u+2)x+7u²−9u+2]。
```
需要新的联合消元或完整高层进位，不能继续假定商有常数上界；也不能用扩大u/x扫描代替证明。

一般奇部、非周期复杂度、规范缺陷、F与min C_s仍无界。没有全题或i3绝对有效有限化，没有改变Work/Lean安排。
