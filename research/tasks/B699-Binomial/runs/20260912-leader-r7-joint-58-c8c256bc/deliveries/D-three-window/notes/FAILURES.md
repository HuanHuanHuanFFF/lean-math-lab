# 失败边界

本轮没有整指标闭合、没有全局 n/α/Cr/a/b 上界、没有 B699 精确反例。

**已严格否定的错误推广**：根基代替完整幂（244,122）；单次源端点5或7仍传到自身指标（46,23）/（22,11）；所有偶n都取η=8（46,23）；源指数替换成gcd指数（52,10）。所有数字来自本轮直接整数核验，见 `evidence/obligations.json`。

**已证的本轮判据不覆盖区**：n=2^v,v≥9 全部不通过 TW。采用 A 冻结联合高度和 a≥1960001 后，最后两类双高幂候选也必然不通过 TW，证明在 `notes/PROOFS.md` §7。没有把“判据不通过”写成反例或数学不可能性。

**仍未解决**：D 原规范混合区的 v、Cr、R/U、α、β、g；两条条带之外的全部主体；A 真正本原高指数的同时实现。本轮 COUNT 只保证失败行稀疏，稀疏集合仍然可以无限且包含任意大2进阶。

**新颖性边界**：新 TW/COUNT 与本轮已读具体 D 行判据比较；没有穷尽历史所有消费者，也没有进行文献级优先权认证。n=22^(420t+1)不属于已读ROW9/ROW-H，但不能因此断言历史上没有其他路径覆盖该行。

**实际证据边界**：独立实现指同一会话另写、未导入生成器的程序，不指另一名研究者；有限回归不替代无限证明；未执行 Lean 或人类审读。
