# 选路、未采用加强与真实失败边界

## 已选择的高增量路线

原任务中的 q³ 主攻已被D补交结果覆盖，撤掉，没有重复做。首先把外侧两个商接入同一 n,j 的中间商，而不是把相关 d/e 或 h 独立展开。新线性＋二次恒等式把固定K分配下的商候选压到常数个；进而检验完整小块能否全指数排除。C=9产生可闭合结果，C=5等仍留下指数方程。

## 实际完成的发现探针（不承担接受性）

- `probe_small_cells.py`：C=5,7,9,11,13 外侧商，用指数模360及二次余数选择模数。仅第一层局部信息不足。
- `probe_local_square.py`：加入 hD≡2ℓC mod C²。它读取前一探针的真实输出；这是选择9块路线的决定性检查。
- `probe_three_positions.py`：统一测试外侧和中间三个位置，保留全部允许 h,g,c 与余数。
- `probe_minimal9.py`：比较54、108、216、540、1080周期，寻找能覆盖全部9块状态的小模数集合。早期版本只使用较弱 g²|2h；最终接受链改用实际精确 g²|h。
- `probe_three_positions_extended.py`：C=25,27,81，仍有余数状态。真实 JSON 和日志保存，不能外推为所有平方或所有3幂都排除。

这些原发现脚本含原工作目录路径，保持原字节；`code/replay_exploration.py` 复制至临时根后只重写路径，提供可移植重跑。默认接受链不重跑它们；最终证书、覆盖证明和检查器独立于发现用模数搜索。发现脚本的小素数筛有浮点平方根，仅用于≤2500的模数探索，不进入主证书的接受判断。

## 不能扩大解释的边界

1. 两投影有非空弱解。n=18610024,j=7865522 通过三商两恒等式，仍有真实共同素数；它不满足约分分母形状。另一例 n=30,j=10 的同层L=203，小于真实gcd1015。新正规式没有解决跨层进位。
2. 模C²不能降为模C。n=128,h=1 的旧弱式过关，而模81式拒绝；丢掉完整幂会破坏9块排除。
3. C=9的全部指数由有限周期证书覆盖，不是把指数逐个扫到某个截止。本轮没有一般分配因子上界。
4. C₁=5尚未闭合。局部探针在 ℓ=3,h=1,g=1,n=2^v,v≡5(mod360) 分支仍有状态。对应 15d²=13n²+6n−4；n=32,d=30,j=1 是不合法的低端解。不能因低端解不合法就断言全部高指数无解。
5. 新固定B高度的四次曲线均无重根，确有明确外部定理可用；但它引入比主结果重得多的出版依赖，且上界极巨大。仅列为可复用有效有限化接口，没有声称实用枚举、Lean或完整i3有限性。
6. “同一行只需至多7个商”是每个完整素数幂分配后的数字。分配本身有3^ω(K)项、K的完全分解也有成本；不能将其宣称为任意大n的快速算法。
7. 本轮没有遇到被隐藏的截断或未完成接受命令。源文章通过网页PDF和截图读取，未把原PDF纳入证据包。没有运行Lean，没有第二独立研究者或人类审稿。
