## 1. 从完整原题到两个投影：采用前置并重写证明

### 1.1 完整估值与约分分母

阶乘估值得

    v_p C(n,u)=Σ_{a≥1} [u mod p^a > n mod p^a]。

所有项非负，p^a>n 时为0。因此 noCommon 排除的某个奇素数 p 在 C(n,j) 中没有任何层的进位。尤其 p≥5 且 p^a|n−r，r∈{0,1,2}，必有 j mod p^a≤r；p=3 时 a≥2 才由 C(n,3) 保证 p 出现。这保留了 p=i=3 的分母补偿。

设 g=gcd(n,j)，α=n/g，β=j/g。由 j C(n,j)=n C(n−1,j−1)、gcd(α,β)=1，有 α|C(n,j)。若奇素数 p|α，则 p|n；p≥5 会在 C(n,3) 出现，p=3 也只允许 v₃(n)=1。因此 noCommon 下

    α=c2^s，c∈{1,3}，s≥0；c=3 ⇒3∤g。

### 1.2 非4倍数和中心行

n 为奇数时，α 为奇数且 α≥2β，只可能 α=3,β=1，即 n=3j。取 n−2>1 的素因子 p；它与6互素，故 p≥5。进位必要条件 j mod p∈{0,1,2} 与 3j≡2 mod p 冲突，因为 p 不可能整除−2、1、4。

n 偶时，n−1 的完整奇素数幂给 n−1|3j(j−1)。若 n=tj，t≥2，则 gcd(n−1,j)=1，故 n−1|3(j−1)；t≥3 时该正数小于 n−1，t=2 时严格位于 n−1 与2(n−1)之间，均不可能。若 v₂(n)=1，α 的可能性为2、3、6，互素合法 β 只能为1，又属于这种整数比例。故

    noCommon ⇒4|n，2j<n，4≤j≤(n−2)/2。

这也处理了 j=n/2；以下投影正规式采用严格半区间。

### 1.3 精确归一化

置

    M=(n−2)/2，
    λ=3 若 v₃(n−1)=1，否则1，
    μ=3 若 v₃(M)=1，否则1，
    N=(n−1)/λ，K=M/μ，ℓ=λμ，D=(n−1)(n−2)=2ℓNK。

本节 D 只是上述正整数乘积，不是旧 avoidingPart。N,K 均为奇数，gcd(N,K)=1，ℓ∈{1,3}，gcd(ℓ,NK)=1。λ、μ 不会同时为3。完整估值强迫

    Π: N|j(j−1)，K|j(j−1)(j−2)。                         (1)

只有孤立的一次3被删除：若 v₃(n−1) 或 v₃(M)≥2，相应整个3幂仍留在 N 或 K，不能只留 v₃ C(n,3) 那么多幂，更不能取根基。

定义 k=n−j，C_s=gcd(K,j−s)，s=0,1,2。三个连续整数中每个奇素数只可能出现于一个位置；由(1)

    C₀C₁C₂=K，三个 C_s 两两互素，且每个都是完整素数幂的乘积。

此外 gcd(g,NK)=1。本文§2—3只要求 n 为4倍数、4≤j<n/2 和 Π；不要求完整 noCommon，也不假设三个 C_s>1。

## 2. 三个相关规范商

定义

    h₀=ℓ C₀ k(k−1)/D = k(k−1)/(2NC₁C₂)，
    h₁=2ℓ C₁ jk/D     = jk/(NC₀C₂)，
    h₂=ℓ C₂ j(j−1)/D = j(j−1)/(2NC₀C₁)。                 (2)

### 2.1 整数性、大小和共同完整幂

N 同时整除 j(j−1)、k(k−1)、jk。C₀|j，C₁|j−1,k−1，C₂|j−2,k；分母中的奇因子两两互素。两个外侧连续整数乘积为偶数。因此三个 h_s 都是正整数。

合法性给

    0<h_s<ℓ C_s；4h₀>ℓ C₀，4h₂<ℓ C₂。                    (3)

中间的严格上界来自 2jk≤n²/2<(n−1)(n−2)，n≥8。外侧分别用 k>n/2、j≤(n−2)/2。

直接从(2)取消与 g 互素的分母，得到

    g|2h₀，g²|h₁，g|2h₂。                                (4)

第二式保留完整 g²，比 g²|2h₁ 更强。对每个 p|C_s，另两个位置的线性因子模 p 是1或2，故

    gcd(h_s,C_s)=1。                                      (5)

特别是 ℓ=1 时，(3) 立即强迫全部 C_s>1。这个非空结论完全不需要 D 原件中 ℓ=3、C₀=1 的 Pell／对数论证。

若 A₀=gcd(N,j)、A₁=gcd(N,j−1)，则 A₀A₁=N。A₀C₀|β，A₁C₂|γ，其中 γ=k/g。因此正整数

    r₀=β/(A₀C₀)，r₂=γ/(A₁C₂)

满足精确共享式 h₁=g²r₀r₂。三个商并不是三个独立参数。

### 2.2 两个无损恒等式

用 k(k−1)+2jk+j(j−1)=n(n−1)，得到

    h₀C₁C₂+h₁C₀C₂+h₂C₀C₁=ℓK+λ。                       (6)

用 (2jk)²−4k(k−1)j(j−1)=4jk(n−1)，得到

    h₁²C₀C₂−4h₀h₂C₁²=λh₁。                              (7)

因为 gcd(h₁,C₁)=1，(7) 还给 h₁|4h₀h₂。保留差而非平方根，有

    j=μK+1−C₁(h₀C₂−h₂C₀)/λ。                             (8)

这些均是等式，不丢指数，不作高度近似。

### 2.3 C² 和 C³ 的必要同余

对全部位置

    C_s² | h_sD−2ℓ C_s。                                 (9)

外侧设 x=j 或 k，则 x=2+Cy、n=2+Cz。精确展开

    ℓCx(x−1)−2ℓC=ℓC²(3y+Cy²)。

中间设 j=1+Cy、k=1+C(z−y)，则

    2ℓCjk−2ℓC(n−1)=2ℓC³y(z−y)。

由于 gcd(C,n−1)=1，可进一步取消完整 n−1：

    C₁³ | h₁(n−2)−2ℓC₁。                                (10)

(9) 在给定规范 n,C_s 下可由(6)的余数式重得；它的价值是保留两个幂层，不能把它削成模 C 后仍宣称等强。(10) 则有更高阶的中间消除。T9 只需(9)。

## 3. 与 Π 等价的行恢复：只分解 K

固定 n≥8、4|n，按§1定义 λ,μ,N,K。把 K 的每个完整素数幂分到一个有序位置，得到 C₀C₁C₂=K、两两互素。**不分解 N。**

对 C_t>1，由(6)

    h_t(K/C_t)≡λ (mod C_t)。                              (11)

余数唯一且非零。列出 0<h_t<ℓ C_t 内所有该余数的提升；C_t=1 时直接列 h_t=1,…,ℓ−1。检查(6)、(7)，再由(8)恢复整数 j，保留 4≤j<n/2。

### 3.1 为什么只有1或7个线性允许提升

ℓ=1 时每个位置至多一个数。ℓ=3 时，写 h_t=r_t+k_t C_t，C_t>1 时 k_t∈{0,1,2}；C_t=1 时 k_t∈{1,2}。线性式只规定 k₀+k₁+k₂ 为一个固定整数。

(1+x+x²)³ 的系数为 1,3,6,7,6,3,1，因此至多7个三元组。实际代码先列最多27个原始提升再检查线性式，绝不把27说成至多7个未筛候选。

### 3.2 反方向证明，不只是声音性

设提升满足两式且恢复的 j 合法。令

    a=h₀/C₀，b=h₁/C₁，c=h₂/C₂，δ=λ/K。

则 a+b+c=ℓ+δ，b²−4ac=δb，所以

    (a−c)²=(ℓ+δ)²−(2ℓ+δ)b。

又 n/2=(ℓ+δ)/δ、j=n/2−(a−c)/δ，故

    jk=(2ℓ+δ)b/δ²，D=2ℓ(2ℓ+δ)/δ²。

从和与差重建出全部(2)。因此 j(j−1)=2NC₀C₁h₂，第一投影成立。

对任意完整 q=p^e|C₀，外侧和中间两式给 j(j−1)≡jk≡0 mod q，且 k≡2−j。q 为奇素数幂，两个根集合 {0,1}、{0,2} 的交集为{0}，故 q|j。同理 C₁|j−1、C₂|j−2。第二投影及规范 gcd 均成立。

因此，该恢复与两个投影的合法解恰好一致，既不漏解也不添加解。它没有使用 α=c2^s，也没有检查所有原题素数，因此只是 Π 的等价正规式。

## 6. 补充：任意一个有界分配因子给出可计算高度

本节是独立可选分支，引入新的、明确登记的出版输入 [E1]；前面的主结果不需要它。

    n=A X²，A=2^ε cg<36B，X=2^t。

    Y²=4hwA²X⁴−12hwAX²+w(8h+w)。                          (14)

中间令 Y=w(n−2j)，得到

    Y²=w(w−2h)A²X⁴+6whAX²−4wh。                          (15)

所有系数绝对值≤H_B=46656B⁴。两个多项式的判别式分别为

    16384 A⁶h³w⁶(w−h)²(8h+w)，
    −1024 A⁶h³w⁶(w−2h)(h+4w)²。

前者非零，因为0<h<w；后者非零，因为w为奇数，所以w≠2h。包括负首项系数在内，都是真正四次、无重根。也可直接用偶四次式 aX⁴+bX²+c 的导数检查：a,c≠0 且 b²−4ac≠0 就排除公共根，无须使用通用判别式库。没有退化为未处理的 Pell 或有理曲线族。

[E1] Bérczes–Evertse–Győry，arXiv:1301.7168v1，Theorem 2.2 (2.6) 对无重根整数多项式 f、deg f=d_f≥3 的整数解 f(X)=bY² 给显式对数高度界。采用数域 Q，S={∞}，b=1；数域次数、判别式绝对值、S大小、Q_S 均为1，d_f=4。其定义的系数高度恰为 log max(1,|coefficients|)。因此
