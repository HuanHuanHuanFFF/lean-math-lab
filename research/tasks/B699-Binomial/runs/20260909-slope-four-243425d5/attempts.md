# 路线比较、失败证据与边界

最终状态：仅比较两条主路线，选择一次，之后集中完成第二条的高度界和有限闭合。没有扩展到一般 `n=qj` 或一般 B699，也没有进行 Lean 构建。

## 路线一：四块 Vandermonde＋EEES

精确候选为 T4 与 S4：

- 实际完整 avoiding 部分 `D | K4(i) C(j,ceil(i/4))`；
- 在额外输入 `noCommon => C(4j,i)<V²` 时，四块分配给出 `C(j,u)C(j,v)<K4(i)²`。

T4 已证明；S4 是在上述 EEES 输入下的正确消费者。本轮没有找到它们的反例。最终不采用此路线，是为了不携带 EEES 的理论/例外处理依赖，而不是因为四块恒等式失效。

### 被反例否定的两个过强推广

**错误命题 A：每个非零行列式都等于 p。**

实际原输入为 `(n,i,j,p)=(88,11,22,13)`。二项式侧指数 `e=1`，完整 numerator 幂 `Q=13`，余数 `a=10,b=9`。因此

\[
4b-a=26=2p,
\]

且 `p∤C(88,22)`。恢复条件是保留 `t∈{1,2}`；两种情况都必须进入支撑证明。

**错误命题 B：每个非零 avoiding 素数都不超过 2i。**

实际原输入为 `(n,i,j,p)=(92,8,23,17)`。`e=1,Q=17,a=7,b=6`，`4b−a=17`，并且 `p∤C(92,23)`，但 `17>2i=16`。

恢复条件是采用 T4 中的四倍关系支撑，而非复制三倍关系的 `K3`。以上两例**不是原 B699 特例的反例**；它们只否定某个单素数/余数支撑断言。

## 路线二：完整幂转移＋初等小素数部分界（最终路线）

候选并已证明：

\[
U\le(4j)^{\pi(i-1)},\quad
E=i-\pi(i-1)-\lceil i/4\rceil\ge1,
\]

\[
3^i\lceil i/4\rceil!\,j^E
<K_4(i)4^{\pi(i-1)}i!\quad\text{在 noCommon 下成立。}
\]

选择依据：所有 `i≥3` 的高度指数都正，不再有低指标净指数不正的例外，也不需要 EEES。随后只沿这条路线使用已指明的 Dusart 估计、固定整数不等式和有限覆盖证书，完成闭合。

没有实际运行早期曾考虑的百万指标素数乘积上界证书；它在纸面重排和直接源定理读取后已不必要。不把这种未运行设想写成实验结果。

- T4、四块 Vandermonde、正高度指数、实际完整幂定位和选定反例。

该范围内没有 T4、Vandermonde 或原题反例。**诊断范围不证明无限命题**；无限部分由 `derivation.md` 的论证承担。

完整闭合不是继续扩大小扫描：`finite_closure.py` 从已证明的绝对范围开始，用 H4 与 TOP 压缩，只为最终 2,848 对生成原题见证。`independent-check.json` 的 `PASS` 同时覆盖了被省略的输入。

## 必须保留的完整幂和等号边界

`(i,j,p)=(3,27,3)` 的二项式侧指数为 2，但完整分子幂为 `Q=27`，不是 `3` 或 `9`。这是 T4 零分支的回归样例，而不是 noCommon 输入。原始数值在 `diagnostics.json`。

最终有限见证有 3 个选择了 `p=i`。检查器同时确认它们的高位进位，不能只看最低位。它们还可能存在其他 `p>i` 的公共素数；`boundary-audit.json` 对此作了实际检查，**没有声称这些例子只有等号见证**。该文件的素数底数列表不参与任何完整幂转移论证。
