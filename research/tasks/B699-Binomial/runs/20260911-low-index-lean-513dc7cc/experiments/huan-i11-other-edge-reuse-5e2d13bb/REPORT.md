# 其余四条 i11 边的有界复用分析

固定 FINAL_PLAN 的全部参数，不搜索新的 c,d、L、权重或高度。当前交付只展开 (2,5)、(c,d)=(5,4) 的最小实际源前缀；其余三行只有来源绑定的差异表。候选没有编译，原题 B 仍为 0/19。

## 1. D=3 是本次必须新增的数学检查

(2,5) 种子是 P=2⁷=128、Q=5³=125、a=b=1、D=aP−bQ=3。令 uδ=4m−δ、vδ=m+δ−1，δ∈{0,1}。同一个 m 的两行均有 uδ+vδ+1=5m。

令 Gδ 为该行实际 qContent，P̂δ、Q̂δ 为各自以 Gδ 归一化的整数 Hom 行。实际等式是

```
Gδ Q̂δ = 128^uδ Qδ(3/128)
Gδ (128^(5m)P̂δ−125^(5m)Q̂δ)
  =128^vδ · 3^(2uδ+1) · Eδ(3/128).
```

特别不能把 (5,3) 的 D=1 余项原样复制。最小精确反例为 m=1,δ=0：u=4,v=0,G=1,E(3/128)=1，实际 G·error=19683=3⁹；漏掉 3 幂会错误地给出 1。

把两行共同的指数增长底数提出，余下常数恰为

| δ | 实际系数 128^vδ·3^(2uδ+1) | 相对于 (128·3⁸)^m 的因子 |
|---:|---|---|
| 0 | 128^(m−1)·3^(8m+1) | 3/128 |
| 1 | 128^m·3^(8m−1) | 1/3 |

两常数都≤1。因此统一 E 缩放因子是 **128·3⁸=839808**，不是 128，也不是 128·3⁵。这只作安全放宽，没有改变旧计划的 λ、L 或权重。

`TwoFivePrefix.lean` 有六个完整证明文本：两个 δ 的下标说明、实际行对应、逐行 G·Q 等式、完整 D=3 余项等式以及全 m≥1 的正确系数上界。最后一个证明分别利用 3≤128 和 1≤3，不假设期望的 Hom 或 G-growth 结论。`Audit.lean` 对六个定理及 δ 定义列出七个 `#print axioms`。前缀在 `PREFIX_FREEZE.json` 记录的字节冻结，未运行 Lean。

## 2. 可统一的缩放接口

对这四个固定种子，共同记号为 P=p^k、Q=q^l、y=aP、D=y−bQ，且 1≤D<y。假设 c>d≥1、m≥1，δ=0/1，uδ=dm−δ、vδ=(c−d)m+δ−1。令 g=Lt^d，BQ=β(c,d)λQ，BE=β(c,d)λE。

实际 Hom 等式给出 Gδ·errorδ=y^vδ D^(2uδ+1) Eδ(D/y)。在 ℚ 中，它的尺度恰为

```
(y^(c−d) D^(2d))^m · (D/y)       当 δ=0
(y^(c−d) D^(2d))^m · (1/D)       当 δ=1.
```

所以对两个 δ 均可导出：如果实际原始 Q/E 值满足 |Qδ|≤BQ^m、|Eδ|≤BE^m，且实际 Gδ≥g^m，则

```
g^m |Q̂δ| ≤ (y^d BQ)^m
g^m |errorδ| ≤ (y^(c−d) D^(2d) BE)^m.
```

这两条是建议统一的中间接口，不应把它们重新作为最终边的外部假设。最终仍应像 (5,3) 一样，用实际 Hom、实际有限 G、Factorial 与 GrowthTree 分别构造它们。

随后只需替换两率定义：

```
A3 = P^c g / (b^c y^d BQ)
W  = (P Q)^c g / (y^(c−d) D^(2d) BE).
```

保持窗口差绝对值≤24、同一个最小 m 满足 4Y<Z^m，Z=floor(W)。A3^m>48 压低 Q 项，Nq≤2Y 与 4Y<Z^m≤W^m 压低 E 项。整数桥仍是 b^(cm)Q̂δ U−a^(cm)P̂δ V；各自清分母后 errorδ=y^(cm)P̂δ−(y−D)^(cm)Q̂δ。所有窗口差符号及零差都保留。

精确检查确认每行 A3 等于原 Ω3^d，且 **W=max(P,Q)^c·Ω4^d**。不能把 (5,3) 中 max(P,Q)=Q 的偶然关系推广成所有行一律 W=Q^c·Ω4^d。
