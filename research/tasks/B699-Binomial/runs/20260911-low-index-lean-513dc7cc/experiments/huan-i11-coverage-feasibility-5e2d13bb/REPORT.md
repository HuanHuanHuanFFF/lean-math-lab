# i11 首层覆盖的压缩可行性

**不建议直接启动完整 CRT。** 精确的保守区间壳筛选把 487,789,034 个不同素数族对减至 185,190,380 对，排除 302,598,654 对；乘 21 个有符号位移后仍为 **3,888,997,980 个潜在步骤**。这是壳相交所给的工作量上界，不是实际非空 CRT 族数，也不是原题候选数。

实际扫描耗时 0.692276 秒，进程峰值工作集 127,094,784 bytes（约 121.2 MiB）。没有执行 CRT 逆元、pair-offset 循环、大系数枚举、全 n/j 检查、Lean 或 Git。

## 采用范围

仅采用刚冻结计划中 `i=11,H=2^15360,r=3,s=7,S=640,Delta=40` 的**有限尺寸输入**。`FINAL_PLAN.json` 的 SHA 为 `7ab80d1357ef87aafa1ead6fbdef0b4dadf851c09c77185c27a7f03fa4b5ab62`。本任务不重新接受 D、Q/E、height 或原题消费者。

继承原 `crt_fast.py` / `crt_bound_probe.py` 的 normalized-K 接口：

`K=142131407644347048724404082572664265244672000000000`，根指数 `33`，高度指数 `7`，

`M = min {m∈ℕ : K*m^33 ≥ (2*11!)^11*H^7}`。

本轮直接用两个整数比较确认

`K*(2^3261)^33 < (2*11!)^11*H^7 ≤ K*(2^3262)^33`，

故 `2^3261 < M ≤ 2^3262`，且 `H>2*(2^3262)`。没有计算实际 M 的完整根。原高分支是 `max(110,M+1)≤n≤H−1`；这里因 M 很大而等于 `M+1≤n≤H−1`。所有合法 `j` 为 `12≤j≤floor(n/2)`。

**未被本统计处理的域：** `24≤n≤M`；所有实际高分支 CRT 相交；更低高度的后续下降和终端覆盖；原题反例推出 `n<H` 的正式消费者。壳统计不会自动消去这些域。

这些接口的量词足够：若某个素数 p 与区间 `[lo,hi]` 满足 `p≤lo≤hi<p+11`，那么区间内所有合法 n,j 都被同一 p 覆盖。原因是 `n−11<p≤n`，合法性又强制 `11<p`、`j<p` 且 `n−j<p`；两项组合数分子有 p 因子，阶乘分母没有。

反例说明仅有“某个组合数的大素因子”不够：`n=26,i=11,p=13` 时 p 整除 `choose(26,11)`，但合法 `j=13` 时 `choose(26,13) mod 13 = 2`。本轮小检查实际计算了这个反例。

本轮检索了当前 run 的 Lean 实例和旧 `20260910-pade-three-closure-4edad426` 的 i11 有限证书。**没有采用一个与源/SHA/std3 对齐的具体 i11 完整区间列表。** 通用正确性定理已验，不代表旧 JSON 的每个实例已 Lean 验收。因此严格统计中删除的已验见证区间、幂族均为 **0**。

旧 `terminal_certificate_11.json`（SHA `4e2e5eac1f319ed6a74f01ccb574d5c6dcae3d89d4a8868f7d1cbe73badd5cf0`）提供了 1,699 个顶端素数区间。只读形状检查确认每项 `p≤lo≤hi<p+11`，全部落在 `[24,29294602]`，与本轮壳高分支无交集。本轮没有重验或采用其中的素性证书。即使日后全部迁移接受，也不会删除第一层任意高区间壳；其大除子/特殊行见证的最大 n 也只有 29,294,602。不能由这些稀疏行自行推出整个 `[24,29294602]` 均已覆盖。

## 新发现的覆盖消费者边界

现有 `FiniteCover.coverLayerCheck_sound` 不能直接实例化本 i11 计划。它经 `HeightRowValid` 要求 `heightExponent≤i*(2s−r)`，并使用 `CofactorCover.noCommon_small_part_lower_of_certificate` 的自然数等式 `i*(2s−r)=heightExponent+d` 与 **H≤n**。

这里 `heightExponent=smallPrimeCount(11)*11+windowDegree(11,3,7)=4*11+84=128`，而 `i*(2s−r)=121`。条件 `128≤121` 为假；自然数差截断不能修复这个前提。该范围差异来自 `HeightCertificate.lean:11`、`RegisteredHeights.lean:20`、`CofactorCover.lean:99–107`，新增源 hash 和精确算术在 `CONSUMER_GAP.json`。

需要一个 **n≤H 的 upper-height 变体**，不是把新 i11 行强塞入旧注册表。具体充分义务是：若 `110≤n≤H`、`11<j≤n/2`、`¬Common n 11 j` 和 `(2*11!)^11*H^7≤K*M^33`，则 `n^4≤M^3*smallPrimePart n 11`。

它有短的纸面推导：现有 `noCommon_bernoulli_size` 给 `K*n^121≤C*U^11*n^84`，其中 `C=(2*11!)^11`、`U=smallPrimePart`。用 `n^7≤H^7` 与 `C*H^7≤K*M^33`，得到 `K*n^128≤K*M^33*U^11*n^84`。取消正的 `K*n^84`，再取自然数 11 次幂的单调逆向，便得目标。随后才可复用 `PrimePowerEnumeration.exists_two_colours_in_power_interval_list`，其列表 `powerIntervalList` 的真实范围保留全部 h、a 及端点裁剪。

本任务没有写或运行这个 Lean 变体。它是具体的剩余源接入义务，不是反例，也不改变上述 normalized-K 壳统计或已验 top-prime 全 j 定理。

## 壳的保守性

对 `p∈{2,3,5,7}` 和 `Q=p^h<H`，原算法有 `1≤a≤M`，单个区间是

`[Qa,Qa+10] ∩ [M+1,H−1]`。

这里 `v_p(11)=0`，因此没有遗漏起始指数或额外的 `p^v` cofactor cap。设 `L=2^3261,U=2^3262`。任何真实区间中的 n 都满足

`n≥M+1≥L+1`，`n≥Qa≥Q`，`n≤Qa+10≤MQ+10≤UQ+10`，`n≤H−1`。

所以真实幂族的全部区间都包含于本轮壳

`S_Q=[max(L+1,Q), min(H−1,UQ+10)]`。

它一般填入很多原算法不存在的 n；**不是精确坏区间**。两个壳不相交，才可安全排除对应族对的全部位移。两个壳相交，只说明还不能用这个准则排除；不证明 CRT 有解。

所有 `Q<H` 的原幂族确实非空：若 `Q>M`，取 a=1；若 `Q≤M`，取 `a=floor(M/Q)+1`，则 `M<Qa≤M+Q≤2M<H`，且 `1≤a≤M`。故本轮 37,136 个族并非因壳填充额外增加的指数族，但族内的壳仍是严格的外包围。

每个 p 的壳端点都随 h 单调。对壳 `[l,u]`，相交的另一颜色壳数等于

`# {lower≤u} − # {upper<l}`。

用两次二分得到这个数；左右颜色互换后再计算一次并检查相等。没有物化任何 pair 列表。

## 实测资源与检查范围

- 先做 `B=16,32` 的有限对照：实际 M 分别 137、1,438，检查 2,907 与 73,969 个真实 a 区间端点包含于壳；分别逐对检查 455 与 1,987 个壳对，和二分结果一致。最多每个玩具实例 100,000 个 a 区间，未执行 CRT。
- `B=64` pilot：152 族，原 8,161 对，壳相交 4,007 对；扫描耗时 0.002789 秒，峰值工作集 24,154,112 bytes。先检查结果，再启动实际规模。
- `B=15360`：内置 30 秒、50,000 个族、500,000 次二分查询、190 MiB 工作集上限。实际 222,816 次二分查询、726 次资源检查；扫描 0.692276 秒，峰值工作集 127,094,784 bytes。最终程序整体命令用时约 0.975 秒。
- 端点流以整数长度前缀和 big-endian 字节确定性计算 SHA，保存在 `full.json`，没有输出或保存所有大端点或 pair。输入证据 hash 与模块验收关联都保存于同文件。

上述是当前执行得到的有限统计，不是新 Lean 验收。时间上限通过循环中的检查实现，未设置系统级进程配额；本次实测远低于上限。

## 是否继续全覆盖

当前结果支持把区间壳剪枝加入未来实现，但不支持直接进行剩余约 38.9 亿 pair-offset 步。所需的下一项突破必须利用真实模约束或幂块关系，或者降低初始高度；继续只寻找已有的小 n 顶端素数区间不会改善第一层成本。

值得另行授权的最小下一检查，是审读旧 i11 幂块压缩证明/证书能否在新高度下保持完整边界，然后只对一个受限素数对和受限指数块生成真实模证书、估计块数与验证成本。那项检查必须重新说明其全 j/原题消费者和全部参数范围；本轮没有执行，也没有默认旧证书已适用于新高度。旧有有限下降与终端证书可作为后续迁移来源，接受状态单列。

本任务完成的是路线成本决策。完整 i11 尚未解决，B 原题计数不增加，新颖性未评估。
