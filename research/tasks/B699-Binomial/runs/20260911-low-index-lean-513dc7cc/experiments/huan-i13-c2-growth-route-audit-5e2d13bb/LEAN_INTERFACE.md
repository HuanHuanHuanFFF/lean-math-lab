# 最小下一步 Lean 接口（设计稿，未编译）

本文件只给接口与验收义务，不新增 Lean 源码或占位证明。N 采用实际 `C2(4m,4m,m)` 的完整素数幂定义；由主任务协调其唯一所有者，不另建不兼容的 N。

## 1. 最短无条件前置：首层区间整除

先证明一个不需要 theta、实数分析或精确 gcd 的自然数引理：

```lean
-- 拟定签名；不是当前已存在的定理。
theorem four_interval_contributes (m q j : ℕ)
    (hm : 3 ≤ m) (hj : 1 ≤ j ∧ j ≤ 4)
    (hlo : 4 * m < j * q) (hhi : 2 * j * q ≤ 9 * m - 2) :
    2 * q + 1 ≤ 2 * ((4 * m) % q) + m % q
```

纸面证明先得 `m<q` 与 `(j-1)*q<=4m<j*q`，于是余数和为 `9m-2(j-1)q>=2q+2`。应明确自然数减法的非负侧条件，不能把整数消去式直接套到截断减法。

随后定义 `P4(m)` 为四个区间内素数的无重数乘积。需要证明：区间两两不交、成员素数的 h=1 指标为 1、`P4(m)|N(m)`、`0<P4(m)`、`0<N(m)`。不需要 N 等于任何 gcd，也不需要先证明 ProC Q2。N 对 Q 系数的全幂整除链由其所有者独立承担。

这一步的验收应直接展开实际 N 的贡献层定义，检查 `h=1` 被包含、p 为素数、有限截断足够、没有漏掉 `p=i` 的任何下游假设。局部桥本身只用首层，N 的完整幂定义不可改成 squarefree 对象。

## 2. 避免把缺失 Chebyshev 缓存变成启动前提

可先令 `L4(m)` 为 `P4(m)` 的各素数 `Real.log p` 之和，并建立

    L4(m) = Real.log(P4(m)) <= Real.log(N(m)).

随后才把它识别成

    S4(m) = sum_(j=1..4)
      [theta((9*m-2)/(2*j)) - theta(4*m/j)].

已有 mathlib 的 theta 定义为对 `p<=floor(x)` 的 prime log 求和。这里是 `(L,U]`，两个 floor 端点直接相减；区间左端是严格不等式。可复用 `theta_eq_sum_primesLE`、`theta_eq_log_primorial`、单调性，是否导入整个 Chebyshev 模块由主任务在串行队列中决定。只需 P4 对数和的第一步不应强制触发该重依赖。

## 3. 最小素数输入与条件消费者

以下是本四区间方法的数值供给接口，不是已经获得的定理：

```lean
-- S4、N 以上述实际定义为准。
def FourIntervalLower : Prop :=
  ∀ m : ℕ, 10000 ≤ m → (183 : ℝ) / 200 * m ≤ S4 m

theorem c2_growth_of_four_interval_lower
    (hSupply : FourIntervalLower) (m : ℕ) (hm : 10000 ≤ m) :
    (910560352 : ℝ) / 1000000000 < Real.log (N m : ℝ) / m
```

条件消费者的有限代数部分只用 `S4<=log N`、`0<m` 和 `183/200>910560352/10^9`。必须把 `hSupply` 显示为未解除的数学假设。消费者本身即使公理审计只有 std3，也不能记为无条件增长或 i13 高度。

按优先级实际编码到第 1、2 步即可完成一个可复用的结构接口；除非明确研究/下游用途需要，不要因第 3 步容易而堆叠假设包装。

## 4. 如何解除 hSupply

选下面一个来源接口，经完整原文对齐、编译及传递公理审计后才能实例化：

**A. BFT 正确分段界。** 只需两个声明：

```lean
def BFTThetaFinite : Prop :=
  ∀ x : ℝ, 1 ≤ x → x ≤ (10 : ℝ)^11 →
    x - (259 : ℝ)/125 * Real.sqrt x ≤ Chebyshev.theta x ∧
    Chebyshev.theta x ≤ x

def BFTThetaTail : Prop :=
  ∀ x : ℝ, (10 : ℝ)^8 ≤ x →
    |Chebyshev.theta x - x| ≤ (213 : ℝ)/1000000 * x
```

源文的严格不等式在这里安全弱化为 `≤`。两段重叠给全局 `max` 包络，四组有理平方比较给 `FourIntervalLower`。这段消费者所需常数和符号方向已由精确检查冻结；两个 Prop 的实际证明仍缺。

**B. 更弱的有限＋无限输入。** 将 A 换为：`10000<=x<=4500000` 的 sqrt 下界及 `theta<=x`，加 `x>=1000000` 的 `|theta-x|<=x/200`。两段分别覆盖 `10000<=m<=1000000` 与 `m>=1000000`。可将前者做有限证书；后者的有效无限来源不能省略。

**C. 直接供给 S4。** 若另一种数学方法直接证明四区间和下界，可跳过全局 theta 不等式。这保留了研究自由度；本文件不声称已有该证明。

## 5. 保留 m>=51 时的有限接口

只需对 `51<=m<10000` 证明目标本身，未必需要达到较强的 `183/200`：

    forall m, 51<=m -> m<10000 ->
      (910560352/10^9)*m < log(N(m)).

每项可给不完整素数幂子集及其合法贡献层数；校验素性、幂/层对应、下界方向、整数索引范围与有理 log 误差。全 C2 截断 `44995`，四区间截断 `44994`。共有 9949 个可能的单点 m，但允许经完整覆盖证明压成区间块。本次未生成表，未检验这些单点或块的通过情况。

若改用 BFT G1/Q2 路径，则需新的完整证明义务：实际 `G(4m-1,m,4m-1)` 与源文 (2.7) 对齐；对每个 `m>50` 的 Proposition 5.1 证明；商整除 `G1/N|4m`；最后的对数单调性。该路线已在纸面与精确常数上通过，但不因引用 BFT 表格就免去有限和无限证明成本。
