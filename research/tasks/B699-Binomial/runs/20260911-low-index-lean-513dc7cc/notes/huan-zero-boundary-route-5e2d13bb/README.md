# 零边界替代路线的有界检查

来源：固定基线的20260909-low-index-structure-b41a5a63/notes/zero-boundary/README.md，已接受共享CofactorCover与SmallPrimeLocalization；本次只测试一个明确新假设，不重复M64扫描或旧证书。

动机：如果同一个三窗口证书能取M=1，两个不同小素数的完整幂都至少为n，而定位又给它们≤n−a≤n。它们必须同时等于n、位置都为0，与n>1时不同素数的幂不相等矛盾。配合已给出的有限小分支，这条路线本可避开Matveev并统一排除大n。

检查义务是(2 i!)^(i+1)≤K，其中K=2^(s(s+1)) F_s² F_(2t)，t=π(i−1)、s=2t+1。对i=28、31、34只做这三个指定的整数比较；全部为假，精确比较摘要见M1-comparison.json。失败的是这份现有证书提供M=1的能力，不是B699，也不是所有不使用Matveev的方法。

实际前沿：新增完整指标0；原Matveev对数前置仍在。只有取得更强的统一常数/结构约束时，才值得回到这一取M=1的路线，单纯微调64不能消除该数学前置。

未测试的另一改写：在A p^x−B q^y=h中把x,y按模3分解，得到有限系数的对角三次Thue方程。它将问题转交给带完整性证明的Thue求解/高度界；尚未找到比Matveev更轻且已可在当前Lean环境使用的完整输入。因此这里保留动机和缺口，不把改写算作新方法已建立或新结果。
