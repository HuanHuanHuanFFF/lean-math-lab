# 一般补充：耗尽源空间的因子与固定部分

设实际非零G∈V，H|G为非竖不可约因子，W_H为其完整源保持空间。若dim W_H=dim V=r>1，则乘以G/H给W_H→V的单射，维数相等，所以

    V=(G/H) W_H。

因此G/H整除V中的每一个多项式。实际重数预算还迫使H在G中的重数为1。尤其dim V≤2时，只要某因子非刚性，它的所有补因子就必须属于整个源pencil的固定部分。

一个完整模gcd消费者如下。设已知dim_Q V≤2，完整F_p源核K维数2；在某N=c，K的两基专化的gcd为常数，且K含一个专化后仍X次数h的成员，其中h为V的X次数上界。则任何G∈V若至少有两个非竖因子（计实际重数），其每个因子源空间都必须一维。

证明：反设某H有dim W_H=2，则dim_Q V=2且R=G/H整除V全体。整数源核格L=V∩Z^M为Z^M的饱和子格：kf∈L蕴含f∈L。故L是自由直和项，模p像维数等于2；既然完整K也维2，L模p恰覆盖K。把R取本原整数代表，由Gauss引理它在Z[N,X]中整除L每个元素。因此R modp再N=c的像整除K两基的专化。

还需防止R退成常数：从K中选一个N=c后保持h次的方向，并用L中的F提升它。F实际q≤h，专化q=h，且R|F。乘法次数可加与各因子降模专化只会降次数，迫使R的X次数也完整保留。若G至少含两个非竖因子，则q(R)≥1（H取一次），其像是两基专化的共同非恒定因子，与gcd常数矛盾。

不能只用dim_Q V≤2就假定L模p覆盖K；上面是在反设非刚性后先得到Q维恰2，才使用秩相等。也不能略去某个方向保持h次的条件。一般r>2时，一个二维W_H只占V的真子空间，此gcd消费者不直接适用；只有dim W_H=r的“全预算”情形才迫使整空间固定部分。
