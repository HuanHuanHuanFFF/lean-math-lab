# 源竖因子给X次数旗标的逐层增维上界

状态：纸面候选与小型精确整数表，待独立审读。原21源、D≤305和V_h的定义与02-geometric-deformation-budget.md相同。只采用已独立接受的dim_Q V107≤1；没有采用旧e108模核维2作为新事实。

## 1. 全空间公共竖因子

对r=3,…,8，记固定非中心源阶为OFF_(r,s)、中心权阶DIAG_r（奇行无中心）。定义

    L_r(v)=Σ_off max(OFF_(r,s)−v,0)
             +ceil(max(DIAG_r−v,0)/2)，
    b_r(h)=min{v≥0 : L_r(v)≤h}。

对于任意F∈V_h，都有

    B_h(N)=∏_(r=3..8)(N−r)^(b_r(h)) | F。          (B)

证明：固定r，若已知(N−r)^v|F，令Q=F/(N−r)^v。Q仍有X次数≤h，在该行各非中心普通阶至少max(OFF−v,0)，中心权阶至少max(DIAG−v,0)。若Q(r,X)不为零，它在各不同源X值的根重数至少分别为前者及ceil(后者/2)；中心这一点来自u=0时只保留t^j、其权为2j。故其X次数至少L_r(v)。当v<b_r(h)时，L_r(v)>h，与X次数≤h矛盾，所以Q(r,X)=0，N−r再次整除Q。归纳得到每个行因子；六条竖线两两互素，故它们的乘积整除F。F=0也符合。

这个论证逐点保留原源条件，不要求七因子、不可约性、可载性或E0/E1。各源X值在同一行互异；中心剪切在u=0时恰给X−s²。对本例F257，同样的互异性也成立，但本命题在Q上证明。

## 2. X首项系数的精确核

记a_h(N)=[X^h]F。权次上界给deg_N a_h≤305−2h；(B)给B_h|a_h。线性映射

    V_h → {a(N):deg a≤305−2h，B_h|a}，F↦[X^h]F

的核恰为V_(h−1)。于是

    dim_Q V_h−dim_Q V_(h−1)
      ≤ max(0,306−2h−Σ_r b_r(h))。               (F)

右边是目标系数空间维数的上界，映射不必满射；等号不作为存在性论断。若B_h的次数已超过305−2h，首项系数只能为0，增维上界确为0。

## 3. h108的无新模证书结论

h=108时

    (b3,b4,b5,b6,b7,b8)=(22,18,15,13,11,10)，Σb=89。

逐行L_r(b_r)分别107、107、106、106、105、106；L_r(b_r−1)分别109、110、109、110、109、111，后者均>108，因此这些指数准确达到最小值。X108首项系数次数至多305−216=89，而B108也恰89次，所以它只可能是B108的常数倍。由(F)及已接受dim V107≤1，

    dim_Q V108≤2。                              (H108-DIM2)

结合02中的几何预算，不论E0或E1，也不论七可载分量是否存在：任何实际G∈V108的全部Q不可约因子都绝对不可约；最多一个因子的源空间可二维，且此因子只能出现一次，其余全部一维。h107若已由另一条专化路线排七分量，不影响这个h108的独立应用。

补充统一首项门：凡306−2h−Σb_r(h)=1且F∈V_h具有X次数恰h，便有[X^h]F=c B_h（c∈Q非零）。所以F的全部竖因子恰为B_h；F/B_h的X首项为常数，加权次数恰2h，全部非恒定因子均平衡。h108属于这种情况。此结论不需要先假设七可载分量，也不需要从模核推Q存在。若增维右端为0，则V_h=V_(h−1)，不存在X次数恰h的非零源多项式。

## 4. 全h的可复用上界

从b(107)=1开始，按(F)逐层累加，得到一个显式上界b(h)≥dim_Q V_h，107≤h≤152。全部46行在experiments/a/source-flag-bounds.json。抽样如下：

|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
|b(h)|1|2|4|6|8|10|26|42|59|71|86|

完整表的终值86恰与已接受e152模块基给出的上界一致，但本递推未使用旧e108/e110/e120/e128等非零模探针。在一般几何预算中可统一代入

    Σ_(d_i>1) e_i d_i ≤ b(h)−1。

例如h109最多容许一个二重或三重几何轨道，且其在G中的重数只能1；不容两个几何二重轨道。h110右端5，可容的轨道总重数同样受此明确费用限制。它们是整个G的必要结构限制，不能误报为已有这些轨道或已排全部七分量。

逐层上界仍不能恢复有理G、原点或原n/j高度。其价值是为后续模方向覆盖与实际因子源型提供不依赖新增重型源核的维数上界；源条件始终只是原题的必要合同。
