# 主线程路线1：E1真实竖线状态与完整Gbar核

预期：若完整58个E1资源状态的实际源核均空，则统一排除七分量E1并得到EDGE7；若只少量为空，记录新必要前沿，不当COVER6或原题点删除。最便宜首测是最低h、两中间层、最高h四个代表；若全部有模核，不据此宣告Q存在，而转向更强的系数/因子联合门，避免无意义扩大计算。

采用固定21源、主run final-row-frontier中的E1状态。对一个状态(h,v,E1)，真实Gbar=G/Π(N−r)^v_r具有X次数h、权次2h+1，各源下阶max(L−v_r,0)。计算包括更大的q≤h,D≤2h+1整个线性空间；零核能排真实状态，非零模核只表示该线性测试没排除。保持v为全部源竖线指数的义务，模核中多出的竖线不能偷偷允许为实际状态。

所有原n/j/g、模板指数、粗支持/完整幂仍无界。若该线性必要域过宽，下一步优先分析全部模核何处依赖额外竖线、是否能给精确有理行关系，不能把模下公共因子直接提升到Q。
