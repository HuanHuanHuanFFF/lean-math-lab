# h² 在一个明列有限乘子空间中不可能

作者 `/root/reg3_terminal`；特征零有限线性空间否定，不是全局饱和否定。源与预算同 [01](01-nine-module-saturation.md)。

令原 h=r u(u−1)y(y−1)DNK。完整展开 h² 得到3,405项，总次数56，多重次数(u,y,r)=(26,20,12)，最大整系数48 bits。

对每个 F∈{P5,V4,V3,V2,V1,V0}，只允许乘子空间

    span_Q { u^a y^b r^c :
      0≤a≤26−deg_u F,
      0≤b≤20−deg_y F,
      0≤c≤12−deg_r F,
      a+b+c≤56−deg_total F }.

这个 ansatz 不允许高次数之间互相抵消后下降，因此并不覆盖所有可能的理想成员表示。禁止从本结果推断 h²∉J，更不能推断所有 h^m 均失败。

生成器严格读取六个原件并核hash，全部系数为整数；C++固定宽度消元在F_32003执行。源行按上述全部乘子枚举、再按总次数排序；单项式按总次数及字典序递减排序。生成列向量数量2,450，坐标单项式7,367。

实际结果：

    rank_F32003(M)=2450,
    rank_F32003([M | h²])=2451.

等价的按行实现：2,450条生成行全部独立；归约 h² 后首个无主元项的指数为(26,16,12)，系数23077。完整探针1.47秒，矩阵用 uint16_t 固定数组，最大原矩阵储存约36.1MB；没有 Python 大整数/字典填充。

**有理系数结论是严格的。** 原矩阵只有2,450行，故 Q 上秩至多2450。增广矩阵在F_32003存在非零2451阶子式，该整数子式在Q也非零，故增广秩至少2451。因此 h² 不在上述有理乘子空间中。这里不需未经证明的“模秩等于有理秩”假设，也没有通过模单位理想推出特征零单位理想。

可复算程序位于 ../../experiments/b/{generate_membership_input.py,rectangular_membership.cpp}。临时输入、日志、结果位于本轮 D: 临时目录；冻结回执与输入审计另载 experiments/b。g++使用已安装工具，不安装依赖。严禁把这次明确失败包装为数学无解；它只排除这个固定证书空间，下一路线是精确九维局部化关系模，而非盲目增加 m。
新增的固定子式证书为 ../../experiments/b/h2-nonzero-minor.json：选取原2,450行及目标h²行，明确给出2,451个坐标列，所得整数子式模32003的行列式为 **29924≠0**。作者另用 verify_minor.cpp 的逐列选主元稠密行列式算法，从原整数输入重建该方阵，直接算得同一29924；它不复用第一程序保存的消元行。完整矩阵只约12.0MB。两个算法仍同属作者检查，独立接受由具名核验另给。
