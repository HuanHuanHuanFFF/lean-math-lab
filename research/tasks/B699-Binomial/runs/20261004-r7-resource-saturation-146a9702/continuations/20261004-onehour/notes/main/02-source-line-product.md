# 主线程路线2：已知源线乘积能否给可用的显式G

动机：若权次305完整源能由六竖线和九条源线ell_a=X−a(N−a)的乘积实现，则该多项式在合法j≥10,n−j≥10处严格非零，可尝试回读K152高度/NC回传契约。这能解锁比逐个可载因子更直接的路线；但换G及高度合同必须另证，不能擅自替换原固定G。

首个可否证测试：非负指数v_r,t_a，源条件off为v_r+t_s+t_(r−s)≥OFF，中心为v_(2s)+2t_s≥DIAG；代价D=Σv+2Σt。先作精确有理LP求最小代价，若实数放松已>305，则此显式乘积路线在本次数预算内不可能；若≤305，再评估整数性和系数高度。LP本身不证明原题，也不将模核当实际G。余下原n/j/g等无界参数未变。

## 精确结果：已知线乘积次数至少315

记Lambda5为下列11个源阶的加权和，权为
(r,s;权)=(3,0;2),(3,1;3),(4,0;5),(5,0;3),(5,1;2),(6,2;3),(6,3;2),(7,1;2),(7,2;3),(8,2;1),(8,3;4)。中心(6,3)取权阶，其余普通阶。固定源下界给Lambda5≥1572。

对F=Π(N−r)^v_r Πell_a^t_a，有严格恒等式

    5 deg_w F − Lambda5(F) = 3t1+7t6+10t7+10t8 ≥0。

这是逐因子源阶可加直接核对：每个竖线在该行的系数和5，九线的Lambda5为(10,7,10,10,10,10,3,0,0)，而5倍各线权次为10。因此任何非负整数指数都给deg_w F≥ceil(1572/5)=315，不能在D305内满足固定21源。该结论不用LP算法；source-line-dual.json保存原15列逐项系数。LP还给达到1572/5的有理指数，证明实数放松最优，但无需该最优性来排D305。

失败的是“仅用九条已知源线及六竖线造D305显式G”这一方法类，并非一般G不存在。至少需要其它因子/构造；不据此界原n或减少R7。这里没有替换原固定G或绕过高度/NC回传契约。
