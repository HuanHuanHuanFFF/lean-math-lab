# 同一G的源保持变形预算（候选）

预期作用：把本轮目标从逐因子费用推进到“同一G的系数是否能同时实现”。成功给七因子可复用的联合必要条件；不承诺COVER6。首次应用于最低h107层，所有原n/j/g、模板和粗幂尺度仍未界。

## 1. 定义与一般联合命题

设固定源线性空间V_h由所有Q[N,X]中q=deg_X≤h、D=deg_w≤305且满足原21源下阶的多项式组成（含0）。取实际非零G∈V_h，从G的Q不可约分解中选取的k个两两不相伴因子H_i（非重数项）。q_i=deg_XH_i，D_i=deg_wH_i。

W_i是q≤q_i、D≤D_i的多项式线性空间，要求在非中心源的普通阶至少为H_i的实际普通阶，在中心源的(1,2)权阶至少为H_i的实际权阶。它不额外要求不可约、可载或在原NC点消失；H_i∈W_i。令d_i=dim_Q W_i。

则

    Σ(d_i−1) ≤ dim_Q V_h−1。

证明：Φ:⊕W_i→V_h，(U_i)↦Σ(G/H_i)U_i。次数不增，源阶在乘法下可加，故Φ确落V_h。若Φ=0，则在分式域ΣU_i/H_i=0；乘上所有不同H_i之积并模H_i，由两两互素/不可约性得H_i|U_i。再由加权次数界得U_i=c_iH_i，c_i∈Q。核恰为Σc_i=0的k−1维空间，因此rankΦ=Σd_i−k+1≤dimV_h。G内重复因子或其它未选因子不破坏论证，它们已包含在G/H_i中。

另由S305得**因子源最小性**：若某非零U维持H_i全部上述源阶，却有D(U)<D_i，则(G/H_i)U仍满足原源而权次<305，矛盾。这里不需要新多项式在原NC点消失或满足旧高度合同；它只用于源理想的已接受最小次数论证，未替换原题消费者。

## 2. 最低h107的刚性

固定原21源、e107/D305的完整F257模核维数为1。完整整数系数条件矩阵满足rank_Q≥rank_F257，故dim_Q V_107≤1；此处只用上界，不把模非零核反推有理G存在。若实际G位于该空间，它非零，故dimV_107=1。

## 3. 小权次因子的一维空间给系数高度

若d_i=1且D_i≤11，则W_i使用至多42个单项式N^aX^b（a+2b≤11且b≤q_i）。所有普通/剪切中心Hasse条件的整数矩阵元素绝对值≤9^11<2^35：在r≤8、源值s(r−s)≤16、剪切s≤4处，单个单项式局部展开的系数绝对值和≤9^a21^b≤9^(a+2b)。

从秩M−1矩阵取M−1个独立行，余子式给非零整数核向量。Hadamard界给每个余子式绝对值≤(sqrt(41)·9^11)^41<2^1558；除整数内容不增大小，全部至多42个系数的l1<2^1564。矩阵行数再多不影响这项取行论证。

因此在h107的实际G中，任何D_i≤11的不可约因子都与某个本原整数F相伴，F权次≤11且l1<2^1564<2^24980。条件采用旧固定小系数NC9消费者（保留合法400|n、同一(n,J)）：这样的H_i不能可载。结合七因子E≤1，每个可载因子在h107时必q_i≥6。

这没有独立重证旧小系数消费者；一般Φ命题、源维数上界与系数界各自分开接受。

## 4. 可直接核对的源线例子与实际收益

ell_a=X−a(N−a)。其(q,D)=(1,2)源保持空间在monomials(1,N,N²,X)内。a0..6各有至少三个不同N的源约束（中心权阶只加强），故空间1维；a7只有(7,0),(8,7)两个独立条件，空间2维；a8只有(8,0)一个条件，空间3维。因此h107的实际G不能含ell7或ell8。它们本来不可载；该结论约束的是完整G分解，不计原点覆盖。
