### 采用全部七项

数据 `outputs/seven_index_certificate.json`；检查器 `code/check_all_certificate.py`。

另外四项初始M超过十亿，必须先做符号族压缩，不能枚举每个余因子。CRT消费者输出新严格高度，再反复应用；最终M只有51..112，才接显式覆盖。

额外算法义务：素数幂列表完备性；所有 d∈[−i+1,i−1] 的CRT解；有符号ceil/floor；低分支B=max(i(i−1),M+1)；全部族最大端点的声音性。最初通用CRT可直接使用全公式，不必立即形式化生成器的单点快速分支。

## 需要独立审查的重点

- 定位使用 `v_p(C(n,i))+v_p(i)≤max v_p(n−r)`，不是无补偿的指数。
- p=i只在旧大素数整除链里出现额外分母补偿，不能从V里删除它。
- M大时必须保留n≤M，否则p^0=1会使“双大幂”推出的非零指数不合法。
- 两个大幂可以处在同一n−r；CRT的d=0不能跳过。
- 同一种p的两条重叠区间不是两种颜色。
- 最终候选非空固定点不是反例，也不是原题矛盾；必须消费全部末端见证。
- 大除子d只需满足原始整除、互素、大小三条件；不要求大整数分解，不依赖“d恰为V”的额外算法。
- 高度表BFT输入、无限量词覆盖证明、普通Python精确检查、Lean是四层不同义务。

## 复现

从包根运行：

```bash
python3 code/reproduce.py
```

只重放较小三项：

```bash
python3 code/reproduce.py --three-only
```

仅重新核验已有数据并跑边界测试，不重新生成：

```bash
python3 code/reproduce.py --check-only
```

Python3.10以上标准库即可，使用大整数，不依赖互联网、SymPy、浮点或Lean。实际耗时与退出码在重放JSON内；这里不承诺新机器的运行时。检查器和生成器由同一会话独立编写不同算法，不应描述为第二个独立会话或人类审稿。
