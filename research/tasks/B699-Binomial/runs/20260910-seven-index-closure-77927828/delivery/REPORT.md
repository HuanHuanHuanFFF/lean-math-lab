## 2. 新机制一：把已知高度反过来喂给余因子约束

沿用实际 U/V/D 与三窗口参数：t=π(i−1)，λ=2s−r，L=i−r−1，

\[
E=s(s+1)+L(L+1)/2,\quad
K=2^{s(s+1)}\left(\prod_{h=1}^s h!\right)^2\prod_{h=1}^L h!.
\]

旧结构在 noCommon 下给

\[
K(n)_i^\lambda\le(i!)^\lambda U^\lambda n^E.
\]

此前卡点是净指数不正，不能从一个低端 N 推出统一 M=64。本轮已经有 n<H，故令

\[
\delta=E-\lambda(i-t)\ge0
\]

并取满足以下**纯整数证书**的 M：

\[
\boxed{KM^{\lambda(t-1)}\ge (2\cdot i!)^\lambda H^\delta.}
\]

则只要

\[
n\ge B:=\max(i(i-1),M+1),
\]

noCommon 必迫使至少两个不同小素数 p<i 的实际完整幂
\(p^{v_p\binom ni}\ge n/M\)。每个这样的幂经完整赋值补偿，被定位到

\[
n\in[Ap^h,Ap^h+i-1],\quad
h>v_p(i),\quad p^h<H,\quad
1\le A\le\lfloor M/p^{v_p(i)}\rfloor.
\]

全部低端 \(2i+2\le n<B\) 原样保留。B 中的 M+1 是为排除零指数而新增的必要分支，不能丢掉。

对于 i=27,30,33，初始最小 M 只有452、535、618。因此先完成了显式区间算法；完整余因子域确实能处理，不是猜测 M=64 可用。

## 3. 新机制二：CRT 消掉巨大余因子的枚举

另外四项的初始 M 达到

```
i=17:       2,268,188,553
i=23:      38,842,635,194
i=26:     126,553,954,161
i=32:     953,256,373,357
```

直接枚举 A 会失去实用性。因此本轮没有直接扩容旧扫描，而是解完整交集方程。

对不同素数幂 Q=p^h、R=q^k，区间相交必须满足

\[
QA-RC=d,\qquad |d|\le i-1.
\]

CRT 给全部解 \(A=A_0+Rz,\ C=C_0+Qz\)。把余因子范围及 n∈[B,H−1] 翻译成一个精确整数区间 \(z_-\le z\le z_+\)，就能直接算出整族的最大 n，无需枚举 A、C 或 z。d=0、负 d、两幂落到同一位置、取整端点均包含在这个参数化中。

对所有小素数幂对与所有 d 求最大值，同时保留低端 B−1，可得到新的严格高度 H′。再用 H′ 求更小的 M。这个反向代入与 CRT 参数化，构成本轮主要新引理；逐步证明见 [notes/PROOFS.md](notes/PROOFS.md)。

原定三项的实际高度链是：

```
i=27: 2^95  -> 104333339 -> 688154 -> 固定
i=30: 2^110 -> 104333342 -> 688157 -> 固定
i=33: 2^125 -> 104333345 -> 439009 -> 327713 -> 固定
```

每个数都是严格上界 n<H；例如 n<688154 对应表中的最大候选688153。全七项共有33个已检查阶段（包含最后固定点核对）。

CRT 算法的循环数依赖素数幂族数量的平方和 2i−1 个位移，不以 M 为循环次数。但是它仍依赖 log H；没有声称任意给出的有效高度都能实际压缩，也没有把非有效常数变成可执行终点。

## 4. 为什么末端排除覆盖全部 j

最终 M 已降到51至112，才显式生成每个素数颜色的区间并，并取两种不同颜色的交集。加入全部合法低 n 后，得到表中完整47,113行。

每个候选通过以下两类消费者之一消去：

**顶端素数区间。** 证书给素数 p 和闭区间 [a,b]，验证
\(p\le a\le b<p+i\)。对区间中的每个合法 n，p∈(n−i,n]。于是 p 同时在 C(n,i) 与 C(n,j) 的分子中、但不在分母中，覆盖每个合法 j。

**大除子行。** 证书给正整数 d，验证

\[
\gcd(d,(i-1)!)=1,\quad i!d\mid(n)_i,\quad Kd^\lambda>n^E.
\]

前两式保证 d|V；noCommon 与三窗口给 KV^λ≤n^E，从而矛盾。检查器不要求分解 d 或证明 d 恰等于全部 V。该原题消费者保留 p=i，不把 radical 当成完整幂。

所有见证的并必须**恰好等于完整候选并集**；区间计数与单行数也独立相符，不能靠重复覆盖抵销遗漏。
