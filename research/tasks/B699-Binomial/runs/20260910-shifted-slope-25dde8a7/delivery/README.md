执行任务：用户附件 `B699-fresh-start-task-20260909(1).zip` 中的 `TASKS.md`。

## 交付的数学结论

均针对原题 **i=3、3<j≤floor(n/2)**，结论仍要求同一个素数 **p≥3** 同时整除两个二项式。

1. **完整无限族**：令 `b₀=j/gcd(n−1,j)`、`b₁=(j−1)/gcd(n−1,j−1)`，则 `min(b₀,b₁)≤32` 时原题成立。纸面有限化后，两种独立实现一致得到7个不同候选，全部有公共素数3。
2. **明确相对高度**：任意反例满足 `n≤H₀(b₀)` 和 `n≤H₁(b₁)`，多项式 H 的精确公式及全部零分支见报告。b 仍无界，所以不是 i=3 的绝对有限性。
3. **统一排除带**：任何反例对所有整数 m 都满足 `n≤33(n−1−mj)²`；若 `v₃(n−1)≠1`，常数可改为3。
4. **完整固定偏移族**：结合第3项和独立有限核查，所有 `n=mj+c`、整数 `−16≤c≤18`、任意整数 m 的合法输入均满足原题。该结论不对 n 或 m 预设上界。

尚未证明整个 B699，也未证明整个 i=3 的绝对有限性。没有 Lean 编译、没有仓库写入，也没有文献首创性主张。

## 复现

实际执行环境为 Python 3.13.5、SymPy 1.14.0。除 `verify_core.py` 的两项符号恒等式核查外，其余脚本只使用 Python 标准库；有限候选的生成与排除不依赖 SymPy。不得以 `python -O` 或 `PYTHONOPTIMIZE` 禁用核查断言。

先检查收到的原始交付字节：

```sh
python scripts/verify_manifest.py
```

在已安装 SymPy 的环境中重放全部检查：

```sh
python scripts/reproduce.py
```

也可同时核查用户原附件的哈希：

```sh
python scripts/reproduce.py --input-archive '/path/to/B699-fresh-start-task-20260909(1).zip'
```

`reproduce.py` 执行全部6个研究脚本，比较候选列表并检查实际二项式整除，输出至 `evidence/`。任何子进程失败都会令最终状态为 FAIL；没有通过时不会输出虚假的 PASS。

**哈希注意事项**：重放会更新含耗时/时间戳的证据文件，因此原始交付的 `MANIFEST.sha256` 应在重放之前验证；重放之后它不再代表新运行的字节。数学候选与核查结果应保持一致，运行耗时不要求一致。

## 验证的含义

本包中的“独立”指两个不同枚举实现、或直接二项式计算与 Legendre 求和之间的交叉核查，不指另一位研究者已经审稿。计算的完备性仍以报告中从任意反例到有限枚举区间的纸面推导为前提。输入包和输出包的哈希通过只证明字节完整，不能替代数学审稿或 Lean 内核验收。
