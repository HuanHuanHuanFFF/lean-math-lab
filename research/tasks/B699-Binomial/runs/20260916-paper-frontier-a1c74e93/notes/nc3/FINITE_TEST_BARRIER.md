# 镜像 m=5：有限原始进位层与内部区间仍可同时兼容

纸面方法边界；不是原题反例，也不是变量模数 Π 的解。来源动机是已读 normalized-three-neighbor 原 `notes/PROOFS.md` §7 的 CRT 端点 `(x,u)=(5,1/2)`。本稿扩展其准确兼容范围，不主张文献新颖性。

## 1. 精确命题

任给正整数 M、有限个奇素数幂组成的集合 S，以及任意非空开区间 `I⊂(0,1/2)`，存在任意大的整数 s≥1、x=5·2^s 和整数 u≥1，使同一个输入

    n=x², j=25u(x+1)/3

同时满足：

1. j 为整数，`4≤j<n/2`，`j/n∈I`；`gcd(n,j)=25`，`α=n/g=2^{2s}`。
2. `v₃(x+1)=1` 且规范丢失因子 `(x+1)/gcd(x+1,j)=3`。
3. 对 S 中每个 p^h，均有 `j modp^h=n modp^h`。因此这一有限集合中的每个真实 Kummer/Legendre 进位指示量都是零；并不只筛选分子窗口弱整除。
4. 令 D=x−1，

       F_h(x,u)=4u(25u−3D)(25u−6D)−(hD−9u)(x²−2)。

   有 `F_1(x,u)≡0 modM`，但可以同时保证 `F_1(x,u)≠0` 和 `F_2(x,u)≠0`。
5. x 可取得充分大，使 G4 与旧 OLD128 的必要大小不等式也都成立。

最后的非零条件意味着本构造**不满足完整 NC3**，而且不能通过同一归一化分支要求的精确双窗口。它说明有限个固定进位层加固定残量模数，不能单独把该结构筛空；不是对包含变量模数、精确方程或其他全局约束的方法作不可能断言。

## 2. 固定同余类

写 `M=2^k M_o`，M_o奇。取

    Q=45 M_o ∏_{r∈S} r, K=max(k,1)。

Q 为奇数，且包含每个 r 的三倍，所以后面除以3时仍保留模r信息。精确端点身份是

    F_1(5,1/2)=0。

另一方面

    F_1(0,u)=2f(u), f(u)=1250u³+450u²+27u−1。

f(1) 为偶数，且 `f'(u)=3750u²+900u+27` 对每个整数u为奇数。由直接二项式展开，每次从模2^a的奇根提升到u或u+2^a，恰有一个成为模2^{a+1}的根。因此存在奇整数 u₂，使 `f(u₂)≡0 mod2^K`。

CRT 给一个固定同余类

    u≡u₂ mod2^K,  2u≡1 modQ。

其模数为 `L=2^K Q`，类内每个u都奇，且3∤u。选 s 为 `lcm(6,ord_Q(2))` 的任意充分大倍数，并要求 s≥K。这样 x=5·2^s 满足 x≡5 modQ、x≡0 mod2^K。

整数多项式代入保证 `F_1(x,u)≡0 modM`。其中奇部用有理端点（2可逆），二部用f的提升；没有把有理端点本身当作合法原题输入。

## 3. 同一个合法输入与全部有限进位层

s≡0 mod6 给 x≡5 mod9，故 `v₃(x+1)=1`。类内3∤u，因此 `(x+1)/gcd(x+1,j)=3`。u奇且(x+1)/3奇，所以 j奇；j被25整除，而 n 的奇部恰为25，故 gcd(n,j)=25。

对任意 r∈S，Q 是3r的倍数，且 x≡5、u≡1/2 mod3r。因此

    j=25u(x+1)/3≡25 modr, n=x²≡25 modr。

原始进位指示量 `[j modr>n modr]` 恰为零。此证明保留 p^h 的整个幂，不把多层条件缩成模p。

若 `I=(a,b)`，0<a<b<1/2，则 `j/n∈I` 等价于

    3a x²/[25(x+1)] < u < 3b x²/[25(x+1)]。

该区间长度随x线性增长，而允许u的间距L固定。可先在I内取有理子区间，以纯整数端点实现同一选择。对充分大的x，区间至少含7个允许u；它们正且给合法 j≥4。

## 4. 避开精确反设，而非伪造它

固定x时，F_1、F_2都是u的三次多项式，首项系数为2500，各至多有3个实根。上述至少7个候选u中可选一个同时避开两者全部整数根。

为什么这不是NC3？在此 x=5·2^s、b=3 分支，若两个原窗口同时成立，令 a=25u，则它们给正整数

    q₀=6a(a−3D)(a−6D)/(x²−2),
    ρ=(2q₀+27a)/D。

旧归一化证明的精确恒等式给 `0<ρ<162`、25|ρ、v₃(ρ)=1，故 `ρ=75h` 且h只能为1或2。消去q₀便是 `F_h(x,u)=0`。所选u避开两种精确等式，因此不满足这一完整双窗口，当然不构成原题反例。

这里保留了同一个n、j、g以及所有有限原始进位测试，明确失败的是随x变化的完整窗口/精确残量，而非一个固定模数。j/n可处在任意内部开区间，故有限兼容性并非只由趋于0或1/2的合法位置造成。

## 5. 旧大小条件可同时成立

本构造g=25，n=x²→∞，故 `g⁴<3n` 对充分大x成立。n的奇部为25、n mod9=7，所以旧OLD128为

    128·25⁴(n−1)³<27n⁴。

只要 `27n>128·25⁴` 就成立。选择s充分大即可同时满足。未声称保留全部历史有理斜率、几何条带或其他消费者；这些需按实际候选逐条检验。

## 6. 对下一项工作的含义

追加固定模数或固定层数不能单独补上通用入口；即使保留完整α、g和内部j位置，也可通过任意预先有限的原始进位层。值得继续的对象是同一输入的变量模数N、K、精确F_h=0，或随n增长的完整进位信息。此处没有证明这些全局工具无效，没有闭合m=5镜像分支，也没有将有限兼容模型当成Π或NC3。
