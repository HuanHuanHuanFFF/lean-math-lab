# NC3：奇素数进制等间距同数字整行（审读稿）

作者 `/root/nc3`。本稿为纸面证明，未 Lean；独立审读状态由主线程记录。保留原题 `4≤j≤⌊n/2⌋`、共同素数 `p≥3`。`NC3(n,j)` 表示不存在这样的同一素数。下文的表示素数 P 未必是最终共同素数。

## 1. 精确结论

设 P 是奇素数，`1≤A<P`，`f,d,k≥1`，且

    n = A P^f S_k(P^d),    S_k(q)=1+q+⋯+q^(k−1).

则每一个合法 j 都满足 i=3 原题。A、P、f、d、k、n、j 均无预设上界；特别 k 可增长。本结论是整行消费者，不是一般 NC3 的归约，也不宣称所有这些行在历史消费者并集中此前均未知。

证明只用 §2 的完整反设前置、几何和因式分解、整数不等式，以及 11、23、239 的小素性核对。不会把两窗口通过升级为 NC3。

## 2. 固定前置与重构

本轮实际采用并定向重构的出处：canonical run `20260912-leader-r7-joint-58-c8c256bc/intake/20260915-daily-results/materials/B-prime-radix-two-digit-row/notes/PROOFS.md` §§1.1–1.2（原始文件 11514 字节）。下面重写必要链，便于独立审读。

令 `g=gcd(n,j)`、`α=n/g`、`β=j/g`。恒等式 `β C(n,j)=α C(n−1,j−1)` 与 `gcd(α,β)=1` 给 `α|C(n,j)`。每个奇素数 p≥5 若整除 n 就整除 C(n,3)；3 唯一可能完全被分母取消的是 `v₃(n)=1`。故 NC3 必须满足

    α=c 2^s, c∈{1,3}; c=3 只能在 v₃(n)=1 时出现。       (ALPHA)

完整无进位公式为 `v_p C(n,j)=Σ_{h≥1}[j mod p^h > n mod p^h]`。因此 NC3 中，凡 p 整除 C(n,3)，每一层都无进位；特别 p^e|n 强迫 p^e|j，保留全部幂。

此外 NC3⇒`4|n` 且 `j<n/2`：若 n 奇，ALPHA 和合法范围只留 α=3、β=1，即 n=3j。n−2 有素因子 p≥5；无进位使 j modp∈{0,1,2}，与 3j≡2 modp 矛盾。若 v₂(n)=1，α∈{2,3,6}，仍只留 β=1，故 n=tj。第一窗口 `n−1|3j(j−1)` 与 gcd(n−1,j)=1 给 `n−1|3(j−1)`；t≥3 时右侧更小，t=2 时比值严格在1与2之间，均矛盾。同一论证排除 j=n/2。

写

    λ=3 若 v₃(n−1)=1，否则1；
    μ=3 若 v₃((n−2)/2)=1，否则1；
    N=(n−1)/λ, K=(n−2)/(2μ), V=λ³μ²∈{1,9,27}。

完整幂窗口给 `N|j(j−1)`、`K|j(j−1)(j−2)`。当 3 的赋值≥2，保留的是完整3幂，不截去一层。N、K 为互素奇数。令 `z=n−j`、`C=gcd(K,j−1)`、`F=K/C`。每个完整素数幂唯一分配到 j、j−1、j−2 中的一项，因此

    H=jz/(NF), U=(j−1)(z−1)/(NC²)

均为正整数。且 gcd(g,NF)=1、g²|jz，故 g²|H。于是

    g⁴ ≤ H²U
       =4V j²z²(j−1)(z−1)/[(n−1)³(n−2)²]
       ≤27n⁴/[16(n−1)³] < 3n.                       (G4)

最后一步对 n≥8 成立：令 r=n−8≥0，`48(n−1)³−27n³=21r³+360r²+1872r+2640>0`。

记 `t=2^{v₂(n)}`、`m=n/t` 为 n 的完整二幂部和奇部。由 ALPHA，`g≥m/3`，所以 NC3 必须满足

    m⁴<243n, 等价地 n³<243t⁴。                    (ODD)

若 P≥5，或 P=3 且 v₃(n)≥2，则另有 P^{v_P(n)}|g。ODD、G4、ALPHA 和窗口都是 NC3 的必要条件；没有反向声明。

## 3. 几何和的完整二赋值

令 q=P^d 为奇数。若 k 奇，S_k(q) 奇。若 k=2^r u，r≥1、u奇，则

    S_k(q)=S_u(q) ∏_{h=0}^{r−1}(q^{u 2^h}+1).

S_u(q) 奇；首因子 q^u+1 与 q+1 的商是奇数；h≥1 时 q^{u2^h}≡1 mod8，故恰含一个2。因此

    v₂(S_k(P^d))=v₂(P^d+1)+r−1。

若 d 奇，`v₂(P^d+1)=v₂(P+1)`；若 d 偶，它等于1。两种情况统一给

    2^{v₂(S_k(P^d))} ≤ (P+1)2^{r−1} ≤ (P+1)k/2。

从而 k 偶时

    t ≤ A(P+1)k/2 ≤ (P²−1)k/2 < P²k/2。          (TBOUND)

同样 n≥P^{f+d(k−1)}≥P^k。A 含高二幂时仍由完整 `2^{v₂(A)}≤A≤P−1` 覆盖。

## 4. k 奇且 k≥3，及 k 偶且 k≥6

若 k 奇且≥3，t≤A<P，而 n≥P³。因此

    n³≥P⁹≥243P⁴>243t⁴，

其中 `P⁵≥3⁵=243`，与 ODD 矛盾。

若 k 偶且≥6，由 TBOUND，足以证明

    16P^{3k−8} ≥ 243k⁴。

P≥3 时只需 `16·3^{3k−13}≥k⁴`。k=6 左侧3888，右侧1296。k→k+1 时左侧乘27，而 `(k+1)⁴≤16k⁴`，所以对全部整数 k≥6 成立。于是 `n³≥P^{3k}>243t⁴`，再次与 ODD 矛盾。这一步处理无界重复次数，不枚举 k。

## 5. k=1

此时 n=AP^f。P≥5 或 P=3、f≥2 时，P^f|g，G4 给

    P^{3f}<3A<3P，

不可能。P=3、f=1 只有 n=3、6，没有合法 j。本段也处理 k=1 时 d 的无关自由值。

## 6. k=2

此时 `n=AP^f(P^d+1)`。

### 6.1 d=1

若 P≥5，或 P=3、f≥2，则 P^f|g；G4 给

    P^{3f}<3A(P+1)≤3(P²−1)。

P≥5 时 `P³>3(P²−1)`；P=3、f≥2 时 `P^{3f}≥729>24`。仅留 P=3、f=1，A=1或2，得到 n=12、24，交由 §8。

### 6.2 d 偶，d≥2

`v₂(P^d+1)=1`，故 `m≥P^f(P^d+1)/2`，并且 `n≤(P−1)P^f(P^d+1)`。因此

    m⁴/(243n)
      ≥ P^{3f}(P^d+1)³/[3888(P−1)]
      > P^{3f+3d−1}/3888
      ≥ 3⁸/3888 > 1。

这与 ODD 矛盾，包含 P=3、f=1 的分母取消情形。

### 6.3 d 奇，d≥3

令 `R=(P^d+1)/(P+1)`，它是奇数，且 `R≥P²−P+1≥7`（d 从3增加2时 R 变为 P²R−P+1，严格增加）。于是

    m≥P^f R, n≤(P²−1)P^f R,
    m⁴/(243n)≥P^{3f}R³/[243(P²−1)]
                >P^{3f−2}R³/243≥3·7³/243>1。

再次与 ODD 矛盾，包含全部高奇间距。

## 7. k=4

若 d≥2，TBOUND 的精确 r=2 给 `t≤2(P²−1)<2P²`，而 `n≥P^{f+3d}≥P⁷`。所以

    n³≥P²¹>3888P⁸>243t⁴，

其中 `P¹³≥3¹³>3888`，与 ODD 矛盾。

若 d=1，则

    n=AP^f(P+1)(P²+1),
    m≥P^f(P²+1)/2,
    n≤(P²−1)P^f(P²+1)。

故

    m⁴/(243n)≥P^{3f}(P²+1)³/[3888(P²−1)]
                >P^{3f+4}/3888。

P≥5 时右侧≥5⁷/3888>1；P=3、f≥2 时右侧≥3¹⁰/3888>1。因此只留 P=3、f=1、A∈{1,2}，即 n=120、240。n=120 的奇部 m=15 满足 `15⁴=50625>243·120=29160`，已被 ODD 排除。剩 n=240，交 §8。

## 8. 三个边界行

对 n=12、24、240，p=n−1 分别为11、23、239，都是奇素数。239 的素性只需试除不超过√239的素数2、3、5、7、11、13，均不整除。

一般地，若 n=p+1、p≥5 为素数，则对 `4≤j≤⌊(p+1)/2⌋<p`，分子 `(p+1)!` 恰含一个 p，而 j! 和 (p+1−j)! 均不含 p，故 p|C(n,j)；同理 p|C(n,3)。因此这三整行全部满足原题，不是仅列若干 j。

§4–8 已覆盖每个 k≥1，以及每个 d、f、A、P 的允许值，整行定理得证。
