## 3. 原题前置的独立重构

固定一个假定 NC3 的合法 `(n,j)`，置 `z=n−j`、`g=gcd(n,j)`、`α=n/g`、`β=j/g`。

### 3.1 ALPHA、一次 3 与非 4 倍数

恒等式 `β C(n,j)=α C(n−1,j−1)` 与互素性给 `α|C(n,j)`。若奇素数 `p≥5` 整除 n，则 p 也整除 `C(n,3)`；p=3 唯一可完全消失的情况是 `v3(n)=1`。所以 `α=c2^s`，`c∈{1,3}`，且 c=3 只能出现在 `v3(n)=1`。没有丢掉 p=3，也没有把完整 3 幂截成分母扣除后的幂。

对任意素数 p，阶乘整数地板差逐层给

`v_p C(n,j)=Σ_{h≥1}[j mod p^h>n mod p^h]`。

每项非负；只要 p 整除 `C(n,3)`，NC3 就要求所有层都为零。p^e|n 因而强迫 p^e|j。

n 奇时，合法性及 ALPHA 只留 `α=3,β=1,n=3j`。n−2 与 6 互素且大于 1，取其素因子 p≥5；第一 p 层强迫 j 的余数是 0、1、2，但 `3j≡2 mod p` 与三者都冲突。

始终有弱窗口 `n−1|3j(j−1)`。若 n=tj、t≥2，则 gcd(n−1,j)=1，故 `n−1|3(j−1)`；t≥3 时正的右侧更小，t=2 且 j≥4 时比值严格在 1 与 2 间。因此所有这种斜率被排除。`v2(n)=1` 的 ALPHA 仅留 α=2、3、6，互素合法 β 均为 1，归入此论证；j=n/2 也被排除。于是 NC3 必须有 `4|n`、`j<n/2`，且 n≥8。

### 3.2 完整幂窗口与 G4

设 λ、μ 只删除 n−1、(n−2)/2 中孤立的一次 3，令 `N=(n−1)/λ`、`K=(n−2)/(2μ)`。N、K 为互素奇数，`λ³μ²∈{1,9,27}`。完整无进位给

`N|j(j−1)`，`K|j(j−1)(j−2)`。

当相应 3 赋值至少 2，3 已整除首个二项式，故保留完整 3 幂；这是所需的强窗口。

令 `C=gcd(K,j−1)`、`F=K/C`。K 中每个奇素数幂在 j、j−1、j−2 中只能落在一项。C 因而完整分配到 j−1，且也整除 z−1；F 的各完整幂落在 j 或 z。模 N 有 z≡1−j，故 N 同时整除 jz 和 (j−1)(z−1)。因此

`H=jz/(NF)`、`U=(j−1)(z−1)/(NC²)`

均为正整数。g 与 NF 互素，且 g²|jz，所以 g²|H。于是

`g⁴≤H²U=4λ³μ² j²z²(j−1)(z−1)/((n−1)³(n−2)²)`

`≤27n⁴/(16(n−1)³)<3n`。

最后严格不等式对 n≥8 成立；平移 r=n−8 后的差为 `21r³+360r²+1872r+2640>0`。这个论证不需要假定窗口投影等价于 NC3。

写 `n=tm`，t 为完整二幂部、m 奇。ALPHA 给 `g≥m/3`，故 NC3 必有 `m⁴<243n`。这是必要条件，不是反向识别。

## 4. 原同数字族的分类没有漏项

完整二赋值为：k 奇时 `v2(S_k(P^d))=0`；k 偶时

`v2(S_k(P^d))=v2(P^d+1)+v2(k)−1`。

可直接把几何和按 k 的完整二幂部分分解；第一因子的二赋值来自 P^d+1，以后的偶幂加一均恰含一个 2。d 奇时第一因子与 P+1 同赋值，d 偶时恰为 1。这正确计入 A 的二赋值；`2^v2(A)≤A≤P−1` 没有假定 A 奇。

逐式检查结果：

- k 奇且≥3：`n≥P³`、t<P，故 `n³>243t⁴`。
- k 偶且≥6：`t<P²k/2`，`n≥P^k`；`16·3^(3k−13)≥k⁴` 从 k=6 起成立，每步的 27 倍增长足够覆盖右侧。这里证明全部无界 k，不靠表格。
- k=1：P≥5 或 P=3,f≥2 时完整 P^f|g 与 G4 矛盾；P=3,f=1 只有 n=3、6，没有合法 j。d 的任意值不影响此支。
- k=2：d=1、d 偶≥2、d 奇≥3 三类完整；P=3,f=1 的孤立取消正确留到 n=12、24。
- k=4：d≥2 统一排除；d=1 仅留下 P=3,f=1、n=120、240；120 已被奇部界排除。
- n=12、24、240 的 n−1 分别为素数 11、23、239。对全部合法 j，分母两个阶乘均不含该素数，而 n! 恰含一次，故同一素数适用于 C(n,3) 与该行所有 C(n,j)。239 的试除范围完整。

所有 P、A、f、d、k 的允许值以及全部合法 j 均已覆盖。

## 6. 数学有效不等于新增原题覆盖

### 6.1 全族都已在 ROW128 的拒绝区

两稿的分类实际上足以证明更便于比较的无条件式：对每个允许参数，`m=oddpart(n)` 满足 **m⁴>3n**。

原稿大部分分类已证明更强 `m⁴>243n`。k=1 和 k=2,d=1 时改用 m≥P^f，原来的 P 幂比较直接给 m⁴>3n；n=12、24、120、240 直接计算也成立。扩展新增的两个小参数带有

- n=30A、A≤8：`m⁴/n=15⁴a³/(30·2^r)≥50625/240>3`；
- n=84A、A≤26：`m⁴/n=21⁴a³/(84·2^r)≥194481/1344>3`。

历史 OLD128 对任何 NC3 给

`128m⁴(n−1)³<κn⁴`，`κ=δ³λ³μ²∈{1,9,27}`，

其中 δ 只删除 n 中孤立的一次 3。定向重构如下：ALPHA 中 s≥1，否则归入前述 n=tj 排除；于是 β、γ 均奇。置 `R=βγ/(NF)`，则 R 为正奇数且 H=g²R。若 g 奇，(j−1)、(z−1) 的二赋值合计至少 3，所以 8|U；若 c=3，则另外 3|U。故 g 奇时 U≥8c，g 偶时 U≥c。写 `g=(m/c)2^t`，两类均给 `g⁴R²U≥8m⁴/δ³`。结合 G4 同一乘积式的严格上界，即得 OLD128。三个连续窗口中最多一处孤立 3，故 κ≤27。

但 m⁴>3n 与 n≥8 给

`128m⁴(n−1)³>384n(n−1)³>27n⁴≥κn⁴`，

矛盾。非 4 倍数先由旧前置排除；无合法 j 的小 n 为空命题。

**因此，两条整族定理相对已采用的旧 ROW128 均没有新增原题未知域排除。** 这不是“差集尚未检查”的模糊状态；已有一个明确旧消费者包含了整个接受族。无需再审计其他旧消费者，也不能把这个新表示接口计为旧残余核心的新下降。
