# H02第一自由行：残量高度与朴素下降失败

2026-09-15 22:56–23:02 UTC，/root。动机来自 arithmetic/HANDOFF 的因子交换身份。投入前判断：若把第一自由行的整数商界成常数，即能把整个H02送入可完成的有限检查；单独得到更小整数而不保持原输入，不算下降。以下给固定残量的有效界，残量本身仍无界。

## 1. 同一输入与整数分拆

采用本轮已核的NC5 H02前置、j≥6：2和3的最大高幂在0、2不同位置，n−1与6互素。因此其小部s只有1或5；s=5仅在v5(n−1)=1时。令q1=(n−1)/s、g=gcd(n,j)、α=n/g、β=j/g、k=n−j。

完整r1窗口给q1|jk；因为g与n−1互素，得到 **q1|β(α−β)**。这是必要条件。gcd(β,α−β)=1，把q1的完整素数幂分为

`q1=uv, β=ub, α−β=vc`，

其中u,v,b,c均正。定义 **t=bc=β(α−β)/q1**；t是规范的正整数，不是随意选择的新参数。

有 `g(ub+vc)−suv=1`。取

`U=su−gc, V=sv−gb`，

则 `vU=j−1>0,uV=k−1>0`，所以U,V为正整数，即使s=5也如此。精确身份是

`UV=g²t−s`，`sα=bU+cV+2gt`。

这里没有产生新j，也未证明新的二项式反例输入。

## 2. 每个固定残量的有效高度

因为b,c≤t、U,V≥1且U+V≤UV+1，

`sα≤t(U+V)+2gt≤g²t²+2gt−(s−1)t≤(gt+1)²−1`。 (A)

本轮采用的H02两条相对界是g⁵<(625/8)n与g⁷<2²²n。第一条给

`g⁴<(625/8)α<(625/8)(gt+1)²`，

所以 `g²<9(gt+1)`，用625/8<81。若g≥10t，则g(g−9t)≥10t²>9，矛盾。因此

**g<10t，α<100t⁴/s，n<1000t⁵/s。**

α界使用整数g≤10t−1，故gt+1≤10t²。第二条和gt+1≤2gt给

`g⁶<2²²α<2²²(gt+1)²/s≤2²⁴g²t²/s`。

从而g²<2¹²t（还可以保留s的平方根，但不需要），再代(A)可得

**α<2¹⁴t³/s，n²<2⁴⁰t⁷/s²。**

因此对每个预定T，所有真实NC5 H02且t≤T的输入有明确绝对n上界。尚未把t本身界住，未完成这些有限底部，也没有新增完整H02覆盖；这是给下一步完整r2耦合使用的有效残量接口。

## 3. s=1的较小整数不自动成为原题下降

s=1时，`n'=g²t=jk/(n−1)` 为正整数，且

`n'≤n²/(4(n−1))<n/3`（n>4）。

U=u−gc、V=v−gb各严格缩小，UV=n'−1。但沿用同一g会给α'=n'/g=g t，通常失去旧六模板；尚无合法j'或全部窗口回传。s=5时n'=5jk/(n−1)，连n'<n也没有这一普遍保证。

主线程做了一次有辨识力的小实验：a3..18、g2..60，只保留α=2^a、H02位置、s1、原r0/r1和两条g界。36个待分解行只找到一个这种弱模型：

`n=155648,j=65303,g=19,α=8192,β=3437`；

`u=491,v=317,b=7,c=15,t=105,U=206,V=184`。

于是n'=37905、沿用g的α'=1995不属于六模板。更根本地，n'=3·5·7·19²本身没有高2/3幂。这个模型的原r2已经失败：n mod8647=2，而j mod8647=4774；r3/r4也失败。它**不是原NC反例**，只证明第一自由行与现有g界不足以保证上述朴素下降。
