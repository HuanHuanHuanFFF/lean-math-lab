# 三次曲线方向交付报告

## 已取得的结果

本轮从一个固定镜像三次残量出发，完成全部b=3规范分支，再把任意规范b接到统一显式高度。以下均为纸面结果与严格计算，已有独立AI接收；没有Lean、人工同行审稿或文献首创声明。

1. **原题b=3接口完整闭合。** 对NC3平方行n=x²，任取epsilon=+/-1、zeta=j或n-j，规范b=(x+epsilon)/gcd(x+epsilon,zeta)不可能等于3。由此与SQ3接成常用消费者：v3(x+epsilon)=1且(x+epsilon)/3∣zeta时，必有同一奇素数p>=3整除C(n,3)、C(n,j)，不再排除平方根奇部m=1或5。
2. **减号整行补齐。** 对任意素数P、r>=1，n=(3P^r-1)²的全部合法j满足原i3结论。加号n=(3P^r+1)²也有本轮统一重构的完整证明，但该加号族是旧成果，不重复计新增覆盖。P=2、P=3与完整3幂端点均已单列。
3. **全平方规范支持下界。** 定义lambda=3当v3(n-1)=1，否则lambda=1，N=(n-1)/lambda。每个平方NC3都必须omega(N)>=4；若v3(n-1)=1，则omega(n-1)>=5。omega计不同素因子，N仍保留未取消处的完整素数幂。
4. **任意真实b的统一高度。** 每个平方NC3的四个实际规范b都满足

       log n <= 2(960 b³)^600000。

   这是Masser 2024全解整点界在一个统一光滑三次族上的应用。固定B时，至少一个真实b<=B的所有平方候选都有明确n上界；b本身仍无界，巨大有限底部未排空。

**一般i=3没有解决，R7仍含3。** 一般非平方行、平方行四块混合及仍增长的b都没有统一终止界。没有发现原题反例。

## 来源与实际贡献

显式椭圆对数下界采用Tzanakis作者修订PDF的David定理；一实根基本周期面积另有直接二覆盖交数证明。一般b采用[Masser 2024](https://doi.org/10.1017/S0305004124000057) §5的全部整数解界，明确核对了首页仅为存在性搜索界的差别。原PDF与609/617/620页的实际字节/图像收据已固定。

旧NORMALIZED材料明确留下m1与m5镜像。本轮补齐这些原先无界的必要分支，且统一界掉所有固定b的大高度部分。旧SQ、既有加号整行和此前被OLD128包含的重复字块族不重计发现功劳；没有声称已证明与全项目历史消费者并集不相交的无限输入集合。

## 失败与下一步

实际NF IntegralPoints因非平凡2挠群报未实现；未得到整点表。简单平方类分裂、常数范数方程以及亏格4平方覆盖的额外Q自同构都未打开更短求解路线，记录在04-reformulations-and-failures.md。

目前四个真实b的乘积只给c(n-1)、c为1或3。它与上面的Masser界兼容，不能构成下降；LOSS乘积给出的奇部界还被旧g⁴<3n支配，不计新覆盖。下一步应寻找保持原NC3的下降，或一个将某个真实b限制到足够小范围的结构入口。只继续固定b列表或略改巨大常数不能结束这些自由参数。
