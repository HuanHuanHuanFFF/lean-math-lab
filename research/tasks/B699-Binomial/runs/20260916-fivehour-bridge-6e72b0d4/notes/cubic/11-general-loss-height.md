# 阶段11：所有规范丢失因子的统一显式高度

2026-09-15 21:33 UTC启动，承接六条固定曲线的成功方法。预期改变：任意固定规范丢失因子b下，原来仍无界的平方行高度统一成为一个明确有限区间，不再逐b建立MW基。b仍无界；本结果不把一般i=3或全部平方行有限化。最小辨识是一般残量三次是否总为光滑亏格1，以及所引整点界是否控制全部解。

## 1. 精确结论

设原NC3成立，n=x²，4<=j<=floor(n/2)。取任意

    epsilon=+1或-1，zeta=j或n-j，
    J=x+epsilon，D=x-epsilon，
    b=J/gcd(J,zeta)，a=b*zeta/J。

则每一个这样从同一原输入定义的b都满足

    log n <= 2(960 b³)^600000。                       (GH)

因此对任意预先固定B，所有这四个规范因子中至少一个不超过B的平方NC3都满足log n<=2(960B³)^600000。也可将(GH)读成每个实际规范因子随log n增长的统一下界。这个界数值极大，但完全显式；尚未排空其有限末端，也没有控制b本身。

本阶段新增使用已发表Masser定理；这不是声称该通用整点定理为本轮原创。当前为作者纸面推导与精确符号核对，独立接受另行登记。

## 2. 必要前置与准确整数三次

采用旧NORMALIZED-NEIGHBOR源PROOFS §§1–2的已固定事实：NC3平方行使x为偶数；同一zeta满足两个弱窗口。于是b为正奇整数、gcd(a,b)=1，且0<a<bD。令

    q=6a(a-bD)(a-2bD)/(x²-2)，
    rho=(2q+3ab²)/D。

q、rho都是正整数。对x>=14，源中完整推导给rho<7b³（epsilon=+还能用6）。消去q得到原整数点(x,a)的必要方程

    F=12a(a-bD)(a-2bD)
       -(rho D-3ab²)(x²-2)=0。                       (F)

NC3到(F)只有必要性；(x,a)和rho均来自同一个原x,zeta，不是独立选择。后续辅助变换也不构造新的NC3输入。

展开(F)有10个系数项：

    12a³-36bxa²+36epsilon b a²
      +(27b²x²-48epsilon b²x+18b²)a
      -rho x³+epsilon rho x²+2rho x-2epsilon rho。

所以当x>=14时，各系数绝对值都不超过48b³。这里是最大系数界，不是系数和。

## 3. 统一排除所有有理奇异参数

设

    k=27-9rho/b³，W=6a/b-6D。

对epsilon=+/-1，(F)经过可逆有理线性变换成为

    G_k=W³-27WD²+2kD³
          +epsilon(18DW+4kD²)-9W-2kD=0，
    G_k=18F/b³。

k是有理数。rho>0直接排除k=27。其余两个待排参数如下。

### k=0，即rho=3b³

F因式分解为

    3(a-bD)[4a(a-2bD)+b²(x²-2)]。

0<a<bD使第一因子非零，故

    4(a-bD)²=b²(3D²-2epsilon D+1)。

b、D均奇，右侧为2 mod4，左侧为0 mod4，矛盾。

### k=-27，即rho=6b³

F因式分解为

    3(a-2bD)[4a(a-bD)+b²(x²-2)]。

第一因子亦非零，因此

    (2a-bD)²=b²(1-2epsilon D)
             =b²(3-2epsilon x)。

epsilon=+且x>=2时右侧为负；epsilon=-时，x偶且b奇使右侧为3 mod4，不是平方。故也排除。

于是k不为0、27、-27。另一个潜在条件k²=54对有理k不可能。

## 4. 全射影线性模型，非仅仿射光滑

齐次化G_k，令齐次变量z，D=x-epsilon z。定义

    L=9W+2kD，C=8k(729-k²)，s0=486-4k²，
    T=(CD-s0L)/9，V=C(z-epsilon D)，Z=L。

这是从[D:W:z]到[T:V:Z]的线性变换，行列式为-C²，非零。并有齐次恒等式

    V²Z-T³-A_k T Z²-B_k Z³ = -C² G_k，
    A_k=-36(8k²+243)，B_k=32k⁴+31104k²-314928。

短Weierstrass模型的判别式为

    Delta=-442368 k²(k²-729)²(k²-54)，

由上一节非零。因此原三次的整个射影闭包与光滑Weierstrass三次线性同构，绝对不可约且亏格1。这里没有仅检查仿射偏导就宣称射影光滑，也没有把原整数点换成普通Weierstrass整点。

从[x:a:z]到[D:W:z]的线性变换行列式是6/b，也非零。所有应用于曲线类型的变换均可逆；为了应用下节，整数点始终仍是原多项式F上的(x,a)。
