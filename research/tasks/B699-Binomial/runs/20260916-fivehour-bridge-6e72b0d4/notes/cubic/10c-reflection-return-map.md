# 阶段10c：反射只变辅助坐标，原指标的准确回传

geometry独立审读提醒需要把这点单列。本补遗澄清阶段07、08、10的记号；不改变任何已冻结恒等式、区间或无根证书。

先固定原输入x0>0、n=x0²、epsilon0、D0=x0-epsilon0、J0=x0+epsilon0，以及同一原j所选择的zeta0=j或n-j。记

    zeta0=a0 J0/3，0<a0<3D0。

如果残量H>27，令a1=6D0-a0、H1=54-H；否则a1=a0、H1=H。这给必要三次方程的可逆整数坐标变换，**不把a1当成新合法指标的分子**。

事实上，若强行定义zeta1=a1 J0/3，则在反射情况下

    zeta1=2D0J0-zeta0=2(n-1)-zeta0，

而不是n-zeta0，且通常不在原合法区间。因此这里没有一个保持NC3的指标下降，也没有把n,j换成别的原题输入。

若epsilon0=-1，再置X=-x0、A=-a1、D=X-1=-D0；若epsilon0=+1，置X=x0、A=a1、D=D0。由此到统一G_k曲线，再到椭圆曲线。所有这些只是原反设所必需的辅助解。

回传时保留原epsilon0与是否反射的标记：

    x0=|X|，D0=x0-epsilon0，J0=x0+epsilon0，
    a1=epsilon0 A，
    未反射时a0=a1；已反射时a0=6D0-a1；
    zeta0=a0J0/3。

原n、j和zeta0在整个论证中由原输入固定。每条模p无根结论排除的是这种辅助解的存在，因此可沿必要性回传反驳原NC3；它不需要也不声称辅助a1重新满足0<a1<3D0。统一解析估计已经明确扩大到0<A/D<6，并完整覆盖相应实分支。

研究沟通中曾出现把反射后形式误写为n-zeta的说法，已由恒等式D0J0=n-1即时纠正；冻结数学证书没有使用该错误公式。此处给出最终唯一采用的回传版本。
