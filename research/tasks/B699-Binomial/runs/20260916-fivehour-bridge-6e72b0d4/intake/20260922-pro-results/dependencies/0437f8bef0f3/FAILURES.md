# FAILURES · 第九轮

## F1. 有限二进精度与真正的整数范数不是一回事

**尝试的强命题**：在平衡Pell域中，把两条线性恢复和高层n=0的二进条件联立，就能仅靠有限精度排掉全部变动指数。

初始模16、32、64、128、256检查都留下状态。因此本轮没有继续无目的加大模数，而构造了以下全精度弱族。

对任意kappa>=3：

```text
t=1+2^(kappa+2)，按Pell定义d,y；
A=2^(kappa+1)，B=3(d-1)/A，h=2A-3；
v=Ay，W=By，Q=d+v，P=Q+hv；
nu=(hd-Q)/2，n=PQnu+2。
```

AB、Pell、两条线性式均为准确整数等式。完整赋值保证A的整除；d,y=1 mod2^(kappa+1)，故

```text
nu=-2 mod2^kappa，n=0 mod2^kappa；
vnu²-PQ²+1=0 mod2^kappa。
```

然而nu/Q<h/A<2且h>4，所以**准确整数残差** `vnu²-PQ²+1<0`，从来不为0。PROOFS P8.1给出全族证明；证书记录kappa3、4、5、6的完整整数值，验证器逐项重算。

**缺失原条件**：精确范数、真正n=c2^s、原P/Q完整素数幂与所有高层无进位。它不是NC3或反例。这里kappa不是原k=n-j。

**否定范围**：只否定该放松系统足以排空/恢复的说法，不能据此声称任何采用更多原条件的局部方法都不可能。

**实际换路**：利用同一精确范数得到y|K(h)，再用有理中心和二次整数范数界住线性侧系数。无界弱族中的A恰好光滑，最终被本轮全局证明而非有限二进测试排除。

## F2. 两侧都有粗素数，也不能反向恢复原输入

**被否的弱命题**：平衡分拆、A/B各含>=11素数、新两侧四次界，就足以恢复原整数核心。

取Pell指数t41：

```text
d=121997262292576714195153
y=70435152225016546773961
A=1025412242452=2U_21
B=356921608428=(9/2)X_20。
```

AB=3(d-1)，13|A、11|B，d<128A^4且d<32768B^4。设v=Ay,W=By，gcd(y,3(d-1))=1保证它确实是Dv=DW=y的平衡分拆。

但原平方目标S=(Q^5-d²)/v有

```text
S-Y0² = 9627743417894500009410215130710929074873342806754273353368778521966389
(Y0+1)²-S = 805177301274723249527150290820160317341076508806886552157902010844328。
```

两个间距都严格为正，所以没有整数Y，更没有整数nu,h及原n,j。这不是NC3；t41亦不是本轮新增原纤维反例。

**重试条件**：下一轮须继续用真实平方范数、原n=c2^s或原P/Q源精度，而不是只优化光滑性/两侧大小。

## F3. “给定任意S”不等于“所有S有统一界”

通用支持接口允许先给定有限素数集合S，计算C_S和Pell指数上界，随后恢复有限候选。常数随S增长，S本身未被控制。

所以不能把“每个实际整数都有有限素数支持”与上述接口拼接，宣称已经得到整个平衡域的统一有限化。不同S的上界不统一；本轮仅完成S={2,3,5,7}末端。S={2,3,5,7,13}只有界的示范日志，没有本轮全末端结论。

**重试条件**：要推广到整个平衡域，必须控制未知支持或找到不支付C_S的方法，而不是不断扩大固定素数表。

## F4. 三组系数不能混用

本轮A=v/y、B=W/y是线性侧系数。它们不是Dv、DW本身，不是B旧负根恢复式的局部a,b，也不是实际Psi系数。

光滑A不等于光滑v，因为v还含y；A/B各有大素数也不等于原P/Q增加了源素数。不能把这里的>=11素数指定为B699原共同见证。

平衡Dv=DW=y仍允许y合数、Pell指数合数。单底时额外的y素数/t素数条件可保留，但本輪不能将它们用于所有平衡纤维。
