# B699 Pro A · KSAT30 与 EDGE9

## 结论

本轮继续固定 `i=9` 与冻结 K152 的**同一个固定非零多项式 G**。不做 Lean，不修改仓库。

新增无高度几何定理：

**KSAT30.** 若 `H∈Q[N,X]` 不可约，`D=60,e=30,μ=180,z≥14`，则

`κ4+κ6+κ8 ≥ 1`。

即 q=30 的六行普通容量饱和、三处对角 κ 全零的不可约类别为空。无系数高度和有理分母限制。

把冻结 KSAT29 与新 KSAT30 放回九分量同一-G账本后：

- 九分量的 `E>0` 分支全部退出；
- `E=0` 仍有 98 个必要竖直状态；
- 因而得到新的 **EDGE9**：

`|C_G|=9 => E=0`。

于是九分量时必有 `D(G)=305`，剥去六条源竖线后的 `Gbar` 的每个非恒定不可约因子都满足 `D=2e`。此外 surviving E0 状态最低 `h=107`，故

`|C_G|=9 => h=deg_X G >=107`,

且 `V=sum v_r=305-2h<=91`。

无条件覆盖仍只是 `|C_G|<=9`，没有得到 COVER8。

## 上一轮账本实现修正

上一轮 KSAT29 后的诊断 DP 在删除“免费 q29”后，`minimum_degree` 初值仍错误保留 `29*n`。这等价于偷偷留下一个不存在的零费用 q29 候选，只会**扩大**必要放松，不会制造 COVER9 证明，也不会破坏 KSAT29 几何定理。

本轮用正确的 `+∞` 初值重跑：仅 KSAT29 时准确计数是 `111 个 E0 + 1 个 E>0` 九分量状态，而不是旧报的 `130+2`。加入 KSAT30 后进一步成为 `98+0`。

因此旧 `130+2` 应视为安全但不精确的过度放松计数；本轮结果取代它。
