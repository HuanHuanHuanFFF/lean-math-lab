# REPORT · B699 D / i=3 · 第四轮 MID128 / BSC

## 结论与范围

本轮在上一轮同一个原始 `(n,j)` 的规范最小临界两底支中，新增了两类结果：

1. **平方下方消费者：** `h=M²-1`，M 偶且 M>=128；以及 `h=M²-3`，M 偶且 M>=256。两条曲线全部由统一不等式处理，不靠有限扫描。
2. **平方间隙中部 MID128：** `h=m²+m+d`，d 为任意正或负奇数、`m>=128(|d|+1)²`。若 `d≡1 mod4,m mod8∈{4,5,6,7}`，或 `d≡3 mod4,m mod8∈{0,1,2,3}`，则同一个原 q 在 q^(3r) 层进位。

两类都证明原来的同一个素数 q>=3 同时整除 C(n,3)、C(n,j)。q=3 的原完整高次幂仍保留，Q=q^r 没有被误当作素数。

范围仍限定 `g=lambda=w=1,b=2r,xi=2mu`、采用旧出口后真实 mu=1；不接管一般两底 low/low 或三槽。历史前置按冻结作者等级采用；新交付是作者纸面证明与确定性证书，不是 Lean、外部独立审读或完整 i=3 证明。

## 主定理为什么超出上一轮

上一轮 NSB64 仅处理紧贴下方整数平方的上侧带。本轮 MID128 位于两个平方之间的中部：

```
h=m²+m+d，|d|+1<=sqrt(m/128)。
```

m 与 d 都可无界，宽度也随 m 增长；d 不是固定常数列表。在本带内旧 NSB64 门槛必然不成立，证明见 PROOFS P5.3。

例如

```
h=m²+m+1，m>=512，m mod8∈{4,5,6,7}；
h=m²+m-1，m>=512，m mod8∈{0,1,2,3}。
```

这里的参数例族不是实际 NC3 例子。它们断言：原 NC3 若进入这些参数条件，就由原 q 得到矛盾。与第3轮的参数覆盖不交已证明；与全仓库所有历史消费者并集的净差仍未审计，故不登记净实例数、比例或新增完整指标。

## 证明机制

保留同一输入的

```
Z=nu/Q，Jph=j/Q³=h-Z，Nph=n/Q³=hZ-2Z²+2/Q³，
(Z²-h)(h-2Z-1)-h=-h/Q³。
```

关键增量是将上一轮有理截断扩展为**实数中心、带符号偏移**：

```
h=t²+A-1，|A|<=B，B>=1，t>=64B²，
Z1=t+A/(2t)+1/t²+(20-A²)/(8t³)，
B0=t³-2t²+(3A/2-1)t-2A+1。
```

重新证明双侧导数和全参数残差，得到

```
|Z-t|<2B/t，
|Nph-B0-(3A²-4A-12)/(8t)|<32B/t²。
```

MID128 取 t=m+1/2、A=d+3/4。B0 的模1相位精确落在16分之一网格上；周期8的完整分类给统一严格间距

```
{j/Q³}-{n/Q³}>27/1024。
```

平方下方 A=0 与 A=-2 两支分别给正间距 `>1/(4M)`、`>3/M²-42/M³`。A=-2 的首项抵消已经用本轮新的单侧四阶截断解决，不留扫描末端。

## 失败边界与实际换路

不是所有平方下方参数都能在本层排除。事实上，若 h=M²-a 为奇数，a>=2、a!=3、M>=128(a-1)²，则同一核心下严格有反向比较 `{j/Q³}<{n/Q³}`。

这是 **LOWER-BARRIER 方法边界**，不是 NC3。证据包给出 h=16639、Q=10007 的精确实代数模型，恢复的 nu 严格介于1290864与1290865之间，因而明确缺失原整数恢复。它否定的是弱实核心中的“整个下方带必在此层进位”，不是原题。

MID128 的另八个局部模状态也在本层不进位，不能把16状态全部标为排除。详见 FAILURES.md。

## 可执行新接口

`evidence/same_input_consumer.py --h H` 可执行两条平方下方及 MID128 的廉价精确门检。`--h` 只返回参数层门检，不声称存在原数对。

`evidence/native_phase.py --h H` 不枚举 Q，而由 `Q>=isqrt(289h//9)+1` 及两个有理隔离根，统一包围所有原 Q 的相位。输出 CARRY / NO_CARRY_THIS_LAYER / INCONCLUSIVE，最后两种都不是 NC3。

`--input JSON` 模式验证同一个原 n,j 的整数恢复、合法区间、Q=q^r 和 q 的素性、活动原源及实际余数。它不把弱代数候选当原反例。q>10^6 需要完整递归 Lucas 素性证书，不以 probable-prime 测试冒充确定证明。
