# PROOFS

## 1. KSAT30

令 `q=30`，`D=60`，`e=30`，`μ=180`。因为六行普通容量均为q，首一化后每行 `H(r,X)` 的全部30个特化根（计重数）都来自真实源值。

### 1.1 根矩约束

首一式 `X^(q-1)` 系数次数≤2，所以六行根和是同一二次多项式 `S(N)` 的值；前三行决定后三行。

`X^(q-2)` 系数次数≤4，所以六行第二根矩满足五阶有限差分关系。程序用整数根多重集直接检查，不扫描系数盒。

### 1.2 κ=0 的源直线和加强亏格

反设 `κ4=κ6=κ8=0`。在对角源，普通m阶首部只能为非零倍 `t^m`，故沿对应源切线限制至少贡献 `2m`。非对角源仍贡献m。任一源直线总贡献若>60，则该线整除H，与Q不可约矛盾。

同一 κ=0 条件经一次普通吹起后，在对应无穷近点仍有普通阶m，故亏格预算除原 `sum choose(m_P,2)` 外，对三个对角点各再支付一份 `choose(m,2)`。因此残余必须满足

`sum_source choose(m_P,2) + sum_diag choose(m_diag,2) <= (q-1)^2 = 841`。

饱和Q不可约但非绝对不可约时，绝对因子X次数至多15。冻结复系数 SAT≤15 强迫低度绝对因子含源线因子，回传与Q不可约矛盾；故可以使用上述亏格预算。

完整根门计数依次为：

`5,205,228 / 1,060,031,175 / 106,403,911 / 556,684 / 556,670 / 185`。

### 1.3 完整 jet

固定六行特化后

`H=H0+WQ`, `W=prod_{r=3}^8(N-r)`, `Q in B_54`，

自由参数数 `(30-2)^2=784`。把首一常数列加入齐次系统，共785列。

非对角源加入所有 `i>=1, i+j<m` 的普通 jet；对角源在 κ=0 下加入所有 `i>=1, i+2j<2m` 的切向 jet。

发现程序对185个系统各找到785个独立行。最终验收器不复用发现器的全局单项式 jet 公式，而由局部多项式卷积重建同一选定子式。模32749、32719均得到185/185个非零785阶行列式，因此每个齐次系统满列秩，首一H不存在。KSAT30成立。

## 2. 修正后的最小次数 DP

高次泛型签名在 KSAT29+30 后是：

- `(e=29, one diagonal kappa)`；
- `(e=30, one diagonal kappa)`；
- `(e>=31, zero source fee)`。

旧实现从 `best=29*n` 开始，这在“免费q29”已经删除后不再是可实现上界。正确Bellman递推必须从 `+∞` 开始，只由实际保留签名转移。

所有被Pareto删除的原始签名均由某个保留签名同时在X次数和六行费用上逐坐标支配，因此用保留签名计算的是与完整原始安全签名同值的必要放松。

单独修正 KSAT29 得 `111 E0 + 1 positive-E`。加入 KSAT30 后得 `98 E0 + 0 positive-E`。

## 3. EDGE9

令 `E=305-2h-V`。冻结同一-G预算已经给正余量总和 `sum(D_i-2e_i)<=E`，并给无条件 COVER9。

若九个可载点因子存在且 `E>0`，显式至少取一个正余量因子A；安全收费为X次数至少3、消耗一单位E，不收任何未经证明的源费用。其它因子用真实特殊类和上述泛型安全签名。

对全部495个正E竖直状态、所有允许A数量与特殊类分配作完整整数枚举，终端Bellman查询3843次，没有任何九分量配置。因此 `E>0 => |C_G|<=8`。

所以若 `|C_G|=9`，必 `E=0`。此时

`305 = 2h+V`，

且Gbar全部非恒定不可约因子的非负余量总和为0，所以每个都满足 `D=2e`。98个E0九分量必要状态的最低h为107，故等号还推出 `h>=107` 与 `V<=91`。

这就是 EDGE9；没有推出 COVER8，因为98个E0必要状态仍存。
