## P1. 核心新桥：共享块直接约束原 n

令

```math
T=(h-1)\nu^2-hPQ.
```

由同一原范数和线性恢复，有精确整数恒等式

```math
vT=(h-1)(PQ^2-1)-hvPQ
   =PQ((h-1)Q-hv)-h+1
   =2PQ\nu-h+1
   =2n-h-3.                                                (1)
```

因此 **完整的 v 整除 2n-h-3**，不是只保留其根基。

把 `h=2n-3-vT` 代入 K(h)，得到

```math
K(h)=4(n^2-6n+4)-4(n-3)vT+v^2T^2.                         (2)
```

G 同时整除 v 和 K(h)，而 G 为奇数，故

```math
\boxed{G\mid R(n),\quad R(X)=X^2-6X+4.}                    (NORM)
```

更广地，G0 的奇数部分也整除 R(n)。对每个 `ell^b|G`，完整保留 `ell^b|R(n)`。R 的判别式为20，G的素因子不为2、5；R 在这些素数处有至多两个互异根，每个根都有唯一的 Hensel 提升。

这是原范数的代数后果，不增加一个独立数值方程。新的用途在于把它和同一个 `n=c2^s` 联立，而不是允许每个素数选择不同 n 或不同 c,s。

### P1.1 三个立即可用的平方剩余出口

由 `R(n)=(n-2)^2-2n`，任意共享素数 ell 满足：

- 原 n 为 `2^(6t)` 时，2 为模 ell 非零平方；
- 原 n 为 `3·2^s` 且 s 偶时，6 为模 ell 非零平方；
- 原 n 为 `3·2^s` 且 s 奇时，3 为模 ell 非零平方。

因为 `ell|R(n)` 不可能同时 `ell|n(n-2)`，所除量均非零。本文主轨道定理比这些二次特征更强，且不依赖纯二幂指数已缩到6的旧出口。

## P2. 一般双进制轨道定理：完整幂、同一 c、同一 s

取任意给定整数 `M>1`，其已知素数幂分解为

```math
M=\prod_{i=1}^k\ell_i^{b_i},\qquad M\mid G.
```

对每个完整模数，定义

```math
T_i=\operatorname{ord}_{\ell_i^{b_i}}(2),
\quad E_i(c)=\{e\in\{0,\ldots,T_i-1\}: R(c2^e)\equiv0\pmod{\ell_i^{b_i}}\},
\quad c\in\{1,3\}.                                       (3)
```

`E_i(c)` 是完整周期内的准确集合；每个集合至多2项。原因是2在自身阶内的幂互不相同，而 R 模奇素数幂至多两根。完整精度 b_i 不能在声称等价时降成1。

由 NORM，对某一个固定 c，原指数 s 必同时满足

```math
s\bmod T_i\in E_i(c)\quad\text{对所有i}.                  (4)
```

对每个 c，逐个选择 `e_i∈E_i(c)`，广义中国剩余定理给出准确相容条件

```math
e_i\equiv e_j\pmod{\gcd(T_i,T_j)}\quad\text{对所有i,j}.  (5)
```

若 c=1、3 的所有选择均不相容，则不存在原 n=c2^s，故本规范 NC3 支退出。对固定 M，这也恰好是模 M 必要条件与 n形状的全部相容性检查；相容并不恢复原范数、P/Q素数幂或 j，更不等价于 NC3。

### P2.1 完整性与执行成本

有限阶可由 Euler 指数 `(ell-1)ell^(b-1)` 逐素因子剥离获得，并以 `2^T=1`、各 `2^(T/r)≠1` 认证最小性。局部集合可穷举一个完整周期，或先作素数层多项式门检，再求两个根的离散对数和提升。CRT 合并必须固定同一个 c。

本包参考实现采用确定性试除素性、有限阶、完整局部周期、广义 CRT。复杂度依赖实际 T_i 和状态合并数；不声称输入位长的多项式时间。默认周期预算超过时返回 `INCONCLUSIVE_RESOURCE_LIMIT`，绝不把未计算当空集。M/G 本身仍无界，**不是一般有限化**。

### P2.2 不求离散对数的快速单素数门

在素数层令 `T=ord_ell(2)`。F_ell 的乘法群是循环群，`<2>` 恰是 T 阶子群，故

```math
R(c2^s)\equiv0\text{ 对某s成立}
\iff \gcd_{\mathbf F_\ell[X]}(R(X),X^T-c^T)\ne1.           (6)
```

仅需在 `X²=6X-4` 下二进制求幂，计算量为 O(log T) 次模乘，不扫描 T 个指数。若余式为 aX+b：a=b=0 给两根可能；a=0,b≠0 给空；a≠0 时测试 `r=-b/a` 是否 R 的根即可。该门为空会排除这个素数的**全部更高共享指数**，不要求它本身是原共同见证。

## P5. 带因子3的奇指数：不用BHV的初等证明

本节证明（经典方程的自包含重建，不声称新发现该经典结论）：

```math
d>1,\ d\equiv1\pmod3,\ y>1,\ p\text{为奇素数}
\quad\Longrightarrow\quad d^2+d+1\ne3y^p.                 (RAM-ODD)
```

置 `x=(2d+1)/3`，则x为正奇整数，目标等价于

```math
1+3x^2=4y^p.                                             (7)
```

### P5.1 必需的Eisenstein整数事实，附证明

令 `O=Z[omega]`，omega²+omega+1=0，嵌入复数，范数 `N(a+b omega)=a²-ab+b²`。
任意复数写成实系数u+v omega，把u,v分别舍入到最近整数，则误差范数至多3/4<1。这证明范数Euclidean，因而 O 是UFD。其单位恰为 `±1,±omega,±omega²`。`lambda=1-omega` 范数3，且3与lambda²相伴；模lambda有omega=1，剩余域F3。

### P5.2 p>=5：迹的完整整除

设 `alpha=(1+x sqrt(-3))/2`，则alpha∈O，alpha+bar(alpha)=1，N(alpha)=y^p。
因为alpha与bar(alpha)互素，在UFD内alpha的每个素元指数是p的倍数。因此alpha=epsilon gamma^p。
当p>=5为素数时，p与6互素，单位epsilon也有p次根，可吸收到gamma，得到alpha=gamma^p。

置 a=Tr(gamma)∈Z，N(gamma)=y。迹多项式满足

```math
V_0=2,\quad V_1=a,\quad V_m=aV_{m-1}-yV_{m-2}.
```

奇数m时a|V_m；V_p=1迫使a=±1。对a=1的多项式，有

```math
V_p(1,Y)=\sum_{k=0}^{(p-1)/2}(-1)^k
\frac{p}{p-k}\binom{p-k}{k}Y^k
=1+pY\bigl[-1+Y A_p(Y)\bigr],\quad A_p\in Z[Y].           (8)
```

系数由递推为整数；k>=1时p不整除p-k，故每个非恒定项系数均被p整除；一次项准确为-pY。这是全参数系数证明，不是有限p表。

若a=-1，则V_p(-1,y)=-V_p(1,y)=1，要求V_p(1,y)=-1；但(8)模p为1，矛盾。
若a=1，则由(8)和y>0得到 `y A_p(y)=1`，迫使y=1，矛盾。

所以p>=5全排。原计划使用Lucas原始素因子定理，最终证明不需要它；BHV不在采用依赖中。

### P5.3 p=3：附完整三次Fermat下降

由(7)，令 A=(x+1)/2、B=(x-1)/2。若x>1，则A,B,y正，且

```math
A^3-B^3=(3x^2+1)/4=y^3,
```

给出非零三次Fermat解。以下给出所需经典下降，避免借一个未核实的第三方解表。

假设存在互素非零有符号整数u,v,z，u³+v³=z³。模9说明恰一个数被3整除；重排并改变符号，让3|z，并选|z|最小。
令alpha=u+v omega。u+v被3整除，而
`alpha=(u+v)-v lambda`，3不整除v，故v_lambda(alpha)=1。
除lambda外，`u+v,alpha,bar(alpha)` 两两互素；于是
`alpha=epsilon lambda gamma³`，lambda不整除gamma。
写gamma=a+b omega，gcd(a,b)=1。定义

```math
A_0=a^3-3ab^2+b^3,\qquad B_0=3ab(a-b),
\quad gamma^3=A_0+B_0 omega.
```

A0不被3整除、B0被3整除；lambda gamma³的系数为 `(A0+B0,2B0-A0)`。
又由范数，`z³=3(u+v)N(gamma)³`，且3不整除N(gamma)，故
`v3(u+v)=3v3(z)-1>=2`。
若epsilon=±omega或±omega²，系数和分别为 `±3(A0-B0)` 或 `±3A0`，3估值恰1，矛盾。
故epsilon=±1，得到

```math
u+v=\pm9ab(a-b),\qquad
\left(z/(3N(gamma))\right)^3=\pm ab(a-b).                  (9)
```

一个有理数立方为整数则该有理数为整数。a,b,a-b两两互素且非零，因此三者分别为有符号整数立方；写a=A1³,b=B1³,a-b=C1³，再得 `B1³+C1³=A1³`。
其中被3整除的那个新数绝对值至多
`|A1 B1 C1|=|z|/(3N(gamma))<|z|`，与最小性矛盾。
下降只用于这个辅助经典方程，不声称构造了保持NC3的较小原(n,j)。

RAM-ODD得证，p=3与p>=5全部完成。

