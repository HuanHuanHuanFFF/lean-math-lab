# REPORT · B699 D / i=3 · 第十轮 BICOF2 / BLOCK-MIX

## 结论摘要

本轮继续同一个原始 `(n,j)` 的规范最小临界两底、真实 `mu=1`、平衡 `D_v=D_W=y` 必要核心。取得三项可登记进展：

1. **BICOF2：** 第九轮的 `d<32768B^4` 加强为
   
   ```math
   d<357B^2.
   ```
   
   从而
   
   ```math
   A^2<2^{12}d,
   \quad Q^2<2^{12}d^3,
   \quad n<2^{41}d^6,
   \quad s\le\lfloor(114t+349)/10\rfloor.
   ```

2. **TRI3：** 平衡域的 Pell 指数满足 `3∤t`。

3. **BLOCK-MIX：** 两个完整无界 one-block 条件域均被排除：
   
   ```math
   B\nmid9X_{(t-1)/2},
   \qquad
   B\nmid9U_{(t+1)/2}.
   ```
   
   因而剩余 B 必须同时消费相邻两个 Pell 块的完整赋值缺额。

这些结论不依赖预先固定 t、d、B、P/Q 的底素数或指数。它们没有闭合整个平衡域，更没有闭合一般 i=3。

## 为什么 B 的次数能从 4 降到 2

第九轮已有

```math
\left|h-R_0+10\sqrt3/B\right|
<(2B+11/B+12/B^2)/d.
```

关键遗漏是：乘以 `4B` 后，中心与 h 的差本身是整数

```math
J=16Ad+120y+27B-4Bh.
```

因此 `J` 必须逼近固定无理数 `40sqrt3`。该无理数到最近整数 69 的距离严格大于 `39/139`，而误差至多 `100B²/d`，立即给出 `d<357B²`。这里没有数值拟合或渐近省略。

## 两个 one-block 分支如何完备处理

由相邻 Pell 恒等式

```math
AB=3(d-1)=9U_aX_b,
\quad a=(t+1)/2,
\quad b=(t-1)/2.
```

### 假设 B|9X_b

定义 `m=9X_b/B`，则 `A=mU_a`。BICOF2 与 Pell 大小给 `m<=39`。

* `m=1`：原 Q 在模 9 下恰含一次 3，与 Q 为 `>=11` 的素数幂冲突；
* `m=2`：原 Q 准确分解为两个互素大于 1 的因子；
* `3<=m<=39`：完整首返周期非剩余证书覆盖 486 个允许状态。

所以整个条件域退出。

### 假设 B|9U_a

定义 `m=9U_a/B`，则 `A=mX_b`。新二次界给 `m<=250`。

* `m=2`：另一个准确因子分解再次否定 Q 为素数幂；
* 在其余 m 中，222 个没有任何 Pell 分支状态；27 个有状态，完整非剩余证书覆盖全部 67 个状态。最难的 `m=117` 使用素数 `11,19,181,241` 联合覆盖。

因此反向 one-block 条件域也退出。

## Frontier reduction

定义

```math
B_U=B/gcd(B,9X_b),
\qquad
B_X=B/gcd(B,9U_a).
```

本轮证明

```math
B_U|U_a,
\quad B_X|X_b,
\quad B_U>1,
\quad B_X>1.
```

所以剩余分配是真混合的。注意这不自动给两个不同奇素数：2 的完整指数也可能跨两块。

## 精确失败边界

`t=41` 存在一个满足平衡 Pell、BICOF2 和真混合分配的精确整数外壳：

