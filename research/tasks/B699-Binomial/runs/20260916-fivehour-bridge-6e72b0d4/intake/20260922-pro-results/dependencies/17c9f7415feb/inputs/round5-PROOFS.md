# PROOFS · B699 D / i=3 · 第五轮 COF40 / COMP1

## P0. 范围、符号和依赖

同一个原始合法数对 `(n,j)`，`k=n-j`，指标始终为 i=3。接续第四轮规范最小临界两底支：

```
g=lambda=w_old=1, b=2r, xi=2mu；沿冻结出口取真实 mu=1。
P=p^a,Q=q^r 为不同原奇素数的完整幂。
P=Q+hv, 2nu=h(Q-v)-Q, v nu²=PQ²-1。
n=PQnu+2, j=(P+nu)Q², k=(Q²+vnu)P。
h>=15奇，Delta=Q-v>=17，Delta≡1 mod16，Q/3<v<Q，nu=2H，H奇。
```

原题附加条件 `n=c2^s`、真实 gcd、完整源幂和全部 noCommon 条件仍须保留，显示的代数式不反推 NC3。旧入口按冻结作者级采用，未被本轮程序升级为 Lean 或外部独立审读。

本轮新符号

```
W_Delta=(Delta³-1)/v
```

**不是**旧 `w_old=P/D_p=1`，也不是 `D_cyc`，更不是旧商 `(Q³-1)/v`。在本证明计算中简写 `d=Delta, W=W_Delta`。`H0` 是新的有理数，不是旧中间源 H。

下面的 COF40 实际只要求正整数 P,Q,v,nu,h 满足上面的三条线性/范数式以及 d=Q-v>=2。它不要求 h 奇、素数幂、n 的形状、SC64/MID128 或旧类群消费者。把它返回 NC3 时才采用原分支桥。COMP1 另要求 d>=14，当前原分支已有 d>=17。

## P1. 完整补商与平方恢复：同一输入的恒等式

由 `P=Q+hv` 与范数：

```
v(nu²-hQ²)=Q³-1。
```

模 v 有 Q≡d，因此 v|(d³-1)。d>=2，故 W=(d³-1)/v 是正整数，并且

```
v=(d³-1)/W,  Q=(d³-1)/W+d。                         (1)
```

置 `Y=d nu-Q²`。原线性关系给 `Pd=Q²+2vnu`，继而

```
vnu(dnu-2Q²)=Q⁴-d>0。
```

这里 Q>d>=2，故 Y>Q²>0。不任意选择平方根的正负。

直接代数计算得到旧五次范数的同输入重建：

```
d²+vY²=Q⁵。
```

除以 v=Q-d 并作精确多项式除法，得到

```
Y²=Q⁴+dQ³+d²Q²+d³Q+d⁴+d²W。                       (2)
```

最后由 `d nu=Y+Q²` 和 `2nu=h d-Q`：

```
h=(2Y+2Q²+Qd)/d²。                                  (3)
```

原坐标还满足 `j-2=PY`。这些都是同一恢复系统的等价代数后果，没有增加新的独立数值方程。真正新增的限制将在 P2 利用 **h 是整数** 得到。

## P2. COF40：删除整个超二次补商区域

### 定理

在 P0 的正整数代数核心内，d>=2，则

```
16d < W²+640W。
```

等价地，整个 `d>=W²/16+40W` 区域没有正整数核心解。W、d、Q、v、h 和原底素数/指数均未预设上界。

### P2.1 有理格点和两个严格平方比较

记

```
H0=(16d⁴+40Wd²-32d+27W²)/(4W²)，
Y0=(8d⁶+20Wd⁴-16d³+15W²d²+20Wd-8)/(8W²)，
Y-=Y0-d²/(8W²)。
```

Y0 按 (1) 精确满足

```
H0=(2Y0+2Q²+Qd)/d²。
```

d>=2,W>=1 时，Y->0：其分子中 `8d⁶-16d³-8>0`，其余项
`20Wd⁴+(15W²-1)d²+20Wd` 均为正。

展开 (2) 得两个精确恒等式

```
64W⁴(Y0²-Y²)=d² U(d,W)，
64W⁴(Y²-Y-²)=d² L(d,W)，
```

其中

```
U=640d⁵W-40d⁴W³-256d⁴+1600d³W²-95d²W⁴-1920d²W
  +1240dW³+512d-64W⁵-480W²，

L=16d⁶-640d⁵W+40d⁴W³+40d⁴W+256d⁴-1600d³W²-32d³
  +95d²W⁴+30d²W²+1920d²W-d²-1240dW³+40dW-512d
  +64W⁵+480W²-16。
```

### P2.2 全参数正性，不是扫描

假设 `d>=W²/16+40W`。则

```
16d-W²>=640W，W²<=16d，d>40，dW>40。
```

对 U 使用以下精确分组：

```
U=[40d⁴W(16d-W²)-256d⁴-480W²]
 +[d²W²(1600d-95W²)-1920d²W]
 +[W³(1240d-64W²)+512d]。
```

三组依次不小于

```
24864 d⁴W²，
80d²W(dW-24)，
216dW³+512d，
```

因而 U>0。第一组使用 d,W>=1；第二、三组使用 W²<=16d。

对 L 分组为

```
L=[16d⁵(d-40W)-1600d³W²]
 +40dW³(d³-31)
 +[256d⁴-32d³-d²-512d-16]
 +[40d⁴W+95d²W⁴+30d²W²+1920d²W+40dW+64W⁵+480W²]。
```

第一组至少是 `d³W²(d²-1600)>0`，第二、四组为正，第三组至少是
`d³(256d-561)>0`。所以 L>0。

另附一个独立形式的代数证书：代入

```
W=1+z, d=W²/16+40W+u, u,z>=0，
```

U、L 分别有41、49个非零单项，所有有理系数严格正，常数项也正。证书生成用 SymPy，重放用标准库稀疏多项式运算重新检查整个恒等式和全部系数。该有限系数表证明的是全部 u,z>=0，不是有限参数样本。

### P2.3 相邻格点矛盾

由 Y,Y-,Y0 均正及 U,L>0：

```
Y-<Y<Y0。
```

用 (3)：

```
H0-1/(4W²)<h<H0。
```

但 `4W²H0=16d⁴+40Wd²-32d+27W²` 是整数，`4W²h` 也是整数。两者之差严格位于 (-1,0)，不可能。COF40 得证。

注意：没有以连续实根近似代替整数恢复；矛盾恰好使用整数格点。没有有限尾部或扫描末端。

## P3. COMP1：完整 W_Delta=1 条件支排除

COF40 已控制该支的大 d，但这里用更紧的格点直接处理全部 d>=14。

当 W=1：

```
H0=4d⁴+10d²-8d+27/4，
K0=H0-3/4=4d⁴+10d²-8d+6∈Z。
```

仍用 P2 的 Y0，改取 `Y--=Y0-3d²/8`。d>=2 时 Y-->0。

有

```
64(Y0²-Y²)=d² U1，
64(Y²-Y--²)=d² L1，
```

其中

```
U1=640d⁵-296d⁴+1600d³-2015d²+1752d-544
  =d⁴(640d-296)+d²(1600d-2015)+1752d-544>0，

L1=16[3d⁶-40d⁵+26d⁴-106d³+131d²-102d+31]
  =16[d⁵(3d-40)+d³(26d-106)+d(131d-102)+31]>0。
```

最后两个正性对所有 d>=14 成立。故 `Y--<Y<Y0`，即

```
K0<h<K0+3/4，
```

与 h∈Z 矛盾。当前原分支 d>=17，因此整个 W_Delta=1 退出，剩余

```
W_Delta>=2。
```

这不是旧 D_cyc=1 的重述。当 W_Delta=1，v=d³-1，实际

```
D_cyc=(d²+d+1)/gcd(d²+d+1,3)，
```

随 d 无界，特别对 d>=17 必大于1。该分拆层与旧 D_cyc=1 不相交；没有据此宣称已审计全部历史消费者并集。

## P4. 新的相对高度：Delta 指数15降至12

本节额外使用当前真实分支的 h>=15 和 `1/3<v/Q<1`，它们不参与 P2—P3。

先重建旧位置界。由原范数：

```
h+1<(nu/Q)²<h+3。
```

再用 `hd=2nu+Q` 和 h>=15：

```
hd²<9Q²。                                           (4)
```

P3 给 W>=2，于是 P2 给

```
d<W²/16+40W<=(321/16)W²。
```

因此

```
v=(d³-1)/W<(sqrt(321)/4)d^(5/2)<(9/2)d^(5/2)，
Q=v+d<5d^(5/2)        (d>=17)。                        (5)
```

由 (4)—(5)：

```
h<225d³。
```

又 P= hQ-2nu<hQ，nu=(hd-Q)/2<hd/2，故

```
n=PQnu+2<h²dQ²/2+2
 <(81/2)Q⁶/d³+2
 <(81/2)5⁶d¹²+2
 <2²⁰ d¹²。                                           (6)
```

用于比较的旧粗估计是：仅由 `v|d³-1` 有 Q<2d³，将它与 (4) 合用只得到
`n<2¹²d¹⁵`。这是本轮从旧接口重算的比较基线，不声称旧报告曾单列这条高度。对 d>=17，(6) 严格小于这条比较基线。

这些仍是相对高度；d 没有绝对上界。

## P5. 固定 W_Delta 的完备恢复：不再枚举 h

### 完备候选范围

W=1 由 P3 直接 EMPTY。固定 W>=2，P2 给准确整数上界

```
d<=floor((W²+640W-1)/16)。
```

当前分支只需 d=17,33,49,...。对每个 d：

1. 检查 W|(d³-1)，从而 v=(d³-1)/W、Q=v+d 唯一。
2. 检查 (2) 右端为整数平方 Y²，取唯一正 Y。
3. 由 nu=(Y+Q²)/d、h=(2nu+Q)/d 检查完整整数性。
4. 检查当前奇偶、h>=15、nu=2 mod4、Q/3<v<Q，然后恢复 P,n,j,k。

若整数候选存在，它仍须经过实际 gcd、`n=c2^s`、P/Q 原完整素数幂和其他完整源/高层条件。**CANDIDATE 不是 NC3，也不是反例。** 程序保存这些待检边界。

由于每个 d 至多一个恢复，检查槽数 O(W²)，每槽仅有限次大整数运算与一次整数开平方。整数位数 O(log W)，但 O(W²) 是按 W 的数值计数，不是输入位长的多项式复杂度。W 仍无界，故不是全局有限化。

### 有界补商的另一相对高度

W>=2 时 d<(321/16)W²<21W²。由 (1)、(4)：

```
Q/d=d²/W+1-1/(Wd)<442W³，
h<9(442W³)²<2²¹W⁶，

n<(81/2)d³(Q/d)⁶+2
 <(81/2)21³·442⁶ W²⁴+2
 <2⁷² W²⁴。
```

因此固定 W 的有效高度和上面的直接恢复器相互一致，恢复器不需要逐 n 枚举。

## P6. 未成功的另一原源层与换路依据

本轮起初检查同一正实核心在另一 P² 尺度的相位。令 Z=nu/Q，P/Q=h-2Z，则

```
j/P²=Q(h-Z)/(h-2Z)²，
n/P²=QZ/(h-2Z)+2/[Q²(h-2Z)²]。
```

固定 h=16639，在原正实根满足 `f_h(Z)=-h/Q³` 时，Q=10007 给严格反向比较，Q=10037 给严格正向比较。证书均用128步有理隔离和分式端点比较；没有使用浮点作判定。

这些模型中的 nu 分别严格处于

```
1290864<nu<1290865，1294734<nu<1294735。
```

所以缺少整数恢复、P 的原素数幂身份、真实 n=c2^s 等条件。它们只否定“固定 h 的弱实核心无条件强迫这个 P² 比较方向”，不否定完整 NC3 中可能存在更强的 p 层定理。新证明改为 P1—P3 的整数格点，正是利用这里缺失的算术信息。
