# REVIEW · 自查账本

## 量词检查

| 声明 | 范围 | 检查 |
|---|---|---|
| `d<357B²` | 仅平衡最小支 | 使用冻结 IRR；未写成一般 NC3 |
| `3∤t` | 平衡域 | 使用原平方范数模 y；y 与 5 的互素性在反设下明确 |
| XBLOCK | 平衡域且 B 整除 `9X_b` | m<=39 为证明界；全部分支处理 |
| UBLOCK | 平衡域且 B 整除 `9U_a` | m<=250 为证明界；全部分支处理 |
| BLOCK-MIX | 上述平衡剩余 | 只声称完整赋值缺额，不声称不同奇素数 |

## 同一输入与原见证

所有公式均沿同一个原 `(n,j)`；没有构造较小 `(n',j')`。证书素数只用于证明平方目标为二次非剩余，不登记为原题共同见证。

## 有限证书完整性

* α 的四步状态在有限环中可逆；从单位到第一次返回是完整周期。
* TRI3 的 k 模 3 条件与每个有限环周期取最小公倍数。
* 模 `mp` 而非模 p 读取被 m 除后的商。
* X 侧 486、U 侧 67 个状态全部有明确非剩余见证。
* U 侧 m=117 的四素数覆盖已逐状态重算。

## 可能误用

* 不能把 553 写成原题候选数。
* 不能把 mixed weak model 写成 NC3。
* 不能将 BICOF2 用到非平衡域。
* 不能从 BLOCK-MIX 推出两个不同粗奇素数。
* Python 重放不等于 Lean。

## 结论

本轮可登记为两个无界 one-block 条件域的删除和 B 次数下降；不能登记整个平衡域或 i=3 闭合。
