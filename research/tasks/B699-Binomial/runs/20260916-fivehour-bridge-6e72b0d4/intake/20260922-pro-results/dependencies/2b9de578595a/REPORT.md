# REPORT · B699 D / i=3 · 第十一轮 TWO-END / BRIDGE256

## 1. 本轮结论

本轮继续处理同一个原始合法数对 `(n,j)` 在 `NC3` 下，经冻结桥进入的**规范最小临界两底、真实 `mu=1`、平衡 `D_v=D_W=y` 必要核心**。没有扩大到一般两底、真三槽、多槽或整个 `i=3`。

第十轮已将平衡分配压入 `BLOCK-MIX`：

```math
B_U=B/gcd(B,9X)>1,
\qquad
B_X=B/gcd(B,9U)>1,
```

其中 Pell 指数写成 `t=8q+1`，相邻块为

```math
U=U_{4q+1},
\qquad
X=X_{4q}.
```

本轮针对 `B_X` 没有奇素因子的**纯二跨块**取得以下严格进展。

### TWO-END：纯二跨块只剩两个二进端点

证明

```math
v_2(U)=1,
\qquad
v_2(X)=v_2(q)+3=:rho,
\qquad
\gcd(U,X)=2.
```

若 `B_X` 是非平凡二幂，则平方范数模 `8` 强制：

```math
\boxed{v_2(B)=2\quad\text{或}\quad v_2(A)=1.}
```

也就是：

* 低二端点
  ```math
  A=mX/2,
  \qquad B=18U/m;
  ```
* 高二端点
  ```math
  A=mX/2^{rho-1},
  \qquad B=2^{rho-1}9U/m.
  ```

这里 `m` 为正奇数，且没有预先界住 Pell 指数或 `rho`。

### LOW2：低二端点完整退出

利用第十轮的整数逼近 `J` 和其模 `16` 格点，先取得统一乘子界

```math
\boxed{m\le73.}
```

随后：

* 29 个奇乘子在完整有限环首返周期内没有合法分支状态；
* `m=9` 由统一纸面不等式排除全部无界 Pell 状态；
* 其余 7 个乘子共 38 个完整首返状态，全部被确定性二次非剩余证书排除。

因此

```math
\boxed{\text{低二端点全部排除}.}
```

### H3--H7：高二端点前五个二进层完整退出

对高端点，`rho=3` 时得到 `m<=73`；`rho>=4` 时得到

```math
m<27\,2^{rho-1}.
```

固定 `rho=3,4,5,6,7`，把准确层条件

```math
v_2(q)=rho-3,
```

与 `q mod 3`、乘子整除及 Pell 首返周期同时放进有限环。完整结果如下：

| `rho` | 奇乘子总数 | 无分支乘子 | 有分支乘子 | 被非剩余消费的完整状态 |
|---:|---:|---:|---:|---:|
| 3 | 37 | 29 | 8 | 17 |
| 4 | 108 | 93 | 15 | 35 |
| 5 | 216 | 191 | 25 | 42 |
| 6 | 432 | 388 | 44 | 69 |
| 7 | 864 | 786 | 78 | 136 |
| **合计** | **1657** | **1487** | **170** | **299** |

全部 299 个完整首返状态均有可重放的非剩余见证。最复杂的 `(rho,m)=(7,373)` 有 10 个全局状态，由辅助素数 `1489,11,79` 分别覆盖 `5,3,2` 个。

因此

```math
\boxed{rho=3,4,5,6,7\text{ 全部排除}.}
```

### BRIDGE256：纯二桥的新准确前沿

若纯二跨块仍来自原输入，则必须

```math
rho\ge8,
\qquad
v_2(q)=rho-3\ge5,
\qquad
32\mid q,
```

从而

```math
\boxed{t=8q+1\equiv1\pmod{256}.}
```

剩余纯二桥唯一可能具有

```math
U=2u,
\quad X=2^{rho}x,
\quad rho\ge8,
\quad m\mid9u,
\quad m\text{ 奇},
```

```math
\boxed{
A=2mx,
\qquad
B=2^{rho}\frac{9u}{m},
\qquad
m<27\,2^{rho-1}.}
```

因此，第十轮的整个平衡 `BLOCK-MIX` 现在准确拆成：

1. **odd--odd**：`B_U` 与 `B_X` 都含非平凡奇部分；
2. **高二桥**：上式成立且 `t=1 mod 256`。

低二桥以及高二桥 `rho=3,...,7` 不再属于前沿。

## 2. Frontier reduction 的准确口径

本轮删除的是纯二跨块中的一个完整端点，以及另一端点的五个无界二进层。它不是固定 Pell 指数、固定 `n` 或固定原素数的扫描。

有限证书中的 `38+299` 是由全参数证明导出的**有限环完整首返状态数**，不是原题剩余实例数。辅助见证素数仅用于否定平方必要条件，不登记为原题共同见证。

没有完成：

* 整个平衡域；
* odd--odd 真混合域；
* `rho>=8` 的高二桥；
* 非平衡多底；
* 一般两底 low/low、真三槽、多槽及其他恢复三次支；
* `i=3` 或原题全局闭合。

R7 不变；没有一般绝对高度、全局有效有限化、保持 `NC3` 的严格下降、Lean 或外部独立审读。

## 3. 精确弱模型与当前障碍

取

```text
q=32,
 t=257,
 rho=8,
 m=1.
```

它满足平衡 Pell、`AB=3(d-1)`、BICOF2、BLOCK-MIX、`v2(A)=1`、`v2(B)=8`、`B_X=128` 以及 `t=1 mod256`；但平方范数严格落在相邻整数平方之间，因此没有整数 `Y,nu,h,n,j`。

它不是 `NC3` 或原题反例，只说明：BRIDGE256 的支持、赋值和大小条件本身仍不足以恢复原输入。下一轮必须接回真实平方范数、原 `Q/P` 的完整素数幂性质或 `n=c2^s`，不能只机械扩展固定 `rho` 的状态表。
