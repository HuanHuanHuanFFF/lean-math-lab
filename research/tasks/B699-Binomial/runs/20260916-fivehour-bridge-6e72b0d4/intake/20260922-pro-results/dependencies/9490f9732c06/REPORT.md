# REPORT · B699 D / i=3 · 第三轮：NSB64 原源三次层进位

日期：2026-09-21。会话标识 D / i=3，不是历史主攻 i6 的 Pro D。

## 本轮结论

在上一轮同一原始 NC3 的规范最小临界两底支中，令

```
m = floor(sqrt(h)),
A = h-m^2+1.
```

本轮给出一个全参数充分排除：

**NSB64：`m>=64 A^2` 时，原来的 q 在 `q^(3r)=Q^3` 层发生进位，
从而同一 q>=3 同除 C(n,3) 与 C(n,j)。**

因此剩余最小支必须满足

**`floor(sqrt(h))<64(h-floor(sqrt(h))^2+1)^2`。**

A 是本轮局部“平方距离加一”参数，不与旧数字块 A、A_*、会话名 A 混用。
这不是新增几个固定 h 的表，也不是扫描无反例：它删除平方上方一个随平方根增长、
带无界参数的区间族。证明没有有限末端待补。

## 精确范围和前置等级

保留 `g=lambda=w=1,b=2r,xi=2mu`，采用既有真实 mu=3 出口后取 mu=1。
沿用同一输入的完整恢复

```
P=Q+hv, 2nu=h(Q-v)-Q, vnu^2=PQ^2-1,
n=PQnu+2, j=(P+nu)Q^2, k=(Q^2+vnu)P.
```

采用上一轮已明列的剩余门槛：h 奇且 h>=15、Q>=11、Delta=Q-v>=17、
`1/3<v/Q<1`。Q=q^r 是原第二窗口中的完整幂；Q>=11 不等于底素数 q>=11。
见证阈值仍是 q>=3，不删去 p=i=3。

冻结旧链按 Overview 和前两轮的作者纸面等级采用。本轮没有在线重建仓库依赖，
没有把旧 Thue/类群/小比值退出升级为独立核验。新 NSB64 的不等式证明与原输入
回传则完整写在本包 PROOFS 中。

## 关键新机制

先从同一范数与比例走廊得到

`h Delta^2<9Q^2`，于是 **`h<Q^2<Q^3`**。

因此这里不再需要额外假定旧特殊族中的 Q^3>h。另有相对位置 `n<P^3`，
但这两项都不是绝对高度。

令本轮局部实坐标 z=nu/Q（不同于旧 i3 整数残量 z），直接保留原坐标：

```
j/Q^3=h-z,
n/Q^3=h z-2z^2+2/Q^3,
(z^2-h)(h-2z-1)-h=-h/Q^3.
```

在 NSB64 域中，证明 m<z<m+1，因而原 j 的小数部分大于 3/4。使用精确有理
截断 z1 和逐单项全参数误差界，证明

```
|n/Q^3 - B0 - (3A^2-4A-12)/(8m)| <32A/m^2,
B0=m^3-2m^2+(3A/2-1)m-2A+1.
```

m 奇时 B0 是半整数，n 的小数部分落在 (1/4,3/4)；m 偶且 A>=4 时落在
(0,1/4)。剩余 m 偶、A=2 出现首项抵消，本轮另保留一阶修正，直接证明小数差
大于 `3/m^2-23/m^3>0`。三个分支覆盖全部奇 h。

最终得到 `j mod Q^3>n mod Q^3`。这使用的是原来的 q^(3r) 层，不是将合数 Q
当作素数，也不是把 D_cyc 中的素数冒充原窗口源。原 q 的二项式估值至少为 1，
原题回传完成于同一 n,j。

## 删除的域与数量口径

本轮在明确采用的最小支必要系统中删除 NSB64 条件域，属于一个无界条件族排除。
例如 h=m^2+2 的所有奇 m>=577，以及 h=m^2+1 的所有偶 m>=256，都在该域中。
这些是全参数定理的例示，不是实际 NC3 点或额外扫描结果。

更一般地，A、m 可以同时增长。取 A=8u+3、m=64A^2+1，则 h=m^2+A-1
满足新门槛且 h≡3 mod8，因此新机制不只作用于纯二幂支已被模8条件删掉的类。
旧 `odd-square+4` 条件族的重叠不另计功。

## 尝试失败后怎样换路

首攻 D_cyc 的源回传。发现“D_cyc 的素数必是原窗口源”不能由分拆直接推出。
精确整数外壳取

```
Delta=17, v=4912, Q=4929, D_cyc=307,
h=377005, P=1851853489, nu=3202078,
n=29227882250289849920.
```

307 是素数且 ord_307(Delta)=3，保留分圆酉分拆、奇偶与已有相对 h 界；但
`n≡6 mod307`、`C(n,3)≡20 mod307`，所以 307 并非原源。这个外壳不满足
完整范数：残差 `vnu^2-PQ^2+1=5373370439580560`，也未满足 n=c2^s。
它只否定弱分拆层的自动源升级，不是否定未来使用完整原条件的回传可能性。

随后改用已经被认证为原源的 q，建立上述 NSB64。更强的“所有 h 都在 Q^3 层
进位”没有被证明；h=21,Q=101 的精确实代数弱模型反驳了相应的连续放松命题。
该模型不具备整数恢复、完整素数幂分拆和 alpha 形状，不能作为原题反例。
