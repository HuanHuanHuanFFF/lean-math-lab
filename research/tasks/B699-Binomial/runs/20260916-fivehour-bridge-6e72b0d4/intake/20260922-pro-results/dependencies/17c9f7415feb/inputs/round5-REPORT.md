# REPORT · B699 D / i=3 · 第五轮 COF40 / COMP1

## 本轮结论

本轮从第四轮原源相位障碍出发，改用同一个原始 `(n,j)` 的**整数恢复格点**。没有增加一个固定 h 扫描表，而是完成以下全参数证明。

仍限定规范最小临界两底支 `g=lambda=w_old=1,b=2r,xi=2mu`，沿旧出口取真实 mu=1。令

```
Delta=Q-v，W_Delta=(Delta³-1)/v。
```

W_Delta 是新引入的正整数完整补商；它不是旧 w_old=1、D_cyc 或 `(Q³-1)/v`。

### 新增无界条件支排除

**COMP1：**整个 `W_Delta=1` 条件支退出。证明对所有 Delta>=14 成立；原分支已有 Delta>=17，因此没有待补的有限末端。

**COF40：**整个

```
16Delta >= W_Delta²+640W_Delta
```

条件域退出。Delta、W_Delta、原底素数及完整指数都可以无界；不是固定参数消费者列表。

所以真实剩余必须满足

```
W_Delta>=2，16Delta<W_Delta²+640W_Delta。
```

主证明甚至适用于更宽的正整数代数核心，不需要 n 的纯二幂形状、素数幂身份或前两轮相位消费者。返回 NC3 的桥仍使用冻结最小支必要系统。

### 新相对高度与恢复器

接回已有 `hDelta²<9Q²` 和 `Q/3<v<Q`：

```
Q<5Delta^(5/2)，h<225Delta³，n<2²⁰Delta¹²。
```

仅用旧整除 `v|Delta³-1` 可重算出较粗的 `n<2¹²Delta¹⁵`；新界在 Delta>=17 更强。这是相对高度，不是 Delta 的绝对界。

固定 W_Delta 时还得到

```
h<2²¹W_Delta⁶，n<2⁷²W_Delta²⁴。
```

新的完备恢复器只枚举

```
Delta=17,33,...,floor((W_Delta²+640W_Delta-1)/16)，
```

每个 Delta 唯一确定 v,Q，随后一次整数开平方和两次整除检查恢复 nu,h。不需要再枚举 h、Q、n 或 j。槽数 O(W_Delta²)，不是输入位长的多项式复杂度。W_Delta 本身仍无界，故不是全局有限化。

## 核心机制

由同一范数恢复得到正整数 `Y=Delta*nu-Q²` 及

```
Y²=Q⁴+Delta Q³+Delta²Q²+Delta³Q+Delta⁴+Delta²W_Delta，
h=(2Y+2Q²+QDelta)/Delta²。
```

在 COF40 区域，构造有理数 H0∈(1/(4W_Delta²))Z，严格证明

```
H0-1/(4W_Delta²)<h<H0。
```

h 为整数，矛盾。全部无限尾部由两个显式多项式的全参数正性控制；除了附带的完整正系数证书，PROOFS 还给出短的逐组正性论证。

COMP1 使用更紧的 `K0<h<K0+3/4`，K0 为整数，直接处理全部 Delta>=14。

## 与旧覆盖的关系

旧第2轮排的是 D_cyc=1。本轮 W_Delta=1 时

```
D_cyc=(Delta²+Delta+1)/gcd(Delta²+Delta+1,3)>1，
```

而且随 Delta 无界。因此两个“单位”条件不是同一个分拆支。相对这两个分拆门的差异已明确；**相对全仓库历史消费者并集的净差没有审计**，不登记为全局覆盖净增百分比。

## 首攻失败与换路

固定 h=16639 的正实核心中，Q=10007、10037 在 P² 尺度分别给严格反向、正向比较。两个例子都缺少整数 nu，因而不是 NC3；它们说明仅换成另一源的同尺度实相位，仍有未受控的 Q 依赖。本轮随后转向上面的整数格点，成功利用了实弱模型缺失的 h 整数性。

另一失败边界：新补商不等式本身不界住 W_Delta。取任意 W>=2、Delta=16W+1，即有一族满足全部显示补商定义、奇偶和新不等式的无界整数外壳；尚未给它恢复原范数、P、nu、n,j。详细量词、模型和重试条件见 FAILURES。
