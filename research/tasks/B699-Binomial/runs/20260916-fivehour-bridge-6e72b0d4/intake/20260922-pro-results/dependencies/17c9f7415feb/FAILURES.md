# FAILURES · 第六轮 DUAL-CYC1 / SPLIT5

## F1. 精确错误命题：W|3(d-1)可无损替换成W|(d-1)

反模型：

```text
d=49，W=72，v=(d³-1)/W=1634，Q=1683。
```

它满足d>=17、d≡1 mod16、v正偶、Q/3<v<Q及vW=d³-1；W整除3(d-1)=144，却不整除d-1=48。D_v=817>1，旧W=1与COF40也都不触发。

缺失的原题条件：原平方恢复不是整数平方：

```text
Y²=8263585552513，floor(Y)=2874645；
Y²-floor(Y)²=1676488>0，(floor(Y)+1)²-Y²=4072803>0。
```

因此不是原NC3，更不是原题反例。该模型只否定删掉一层3的参数化。本轮保留B支，利用9|W和3∤t建立独立无界尾部证明，再完成有限末端；此失败已修复，不应原样重试。

## F2. 精确错误命题：两侧分别酉加三次分圆分拆，必有gcd(D_v,D_W)=1

弱整数模型：

```text
d=7649，v=145312，W=3079729，Q=152961；
D_v=19，D_W=3079729，gcd(D_v,D_W)=19；
h=21，nu=3834，P=3204513。
```

它满足：

```text
vW=d³-1，Q=d+v，d≡1 mod16，v偶，Q/3<v<Q；
D_v、D_W分别是v、W的酉因子，Phi3(d)=D_vD_W；
P=Q+hv，2nu=hd-Q，h>=15奇，nu≡2 mod4；
gcd(v,W)=19整除h²-6h-11=304；9²≡5 mod19。
```

但原范数残差为

```text
vnu²-PQ²+1=-74974071011040800≠0。
```

从真正范数商计算的Y²也非平方：

```text
floor(Y)=24004963246；
Y²-floor(Y)²=26057970034；(floor(Y)+1)²-Y²=21951956459。
```

因此这只是满足显示的分拆、共享限制和线性恢复的弱模型。它不满足完整原范数，不能恢复合法原(n,j)必要链，也没有P、Q实际源素数幂、n=c2^s或全部NC条件的认证。**本轮没有证明“完整整数核心中的两侧互素”是假的；证明的是新弱分拆信息不足以推出它。**

重试条件：要排除共享19/31等使5成为平方的素数，必须进一步使用原范数的更高精度、真实n形状或实际素数幂。仅引用两侧分别酉不够。本轮换成可证明的G0|h²-6h-11和SPLIT5，没有把互素当作前提。

## F3. 新双侧非平凡与共享限制不是全局有限化

仍可以令

```text
d=7649+17328s，s>=0；v=19(d-1)，W=(d²+d+1)/19，Q=d+v，h=21；
nu=(d+19)/2，P=419d-418。
```

该族保持d≡1 mod16、d≡2 mod3及19²|Phi3(d)，故v、W为正整数、D_v=19、gcd(D_v,D_W)=19，且共享19符合SPLIT5；两条线性恢复和nu≡2 mod4也保持。参数d、W、D_W无界。

其原范数残差准确为

```math
-\frac{d-1}{4}(670381d^2-1272882d+596737)<0\qquad(d\ge2).
```

括号在d=2+x时变成670381x²+1408642x+732497，所有系数为正。它也没有通过全体旧相对高度、原n形状和NC条件。故它只说明**本轮新显示的分拆与共享约束本身**不界住参数，不能拿来否定完整系统的可有限化性。不能把此族称为NC3或反例。

重试要求：继续联立未满足的平方/范数条件，而非删除它们后宣称参数可以自由增长。
