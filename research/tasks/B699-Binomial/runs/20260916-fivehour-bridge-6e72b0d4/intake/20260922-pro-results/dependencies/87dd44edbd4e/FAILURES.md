# FAILURES — 精确失败边界、修正与未完成路线

## F1. 上一轮建议的 R_* 上界没有完成

尝试命题：在当前全部真实必要前提下，原 q³ 层无进位能否推出 R_*<2D+10？

本轮仅完成了精确相位式。令 y=ν/Q，x=P/Q，ε_Q=2/Q³，且 y不是整数，则

    carry_(Q³)=1+floor(xy+ε_Q)−floor(xy+ε_Q+{y})，

因此

    carry_(Q³)=1 ⇔ {xy+ε_Q}+{y}<1。

在全真前提下没有得到所求 R_* 上界，也没有找到满足这些全真前提而反驳它的精确点。
所以本轮状态是 **未证成**，不是“已证明该命题为假”，更不是一般方法不可能。

值得重试的实质条件：把 ν modQ 与 Pν modQ² 的实际整数余数联立；
或由完整 P=p^a、v|(Q³−1)、α=c2^s 迫使某个相位落入确定区间。
只用连续大小的 R_*/D 与根的正性仍不够支持这个上界。

## F2. 标量 core 本身并不自动给 q³ carry

被否证的过强命题：只要最小支的数值恒等式、P≥4Q 和 P,Q 为素数成立，就有 Q³ 层进位。

精确整数点：

    P=89，Q=3，ν=20，h=43，v=2，
    n=5342，σ=j=981，τ=k=4361。

它满足

    P=Q+hv，hQ=P+2ν，vν²=PQ²−1，
    Pν²=(P+ν)²Q−h，n=PQν+2，σ=(P+ν)Q²，P≥4Q。

但 Q³=27 层：

    floor(5342/27)−floor(981/27)−floor(4361/27)
    =197−36−161=0。

这不是 NC3，更不是当前未解最小支的整数点：

- 4∤n，真实 α=5342 不是 c2^s；
- 真实 μ=3，Q=3 只是 n−2 中被剥离的一次3，不是 C(n,3) 的源；
- n>Q⁴，不在当前下一位宽；
- 真实 H=10，而标量 ν=20 不等于 2μH=60；
- h 不在本轮 NS64 条件内。

直接计算得到

    gcd(C(5342,3),C(5342,981))=2²·5·7²·2671。

原题有共同奇素数。代码 `src/weak_model.py` 直接计算两个原二项式后取 gcd。
它的 D=1、R_*=0，也不属于上一轮 D≥3 的有限实验范围；不与该实验输出冲突。

这个点只反驳上面明确删掉源资格/位宽/α的过强命题，不能用于反驳 F1 的全真命题。
重试时必须加入实际 source 与原始恢复，不能只要求两个底数看起来是素数。

## F3. A=2 的正余量模板错误，但本轮已修正

## F4. 未越过 NS64 范围的原因与重试条件

本轮统一正系数证书只覆盖 d≥64(κ+1)² 且 κ≥0、h奇。
不能把它扩成所有奇 h，不能扩到平方左侧，不能删除 Q³>h 或 P≥4Q。

κ更大时，τ的余量可能跨越更多整数；仅知道根靠近平方不足以决定进位。
有价值的新条件是实际 ν modQ、Pν modQ²，或两源高层联合进位；
不是继续优化64这一常数，也不是依次扫描固定 κ。
