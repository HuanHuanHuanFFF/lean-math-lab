## 2. 双侧完整分圆块

定义

```math
D_v=\frac v{\gcd(v,3(\Delta-1))},\quad
D_W=\frac{W_\Delta}{\gcd(W_\Delta,3(\Delta-1))},\quad
\sigma_3=3\text{ 当 }\Delta\equiv1\pmod3,\text{ 否则 }1.
```

```math
\boxed{\Delta^2+\Delta+1=\sigma_3D_vD_W,\qquad D_v,D_W\ge7.}
```

每个因子分别是v、W_Delta的酉因子，保留其完整素数幂；每个底素数都满足ord_ell(Delta)=3。但两侧本身**不保证互素**。

```math

\quad\min(v_2(v),v_2(W_\Delta))\le2,
\quad\min(v_5(v),v_5(W_\Delta))\le1.
```

```math
(h-3)^2\equiv20\pmod\ell,
```

所以5是模ell的非零平方，且完整ell^min(v_ell(v),v_ell(W))整除h²-6h-11。

## 3. 无界支持模板的直接消费者

若 `(Delta²+Delta+1)/sigma3=ell^a` 为一个素数幂，则新的两侧非平凡性迫使a>=2，并且5必须是模ell的平方。因此排除：
