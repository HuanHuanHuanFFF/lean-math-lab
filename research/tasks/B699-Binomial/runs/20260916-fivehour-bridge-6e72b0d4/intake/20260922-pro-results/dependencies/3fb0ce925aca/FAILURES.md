# FAILURES — 第九轮

## 1. p-adic / Thue-Mahler 路线无需继续

开局曾考虑把 F5(y)=3*2^S 当作 2-adic 逼近或 Thue–Mahler 方程。该路线理论上可给有限性，但成本高，且可能只给非有效或大型有效界。

**停止原因：** 残指数 S≡4 (mod5) 直接把右侧化成 48 乘整数五次幂，而 F5(y) 有严格相邻五次幂夹逼。更强的初等矛盾已经完整排空残域。

**重试条件：** 只有以后出现类似残方程但没有“指数模次数 + 相邻幂夹逼”结构时，才值得重新使用 p-adic/Thue–Mahler。

## 2. 固定模数继续扩张仍不值得

第八轮镜像 F5(-5/4)=3/64 已说明任意固定奇模数及固定2进精度可相容。本轮没有推翻该局部外壳；而是用阿基米德整数夹逼绕开它。

因此不能从本轮成功反向声称“再多做几个模数也会成功”。

## 3. 不可泛化到任意五次多项式值方程

夹逼只针对第八轮分类得到的固定 F5 及其残指数类。不能声称一般五次多项式 P(y)=c*2^S 都有相同夹逼。

值得复用的模板是：若最终固定多项式 P 满足

    a y^d < P(y) < a(y+1)^d

且指数条件使 RHS=a X^d，则残域立即为空。
