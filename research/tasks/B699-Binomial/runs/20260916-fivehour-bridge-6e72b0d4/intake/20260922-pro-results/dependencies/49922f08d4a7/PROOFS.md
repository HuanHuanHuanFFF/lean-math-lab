# PROOFS — B / i3 第十一轮：七次 3+4 平衡分配完整闭合

2026-09-21。数学执行者 Pro E。作者纸面证明和同作者两个精确检查器；无 Lean、无仓库写入、无外部独立审稿。

## 0. 原题、作用域与主定理

固定同一个自然数输入 `n,j`，`4≤j≤floor(n/2)`，`k=n−j`。Common3 表示存在同一个奇素数 `q≥3` 同除 `C(n,3),C(n,j)`；NC3 是其否定。全文不改变原 `(n,j)`，`σ` 只表示原 `j` 或 `k`。

唯一没有在本轮重验完整旧链的深前置是

```text
NC3 ⇒ 4 | n.
```

所以直接假设 `4|n` 的版本由本文完整证明；偶数但不被4整除的行沿用冻结出口，不重复登记为新覆盖。

### 定理 S7（SEPTIC-ALL）

令 `f∈Z[X]` 系数非负，`f(0)=2`，`deg f=7`，`H=f(1)`。令 `T=p^e` 为奇素数幂，且

```text
T ≥ [2(H+2)]^18,
```

`n=f(T)` 为偶数。则该原行的全部合法 `j` 满足 Common3。

本文的 `f,J,U,V,W,R` 均为数字多项式；它们不是实际内容三次 `Ψ`、恢复三次 `Pρ`、最小支的 `P,Q`，也不是原端点源块。

## 1. 采用的大进制接口与唯一 3+4 分配

采用第七至第十轮已经展开的同输入大进制提升。假想同一输入满足 NC3，则原工作素数 `p` 的全部进位层均为零，故

```text
j=J(T),
```

其中 `J` 和 `f−J` 的数字系数非负。完整第一、第二窗口在声明门槛下提升为必要多项式整除

```text
f−1 | J(J−1),
f−2 | J(J−1)(J−2)          in Q[X].
```

这只是必要条件，不能反推 NC3。

第一源的不可约因子连同完整重数分到两个互补块。排除整个 `f−1` 进入一个槽后，可取互素整数多项式

```text
f−1=UV,  U(0)=V(0)=1,
σ=VW,   U | VW−1,
```

并有

```text
W(W−U)(W−2U)=(UV−1)R,      (1.1)
gcd(U,W)=gcd(U,R)=1.        (1.2)
```

微分必要式为

```text
U | W R' − R(3W'−2U').      (DIFF)
```

上一轮以前已经关闭 `≥2/3` 等号；故七次两个块次数必须严格位于 `(7/3,14/3)`，只能是 `3+4`。若三次块最初进入 `σ` 而非 `σ−1`，换用原对侧端点 `n−σ` 会交换两个块，所以总可选择

```text
deg U=3, deg V=4, deg W≤3.
```

`U,V` 在正实轴上均为正：它们常数为1，而乘积 `f−1` 在非负实轴严格为正，因此没有正实根。故其首项系数为正。

## 2. 端点的低次数边界全部不可能

令 `t=lc(W)/lc(U)`；若次数不足，把对应首项比记为0。原两个数字端点 `σ=VW` 与 `f−σ=V(U−W)+1` 的首项非负，因此

```text
0≤t≤1.
```

### 2.1 `t=0`

令 `s=deg W≤2`。若 `s=0`，(1.1) 左边次数为6，小于右边除数 `UV−1` 的次数7，矛盾。

若 `s=1`，则 `R` 为常数。DIFF 强迫

```text
3W'−2U'=0,
```

但左边的二次首项为 `−6 lc(U)`，不可能。

若 `s=2`，则 `R=a(X−r)` 为一次。设该根进入槽 `k∈{0,1,2}`，即 `W(r)=kU(r)`。DIFF 的常数商在根处等于 `ka`，故

```text
W−(X−r)(3W'−2U')=kU.
```

比较三次首项得到 `k=6`，矛盾。

### 2.2 `t=1`

此时 `D=W−U` 的次数至多2。若 `deg D=0`，(1.1) 同样次数不足；若 `deg D=1`，常数 `R` 会强迫 `3W'−2U'=U'+3D'=0`，二次首项非零；若 `deg D=2`，对一次 `R` 重复上一根值论证，比较三次首项得到 `k=−2`，仍不在 `{0,1,2}`。

所以必须

```text
0<t<1,  deg W=3,
```

三个槽多项式 `W,W−U,W−2U` 都恰为三次。由(1.1)

```text
deg R=9−7=2.               (2.1)
```

## 3. 一个新的二阶必要同余

原逆关系写成

```text
VW=1+UQ.
```

由(1.1)模 `U` 有 `R≡−W^3 (mod U)`。再将(1.1)模 `U^2` 展开：

```text
W^3−3UW^2 ≡ −R+UVR        (mod U^2).
```

而 `VR≡−VW^3≡−W^2 (mod U)`，故

```text
W^3 + R − 2UW^2 ≡0         (mod U^2).      (U2)
```

即

```text
U^2 | W^3+R−2UW^2.
```

这是原第一逆关系与第二身份共同给出的必要条件；没有将它反向当充分条件，也没有约去 `U'`。

二次 `R` 的每个不可约因子连同完整重数只能进入一个槽，因为三个槽两两互素。于是只有两类：

1. 整个二次 `R` 进入同一槽；
2. `R` 分成两个不同的有理线性因子，进入两个不同槽。

## 4. 整个二次商进入一个槽

设整个 `R` 进入槽 `k∈{0,1,2}`。写

```text
R=ρA,
W−kU=AC,
```

其中 `A` 为二次、`C` 为一次。将 `C` 的有理根移到0，规范 `A` 为首一，并将 `U,W` 同比例缩放使 `U` 首一。可写

```text
A=X^2+aX+b,
C=cX.
```

DIFF 的商次数至多1；模 `A` 后它必须等于 `kρA'`。代回得到

```text
(3k−2)U' + 2A'C + 3AC' =0.
```

比较首项后

```text
c=3(2−3k)/7,
U=X^3+(15a/14)X^2+(9b/7)X+d.              (4.1)
```

现在使用(U2)。将

```text
W^3+ρA−2UW^2
```

除以 `U^2`，六个余式系数必须全为零。精确 Gröbner 消元（包内两个检查器分别用 lex 与 grevlex 复核）给出共同必要因子

```text
a^6(3a^2−14b)=0.                           (4.2)
```

若 `a=0`，同一基底进一步给 `b=d=0`，于是 `A=X^2,U=X^3`，违反 `gcd(U,R)=1`。所以 `a≠0`，并且

```text
b=3a^2/14,
d=27a^3/2744.                              (4.3)
```

对应三个槽的 `ρ` 分别为

```text
k=0:  ρ= 3^8 a^7 /(2^4·7^10),
k=1:  ρ=−3^8 a^7 /(2^7·7^10),
k=2:  ρ=−3^8 a^7 /(2·7^10).
```

### 4.1 原数字原点不能任意换到别的根

将 `r=X/a` 代入 `f−2`，除去显式线性因子 `X` 后，只出现下列四个三次多项式：

```text
C1=392r^3+588r^2+252r+27,
C2=1568r^3+1764r^2+504r+27,
C3=3920r^3+4116r^2+1008r+27,
C4=1960r^3+1764r^2+252r−27.
```

它们分别在模 `5,11,13,13` 下无根，因此在 `Q` 上没有线性因子。原条件 `f(0)=2` 所对应的有理原点只能是上面的 `X=0`。故回到原数字变量时只剩非零有理缩放 `Y=sX`，没有平移。

### 4.2 三个规范族

置 `Y=7X/(3a)`。三个槽恢复为

```text
F0(Y)=256Y^7+1568Y^6+3696Y^5+4200Y^4
      +2352Y^3+588Y^2+49Y+2,

F1(Y)=−5120Y^7−25984Y^6−49056Y^5−42336Y^4
      −16464Y^3−2352Y^2−98Y+2,

F2(Y)=−80Y^7−448Y^6−924Y^5−840Y^4
      −294Y^3+(49/4)Y+2.
```

原多项式是 `F_k(sX)`。

- 对 `F1`，若 `s>0` 则一次系数为负；若 `s<0` 则二次系数仍为负。
- 对 `F2`，若 `s>0` 则三次系数为负；若 `s<0` 则一次系数为负。

它们都不可能是非负数字多项式。

只剩 `F0`，且非负性强迫 `s>0`。写 `s=u/v` 既约。由一次系数 `49s` 与首项 `256s^7` 都为整数，得到 `v|49` 且 `v^7|256`，所以 `v=1`；即

```text
s∈Z_{>0}.                                   (4.4)
```

对应原端点为

```text
Σ(Y)=8Y(6Y^2+14Y+7)
     (32Y^4+116Y^3+124Y^2+37Y+1)/7.         (4.5)
```

`Σ(sX)` 是原整数数字多项式。其三次系数是 `11136s^3/7`，而 `7∤11136`，故

```text
7 | s.                                       (4.6)
```

### 4.3 完整 7 源排掉唯一正族

在原输入处令 `y=sT`；由(4.6)，`r=v7(y)≥1`。精确分解

```text
F0(y)−2
 = y(8y^3+28y^2+28y+7)
     (32y^3+84y^2+56y+7).                   (4.7)
```

当 `7|y` 时，后两个括号的 `7` 进估值都恰为1。因此原 `n−2` 中的完整源指数为

```text
E=v7(n−2)=r+2.                               (4.8)
```

另一方面，由(4.5)，当 `7|y` 时

```text
v7(6y^2+14y+7)=1,
32y^4+116y^3+124y^2+37y+1 ≡1 (mod7),
```

所以

```text
v7(Σ(y))=r=E−2.                              (4.9)
```

故 `Σ(y)` 不被 `7^E` 整除，而 `Σ(y)−1,Σ(y)−2` 都是7进单位。完整第二源 `7^E|n−2` 没有进入三个合法槽中的任何一个，违反同一 NC3 输入的完整源窗口。若 `Σ` 命名的是原 `k` 而非 `j`，结论不变，因为 `C(n,k)=C(n,j)`，同一无进位窗口也要求 `k mod 7^E∈{0,1,2}`。这里保留了整个 `7^E`，没有把源截成一次7。

因此整块单槽类全部退出。

## 5. 两条线进入两个不同槽

现在 `R` 必须分裂为两个不同的有理线性因子，且进入不同槽。用有理仿射坐标把两个根送到 `0,1`，写

```text
R=ell X(X−1),
W(0)=kU(0), W(1)=lU(1),
(k,l)∈{(0,1),(0,2),(1,2)}.
```

DIFF 的线性商在两个根处分别为 `−k ell,l ell`，所以

```text
3X(X−1)W'−(2X−1)W−2X(X−1)U'
 +[(k+l)X−k]U=0.                             (5.1)
```

将 `U` 规范为首一。解这个线性 ODE 和两个根值条件后，`U,W` 只剩两个有理参数 `A,B`。精确解为：

```text
(0,1):
U=X^3+BX^2+AX−B/2−5/7,
W=(5/7)X^3+(3B/4−1/14)X^2+(A−B/4−5/14)X;

(0,2):
U=X^3+BX^2+AX−A−3B/2−25/14,
W=(4/7)X^3+(B/2−5/14)X^2+(−3B/2−25/14)X;

(1,2):
U=X^3+BX^2+AX−3A−7B/2−55/14,
W=(3/7)X^3+(B/4−11/28)X^2
  +(−A−7B/4−55/28)X−3A−7B/2−55/14.
```

再把(U2)

```text
U^2 | W^3+ell X(X−1)−2UW^2
```

的六个余式系数置零。精确消元给出下表中的必要三次式：

| 槽对 | 必须满足的 `P_{kl}(B)=0` |
|---|---|
| `(0,1)` | `7B^3−490B^2+8596B+13512` |
| `(0,2)` | `7B^3+553B^2+11725B+16875` |
| `(1,2)` | `218750B^3+828625B^2+817124B+60621` |

完整 ODE 解和 Gröbner 基底保存在 `cert/classification.json`；两个检查器分别以 lex/grevlex 次序核对原余式理想与基底双向约化。

模13时三个三次式分别化为

```text
7B^3+4B^2+3B+5,
7B^3+7B^2+12B+1,
12B^3+5B^2+9B+2.
```

它们在 `F_13` 的全部13个元素上均非零。三次式因此在 `F_13` 上不可约；其首项不被13整除，Gauss 引理推出原三次式在 `Q` 上不可约，特别没有有理根 `B`。

所以双线性两槽类为空。

## 6. SEPTIC-ALL

二次商的所有完整槽分配都已排空。故在 GATE7：

```text
f∈Z[X] 非负系数, f(0)=2, deg f=7, H=f(1),
T=p^e 奇素数幂,
T≥[2(H+2)]^18,
n=f(T) 偶,
```

不存在 NC3 输入。于是该原行每个合法 `j` 都有同一个奇素数同时整除 `C(n,3),C(n,j)`。

本轮没有将数字多项式必要系统反向称为 NC3，没有改变原 `(n,j)`，也没有使用或混同实际 `Ψ` 与恢复 `Pρ`。
