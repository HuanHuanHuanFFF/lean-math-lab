# FAILURES · 第五轮 COF40 / COMP1

## F1. 首攻的精确失败命题：另一源 P² 相位并非由固定 h 的实核心决定

待检的加强命题：在第四轮已证明 Q³ 相位反向的 h 区域，正实核心与旧大小走廊可统一强迫 `{j/P²}>{n/P²}`，不需要 Q 的额外整数信息。

对 h=16639，取唯一正实根 Z 满足

```
(Z²-h)(h-2Z-1)-h=-h/Q³，128<Z<130。
```

定义

```
nu=QZ，v=Q(1-(2Z+1)/h)，P=Q(h-2Z)，
n=PQnu+2，j=(P+nu)Q²，k=(Q²+vnu)P。
```

它们满足实数意义的全部三条线性/范数、j+k=n、Delta>17、1/3<v/Q<1。精确128步有理根隔离和严格端点比较给：

| h | Q | P² 尺度的比较 | 原恢复缺口 |
|---|---:|---|---|
|16639|10007|`{j/P²}<{n/P²}`|`1290864<nu<1290865`|
|16639|10037|`{j/P²}>{n/P²}`|`1294734<nu<1294735`|

显示小数仅可作为阅读提示，证据文件使用完整有理端点：

```
Q10007: j相位约0.615701，n相位约0.802529；
Q10037: j相位约0.617547，n相位约0.038771。
```

### 不成立的是什么

上述两个精确弱模型否定的是 **h 与实核心即可统一判定 P² 尺度方向**。这里 P 不是已经认证的素数幂，nu 不是整数，因此不能把实尺度比较称作实际 p 进位。

### 缺失条件

完整整数恢复、nu=2H 且 H 奇、Delta 的整数同余、真实 gcd、n=c2^s、P 的原活动素数幂身份、完整源窗口及全部高层 NC3。Q 被试除证明为素数不补上这些缺口。

### 重试条件与本轮换路

若继续该 p 路线，必须加入原 Q 的整数分布、完整 P 源或 n 形状，不能只提高同一实展开精度。本轮据此改用 `W_Delta` 的完整整除与 h 的整数格点，得到 COF40/COMP1。

## F2. 新不等式不会自动界住 W_Delta

错误外推：`W_Delta>=2` 与 `16Delta<W_Delta²+640W_Delta` 本身已经给原题全局有限化。

精确无界整数外壳：任意整数 W>=2，取

```
Delta=16W+1，
v=(Delta³-1)/W=4096W²+768W+48，
Q=v+Delta=4096W²+784W+49。
```

则 W=(Delta³-1)/v，Delta≡1 mod16、v正偶、Q正奇、gcd(v,Q)=1、3v>Q。新门槛的差为

```
W²+640W-16Delta=W²+384W-16>0。
```

因此它不触发 COF40，且 W 可以任意大。D_cyc=v/gcd(v,3(Delta-1)) 也大于1。

### 缺失条件

没有恢复整数 h、nu、P；没有满足原范数 `vnu²=PQ²-1`，也没有原 n,j、n=c2^s、实际素数幂分拆或 NC3。它只证明显示的补商标量约束不能单独把参数变成绝对有界，不是完整必要系统的整数反模型。

### 重试条件

必须用原范数/平方恢复的更多算术，或将两侧原完整素数幂与 n=c2^s 接到 W_Delta 的支持和指数。扩大固定 W 的表不等于去掉 W。

## F3. 为什么“冗余恒等式”这次产生了新约束

五次范数、Q 的补商表达与 h 恢复式仍相互依赖。本轮没有把它们计作三条独立方程。新增信息是正整数 W、正根 Y 和 **整数 h 的有理格点间距** 的联合使用。

删除 h∈Z 后，平方根恢复当然有正实解；因此不能只引用平方差的正性便宣布实核心矛盾。PROOFS P2.3 的两个整数格点是必要步骤。
