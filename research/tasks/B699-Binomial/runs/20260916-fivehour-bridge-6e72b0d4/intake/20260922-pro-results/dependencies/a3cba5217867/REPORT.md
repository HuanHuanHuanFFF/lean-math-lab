## 1. 本轮结果与范围

本轮不是整个 i=3 闭合。所有原题出口都限定于同一原始合法 `(n,j)` 的规范最小临界两底支：`g=lambda=w_old=1,b=2r,xi=2mu`，沿冻结出口取真实 `mu=1`。原恢复为

```math
P=Q+hv,\quad2\nu=h(Q-v)-Q,\quad v\nu^2=PQ^2-1,
\quad n=PQ\nu+2=c2^s,\quad c\in\{1,3\}.
```

P,Q是不同原奇素数的完整幂；保留原 gcd、孤立3、全部源幂及高层条件。显示的代数核心不是 NC3 的充分模型。

用旧 `d=Delta=Q-v,W=(d^3-1)/v`，以及双侧分圆块

```text
Dv=v/gcd(v,3(d-1)), DW=W/gcd(W,3(d-1)), G=gcd(Dv,DW),
Phi3(d)=sigma Dv DW, Dv,DW>=7,
sigma=3 当 d≡1 mod3，否则1。
```

## 2. 核心：不允许每个辅助素数使用不同的 n

令 `T=(h-1)nu²-hPQ`。同一原范数给出

```math
2n-h-3=vT.
```

旧共享条件是 `G|h²-6h-11`。因此

```math
h^2-6h-11=4(n^2-6n+4)-4(n-3)vT+v^2T^2.
```

G为奇数，故 `G|n²-6n+4`。这不是增加一个独立数值方程；新的约束来自把这条后果和真实 `n=c2^s` 同时使用。

对每个 `ell_i^b_i|G`，令 `T_i=ord_(ell_i^b_i)(2)`，准确列出

```math
E_i(c)=\{e\bmod T_i:(c2^e)^2-6c2^e+4\equiv0\pmod{\ell_i^{b_i}}\}.
```

每个集合至多2项。同一个c必须在所有模数上相同，同一个s必须通过广义CRT；单素数分别非空远远不够。

实际完整周期证书为：

| ell | T | E(1) | E(3) |
|---|---:|---|---|
|409|204|96,110|85,99|
|1129|564|32,534|341,403|

两个阶的最大公因数是12。c1对应 `{0,2}` 对 `{8,6}`；c3对应 `{1,3}` 对 `{5,7}`。两种c都无交集，所以整个409/1129共享共现支退出。没有扫描n；204、564是被认证为完整的群周期。

任意单素数还可不求离散对数，直接检查

```math
\gcd_{\mathbf F_\ell[X]}(X^2-6X+4,X^{\operatorname{ord}_\ell(2)}-c^{\operatorname{ord}_\ell(2)}).
```

使用二进制多项式模幂，代数运算次数O(log T)，不是O(T)指数扫描。1321442641的周期为66072132，本轮没有逐个枚举这个周期。

辅助ell本身未必整除C(n,3)，所以它绝不被称作新原共同素数。推论是反证NC3，得到原定义要求的某个同一素数p>=3。

## 3. 单素数幂支的准确收缩

未分歧侧采用 Bennett–Levin《The Nagell–Ljunggren equation via Runge’s method》arXiv:1312.4037v1，第一页 Proposition 1 和四个例外。长度3下，正整数 `x²+x+1=y^a,a>=2` 只能x18,y7,a3。当前d奇且1 mod16，故退出；a1已由两侧非空排除。

带因子3的奇素数指数通过Eisenstein整数迹递推直接排除，不采用原计划的BHV。写 `x=(2d+1)/3`、`alpha=(1+x sqrt(-3))/2`，则 `Tr(alpha)=1,N(alpha)=y^p`。p>=5时唯一分解和单位吸收给alpha=gamma^p；a=Tr(gamma)只能±1。全参数迹多项式

```math
V_p(1,Y)=1+pY[-1+Y A_p(Y)],\quad A_p\in\mathbf Z[Y]
```

不允许y>1。p3由本包附出的三次Fermat下降排除。这里的下降仅证明辅助经典方程，绝不是保持NC3的原输入下降。

偶指数仍有Pell型平方解，因此本轮明确保留 `a=2^e`。利用6阶单位和模ell迹再得 `2^(e+1)|(ell-1)`，合旧SPLIT5与d1 mod16，底数必须为1或49 mod120。

## 4. 失败与换路

“带因子3也没有完幂”是错误的：Pell递推给出无界平方解。但这不是无界素数值的证明，更不是NC3实例。本包给出k8的精确整数弱模型，ell=1321442641是素数，它满足双侧分拆和本轮单底指数条件，却没有原整数平方恢复；同时本轮FAST门已杀掉这个特定共享底数。

“分别通过每个素数轨道，就能拼成一个原指数”也错误，409/1129就是完整局部相容、全局不相容的证书。

一般变ell的平方与更高2幂指数仍缺终点。未把相近四次方程的非匹配文献当作定理使用；下一步需要精确四次范数或原p/q高层源信息。详见FAILURES.md。
