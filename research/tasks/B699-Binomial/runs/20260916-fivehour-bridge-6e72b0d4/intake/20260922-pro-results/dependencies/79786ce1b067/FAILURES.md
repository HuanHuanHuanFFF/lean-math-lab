# FAILURES · B699 D / i=3 · 第四轮

## F1. 被否定的精确命题：整个窄平方下方带都在 Q³ 层进位

错误草案：给定足够大的 M 及小于 M 的正 a，只要 h=M²-a 为奇数，所有满足原实核心和相对大小走廊的点都满足 `{j/Q³}>{n/Q³}`。

本轮已证明更准确的边界：

```
a>=2，a!=3，M>=128(a-1)²
⇒ {j/Q³}<{n/Q³}。
```

两条可用例外是 a=1 和 a=3；它们已经由 BSC−1/BSC−3 完成，不再列为待解。

### 非空的精确实代数弱模型

取 M=129、a=2、h=16639、Q=10007。Q 的素性由确定性试除核对。
令 Z 为

```
(Z²-16639)(16639-2Z-1)-16639=-16639/10007³
```

在相应正根区间内的唯一实根，定义

```
nu=QZ，v=Q(1-(2Z+1)/h)，P=Q(h-2Z)，
n=PQnu+2，j=(P+nu)Q²，k=(Q²+vnu)P。
```

这些数精确满足代数范数、线性恢复以及 j+k=n。完整有理根隔离证书在
`certificates/phase_diagnostics_and_failure.json` 中，不以显示小数作证据。

原走廊的实数版本满足 Delta>17、1/3<v/Q<1；但

```
1290864 < nu < 1290865。
```

因此 nu 不是整数。该 h 的整个允许 Q 实相位区间也严格满足反向比较。

### 缺失的原题条件

nu、v、P、n、j 没有恢复为整数；没有整数意义的 Delta≡1 mod16、H 奇、真实 gcd；没有 n=c2^s；P/Q 的完整原源分配和实际 NC3 均未建立。即便这里 Q 本身为素数，也不能消掉这些缺口。

这不是原题反例，不是现有 NC3 必要系统的整数反模型。它只证明弱实核心无法给“全部下方带同层进位”。

### 重试条件

对 LOWER-BARRIER 区域，须使用整数组合、原 n=c2^s、另一原源 p 的层，或同一个 q 的其他层。不能再仅提高实根展开精度，期待这一层的符号翻转。

本轮已据此改用半整数中心，在平方间隙中部取得 MID128。

## F5. 算法与证据边界

* h-only 根隔离器是条件消费者，不证明某 h 存在合法原输入。它不界住 h。
* 相位区间跨整数边界或精度不足时返回 INCONCLUSIVE，禁止解释成 Common3 或 NC3。
* 固定的47个 h 诊断和23177个小整数估值事件只检查代码，不是主定理末端。
* 当前没有满足全部原条件的新增数值候选，更没有反例。旧 h43,Q3,v2 弱点被输入验证器明确拒绝。
* 符号生成器与标准库检查器由同一会话编写，不称外部独立审读。
