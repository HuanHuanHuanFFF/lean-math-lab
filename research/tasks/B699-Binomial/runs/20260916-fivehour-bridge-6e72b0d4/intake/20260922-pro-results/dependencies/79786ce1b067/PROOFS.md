## P0. 原输入、逻辑类型与依赖范围

本轮始终是同一个原始合法数对 `(n,j)`，`k=n-j`，当前指标始终为 i=3。
采用的前置分支为

```
g=lambda=w=1, b=2r, xi=2mu；沿冻结出口取真实 mu=1。

P=Q+hv，2nu=h(Q-v)-Q，v nu^2=PQ^2-1，nu=2H>0。

```

完整原条件还保留 `Delta≡1 mod16`、H 奇、真实 gcd、`n=c2^s`、原窗口完整素数幂和所有高层无进位。上述代数关系是 NC3 的必要表示，不反推 NC3。新不等式实际上不需要使用其中全部附加条件，因而也可在更宽的充分消费者契约下理解：若同一个合法整数输入满足显示的数值系统，且 q 是 C(n,3) 的活动原素数，则下面的进位结论证明 Common3(n,j)。

源自 Overview 及第1—3轮的入口仍按冻结作者纸面等级采用，未升级为独立数学核验。具体来源和未重放前置见 SOURCE_ADOPTION.md。新变量 M、m、t、A、B、d 仅在本轮相应命题中使用；它们不是旧 A_*、B_*、整数残量 z、间距 delta 或负根参数 d。

本轮目标是证明原 q 在 `q^(3r)=Q^3` 层发生进位。没有创造新数对，没有做下降，也不将 Q 当成素数。

## P1. 同一输入的标准化精确等式

置 `Z=nu/Q`、`Nph=n/Q^3`、`Jph=j/Q^3`。原范数与 v 的完整整数性给

```
Z^2=h+(Q^3-1)/(vQ^2)，故 h+1<Z^2<h+3。
h Delta=2nu+Q。
```

由于 h>=15，`2sqrt(h+3)+1<3sqrt(h)`，从而

```
h Delta^2<9Q^2。
```

特别地 Delta>=17 给 `Q^2>(289/9)h`，并有 h<Q^2。

由 P=hQ-2nu 得

```
Jph=h-Z，Nph=hZ-2Z^2+2/Q^3。
f_h(Z):=(Z^2-h)(h-2Z-1)-h=-h/Q^3。
```

这些是同一原式的换元，不是增加独立方程。精确程序还核对：若 R=vnu²-PQ²+1，则在原线性恢复下

```
(P+nu)Q²+(Q²+vnu)P-n=-2R，
(P+nu)(Q²+vnu)-(n-1)=-R。
```

## P2. 带符号偏移、实数中心的统一估计

### 引理 SC64

令 t 为正实数、A 为实数、B 为实数，满足

```
h=t²+A-1，B>=1，|A|<=B，t>=64B²。
```

只在仍满足 P0—P1 的同一输入上使用。定义

```
Z1=t+A/(2t)+1/t²+(20-A²)/(8t³)，
B0=t³-2t²+(3A/2-1)t-2A+1，
c1=(3A²-4A-12)/8。
```

则

```
|Z-t|<2B/t，
|Nph-B0-c1/t|<32B/t²。                         (SC64)
```

这里 t 不必为整数，A 可以为负。第3轮的 [m,m+1] 单侧导数估计不能直接冒用；下面给出新的双侧证明。

### P2.1 根与截断均在双侧区间内

由 B<=t/64、t>=64，有

```
h>=t²-B-1>t²/2。
```

联立 P1：`Q²>(289/9)h>(289/18)t²>16t²`，所以 Q>4t，尤其 Q>t。

`A<Z²-t²<A+2` 给 `|Z²-t²|<B+2<=3B`。因此 `t-1<Z<t+1`，且

```
|Z-t|<3B/(2t-1)<2B/t。
```

同时

```
|Z1-t|<=B/(2t)+1/t²+(20+B²)/(8t³)<1，
```

故 Z1 也位于 (t-1,t+1)。

### P2.2 整段导数下界

对 y∈[t-1,t+1]，

```
f_h'(y)=2h(y+1)-6y²-2y
 >=2t³-6t²-(2B+16)t-8
 >=2t³-(193/32)t²-16t-8
 >(3/2)t³。
```

最后一个严格不等式由 t=64+u、u>=0 后的正系数恒等式保证：

```
(1/2)t³-(193/32)t²-16t-8
=(1/2)u³+(2879/32)u²+5356u+105336>0。
```

另一方面 `phi(y)=hy-2y²` 在该区间满足

```
0<phi'(y)=h-4y<h<(65/64)t²。
```

## P3. 平方下方第一族 BSC−1

**定理。** 若 `h=M²-1`，M 为偶整数且 M>=128，则原 q 在 Q³ 层进位。

取 t=M、A=0、B=1。由 P1，`M<Z<sqrt(M²+2)<M+1/M`。所以

```
{Jph}=1-(Z-M)>1-1/M。
```

此时 `B0=M³-2M²-M+1` 为整数，c1=-3/2。SC64 与 M>=128 给

```
B0-7/(4M)<Nph<B0-5/(4M)。
```

因此 floor(Nph)=B0-1，且

```
{Jph}-{Nph}>1/(4M)>0。
```

整个无限 M 尾部由同一不等式处理；未扫描 M 或 n。

## P4. 平方下方第二族 BSC−3：必须处理的一阶抵消

**定理。** 若 `h=M²-3`，M 为偶整数且 M>=256，则原 q 在 Q³ 层进位。

取 t=M、A=-2、B=2。P1 给 `M-1<Z<M`。此时

```
B0=M³-2M²-4M+5∈Z，c1=1。
```

SC64 给 `B0+3/(4M)<Nph<B0+5/(4M)`，故 floor(Nph)=B0。
`{Jph}=M-Z` 与 `{Nph}=Nph-B0` 的一阶项同为 1/M，不能用一阶近似决定方向。

取新的单侧截断

```
Z*=M-1/M+1/M²+2/M³+9/M⁴。
```

它位于 (M-1,M+1)。直接展开有

```
f_h(Z*)=-53/M²-70/M³+58/M⁴-46/M⁵-255/M⁶
         -510/M⁷-186/M⁸+254/M⁹-702/M¹⁰-972/M¹¹-1458/M¹²。
```

对 M>=64，逐项绝对值控制给 `|f_h(Z*)|<60/M²`。精确和在证书内。
由于 f_h(Z)<0、f_h'>(3/2)M³，可作单侧比较

```
Z<Z*+40/M⁵。
```

定义 `G(y)=B0+M-y-(hy-2y²)`。在所用区间 G 严格递减且 |G'|<M²。新的精确恒等式为

```
G(Z*)=3/M²+36/M³+12/M⁴-28/M⁵+44/M⁶+72/M⁷+162/M⁸>3/M²。
```

最后一个不等式用 `36/M³-28/M⁵>0`，其余项均正。因此

```
{Jph}-{Nph}=G(Z)-2/Q³
 >3/M²-40/M³-2/M³
 =3/M²-42/M³>0。
```

本节的 A=-2、9/M⁴、残差多项式及 42/M³ 均为本轮重新推导，不能与第3轮 A=+2 的截断混同。

## P5. 平方间隙中部 MID128：带符号的增长宽度族

**定理。** 令 m 为非负整数、d 为任意奇整数（允许 d<0），满足

```
h=m²+m+d，m>=128(|d|+1)²。
```

在以下任一模类中，原 q 在 Q³ 层进位：

```
d≡1 (mod4)，m mod8∈{4,5,6,7}；
d≡3 (mod4)，m mod8∈{0,1,2,3}。                     (MID128)
```

而在同一带内其余八个 (d mod4,m mod8) 状态，严格有 `{Jph}<{Nph}`；这只说明本层不进位，不声称输入是 NC3。

### P5.1 选择半整数中心

取

```
t=m+1/2，A=d+3/4，B=|d|+1。
```

则 h=t²+A-1、|A|<=B、t>=128B²。由于 |d| 远小于 m，

```
m²<h<(m+1)²；所以本定理的 m 就是 floor(sqrt(h))。
```

由 SC128，Z 仍严格位于 (m,m+1)，故

```
{Jph}=1/2-(Z-t)，|{Jph}-1/2|<1/64。
```

### P5.2 精确周期相位

这次 B0 的分母为 16：

```
16B0=16m³-8m²+(24d-18)m-20d-13。
```

d 为奇数，所以该分子为奇数。m→m+8、d→d+4 时，分子之差均被16整除，故只需下表全部16个状态：

| d mod4 \ m mod8 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 1：16{B0} | 15 | 13 | 11 | 9 | 7 | 5 | 3 | 1 |
| 3：16{B0} | 7 | 5 | 3 | 1 | 15 | 13 | 11 | 9 |

这是对所有整数 m,d 的周期恒等式，不是观察16个小样本再猜周期。

由 `|Nph-B0|<21/1024<1/16`，Nph 不会跨过 B0 所在单位区间的端点。若表中余数 R<=7，则

```
{Jph}-{Nph}
 >1/2-1/64-(7/16+21/1024)
 =27/1024>0。
```

若 R>=9，则反向间距同样严格大于 27/1024。

### P5.3 与第3轮覆盖的精确分离

旧 NSB64 对 m=floor(sqrt(h)) 要求

```
m>=64(h-m²+1)²。
```

在本带内 `h-m²+1=m+d+1>m/2`，所以旧右端大于16m²>m，旧门检必不成立。因此 MID128 与第3轮 NSB64 的 h 参数域不相交。

这不是与所有历史消费者并集的净差审计。特别，不能由两个参数域不交便断言发现了实际 NC3 实例；本定理恰是证明相应条件下不存在 NC3。

示例：

```
h=m²+m+1，m>=512，m mod8∈{4,5,6,7}；
h=m²+m-1，m>=512，m mod8∈{0,1,2,3}。
```

d 本身也可无界：任取 d=4u+1，选择足够大的 m≡4 mod8 满足门槛即可。
其中取 d≡1 mod8 仍有 h≡5 mod8，所以本族并非全部落在旧纯二幂 h 模8已排类内。

## P6. 平方下方方法边界：除两个例外外，本层方向相反

设

```
h=M²-a 为奇数，a>=2，a!=3，M>=128(a-1)²。
```

则在同一核心系统中，严格有

```
{Jph}<{Nph}。                                      (LOWER-BARRIER)
```

因此不能将“整个足够窄的平方下方带”都交给同一 q^(3r) 层来排除。

证明：取 A=1-a、B=a-1，使用 SC128。

* a 为偶数时，M 为奇数，B0 是半整数。先证明 Z<M：
  `f_h(M)=(a-1)M²-2aM-a²>0`，因为 a<=2B<=M/64。
  与 f_h(Z)<0 及严格递增性合得 Z<M。
  所以 `{Jph}=M-Z<1/64`，而 `{Nph}>1/2-21/1024`，方向严格相反。

* a 为奇数且 a>=5 时，M 为偶数，B=a-1>=4，B0 是整数。
  由 Z²<M² 及 Z>M-1，令 eta=M-Z，有
  `0<eta<B/(2M-1)<B/(2M)+B/M²`。
  又 c1=(3B²+4B-12)/8，故
  
  ```
  Nph-B0-eta
  >3(B²-4)/(8M)-33B/M²>0。
  ```
  最后一步由 B>=4、M>=128B² 直接保证。同时
  `|Nph-B0|<21/1024`，所以 floor(Nph)=B0，得反向小数比较。

本节不否定原题，不证明这些整数核心实际有解，也不排除在更低的 q 层或另一原素数处出现进位。FAILURES.md 给出非整数实模型，证明这不是纯符号误判。

## P7. 精确的 h-only 原层判定器，不枚举 Q

原 h Delta²<9Q²、Delta>=17 给

```
Q>=Qmin=floor(sqrt(289h/9))+1。
```

用精确整数计算 `Qmin=isqrt((289*h)//9)+1`，没有浮点开平方。

程序在 `[floor(sqrt(h+1)), floor(sqrt(h+3))+1]` 内分别隔离

```
f_h(Z_-)=-h/Qmin³，f_h(Z_+)=0。
```

每次先用有理数检查端点符号和 f_h' 的两个端点值均正。由于 f_h' 是凹二次式，这证明整段严格递增。检查失败就返回 INCONCLUSIVE，不擅自选根。

任意真实 Q>=Qmin 的原 Z 满足 `Z_-<=Z<Z_+`。将两个精确有理隔离区间的外端点合为 [L,U]，便有

```
Jph∈[h-U,h-L]，
Nph∈[min phi([L,U]),max phi([L,U])+2/Qmin³]。
```

phi 是二次式，极值只需检查两个端点及处于区间内的顶点 h/4。若两个区间分别不跨整数边界，便能用有理数严格比较整个小数部分区间：

* J 的下端严格大于 N 的上端：CARRY，足以排除该 h 的所有原核心候选；
* J 的上端严格小于 N 的下端：NO_CARRY_THIS_LAYER，不推断 NC3；
* 其余：INCONCLUSIVE。

隔离位数的终止并不影响正确性：精度不足只会得到 INCONCLUSIVE。该程序无需输入 n、Q 或搜索 Q；但 h 仍然无界，逐 h 使用它不是全局有限化。本轮47个 h 的诊断仅检验实现与显式全参数定理一致，不作为无界定理的证明。

## P8. 返回同一个原素数

上述 CARRY 分支均证明

```
j mod Q³ > n mod Q³，Q³=q^(3r)。
```

由计数阶乘中 q 的倍数，

```
v_q(C(n,j))=Σ_{e>=1}[floor(n/q^e)-floor(j/q^e)-floor((n-j)/q^e)]。
```

每项为0或1。e=3r 项由于显示的余数不等式等于1，故 q|C(n,j)。

同一个 q 是原第二窗口活动素数。q>3 时 q|(n-2) 直接给 q|C(n,3)。若 q=3，必须保留原粗块中的完整高次3幂；孤立的一次3已按真实规则剥离，而保留指数至少2，故 `v_3(C(n,3))=v_3(n-2)-1>=1`。没有删除 p=i=3，也没有用更大的任意 Q 替换原完整源幂。

这给出 Common3(n,j)，与同一个原 NC3 输入矛盾。阶乘证明已在此给全；Granville 作者页面仅为经典进位表述的外部核对，不承担新的有效高度或 CAS 前置。
