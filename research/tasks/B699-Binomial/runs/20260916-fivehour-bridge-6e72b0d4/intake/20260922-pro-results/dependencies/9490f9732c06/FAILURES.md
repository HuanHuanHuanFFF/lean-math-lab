# FAILURES · B699 D / i=3 · 第三轮

## F1. 不能把 D_cyc 的分圆素数直接升级为原源

### 被否定的精确弱命题

从 `v|Delta^3-1`、D_cyc 的完整酉分拆、ord_ell(Delta)=3、已有大小/奇偶门槛
及线性形式 `P=Q+hv,2nu=hDelta-Q,n=PQnu+2`，即可推出每个 ell|D_cyc
整除 C(n,3)。这个推论不成立。

### 精确整数外壳

```
Delta=17, v=4912, Q=4929, D_cyc=307,
h=377005, P=1851853489,
nu=3202078, H=1601039,
n=29227882250289849920.
```

307 为素数，且 Delta^3=1 mod307、Delta≠1 mod307。
`v/gcd(v,3(Delta-1))=307` 且 gcd(307,v/307)=1。
Delta≡1 mod16，v 偶，H 奇，v/Q>1/3，h 奇，P>=4Q，
`h<36D_cyc^2+30D_cyc+9`。

然而 `n mod307=6`，`C(n,3) mod307=20`，307 不是原源。

### 缺失的原题条件

完整范数失败：`vnu^2-PQ^2+1=5373370439580560>0`。
P/Q 的真实完整素数幂、同一原 j 的完整源、真实 gcd、n=c2^s 也未认证。
所以这不是 NC3，不是原题反例，也不反驳“在完整原条件下 D 的某些素数可以回传”。

### 无界版本及修正条件

取 x=48a+17，a>=0，令

```
Delta=x, v=x^3-1, Q=v+x, D=x^2+x+1,
h=4D^2+9, P=Q+hv, nu=(hDelta-Q)/2, n=PQnu+2.
```

这里 h≡9 modD，Q≡Delta modD，得到 n≡6 modD；D 的每个素因子为1 mod3，
因此都至少7，均不除 n(n-1)(n-2)。而

```
4(vnu^2-PQ^2+1)=(x-1)(x^2+x+1) R(x),
R(x)=32x^9+72x^8+176x^7+241x^6+408x^5+292x^4
     +358x^3+112x^2+108x-59>0  (x>=17).
```

这个无界外壳始终违反范数。重试必须新使用完整范数、真实恢复或活动源资格，
而不是仅扩大 residue/支持表。本轮据此换路，使用已经认证的原源 q。

## F2. 不能把 NSB64 加强成“全部 h 的 Q^3 层都进位”

### 被反驳的只是连续放松命题

若 h>=15、Q>=11、Delta>=17、1/3<v/Q<1，满足完整实代数恢复关系，
就一定有 `{j/Q^3}>{n/Q^3}`。这个在实数放松系统中的命题是假的。

取 h=21、Q=101；z 为下面方程在 (4,5) 内的唯一实根：

`(z^2-21)(21-2z-1)-21=-21/101^3`。

定义

```
nu=Qz, v=Q(1-(2z+1)/21), P=21Q-2nu,
n=PQnu+2, j=(P+nu)Q^2.
```

这些实数精确满足原核心等式及大小走廊。根的有理隔离证书给出

```
0.7159 < {n/Q^3} < 0.7160,
0.2022 < {j/Q^3} < 0.2023.
```

因此该层没有所需方向的不等式。小数只为阅读，证书存放精确有理端点。

### 边界

nu、v、P、n、j 并未被恢复为整数；没有 Delta≡1 mod16 的整数意义，
没有 alpha 形状、P 的完整素数幂、原窗口全部条件和真实 NC3。
它不是原题反例，也不否定整数 NC3 的全局排除。它仅说明：不能将本轮的
平方邻域相位论证不加条件推广至所有实参数。

重试可使用整数恢复或其他原源层；不能从十个区间探针归纳全部 h。
