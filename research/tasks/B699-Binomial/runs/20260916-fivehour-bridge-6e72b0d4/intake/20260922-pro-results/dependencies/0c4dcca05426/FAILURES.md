# FAILURES · 第十轮

## F1. 真混合不是充分恢复条件

被否的弱命题：平衡 Pell、BICOF2 以及 B 同时消费两个相邻块，就足以恢复原整数核心。

精确弱模型取 `t=41`：

```text
A=867656512844,
B=421816446324,
d=121997262292576714195153,
y=70435152225016546773961.
```

它满足

```text
AB=3(d-1)，d<357B²，
B不整除9X_b，B不整除9U_a。
```

但平方目标严格位于相邻平方之间；完整间距见 `certificates/mixed_weak_model.json`。所以它缺少真实整数 Y、nu、h、原 P/Q 素数幂和 n=c2^s，不是 NC3 或原题反例。

**重试条件：** 下一轮必须继续使用真实平方范数、原 Q/P 素数幂或 n=c2^s；仅优化两块支持与大小不会自动闭合。

## F2. BLOCK-MIX 不等于两个不同粗奇素数

由

```text
B/gcd(B,9X_b)>1，B/gcd(B,9U_a)>1
```

不能推出两个残块互素，也不能推出每侧均出现不同的奇素数。B 在素数 2 处的总赋值可能超过任一单块赋值，从而由同一个 2 完成部分“跨块”。

因此本轮只登记完整赋值缺额的真混合，不登记“B 至少有两个粗素数”，更不把辅助素数升级成原题见证。

**重试条件：** 先利用 `gcd(U_a,X_b)=2` 和准确 2 赋值，把剩余分为 odd--odd 与纯 2 桥，再分别接原 Q 素数幂。

## F3. 有限状态证书的量词边界

X 侧的 `m<=39`、U 侧的 `m<=250` 来自 BICOF2 与 Pell 大小，不是任意计算上限。证书在这些范围内是完备的：

* 首次返回给出完整有限环周期；
* TRI3 的 `k!=1 mod3` 显式并入周期；
* 商 `9X_b/m` 或 `9U_a/m` 通过模 `mp` 恢复，没有在模 p 非法除法；
* 每个允许状态都有一个二次非剩余见证。

但 Python PASS 仍不是 Lean 或外部人审，也不验证冻结入口本身。

## F4. BICOF2 依赖的准确前置

BICOF2 使用第九轮已经证明的同一正根误差式 IRR。若离开平衡 `D_v=D_W=y`，中心 R0、整数 J 和结论均不能直接照搬。

因此不能把 `d<357B²` 写成一般最小支、一般两底或整个 NC3 的界。

## F5. 仍未闭合的区域

真混合平衡域仍允许 t、d、y、A、B、P、Q、n 及完整指数共同无界。非平衡多底、一般两底 low/low 和交叉、真三槽/多槽、实际内容三次与其他恢复三次支均未处理。
