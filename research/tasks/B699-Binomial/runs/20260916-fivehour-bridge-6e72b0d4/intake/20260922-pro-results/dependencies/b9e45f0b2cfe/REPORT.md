# REPORT — B / i3 第五轮：任意次数数字源整行闭合

日期：2026-09-21。执行者 Pro E。只研究 i=3；无 Lean、无仓库修改。

## 本轮最强结论

**EIS-BLOCK。** S 为任意有限正整数位置集合，块数 b=|S|≥2 为偶数。T=p^e，p 为奇素数、e≥1。若

    T≥4(3b+4)^4，

则原行

    n=2+3∑_(a∈S)T^a

的全部 `4≤j≤⌊n/2⌋` 均有同一个奇素数同除 `C(n,3),C(n,j)`。

最高次数、所有位置差、位置大小、p、e 与 b 都可以无界；门槛与次数/间隔无关，只随块数增长。对侧原源的支持个数和三槽分配没有限制。这里的 b 是块数，不是旧两底指数。

特别，全部 a>b≥1 和全部 T=p^e≥40000 的

    n=3T^a+3T^b+2

整行闭合。例如 T=5^7=78125 固定后，所有 a>b≥1 都成立。

这是统一无界原行消费者，不是枚举一批高次多项式。证明以不可约整数多项式 `1+3∑X^a`、原 p 的全部无进位、完整第一源和非零结式大小矛盾闭合；没有待枚举底部。数学主链见 PROOFS §§1–4。

## 两个专用无界幂族

对正奇 m、任意 d≥2、任意奇素数工作进制 T=p^e：

|定理|整行|充分门槛|
|---|---|---|
|POWER2|2(mT+1)^d|T≥32·9^d m^(2d−1)|
|POWER1|(mT+1)^d|T≥32·64^d m^(3d−1)|

**不要求 p∤md。** 实际完整原源指数恰为 E=e+v_p(m)+v_p(d)，T 只用于分组进位，不截断实际 p^E。p=3 完整高幂与真实孤立一次3的规则保留。

简明子族：全部 d≥2、e≥2d+4 的 `2(3^e+1)^d`；全部 d≥2、e≥4d+4 的 `(3^e+1)^d`。两个指数同时无界。

## 可复用的更一般结式接口

令 f(X) 是次数 d≥1 的非负整数系数多项式，H=f(1)，f(0)=r，T=p^e，n=f(T)。选 (r,s)=(0,1),(2,1) 或 (1,2)。若 f−s 在 Q[X] 不可约，则：

- s=1、n 偶、T≥4(H+2)^4，整行成立；
- s=2、4|n、T≥8(H+2)^6，整行成立。

不可约的是多项式，不是其整数值。完整整数源可有任意多素数因子。证明中的结式、数字多项式与实际 Ψ、恢复 Pρ 都是不同对象。
