## 1. 二次特征：第5源全近侧只允许 `chi_10=+1`

对奇素数 `p∤10` 写

```text
chi_10(p)=(10/p).
```

二次互反律给

```text
chi_10(p)=(2/p)(5/p)=(2/p)(p/5).
```

故其模 40 的正特征类恰为

```text
1,3,9,13,27,31,37,39 (mod 40).                  (1.1)
```

程序只重放这张有限 Dirichlet 特征表；无限结论来自模 40 周期。

### 1.1 全部 `q5` 素数均在正特征类

取任意 `p|q5`。全近侧 `Q51=q5` 给

```text
p | U-1.
```

又 `U=10g^2z^2`，而粗块与 `g` 互素。若 `p|z`，则同时有 `U≡0,1 (mod p)`，矛盾；故 `p∤gz`。于是

```text
1 ≡ 10(gz)^2 (mod p),
```

从而

```text
chi_10(p)=+1.                                      (1.2)
```

当前准确剩余还要求 `q5` 中存在一个真实源素数

```text
p∉{13,17,23,61},   p∤L4L7.
```

在 `7≤p<31` 的素数中，满足 (1.1) 的只有 `p=13`。因此该真实剩余素数必有

```text
p≥31,  特别 q5≥31.                                (1.3)
```

这里没有声称 `q5` 是素数，也没有把支持限制为有限集合。

## 2. 第3源的特征强迫 `d≥7`

由 `n≡5130 (mod9000)` 且 `120|9000`，有

```text
n≡90 (mod120),
q3=(n-3)/3≡29 (mod40).
```

所以

```text
chi_10(q3)=-1.                                    (2.1)
```

完整第3源写成

```text
q3=E3 I3,
```

其中 `E3` 是端点块，`I3` 是槽 1/2 的内部块。对任意 `p|I3`，在原完整层有 `n≡3`，而 `(j,k)≡(1,2)` 或 `(2,1)`。由于 `N=n-1≡2`，得到

```text
U=jk/N≡1 (mod p).
```

与 §1 相同，`U=10g^2z^2` 迫使 `chi_10(p)=+1`，故

```text
chi_10(I3)=+1.
```

合用 (2.1)：

```text
chi_10(E3)=-1.                                    (2.2)
```

于是 `E3` 不是平方。按真实规范写

```text
E3=d3 h3^2,
E4=d4 h4^2,
d=d3d4,
h=h3h4,
z=d h v,
```

其中 `d3,d4` 平方自由，且第3/4粗块互素。由 (2.2)，`d3>1`；所有粗素数至少为 7，所以

```text
d≥d3≥7.                                           (2.3)
```

这重新得到当前需要的非平方内容，不依赖把旧 `(10/E3)=-1` 当作独立新方程。

## 3. q2 的真实平方精度

完整第2源沿用 C1/C3 的准确分配

```text
q2=E2 M2,
E2=gcd(q2,U),
M2=gcd(q2,j-1).
```

端点块进入 `z^2`，中心块以平方进入 `eta`：

```text
E2 | v^2,                M2^2 | eta.               (3.1)
```

因此

```text
v^4 eta^3 ≥ E2^2 M2^6
            = q2^2 M2^4
            ≥ q2^2.                                (3.2)
```

当前 NC6 已越过单位窗口，故 `q2≥7`；于是还可用

```text
v^4 eta^3≥49.                                      (3.3)
```

(3.1) 不把源指数加倍：平方指数来自原目标 `(j-1)(k-1)`，源仍是原来的完整 `q2`。

## 4. 两侧真实大缺欠与 D25：得到三次 q2 压缩

采用同一原输入的实际支持部分

```text

```

在第5源全近侧 `Q51=q5` 时，完整第2/5源给

```text

```

当前残域还必须避开已有两个消费者，故

```text

Delta4 > 10 g^2 D25.                               (4.2)
```

真实恢复中

```text
Delta_r=rho_r^2,
rho_r=h_r/gcd(h_r,v).
```

由于 `h3,h4` 互素，

```text
Delta3 Delta4
  = (h/gcd(h,v))^2
  ≤ h^2.                                           (4.3)
```

将 (4.2) 相乘并用 (4.3)：

```text

```

另一方面

```text

```

故

```text

  > 27000g^7d^2D25^2v^2.                           (4.5)
```

由 (4.1)、`E2|v^2` 及 `q2=E2M2`，


代入 (4.5)，得到本轮核心新压缩：

```text

```

这不是旧低残量式的常数改写：它同时使用了第2/5实际目标支持、两侧真实大缺欠和 `U<n/3`，并把 `q2` 提升为三次相对控制。

用 `g≥10,d≥7,q2≥7,q5≥31`，(4.6) 给

```text

  = 4,360,912,290,000,000,000.                    (4.7)
```

无界参数仍然存在；(4.7) 是统一下界，不是绝对上界或有限化。

## 5. 三个无界指数进入同一尖点

低残量必要条件为

```text
4608 g^4 q5^4 d^2 v^4 eta^3 < 5n.                 (5.1)
```

### 5.1 纯 3 幂指数 `a`

用 `g=n/3^a`、`q5≥31`、`d^2≥49`、(3.3)，由 (5.1)：

```text
5·3^(4a)
 > C_A n^3,
C_A=4608·31^4·49^2
   =10,217,659,027,968.                             (5.2)
```

函数右端随 n 增长。把 (4.7) 的最小整数 `n0=4,360,912,290,000,000,001` 代入，精确整数比较给

```text
5·3^(4·35) ≤ C_A n0^3.
```

所以

```text
a≥36.                                               (5.3)
```

### 5.2 高 2 小部指数 `b=v2(n-2)`

由 `q2=(n-2)/2^b` 和 (4.6)，丢掉只会加强右侧的实际参数，得到

```text
n·2^(3b) > C_B (n-2)^3,
C_B=27000·10^7·49·31^2
   =12,714,030,000,000,000.                         (5.4)
```

`(n-2)^3/n` 在 `n>2` 严格递增。于 `n0` 精确核对

```text
n0·2^(3·59) ≤ C_B (n0-2)^3,
```

故

```text
b≥60.                                               (5.5)
```

这继续删除了 C4 尚余的全部 `8≤b≤59` 无界分支。

### 5.3 完整 5 层指数 `E=v5(n-5)`

用 `q5=(n-5)/5^E`、`g≥10`、`d^2≥49` 和 (3.3)，(5.1) 给

```text
C_E (n-5)^4 < 5n·5^(4E),
C_E=4608·10^4·49^2
   =110,638,080,000.                                (5.6)
```

因 `n>10`，有 `(n-5)^4>n^4/16`，于是

```text
80·5^(4E)>C_E n^3.                                  (5.7)
```

在 `n0` 精确核对

```text
80·5^(4·23) ≤ C_E n0^3,
```

所以

```text
E≥24.                                               (5.8)
```

```text

n≡2 (mod 2^60),
```

这当然蕴含旧 `n≡5130 (mod9000)`；没有把弱模样本外推成无限结论。

## 6. 精确 CRT 放大算子

为保留可继续路线，定义：给已证下界 `(A,B,F)`，令 `R(A,B,F)` 是满足

```text
R≡0 mod3^A,   R≡2 mod2^B,   R≡5 mod5^F
```

的最小正整数。任一真实候选均有 `n≥R(A,B,F)`。由 (5.2)、(5.4)、(5.7)，进一步必须满足

```text
5·3^(4a) > C_A R^3,
R·2^(3b) > C_B(R-2)^3,
80·5^(4E) > C_E R^3.                                (6.1)
```

这定义一个完全整数、可重放的单调放大算子 `T(A,B,F)`。从本轮基础门

```text
(36,60,24)
```

出发，包内确定性程序精确重放六步：

```text
(36,60,24)      -> (89,134,60)
(89,134,60)     -> (202,294,137)
(202,294,137)   -> (447,638,304)
(447,638,304)   -> (978,1387,667)
(978,1387,667)  -> (2129,3008,1453)
(2129,3008,1453)-> (4623,6522,3155).
```

每一步都使用该步真实 CRT 最小正代表和严格整数比较；没有浮点判定。因而本包所核的任何当前候选特别必须超过最后一组三下界。

**边界：** 本轮没有证明该递推对所有步发散，也没有给 `a,b,E` 上界。有限地多算更多步只会继续抬高常数，不构成闭合、统一有限化或有限末端。本轮的主要数学增量是 §§1—5 的结构门和算子本身，不把“六步”计成六项独立成果。
