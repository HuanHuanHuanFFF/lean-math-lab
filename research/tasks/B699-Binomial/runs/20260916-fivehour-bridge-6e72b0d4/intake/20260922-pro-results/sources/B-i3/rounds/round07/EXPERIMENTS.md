# EXPERIMENTS — 第七轮的精确计算和实际作用

## 环境

运行开始时容器cgroup内存限额4GiB，已用约282714112字节；CPU配额4核；可用磁盘约30GiB。只运行本轮自己创建的进程，没有修改或终止其他任务。源文件、输出和ZIP全部在/mnt/data。

Python 3.13.5。证书生成器使用本环境SymPy；默认两检查器和replay只需标准库。准确版本另见outputs/environment.json。

## 第一方向：直接Groebner诊断

src/quartic_probe.py固定z0、U二次首项1，在有限域32003生成5个方程。请求35秒终止；外层工具超时，未输出完整Groebner基。没有从这次计算推出零维、无解或穷尽结论。

后续src/quartic_reduced_probe.py只生成降参方程。大量项数没有被算作研究成果，也没有继续扩大固定系数范围。

## 第二方向：DIFF后的精确分类

src/ode_probe.py通过线性系数解恢复三个槽对的U,W；余式在ell中一次，所以显式2×2行列式即可消元，避免了未完成的高维Groebner。

src/ode_templates.py恢复每个有理候选，重新核对第一逆关系，按原常数点与非负系数筛选。输出中的自由变量B仅是规范化前的首项尺度，不是原任务里的其他B。

这两脚本属于探索记录；完整证明是PROOFS §3—7。最终重放不需要重新运行它们。

## 冻结证书和两算法

certificates/round7.json固定：

- 三个槽对的ODE、六个精确余式和三个完整消去因式；
- 全部有理候选、ell、U,V,W,f及规范仿射映射；
- 原F4的有理原点及整数缩放边界；
- 11条原行应用（含2条旧mod4出口，仅作回归）；
- 11条原三次恢复的完整3源/三个指定层进位；
- 一个真实整数弱外壳，直接核对共同3的估值为2和18。

A使用稀疏多变量有理系数、首一精确长除法和整数阶乘取整。B独立实现稠密有理长除法、带次数界的网格身份、有理根定理和逐p位相加。

B不是靠随机点：余式关于形状参数a的次数≤8；证书和消去乘积的次数显式限制≤10；使用11个不同a点、两个ell点，线性ell和规定次数下的身份因此精确。它不扫描原n,j，不能用这些点的数量衡量覆盖。
