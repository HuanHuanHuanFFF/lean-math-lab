## 0. 原题、作用域与三条准确结论

原题固定同一个自然数输入 `(n,j)`，`4<=j<=floor(n/2)`，`k=n-j`。Common3 表示存在同一个奇素数同时整除 `C(n,3)`、`C(n,j)`；NC3 表示其否定。

本轮新消费者不要求两底、规范最小支、g=1 或特定 alpha 模板。用于反设 NC3 时，真实 g、alpha、全部完整源、孤立一次 3 以及实际 Psi 的三条恢复仍然保留。没有辅助输入被称作 NC3，也没有下降。新数字 a,b,c 不是旧源块 a,b 或 alpha 中的 c；`z_d,w_d` 不是旧规范 z,w。本轮的二次判别式只属于 `AT^2+BT+1`，不是 Disc(Psi)。数字余式、实际 Psi、恢复 P_rho 和第三轮 F_h 是不同对象。

### PLUS128：二倍平方的正侧主导完整源

设 m 为正奇整数，p 为奇素数，e>=1，P=p^e，gcd(m,p)=1。若

    P>=128m^3，X=mP+1，n=2X^2，

则原行的全部合法 j 都满足 Common3。

不限制 X+1 的素数个数或三槽分配，不要求 omega(t3)=2。m,p,e,n 均不设上界。P 是 X-1=mP 及 n-2 中的完整原 p 幂。

### Q2DIG：较低门槛的非分裂正三位族

设 A,B 为正整数，A+B 偶，p 奇素数，e>=1，P=p^e，p 不整除 B。记

    K0=A+B^2，T0=16A K0(A+B+1)，Delta_dig=B^2-4A。

若 P>=T0，且 Delta_dig 不是正整数平方，则

    n=AP^2+BP+2

的全部合法 j 满足 Common3。Delta_dig=0 或负值也包括。

### Q2ALL：接完整第二源后不再限制判别式

保留 Q2DIG 的整数、奇偶与完整源假设，但不限制 Delta_dig。若

    P>=64A^2(A+B^2)^3，

则同一正三位行的全部合法 j 都满足 Common3。

Q2ALL 的分裂零支使用已冻结的 `NC3 => 4|n`，按原 Overview §3 的作者级必要前置采用，不在本轮重证。PLUS128、Q2DIG 不需要这个额外前置。三个消费者的交集只计一次。

## 1. 原源与完整进位：必要方向及见证回传

对任意素数 l、正整数 r，定义同一原输入上的进位项

    c_(l,r)=floor(n/l^r)-floor(j/l^r)-floor(k/l^r)。

它是 0 或 1。由阶乘中 l^r 倍数的计数，

    v_l C(n,j)=sum_(r>=1) c_(l,r)。

故一个正项已足以给 l|C(n,j)。若 l 也是 C(n,3) 的素因子，NC3 就要求其每一层都无进位。

### 1.1 完整第一源

本轮各行 n 偶，所以 N=n-1 奇。令真实 lambda=3 当且仅当 v3(N)=1，否则为 1。N/lambda 中每个完整 l^r 都保留原指数；l=3 时 r>=2。因为 n、n-2 是模 l 单位，

    v_l C(n,3)=r-v_l(6)>0。

又 n mod l^r=1。NC3 下无进位要求 `j mod l^r` 是 0 或 1，于是

    N/lambda | j(j-1)，等价 N | lambda*j(j-1)。       (FW)

这是 NC3 的必要条件，不能反向认定 NC3。

若 FW 失败，选择一个未整除 j(j-1) 的完整源 l^r；同一原输入在 l^r 层发生进位，l 就是共同见证。高次 3 幂没有减层，唯一剥离项是真实孤立一次 3。

### 1.2 本轮选定的完整 p 源

Q2DIG/Q2ALL 有 n-2=P(AP+B)，p 不整除 B，故 v_p(n-2)=e。PLUS128 有 n-2=2mP(mP+2)，p 不整除 m，故同样恰为 e。

p>=5 时 p|C(n,3)。p=3 时只有 e=1 可能被分母取消；本轮各门槛使 P 至少为 96，故这一例外不在声明域，实际 e>=2。于是 p=3 的完整高幂也合法。

P^2 在下文只是原 p 的更高进位测试层，不是擅自扩大的原源除数。

## 2. 同一 j 的正向数字盒

考虑 `n=AP^2+BP+2`，假设 `P>A+B+2`。若原 p 在 P、P^2 两层均无进位，则

    j=aP^2+bP+c，
    0<=a<=floor(A/2)，0<=b<=B，c∈{0,1,2}。          (BOX)

证明：n mod P=2 给 c<=2。由于 B<P，n mod P^2=BP+2，下一层无进位给 b<=B。再由原合法区间，

    j/P^2 <= A/2+B/(2P)+1/P^2 < A/2+1/2，

得到 a<=floor(A/2)。同时 n<P^3，未隐藏任何更高 P 位。

这只是由原素数 p 的合法进位条件作分组，不假定块内各 p 位可以任意独立选择。

各门槛都保证 P>A+B+2。PLUS128 对应 A=2m^2、B=4m，`128m^3>2m^2+4m+2`；Q2DIG 的 T0 也严格大于 A+B+2；Q2ALL 的门槛更高，见 §6。

## 3. 第一源的精确线性余式

令 `N=AP^2+BP+1`，使用同一 j 的 BOX，定义

    u_d=Ab-Ba，w_d=Ac-a，
    G=(u_d P+w_d)(u_d P+w_d-A)。

恒等式

    Aj=aN+u_d P+w_d，
    A(j-1)=aN+u_d P+w_d-A

给出 `G≡A^2 j(j-1) mod N`。因此 FW 推出 `N|lambda G`。

再定义

    R_d=A u_d(2w_d-A)-B u_d^2，
    S_d=A w_d(w_d-A)-u_d^2。

直接展开得到

    A G-u_d^2 N=R_d P+S_d。                        (REM)

所以 `N|lambda(R_d P+S_d)`。这是完整第一源的代数后果，不是另一个独立恢复条件。

## 4. Q2DIG 门槛强制余式恒等为零

BOX 给

    |u_d|<=AB，-A/2<=w_d<=2A，
    |2w_d-A|<=3A，|w_d(w_d-A)|<=2A^2。

最后一式可直接在 `-1/2<=w_d/A<=2` 上检查 `t(t-1)` 的范围。因而

    |R_d|<=A^2 B(3A+B^2)<=3A^2 B K0，
    |S_d|<=A^2(2A+B^2)<=2A^2 K0。

lambda<=3，所以

    |lambda(R_d P+S_d)|<=9A^2 B K0 P+6A^2 K0 < AP^2 < N。  (SMALL)

严格不等式的全域证明是：P>=T0 给

    P-9ABK0>=AK0(16A+7B+16)，

从而

    AP^2-9A^2BK0P-6A^2K0
      >=A^2K0[P(16A+7B+16)-6]>0。

SMALL 与整除联立，得到 R_d P+S_d=0。又

    P>=T0>2A^2K0>=|S_d|。

若 R_d 是非零整数，就有 `P<=|R_d|P=|S_d|`，矛盾。因此

    R_d=S_d=0。                                   (ZERO)

全程 A,B,P,j 都没有扫描或预设绝对上界。

## 5. 零截面的完整分类：证明 Q2DIG

若 u_d=0，S_d=0 给 w_d=0 或 A。结合 BOX，前者只可能 a=b=c=0，即 j=0；后者只可能 a=b=0,c=1，即 j=1。两者都不合法。

若 u_d≠0，由 R_d=0 得

    A(2w_d-A)=B u_d。

将它与 S_d=0 联立，得到精确关系

    (B^2-4A)u_d^2=A^4。                           (SPLIT)

故 Delta_dig>0，且其平方根 A^2/|u_d| 有理。整数的有理平方根必为整数：把平方根写成既约 r/s，s^2|r^2 迫使 s=1。因此 Delta_dig 必是正整数平方。

Q2DIG 正好排除这一情形，故所有原 NC3 输入均矛盾，整行闭合。

## 6. 完整第二源排空分裂支：证明 Q2ALL

本节反设 NC3，并采用冻结必要条件 4|n。令

    L=AP+B，n-2=PL，
    mu=3 当且仅当 v3((n-2)/2)=1，否则 mu=1。

由于 v2(n-2)=1，完整第二源为 `(n-2)/(2mu)`。其 NC3 必要窗口推出

    L | 2mu*j(j-1)(j-2)。                         (SW)

这里的 2 与 mu 只恢复实际小部，任何高次 3 幂仍完整保留。

### 6.1 更高统一门槛先接上 ZERO

取 `P>=64A^2K0^3`。因 `K0>=A+B>=2`，有 `A+B+1<=2K0`，故

    T0=16AK0(A+B+1)<=32AK0^2<64A^2K0^3。

因此 §2–4 原封不动成立，仍有 R_d=S_d=0。u_d=0 的非法 j 已排，只需处理 SPLIT。

### 6.2 同一第二源的固定余数

定义 `r_c=A^2c-Bu_d`。有精确恒等式

    A^2j-r_c=(AP+B)[a(AP-B)+Ab]。

故由 SW 得

    L | 2mu * r_c(r_c-A^2)(r_c-2A^2)。            (SW-REM)

对 s∈{0,1,2}，

    |r_c-A^2s|=|A^2(c-s)-Bu_d|
       <=2A^2+AB^2<=2AK0。

因此 SW-REM 右端绝对值至多

    6*(2AK0)^3=48A^3K0^3。

但

    L=AP+B>=64A^3K0^3+B>48A^3K0^3。

只能有 `r_c(r_c-A^2)(r_c-2A^2)=0`。这也是全参数严格小量论证，没有固定系数底部遗漏。

### 6.3 全部零分支恰落入 n≡2 mod4

SPLIT 已给 `Delta_dig=d^2>0`，d 正整数，并且

    |u_d|=A^2/d，0<d<B。

若某个因子为零，即 `r_c=A^2s`，则

    c-s=B u_d/A^2=±B/d。

左端是绝对值至多 2 的整数，而 B/d>1。因此只能

    B/d=2，B=2d，A=3d^2/4。

A 整数迫使 d=2t。于是 `A=3t^2,B=4t`。A+B 偶又迫使 t 偶，记 t=2r，得到

    A=12r^2，B=8r，n=12r^2P^2+8rP+2≡2 (mod4)。

这与本节同一原 NC3 输入的 4|n 矛盾。

所有分裂零分支至此排空。Q2ALL 不需要判别式限制；代价是显式保留更高门槛及冻结 4|n 前置。不能把这一结论误写成 Q2DIG 原门槛下也无条件允许分裂。

## 7. 利用系数公因子把二倍平方门槛降到立方：PLUS128

现在 `A=2m^2,B=4m`，m 奇正，X=mP+1 偶。`N=2X^2-1` 奇；模 3 时 X^2 为 0 或 1，N 为 2 或 1，故真实 lambda=1，完整第一源就是 `N|j(j-1)`。

BOX 为

    0<=a<=m^2，0<=b<=4m，c∈{0,1,2}。

定义本节局部数字余量

    z_d=mb-2a，w_d=2m^2c-a，
    R_d=4m z_d(w_d-m^2-2z_d)，
    S_d=w_d(w_d-2m^2)-2z_d^2。

比 REM 更强的恒等式是

    (2m z_d P+w_d)(2m z_d P+w_d-2m^2)
       -2z_d^2 N = R_d P+S_d。                  (REM-PLUS)

左侧乘积模 N 等于 `(2m^2)^2j(j-1)`，所以 `N|R_dP+S_d`，没有附加分母问题。

数字盒给

    |z_d|<=4m^2，|w_d|<=4m^2，
    |w_d-m^2|<=3m^2，|w_d-2m^2|<=3m^2。

故有刻意不优化常数的界

    |R_d|<=176m^5，|S_d|<=44m^4。

若 P>=128m^3，则

    2m^2P^2>=256m^5P>176m^5P+44m^4，

因为 `80m^5P>44m^4`。因此余式绝对值严格小于 N，得到 `R_dP+S_d=0`。

R_d 非零时是 4m 的倍数，故

    P<=|S_d|/(4m)<=11m^3，

与门槛矛盾。于是 R_d=S_d=0。

全部零支如下：

- z_d=0 时 w_d=0 或 2m^2，只给 j=0 或 1；
- z_d≠0 时 R_d=0 给 `w_d=m^2+2z_d`，代入 S_d=0 得 `2z_d^2=m^4`，因 m 奇而矛盾。

PLUS128 证毕。证明没有使用 X+1 的分解、两槽条件或 omega(t3)，所以真实三槽和任意多素数支持均被包括。

## 8. 返回原题，未破坏任何真实接口

对声明域中的任一原合法 j：

1. 若 P 或 P^2 层有进位，原素数 p 就是共同见证；
2. 否则进入 BOX。PLUS128/Q2DIG 证明完整第一源必须失败，由 §1.1 得同一原输入的共同源素数；
3. Q2ALL 在非分裂域使用同一出口，在分裂域再使用完整第二源，最终反设矛盾。其特殊系数零族由已冻结的 NC3=>4|n 退出。

PLUS128 中第一源没有 3，第二种见证至少为 5；第一种仍允许 p=3,e>=2。Q2DIG/Q2ALL 的第一、第二源中出现高次 3 幂时也保留完整指数。

不使用 alpha、真实 g、实际 Psi 或可约 P_rho 分类，不等于删除这些条件。反设 NC3 的一个较弱必要子系统已经矛盾，当然足以排除完整 NC3。没有改写原 n,j，没有把辅助商当新输入，没有把必要条件反向使用。

取

的全部合法 j 的 Common3，不枚举 j。

### 9.1 与旧 TS-ROW 的选源方向准确比较

新源在 X-1。它的对侧完整分解为

    X+1=3*499*1163*2657*155377*13455809771。

各因子均通过确定性素性证书；3 的真实指数是 1，剥离后有五个不同底。这表明本轮从 X-1 选源时不需要对侧两底。

**旧 TS-ROW 的实际方向不同：它从 X+1 选主导源，对侧是 X-1。** 在本行，其对侧两底条件成立，失败的是主导门槛。X+1 最大完整素数幂只有

    P_old=13455809771，
    m_old=(X+1)/P_old=718753216752579，d3=1，
    64*m_old^3=23763990938074386300083076979621085959283234496>P_old。

且 `P_old/m_old^3=P_old^4/(X+1)^3` 随选定源大小严格增加，所以更小的 X+1 源也都失败。上述原方向检查在行证书中逐项验证。

这不是对全部其他历史消费者的净差审计，不能声称它们都不覆盖本行。

### 9.2 递归素性证书为何是确定性的

对 t>2，完整分解 t-1 为递归已证素数幂。证书给 g，使

    g^(t-1)=1 mod t，
    gcd(g^((t-1)/l)-1,t)=1 对每个 l|t-1 的素数。

任取素数 r|t，g 模 r 的阶含 t-1 中每个素数的完整指数，否则某个上述 gcd 不会为 1。因此 t-1 整除 r-1。r<=t 迫使 r=t，故 t 为素数；递归基例为 2。

第二检查器对小数试除，对大数只取 t-1 的已证因子块 F，满足 F^2>t。相同阶条件使每个素因子 r|t 都满足 F|r-1，因此 r>sqrt(t)，不可能是合数 t 的全部素因子。它只需部分因子块，算法与完整阶检查不同。

## 10. 失败外壳与为什么第二源不可省略

### 10.1 通用分裂族通过第一源和原 p 的全部无进位

对任意素数 P>8，令

    A=8，B=6，n=8P^2+6P+2，j=4P+2。

有 `N=(4P+1)(2P+1)` 和 `j(j-1)=2N`。原 p=P 的基 P 数字分别为 n=(8,6,2)、j=(0,4,2)、k=(8,2,0)，全部无进位。非平凡余式零支为 u_d=32,w_d=16，Delta_dig=4。

它不是 NC3：4P+3 有某个素因子 l>=5，而 n≡2、j≡-1 mod l，直接产生共同见证。4P+3 不会是纯 3 幂：若 `4P+3=3^a`，则 a 奇且 a>=3，迫使 3|P，和 P>8 素数矛盾。

诊断 P=101 给 n=82216,j=406,g=2,alpha=41108；原始回查的共同素数有 11、37。

这个无界整数外壳精确说明不能只删去 Q2DIG 的判别式条件。Q2ALL 正是额外使用完整第二源、冻结 4|n 和更高门槛修复它。不能倒推较低门槛也已经在分裂域闭合。

### 10.2 H_minus 原路线未闭合

继续使用过原 p 的完整商估值

    v_p C(n,j)=v_p C(Q*nu,Q^2+nu*v)，

但没有证明其在全部真实 H_minus 输入中必为正。本轮不登记任何 H_minus 新削减。

精确实代数外壳取 h=1033,Q=1067089，令 y 是 F_h(y)=-h/Q^3 的高侧根，再由原数值关系定义 x,P,nu,v,n,sigma,tau。它满足实数核心方程、P>4Q、n<Q^4，形式 Q^3/P^2 两层差都为 0。

检查器以有理隔离区间证明 `34314295<nu<34314296`，故它明确不是整数原输入。P 也不是一个已经恢复的真正原素数幂。这只反驳实数相位/大小条件独自强迫进位的快捷路线，不反驳带全部整数、alpha 和完整源条件的目标。详见 FAILURES 和 real_shell.json。

## 11. 证书、插值与有限回归各承担什么

检查器 A 用标准库稀疏多项式乘法重建六个恒等式和全域不等式。检查器 B 不导入 A，用有显式次数上界的张量网格核对恒等式：若多项式在第 i 个变量的次数至多 d_i，并在每个变量各 d_i+1 个不同值的笛卡尔积上全为零，则依次应用一元根数界可知恒等为零。这些是符号恒等式证书，不是扫描原 n,j。

数字盒归一化为 a=m^2*s、b=4m*t，s,t∈[0,1]，c=0,1,2。证书给出 `176±R_d/m^5`、`44±S_d/m^4` 的二次伯恩斯坦系数，全部非负，因基函数非负而覆盖整个实盒。A 验证单项式到伯恩斯坦的系数变换，B 在定次数有理网格上独立重建。§7 另有不依赖这些证书的直接绝对值界。

全部 181 个正移位系数、108 个盒系数、33 个递归素性节点已检查；18 项坏证书或非法作用域被拒绝。重新生成四份证书与冻结版本字节一致。

259 个原始二项式 gcd、33344 个专用数字盒和 71 个非分裂通用数字盒只是回归。新增分裂 Q2ALL 回归中，A=8,B=6 保留了一个第一窗口候选，再由第二窗口排掉；特殊 A=12,B=8 由 n mod4=2 退出。有限测试从未代替无限域证明。

## 12. 真实边界与剩余

PLUS128、Q2DIG、Q2ALL 均在各自声明域内完成整个原行，不留待枚举底部。但本轮没有闭合完整 i3，没有反例，没有一般绝对高度，没有 NC3 保持下降，没有全题有限化。

仍开放：H_minus 中 h,Q,P,nu,v,D,R_*；负向 X=mP-1 不加冻结额外槽前提的域；正向所有源低于门槛的域；二倍平方一般行、两底 low/low、一般多槽及其余 i3。R7 仍为 {3,4,5,6,7,8,9}。

本轮明确完成原方向 TS-ROW 在 n=2^167 的门槛比对，但未完成相对全部历史消费者的净差审计。作者纸面和同作者第二算法不是外部独立审稿；Q2ALL 的 NC3=>4|n 仍保持冻结作者前置等级。
