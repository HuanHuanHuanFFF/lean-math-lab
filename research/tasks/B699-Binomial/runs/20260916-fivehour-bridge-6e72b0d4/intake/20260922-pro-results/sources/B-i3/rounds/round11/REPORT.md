# REPORT — B / i3 第十一轮：SEPTIC-ALL

## 最强新增结论

设 `f∈Z[X]` 的系数非负，`f(0)=2`，`deg f=7`，记 `H=f(1)`；令 `T=p^e` 为奇素数幂。若

```text
T ≥ [2(H+2)]^18
```

且 `n=f(T)` 为偶数，则该原行的全部合法

```text
4 ≤ j ≤ floor(n/2)
```

都满足 Common3：存在同一个奇素数同时整除 `C(n,3)` 与 `C(n,j)`。

这关闭第十轮交接指定的七次严格平衡门。没有规范例外、指数方程残支或有限末端。

对 `n≡2 (mod4)` 的回传继续采用冻结前置 `NC3⇒4|n`；本轮没有重验该旧链。直接声明 `4|n` 时，本包给出完整七次新链。

## 本轮真正减少的未知域

第七轮已将大进制第一源的两个完整分配块压到

```text
d/3 < block degree < 2d/3.
```

在 `d=7` 时只可能是 `3+4`。本轮证明：选择三次块为 `U` 后，所有端点低次数边界都不可能；真正内部支的第二源商 `R` 恰为二次，而二次商的全部完整槽分配均退出：

1. 整个二次商进入一个槽；
2. 两个不同有理线性因子进入两个不同槽。

第一类一度留下一个正系数规范族，但原完整 `7` 源比规范端点多出整整两层，故整族退出。第二类精确消元为三个有理参数三次式；它们模 `13` 都无根，因此没有有理解。

系数、奇素数底和指数均可无界。门槛以下的七次行仍随系数增长，不是有限底部。

## 新的可复用结构

从原第一逆关系与第二源身份可推出新的二阶同余

```text
U^2 | W^3 + R - 2 U W^2.
```

它比只保留 `R≡−W^3 (mod U)` 更强，并且不要求 `U` 平方自由。本轮两类二次商分类均用到它。
