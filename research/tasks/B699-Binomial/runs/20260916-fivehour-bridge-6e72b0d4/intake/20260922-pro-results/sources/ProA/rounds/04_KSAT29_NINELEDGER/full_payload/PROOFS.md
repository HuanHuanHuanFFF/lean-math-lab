# PROOFS

## 1. KSAT29 的有限化

设 `q=29`，`D=2q=58`，`e=q=29`，六行 `r=3,…,8` 全部普通容量饱和，因此每行普通重数和均为29，所有特化根均来自该行真实源值。

首一式的 `X^(q-1)` 根和 `S(N)` 次数≤2。第3、4、5行决定 S，故第6、7、8行根和被唯一确定。
`X^(q-2)` 的二阶对称和次数≤4，六行值满足五阶差分为0。

假设反面 `κ4=κ6=κ8=0`。对每条源直线 `ell_t`，非对角源贡献普通阶 m；对角源因 κ=0，在该切线方向贡献至少2m。线上总贡献若严格大于58，则 `ell_t|H`，与不可约矛盾。

同一 κ=0 还给对角吹起后的第二份 `choose(m,2)` 费用，因此
`Σ choose(m_P,2)+Σ_diag choose(m_diag,2) ≤ (q-1)^2=784`。
这里使用上一轮已经登记的加权平面亏格输入；本轮没有提高该出版输入的证据等级。

若 H 在代数闭包可约，Galois 共轭绝对因子具有相同 X 次数，所以每个绝对因子的 X 次数≤14。
冻结 SAT≤14 的复系数扩张强迫其含一个有理 `ell_t`，与 H 的 Q-不可约性矛盾。因此当前 H 绝对不可约，可以合法使用上述亏格预算。

完整整数根门枚举结果：
`triples=4,424,902; pairs=770,922,972; root=75,369,354; line=401,547; z=401,545; genus=153`。
最终只剩153个真实普通重数配置。

## 2. 153 个完整 jet 系统

固定六行特化后，仍使用
`H=H0+WQ`, `W=∏_{r=3}^8(N-r)`, `Q∈B_52`。
参数数为 `(q-2)^2=729`；加首一常数列后齐次矩阵共有730列。

每个非对角源加入全部 `i≥1, i+j<m` 的普通 jet；三个对角源在 κ=0 假设下加入全部 `i≥1, i+2j<2m` 的切向 jet。
发现器对153个配置均找到730个独立行；最终局部卷积验收器重新构造所选矩阵。

- 模32749：153/153 个730阶所选子式非零；
- 模65521：153/153 再次非零；
- 根门由两个独立编译的同一数学算法版本生成并逐字节一致。

故不存在有理首一解，KSAT29 成立。

## 3. 九分量账本回代

零余量泛型签名中，原 `free_degree_ge29` 被安全拆为：

- `q=29` 饱和：必须支付至少一个对角 κ 单位，X次数29；
- `q≥30`：暂不收源费用，X次数至少30。

其它 KNEAR16–24、KSAT25–28、TRIPLE45、GAMMA5/TAIL567、真实 B22/S/L 签名和 TRACE 保持上一轮接口。

对全部2035个竖直状态重新判九分量：
- E0 状态使用同一状态的真实特殊签名、TRACE 与泛型最小 X 费用，剩130个必要状态；
- E>0 时 TRACE 不合法使用；显式放回正余量因子 A（每个至少 X次数3并消费至少1单位E），495个正E状态中仅2个仍容许九分量，均 E=1。

这是必要条件放松的完备枚举，不声称这些状态可由实际 G 实现。

## 4. double5 路线失败边界

在同一账本中进一步删除全部 `double5` 泛型签名，相当于假设整个 q=5 双缺重类别不存在，严格强于任何只给它增加位置/切向费用的结论。
结果仍为：
- E0 九分量状态 122；
- E>0 九分量状态 2。

所以“只继续加强 double5”不能把9降到8。
