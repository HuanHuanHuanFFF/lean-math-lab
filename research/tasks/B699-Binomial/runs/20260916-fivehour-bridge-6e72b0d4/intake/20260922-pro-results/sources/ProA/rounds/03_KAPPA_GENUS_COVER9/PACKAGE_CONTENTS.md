# 压缩包内容

- REPORT / PROOFS：主结论COVER9、全部新定理量词、亏格与有限证书完整推导。
- FAILURE_BOUNDARIES / HANDOFF / SESSION_STATE：零κ适用边界、非EDGE9、九分量下一门。
- SOURCE_ADOPTION / SOURCE_MANIFEST：旧ZIP固定哈希、采用接口、出版输入与未复验部分。
- code：离线接收器、独立E2枚举、局部卷积子式、低次三缺重、全状态签名账本与九分量边界验证。
- certificates：31批完整根门及20457个选定子式、低次有理残余空间和九分量放松模型。
- sources：两个小型冻结输入；最终2035状态不是由旧37表预筛。
- discovery：发现代码、实际日志、分阶段条件账本；其中脚本的旧绝对路径仅为历史发现记录，不是最终重放依赖。
- verification/author：完整实际主接收日志、65521交叉值、2035状态收据、负面测试及补充边界收据。
- verification/environment.json：本轮容器环境快照，非永久机器规格。
- OMITTED_REBUILDABLES：重复根门、可重建二进制等未再次装包的字节哈希，不是缺失主证据。
- MANIFEST.sha256：包内其余全部文件哈希。

作者原receipt与添加显式九分量检查后的final_author_receipt均保留。干净解压重放统一执行最终code；
实际退出码、ZIP哈希和确定性输出对照在包外CLEAN_REPLAY_RECEIPT。
