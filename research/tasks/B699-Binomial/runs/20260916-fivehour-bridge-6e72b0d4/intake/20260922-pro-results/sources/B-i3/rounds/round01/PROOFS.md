## 1. 基本奇偶与 `v<Q`

### Lemma 1.1 — `v<Q`

由

```text
P=Q+hv,
hQ=P+2ν
```

消去 `P`：

```text
hQ = Q+hv+2ν,
h(Q-v)=Q+2ν>0.
```

`h>0`，故

```text
D:=Q-v>0.
```

所以 `0<v<Q`。这是同输入上的等价代数后果，不是下降到新的 NC3 输入。

### Lemma 1.2 — 精确 2 部进入 `v`

冻结最小支中 `h` 为正奇数；当前 `Q` 为奇素数。`P,Q` 均奇，而

```text
P-Q=hv
```

为偶数，故 `v` 为偶数；于是 `D=Q-v` 为奇数。

又真实 `μ=1`、`ν=2H`。在该支中 `K=(n-2)/2=PQH` 为奇数，故 `H` 奇，因此

```text
v2(ν)=1.
```

置

```text
m := (Q³-1)/v = ν²-hQ².
```

`ν²` 为 4 的倍数，`hQ²` 为奇数，因此 `m` 为奇数。于是 `Q³-1=v m` 给出

```text
v2(v)=v2(Q³-1)=v2(Q-1),
```

最后一步因 `Q` 奇且 `Q²+Q+1` 为奇数。

**结论：** `Q-1` 的完整 2 部全部进入 `v`，没有在 `m` 中留下 2。

## 2. 非酉分配的准确异常集合

### Lemma 2.1 — `gcd(v,m)` 只可落在 `h²−6h+1`

令

```text
d := gcd(v,m).
```

模 `d`：由 `P=Q+hv` 得 `P≡Q`。由 `hQ=P+2ν` 得

```text
2ν ≡ (h-1)Q  (mod d).
```

又 `d|m=ν²-hQ²`，故

```text
0 ≡ 4m
  ≡ (h-1)²Q²-4hQ²
  = (h²-6h+1)Q²            (mod d).
```

由 `d|v` 与 `gcd(v,Q)=1`，有 `gcd(d,Q)=1`，所以

```text
gcd(v,m) | h²-6h+1.       (2.1)
```

这是本轮因子分配路线的关键合法替代；没有假定 `v` 是 `Q³-1` 的酉因子。

### Corollary 2.2 — S-酉分配

设素数 `ℓ∤h²−6h+1`。若 `ℓ^e || Q³-1`，则由 (2.1) 不可能同时 `ℓ|v` 与 `ℓ|m`，所以完整 `ℓ^e` 必全部进入 `v` 或全部进入 `m`。

因此非酉共享只可能发生在有限（但随 `h` 变化）的异常素数集合

```text
S_h = { ℓ : ℓ | h²-6h+1 }.
```

若奇素数 `ℓ|gcd(v,m)`，则 `(h-3)²≡8 (mod ℓ)`；特别在 `ℓ∤2` 时，2 必为模 `ℓ` 的平方，故 `ℓ≡±1 (mod 8)`。本推论本轮未进一步用于闭合。

## 3. 欧几里得重编码

### Lemma 3.1 — `v | D³−1`

由 `D=Q-v`，有 `Q≡D (mod v)`。而 `v|Q³-1`，故

```text
v | D³-1.
```

定义新的**同输入辅助共因子**

```text
R_* := (D³-1)/v ∈ Z_{>0}.
```

这里 `R_*` 不是原完整分配中的 `R=q^r`，也不是新的 source；只是 `D³-1` 的余因子。

### Lemma 3.2 — `m` 的精确欧几里得展开

因 `Q=D+v`，有恒等式

```text
Q³-1 = v(Q²+DQ+D²) + (D³-1).
```

除以 `v`：

```text
m = Q² + DQ + D² + R_*.   (3.1)
```

这使 `Q³-1=v m` 的大共因子与一个更小底 `D=Q-v` 的立方余数精确连接，但本轮不把它误称为保持 NC3 的下降。

## 4. 精确平方恢复

### Lemma 4.1 — Pell-square 型恒等式

定义

```text
W := Dν-Q².
```

则

```text
W² = Q²m + 2Q-v = Q²m+Q+D.     (4.1)
```

**证明。**

从 `m=ν²-hQ²` 得

```text
W²-Q²m
 = (D²-Q²)ν² - 2DνQ² + (1+h)Q⁴.
```

由于 `D=Q-v`，`D²-Q²=-v(2Q-v)`；又 `vν²=PQ²-1`，故

```text
W²-Q²m
 = (2Q-v)
   + Q²[-(2Q-v)P - 2Dν + (1+h)Q²].
```

最后一个方括号为 0。确实，用 `P=Q+hv`、`2ν=hD-Q`：

- 非 `h` 项：`-(2Q-v)Q + Q(Q-v)+Q²=0`；
- `h` 项：

  ```text
  -h[v(2Q-v)+(Q-v)²-Q²]=0.
  ```

故 `W²-Q²m=2Q-v=Q+D`，证毕。

这是原最小支的派生恒等式，**不是新的独立方程**。

### Lemma 4.2 — `4|R_*`

由 Lemma 1.2，`ν≡2 (mod4)`；`D,Q` 奇，所以

```text
W=Dν-Q²
```

为奇数，`W²≡1 (mod8)`。

把 (3.1) 代入 (4.1)：

```text
W² = Q²(Q²+DQ+D²+R_*) + Q + D.
```

模 8，奇数平方均为1，得到

```text
1 ≡ 1 + QD + 1 + R_* + Q + D  (mod8),
```

即

```text
R_* ≡ -(Q+1)(D+1)  (mod8).     (4.2)
```

另一方面 Lemma 1.2 给 `v2(v)=v2(Q-1)`；而

```text
R_*=(D³-1)/v,
v2(D³-1)=v2(D-1)
```

（`D²+D+1` 为奇数）。由 `D=(Q-1)-v+1` 且 `v` 与 `Q-1` 有相同精确 2 估值，可先得 `v2(D-1)≥v2(Q-1)+1`，故 `R_*` 至少为偶数。

结合 (4.2)：`Q,D` 均奇，`(Q+1)(D+1)` 至少被4整除，因此 `R_*≡0或4 (mod8)`，即

```text
4 | R_*.
```

于是

```text
D³≡1 (mod4),
D≡1 (mod4).                      (4.3)
```

再由 `4|R_*` 回代估值得到更精确的

```text
v2(D-1) ≥ v2(Q-1)+2.             (4.4)
```

所以当前残域的 2 进形状为一个完整的两级跃迁，而不是固定模数筛。

## 5. 当前下一位宽的线性共因子缺口

这一节才使用最新 9/20 已闭低比值所得的

```text
P≥4Q
```

以及当前 `r=1,b=2` 位宽的

```text
t<Q².
```

### Lemma 5.1 — `h<2Q-4`

由 `t=P+ν` 与 `hQ=P+2ν`：

```text
2t=P+hQ.
```

所以

```text
2Q² > 2t = P+hQ ≥ 4Q+hQ,
```

从而

```text
h < 2Q-4.                        (5.1)
```

### Lemma 5.2 — 平方恢复给 `W>Q²+DQ/2`

由 (3.1)(4.1)：

```text
W² = Q⁴ + DQ³ + D²Q² + R_*Q² + Q + D.
```

而

```text
(Q² + DQ/2)² = Q⁴ + DQ³ + (D²/4)Q².
```

二者差为

```text
(3D²/4 + R_*)Q² + Q + D > 0.
```

另外 `W²>Q⁴`，故 `|W|>Q²`；但 `W=Dν-Q²>-Q²`，所以 `W>Q²`，可以取正平方根比较，得到

```text
W > Q² + DQ/2.                  (5.2)
```

### Lemma 5.3 — `Q` 被 `D²` 从上方控制

由 `hD=Q+2ν` 乘以 `D`，并用 `Dν=W+Q²`：

```text
hD² = QD + 2Dν
     = 2Q² + QD + 2W
     > 4Q² + 2QD.               (5.3)
```

同时 (5.1) 给 `hD²<(2Q-4)D²`。故

```text
(2Q-4)D² > 4Q²+2QD,
(Q-2)D² > 2Q²+QD,
Q(D²-D-2Q) > 2D².               (5.4)
```

因此 `D²-D-2Q>0`。又 (5.4) 右侧给

```text
D²-D-2Q > 2D²/Q > 4,
```

因为前一正性已经给 `D²/Q>2`。左边为整数，所以

```text
D²-D-2Q ≥ 5,
2Q ≤ D²-D-5.                    (5.5)
```

这首先强迫 `D≥5`（也与 `D≡1 mod4` 相容）。

### Theorem 5.4 — `R_*≥2D+10`

由 `v=Q-D` 与 (5.5)：

```text
v ≤ (D²-3D-5)/2.
```

于是

```text
R_*=(D³-1)/v
   ≥ 2(D³-1)/(D²-3D-5)
    = 2D+6 + (28D+28)/(D²-3D-5)
    > 2D+6.                      (5.6)
```

`D≡1 (mod4)`，所以 `2D+6` 是 8 的倍数；而 `R_*` 是 4 的倍数。严格大于这个 8 的倍数的下一个可能 4 倍数至少是

```text
R_* ≥ 2D+10.                    (5.7)
```

**这就是本轮真实无界前沿减少。**

在当前下一位宽的最新最小残域中，不存在任何

```text
R_* < 2D+10.
```

这里 `D` 无界，所以不是有限前缀或固定模数结论。

## 6. 一个固定 `h` 的二元三次式（结构，不计独立前沿）

从

```text
ν=(hD-Q)/2,
D=Q-v,
vν²=PQ²-1,
P=Q+hv
```

消去 `P,ν,D`，得到

```text
4Q³ + (-h²+6h-1)Q²v
     + 2h(h-1)Qv²
     - h²v³ = 4.                (6.1)
```

固定 `h` 时这是一个二元三次 Thue 型方程；但本轮 `h` 自身仍无界，所以 (6.1) **不构成一般有限化**，也没有把固定-h 的求解误写成当前分支闭合。

## 7. 实际内容三次 `Ψ` 的同输入专门化

这一节只采用冻结 B 已证明的实际 `Ψ` 不变量，不把它与恢复三次 `Pρ` 混用。

冻结公式（NC3 必要接口）为

```text
I   = 9Cu/(c²λ),
J_B = 54uδ/(c³λμ),
Δ   = 27u²z/(c⁴λ³μ²),
vp(gcd(I,J_B))=vp(u)  对每个 p≥5.
```

当前最小支中

```text
λ=μ=1,
u=Q,
ξ=2,
ζ=2v,
z=ξζ=4v.
```

### Proposition 7.1 — 去 `2,3` 的 `gcd(I,J_B)` 恰为 `Q`

因 `Q=q^r` 为完整奇素数幂、`q≥5`，且对所有 `p≥5` 有

```text
vp(gcd(I,J_B))=vp(u)=vp(Q),
```

所以从 `gcd(I,J_B)` 去掉全部 2、3 幂后，所得整数恰为

```text
Q.
```

当前下一位宽 `r=1` 时就是 `q¹`。

### Proposition 7.2 — `Disc(Ψ)` 的平方类为 `3v`

代入 `u=Q,z=4v,λ=μ=1`：

```text
Δ = 108 Q² v / c⁴
  = 36 Q²/c⁴ · (3v).
```

前因子是有理平方，所以实际 `Ψ` 的判别式平方类为

```text
3v.
```

因此冻结 B 的二次预解域在这支上精确收缩为

```text
K_B = Q(√(3v)).
```

### Corollary 7.3 — 冻结充分消费者的准确翻译与当前失败点

冻结消费者说：若去 2,3 的 `gcd(I,J_B)` 是整数立方，且 `Δ` 是平方或5倍平方，则原题 Common3 成立。

本支翻译成：

```text
Q 为立方，且 3v 为平方或5倍平方
```

即可直接回传 Common3。

但当前 `r=1,Q=q`，去小素数 gcd 的 `q` 指数为1，不是立方，所以该消费者**本身不能关闭当前下一位宽**。这不是反例；只是说明要继续利用 B 的更一般射线类群必要条件，而不能把旧充分门槛误用。

## 8. Cyclotomic 分配的另一个必要条件

由

```text
Q³-1=(Q-1)(Q²+Q+1)=v m,
0<v<Q,
```

有

```text
(Q²+Q+1)/gcd(v,Q²+Q+1) > Q.
```

这个整数整除 `m`。若其奇素因子 `ℓ∤h`，由 `m=ν²-hQ²` 可知 `h` 必须是模 `ℓ` 的二次剩余。

等价地：若 `ℓ|Q³-1`、`ℓ∤h` 且 `(h/ℓ)=-1`，那么完整 `ℓ`-幂不能进入 `m`，必须完整进入 `v`。结合 `v<Q`，所有这类非剩余完整幂的乘积严格小于 `Q`。

这是真实因子分配约束，但本轮没有把它推进到绝对界或第三底矛盾，因此不计主要前沿减少。

- Sections 1–8 都是在 **同一个原始 `(n,j)`** 的 NC3 必要系统中推导。
