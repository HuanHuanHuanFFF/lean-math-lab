# REPORT — B / i3 第六轮：CUBIC-ALL

2026-09-21；数学执行者 Pro E。本轮不做Lean、不修改仓库。

## 最强新增结论

本轮完整处理了第五轮交接指定的**可约第一数字源的三次零分支**：不再要求f−1不可约。

对任意整数A≥1、B,C≥0，令H=A+B+C+2，T=p^e为奇素数幂。如果

    n=A T³+B T²+C T+2 为偶数，
    T≥(2(H+2))^10，

则该原行的全部4≤j≤⌊n/2⌋满足Common3。称为 **CUBIC-ALL**。

A、B、C、p、e、n均不设上限；B或C允许为零；不限制其他源的底数和槽数，没有待排有限底部。4|n域的证明完全展开；n≡2 mod4的既有出口采用Overview的NC3⇒4|n，不重复计作新覆盖。

## 决定性机制不是“所有结式非零”

本轮先精确提升两个必要窗口为Q[X]中的

    f−1|J(J−1)，f−2|J(J−1)(J−2)。

两式确实存在同时成立的非平凡正整数系数族，不能跳过零支。完整三次分类只有一个形式族：

    n=216u³+162u²+27u+2，
    τ=(3u+2)(4u+1)(6u+1)，
    σ=4u(36u²+21u+1)，u∈Z_{>0}。

σ、τ仍是原j,k。它满足形式两源，但在原整数恢复中固定损失三层3幂。令E=v3(n−2)，则E≥4且

    v3(τ(τ−1)(τ−2))=E−3。

原3在3^(E−2)、3^(E−1)、3^E连续三层进位，因此

    v3 C(n,j)≥3，v3 C(n,3)=E−1>0。

共同见证正是允许的p=3。此处真实μ=1；完整3^E不能错当孤立一次3。故唯一形式零支也全部退出，三次整行消费者完整闭合。

## 两项任意次数扩展

### PRIMARY-2/3

设f系数非负、f(0)=2、d=degf≥1、H=f(1)、n=f(T)偶，T=p^e奇素数幂，且

    T≥(2(H+2))^(2d+4)。

若f−1有不可约幂因子G^m，满足3m degG>2d，则整行Common3。这允许整个f−1可约。

更准确的必要平衡是：在大进制提升后的两源系统中，第一源分配到两个原端点的完整多项式块次数都必须位于[d/3,2d/3]。这是有条件系统的结构，不是全NC3的无条件次数参数化。

### SPLIT-BLOCK：门槛不随次数与间隔增长

U系数非负、U(0)=1、r=degU≥1；B≥2且存在素数ℓ满足vℓ(B)=1；h>2r。设

    f=1+U(1+BX^h)，H=1+(B+1)U(1)。

若T=p^e奇素数幂、n=f(T)偶，且T≥4B³(H+2)²，则整行Common3。

f−1是两个非恒定因子的乘积，不能直接套第五轮的“整个源不可约”。门槛独立于r、h和内部位置间隔；源的算术素因子数量、对侧槽数不受限制。

显式子族：

    T≥1152(2m+1)²，m≥1，r≥1，h>2r
      ==> n=2+4mT^r+2T^h+8mT^(h+r) 整行Common3。

这组n自动被4整除，不需要旧奇偶出口。固定m=1、T=5^6=15625，即包含全部r≥1、h≥2r+1。系数和可以增长，但固定T不能任意增加U(1)。
