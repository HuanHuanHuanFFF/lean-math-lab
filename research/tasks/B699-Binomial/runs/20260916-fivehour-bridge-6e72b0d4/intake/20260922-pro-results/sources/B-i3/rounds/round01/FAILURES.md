# FAILURES — 本轮失败边界与重试条件

## F1. `v|Q³−1` 不能直接升级成酉因子

**失败命题：** `gcd(v,(Q³−1)/v)=1`。

本轮没有证明它，旧材料也明确禁止这么用。

**正确替代：**

```text
gcd(v,m) | h²-6h+1,
m=(Q³−1)/v.
```

因此只能在 `S_h={p:p|h²−6h+1}` 外得到完整酉分配。由于 `h` 仍无界，`S_h` 自身也会变动；这不足以给 `v,Q` 绝对界。

**值得重试的新增条件：** 若能把 `h²−6h+1` 的 source 支持与 `P,Q`/实际 `Ψ` 分歧集合证明互斥，或统一控制其大素因子，就可能把 S-酉提升为真正强下降。

## F2. Euclid 重编码不是 NC3 保持下降

`D=Q-v<Q` 且 `v|D³−1` 很像欧几里得下降，但目前没有从 `(D,...)` 恢复一个新的合法 `(n',j')` 且保持 NC3/source-window。

所以本轮只把它当同输入坐标。不得写成“Q 下降到 D，故无限下降”。

**重试条件：** 找到保持原 `(n,j)` 的某个单调复杂度，或证明 `R_*` 必重新占据原完整 source 的指定槽，从而在同输入触发 carry；不能仅构造新整数解。

## F3. Pell-square 恒等式本身不闭合

精确有

```text
(Dν-Q²)²=Q²m+Q+D.
```

它很强，但 `D,m,R_*` 都可无界，单独把它识别为 Pell/二次曲线不会自动有限化。

本轮真正的用途是与 `P≥4Q`、`t<Q²` 联立，得到 `R_*≥2D+10`。

**重试条件：** 若能从 source carry 再给 `R_*` 的上界（例如 `<cD` 且 `c<2`，或一个与本轮下界冲突的精确数字区间），即可闭合当前最小支。

## F4. 实际 `Ψ` 的旧充分消费者在当前 `r=1` 卡住

本轮专门化得到：

```text
strip_{2,3}(gcd(I,J_B))=Q,
Disc(Ψ) squareclass = 3v.
```

冻结充分消费者还要求前者为整数立方。当前下一位宽 `r=1,Q=q`，其指数就是1，因此此门槛失败。

这不是 NC3 相容性的证明，更不是反例；只是该**充分消费者**没有覆盖当前支。

**值得重试：** 使用 B 更一般的射线类群必要条件。现在二次预解域已经不再是一般 `K_B`，而是明确 `Q(√(3v))`，且唯一活动完整 `q`-块的指数/分歧形状也已固定得多。

## F5. Zsigmondy / primitive divisor 尚未形成第三 source

`Q²+Q+1` 必有大于 `Q` 的余块进入 `m`，且其中不整除 `h` 的素数要求 `h` 为二次剩余。但“出现 primitive prime”并不自动等于“进入另一个原 source 槽”，更不能直接称为共同见证。

**重试条件：** 必须把 primitive prime 的完整估值送回实际 `N,K,j,j-1,j-2` 分配，或实际 `Ψ` 的分歧/类群约束。

## F6. 固定 `h` 的 Thue 化不能冒充一般有限化

本轮有精确二元三次

```text
4Q³+(-h²+6h-1)Q²v+2h(h-1)Qv²-h²v³=4.
```

固定 `h` 可转 Thue 型问题，但 `h` 本身仍无界。逐个 `h` 求解不能作为本轮一般终点。

## F7. 有限扫描的精确边界

辅助扫描：奇数 `3≤D≤5000`，枚举全部 `v|D³−1`，共 195126 对；没有满足弱 core 的正整数点。两个独立恢复算法一致。

**缺少的真实 NC3 条件：** 这个扫描甚至没有先要求完整 `P,Q` 为合格 source 素数幂、`α=c2^s`、原始 `j/k`、实际 `Ψ`、全部窗口与 carry。因此它只是路线的低高度否证实验。

不能从“未见点”推出一般无解。

## F8. 没有取得的目标

本轮没有：

- 闭合 i=3；
- 找到原题反例；
- 闭合整个最小临界支；
- 给 `Q,h,v,P,ν,g,u,δ,ρ,Q0,θ` 任一旧无界参数统一绝对界；
- 建立 NC3 保持的严格下降；
- 给一般两底/multislot 可执行有限化。

本轮真实贡献是：当前最小下一位宽支的无界低 `R_*` 区域被删，并得到新的完整 2 进与 S-酉分配接口。
