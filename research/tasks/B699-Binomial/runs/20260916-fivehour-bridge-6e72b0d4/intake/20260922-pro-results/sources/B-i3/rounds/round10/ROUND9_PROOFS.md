# PROOFS — B / i3 第九轮：五次最后残域的整数五次幂夹逼

2026-09-21。只研究 i=3；无 Lean、无仓库修改。证据等级：作者纸面证明 + 同作者两个精确检查器。

## 0. 采用前沿

沿用第八轮 QUINTIC-RIGID 的准确必要残域。对非负整数系数五次多项式

    f(X)=A5 X^5+A4 X^4+A3 X^3+A2 X^2+A1 X+2,
    A5>=1, A1,...,A4>=0,

令 H0=f(1)，T=p^e 为奇素数幂，并保留门槛

    T >= [2(H0+2)]^14,
    n=f(T) 为偶数。

第八轮已经证明：如果同一个原输入 (n,j) 是 NC3，那么必进入唯一规范族

    F5(Y)=48Y^5+200Y^4+280Y^3+150Y^2+25Y+2,
    f(X)=F5(10bX),
    y=10bT,
    F5(y)=3*2^S,
    S=7494+7500q, q>=0,

并且同一输入还有 g=24、alpha=2^(S-3)、lambda=mu=1 及第八轮完整恢复。本文不重新证明这些分类，只采用其冻结结论。

本轮目标是排空上述唯一指数方程残域。

## 1. 残指数自动产生一个整数五次幂

由

    S=7494+7500q

得到

    S-4=7490+7500q=5(1498+1500q).

所以

    M=(S-4)/5=1498+1500q

是正整数。令

    X=2^M in Z_{>0}.

因为

    3*2^S = 3*2^4*2^(S-4) = 48*(2^M)^5,

残方程等价于

    F5(y)=48X^5.                                      (1)

这里 X 只是由原指数 S 定义的正整数；没有生成新的 NC 输入，也没有改变原 (n,j)。

更一般地，本节只用到 S≡4 (mod5)。7500 周期的其他信息不再需要。

## 2. F5(y) 严格夹在相邻整数五次幂之间

对任意实数 y>=0，直接展开

    F5(y)-48y^5
      =200y^4+280y^3+150y^2+25y+2 >0.              (2)

另一方面

    48(y+1)^5-F5(y)
      =40y^4+200y^3+330y^2+215y+46 >0.             (3)

所有系数严格为正，因此这是全半轴严格不等式，不是有限 y 扫描。

合并 (2),(3)：

    48y^5 < F5(y) < 48(y+1)^5.                     (4)

在真实残域 y=10bT>0，代入 (1) 并除以48得

    y^5 < X^5 < (y+1)^5.

正实函数 t↦t^5 严格递增，因此

    y < X < y+1.                                    (5)

但 y,X 都是整数，(5) 不可能。

所以第八轮唯一规范残域为空。

## 3. QUINTIC-ALL

结合第八轮完整分类得到：在 GATE5 条件

    f in Z[X]，系数非负，f(0)=2，deg f=5，H0=f(1)，
    T=p^e 为奇素数幂，
    T >= [2(H0+2)]^14，n=f(T) 为偶数，

下，不存在 NC3 输入。因此该原行的每个合法

    4 <= j <= floor(n/2)

都存在同一个奇素数 >=3 同时整除 C(n,3), C(n,j)。

这是整行充分结论；系数、p、e 均可无界。它不要求 f-1 不可约，也不要求任何固定因子次数分配。五次门槛以上没有留下规范例外、指数方程或有限末端。

对 n≡2 (mod4) 的偶数行，仍按第八轮采用的冻结前置 NC3=>4|n 回传；本文没有重新证明该旧链。直接声明 4|n 时，本轮与第八轮五次分类构成完整本轮链。

## 4. 端点与方向检查

1. y=0 也不产生例外：F5(0)=2，不可能等于3*2^S。真实残域本来有 y>0。
2. 严格性不可改成非严格；上下差多项式常数项分别为2和46，均严格正。
3. 本轮只从第八轮必要残域推出矛盾，不把必要条件反向当作 NC3 充分刻画。
4. 实际 Psi、恢复 P_rho、C^2 等对象本轮完全未使用，因此没有混用风险。
5. p=3 端点、完整素数幂、孤立3等全部由第八轮分类的原题接口原样保留；本轮没有删除或改写任何源。

## 5. 为什么这不是固定模数路线

第八轮已记录镜像点可兼容任意预先固定的局部模条件。本轮不增加任何模数。矛盾来自：

- 指数算术进展强迫 2^(S-4) 本身成为整数五次幂；
- F5 的真实阿基米德大小恰严格落在两个相邻整数五次幂之间。

所以它是全局整数大小矛盾，直接避开固定 CRT 镜像失败边界。

## 6. 实际前沿减少

第八轮终点仍有无界 q,y,b,p,e 的唯一 F5 残域。本轮把它整片排空，故：

    五次 GATE5 区域：刚性归约 + 唯一候选  -->  无候选（整行闭合）。

这没有闭合一般 i=3。低于 GATE5 门槛的五次行仍可随系数增长；一般六次及以上平衡分配、H_-、负向三槽、两底 low/low、多底区域仍开放。
