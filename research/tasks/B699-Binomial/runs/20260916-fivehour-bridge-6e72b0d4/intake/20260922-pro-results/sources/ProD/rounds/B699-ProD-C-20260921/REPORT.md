## 2. 精确完整源接口 S

固定同一合法 `(n,j)`，`k=n-j,N=n-1,U=jk/N`，要求 U 为整数，q_r 按 i6 删除完整 2/3/5 部。置 `Z4=(j-2)(k-2)`。

|实际源窗口|精确等价的标量测试|
|---|---|
|q2 全部完整幂|`q2^2 | U^2(U-1)`|
|q3 全部完整幂|`q3 | U(U-1)`|
|q4 全部完整幂|`q4^2 | U^2(U-1)^2 Z4`|
|q5 全部完整幂|`q5 | U(U-1)(2U-3)`|
|q5 全近侧|`q5 | U-1`|

第 2 源额外有精确缺额恒等式

    q2^2/gcd(q2^2,U^2(U-1))=D2^2,
    D2=q2/[gcd(q2,U) gcd(q2,j-1)].

这里的平方不能改成 radical。q4 的 Z4/C² 与 V4 的整数性也只计一次。

**逻辑地位：** 一个测试失败，能从那个原源取得 p>=7 的共同素数；所有测试通过，仍只取得 NC6 必要窗口。第 e+1 层及更高层进位没有自动消失。

`code/source_adapter.py` 接收原输入或精确范数候选，输出 `COMMON6_BY_FAILED_FULL_SOURCE` 或 `SURVIVES_FULL_SOURCES_NOT_NC6`。这是候选接口，不是对无界 n 的有限化。

## 3. 实际间距的完整估值 V

保留真实 RES10 条件、全近侧、完整源幂，以及实际

    U=10g^2z^2, E3E4=d h_D^2, z=d h_D v,
    L3=(3^(a-1)-10g z^2)/(I3 C), Gap=A4-Cr.

令 `c3=v3(g)`。本轮证明

    gcd(g,L3)=3^c3, v3(L3)=c3,
    v2(Gap)=1+2v2(z), v3(Gap)=2+4c3,
    v5(Gap)=4+2v5(z).

粗素数的精度为：

    p>=7, p|g        => vp(Gap)=3vp(g)+2vp(z);
    p|q5，全近侧      => vp(Gap)=0;
    p^e||E3 或 E4    => vp(Gap)=vp(U)-e.

并且

    Delta_r=E_r/gcd(E_r,Gap), r=3,4.

最后一个式子准确说明了方法边界：现有 Delta3、Delta4 与间距的对应端点估值是同一个约束。不能将它们叠加出不存在的新冲突。

**实际效果：** 校正/接入了精度信息；没有证明任何无界参数有绝对上界，没有强迫剩余 p 进入旧支持集合或旧吸收分支。

## 4. 高层方向：精确运输不是 NC6 下降

在一个已经通过完整源层的实际 p^e 上写

    n=r+p^e h, j=b+p^e y, 0<=b<=r.

则 `vp C(n,j)=vp C(h,y)`。但是 p 未必整除 C(h,6)，所以这不是 NC6 的严格下降。包内用 `(192,78),p=11 -> (17,7)` 精确展示同一个原源身份会丢失。

q5 近侧 b=1、`xi=(U-1)/p^e` 时，整数式为

    3y-4xi+p^e[y(h-y)-h xi]=0.

若 `s=vp(eta)`，额外的 s 层反而已经被强迫无进位；源指数仍然是 e。这条式子没有使尚未控制的 h 与 xi 余数自动矛盾。

## 5. 失败结果不是反例

### F31：任意预定深度的无界弱族

对任意 `1<=e<H`，本轮明确构造一条无界原整数族：

- 真实 alpha=3^a、gcd、正确 B 尾、合法偶数 j、8g^4<n；
- q5 含真实完整 31^e，原近侧槽为 1；前 H 层全部无进位；
- beta/gamma 两侧至少五位，DEN± 不触发，范数在 31^H 上相容；
- 第一源 `n-1|jk` **恒失败**。

一个短展示是

    a=557+9300m, g=765510,
    n=g*3^a, j=g*(3^a-7)/2, m>=0.

这条展示的 e=1,H=2；更大的 H 必须使用一般构造，不能把同一个样本外推到无限层。

它没有全局整数 z，也没有全部 q5 全近侧、真实 L 商和 p∤L4L7。因此它只否证列明条件下的局部捷径，不否证原完整恢复路线。

### 真实范数弱输入

包内 a=132,z=1 的精确大整数输入通过原第一源、真实 gcd、W10、alpha、91/88 个非零三进制位与 DEN± 检查，但第 2—5 源失败；其 8g^4<n 不成立、C=A4=1、q5 不全近侧。真实共同素数 7 的源/目标估值为 1/69。

这保证报告没有把一个带全局缺口的模型冒充当前 NC6 或原题反例。

### 其他记录
