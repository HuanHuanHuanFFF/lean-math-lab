## 结论与严格账本

本轮完成两个**全参数数对充分消费者**：

- **TC7**：真实 `α=3^a`，任一实际分量 `x∈{β,γ}` 的数字仅位于两个宽度不超过 h 的区间，且 `a≥7h`，则原第一源必失败。

两个定理均保持同一个原 `(n,j)`，可从完整第一源缺额取同一个 `p≥7`，同时证明原 i4、i5、i6。块宽、块内非零位数、位置、指数和 g 不设绝对上界；没有靠有限扫描证明这些结论。

**但本轮尚未认证相对全部历史消费者并集的净差，也未迫使一般真实 RES10 唯一候选进入上述支持。严格登记 `frontier reduction = 0`。** 全近侧、中心较小、低残量、两侧大缺欠的总分支仍未闭合。R7 不变；没有原题反例、绝对有限化或新的原题有限末端。

## 1. 为什么本轮换路

C1 已证明 Gap 在 E3/E4 的精度只是旧缺欠的另一种表达；Overview §3C 又确认数值间距、第三纯 5 幂恢复式的冗余。本轮没有重做该消元。

首攻原本原范数 `δ²+40(n−1)z²=α²` 的乘方恢复。得到明确边界：在原二次阶 `Z[√(−10(n−1))]` 中，`δ+2z√(−10(n−1))` 根本不是普通的非平凡整数幂。这个结论不排除范数解，只否证“纯 3 幂范数自动给出可直接套用的元素乘方”的前提。证明见 PROOFS §6。

随后转到同一第一源的精确商余数，而非任意局部同余根。目标从“通常三进制少数几个非零位”改为“每块内部可以任意密集、宽度同时增长的两个区间”。首个否证检验针对真实商余数及 g 整数性；没有采用丢失第一源的 CRT 弱壳作为主命题反例。

## 2. TC7 的准确量词

固定

    n mod1800∈{1280,1530}, 7≤j≤floor(n/2), k=n−j,
    g=gcd(n,j), α=n/g=3^a, β=j/g, γ=k/g.

若存在 `x∈{β,γ}` 和整数

    h≥1, r≥h, 1≤A,b<3^h, 3∤b, a≥7h,
    x=A·3^r+b,

则

    (n−1) ∤ j(n−j).

因此该数对有同一个 p≥7 同除 `C(n,4), C(n,5), C(n,6), C(n,j)`。

这是两个区间 `[0,h−1]` 与 `[r,r+h−1]` 中的**全部**通常三进制数字支持。A、b 的内部数字任意，r 不必为 h 的倍数，h 也不必整除 a。单个低块另由平方小于 α 的零分支处理。

TC7 不需要 W10、q2…q5、全近侧、C<A4、质量条件或固定 q5 支持。用于当前 RES10 时这些真实条件全部保留，只是证明不需使用它们。注意：由于 `a≥7`，TC7 的纯三幂商在两尾表述中实际上只能命中 B 尾；A 尾 n mod9=2，与 9|n 不相容。不能把这写成 A 尾新增整类闭合。

## 3. 证明的非恒等冲突

若第一源成立，对任一实际分量 x 有旧的、但在本稿自含重建的精确式

    x²=αH+t, H=floor(x²/α)>0,
    t=x² modα>0, gt=x−H.

令 M=3^h。前三种平方位置直接使实际余数 `t>x` 或 H=0。最后靠近顶部的分支，把 `2Ab` 作实际除法

    2Ab=q·3^d+c, d=a−r, 1≤d≤2h.

完整处理 c=0 后，有 c≥1、g≤M−1，并恢复

    3^(a−2d)[(A−gc)3^d−A²]=gb²−b+q.

右边是严格介于 0 和 M³ 之间的正整数；左边是正的 `3^(a−2d)` 倍数，而 `a≥7h` 给 `3^(a−2d)≥M³`。由整数性直接矛盾。

这个矛盾不是再次叠加 Gap、C²/V4 或旧 Δ3/Δ4，也没有提高旧多项式核次数。完整划分及所有零分支见 PROOFS §0–2。

## 4. BL6：对齐分块的强化

对原实际 `α=T^m`，T 可以是任意奇整数，不要求素数或 3 的幂。只要 m≥6，且 β 或 γ 的 T 进制非零块至多两个，原第一源就必失败。

其证明允许两个块内含任意多通常三进制位。`T=3^h,m=6` 是 TC7 的对齐强化，但不能把“6”直接搬到任意非对齐两簇。最末 `m=6,r=4` 的分支单独由

    T²K=gb²−b+q<T³,
    K≥T²−A²≥2T−1

得到矛盾。不是遗漏一个小边界后从样本声称全参数成立。详见 PROOFS §3。

## 5. 完整源与跨指标回传

两尾 `gcd(n−1,30)=1`。定理给整数缺额

    D1=(n−1)/gcd(n−1,j(n−j))>1.

对任一真实素因子 p|D1，取原完整 `p^e||(n−1)`。原 e 层有 `j mod p^e>1=n mod p^e`，所以 p 整除目标二项式。p≥7 大于4、5、6，分母4!、5!、6!均不取消它；同一个 p 因此同时返回三项原目标。同一个 j 的区间对 i4/i5/i6 都合法。

代码返回完整缺额块，不伪称已经分解其中的大整数。**没有升级 i7/i8**：p=7 可能被 i7 分母取消，对 i8 又不够阈值。没有新数对，没有 NC6 下降。

## 6. 与旧消费者的区别及净差缺口

本轮证明一条明确无界原输入族：

    h=29+420u, T=3^h, u≥0,
    g=190, α=T^7, n=190T^7,
    β=(T−1)T^4+(T−2), j=190β.

它具有真实 gcd、正确 B 尾、合法偶数 j、`8g⁴<n`；两侧通常三进制位数分别为 `2h` 和 `5h+1`，均可任意增长。四条整系数 Bézout 恒等式统一界住两个分量的 DEN± 公因子，证明整个族均不触发这两类分母门槛。实际 q5 还含完整一次7，且该层在近侧，所以也不是旧四素数支持域。

这给出了对**明确列出的四位、DEN±、固定 q5 支持**条件的区别，不是对全历史并集的区别。精确检查的种子有 `C=A4=1`，已被旧 CENTER 覆盖；它没有 W10，也没有全部 q5 全近侧。其原共同素数53的源/目标估值为 `1,1,1,16`（分别对应 i4/i5/i6/j）。不能把这个种子或整族包装为当前 NC6 残域的反模型，也不能据它把净覆盖账本改成正数。
