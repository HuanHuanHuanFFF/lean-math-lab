# FAILURES — 第十一轮

## 1. “二次商整块进单槽必然无解”是假的

精确消元确实留下一个正系数规范族

```text
F0(Y)=256Y^7+1568Y^6+3696Y^5+4200Y^4
      +2352Y^3+588Y^2+49Y+2.
```

因此不能只靠 DIFF、模4或形式槽分类宣布单槽为空。真正的退出机制是原完整 `7^{v7(n−2)}` 源：规范端点只吸收了其中少两层。

值得重试的条件：若其他次数的规范族也产生一个固定素数在 `n−2` 中比端点多出统一正层数，可以直接复用这个源缺额机制。

## 2. 只看 `n mod4` 不能排掉正规范族

`F0(y)≡y+2 (mod4)`；当 `y≡2 (mod4)` 时完全兼容 `4|n`。所以旧奇偶出口不能替代完整7源。

## 3. 不能漏掉首项比 `t=0,1`

若直接假设 `0<t<1`，会遗漏一个原端点次数低于7的真实代数可能。本文分别证明：`t=0` 的一次商根会要求槽号 `6`，`t=1` 会要求槽号 `−2`；这些才合法排掉边界。

## 4. `U^2` 同余仍只是必要条件

```text
U^2 | W^3+R−2UW^2
```

来自原逆关系和第二身份，但不能反向恢复所有数字条件或 NC3。包内只用它删除候选；没有把满足该同余的形式点称为原题输入。

## 5. 固定次数闭合不等于完整 i3

SEPTIC-ALL 只处理声明门槛以上的七次非负数字行。门槛以下随系数增长，八次以上、`H_-`、两底 low/low 和一般多底仍无界；本轮没有一般高度、下降或反例。
