# EXPERIMENTS

## 路线选择

- 预期成功：删除 GATE7 下整个七次 `3+4` 无界域。
- 成功后仍无界：门槛以下、八次以上、`H_-`、两底 low/low、多底。
- 首个证伪检查：二次商整块进单槽是否真的为空。

该检查立即发现一个正系数规范族，否证“形式分类即可全空”。随后恢复其原完整7源，得到统一两层缺额并关闭整族。

## 精确计算

1. 单槽：六个 `U^2` 余式系数的精确 Gröbner 消元；三个槽共同只剩同一一参数形状。
2. 原点：四个三次余因子的有限域无根证书，证明原 `f(0)=2` 只能对应规范坐标0。
3. 两槽：三个槽对的 ODE 线性解；`U^2` 余式理想分别消去为一个三次式。
4. 终端：三个消元三次式在完整 `F_13` 上无根。

有限域穷尽的是13个元素或固定小域，不是扫描原题 `n,j`。

## 实际结果

- 单槽正族存在，但完整7源退出；
- 另外两个单槽族违反数字系数非负；
- 双线性类无有理解；
- GATE7 整片闭合。
