# 方法边界与未完成义务

## 1. 两个接口不是两组独立自由参数

核对实际源定义后，B的`R_B,U,F₀,t_B`恰为E的`u,z,C,δ`。原始MOM整数恢复式也可从同一实际四系数直接消去得到恒等式。仅把它们重写一遍，或把同一范数方程分别标作B与E，再称“联立产生新限制”，不会减少自由量。

这条路线并非被证明永远无用；本轮转而保留中点值和整数ε，获得了有效有限化。真正新信息是ε的符号、严格大小和整除如何联合控制g，而不是符号改名。

## 2. ω(t₃)=2不自动等于两边都没有超额幂

准确分配只给 `u=P^(A−l)Q^(B−r)`。本轮没有证明 `A=l`、`B=r`或二者至少一个成立，也没有得到变动P,Q的绝对界。因此不能声称“整个两素因子t₃已闭”。

本轮也没有找到满足全部NC必要前置、用来否证这些更强断言的真实候选。记录的是尚缺义务，不是擅自宣称一般不可能性。

## 3. 忽略α的完整两窗口弱模型确实非空

一次有界可否证实验（不是闭合证书）检查4|n、n≤200000的完整N/K窗口，保留两个弱数对：

- `(76672,26775)`：g=1、α=76672=128·599，违反α=c2^s。
- `(175492,60606)`：g=2、α=87746，同样违反该形状。

没有用“这段范围没有α幸存”外推无限结论。原始输出与代码在`outputs/window_probe.json`、`code/window_probe.py`。第一例已在接收材料出现，本轮重算不算新反例。

## 4. 把高次3误作孤立3会留下伪终点

完备GAP31恢复的三行见`outputs/gap_probe31.json`。`(496,210)`和`(56,11)`都已有实际共同奇素数3；只有错误的小部取值使它们通过代数必要式。这里不是“再加一个随意模筛”，而是恢复定义所必需的完整3指数检查。

若只用带系数3、6的弱窗口，而不检查真实λμ，GAP31终点不能照搬。本包明确拒绝这三行。

## 5. 有效固定参数恢复不等于全局绝对高度

`n<2²¹δ⁸`确实是新高度，且固定δ后所有剩余数值参数均可执行恢复。但δ仍自由。把这条式子与`gδ<μC`相互代入，不会自动消去δ；所得仍是共同增长的必要不等式。

没有构造保持同一NC条件的下降。没有把ε、u,z或二次式根互换解释成新NC输入；也没有从三次结式的根直接反推原题反例。

## 6. 证据能力边界

SymPy的零恒等式检查不等于Lean证明；第二份标准库实现不等于不同研究者审读。有限程序只承担已经证明完备的δ≤31系数盒和C≤3小终点，不能承担任意δ或一般原题。

定向读取的材料足以核对本轮所用符号和已报告前沿；没有完整重建28轮历史或全部消费者差集，不能宣称全球首创/覆盖差集已认证。网络检索未提供本轮采用的新外部定理，核心新证明无需外部出版结果。
