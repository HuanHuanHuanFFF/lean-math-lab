## 六轮结果

### 01 · H025 joint-slot closure
文件：`packages/01-H025-joint-slot-closure.zip`

- i6/H025：若完整 `5^E` 层在目标侧满足相应无进位条件，得到绝对高度并完成有限末端，从而闭合一个完整数对子族。
- i5/H02⁺：闭合 q4“一个端点槽＋一个近侧槽同时缺失”的无界分支。
- 恰三底 `t` 的 q4 剖面进一步压至 `{1,2,3,4}` 或 `{0,1,2,3}` 两种四槽全非空形态。
- 给出同三行多项式方法的任意次数障碍，避免继续无效加次数。

### 02 · three-base absolute height
文件：`packages/02-three-base-absolute-height.zip`

- 对 i5/H02⁺ 的整个“q2 全居中＋q4 缺端点”分支建立统一绝对高度：`ln n < 2^512`。
- 因恰三底 `t` 强迫 q2 居中且 q4 至少缺一端点，因此三底 `t` 从“无界”推进为统一绝对有效有限化。
- 巨大有限底部尚未排除，因此三底分支尚未闭合。

### 03 · row4 missing-slot absolute height
文件：`packages/03-row4-missing-slot-absolute-height.zip`

- 去掉上一轮“q2 必须全居中”的要求。
- 对 i5/H02⁺：只要 q4 缺少任一非中心槽 `b∈{0,1,3,4}`，就有 `ln n < 2^512`，q2 可任意分配。
- 同样可严格转移到 1280/1530 两个 i6 尾类的对应分支。
- q4 五槽全非空仍未由该几何高度链控制。

### 04 · dominant q4 closure
文件：`packages/04-dominant-q4-closure.zip`

- 写 `q4=Q R`，`Q` 为一个完整素数幂。
- i5/H02⁺：`R^10 ≤ n` 足以整行闭合。
- i6 两尾类：`R^9 ≤ n` 足以整行闭合。
- 还得到多个实际槽乘积的数对消费者；允许 q4 五槽全部非空。
- 所需有限末端已经完成，不依赖上一轮双指数巨大底部。

### 05 · affine two-window closure
文件：`packages/05-affine-two-window-closure.zip`

- 新的自含二次仿射消元：对 `r∈{3,4}`、槽 `b`，若 `D=gcd(n-r,j-b)` 足够大，则直接得到 Common5；主判据本身不要求 H02，也不依赖 QIG/几何高度。
- 在 H02⁺ 中把整行余部条件从上一轮 `R^10` 改进到 q3 或 q4 的 `R^3≤n`。
- 两个 i6 H025 尾类也得到相同的立方条件。
- 该条件所需反设高度降至 `<2^37` 量级，有限末端已完整验收。
- 给出五槽全部非空、没有单一主导完整素数幂但聚合槽块足够大的无限展示族。

### 06 · high-digit-gap closure
文件：`packages/06-high-digit-gap-closure.zip`

- 利用同一个合格源素数的所有更高 `p^H` 无进位层，而不局限于窗口项本身的最大完整幂。
- 建立高位大空档整行消费者 HG：写 `n=A p^H+C`，在明确 q1/q3 门槛下整行成立。
- i5 得到双块长间隔整行族；i6 两个 H025 尾类得到更强的原生第5源位版本。
- 构造 1280 和 1530 两类各一个显式无限 H025 子族，并证明：对每个指定 `E≥2`，各族都有无限多行满足 `v5(n-5)=E`，且整行 Common6。
- 这是真正删除 H025 中一批 `E` 任意无界的子族，但还不能升级为两个完整模类闭合。

## 当前最值得接续的边界

1. `i6/H025`：1280/1530 整类仍未闭合；需要证明一般剩余 NC 必然产生可消费的高层数字空档、聚合槽块，或直接界住 `E,q5,α` 的指数。
2. `i5/H02⁺`：三底 `t` 已有绝对有限化，且大量缺槽/主导块/聚合块区域已经闭合；真正残余更集中在 q4 五槽全非空、各实际槽均较分散的区域。
3. 下一步优先联合同一输入的 q3/q4 仿射表示、第一行平方商及高层无进位，而不是继续单纯增加固定多项式次数或扩大有限扫描。
