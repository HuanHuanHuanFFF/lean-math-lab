# B699 Pro E：同一原输入的立方类排除与实际三次式桥接

日期标签：2026-09-17。作者纸面证明＋确定性有限末端；没有 Lean、独立研究者审读或完整旧消费者差集认证。

## 0. 结论、量词与符号

原题本轮范围是整数 `4 ≤ j ≤ floor(n/2)`。始终令 `k=n−j`，`NC` 表示不存在同一个奇素数同时整除 `binom(n,3)` 与 `binom(n,j)`。全文不更换原始 `(n,j)`。

定义正整数

    M(n,j) = (n j k)² (n−2)(j−1)(k−1).

**定理 CUBE（原题充分消费者）。** 若 M(n,j) 是整数立方，则存在素数 p≥3，同时整除 binom(n,3)、binom(n,j)。不限制 n、j、素数底数或指数。

定义原始有理数

    rho(n,j) = (n−2)(j−1)(k−1)/(n j k).

在全部合法原输入上，`M 是整数立方 ⇔ rho 是正有理数立方`，因为 `M=(njk)³rho`，而有理数的立方若为整数，其立方根必为整数。

**本定理不是“所有 i3 输入闭合”。** 它仅排除下述立方匹配分支；一般 omega(t3)=2 没有闭合。与全部旧消费者并集相比，尚未认证非空的新覆盖差集。有限搜索只找到中心输入，详见 REPORT/FAILURES。

下面先重建主证明实际用到的初等 NC 前置。来源总览提供相同接口，但本证明不调用旧 FOUR11、THIN9、VG8、QT100K、R=7 Pell、RQ128 或出版整点/类域论结果。

## 1. 从 NC 得到源幂与 alpha 形状：必要，非等价

令

    g=gcd(n,j), alpha=n/g, beta=j/g, gamma=k/g.

有 gcd(alpha,beta)=gcd(beta,gamma)=1，alpha=beta+gamma。

阶乘估值恒等式为

    vp binom(n,j) = sum_{a≥1} ( floor(n/p^a) − floor(j/p^a) − floor(k/p^a) ).

每个括号是 0 或 1；它为 1 当且仅当 `j mod p^a > n mod p^a`。所以，若 p 是 binom(n,3) 的奇素因子，NC 强迫每一层都无进位。

若完整奇素数幂 Q=p^e 恰整除 n−r，r∈{0,1,2}，则：p≥5 时 p 是源素数；p=3 且 e≥2 时 p 也是源素数，且必须在完整 Q=3^e 层使用无进位。p=3,e=1 时可能被 3! 取消，不能把它强行当源。于是对上述源幂

    j mod Q ∈ {0,...,r}.

特别，整个高次 3 幂保留，不把 3^e 错删为 3^(e−1)。

另外 `j binom(n,j)=n binom(n−1,j−1)` 蕴含 alpha | binom(n,j)。对 p≥5 整除 n，p 也整除 binom(n,3)，因此 p 不能整除 alpha。若 v3(n)≥2，同理 3 不能整除 alpha。故

    alpha=c 2^s, c∈{1,3}, s≥0,

其中 c=3 必须 v3(n)=1；同时 3∤g。孤立 3 的许可始终保留。

### 1.1 n 不能为奇数

若 n 奇，则 alpha 为 1 或 3。合法 beta≤alpha/2 排除 alpha=1；alpha=3 时只能 beta=1，即 n=3j。此时 n−2 是大于 1 的奇数且不被 3 整除，故有素因子 p≥5。源窗口给 j mod p∈{0,1,2}，但 3j≡2 mod p；代入三个余数分别要求 p 整除 2、1、4，不可能。所以 n 偶。

### 1.2 第一窗口排除 beta=1，得到 4|n 与严格中心不等式

现在 n−1 奇。置 lambda=3 当且仅当 v3(n−1)=1，否则 lambda=1；令 N=(n−1)/lambda。第一源窗口给

    N | j(j−1), gcd(N,g)=1.

由于 n≡1 mod N，这与 `N|jk` 等价，继而与 `N|beta gamma` 等价。这些等价均在此固定 N 和 g 的定义下使用，不是 NC 的等价刻画。

若 beta=1，则 N | alpha−1，故

    n−1 ≤ lambda(alpha−1) ≤ 3(alpha−1).

但 g=j≥4，故 n−1=alpha g−1≥4alpha−1>3(alpha−1)，矛盾。

若 alpha 奇，只剩 alpha=3,beta=1，已排。若 v2(n)=1，则 alpha 只可能是 2 或 6；满足 gcd(alpha,beta)=1 与 1≤beta≤alpha/2 的 beta 都只能是 1，也已排。因此

    4|n, alpha=c2^s 且 s≥1, beta 与 gamma 均为正奇数.

若 j=n/2，约分后 alpha=2,beta=1，又已排。因此 NC 必有 j<n/2。主证明不要求旧的 s≥3 或更强估值条带。

## 2. 两窗口完整分配与正整数恢复：必要

定义真实 mu：`mu=3 iff v3((n−2)/2)=1`，否则 mu=1。令

    K=(n−2)/(2mu).

由 4|n，N、K 都是奇正整数，gcd(N,K)=gcd(N,g)=gcd(K,g)=1。lambda 与 mu 不会同时为 3，所以 lambda mu∈{1,3}。若 c=3，则 lambda=mu=1。

第二源窗口给

    K | j(j−1)(j−2).

因为三个相邻数中任意两者没有共同奇素因子，每个完整奇素数幂只能进入一个位置。定义

    L=gcd(K,j), H=gcd(K,j−1), R=gcd(K,j−2).

则 K=LHR，三者两两互素，保留全部完整幂。令 C=LR，故 K=CH。L|j，R|k，H 同除 j−1 与 k−1；所以 C|jk。定义

    u=beta gamma/(N C),
    t3=Cu=beta gamma/N,
    z=(j−1)(k−1)/(N H²).

它们都是正整数；t3、u 为奇数。理由：N、C 互素且都与 g 互素，所以 N C | beta gamma；N 同除 jk 与 (j−1)(k−1)，又 gcd(N,H)=1，而 H² | (j−1)(k−1)。

此外 H 与 beta gamma 互素，因此

    C=gcd(K,t3), H=K/C, gcd(u,H)=1.

两端差恒等式 `jk−(j−1)(k−1)=n−1` 给

    C u g² − z H² = lambda,                         (2.1)
    n = 2mu C H+2.                                 (2.2)

也有 gcd(u,z)|lambda：由 (2.1) 与 gcd(u,H)=1 可得。

置 q=mu C。因为 H|(j−1)、4≤j<n/2=qH+1，唯一的整数

    m=q−(j−1)/H

满足

    1≤m<q,
    j=(q−m)H+1,
    k=(q+m)H+1,
    n/2−j=mH.                                      (2.3)

alpha 偶使 g|(n/2−j)，而 gcd(g,H)=1，所以 g|m。记 d=m/g，为正整数。注意 **mH** 才是 n/2−j，不能丢掉 H。

由 (j−1)(k−1) 得到精确等式

    q²−m²=zN,
    2mu C zH+z=lambda(mu²C²−m²).                    (2.4)

这些关系均来自同一个原输入。反过来，任意满足它们的整数元组不一定满足真实 gcd、alpha 形状、孤立 3 规则和所有进位；本证明不进行这种错误反推。

## 3. 中间块的严格相对下界

由 (2.4) 及 z,m>0，

    2zH < lambda mu C.

再用 (2.1)：

    2u g² = (2zH²+2lambda)/C
           < lambda mu H + 2lambda/C.

若 C>2lambda，则 2lambda/C<1。左边是偶整数，lambda mu H 是奇整数，因此

    2u g² < lambda mu H.                            (3.1)

这是必要相对界，不是 H 或 g 的绝对高度。它将用于立方间隙，而不是被单独记成大范围闭合。

另一个全域初等事实是

    g^6 z² ≥ 64.                                   (3.2)

g 偶时 g≥2，直接成立。g 奇时 j、k 都奇，且 n=j+k≡0 mod4；故 j−1、k−1 中一个被 4 整除，另一个被 2 整除，乘积被 8 整除。分母 N H² 为奇数，于是 8|z，仍得 (3.2)。

## 4. 立方条件的规范恢复：等价，不丢分母

在第 2 节同一 NC 输入上，用 (2.1) 的原始乘积定义直接得到

    rho = [(H)/(u g)]³ · [2mu u²z/alpha].             (4.1)

所以

    M 为整数立方
      ⇔ rho∈Q_{>0}³
      ⇔ 2mu u²z/alpha∈Q_{>0}³.                     (4.2)

唯一地写

    s−1=3h+r, h≥0, r∈{0,1,2};
    A0=c2^r ∈ {1,2,3,4,6,12}.

A0 是无立方因子的正整数。因为 alpha=c2^s，(4.2) 等价于 `mu u²z/A0` 为正有理立方。分子是正整数，约分后的分母整除无立方因子整数 A0；若该分数为有理立方，约分后分母必须也是整数立方，故分母只能为 1。因而存在正整数 w，且

    mu u²z=A0 w³.                                  (4.3)

反向显然成立。因此 (4.2) 与 (4.3) 在同一输入下完全等价；w 不是近似根，也没有遗漏分母分支。

## 5. C>2lambda 的无限立方间隙矛盾

消去 (2.1)–(2.2) 中的 C，使用 n=alpha g=c2^s g，得

    c u g³ 2^(s−1) = mu zH³+lambda mu H+u g².

乘以 u²，代入 (4.3) 及 c2^(s−1)=A0 2^(3h)，得到

    A0[(u g2^h)³−(wH)³] = lambda mu u²H+u³g² >0.    (5.1)

两立方的底数为正整数，故 `u g2^h ≥ wH+1`，于是左边严格大于 `3A0w²H²`。另一方面，由 (3.1)，右边严格小于 `(3/2)lambda mu u²H`。因此

    2A0w²H < lambda mu u².

再次使用 (3.1) 消去 H：

    4A0w²g² < (lambda mu)²u.

两侧为正，立方后用 `A0²w^6=mu²u^4z²` 约去正因子，得到

    64 A0 u z²g^6 < lambda^6 mu^4.                  (5.2)

lambda,mu 的三种可能为 (1,1),(3,1),(1,3)，所以右边至多 729。由 A0,u≥1 与 (3.2)，左边至少 4096。矛盾。

这里没有固定任何粗素数底、完整指数、g、u、z、H 或 n。没有使用浮点“很接近一个立方”，而是两个真实整数立方之间的严格最小间隙。

## 6. C≤2lambda：严格有限化并返回原题

这一步是第 5 节的唯一剩余端点，而不是扩大旧扫描表。

由 (2.4)，z≥1、m≥1：

    n−1 = lambda(q²−m²)/z
         < lambda mu² C²
         ≤ 4lambda³mu²
         ≤ 108.

所以 n≤108。所有原题合法输入必有 n≥8。附件 `outputs/CERTIFICATE.json` 的 endpoint 部分覆盖全部

    8≤n≤108,
    4≤j≤floor(n/2),

共 2601 个数对。每行明确提供一个奇素数 p，构造器直接计算原始两个二项式并取其 gcd 的奇素因子。第二检查器不调用构造器、不调用 math.comb，而以试除素性与阶乘估值式分别核验

    vp binom(n,3)>0,
    vp binom(n,j)>0.

检查器自行生成完整合法数对集合，拒绝缺项、重复、越界、合数、p=2 与不整除见证。9 种损坏证书均被拒绝，详见 ACCEPTANCE.json。

本节是精确有限算术证书；无限归约由第 1–5 节承担。两种实现仍由同一作者提供，不冒充外部独立审稿或 Lean。

C>2lambda 与 C≤2lambda 穷尽所有情况。因此不存在满足 M 为立方的 NC，**定理 CUBE 得证**。

## 7. 实际内容三次式：不省略原始整数恢复

本节将新判据与 B 的实际三次不变量连接。仅定义与代数恒等式对全部原输入成立；涉及 ell=2^s 的部分标明 NC 前提。

令

    F(Y)=sum_{r=0}^3 binom(j,r)binom(k,3−r)Y^r,
    hF=content(F)>0,
    Psi(Z)=Z³F(1−1/Z)/hF=ell Z³−b0 Z²+c0 Z−d0.

变换 `Z³F(1−1/Z)` 是整数系数的幺模变换，逆变换也为整数系数；所以保留 content。其未约分系数为

    hF ell = n(n−1)(n−2)/6,
    hF b0  = j(n−1)(n−2)/2,
    hF c0  = j(j−1)(n−2)/2,
    hF d0  = j(j−1)(j−2)/6.

**NC 下 ell=2^s。** 记 F_r 为 F 的第 r 项系数。准确组合恒等式是

    binom(n,j) F_r
      = binom(n,3) binom(3,r) binom(n−3,j−r).        (7.1)

中间因子 binom(3,r) 不能遗漏。对任一奇素数 p|binom(n,3)，NC 给 p∤binom(n,j)，于是 vp(F_r)≥vp binom(n,3)，每个 r 都成立。又 hF|F(1)=binom(n,3)，所以 hF 与 binom(n,3) 的奇部分完全相同。

设 e=v2(j)=v2(g)，v=v2(n)>e。因为 4|n，四个未约分系数的 2 赋值分别为 v、e、至少 e、至少 e。最后一项：j 奇时 e=0；j 偶时 j−2 也偶，直接从 j(j−1)(j−2)/6 得到赋值至少 e。因此 v2(hF)=e，ell=2^(v−e)=2^s。此外 b0=3beta/c 为奇整数。

这只证明了实际内容归一化需要的事实；没有调用不可约性或类域论。

## 8. I、J_B、Delta 的原始恒等式与 E 规范式

定义

    I=b0²−3ell c0,
    J_B=2b0³−9ell b0 c0+27ell²d0,
    Delta=Disc(Psi).

直接展开得

    I = 9ell²jk/[n²(n−1)],
    J_B = 54ell³jk(n−2j)/[n³(n−1)(n−2)],
    Delta = 108ell^4j²k²(j−1)(k−1)
            /[n^4(n−2)²(n−1)³].                   (8.1)

以及

    4I³−J_B²=27ell²Delta,
    nI=3ell(b0−c0),
    jI=b0(b0−c0).                                  (8.2)

Delta>0，I>0，因为全部合法输入 n≥8,j,k≥4。式 (8.2) 保留原始整数恢复，不将一般三次式冒充原题输入。

在 NC 下代入 ell/alpha=1/c、jk=N C u g²、n−2j=2gdH 与第 2 节定义，得到新的显式桥接

    I = 9t3/(lambda c²),
    J_B = 54u d/(c³lambda mu),
    Delta = 27u²z/(c^4lambda³mu²),
    d=m/g∈Z_{>0}.                                  (8.3)

这些是精确等式，不只是比例或平方类相同；小素数 2、3 的因子没有丢失。`check_identities.py` 对原始恒等式做精确有理多项式检查，另直接构造全部 n≤150 的 5184 个实际内容三次式回归。

### 8.1 粗素数共同不变量由 u 控制，而不是整个 t3

若奇素数 p|L，模 p 有 j≡0,n/2≡1，所以 mH=n/2−j≡1。若 p|R，则 j≡2,n/2≡1，所以 mH≡−1。结合 gcd(C,Hg)=1，得

    gcd(C,d)=1.

因此对 p≥5，由 (8.3)

    min(vp(I),vp(J_B))
      = min(vp(Cu),vp(ud))
      = vp(u).

若 x_(6) 表示删掉 x 中全部 2、3 幂后的正整数，则

    gcd(I,J_B)_(6)=u_(6).                           (8.4)

另外

    Delta = [3u/(c²lambda²mu)]² · (3lambda z),       (8.5)

所以二次预解域的平方类由 3lambda z 给出。若采用 B 已报告的三次分歧定理，其 p≥5 支持因而直接读为 `{p≥5: 3∤vp(u)}`。本轮只重建 (8.3)–(8.5)，不重证 B 的类域论，也不把这条翻译单独累计成新增覆盖。

## 9. 最简洁的 B/E 消费者桥接：全部原输入上的恒等式

由 (8.1) 与 ell=n(n−1)(n−2)/(6hF)，直接约分：

    (2Delta/ell)(n hF)³ = M(n,j).                   (9.1)

故对全部合法原输入

    M 为整数立方 ⇔ 2Delta/ell∈Q_{>0}³.              (9.2)

结合定理 CUBE，获得 **实际内容三次式消费者**：

    2Delta/ell 为有理立方 ⇒ 原题 i3 对此数对成立.

这并不适用于任意虚构三次式：Psi 必须由同一原始 n,j 的 F 实际构造。NC 下还有

                · [2mu u²z/alpha],                (9.3)

与第 4 节一致。这里无须计算数域、类群或分解粗素数。

## 10. omega(t3)=2 中究竟排除了什么

此节额外采用输入总览的旧作者前置 L,R>1；主定理不依赖它。若 omega(t3)=2，可定向写

    L=P^ellP, R=Q^ellQ, t3=P^A Q^B,
    P≠Q 为奇素数，A≥ellP≥1，B≥ellQ≥1.

由于 beta⊥gamma 且 N=ab 与 K 互素，完整支持分配给出

    beta=aP^A, gamma=bQ^B,
    u=P^(A−ellP)Q^(B−ellQ).

不是随意把 beta/gamma 的支持换成 t3 的支持：这里用到了 t3 恰两底、L 与 R 已经各占一底、以及 beta gamma=N t3。

本轮严格排除其中满足

    mu P^(2(A−ellP))Q^(2(B−ellQ)) z
      = c2^r w³,
    r=(s−1) mod3,

的整个匹配分支，P,Q、指数、g、z、w 都不设上界。一般两底分支仍保留；没有强迫 C=t3 或 u=1，也没有消掉任一参数在全体剩余 NC 上的无界性。

因为 gcd(u,z)|lambda，对于 p≥5，这个匹配条件要求 u 和 z 中相应指数各为 3 的倍数；但 2、3 的赋值仍须满足上式的精确匹配。它不是“只检查几个固定底数”。
