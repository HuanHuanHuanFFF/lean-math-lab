# Pro E 本轮报告：两底 g=2、u=1 的五类无界幂行

任务日期：2026-09-18。本轮依据原累计入口及上轮 TP 交接；未刷新远端状态。没有 Lean、外部独立研究者验收或新增出版定理依赖。

## 1. 最强新增结论

在同一个原始 NC3 输入中，若

    g=gcd(n,j)=2，u=t3/C=1，n=2^(M e+1)，
    M∈{4,6,10,14,22}，e≥1，

则

    omega(t3)≥3。                                    P2-POWER

因此这些行的完整 `g=2,u=1,omega(t3)=2` 切片闭合。e、源素数底数、完整指数、C、H、z 均没有先验上界。这不是只排除五个固定 n，也不是将旧 t 扫描阈值提高；它由统一的完整源分解、同源整数平方间隙与一/二阶余式障碍证明所有大根，剩余端点有完全确定性证书。

更强的弱窗口陈述：M=4,6,10 时，n=2x^M 可以允许全部偶整数 x≥2；M=14,22 的无限段分别允许全部偶整数 x≥256、2048，但小尾部仅覆盖二幂根。非二幂根的这种窗口结论不被额外计作原 NC3 新覆盖，因为真实 alpha 还有自己的约束。

**未完成：** 一般 i3、一般两底、整个 g=2,u=1 切片、一般绝对高度。完整指标 R7={3,4,5,6,7,8,9} 不变。没有原题反例。

## 2. 关键可复用接口

在16|n、两个完整窗口、真实 g=2、规范 u=1 下，使用同一个原恢复整数

    m=(n/2-j)/H∈2Z_{>0}，
    4C-zH²=lambda，
    lambda m²=lambda mu²C²-z(2mu CH+1)。

令 T=lambda mu H。新的平方间隙给

    T≤4z+3，T≡7 (mod8)，H⁴<16n/(lambda mu²)。        G2-H4

较弱前提4|n时仍有 T<4z+6；模8加强不能省略16|n。H4是相对界，不是一般绝对高度。其价值在于：代入 n=2x^M 后，足以禁止大完整源块进入 H。

对奇辅助素数 ell，n=2x^(2ell) 的 K 规范拆成三个两两互素块；所有共同 ell 幂移到第一块，孤立3按真实 mu 处理。两个大块不可能进 H。若 C 仅有两个素数底数，就迫使 B=(x²-1)/mu 整块进入 H。写 H=B eta：

    C eta=1+x²+...+x^(2ell-2)，
    4Q_ell(x²)-eta=zB² eta³，eta为正奇数。

H4把 eta 控制在 B 或 B² 内，同一个等式的模 B / B² 余式却是正偶数，严格小于同一模数；整除与奇偶冲突。此统一机制实际消费 ell=5,7,11，分别给 M=10,14,22。M=4、6使用其更精细的三块结构。
