## 2. 共用完整素数幂转移

本节仅在完整 NC9、H(n,J)=0 下使用。对非命中源值定义非零整数

    E_r=∏_{v∈V_r\Z_r(H)} H(r,v)，空积1；
    d_r=q_r/gcd(q_r,|E_r|)。

若完整 Q 采用非命中值 v，则 H(n,J)=0 与源同余给 Q|H(r,v)，该完整 Q 从 d_r 消去。若采用命中值，d_r 中余下的所有 p 幂仍保有同一源同余。实际零值不能放进 E_r。

在每个 P=(r,v) 引入整数局部多项式 L_P。若对普通坐标 u=N−r,t=X−v 有

    F−H L_P∈(u,t)^m，

那么在该完整 Q 的实际源上，u(n,J)、t(n,J) 都被 Q 整除，故 Q^m|F(n,J)。没有除以梯度或局部行列式；H(n,J)=0 在此不可省略。因此

    ∏_{r=3}^8 d_r^m | F(n,J)。                 (T)

设 deg_w H≤D, ||H||≤2^h。源坐标满足 r≤8,v≤16，故

    |H(r,v)|≤2^(h+3D)。

共有21个不同源位置，z≥14，所以

    ∏ d_r ≥ n^6/(1680^6 · 2^((21−z)(h+3D)))。

对 F∈B_d，合法 J≤n²/4 给 |F(n,J)|≤||F|| n^d。我们始终分别处理 F(n,J)≠0 和 F(n,J)=0，不以形式多项式非零代替点值非零。

### 2.1 整数局部商与维数

若 e_P 是 H 在 P 的普通消失阶，取 L_P 的普通次数<m−e_P；m−e_P≤0 时没有局部商未知量。H 的非零最低齐次项保证

    L_P ↦ H L_P mod (u,t)^m

在 Q 上单射。F=0 的联合解只能有各 L_P=0。因此联合核在 F 系数上的投影也是单射，投影维数下界为

    b(d) − Σ_P [T(m)−T(max(m−e_P,0))]，
    T(a)=a(a+1)/2。

一切条件均构成整数矩阵。在秩为 ρ 的非零最大子式上使用 Cramer 法，每个自由列给出一个整数核向量；这些向量在 Q 上张成整个核。若投影空间维数超过 b(d−deg_w H)，则至少一个该整数基向量的 F 不被 H 整除。并不需要恢复依赖未知大 H 的全部矩阵。

### 2.2 共同零点分支

非零整数 R(N) 的正整数根 n 满足 n≤||R||。若 H Q-不可约、X 次数 t>0且 H∤F，则关于 X 的结式 R=Res_X(H,F) 非零；H 的 Q[N] 内容必为单位，再用 Gauss 引理即可。若 e=deg_XF>0，Sylvester 行列式给

    ||R||≤(e+t)! ||H||^e ||F||^t。             (RES)

若 H(n,J)=F(n,J)=0，则 R(n)=0。此结论包括首系数在 n 处降次，无需除以该首系数。F 不含 X 时直接用一元整数根界。

## 4. 二元 Mahler 预算：必须相乘的是测度而非系数范数

对非零 P∈C[N,X]，定义二元 Mahler 测度

    M(P)=exp ∫_{[0,1]^2} log|P(e^{2πit},e^{2πiu})| dt du。

非零多项式的对数在环面上可积。以下事实也可先避开零专化，再作积分；零专化集合为零测集。

一元 Jensen 公式给 M(PQ)=M(P)M(Q)。在二元定义中对 log 相加同样得到乘法性。对整数非零 P，先把它视为 X 的多项式，其 X 首系数为非零 a(N)。在几乎所有 N 的单位圆值上，一元 Jensen 给 M_X(P(N,X))≥|a(N)|。再对 N 积分，得 M(P)≥M(a)≥1。

写 P=Σ_b a_b(N)X^b，d_N=deg_NP,d_X=deg_XP。一元系数界对几乎所有 |z|=1 给

    |a_b(z)|≤binom(d_X,b) M_X(P(z,X))。

对 log 积分，再对 a_b 使用一元系数界，得到

    |p_ab|≤binom(d_N,a) binom(d_X,b) M(P)。

对系数求和可得

    ||P||≤2^(d_N+d_X) M(P)。                  (MC)

另由环面三角不等式，M(P)≤||P||。所有这些事实不要求绝对不可约。

**不能替换为系数范数乘法。** 例如(1−N)(1+N)=1−N²，两个因子的 l1 范数乘积为4，乘积多项式的范数仅为2。故 ∏||H||≤||G|| 通常为假。这里是在各因子上先用(MC)，再用 M 的乘法性，并非忽略系数抵消。

K152 的同一 G 满足

    ||G||≤23562·2^1242694 < 2^1242709，
    log2 M(G)<1242709。                        (GB)

把任意一组不同的本原 Q-不可约整数因子 H_i 从 G 各取一次。由 Gauss 引理，G=(∏H_i)R，R仍是非零整数多项式，故 M(R)≥1。

    Σ_i log2 M(H_i)≤log2 M(G)<1242709。        (JOINT)

这一步对各因子分别在不同原题输入上可能承载 NC9 也成立，因为它们始终是同一个固定 G 的因子。

## 5. 43→39：严格的联合计数

令 C 为固定 G 的不同本原不可约因子中，存在某个合法400倍数 NC9 输入使 H(n,J)=0 的集合。C 可能为空；这里不假定原题反例存在。

每个 H∈C 已有 deg_wH≥7、deg_XH≥3。设 u 为其中加权恰7的数量。这样的 H 必为 X 三次。C3-L85 的逆否命题给

    ||H||>2^85000。

注意这只是“可承载 ⇒ 超过门槛”，不反向断言高系数保证承载。由 d_N≤7,d_X=3 及(MC)，

    log2 M(H)>85000−10=84990。

(JOINT) 给 84990u<1242709。因为

    15·84990=1274850>1242709，

所以 u≤14。若 K=|C|，其余因子的加权次数≥8，且加权最高齐次部分的乘积非零，因此次数相加，得到

    7u+8(K−u)=8K−u≤deg_wG≤305。

从而

    8K≤305+14=319，K≤39。

这不是识别了四条实际曲线并删除；是证明超过39条这样的不同因子不能同时装进固定 G 的次数与测度预算。

### 5.1 三次分量的单独及混合限制

再令 v 为 X 三次、加权≥8的可承载因子数。冻结 C3-L200 给其 ||H||>2^200000，且 d_N+d_X≤305+3，故

    log2 M(H)>199692。

于是

    84990u+199692v<1242709，
    u+v≤14，v≤6。

若 r 为 X 次数≥4的因子数，则 r 中各因子加权≥8，且

    7u+8(v+r)≤305。

本轮把这些有限整数计数条件重算成完整证书；这只是对已经证明不等式的检查，不是有限原题枚举。

仅用旧 h=80000，可得 u≤15、K≤40。因此本轮 h=85000 的变化实际解锁了40→39，而不是纯粹改善一个无消费者的常数。

## 6. Q8-L21：低高度四次、普通源重数≤21的整类消费者

反设本定理输入为 NC9。由 S14，z≥14。H 的每行专化非零、次数≤4，所以

    z≤2+3+3+4+4+4=20，e_P≤4，μ≤24。

    T(4)−T(4−e)=4e−e(e−1)/2，1≤e≤4。

记 δ=Σ e(e−1)/2，则总有效条件为4μ−δ。若 μ≤20，它≤80；若 μ=21，由 z≤20有 δ≥μ−z≥1，故它≤83。因此

    dim F投影≥b(23)−83=156−83=73，
    dim H倍式=b(15)=72。

可取不被 H 整除的整数 F；所有局部商同时为整数。

    200·9^46<2^160，200·9^16<2^80

严格保证。任何相关子式秩≤200，高列≤120。Cramer 加 F 系数求和给

    ||F||<2^B，B=120h+12000=2532000，

因为120·40+80·80+8=11208<12000。

若 F(n,J)≠0，(T) 中 m=4，H源值界为2^(h+24)，非命中数≤7，得到

    n < 2^(B+24·11+28(h+24))
      = 2^3120936 < 2^14000001。

所以 F(n,J)=0。F不含X时根界矛盾；否则 e≤11,t=4，非零结式范数小于

    2^(11h+4B+ceil(log2(15!)))
    =2^10359041<2^14000001，

该证明在对角点也使用普通四重条件；没有混入较弱的对角权2条件。它允许源奇点，并保留全部实际源点。

## 7. EDGE39：把下一步定位到小高度高重数四次

假设 K=39。由8K−u≤305与u≤14，

    7≤u≤14。

设 b_8 为可承载因子中加权恰8的数量。其余除u个加权7以外至少加权9，因此

    7u+8b_8+9(39−u−b_8)≤305，
    b_8≥46−2u。

若所有这些加权8因子都满足 ||H||>2^21000，则它们的 X 次数至多4、N 次数至多8，由(MC)每个都贡献 log2 M(H)>20988。加上u个加权7因子，

    log2 M(G)>84990u+20988(46−2u)
             =43014u+965448
             ≥1266546>1242709，

矛盾。因此至少一个加权8可承载 H 有 ||H||≤2^21000。

它的 X 次数不能≤2（冻结Q2），也不能=3（冻结C3-L200），故必为4。Q8-L21 排除 μ≤21；竖行容量给 μ≤24，因此22≤μ≤24。EDGE39证毕。

这给的是“若K=39，则存在这样一个因子”的必要条件；并未证明这个低高度四次类空，也未据此声称K≤38。

## 8. 方法上限和不应过度解读的诊断

1. **联合预算本身不能证明38。** 抽象计数 u=7,v=0,r=32，取七个加权7的对数测度代理均84991、其余代理0，总加权305、总X次数149、总测度代理594937，都满足当前全局数值条件而总数39。它不是实际因子构造，更不是NC9反例；只说明这些数值必要条件没有排掉39。
2. **Q8证明不能直接把μ≤21改成μ≤22。** 取普通重数计数(a_1,a_2,a_3,a_4)=(18,2,0,0)，则z=20,μ=22，有效条件86，F维数下界70不超过倍式72。这个计数模型可以符合各行总容量，但未认证实际不可约H存在。它仅否定当前维数估计的直接延伸。
3. 本轮初始对1303个旧残余掩码作了一个新模秩诊断，发现120个17源掩码在18列补空间中模秩17，另2个模秩16。该诊断没有恢复全部有理核，没有接首三窗的全算术，未用于新消费者或39结论。它不能减少源集合清单。
4. 继续提高C3-L85门槛到约180000足以使加权7最多6个并给38，但现有Cramer估计不支持该门槛。一个更具体的替代目标是EDGE39留下的加权8、X四次、范数≤2^21000、μ22..24。两条都是未完成目标。
