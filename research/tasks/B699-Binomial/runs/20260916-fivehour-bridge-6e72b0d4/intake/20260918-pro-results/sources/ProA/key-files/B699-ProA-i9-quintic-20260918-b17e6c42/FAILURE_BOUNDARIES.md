# 本轮失败边界、纠正与未完成事项

## 已纠正的实际探索错误

初始饱和根列探针的二次外推把r=7,8,9的系数错误用于r=6,7,8，产生“二阶系数筛后0项”的无效诊断。逐项核对插值公式后修复为正确的(1,−3,3)、(3,−8,6)、(6,−15,10)，再用不同枢轴r=3,5,8的有理Lagrange实现交叉核对。正确结果为5453/3499/92。无效输出保留在`logs/invalid-shifted-root-gate.json`，不参加接收；不能引用其中的0项。

## 不能推广的结论

1. 五次μ30必须单独处理。包络(12个一重点、9个二重点)让m24的核维数余量为−11；不能从μ≤29的格证明直接推出μ≤30。SAT30已用实际系数整类分类关闭，不把包络当成实际曲线。
2. Q10-L25当前允许范数为2^25000。把同一参数直接改成2^26000，结式指数超过入口；检查器明确拒绝该越界。它不证明26000门槛数学上不可能，只否定这一套未改参数的证据。
3. 普通重数不等于特化根重数。只在μ30饱和时，由六行容量等号证明逐点相等。μ29一行缺一重仍待新分类。
4. 系数l1范数不满足所需乘法预算。例如||X−1||||X+1||=4，而||X²−1||=2。联合计数使用Mahler测度，不使用这个错误不等式。
5. 按全部列支付Hadamard上界，要求所有列上界至少1，且非命中损失保留全部完整Z。大矩阵没有实际恢复，F(n,J)=0由H∤F的非零结式处理。
6. 33不是32。一个D7、11个D8、21个D10的抽象计数满足现有次数、X次数、测度必要条件；没有构造真实因子或NC输入。仅增加D12的费用不能排除此计数。
7. 92个根列、28个可约解、1223/1527个重数包络，都不是有限原题n,j候选，也不是已恢复的G分量。
