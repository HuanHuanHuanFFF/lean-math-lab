# PROOFS · i5/H02⁺ 的第4行缺槽分支：删除 q2 全居中前提

日期：2026-09-17。本轮为作者纸面证明＋确定性有限代数证书。Reider 与 Matveev 是明确采用的出版输入；无 Lean、无外部独立数学审读。新有限接受不等于主定理经过形式化，也不等于巨大原题有限底部已经排除。

所有 log、ln 为自然对数。原输入 (n,j) 在整条证明中不改变；q_r 使用目标5自己的完整小部。几何中的点和除子只是辅助对象，不是新的原题候选。

## 0. 准确主定理、增量与不成立的升级

定义

s5(x)=2^{v2(x)}3^{v3(x)}·(5 if v5(x)=1 else 1),
q_r=(n-r)/s5(n-r), k=n-j, g=gcd(n,j).

尤其 s5(125)=1，原完整125保留在q_r中。

**定理 MS-ABS。** 对同一个合法输入

NC5(n,j), n mod72 ∈ {18,56}, 6≤j≤floor(n/2)，

若存在 b∈{0,1,3,4} 满足

    gcd(q4,j-b)=1,                                      (MS)

则

    ln n < 2^512，因而 n < 2^(2^513).                   (ABS)

**没有 q2 全居中前提，也没有 t 的底数数量前提。** q2可以在三个源槽任意分配，所有完整粗素数、指数、g、α、β均未预设上限。

上一轮 CP-ABS 只覆盖“q2全居中＋q4缺端点”。本轮包含旧分支，并新给：(a) q4缺端点但q2不居中；(b) q4缺近侧槽1或3、q2任意。新增的是这些分支的统一绝对高度，不是只增加底数下界。

反向表述：若行域和(MS)成立，且 ln n≥2^512，则该原输入必有共同素数p≥5。巨大有限底部未完成；不能称整个缺槽分支、三底区域或任何完整指标已经闭合。

采用冻结 C5 中心消费者 NC5⇒gcd(q4,j-2)>1 后，任何 q4 没有用满五个槽的 NC5 输入都满足(ABS)。这个完整“五槽”推论另有旧依赖，主定理(MS)本身不需要它。

## 1. 完整源幂、三槽分配及所有消去

阶乘倍数计数给

v_p C(n,j)=Σ_{e≥1}[j mod p^e > n mod p^e]。

若完整Q=p^e∥q_r，p是C(n,5)的源素因子：p>5时5!不含p；p=5时e≥2，源分母只消去一次5。NC5迫使整个Q层无进位，故唯一b∈{0,…,r}满足

    j≡b, k≡r-b (mod Q)。                               (1)

这是必要条件，不能反向当成NC5。

不同q_r两两互素；r>0时gcd(g,q_r)=1，因为其素数底数大于所有非零窗口距离及r。整系数多项式在整数点总消失阶w时，相应完整Q^w整除其取值。原点阶T则g^T整除；用上述互素性合并，没有除阶乘或降根基。

令

    A2=gcd(q2,j), M2=gcd(q2,j-1), C2=gcd(q2,j-2)。

在(1)下它们是三个完整槽块，两两互素，且q2=A2 M2 C2。不要求M2=q2。

q4缺端点0对应gcd(q4,j)=1，缺端点4对应gcd(q4,k)=1，因为q4|(n-4)。交换X,Y使0与4、1与3互换。因此只需构造缺0及缺1两种多项式。

## 2. 两种固定八点曲面及零交数曲线分类

使用与上一轮相同的有理变换

    u=X/(X+Y-1), v=Y/(X+Y-1)。                         (2)

它在原点、第2/3/4行及所有合法X,Y≥6处正则可逆。

令A_i=(i/2,(3-i)/2), i=0,…,3；B_i=(i/3,(4-i)/3)。缺槽r∈{0,1}时，爆破四个A点和四个B_i（i≠r），得到光滑有理曲面S_r。

两条源曲线为L_A:u+v=3/2、L_B:u+v=4/3。以H表示(1,1)的拉回，有

    D0=~L_A+~L_B=(2,2)-ΣE_i=-K,
    D0²=0, D0.H=4, H²=2,
    ~L_A²=~L_B²=-2, ~L_A.~L_B=2。

D0是有效nef除子：对自身两分量交数0，对其他不可约曲线交数非负。不能由此假定D0半丰沛。

### 2.1 任意次数先界定，之后才枚举

设不可约曲线C满足D0.C=0，不是两条源曲线。例外曲线满足D0.E_i=1，先排除。记C原双次数(a,b)、d=a+b≥1、e=a-b，八点重数c_i。

因C与D0不相交，分别作Bézout得Σ_A c_i=Σ_B c_i=d。原曲线不能经过(∞,∞)，因此u^a v^b系数非零，限制v=s-u的次数准确为d。比较s=3/2与4/3限制式的最高两项，给

    Σ_A(3i)c_i - Σ_B(2i)c_i = b。                    (3)

邻接公式及p_a(C)≥0给C²≥-2。写c_i=d/4+θ_i，得

    e²/2+Σθ_i²≤2。                                    (4)

缺0时，(3)化为d-e/2=<θ,w0>，||w0||²=65，因此d≤12；该前置的16类、六根曲线在上一轮已给。本轮定向重验其完整有限计算，不重跑其他旧历史链。

缺1时，B索引为0,2,3,4，(3)化为

    (d-e)/2=<θ,w1>,
    w1=(-9/2,-3/2,3/2,9/2; 9/2,1/2,-3/2,-7/2),
    ||w1||²=80。

因此((d-e)/2)²≤160且|e|≤2。d≥28会使左侧≥13²>160，矛盾。故

    d≤27。                                             (5)

然后才完整枚举非负整数类。满足组和、(3)、2ab-Σc_i²≥-2的类恰有36个。每类整数Taylor矩阵都有一维核；证书列出一个非零整数核向量并精确分解。模素数65521的秩为列数减一，连同整数核向量证明特征0核准确一维，不是仅依赖有限域秩猜测。

即使C只定义在C上，也属于这些核：有理矩阵扩标量不改变秩，一维核只产生证书中的因子。所以分类不是仅限有理定义的曲线。

    Z1.C≤(149/4)δ+sqrt(78(dδ/2+2))

    N1.C≥δ(151h²/2-149h/4+1)≥157δ/4>2。              (8)

## 4. 缺端点：在旧曲面再爆破一个点，删除“q2必须全居中”

    (2,1,-1,1,-8,-16)，

全部非零；T也不在L_A、L_B及原八个爆破点上。故T与Z0和D0的支持都不相交。

### 4.1 全部曲线类型的交数检查

新例外曲线N0.E_T=8h+1≥9；旧例外曲线交数≥82；两源曲线交数4；旧六根曲线因为不经过T，交数仍≥4。

D0零交数曲线只可能是上述旧根/源曲线或新E_T：任何其他严格变换的D0交数等于其像的原D0交数。因此没有漏掉新零交数类型。

对剩余不可约C，记δ=D0.C≥1、原双次数和d≥1，旧八点重数c_i，以及T处重数μ≥0。Σc_i=2d-δ。由K'.C=-δ+μ，邻接公式给

    C²≥δ-μ-2。

令e=a-b、θ_i=c_i-(2d-δ)/8，展开交数得

    e²/2+Σθ_i²+(μ-1/2)²
      ≤dδ/2-δ²/8-δ+9/4
      ≤dδ/2+9/4。                                    (11)

Z0的正交范数平方72，其均值项为(31/2)δ。对Z0的正交部分和μ-1/2联合使用Cauchy。因8h+1≤9h、dδ≥1，

    72h²+(8h+1)²≤153h²，
    dδ/2+9/4≤(11/4)dδ，
    153·11/4<21²。

所以

    h Z0.C+(8h+1)μ
      ≤(31h/2)δ+(8h+1)/2+21h sqrt(dδ)

    N0.C≥(m+1-20h)δ+2d-21h sqrt(dδ)
         ≥δ(359h²/8-20h+1)≥207δ/8>2。               (13)

另有

    N0²=1464h²-264h+23≥1223。                          (14)

因此Reider再次给|R0|无基点。

### 4.2 源精度的完整回传

## 5. 有效整数核基与任意 h 的联合界

两种构造都取D=4m+4，并置

    F(X,Y)=(X+Y-1)^D (z_r^hG)(X/(X+Y-1),Y/(X+Y-1))。

则F∈Z[X,Y]、deg F≤D，在选定原合法输入非零。双次数限制保证第1行两点各消失2m+2阶；第3行四点及第4行四个保留槽各消失m阶。所以

    w1=2m+2，w3=w4=m，W=4m+2，D-W=2。               (16)

这是对每个h、每个原合法P都存在一个受统一界控制的非消失F，不是声称同一个F同时在所有合法点非零。

### 5.1 系数界并未因补点或近侧配置失效

G的未知单项式数J≤(2m+3)²<2^16 h^4。源点有分母2或3；新增T分母1。整数Taylor矩阵的行元素可写成

    binom(a,r) binom(b,s) x^(a-r)y^(b-s) d^(D-a-b)，

其中d∈{1,2,3}、0≤x,y≤4，越界项为0，均满足绝对值≤2^(5D)，D≤404h²。新增点改变方程数但不改变列数/元素界。

选满秩子式，Cramer对每个自由列给整数核基。每坐标≤rank!·(2^(5D))^rank；由rank<J及log2 rank≤20h²，

    ||G||_1≤2^(2^29 h^6)。

两种z均满足||z||_1<2^400；逆变换每项范数≤3^D≤2^(808h²)。因此仍安全地有

    ||F||_1≤2^(2^31 h^6)。                            (17)

Reider保证有非零评价的截面，有理核基扩标量张成全部截面，故至少一个上述有界整数基向量在原P非零。没有实际展开巨大h矩阵；给出的是有限整数算法和对全部h成立的界。

### 5.2 完整粗幂整除

缺0或4时，(15)给

    (gq2)^(8h) M2^(9h) q1^(2m+2) q3^m q4^m | F(j,k)。

    (gq2)^(8h) q1^(2m+2)q3^m q4^m | F(j,k)。         (18)

互素性见§1；p=5的高次完整幂也按整个Q处理。

H02⁺下第1/3/4行的完整2/3小部分别为(1,1,4)或(1,3,2)。至多一行支付孤立一次5，所以

    S1^(2m+2)S3^mS4^m≤2^(2m)3^m5^(2m+2)，
    log2(上述成本)<10m+6。

n≥18且r≤4时n-r>n/2。先使用F(j,k)≠0，再结合(16)–(18)，得

## 6. 准确的变系数 Matveev 接口与绝对高度

由j C(n,j)=n C(n-1,j-1)、g=gcd(n,j)，有α=n/g整除C(n,j)。NC5迫使α不含源中的合格素数。因此原输入可准确写成

n mod72=56：n=2^A U，n-2=3^B V，U≤5g，V≤10q2；
n mod72=18：n=3^B U，n-2=2^A V，U≤10g，V≤5q2。

A、B为对应完整指数，U、V是真实整数，不是固定系数。U/V约分后的对数高度满足

    h(U/V)≤ln(10gq2)<3+ln(gq2)。

取正有理底数2、3、U/V，指数按行域为(A,-B,1)或(-A,B,1)，乘积减一准确为

    n/(n-2)-1=2/(n-2)>0。

Matveev的实代数数乘积减一版本在数域次数1、A1=1、A2=2、A3=3+ln(gq2)、B0=2L时给

    ln((n-2)/2)
      <10^12(1+ln(2L))(3+ln(gq2))。                 (21)

常数上界为(28/5)30^6 3^4=330674400000<10^12。U/V=1时删除第三底数后同一安全界仍成立；不需要乘法独立。

选h=ceil(10^12(1+ln(2L)))，将(20)代入(21)，得

    L<2^31 h^6。

对L≥e，有h<2^43 ln L，因此

    L<2^289 (ln L)^6。

当L≥2^512，L/(ln L)^6递增，且在左端大于2^458>2^289，矛盾。小L当然在界内。所以ln n<2^512；由ln2>1/2安全转为n<2^(2^513)。MS-ABS证毕。

## 7. 同一输入的 i6 转移与全局边界

只在旧D6尾类 n mod1800∈{1280,1530} 中，v5(n)=1且n-1,…,n-4不含5。因此5∤C(n,5)。Common5的见证实际≥7，并由

    6 C(n,6)=(n-5) C(n,5)，p∤6
