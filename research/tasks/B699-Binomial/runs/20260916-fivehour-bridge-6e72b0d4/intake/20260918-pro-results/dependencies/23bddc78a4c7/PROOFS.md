# Pro E：两底 g=2、u=1 的幂行闭合

任务日期：2026-09-18。证据级别：作者纸面证明、精确整数证书、同作者另一算法复核。没有 Lean 或外部独立研究者验收。

## 0. 精确目标、主定理和不成立的反向

原题的 i=3：对任意自然数 4≤j≤floor(n/2)，存在同一个奇素数 p≥3，使 p 同时整除 binom(n,3) 与 binom(n,j)。NC3(n,j) 表示此原数对的反设，k=n−j。

**主定理 P2-POWER。** 在同一个 NC3 输入中，若 g=gcd(n,j)=2、规范 u=1，而且

    n=2^(M e+1),  e≥1,  M∈{4,6,10,14,22},

则 omega(t3)≥3。因此这些行上的整个 `g=2,u=1,omega(t3)=2` 分支不可能。

所有素数底数、完整源指数、e、C、H、z 均不预设上界。主定理不表示这些 n 的所有 j 已闭合：它仍带真实 g=2、u=1 和两底前提。一般 i3、一般两底、整个 g=2,u=1 均未闭合；没有一般绝对高度。

本稿实际上证明更强的两个窗口结论。对 M=4,6,10，允许任意正偶数 x，并令 n=2x^M；在两个完整窗口、真实 g=2、u=1 下必有 omega(t3)≥3。对 M=14,22，相同结论在分别 x≥256、x≥2048 成立；本轮的小端点仅完整覆盖 x 为二幂的子域。因此不宣称 M=14,22 的所有较小偶数根都已处理。

**符号。** t3、C、H、u、z、lambda、mu 全部沿用原 i3 定义。M 是本稿的幂行乘数，e 是 x=2^e 的指数；二次恢复量仍记 m。辅助奇素数记 ell，绝不把它当作旧恢复 q=mu C。块商 eta=H/B 不是第一窗口的分配 b。

## 1. 从同一个原数对重建窗口和规范参数

### 1.1 完整源幂与 p=3

对素数 p，阶乘计数恒等式给

    v_p binom(n,j)
      = sum_{h≥1} (floor(n/p^h)−floor(j/p^h)−floor(k/p^h)).

每项为0或1，当且仅当 j mod p^h > n mod p^h 时为1。

假设4|n。定义真实孤立3小部：

    lambda=3 iff v3(n−1)=1，otherwise 1；
    mu=3 iff v3((n−2)/2)=1，otherwise 1；
    N=(n−1)/lambda，K=(n−2)/(2mu)。

N、K 是互素正奇数。对 N 或 K 中任何完整 p^a，p 都是 binom(n,3) 的奇素因子。p≥5 时分母6没有消去；p=3 时，孤立一次3已被去除，仍在 N 或 K 中的3幂指数至少2，所以 binom(n,3) 在3处仍有正赋值，且源窗口仍使用整个3^a。

NC3 因而要求

    N | j(j−1),             K | j(j−1)(j−2).             (W)

这是必要条件，不是充分条件。若第一个窗口失败，可从 N 选一个完整源幂，得到 j mod p^a>1 的进位；若第二个失败，可从 K 选一个完整源幂，得到 j mod p^a>2 的进位。选到的同一个 p 同时整除两个原二项式。

在本稿全部幂行 n=2x^M、x 偶且 M 偶中，x^M 模3为0或1，所以3不整除 n−1；因此 lambda=1。不需借用旧 NC 排除链来取得这些行的窗口。

### 1.2 完整分配和 u=1

本节假设 (W) 及真实 gcd(n,j)=2。令 beta=j/2、gamma=k/2。

由于 n≡1 mod N，第一窗口等价于 N|jk；N 为奇数，所以 N|beta gamma，规范

    t3=beta gamma/N

是正奇整数。

K 的每个完整奇素数幂只能完整进入 j、j−1、j−2 中一个位置：这些整数的任意两者在奇数部分互素。因此

    H=gcd(K,j−1)，C=K/H，gcd(C,H)=1，
    H | j−1，H | k−1，C | jk。

H 与 jk 互素，C 与 N 互素，所以

    C=gcd(K,t3)，C|t3，u=t3/C。

特别 C 是 K 的**酉因子**：在每个素数处，它的指数不是0就是 K 的全部指数。本稿有限末端枚举正是依赖这一点，不枚举任意截断指数。

另外 N 同时整除 (j−1)(k−1)，H² 也整除该乘积，且 gcd(N,H)=1，故

    z=(j−1)(k−1)/(NH²)

为正整数。由 jk−(j−1)(k−1)=n−1 得

    C u g²−zH²=lambda，n=2mu CH+2。

固定本轮子域 g=2、u=1：

    4C−zH²=lambda，        n=2mu CH+2。               (NORM)

此时 C,H,z 全为奇数。对 z 的奇性，使用 j,k 偶、N,H 奇；没有假设 z 是平方或立方。

### 1.3 同一个原 j 的恢复，不丢判别式

因为 H 同除 j−1 与 n/2−1，可定义原恢复整数

    m=(n/2−j)/H。

合法区间和 g=2、n≥16 给 m>0，且 m 为偶数。精确地

    j=(mu C−m)H+1，k=(mu C+m)H+1，
    lambda m²=lambda mu²C²−z(2mu CH+1)。            (DISC)

(NORM)、(DISC) 只是原输入的必要条件；反向恢复候选还必须检查真实 gcd、区间、窗口和全部 NC 约束。下文的平方间隙始终使用这个同一个 m。

## 2. 新的整数平方间隙和 H 四次高度

### 2.1 G2-SG：保留原恢复量的整系数平方

置

    T=lambda mu H，E=lambda mu C−zH，
    A=lambda mu E−2z。

由 (NORM)、(DISC) 直接计算

    E²−lambda²m²=4Cz，
    A²−(lambda²mu m)²=4z²(T+1)，                  (SG)
    4A=z(T²−4T−8)+lambda³mu²。

A 与 lambda²mu m 均为偶整数。

证明 T<4z+6。反设 T≥4z+6。由于 z≥1，此时 T≥10，最后一式给 A>0；(SG) 的右侧严格正，所以 A>lambda²mu m≥0。两个偶整数的间隔至少2，从而

    4A−4 ≤ A²−(lambda²mu m)² = 4z²(T+1)。

代入4A，得到

    z[T²−4(z+1)T−4z−8]+lambda³mu²−4 ≤ 0。

方括号的二次式在 T≥4z+6 上递增；在 T=4z+6 时为4z+4。于是左侧至少

    z(4z+4)+1−4 ≥ 5 > 0，

矛盾。因此

    lambda mu H < 4z+6。                           (SG0)

这条证明没有采用旧 SQG、对数下界或任何有限数表，也没有将 (NORM) 单独冒充 (DISC)。

### 2.2 在16|n时的精确奇偶加强

现在额外假设16|n；本稿所有主定理行自动满足。真实 gcd=2 给 beta、gamma 奇，beta+gamma=n/2≡0 mod8，因此 beta gamma≡−1 mod8。

由 t3=C、N=(n−1)/lambda、mu CH=n/2−1，有

    (lambda mu H) beta gamma=(n−1)(n/2−1)≡1 mod8。

所以 T≡7 mod8。z 为奇数；由 T<4z+6 得

    T≤4z+3，T≥7，z≥T/8。

代回同一 n 的式子

    n=mu(zH³+lambda H)/2+2
       >mu zH³/2 ≥lambda mu²H⁴/16，

得到全局有效的**相对**高度

    H⁴ < 16n/(lambda mu²)。                       (H4)

没有把它称为一般 n 的绝对高度。它在固定 n 的代数行上，可与完整源块的大小直接冲突。

## 3. 四次幂行：三个互素块都必须遇到 C

设 n=2x⁴，x 为偶数，x≥64。lambda=1。

若mu=3，该孤立3完整地位于 x−1 或 x+1 的一个因子中。令 delta_-、delta_+∈{1,3}，delta_-delta_+=mu，按真实位置除去一次3。则

    B_-=(x−1)/delta_-，B_+=(x+1)/delta_+，B_2=x²+1，
    K=B_- B_+ B_2。

三个块两两互素，且均大于1。因为 x 偶，gcd(x−1,x+1)=1，gcd(x²+1,x±1)=1；这里没有丢掉高次3。如果源中3赋值≥2，则mu=1，不进行这种除法。

证明每个 B 都必须与 C 有非平凡 gcd。若某个 B 与 C 互素，由 K=CH 得 B|H。

**二次块。** 若B_2|H，(H4) 给 H⁴<32x⁴/mu²≤32x⁴，但 H⁴≥(x²+1)^4>x⁸，x≥64 时矛盾。

**任一线性块。** 统一写 sigma∈{1,−1}、F=x−sigma、delta 为相应孤立3因子、nu=mu/delta、B=F/delta、H=B eta。eta 为正奇数。定义

    Q_sigma=(x⁴−1)/(x−sigma)
           =x³+sigma x²+x+sigma。

有 C=Q_sigma/(nu eta)，且 (NORM) 给精确整数式

    4Q_sigma−nu eta=nu z B² eta³。

所以 B|16sigma−nu eta。

另一方面 (H4) 给

    (nu eta)^4
      =mu⁴H⁴/F⁴
      <32mu²(x/F)^4
      ≤288(64/63)^4 <5⁴。

最后一项是严格有理数比较，由证书核对。nu eta 是正奇数，因此 nu eta≤3。非零整数 16sigma−nu eta 的绝对值至多19。可是 B≥(x−1)/3≥21，矛盾。

故三个两两互素的块都与 C 有非平凡 gcd，C 至少有三个不同素因子。这是所有 x≥64 的无限证明，不需先固定底数或源指数。

## 4. 六次幂行：全部三个二次块由大小排除

设 n=2x⁶，x 偶且 x≥64。lambda=mu=1。

若3|x，则 x⁶−1 不被3整除。若3∤x，则3整除 x²−1，并且

    x⁶−1=(x²−1)(x⁴+x²+1)

中的第二因子在3处恰有一次赋值，故源3至少为平方，不是孤立3。因此总有mu=1。

令 Phi_3=x²+x+1、Phi_6=x²−x+1。构造三个互素块：

- x≡0 mod3：B_0=x²−1，B_3=Phi_3，B_6=Phi_6；
- x≡1 mod3：B_0=3(x²−1)，B_3=Phi_3/3，B_6=Phi_6；
- x≡−1 mod3：B_0=3(x²−1)，B_3=Phi_3，B_6=Phi_6/3。

在后两种情形，相应 Phi 在3处的赋值恰为1，而 B_0 接收 K 的完整3幂。这不是删去3。

这些块的乘积是 K=x⁶−1，两两互素，每一个至少为 (x²−x+1)/3。若一个块不遇到 C，则它完整进入 H，所以

    H > (x²−x)/3 ≥ (21/64)x²。

从x≥64得

    H⁴ > (21/64)^4 x⁸
        ≥ (21⁴/4096)x⁶ >32x⁶。

最后不等式为194481>131072，与(H4)矛盾。因此C必须至少有三个不同素因子。

## 5. 变奇素数 ell 的完整分块与两个余式障碍

这一节给统一方法，随后实际消费 ell=5,7,11；不是先对这几个素数分别猜模数。

设 ell≥3 为奇素数，n=2x^(2ell)，x 偶。仍有lambda=1。令

    P_+=(x^ell−1)/(x−1)，P_-=(x^ell+1)/(x+1)。

它们是两个明确的整数多项式。P_+、P_- 互素；它们与 x²−1 的公因子只能是ell。若ell|(x−1)，则P_+的ell赋值恰为1；若ell|(x+1)，则P_-的ell赋值恰为1。这个赋值可由 x=±1+ell a 的二项式展开立即得到。两个情况不会同时发生。

mu 总整除 x²−1。特别ell=3时源3至少平方，所以mu=1；ell≠3时，孤立3仅来自 x²−1。

若ell|x²−1，将相应P中的一个ell移到 (x²−1)/mu；否则不移动。得到三个**两两互素、乘积为K**的正整数块

    B_0=d_ell(x²−1)/mu，B_+，B_-，
    d_ell∈{1,ell}。

所有源指数完整保留。B_± 各至多被除一次ell，因此

    B_± > (2/(3ell)) x^(ell−1)。

其中 x/(x+1)≥2/3 用于 P_-；P_+ 的下界更强。

### 5.1 两个大块必须占据两个不同底数

若

    x^(2ell−4)>162 ell⁴，                         (LARGE)

则 B_±^4>32x^(2ell)。根据(H4)，B_+或B_-都不可能完整进入H。因此每一个都遇到C。

若omega(C)≤2，这两个互素块已经占据C的全部可能底数，B_0便与C互素，所以

    B=(x²−1)/mu | H。

置 y=x²，H=B eta，eta 为正奇数，并令

    Q_ell(y)=1+y+...+y^(ell−1)。

从 K=CH 得 C eta=Q_ell(y)。范数式给

    4Q_ell(y)−eta=z B² eta³，                     (R)
    eta⁴ <32mu² y^ell/(y−1)^4。                  (SIZE)

这是同一原输入上的必要等式；eta不能被替换为另一个同余解。

### 5.2 一阶障碍

若

    y−1>4ell mu，
    (y−1)^8>32mu^6 y^ell，                        (R1)

则0<4ell<B，且由(SIZE)得0<eta<B。而(R)模B给

    B | 4ell−eta。

4ell偶、eta奇，差不为0；两个数都在(0,B)，差的绝对值小于B。矛盾。

### 5.3 二阶障碍

令F=y−1。精确二项式展开给

    Q_ell(y)=ell+binom(ell,2)F+F²R_ell(F)，

R_ell为整数多项式。令

    R=4ell+2ell(ell−1)F。

若

    0<R<B²，
    (y−1)^12>32mu^10 y^ell，                      (R2)

则0<eta<B²，而且(R)给B²|R−eta。R偶、eta奇，差非零且绝对值小于B²，矛盾。

这一层**不能**省略同一输入恢复所给的H四次高度。仅范数方程并不保证(SIZE)。二阶也不能不加证明升级为三阶：模B³会出现未知 z eta³ 项。

### 5.4 实际使用的全指数阈值

采用mu≤3，以下整数比较足以覆盖所示整个 x 半轴：

|ell|x入口|余式阶数|基点的严格整数检查|
|---|---:|---:|---|
|5|8|1|8^6>162·5^4；63>60；63^8>32·3^6·64^5|
|7|256|1|256^10>162·7^4；65535>84；65535^8>32·3^6·65536^7|
|11|2048|2|2048^18>162·11^4；F²>9(44+220F)、F^12>32·3^10·y^11，y=2048²、F=y−1|

这些只是无限不等式的基点证书，不是扫描上限。证明其向上保持：LARGE左边递增；对a>ell，

    (y−1)^a/y^ell = y^(a−ell)(1−1/y)^a

在y>1上严格递增。一阶的线性不等式显然保持。二阶中F²−9(44+220F)在基点之后严格递增，因其导数2F−1980正。

故M=10的全部偶根x≥8、M=14的全部偶根x≥256、M=22的全部偶根x≥2048，两底都被排除。

## 7. 素性、完整性和损坏证书拒绝

### 7.1 递归满阶素性证书的初等证明

对整数p>2，证书给p−1的完整素数分解，所有因子已递归证明为素数；另给a，使

    a^(p−1)=1 modp，
    gcd(a^((p−1)/q)−1,p)=1  对每个素数q|(p−1)。

任取素数r|p。a在模r下的乘法阶整除p−1，但不整除(p−1)/q，对所有q同时成立；所以该阶恰为p−1。因此p−1|r−1，r≥p；又r|p，所以r=p，p为素数。递归以p=2结束。

这不是 Miller–Rabin 概率判断。构造器使用的SymPy分解只是提议；若提议有错，递归证书或最终乘积检查必失败。检查器只用Python标准库，不导入构造器或SymPy。

本轮共有142个递归素性结点。对K的分解逐行检查素因子互异、指数为正、乘积恰等于K；再重建完整酉因子域，不能只检查作者给出的幸存清单。

## 8. 返回原题以及实际剩余范围

对于任何主定理行，反设某个原始合法(n,j)是NC3，且真实g=2、规范u=1、omega(t3)≤2。第1节给两个完整窗口与规范恒等式。写x=2^e；它或进入第3—5节对应无限段，或进入第6节的完整有限域，均矛盾。

因此该原输入存在共同奇素数p≥3。整个论证没有把n改成较小数、没有换j，没有把另一个数对的共同素数运输回来。由于窗口本身由完整源幂推出，p=3和高次3幂均已保留。

对纯二幂n=2^v，g=2,u=1的两底NC输入现在必须：

    v为偶数；或者
    v为奇数且 gcd((v−1)/2,2310)=1。

这里2310=2·3·5·7·11。这只是被证明排除的五个指数倍数族的等价重述，不是所有未解决i3输入的分类。

仍未消去：其他v、n=3·2^v分支、其他g/u、非两底输入，以及一般n,j,t3,C,H,z的无界性。本轮没有认证与全部历史消费者并集的非空差集，也没有进行全球新颖性审计。

## 9. 为什么只看范数不够：明确的无限弱模型

取任意r≥0，令

    H=47+48r，z=3，C=(3H²+1)/4，
    n=2CH+2，lambda=mu=1。

这些都是正整数；n被16整除，lambda和mu确实等于从n计算的真实孤立3值，C,H奇且互素，T=H≡7 mod8，且4C−zH²=1。

然而H≥47，所以H>4z+3=15，且

    H⁴>16n。

对这些无限断言，H≡7 mod8且H²≡1 mod32给C≡1 mod8，从而16|n；H≡2 mod3、C≡1 mod3给3|n与3∤CH，所以lambda=mu=1。另有

    H⁴−16n=H³(H−24)−8H−32>0，H≥47。

这里没有给出任何原始整数j，更没有真实gcd或alpha形状声明。若同一偶整数m真满足恢复判别式，第2节立刻矛盾。故这个无限族精确否定“仅由范数和这些奇偶条件推出H4”的错误命题，不是原题反例族。

脚本还重新计算旧TP交接中的原始弱输入，确认其两个窗口、g=2、u=1和新平方恒等式。该旧输入不满足16|n，且原共同素数197仍在；没有把它升级为新NC实例。
