## 最强新增结论

本轮继续 i=3，没有重复扩大旧 t3/模数/薄系数门槛。新证明是：

> 对同一 NC3 输入，若 Q=(n−1)(n−2)/(j(n−j)) 是整数，则 omega(t3)≥3。

因此当前两底前沿可删除整个

    omega(t3)=2, g=1, u=1

分支。底数、完整指数、n,H,z都不设上界。更一般地，NC3 的整数 Q 分支等价于 g=1,u|lambda mu，本轮将其全部排除在 omega(t3)≤2 之外。

**一般 i3 未闭合；R7={3,4,5,6,7,8,9} 不变；没有原题反例。** 这是两底族内的一个完整无界切片闭合，不是整个两底族闭合，也不是 g=1,u=1 对所有 t3 都不可能。

    j²+k²−2(D−1)jk−3j−3k+2=0.

韦达跳跃完整分类全部正整数点：只来自种子 (0,1)、(0,2) 的两条递推 x_(r+2)=2(D−1)x_(r+1)+3−x_r。这个下降只用于辅助曲线的完整分类，不声称保持 NC。

    t3=lambda A B V,

A,B,V为三个两两互素且>1的奇整数。主要因式分解是

    U_(2h+1)=(U_(h+1)−U_h)(U_(h+1)+U_h).

这不需要原始素因子定理或任何素数表。

最低指标只有非法 j=1，以及完整变系数族

后一族对任意 p≥5|D 直接用源进位闭合；D为任意3幂时保留完整3幂给共同素数3。端点没有留下待算的无界参数。

## 新前沿怎样写

一般必要系统保持原定义：t3=C u，n=2mu C H+2，jk=N C u g²。半比值

    Theta=(n−1)(n−2)/(2jk)=lambda mu H/(u g²)

的最简分母为

    den(Theta)=u g²/gcd(u,lambda mu).

在两底分支，u的支持包含在C中，故 gcd(u,lambda mu)=gcd(u,g)=1。现在必须

    den(Theta)=u g²>1.

这没有给分母上界。实际剩余为 g>1 或 u>1：g=1,u>1；g>1,u=1；两者都>1，均尚可无界。一般粗底数、完整指数和n都仍自由。

## 路线诊断，不计作主要进展

首次定向问题是：只保留两个窗口时，是否已有两底模型或能强迫u=1？10^7以下4的倍数行的第一窗口CRT搜索得到10个两窗口弱模型，最小omega(t3)=3；这不能证明一般两底为空。

之后改从u=1恢复式生成点。g=1、H≤301、z≤20008的有界恢复没有点；完整韦达轨道却给出远高于该范围的无限g1u1弱模型，证明“没搜到”不能被当成全域结论。

为检验g=1是否可删除，另做g=2..49、H≤1001、z≤20000的规范恢复，共16,421,403个候选同余组合；只得到旧弱模型(2832832,957672)，其g=8,u=1,t3=5·7·283。它不能反驳或证明g>1两底命题，本轮不向该区域扩张结论。
