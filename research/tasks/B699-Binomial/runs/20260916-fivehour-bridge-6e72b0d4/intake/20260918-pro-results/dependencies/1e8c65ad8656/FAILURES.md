# 失败命题、弱化边界与何时重试

本文件记录实际可检验的数学诊断，不是内部思维过程。没有把探索样本升级为原题反例或无限完备表。

## F1. 首步反射整数，不能推出整条整数下降链

尝试对象：上一轮精确分母表给出两次原反射同时整数仅在 g∈{1,2},u=1，于是测试 g=2,u=1 的半整数二次递推是否仍能完整分类原输入。

错误命题：完整两个窗口且 g=2,u=1 ⇒ 原韦达反射可一直保持整数直到有限种子。

精确诊断：PROOFS §5 原输入 n=58107298636563670183229460572、j=9206228375889194192273417806。真实 Q=15/2，递推系数 Q−2=11/2。前三步整数，第四步为 23129447507749431719977641/2。源码与四步有理数见 CERTIFICATE 的 weak_g2_model。

这只反驳上述弱命题，不反驳加入 omega(t3)=2 或完整 alpha 条件后的新命题。本例有10个 t3 素数，且违反 alpha。

可重试条件：新的前提确实强迫所有后继坐标有足够2赋值，或采用带分母且保留原输入恢复的轨道理论；不能仅因前三步通过就重试相同归纳。

## F2. 单步原韦达反射并不保持 NC，且不是偶然样本失败

错误命题：Q 保持、r 整数、n 严格下降，足以构造 NC3 保持下降。

统一诊断：PROOFS §§2–3 的完整幂运输。在旧中间源 p^a 下，新 n*−1 含 p^(a+e)，固定 j−1 只含 p^e，故 a 个连续层必进位。采用 H>1 后，反射的新输入必有 H 作为共同因子。

只查看模 p 或旧 p^a 会掩盖该错误；必须看新完整 p^(a+e)。即使 g=2 的真实 gcd 保持，这个障碍也存在。

可重试条件：改变变换或目标不变量；或者使用不要求每一步保留 NC 的辅助分类，并另证原点约束。没有证据支持继续尝试证明这一原单步映射保持 NC。

## F3. 固定 g=2,u=1,H=5 及两个窗口不能给绝对高度

错误命题：真实两个窗口、孤立3规则与固定 (g,u,H)=(2,1,5) 足以界住 n。

统一诊断：PROOFS §6 给全部 r≥0 的显式矩阵族，n_r→∞。真实 Theta=15/4、范数域参数105也固定。因此固定一个二次域、固定某些小残量，并没有结束原整数输入高度。

反例级别：这是“弱条件蕴含高度”命题的反例族，**不是 B699 反例族**。所有成员有原共同素数197；它们不满足 alpha 二幂形状，也没有两底支持声明。

可重试条件：加入且实质使用 alpha=c2^s、omega(t3)=2、完整无进位条件或新的高度不等式。只增加该固定轨道的扫描上限无益。

## F4. 不能把一次变换的新共同因子搬回原输入

TP 的结论是 p^a 同除 C(n*,3)、C(n*,j*)。没有一般恒等式把这个共同因子送回 C(n,3)、C(n,j)。本轮特别保存 source_n/source_j 与 target_n/target_j，并用 original_and_target_swapped 损坏测试拒绝混用。

本轮没有产生新的原始 NC3 域排除；尤其没有声称闭合 g=2,u=1 两底切片。

## F5. 探索用 Pell 求解器不是无限完备性证据

实际运行：probe_pell_g2.py 对有限 D 和递推指数做诊断；probe_g2_many.py 的完成运行范围为奇 D=9..201、指数0..89、数值上限420 bits。结果只是发现弱输入，不是所有规范解或全部两底输入的分类。

主定理完全不使用 SymPy diop_DN 的完备性。无限弱族只采用明写的 T、整数种子、范数恒等式及有限周期证书，因此不需要任何 Pell 分类定理。

探测日志中的重复轨道命中不计成新数学实例。未找到两底模型不等于两底闭合。

## F6. 探索运算的真实运行边界

较早一次多 D 探索拟处理 D≤401、允许分解更大 C（约130 bits）时，在20秒工具调用窗口超时，没有得到可供本轮验收的完整输出。没有证据表明是 OOM，也不把它写成数学失败。

调整为 D≤201、420-bit递推截断、小素数先筛、只对低于56 bits且小素数不足三个的 C 做完整分解，串行完成。实际输出含2个弱模型。源码保留完成运行的版本；未成功的初版没有被重构为成功记录。

probe_g2_many.py 导入 probe_pell_g2.py 会再执行有限 pilot，这个已运行源码行为保留并在 README 标出。它不进入主证书重放，不能把其耗时作为证明成本或全局计算复杂度。

## 仍值得检验，但本轮未证明

- g=2,u=1 两底输入必有非常低的残量支持；能否在带实际恢复的半整数轨道上得到三个互素大因子？本轮没有全指数分解。
- 能否用 alpha=c2^s 与两底支持排除原非分裂曲线上的整数点？固定基域并不控制原输入高度，需新约束。
- 允许经过非 NC 中间点的复合映射是否能返回 NC 并严格下降？本轮只处理原单步反射，没有否定全部复合方法。
