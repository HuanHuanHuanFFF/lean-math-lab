## 本轮到底删掉了什么

继续上一轮两个负有理根族。仍用同一个原 n,j 的规范 λ,μ,g,H,C,u,z,ε,T,ρ，不更换窗口或去掉完整3幂。统一记

|κ|负根族|M|B（上一轮 ODD13 的同一 B）|
|---|---|---|---|
|1|ρ=A dM，d≥3奇|d²+2d−2|d²+d−3|
|3|A=27，ρ=dM，d≥5奇且3∤d|d²+6d−18|d²+3d−27|

新主结论：

> **两个负根族中的 B 为任意素数幂的参数域全部排除。**

更强地，同一 NC3 输入的实际二次奇因子满足

    3<Q0<B。

c=1 时进一步有

    Q0=gcd(B,n)，1<gcd(B,n)<B，
    gcd(gcd(B,n), B/gcd(B,n))=1。

因此 B 的完整素数幂必须一部分进入原 n，另一部分完全不在原 n 中。不能只留根基：对任意 p≥5、p|B，必须

    vp(n)=0 或 vp(n)=vp(B)。

只取入较低次幂或让 n 含有更高次同素数幂都不允许。

**孤立3没有省略：** c=3 时令 B'=B/3^v3(B)、Q'=Q0/3^v3(Q0)，准确结论是 Q'=gcd(B',n)、Q0∈{Q',3Q'}。不能一般写成 Q0=gcd(B,n)。这一修正仍足以排除 B 的全部素数幂分支；c=3、3∤B 时，原n内外的完整幂两侧非空也成立。

这不是上一轮的 M 素数幂消费者。采用旧 SIGN/RAT 完整根分类及旧 NEG 后，可约恢复三次的剩余表示必须同时满足 ω(M)≥2、ω(B)≥2。Pρ 不是实际内容 Ψ；没有由此证明 Pρ 总不可约或 ω(t3)≥3。

以上量词不设素数、指数、d 或 n 的扫描上限；不声称二次式取素数幂有已证明的无穷多个值，也未认证与全部历史消费者并集的非空差集。

## 新闭合的关键算术

从上一轮的本原因式分解保留

    E=am，W−E=2Ug²，U≥1，
    L0 Q0=n/2=cg2^(s−1)，Q0为奇数，
    Q0>BW²/(κ²m³)，m|M。

不把 Q0|cB 简化成一次模p检查，而是比较两个模g²关系的完整赋值，得到 Q0 的上述精确gcd恢复。

同时 W>2g²、Q0≤cg 给出新严格式

    4B Q0³<κ²c⁴m³≤κ²c⁴M³。

若 Q0≥B，则4B⁴<κ²c⁴M³。三个全区间八次正系数多项式排空大区；孤立3的两条小边界直接矛盾，剩余只有 κ=3,d=5,Q0=13 的四个完整系数状态，全部无整数坐标。

为避免重跑旧78状态链，另从旧纸面 d 界定向重建 Q0=1、3 的底部：只增加8个完整系数状态。**本轮共12状态、两个平方判别式，恢复根分别为0、11/37、13/73，没有合法本原坐标。** 这不是 n 扫描，也没有遗漏任何无限指数尾部。

## 新的补因子有限化

令真实正奇整数

    θ=cB/Q0。

新不等式给

    d²<8θ³，Q0<12θ²。

再接上一轮已经证明的 n²<2^27 Q0^15，得到

    n²<2^81 θ^30，n<2^41 θ^15。

c=1 时 θ=B/gcd(B,n)，恰好控制原n没有取入的 B 完整幂部分；这补上了只控制固定 Q0 的另一侧。固定 θ 后，原 n,j 真正有效有限，不留隐藏的无界g；但 θ 本身仍无界，界下全部终点没有被执行。

还定向澄清了13的赋值：若v13(n)≥2，则13∤Q0，而不只是Q0中最多保留一次13。这不单独记作新的整行闭合。

构造 r=1102+4524t（t≥0），
