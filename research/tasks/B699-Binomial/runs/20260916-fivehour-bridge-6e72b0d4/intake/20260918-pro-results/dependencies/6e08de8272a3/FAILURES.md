# 失败、弱模型、修正和重试条件

## 1. 一般 omega(t3)=2 尚未闭合

最初目标：联合 C=LR|t3、两端完整分配与 alpha=c2^s，尝试强迫 C=t3 或 u=1，或者消掉 P,Q 中一个无界底数。

结果：没有证明该命题，也没有找到满足其全部前提的反例。只得到两底族的精确参数形状以及一个立方匹配子分支的排除。不能把“有限样本没有解”升级成 u=1 或整个两底族无解。

重试门槛：需要新约束能把任意底数/指数压住，或构造真的满足两个完整窗口、真实 alpha/孤立3、gcd 与合法区间的 omega(t3)=2 弱模型。仅给固定 P,Q 的有限性不解决当前目标。

## 2. 弱窗口不等于 NC：三份精确数对

删除 alpha 形状后，在 4|n,n≤500000 的全部第一窗口 CRT 根中，有以下三个通过第二窗口的弱解：

|n|j|g|alpha|t3|C|u|
|---|---|---|---|---|---|---|
|76672|26775|1|76672|17425=5²·17·41|3485|5|
|175492|60606|2|87746|9919=7·13·109|763|13|
|335548|115092|4|83887|4726=2·17·139|2363|2|

第一个已在输入总览中出现，本轮复现，不计新发现。三者均不满足 NC 所需 alpha 形状；第三个甚至失去 t3 为奇数的结论。三个 t3 的 omega 都是3，**它们不能反驳“在完整 omega(t3)=2 前提下 u=1”这个尚未解决的命题**。

本轮又实际计算了原始两个二项式，其真实 gcd 分别为

    61723643520,
    266578490220,
    3884416727676.

全部含奇素数3，完整共同素因子列表在 outputs/WEAK_MODEL_CHECKS.json。因此它们不是原题反例，不是漏验。它们只诊断“只依赖两个源窗口便视为满足NC”或“无条件强迫u=1”的错误。

带真实 alpha 条件、512|n,n≤5000000 的有界搜索没有两窗口解；这不证明无界系统为空，且未枚举该范围内其他 n 行。

## 3. 立方消费者的非空增量未认证

命题 CUBE 已有完整纸面归约与有限端点，但原始谓词的全量 n≤5000 搜索只有2497个中心输入。第二算法完整复核到 n≤300，结果相同。

不能据此说“立方条件一定强迫 j=n/2”；也不能说“已认证了新的非中心原始实例”。中心数对本来就被短 NC 前置排除。

与旧平方条件的差集可以非空，例如(8,4)，但仍被其他旧消费者覆盖。因此没有完成相对于全部旧消费者并集的非空差集证明。后继不得把这一状态擅自升级。

重试门槛：找到非中心原始立方输入并逐条核对旧消费者，或者证明新立方约束可进一步消去一般残量参数。仅扩大 n 的有限扫描不是主要成果。

## 4. 将精确立方换成变系数立方的障碍

新证明使用两个真实整数立方的差，必须有

    mu u²z=c2^r w³.

若改成 `mu u²z=D c2^r w³`，D 为自由的无立方因子整数，则出现 X³−D Y³，不能用相邻整数立方的最小间隙估计。D 固定时 Thue/对数界可能有效，但 D、其粗素数支持和高度都仍自由。

没有证明“D接近1”“D只有两个素因子”或“所有D受绝对上界”。除非加入能统一控制 D 的新原输入约束，否则不能宣称它给真正有限终点。

## 5. B/E 桥接不自动给一般类群消失

精确新身份将 p≥5 的共同不变量赋值变成 vp(u)，二次平方类变成 sf(3lambda z)。这消除了符号不明，不会自动限制 u 或 z 的粗素数支持。

本轮没有重做 B 的一般类域论。不能从两个已闭合底域推广到全部二次域，也不能只扩大二次域表后计为一般原题推进。原始恢复式 nI=3ell(b0−c0)、jI=b0(b0−c0) 始终保留。

## 6. 两处容易发生的公式错误：最终版本已纠正

- `mH=n/2−j`，不是 `m=n/2−j`。因此端部上是 mH≡±1，不是可直接写 m≡±1。最终证明只使用正确形式，并由 gcd(g,H)=1 推出 g|m。
- 内容整除的组合恒等式必须包含 binom(3,r)：

      binom(n,j)F_r=binom(n,3)binom(3,r)binom(n−3,j−r).

  忽略此因子会写出错误恒等式。最终 NC 内容结论仍成立，因为这个因子是整数；代码逐项回归正确版本。

## 7. 工具诊断不是数学失败

符号核验第一次直接在有理函数系数域求 discriminant 时，SymPy 的启发式 gcd 抛出 HeuristicGCDFailed。改为先计算四个独立系数的一般三次判别式，再代入并验证分子多项式恒等于零，完成精确核验。

随后发现脚本中空乘积 r=0 的 Python 除法曾引入1.0，导致本应为零的符号式检测失败。最终改为显式 SymPy Rational，全程精确。两次未通过的中间输出没有被记为成功证书；冻结脚本与 IDENTITY_CHECKS.json 对应最终通过版本。

探索脚本在 --no-shape 情况下原计数字段名 alpha_shape_pairs 不够准确；已更名为 post_filter_pairs，并附 require_alpha_shape 字段，两次搜索重新执行。数值结果未变化。

外部检索没有提供本轮采用的新定理；没有把无法访问的 PDF、CAS 完整点表或一般出版结果加入主证明。
