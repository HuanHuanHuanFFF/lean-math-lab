原题：所有自然数 1≤i<j≤floor(n/2)，存在同一个素数 p≥i 同除 binom(n,i)、binom(n,j)。本轮只处理 i=3，即合法 4≤j≤floor(n/2) 与共同奇素数。

**一般 i3 未闭合；R7={3,4,5,6,7,8,9} 不变；没有原题反例。** 本轮新增纸面充分消费者与精确有限端点；没有 Lean、独立研究者/人类审读、全体旧消费者差集认证或一般绝对高度。

原总览已关闭的两块、旧两位 E=4/5、平方条件、t3≤100000、t3素数幂、缺失分配、R=7、薄系数d≤9、旧估值低条带和指定RQ128区域不重新列为主目标。旧结果仍保留原作者等级，本轮没有重跑这些证明。

## 2. 同一原输入的规范系统

NC3 表示合法原数对没有共同奇素数。置

    k=n−j, g=gcd(n,j), alpha=n/g=c2^s,
    beta=j/g, gamma=k/g.

c∈{1,3}；c=3必须v3(n)=1、3∤g。短前置给4|n、alpha偶、beta/gamma奇互素、j<n/2。旧前沿另有更强估值约束。

lambda=3 iff v3(n−1)=1，否则1；mu=3 iff v3((n−2)/2)=1，否则1。lambda mu∈{1,3}，c=3时两者均为1。

    N=(n−1)/lambda, K=(n−2)/(2mu),
    N|j(j−1), K|j(j−1)(j−2).

完整分配：

    N=ab, a=gcd(N,j), b=gcd(N,j−1);
    K=LHR, L=gcd(K,j), H=gcd(K,j−1), R=gcd(K,j−2).

各源幂完整、各块互素。规范残量：

    t3=beta gamma/N,
    C=gcd(K,t3)=LR, H=K/C, u=t3/C,
    z=(j−1)(k−1)/(N H²)>0.

必要关系：

    C u g²−zH²=lambda, gcd(u,z)|lambda,
    n=2mu C H+2,
    q=mu C, j=(q−m)H+1,
    1≤m<q, g|m, mH=n/2−j,
    lambda(q²−m²)=z(n−1).

窗口/恢复关系不能反推完整NC；恢复候选仍须核验真实gcd、alpha、孤立3、整数性、区间与全部进位。

旧作者前沿仍可按源等级使用：

    a,b,L,R≥11, H>1,
    t3>100000, omega(t3)≥2,
    n≤3(C²−1)≤3(t3²−1),
    g^4<3n,
    n<11u^5z^4g^7,
    v2(n)≥4v2(j)+9.

它们都不是一般绝对有限化。

## 3. 本轮新判据 CUBE：可直接作用于原题

对全部合法原输入定义

    M(n,j)=(nj(n−j))²(n−2)(j−1)(n−j−1).

**M 为整数立方 ⇒ 存在共同奇素数。** 判据不命中只能记 UNKNOWN。实现为 `scripts/cube_consumer.py`。

在同一 NC 系统内，下列三件事等价：

    M为整数立方；
    2mu u²z/alpha为正有理立方；
    mu u²z=c2^r w³，其中r=(s−1) mod3，w正整数。

本轮证明最后这个匹配分支不可能，完整论证在 PROOFS.md §§1–6。它对粗底数/指数、g,u,z,H都不限界。

核心短证明：C>2lambda 时由恢复与奇偶性得到

    2u g²<lambda mu H.

设 s−1=3h+r、A0=c2^r。匹配条件把同源方程变成

    A0[(u g2^h)³−(wH)³]=lambda mu u²H+u³g²>0.

相邻整数立方间隙强迫

    64A0u z²g^6<lambda^6mu^4≤729.

但g偶时g^6≥64；g奇时8|z。因此左边至少4096，矛盾。C≤2lambda时恢复给n≤108，全部2601个原题数对已完成共同奇素数证书。

主证明只使用重建的短前置；不依赖旧大表、THIN9、VG8、R=7 Pell、旧整点分类或类域论。

## 4. 与 B 实际三次式的精确连接

使用实际

    F(Y)=sum binom(j,r)binom(k,3−r)Y^r,
    hF=content(F),
    Psi(Z)=Z³F(1−1/Z)/hF=ell Z³−b0 Z²+c0 Z−d0,
    I=b0²−3ell c0,
    J_B=2b0³−9ell b0c0+27ell²d0,
    Delta=Disc(Psi).

NC下ell=2^s，d=m/g>0，且

    I=9t3/(lambda c²),
    J_B=54u d/(c³lambda mu),
    Delta=27u²z/(c^4lambda³mu²),
    gcd(C,d)=1.

从而

    gcd(I,J_B)去掉全部2、3幂 = u去掉全部2、3幂,
    Delta平方类 = 3lambda z的平方类.

若调用 B 的旧分歧定理，其粗分歧支持是 `{p≥5:3∤vp(u)}`。本轮没有重证该类域论，也没有给一般二次域或支持加界。

更直接地，对**全部原输入**有

    (2Delta/ell)(n hF)³=M(n,j).

所以新充分条件也可写为 `2Delta/ell∈Q³`。原始整数恢复一直保留：

    nI=3ell(b0−c0), jI=b0(b0−c0).

一般三次式不是原题输入，不可绕过这两式。

## 5. omega(t3)=2 尚剩什么

采用旧 L,R>1 后，若 omega(t3)=2，定向写

    L=P^ellP, R=Q^ellQ, t3=P^A Q^B,
    beta=aP^A, gamma=bQ^B,
    u=P^(A−ellP)Q^(B−ellQ).

本轮只排除了满足

    mu P^(2(A−ellP))Q^(2(B−ellQ))z=c2^r w³

的整匹配分支。没有强迫u=1、C=t3，没有给P,Q或指数绝对界。

所有一般n,j,g,s,t3,C,u,z，a,b,L,H,R的支持与完整指数仍无界；非匹配立方类与一般两底族仍未知。
