# 失败边界和不应升级的结论

1. 没有新增整指标闭合。R7与58族不变，a,b,g、粗素数种类、最大粗素数仍无统一绝对界。新结果是明确源类消费者。
2. S为旧U+F整理，不能宣称新的更强全局指数。CP是无限结构的消费，不声称其所有实例从未被其他历史消费者覆盖。
3. Φ1、Φ2、Φ4必须保留异常权重。B=13时Φ4(B)=170的完整S25=10，10^4>170；因此把全部圆分因子都归入四次根光滑界是假的。源码亦检查1、2的反例。
4. 底数条件gcd(B,10)=1、C<B、有限支撑u、CP权重和最终400|n均不能省略。不同因子可不互素，但需要完整赋值相加，不是rad。
5. 固定E只得到有限形状，不界B/C。e=0空乘积N=C或N=Φ1(N+1)能够编码一般整数；不能用“固定一个表示后有限”替代所有表示统一有界。没有把CP失败称作整数NC9存在。
6. A+未排除h≡2、3 mod6。h14的模7根为单根，可以逐层提升；多扫模数不是完整消除路线。A−只采用声明的奇指数1、5两类。
7. notes/PROOFS.md§5的真实整数族有完整(3,1)、gcd和大小性质，但11是实际共同素数。既不是反例，也没有被声称满足全窗口NC9、标量和cuts。它只否证“所列投影已经矛盾”。
8. 多个满足S的数可相乘，并不表示任意Common9见证在放大后保持。没有NC9保留、原题合法性保留且严格减小量的下降。
9. 源诊断抽样、两种整数实现、损坏测试和逐字节核对只用于相应检查。没有完整原题有限枚举，也没有历史数学重验或Lean。
10. 实现记录：第一次diagnostics.py在最后大例构造处将multiplicities作为profile的不存在关键字，导致TypeError。原stderr保留在logs/diagnostics-first-failure.stderr.txt；修正实参传递后整个诊断和新完整入口重跑通过。不把失败运行计为接收成功，也不伪称这是数学反例。
