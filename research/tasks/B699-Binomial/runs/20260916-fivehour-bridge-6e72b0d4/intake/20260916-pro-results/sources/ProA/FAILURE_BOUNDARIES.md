# 失败边界与重访条件

## 已经补齐的旧障碍

“存在一个次数小于总行权的非零形式核”不足以排除其合法零点。本轮使用两个明确整数核；当两者同为零时，令形式N取0后的两多项式通过固定非零Sylvester行列式给n|R0。零分支由绝对高度处理，未把整除零用成大小矛盾。

模素数核本身不能提升到有理核。本轮在649×650矩阵上给出两条真实整数左关系及647阶非零模子式，先证明rank_Q=rank_Fp=647，再以整数伴随矩阵定义核。没有使用未证明的“模秩就是有理秩”。

## 保留的低收益探索

1. 初始要求G(0,X)为常数的若干模板过强；一般右核反而允许两个限制多项式互素。相应发现日志保留，不登记为原题覆盖。
2. 一次探索脚本导入尚未加main保护的模块，重复打印了已经有的模块级探针；之后加保护。没有重跑历史数学全链；这些重复输出不计作新验收。
3. H012自由行为{3,4,5,6,7,8}。仅对13个指定的D=W模板，D∈{12,16,20,24,28,32,36,40,48,56,64,72,80}、预置U(U−1)V(V−1)，模1000003得到满列秩。准确剖面见logs/h012_probe.json。这只排除了这些固定线性空间，绝不说明所有多项式、权重、非对称核或联合算术方法失败。
4. H013的倒数和2719/2520>1；H012的对应和2509/2520<1只是候选路线的启发式区别，不是H012不可解证明。

## 未展开对象及仍有效的结论

整数G0,G1和固定R0通过有限矩阵、行列式、伴随矩阵完全定义，均可执行构造；本轮没有计算/打印其巨大整数展开，没有分解R0。完整非零性和明确系数/高度界由有限证书严格支撑。这不同于未指定核存在，也不等于Lean内核接受。

## 仍无界的量

57族是模板数，不是有限候选数。56个单高幂族仍有外层指数；α=2^a5^b仍有a,b以及g、β、粗素数支持。该双高幂族只剩(1,2),(2,1)，未整体闭合。

H013有绝对反例高度并通过旧局部桥闭合；这不是一般i9高度。R7仍为{3,4,5,6,7,8,9}。未产生NC保持的下降，也未找到原题反例。

## 下一判别点

优先考察H012：改变已经失败的D=W对称预因子模板，尝试允许小正次数差，同时保留更高原点阶以消g，或利用非自由最大行的真实完整幂/旧cut。第一判别应是精确可提升的核及N=0消元是否非零；若只得到模素数核而缺精确秩提升，或零支仍未受控，不登记有效有限化。不要重跑本轮H013发现或旧84/60/58族搜索。
