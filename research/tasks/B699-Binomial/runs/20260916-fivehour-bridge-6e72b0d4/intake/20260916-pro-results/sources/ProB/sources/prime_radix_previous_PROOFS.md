# 完整推导：奇素数进制的首位／尾块约束与两位整行

日期：2026-09-15。对象为全部自然数 `4≤j≤⌊n/2⌋`，Common 表示存在同一个奇素数 p≥3 整除 `C(n,3)` 与 `C(n,j)`。NC3 是其完整否定。以下的 P 是用于表示 n 的奇素数，未必为最终共同素数。

本轮为作者纸面证明；固定系数8消费者另有明确有限证书。没有 Lean、独立数学审稿或人类审稿，不主张新颖性。原件保持原字节。两投影不等价于 NC3。

## 0. 最强结论

**PREFIX（任意尾块，非零位数不必固定）。** 设 P 为奇素数，

    n=A P^E + B P^f，E>f≥1，1≤A<P，1≤B<P^(E−f)，P∤B。

设 P≥5，或 P=3 且 f≥2。如果

    P^f > 3AB+2，

则该 n 的全部合法 j 满足 Common。B 可以有任意多个非零 P 进制数字。这不是仅处理下一档固定复杂度。

**PROFILE（两位的统一指数限制）。** 进一步令 1≤B<P。若该行有 NC3，则 f≤2、E≤8。更准确地，P≥5 时 E≤2f+4；P=3,f=2 时 E≤7；孤立三分支 P=3,f=1 时 E≤4。因而 f≥3 或 E≥9 的全部两位行无需新有限大表即可闭合。

**COEFF8（完整整行，含唯一有限底部）。** 对所有奇素数 P、E>f≥1 及

    1≤A,B≤min(8,P−1)，

行 n=A P^E+B P^f 的全部合法 j 满足 Common。P,E,f,n,j 均没有预设上限；P=3 的一次幂取消已单独处理。

特别地，对 P=3、5、7，任何被 P 整除、P进制非零数字最多两处的 n 都完整闭合。一处非零数字的情形直接由§3处理，不要求该数字≤8。

由这些结论，任何真正反例中，若某个奇素因子 P 对应的 n 恰有两个非零 P进制位，那么必须

    P≥11，f∈{1,2}，f<E≤2f+4，max(A,B)≥9。

P,A,B 仍可无界。一般二幂 n 没有这样的奇素因子，本模块没有解决那部分。

## 1. 必要的旧前置：本轮完整重写，不重复计功

### 1.1 进位、α及4整除

Legendre 地板差给，对任意素数 p，

    v_p C(n,j)=Σ_(h≥1)[j mod p^h > n mod p^h]。

它来自 `v_p(n!)=Σ⌊n/p^h⌋`；每项非负。若 p|C(n,3)，NC3 必须使所有项为零，而不只是某个已出现幂层为零。

令 g=gcd(n,j)、α=n/g、β=j/g。由 `β C(n,j)=α C(n−1,j−1)` 及 gcd(α,β)=1，α|C(n,j)。任何奇素数 p≥5 若整除 n，也整除 C(n,3)；p=3 只有 v₃(n)=1 时可能被3!完全取消。故

    α=c2^s，c∈{1,3}；c=3⇒v₃(n)=1。

n 奇时，合法性 α≥2β 只允许 α=3,β=1，于是 n=3j。取 n−2 的任意素因子 p，它≥5，NC3 强迫 j modp∈{0,1,2}；但 3j=n≡2 modp 将使 p 整除2、−1或−4，矛盾。

n 偶且 v₂(n)=1 时，α∈{2,3,6}，互素性与半区间仍迫使 β=1。对于 n=tj、t≥2，n−1|3j(j−1) 及 gcd(n−1,j)=1 将迫使 n−1|3(j−1)。t≥3 时右侧为严格较小的正数；t=2,j≥4 时比值严格在1与2之间。故

    NC3 ⇒ 4|n，j<n/2。

n≥8 自动成立。n−1 的完整幂条件用于上面：p≥5 的所有幂 p^e|n−1 给 j modp^e∈{0,1}；p=3 只允许分母取消一次，故始终有弱窗口

    n−1 | 3j(j−1)。                                  (W1)

### 1.2 完整三窗口给 g⁴<3n

定义

    λ=3 iff v₃(n−1)=1，否则1；
    μ=3 iff v₃((n−2)/2)=1，否则1；
    N=(n−1)/λ，K=(n−2)/(2μ)，V=λ³μ²∈{1,9,27}。

N,K 为互素奇数。NC3 给完整投影

    N|j(j−1)，K|j(j−1)(j−2)。                         (Π)

若 v₃(n−1) 或 v₃((n−2)/2) 至少2，3已经整除 C(n,3)，于是第二个二项式的全部3层都须无进位；对应完整3幂仍在 N 或 K 中。没有把它削成分母取消后的较小幂。

记 k=n−j，C=gcd(K,j−1)，F=K/C。K 的每个完整奇素数幂唯一分配到 j,j−1,j−2，因此

    H=jk/(NF)，U=(j−1)(k−1)/(NC²)

为正整数。N 同时整除两个分子；C整除 j−1 与 k−1；F整除 jk。g 与 NF 互素，故 g²|H。并且

    H²U=4V j²k²(j−1)(k−1)/[(n−1)³(n−2)²]。

用 jk≤n²/4、(j−1)(k−1)≤(n−2)²/4 得

    16(n−1)³g⁴≤Vn⁴≤27n⁴。

对 n=8+r，r≥0，

    48(n−1)³−27n³=21r³+360r²+1872r+2640>0。

于是

    g⁴<3n。                                          (G4)

这条大小链来自冻结 D-as-B／本会话数字稿；本轮不重新计为新发现。它本身只需4|n及完整Π，不依赖α形状。没有三次判别式、Padé或出版高度。

## 2. 核心新引理：首位／尾块的联合行列式

先完全不提素数。假设正整数 T,A,B,X 满足 T>A，且

    n=T(AX+B)，j=T(uX+v)，0≤u≤A，0≤v≤B，4≤j≤n/2。

设

    Δ=Av−Bu，d=gcd(AX+B,uX+v)，g=Td。

若 W1 和 G4 同时成立，则

    n≤3(A+T|Δ|)²+1，                                 (CAP)
    T d²≤3|Δ|+2≤3AB+2。                              (DET)

证明：Aj−un=TΔ。令 y=u+TΔ，整数多项式身份为

    3A²j(j−1)−3y(y−A)
      =3u(n−1)[2y−A+u(n−1)]。

故 n−1 整除 Z=3(u+TΔ)(u−A+TΔ)。Z不为零：若首因子为零，T|u、0≤u≤A<T，得u=0,Δ=0,v=0,j=0；若次因子为零，同理u=A,Δ=0,v=B,j=n。均不合法。

因此 n−1≤|Z|≤3(A+T|Δ|)²，得到 CAP。

令 S=3(A+T|Δ|)≥3。G4与CAP给 g⁴<S²+3。g²,S为整数，如果g²≥S+1，则g⁴≥S²+2S+1>S²+3，矛盾。因此

    T²d²=g²≤3(A+T|Δ|)。

除T后，Td²≤3|Δ|+3A/T<3|Δ|+3。取整数得 DET。|Δ|≤AB由系数区间给出。

完整d²保留下来，未改成d或根基。这个引理只是(W1,G4,共享表示)的必要后果，不反向识别NC3；零行列式Δ=0也未被跳过。

## 3. 从奇素数无进位到共享表示

设 P奇素数，n=A P^E+B P^f，E>f≥1，1≤A<P，1≤B<P^(E−f)，P∤B；令 T=P^f、X=P^(E−f)。P≥5时v_P C(n,3)=f；P=3时等于f−1。因此先要求 P≥5 或 f≥2。

在NC3下P不整除C(n,j)。由全部进位为零，j的每个P进制数字不大于n相应数字。最低f位全零，首位不超过A，尾块不超过B，故

    j=T(uX+v)，0≤u≤A，0≤v≤B。

B不要求是单个P进制数字。条件P^f>A成立，应用 DET 得

    P^f≤3AB+2。

所以反向严格不等式正是 PREFIX 的整行消费者；对每一个合法j分别反证，未只处理已经满足共享表示的j。若j不是这种无进位表示，则P本身已经是共同素数。

若n仅有一个非零位 n=A P^E、1≤A<P、E≥1，且P|C(n,3)，同一论证给j=uP^E、g≥P^E。但

    (P^E)⁴>3A P^E=3n

（P≥3,E≥1 时 P^(3E)>3A），与G4矛盾。P=3,E=1只给n≤6，无合法j。由此所有单非零位行均闭合。

## 4. 两个非零位：两个指数统一受界

现在再要求 B<P，故 A,B≤P−1。

### 4.1 通常分支 P≥5，或P=3,f≥2

由 DET：

    P^f≤3AB+2≤3(P−1)²+2。

对P≥3，

    P³−3(P−1)²−2=(P−3)P²+6P−5>0，

故 f≤2。

由 CAP：

    n≤3[A+AB P^f]²+1。

又 A+ABP^f≤P−1+(P−1)²P^f<P^(f+2)。P≥5时

    n<3P^(2f+4)+1<P^(2f+5)。

n≥P^E，故 E≤2f+4≤8。P=3,f=2时，直接 n≤3(2+4·9)²+1=4333<3^8，故E≤7。

### 4.2 唯一例外：P=3,f=1

此时3可能被3!取消，禁止用3的无进位去限制j。由于A,B∈{1,2}且NC3要求n偶，必有A=B。

    n=3A(3^(E−1)+1)，A=1或2。

3^d mod8仅由d奇偶决定，故v₂(n)≤3。§1.3给n<100，因n≥3^E而得E≤4；继而由529项小基例排除。这个分支没有使用错误的3位支配。

PROFILE的全域无表结论f≥3或E≥9，来自上述不等式；孤立三若E≥9，直接n>100矛盾，甚至不需小基例。

## 6. 能接通什么，仍然缺什么

1. PREFIX覆盖任意复杂尾块B的一个完整区域，全部高位E无需固定；PROFILE进一步把两位行的最低、最高指数均界成绝对常数，而非从3个1扩到4个1的单档扫描。
2. COEFF8只需几百参数行，没有调用旧百万β、v≤36或Padé有限表。P=3,5,7的两位情形因此无需指数上限。
3. 对任何真正NC3，若n在某个奇素因子P的进制中恰有两个非零位，剩下只可能P≥11、max(A,B)≥9、f≤2、E≤8。P,A,B仍无界。这不是一般i3有限化。
4. 本轮没有给一般n找到必满足PREFIX的素因子；二幂行不在该奇素因子入口内。平方根四块、规范缺陷、F、min C_s仍无界。
