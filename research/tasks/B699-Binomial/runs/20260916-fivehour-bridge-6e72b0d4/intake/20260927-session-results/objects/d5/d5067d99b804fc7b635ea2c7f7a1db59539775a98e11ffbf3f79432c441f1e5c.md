本轮：四个完整有效核对及一个系数可无界的普通范数条件族被排除；历史净差未审计，认证历史净删域0。不是Lean或完整B699证明。

## 重放

Python 3.10或更新版本，仅标准库，使用正常解释模式（不要加`-O`）。在解压根目录运行：

```sh
python scripts/replay.py --receipt /absolute/path/outside-the-bundle/r10-replay.json
```

该操作核对载荷清单，在外部临时目录重新生成7份证书，逐字节比较，运行分离接收和10项篡改测试；不会修改载荷。

绑定最终ZIP字节并执行全新解压：

```sh
python scripts/verify_zip.py /absolute/path/B699-C-pair-pell-obstruction-r10-20260927.zip \
  --receipt /absolute/path/outside-the-bundle/final-replay.json
```

## 文件组织

- 根目录：报告、证明、失败边界、交接、状态、来源采用说明。
- `scripts/`：发现器、分离接收器、篡改测试、只读重放、最终ZIP验证器和探索程序。
- `certificates/`：7份确定性主证书。
- `sources/`：Overview和R9冻结原件/接收哈希。
- `logs/`：本轮实际执行、探索、研究审查及篡改回执。
- `replay/`：载荷ZIP的实际干净解压回执。

`PAYLOAD.sha256`覆盖核心载荷，不含清单自身和随后生成的重放回执。`SHA256SUMS`覆盖最终全部成员但不包含自身。最终ZIP哈希只写入包外回执，避免自哈希循环。
