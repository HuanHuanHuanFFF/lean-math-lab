# Interrupted invocation, not a PASS

An initial full replay was invoked directly through the container tool with too short a tool timeout. It was terminated while receiving the two largest new profiles. No complete REPLAY_RECEIPT was emitted, and its partial results are not used as the author acceptance.

A subsequent attempt to request an interactive execution session was rejected by the tool with `StreamingExecNotEnabledContainerError` before starting the replay.

The author run was then restarted from a genuinely fresh output directory, keeping its own console and exit-status file. It regenerated all geometry and all resource checks and completed with process exit code 0. Only this completed run supplied the delivered positive certificates.

There is no deferred user task or external monitoring. All computation and delivery occur within this response.
