## 重放

需要Python 3.10或更高版本，主重放只使用标准库，不联网。

    python scripts/replay.py --receipt /absolute/path/replay.json

该命令校验载荷SHA，重新生成5份证书，比较逐字节输出，运行不导入发现器的接收器、重算完整诊断箱并执行8种篡改拒绝。绝对路径回执必须位于包外，不能写入冻结载荷。

单独检查一份可展开的普通整数菜单：

    python scripts/check_menu.py 0 29 3 1

参数依次t,b=a-t,E,W。资源保护上限不是数学上界。输出不声明NC；即使恢复普通j，也仍列出原源及未查的历史门。固定大幂失败菜单由certificates/integer_menu_family.json与证明承担，不尝试展开3的天文指数。
