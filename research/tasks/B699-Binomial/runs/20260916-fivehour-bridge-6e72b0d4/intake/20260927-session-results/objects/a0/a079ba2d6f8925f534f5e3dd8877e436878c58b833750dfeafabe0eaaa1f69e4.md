# REPLAY — 仅重生成本轮新研究

依赖：Python 3.10+标准库、g++支持C++17。正式重放无需联网或SymPy，不运行Lean，不读写仓库。

从ZIP解压后的根目录执行：

```
python code/verify_manifest.py
python code/replay.py --out /absolute/path/not-yet-existing --jobs 2
python code/compare_replay.py . /absolute/path/not-yet-existing
python code/verify_manifest.py
```

输出目录必须事先不存在、且置于包外。进程只在输出目录生成二进制和临时结果。用--jobs 1可串行执行。

每次输出REPLAY_RECEIPT.json含代码哈希、输入清单哈希、全部确定性证书哈希、环境和准确计数。compare_replay核对证书完整文件集合及全部字节，且核对运行源码与解压包。

MANIFEST.sha256覆盖除其自身外的整个交付载荷。包内CLEAN_REPLAY_RECEIPT绑定一次干净解压载荷验证，不自引用；最终ZIP另以外置FINAL_ARCHIVE_REPLAY_RECEIPT绑定最终ZIP的SHA-256并记录最终ZIP自身重新解压的完整重放。不要将环境时长、日志计时不同误当数学证书不同。
