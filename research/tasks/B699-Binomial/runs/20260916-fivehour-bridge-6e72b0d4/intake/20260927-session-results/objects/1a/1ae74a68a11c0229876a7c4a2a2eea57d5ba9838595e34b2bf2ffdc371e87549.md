# 失败边界与不允许的回传

## 1. 本轮没有取得的结论

R7={3,4,5,6,7,8,9} 不变；没有完整 B-RES10、一般 i=6 或 B699 闭合；没有 Lean；没有一般绝对高度、统一可执行有限末端或保持 NC6 的严格下降。未审计所有历史消费者，故“相对历史覆盖的认证净删域”记为 0，而不是由 81 个样例、8 个剩余类或 6 个 CRT 样例推算。

本轮证明了原输入数对的充分消费者。该消费者的无界覆盖域不等于“当前主线尚未覆盖的无界域”：用于证明其非空、无界的实例没有纯三幂 α，已不在当前完整 B-RES10 残域中。

## 2. 源窗口不是完整 NC 的等价模型

对 p^e||q_r，NC6 必须有 j mod p^e∈{0,…,r}；反过来，仅满足此窗口不能保证 p 不整除 C(n,j)，因为 p 的更高层仍可能进位。即使所有 r 的有限窗口都成立，也不能直接反推 NC6。

q4=E4 A4 C 只在完整第四源已满足时使用；实际输入的 gcd 可以仅吸收部分 p 幂。例 (151,16)：q4=49、C=7，完整层仍失败。不能以 rad(q4) 代替 q4，也不能把 C² 强制整除误写为源指数 2e。

## 3. 允许落点表没有给出充分恢复

近侧要求 (10/p)=1，中央要求 (30/p)=1。两者同时为 −1 时只允许端点；这不是说端点一定存在真实 NC6 恢复。

B4-SIGN 的 (10/(E4C))=−1 排除正特征分配；仍可能 E4 平方、(3/C)=−1。条件 d≥77 只在 (3/C)=+1 时成立。总览没有给出 d4 的完整定义，本轮没有证明一般 d4≥1。

## 4. 中央奇指数的局部弱族

n=3·7^e+4、j=7^e+2（e≥1）保持原整数数对，p=7 的完整中央源、全部高层无进位以及任意精度的局部范数。但 v7(jk)=0，中央乘积估值恰为 2e。

未保持：全局整数 Y 的 W=10Y²、α=3^a、所有其他源、B-RES10 同余。它只反驳“上述局部条件蕴含端点额外幂或中央 2e+1”的命题，不是 NC6，也不否认全局条件能排除此分支。

## 5. q5 无界估值族的保留/丢失账本

取 PROOFS.md 第 7 节的准确量词：任意 A≥2、B≥4、E≥3、m≥2，选择所述 CRT 数列，必要时将首项增加一个完整周期，保证 q5>899。

| 条件 | 状态 |
|---|---|
| 同一原始合法 (n,j)，真实 gcd g=30 | 精确保持 |
| (n−1)|jk，U=jk/(n−1) | 精确保持 |
| 全局整数十倍平方 W=10Y² | 精确保持 |
| n≡5130 (mod9000)，指定 v3(n),v2(n−2),v5(n−5) | 精确保持 |
| p=31 完整源指数 e=1，近侧余数 j≡4,k≡1 | 精确保持 |
| 前 m 个三十一进制位置无进位 | 精确保持 |
| v31(U−1)=m，可任意大、任意奇偶 | 精确保持 |
| q2、q4、q5 非平方 | 六个证书保持；一般族取 B、E 奇数也保持 |
| α=n/g=3^a | 明确失败：α≡7 (mod8) |
| 完整第四源 q4=E4 A4 C | 明确失败：E4=C=1 而 χ10(q4)=−1 |
| 全部 q5 均在近侧 | 明确失败：Q51≤899<q5 |
| p=31 的所有高层 noCommon | 没有保持；六个证书都有更高层进位 |
| 全部指标原题反例/真实 NC6 | 否；U4-CHAR 给出 Common6 |

A 是 v3(n)，不是当前主线 α=3^a 中的 a。不能拿样例 A=42 去宣称已通过 a≥41 的规范门槛。

为了同时保留 n≡5130 (mod9000)，E 必须至少 3。E=2 与 n≡5 (mod125) 冲突；本轮量词复核已经修正这一点。全部计算样例是 E=27。等差数列首项移位只为保证 Q51<q5；不影响精确估值。

## 6. 计算证据的范围

32 个单位类是完整周期表；92 个小素数是回归，不是全素数证明。81 个一般消费者样例验证程序与原题回传，不是全部实例。6 个 CRT 样例验证构造实现，不能替代任意参数的根提升与 CRT 证明。

发现与接收代码由同一作者生成。不同算法（Jacobi/补充律、Legendre/进位、直接 math.comb）不构成外部独立数学审读。哈希与干净重放证明文件一致性及可重复执行，不证明所有纸面论证正确。

主源取回文本已读，raw-byte materialize 失败。包内来源快照没有原文件的字节级保真保证；其 SHA 只标识本包实际保存的快照。

## 7. 不应重复投入的路线

不要在缺少纯三幂 α、全 q5 近侧和高层 noCommon 时继续寻找 v31(U−1) 的统一常数上界；本轮已给该弱条件集的无限反例族。不要只凭中央奇指数和局部平方强迫端点增精度。不要把有限同余门槛继续增大说成统一有限化。

下一条有信息增量的检查应在同一原输入上使用完整 α=3^a 和全局本原范数，并联立 C²、q5 全近侧，处理 E4 平方且 (3/C)=−1 的残支。
