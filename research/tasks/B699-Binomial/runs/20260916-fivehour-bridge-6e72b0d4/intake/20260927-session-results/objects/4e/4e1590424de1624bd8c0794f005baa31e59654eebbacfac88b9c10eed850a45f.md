# FAILURE_BOUNDARIES

## 不得升级的结论

- R7不变；不得把 k=3 或 u=1 比例域关闭写成完整 m=1 首档、i=3 或 B699 闭合。
- `T2|Λε`、`T0|Hε` 只是必要条件。允许的常数槽分配并不等于真实 NC3。
- 同一数对子 Common3 不自动给整行；必须验证 n−1 恰为两个不同奇底完整幂，且恢复的是原唯一半行 CRT 候选。
- u=1 是新一般定理的真实假设。u≥2 时 X=uP+x0，不是 P+x0；不能代入本表伪造容量。
- 一般比例界仍有无界k。k=4局部有限范围不是全局有限化，末端本轮未做。
- 本轮没有证明一般 μ 绝对有界，也没有构造或发现原题反例。

## 完整幂与符号

- 原 R0<0,R1>0,R2<0 时 S=R0R1R2>0；本轮 D_s 为另一套原源一次式，不应与R_s混名。
- 约掉原槽的 P/Q 是在模 ℓ^E 上，因为 gcd(PQ,PQ−1)=1；没有截短 E。
- ℓ=3 只在原源赋值恰为1时不活动。两个证书中源是3²，j mod3=0但j mod9=3，不能按模3误判。
- 不可把 d|Q、整数恢复或概率素性标记替代 Q=q^σ；接收实例有完整阶素性证明。

## 历史依赖与重叠

- 新高侧 k=3 定理独立于旧根账本；“整个 k=3 首档闭合”需要采用旧边界已排空其余小z/低二幂域。
- 旧下界只读采用，未重放125,000行账本。包不是全历史依赖重放包。
- 旧 b=0、b=1..4、低二幂、m=2、z≤2 不重新计收益。
- k=3 回归实例也有旧原源拒绝，不能称先前存活 NC；8行不是8个未知案例。
- 未证明新域含无穷多个实际素数幂对；未审计全部更早子族的不重叠。
