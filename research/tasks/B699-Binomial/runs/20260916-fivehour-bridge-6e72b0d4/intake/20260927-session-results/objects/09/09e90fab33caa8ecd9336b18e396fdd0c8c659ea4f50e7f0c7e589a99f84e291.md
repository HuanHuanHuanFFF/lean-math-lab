# PROOFS — TAIL7-DOUBLE(8,9) 与固定 G 的 FRONTIER120

日期：2026-09-26（Asia/Tokyo）。证据等级：本轮作者纸面推导、确定性穷举和整数／有限域子式证书。没有 Lean 或外部独立数学审读。

## 0. 采用的接口与量词

原题仍为：对自然数 `1≤i<j≤floor(n/2)`，存在同一素数 `p≥i` 同时整除 `C(n,i)` 和 `C(n,j)`。本轮固定 `i=9`，所以素数条件等价于 `p≥11`。NC9 是否定该共同素数见证。原始 `(n,j)`、`k=n−j`、`J=j(n−j)` 不变，不对完整素数幂取根基或删去幂次。

采用冻结 K152 的同一非零整数辅助多项式 `G(N,X)`；本轮使用的接口处于已有 `400|n` 的 i9 入口。`N,X` 是辅助变量，不是一次新的原输入选择。采用后续 R12 / FRONTIER123 的 COVER8 与 EDGE8，以及 493 条可载因子的安全费用签名。没有在本轮重证明这些历史全链；精确出处和字节校验见 SOURCE_ADOPTION.md。

设 `h=deg_X G`，`v_r` 是 `N−r` 在 G 中的**全部重数**，`r=3,…,8`，`V=Σv_r`。设

    Gbar = G / ∏_{r=3}^8 (N−r)^{v_r}.

权次约定 `D(N)=1,D(X)=2`。八分量时，已采用的 EDGE8 给出

    E=305−2h−V=0,  D(G)=305,  D(Gbar)=2h.

因此 Gbar 的每个非恒定因子都平衡：`D(H)=2 deg_X H`。其 X 首系数为非零常数，故可以在 Q 上首一化；**不要求在 Z 上首一**。选取八个不同可载不可约因子，各选一次。它们的 X 次数之和不超过 h；额外重数和未选因子绝不能另算成第九个可载因子。

采用的可载因子接口还包括：这些因子的正普通源阶支持数 `z≥14`。本轮新引理本身明确包含这个假设，不将其删除或推给任意不可载因子。

## 1. 六源费用的同一 G 推导

21 个源点为

    P_{r,s}=(r,s(r−s)),   3≤r≤8,  0≤s≤floor(r/2).

对因子 H，设普通平面阶为 `m_{r,s}`，`μ_r=Σ_s m_{r,s}`，`q=deg_X H`。首一特化 `H(r,X)` 的次数仍为 q，故 `μ_r≤q`。定义 `Δ_r=q−μ_r≥0`。

在中心 `r=2s`，取局部坐标

    u=N−r,  t=X−s²−su.

设 H 的 `(1,2)` 权阶为 `w_r`，令 `κ_r=2m_{r,s}−w_r≥0`。只在 r=4,6,8 有 κ；奇数行 κ 恒为 0。真实费用为

    c_r(H)=2Δ_r+κ_r.

普通阶和权阶对乘法可加。对偶数行，

    c_r(H)=2q−2Σ_{s<r/2}m_{r,s}−w_r;

奇数行去掉 w 项即可。因此同一个 Gbar 上所有因子按重数计算的费用和不超过下述容量 C，而舍去未选因子与额外重数只会减小费用。

原普通源阶 OFF 与中心权阶 DIAG 为：

|r|OFF（非中心，s 递增）|DIAG|
|--:|--|--:|
|3|77,74|0|
|4|67,57|56|
|5|51,54,46|0|
|6|40,43,48|41|

剥去本行 `(N−r)^{v_r}` 后，对原始源下界逐项取正部。因此

    C_r = 2h − 2Σ_OFF max(OFF_{r,s}−v_r,0) − max(DIAG_r−v_r,0).

所有本轮价格都使用同一个 `(h,v)` 生成的六个 C，不从另一状态借容量。

## 2. 新几何定理：TAIL7-DOUBLE(8,9)

**定理。** 设 `q∈{8,9}`，`H∈Q[N,X]` 不可约，`D(H)=2q`，`deg_X H=q`，`z≥14`。如果

    Δ_7=2,  Δ_r=0 (r≠7),

那么

    κ_4+κ_6+κ_8 ≥ 1.

等价地，两个次数下真实费用恰为

    c0=(0,0,0,0,4,0)

的不可约可载因子域为空。该结论没有系数高度、分母或原始 n 的扫描上限。它不声称 q≥10 的同类结论。

下面反设所有 κ 均为 0，给出穷举与子式证书的完备性证明。

## 3. 五个饱和行决定全部六行多项式

首一化 H。除第 7 行外，五行饱和，所有 q 个特化根都由普通源根填满。因此对 r=3,4,5,6,8，

    F_r(X)=H(r,X)=∏_s (X−s(r−s))^{m_{r,s}}.

第 7 行先取 q−2 个普通源根组成 `B_7(X)`；其余因子是一个首一**有理系数二次式**，不要求分裂、不要求实根，也不要求常数项为整数。

对每行普通重复根定义

    s_r=Σ roots,   t_r=Σ_{a<b} root_a root_b.

写 H 的最高三个 X 系数为

    H = X^q − S(N)X^{q−1} + T(N)X^{q−2} + … .

权次给 `deg S≤2,deg T≤4`。由 N=3,4,5 三行，

    S(6)=s3−3s4+3s5,
    S(7)=3s3−8s4+6s5,
    S(8)=6s3−15s4+10s5.

所以第 6、8 行的普通根和必须等于这些值。尤其 S(7) 是整数，但这**不意味着**余二次式的常数项是整数。

由五个饱和行的 T 值，四次插值唯一给出

    T(7)=(-t3+5t4−10t5+10t6+t8)/5.

因此令

    L = 3s3−8s4+6s5−s7,
    B = −t3+5t4−10t5+10t6+t8−5t7−5L*s7,

则全部第 7 行必须为

    F_7(X)=B_7(X)·(X²−L X+B/5).

`L,B` 是精确整数，代码没有施加 `5|B`。若某个普通阶为 0 的第 7 行源值 x 满足 `5x²−5Lx+B=0`，则 H 实际在该源为零，和阶为 0 矛盾，可以剔除。若余二次式撞到普通阶已正的源，则必须保留；本轮确实保留。

## 4. 源线剪枝为什么是必要条件

对 t=0,…,8，设

    ell_t=X−tN+t².

代入 `X=tN−t²` 后，H 变成 N 次数至多 2q 的一元多项式。点 `P_{r,s}` 位于该线当且仅当 `t=s` 或 `t=r−s`。非中心点贡献至少普通阶 m；中心点因 κ=0 而有 w=2m，在该线上的 N 消失阶至少 2m。

所以定义线负载

    load_t = Σ_{r,s} m_{r,s}([t=s]+[t=r−s]).

若 `load_t>2q`，一元限制恒零，于是 `ell_t|H`，与 H 在 Q 上不可约且 q≥8 矛盾。**等于 2q 不剥除。** 不需要绝对不可约、亏格公式或数值近似。

## 6. 完整二维 jet 空间，不截断系数盒

令 `W=∏_{r=3}^8(N−r)`，以六行 F_r 作 Lagrange 插值得 H0。前两非首系数已经满足 N 次≤2、≤4；更低的 X 系数允许 N 次至少 6，而插值的 N 次至多 5。因此 `D(H0)≤2q`。

任意满足这六行值、权次至多 2q 的 H 都且仅能写成

    H=H0+WQ,   D(Q)≤2q−6.

证明是逐个 X 系数作六个不同 N 根的整除；反向直接代入。Q 的完整单项式基为

    N^a X^b,  a,b≥0, a+2b≤2q−6,

维数恰为 `(q−2)^2`。不限制 Q 系数分母或大小。

对普通源加入所有 `i+j<m` 的局部 Hasse 系数为零条件；对中心加入所有 `i+2j<2m` 的条件。`i=0` 条件已由固定行值满足，矩阵加入全部 `i≥1` 条件即可。于是关于 Q 系数和齐次 H0 坐标得到列数

    K=(q−2)^2+1 = 37 或 50

的齐次矩阵。

饱和 F_r 系数整数，第 7 行分母整除 5；六节点 Lagrange 分母整除 120。因此 **600H0 整系数**。接收器使用真正整数矩阵

    A_Z=[ W·N^a X^b 的 jet 列 | 600H0 的 jet 列 ].

若原首一 H 存在，那么 `(Q 的系数,1/600)` 是 A_Z 的非零有理解。

## 7. 非零整数子式排除每个完整系数族

主程序在 p=32749 和 p=32719 两个经试除确认的素数上，对每个配置产生一个 K×K 非零子式，记录具体 jet 行号和带符号行列式。所有 105,047 个配置均在两个素数上满列秩：210,094 次。

接收程序不调用主程序的二项式 jet 公式：它用 `(r+u)^a`、`W(r+u)`、`(x+su+t)^b` 的**局部多项式逐次卷积**重建整数列，以从右下向左上的消元求行列式。接收值逐项等于 `600×主记录值 (mod p)`，共 210,094 次；重复行、越界行、超出已知源阶的行均拒收。

整数矩阵的行列式是整数系数的多项式表达式，模 p 化与求行列式可交换。因此一个非零模子式说明对应整数子式非零，从而 Q 上满列秩。这排除了上述非零有理解。**没有使用“仿射系统模 p 无解就意味着 Q 上无解”的错误推理。** 例如 `p*x=1` 在 Q 有解而模 p 无解；它不提供本证明需要的满列秩方形子式。

另取 q8、q9 各自首、中、末三个配置的记录子式，用 Python 任意精度整数 Bareiss 消元计算六个精确整数行列式，每次除法核对余数为 0，结果全部非零，并核对其模 32749 值。六个整数值完整保存在 `certificates/exact_integer_minors.json`。

这完成 TAIL7-DOUBLE(8,9) 的作者级证明。两个素数、两生成器、两矩阵实现仍由同一作者完成，不等于外部独立审读。

## 8. 安全签名更新：不用“代理费用=真实费用”的额外假设

原始 493 行数值签名已与 R12 字节 SHA-256 核对一致。旧零基索引 431 为

    (e,c)=(8,(0,0,0,0,4,0)).

原安全签名的含义是：实际次数和实际费用逐坐标至少等于代理。不能反过来把代理当成实际缺重。

本轮只替换这一行。对该行的任何真实原像：若实际次数≥10，选新代理 `(10,c0)`；若实际次数为 8 或 9，定理排除真实费用等于 c0，所以至少一行有严格费用增加。奇数行的真实费用为偶整数，严格增加至少 2；偶数行至少增加 1。

因此使用七个安全后继：

    (10,c0),
    (8,c0+2e3), (8,c0+e4), (8,c0+2e5),
    (8,c0+e6), (8,c0+2e7), (8,c0+e8),

其中 e_r 是行坐标单位向量。这个保守分叉保留**全部**原像，不要求知道更大的实际缺重发生在哪行，也不把全部增量假设成 κ。其余 492 行不变，故 `493−1+7=499`。

这里的签名覆盖适用于八个选中的可载因子；未选中、不可载的因子只用费用非负性，不错误套用这些最低次数。

真实因子次数、费用至少为安全代理，且所有 w 非负，故不等式同样适用于实际选中因子。对八个因子相加，再用 `Σc≤C`：

## 10. 剩余前沿与证据终点

对原 123 状态，确定性 Bellman 计算生成新签名的八项费用结果。三个被删状态的下界另有上述整数价格，不依赖 Bellman 实现的正确性。其余 120 个状态均附一个八项**弱资源见证**，由单独 Python 接收器检查行号、次数和六行容量。这说明它们在本轮标量费用放松内仍相容，而非存在真实 G 分解。

因此，在采用的历史接口下：

    FRONTIER123 → FRONTIER120,
    新删 {1644,1868,1940},
    最低 h=113 仍有 {1643,1646,1650}.
