# INDEX

- REPORT.md：准确结果、净差与失败边界摘要。
- PROOFS.md：P0–P9完整条件、真实商、全指数矛盾、共享c门与回传。
- FAILURE_BOUNDARIES.md：零平方/非单位、局部族、来源与量词限制。
- HANDOFF.md、SESSION_STATE.json：下一A382入口与仍无界参数。
- certificates/01…09：本轮9份确定性证书。
- evidence/core.py：来源读取、规范序列化；不包含旧数学重放。
- evidence/generate.py：本轮证书生成。
- evidence/verify.py：不同源/根/原式/CRT公式接收。
- evidence/negative_tests.py：故意变更证书的拒绝测试。
- logs/：真实运行输出。
- inputs/：指定Overview及直接父原字节、HANDOFF和PROOFS。
- REPLAY.md、replay.py：离线重放说明与入口。
- ENVIRONMENT.json、SOURCE_ADOPTION.md、RESEARCH_LOG.md：环境/来源/研究过程。
- PAYLOAD_SHA256SUMS.txt、SHA256SUMS.txt、CLEAN_REPLAY_RECEIPT.json：摘要和实际干净重放。
