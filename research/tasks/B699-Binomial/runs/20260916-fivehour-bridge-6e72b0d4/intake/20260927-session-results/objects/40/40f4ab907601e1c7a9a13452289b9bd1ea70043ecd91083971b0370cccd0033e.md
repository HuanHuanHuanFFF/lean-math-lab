# 离线、干净目录重放

环境：Linux/POSIX、Python 3.10+标准库、GNU g++（C++17）。不需要网络或第三方Python库。不要用`python -O`关闭接收断言。

在解压后的证据包根目录执行：

```sh
python code/verify_manifest.py .
python code/replay.py --out /tmp/b699-s5q-tail18-fresh --jobs 2
python code/compare_replay.py . /tmp/b699-s5q-tail18-fresh
python code/verify_manifest.py .
```

`--out`必须不存在。程序在输出目录重新编译全部C++、构造本轮源界/商系统、重新枚举几何根门与所有多重集、核验全部子式和模块轨迹、逐格比较DP、执行损坏证书负控制，再生成REPLAY_RECEIPT.json。

完整重放重新生成117份确定性证书。比较器核对证书路径集合及每个文件的SHA-256，不将运行时长、临时绝对目录或日志路径作为数学证书内容。

它不会重跑LOW-T43或FRONTIER43内的历史数学链；这些明确作为冻结前置。不存在隐式网络调用、Lean或仓库操作。

## 回执避免自引用

包内`verification/clean_payload_replay.json`来自完整候选ZIP的干净解压重放，绑定该候选载荷。加入该回执后重新生成最终MANIFEST/ZIP，再对最终ZIP进行第二次干净解压完整重放；最终ZIP的精确SHA和回执在包外交付。回执不声称同时位于被自身完整哈希绑定的ZIP中。
