# FAILURE_BOUNDARIES — ZERO-SPLIT

## 1. 本轮究竟关闭到哪里

关闭的是：

- 交接恢复族 P=dv−1、Q=d(d+1)v−1、j=Qv 的全部原数对（d 为奇数≥3、v≥1），并在真实不同底完整两幂、v 偶数时提升为整行。
- 首档 P<dH<2P、规范次数 m=1 中，至少一个实际消元常数为零的全部原候选；以唯一 CRT 候选提升整行。

没有关闭整个中间壳、整个首档、整个 m=1、m=2 或一般 i=3。R7 不变。

## 2. T0=1 与光滑 n

旧交接的 T0=1、n=2^α 或 3·2^α 是正确继承的必要条件。本轮没有反向把它当充分条件，也没有声称解出了该指数方程。新第三源矛盾不需要这个限制，因而覆盖其交集。无需再为已排恢复支保留 α 为开放支参数；其他域的二幂指数仍可能无界。

## 3. PAIR 与 ROW 不得混淆

PAIR 是关于明确实际整数 (n,j) 的公共素数定理，允许中间 P,Q 合数多底；它并不声称这些 P,Q 满足两幂源假设。

ROW 提升必须单独验证 P=p^a、Q=q^b、p≠q、p,q 奇、P≥5 和 n−1=PQ 恰等式。脚本拒绝 (53,539)（Q=7²·11）、(9,27)（同底）、(3,5)（本消费者范围外），不把必要形状充作真实两幂输入。

PAIR 有无穷实际整数数对，ROW 是无高度截断条件定理；未证明满足 ROW 素数幂条件的实际行有无穷多组。

## 4. 零槽因子只能在完整重叠检查后剥离

从 n−2=AB、J=AC、gcd(B,C)=1 出发，若奇素数同时出现在 A、B，则完整赋值相加；它在 J 中只有 A 的赋值。因此原 NC 本身矛盾，不能直接取消 A 后遗失重叠指数。

例如 PAIR 输入 d=7,v=6 给 W=327，v 与 W 共享 3，原 n−2 含 3²。W 单独只含一个 3 并不意味着原第三源中的 3 被分母消掉。该例 Q 非素数幂，明确只作完整赋值边界测试。

## 5. 保留孤立的 3

只有 v3(原源)=1 时才除去因子 3；若原源赋值≥2，窗口仍是完整 3^e，不是 3^(e−1)。唯一有界末端 (n,j)=(6932,957) 恰由完整 3² 窗口排除；两个二项式的赋值分别为 1、5。

## 6. 不以必要容量冒充 NC 或关闭非零域

ZERO-SLOT-SPLIT 的容量整除是 NC 必要条件。即使某模型满足容量、两底 Lucas、原 n 光滑形状，仍不能称 NC3。

示例 P=7,Q=73,n=512,j=147 仍在本轮新消费者之外；它不是反例，第三源的实际素数 5（也可用 17）给公共整除。P=7,Q=37 是未被本轮结构定理覆盖的非零 m=1 示例，也不是 NC3 反例。

首档剩余 m=1 常数现在全部非零，故可合法使用旧 RES-LCM；T2|LCM 仍非充分条件，也没有由此得到统一绝对高度界。

## 7. 对称表达不是另一输入或严格下降

一般零位分类中，槽 2 可写辅助 J=n−j，用恒等式 C(n,J)=C(n,j)。证书同时存 original_n、original_j、auxiliary_J；没有声称 J 在半行，也未生成新原题候选，更不是严格下降定理。

## 8. m=2 的零根限制不等于有限化

A|e、A∈{±1,±2} 只限制一个辅助整数。P,d,k,n,j 以及底素数和指数仍无界；本轮未分类或关闭这些三次零常数恢复支。

## 9. 有限计数与历史净收益

20,000 个 PAIR 网格、714 个真实整行、135 个有界 m=1 零常数行、4,382 个逐项二项式输入都是明确范围内的证据，不是无限证明的替代品。

714 行中大量输入已有旧数值或源检查；135 行只有 22 个通过分块、21 个通过完整两底 Lucas。不能把原始形状证书数当成未知 NC 状态数。

对旧 P≤1000 证书的只读审计发现 9 个 m=1 零常数记录；它们此前已被其他源拒绝，本轮旧有限账本净新增 NC 排除数为 0。新的收益是无高度截断结构删除，而非虚报旧 finite frontier 的下降。

未核验全部更早历史子族，不能声称与未提供的旧覆盖无重叠。

## 10. 实现与审读边界

素性与分解采用确定性试除；大输入可能很慢，没有复杂度或统一快速分解保证。脚本不联网、不读旧聊天、不操作仓库。

证书生成和重放均为同一作者实现。整数多项式检查、Lucas/Legendre 与逐项整数二项式交叉检查提高可核验性，但不是 Lean，也不是外部独立数学审读。
