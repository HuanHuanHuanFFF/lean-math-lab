# REPLAY

```bash
python replay.py
```

验收顺序：

1. 检查最终SHA256SUMS.txt（内部payload回放阶段尚无最终清单时检查PAYLOAD_SHA256SUMS.txt）。
2. 执行独立接收器evidence/verify.py：核验父输入字节、不重证父数学；用Pell二进幂检查真实商周期、模3矛盾、Q336完整幂周期及原n接口；直接遍历共同周期重算父投影净变化；核对A100准确弱边界及非平方区间。
3. 在临时目录运行evidence/generate.py，八份新证书与包内文件逐字节相同。

生成器使用Pell递推和r+kM提升；接收器不导入生成器，使用Z[√3]二进幂和共同周期过滤。仍是同作者第二实现，不是外部独立审读。

手工接收：`python evidence/verify.py`。
手工再生成至外部目录：`python evidence/generate.py --out /tmp/new-certificates`。

没有浮点证明、因子分解扫描、联网依赖、Lean或仓库操作。q45/105样本只是诊断，主结论覆盖来自正文恒等式、完整周期及归纳。
