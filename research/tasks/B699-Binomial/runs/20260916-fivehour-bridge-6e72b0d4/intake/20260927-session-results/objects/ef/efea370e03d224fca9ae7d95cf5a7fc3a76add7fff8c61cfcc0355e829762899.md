当前 C 残域还保留 alpha=3^a、N|jk、U=jk/N=10g^2z^2（z为正整数）、本原范数、v2(g)=1、E4平方、实际 C=gcd(q4,j-2)、chi_C(3)=-1、完整第二至第五源及全部q5近侧、全部冻结高门。采用原逆元条件 r0=2Ac<s。没有修改这些前提。

    X=beta-10gz^2=(j-U)/g >0,

用 d_e、d_o 表示同一对 alpha X、alpha Y 中偶数侧、奇数侧的有效平方自由核，具有普通整数证书

    alpha X_e=d_e h_e^2,  alpha X_o=d_o h_o^2.

X_e、X_o 是 X、Y 的一次重命名，不改变 j 或 k。新证明使用双侧乘积和原z的奇偶，不要求为每个源另选平方根。

## 1. 同一普通因子的二进奇偶桥

### 引理1（EVEN-CORE-PARITY）

设 g 为偶数且 alpha 为奇数，其他宽合同成立。令 nu=v2(z)。X、Y恰有一侧为偶数，而且

    v2(X_e)=1+2nu,
    d_e/2 = 5 (mod8)  当 nu=0,
    d_e/2 = 3 (mod8)  当 nu>=1.

相应地 d_o=7(mod8) 当z奇，d_o=1(mod8) 当z偶。特别：

    d_e=6  => z偶；
    d_e=10 => z奇。

在当前v2(g)=1下，令 x=gz，则

    d_e=6  => x=0(mod4),
    d_e=10 => x=2(mod4).                         (1.1)

证明：真实 gcd 给 gcd(beta,gamma)=1，alpha奇给 beta、gamma 一奇一偶。N奇且

    beta*gamma=10Nz^2

说明偶数侧 beta_e=2^(1+2nu)*b0，b0奇。10gz^2的二进估值严格大于1+2nu，故 X_e 与 beta_e 的二进估值相同。写 z=2^nu*z0，z0奇，使用同一侧范数式：

    alpha X_e /2^(1+2nu)
       =2^(1+2nu)*b0^2-5z0^2.

有效平方自由核为偶数，故左侧=d_e/2乘一个奇数平方。奇数平方模8为1，因此得到所列两个余数。另一侧用 alpha X_o=beta_o^2-10z^2 即得。这里并未把因子估值增加到任何原源指数上。

### 引理2（同一乘积到普通 Pell 型方程）

若给定同一有效核对满足

    d_e*d_o=10D*m^2,

其中D为正平方自由整数，m为正整数，则存在普通正整数w使

    U-1=Dw^2,
    10(gz)^2-Dw^2=1.                            (1.2)

证明：将两个普通平方证书相乘，并使用同一XY恒等式，得到

    U-1=D*(m*h_e*h_o/(alpha*z))^2.

若最简分数r/s的D(r/s)^2为整数，则s^2|D；D平方自由迫使s=1。因此w确为普通整数，不是分别在各p选的局部根。

对于本轮四个具体核对，m=1。一般共有核、共有M2贡献已留在m与h_e,h_o中；上述步骤从未将M2设成1。

## 2. 显式单位的完整约化引理：不使用CAS完整解表

### 引理3（有限条带覆盖所有整数解）

设D>0，10D不是平方，并给定任意正整数u,v满足

    u^2-10D*v^2=1.

不要求该单位最小，也不假设已知整个单位群。任意正整数解

    10x^2-Dw^2=1

都能通过矩阵

    F=[[u,Dv],[10v,u]]

的某个整数次幂（允许逆幂），送到一个整数解(x0,w0)，使x0>0且

    w0^2 <= (u-1)/(2D),
    x0^2 <= (u+1)/20.                            (2.1)

证明：置 epsilon=u+v*sqrt(10D)>1，xi=10x+w*sqrt(10D)，其范数为10。乘以epsilon及其逆都保持整数系数、首系数被10整除。可选整数k，使

    sqrt(10/epsilon) <= xi*epsilon^k < sqrt(10*epsilon).

该区间上、下端比为epsilon，故覆盖所有正xi的一个乘法代表。范数仍为10，两个实嵌入都为正，故x0>0。用

    10x0=(eta+10/eta)/2,
    w0=(eta-10/eta)/(2sqrt(10D))

在两端取上界，分别得到(2.1)。这是覆盖所有整数解的证明，不是扫描猜想。

因此，若枚举(2.1)限定的全部小解，再证明某同余性质在F及F^{-1}下保持，该性质就对原方程的全部正整数解成立。辅助单位变换不被解释为原(n,j)的变换，更不是保持NC的下降。

## 3. 一个允许系数无界的整族约束

### 定理4（ELL-NORM）

任取普通正整数 ell，置 D_ell=10ell^2-1。对全部普通正整数x,w满足

    10x^2-D_ell*w^2=1,

都有

    x = ell (mod 2ell*D_ell),
    w = +/-1 (mod20ell^2),
    v2(x)=v2(ell).                               (3.1)

D_ell不需要平方自由。10D_ell=100ell²-10严格位于(10ell-1)²和(10ell)²之间，故所用二次根不退化。

证明：取显式单位

    u=20ell^2-1=2D_ell+1,  v=2ell.

展开即得u^2-10D_ell*v^2=1。引理3的界是w0^2<=1。w0=0会要求10x0^2=1，无解；w0=+/-1时恰得x0=ell。因此全部解来自两个约化种子(ell,+/-1)。

单位与逆单位的x坐标是 ux +/-2ell D_ell w。若 x=ell (mod2ell D_ell)，因为u-1=2D_ell，该同余在两种变换下均保持。w坐标为 +/-20ell x+u w，在模20ell^2下变为-w，所以w=+/-1保持。第一同余又给x/ell=1(mod2D_ell)，为奇数，得到完整二进估值。

### 对当前同一因子对的全参数删类

若当前真实输入还具有普通整数分解

    U-1=(10ell^2-1)w^2,

则v2(g)=1给 v2(z)=v2(ell)-1。与引理1联立，排除以下全部条件类：

    d_e=6 且 v2(ell)=1；
    d_e=10 且 v2(ell)>=2。                       (3.2)

ell、w、z、g、a及全部原源支持/指数不设大小上限。ell奇数与当前偶g已经不相容；该简单后果不另计收益。

若D_ell平方自由，(3.2)还给有效核的整族表述：

    v2(ell)=1  => 禁止 {d_e,d_o}={6,sf(15D_ell)}；
    v2(ell)>=2 => 禁止 {d_e,d_o}={10,D_ell}。       (3.3)

第一行的共有核可能为3；要按引理2保留它，不得删掉M2。这里没有证明平方自由D_ell的分布或数量，也没有把这两族称为全部剩余核。

### 不得丢掉普通除法或平方自由条件

仅知道sf(U-1)=sf(D_ell)，在D_ell非平方自由时不足以调用(3.1)。例如ell=314有

    D_ell=985959=39*159^2,
    x=2, U=40, U-1=39=D_ell*(1/159)^2.

这是有理平方比，却没有普通整数w，且314不整除2。本例仅为归一化边界，不是当前原输入模型。

## 4. 四个确定的完整非平方有效核对全部排除

### 定理5（PAIR-PELL-FOUR）

在第0节的宽真实合同下，以下任一无序有效核对不可能出现：

    {6,65}, {6,185}, {10,71}, {10,159}.           (4.1)

平方部h_e,h_o以及原输入高度均无界。

由引理2，四种核对依次给D=39,111,71,159。所需单位和全部有限约化末端如下：

| 有效核对 | D | u | v | |w0|上界 | 全部约化种子 (x0,w0) | 全轨道x mod4 | 原恢复要求x mod4 |
|---|---:|---:|---:|---:|---|---:|---:|
|6,65|39|79|4|1|(2,+/-1)|2|0|
|6,185|111|1999|60|3|(10,+/-3)|2|0|
|10,71|71|1279|48|3|(8,+/-3)|0|2|
|10,159|159|319|8|1|(4,+/-1)|0|2|

每个单位范数恰为1。发现器在理论界内逐w0检查(10x0)^2=10+10D*w0^2；全部非负末端的右侧分别是：

    D39:  10,400；
    D111: 10,1120,4450,10000；
    D71:  10,720,2850,6400；
    D159: 10,1600。

只保留平方根被10整除者，得到表中种子。分离接收器不用此方向，而从独立的x0界2、10、8、4逐x0检查w0平方，共24项，恢复同一全部种子。

四行都有u=-1(mod4)、Dv=0(mod4)，故正、逆单位作用下x变为-x模4。种子的0或2类各自不变。引理3覆盖所有解，引理1要求的另一类于是矛盾。

其中{6,65}与{10,159}分别是定理4在ell=2、4的直接应用；另外两行有独立的完整有限约化，不能仅因某个非平方自由D_ell的平方类相同而省略普通整数检查。

### 与R9中央字符的区别

四个核都不是旧被排的有效核15。仅就R9中央字符必要条件而言，四个核对分别可取抽象中央素数17、7、17、7，同时满足
