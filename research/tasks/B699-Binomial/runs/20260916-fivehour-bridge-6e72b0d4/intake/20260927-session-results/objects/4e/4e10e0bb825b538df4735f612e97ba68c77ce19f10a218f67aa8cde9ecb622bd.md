# B699-C-central-norm-lift-r2-20260926

独立的第二轮证据包。Python 3.11+ 标准库；无网络、无Lean、无外部CAS、无仓库操作。

入口：REPORT.md → FAILURE_BOUNDARIES.md → PROOFS.md → HANDOFF.md。

## 执行

在解压后的本目录内，使用正常 Python（不要启用 `-O`，以免关闭断言接收）：

    python scripts/accept.py
    python scripts/replay.py --receipt /absolute/path/replay.json

按行精确恢复示例：

    python scripts/recover.py 275562 --output recovery.json

输出CANDIDATE只表示严格规范恢复，不表示NC6。

有限前缀生成示例：

    python scripts/prefix.py 1000000000000 --min-a 2

冻结最低门可用 `--min-a 41 --latest-gates`。程序默认限制候选z槽预算；不足返回NOT_RUN_BUDGET，绝不宣称完成。没有提供全局X，因而这个命令不是完整B699有限末端。

重新生成本轮证书和诊断：

    python scripts/research.py --out /absolute/path/new-output --include-probes

## 文件

- 五份主文档：REPORT、PROOFS、FAILURE_BOUNDARIES、HANDOFF、SESSION_STATE。
- scripts：规范恢复器、完整前缀生成器、发现器、分离接收器、重放器和本轮路线诊断程序。
- certificates：全部按行整数矩阵、前缀逐行记录、类阶矩阵、精确大整数模型、余式表、周期/严格常数证书。
- logs：原始运行日志、初筛原始时间记录、路线决定和审计说明。
- sources：原始Overview字节、上一轮原ZIP和来源说明；没有重新执行前轮全链。
- replay：实际干净解压的载荷重放回执；外部最终回执绑定最终ZIP。
- PAYLOAD.sha256与SHA256SUMS：载荷及最终包的不同层次清单，避免自哈希循环。

不把可重复运行、文件哈希或同作者分离实现当成外部独立数学审读。
