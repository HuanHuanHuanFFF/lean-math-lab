## 离线接收

Python 3.10 或更高，仅标准库，无需 pip、网络、CAS、Lean 或仓库：

```text
python3 -B scripts/verify.py --output /tmp/m2top-verify.json
python3 -B scripts/consume.py --P 1331 --Q 1867429
python3 -B scripts/replay_archive.py /path/to/evidence.zip --output /tmp/m2top-replay.json
```

输出必须在解压树外。`verify.py` 不修改解压树。`discover.py` 会重写证书，仅应在工作副本运行。
