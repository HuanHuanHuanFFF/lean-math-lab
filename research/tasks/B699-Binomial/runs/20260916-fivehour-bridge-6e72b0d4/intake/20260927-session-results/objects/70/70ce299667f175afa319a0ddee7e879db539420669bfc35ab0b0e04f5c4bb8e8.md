# Replay contract

Run from the package root, without Python optimization:

    python3 code/verify_manifest.py
    python3 code/replay.py --out /absolute/new/output --jobs 4
    python3 code/compare_replay.py /absolute/new/output

Replay creates a fresh output directory, recompiles C++ sources, verifies every frozen input hash, regenerates both stages, and emits REPLAY_RECEIPT.json only after every test passes.

Deterministic certificate scope: all files below certificates/, including full root lists from both anchors, all 30,222 selected nonzero modular minors, 12 exact integer determinants, complete 75/2145/7170 numerical combinations, signature mappings, all104 fee records, full 1,203,003-cell integer tables, prices, negative controls and the final77 frontier.

Logs, process timings, executable binaries and environment metadata are not compared byte-for-byte. They are retained in verification/author_logs and verification/author_runs for the author execution. No compiled binary is shipped; no font files, credentials or repository copies are included.

Input-derived price coefficients are independently validated with exact integers; no optimizer is required. Root-count regression expectations are checked only after actual complete enumeration. They are not used to suppress gates or replace proof of completeness.
