# REPLAY

## 最短路径

```bash
python replay.py
```

从本包目录或任意目录调用其绝对路径都可。仅使用 Python 标准库，不访问网络，不写包内文件。
SHA256SUMS 校验失败或任何数学检查失败即返回非零退出码。

## 重建证书，不覆盖发布文件

```bash
python evidence/generate.py --output ../new-certificates
```

生成输出应与 certificates/ 中的五份 JSON 逐字节一致。
科学接收器可单独运行 `python evidence/verify.py`，但单独运行时不校验整个包的文件摘要。

可选的另一库符号发现检查：

```bash
python evidence/discover_sympy.py
```

此命令需要 SymPy；不属于标准库离线接收的前置。已运行输出存于 logs/discover_sympy.log。

## 完整性层级

1. `PAYLOAD_SHA256SUMS.txt` 固定新证明、程序、证书及原始日志。
2. 科学载荷被压缩后解压至全新目录，执行 `python replay.py`，产生内部实际回执。
3. 加入该回执和日志后生成最终 `SHA256SUMS.txt`，再创建最终 ZIP。
4. 最终 ZIP 再解压至另一新目录，检查 CRC、文件全集哈希和数学重放；结果存于外部 validation.json。

内部回执明确指向第1层载荷摘要；不假称包含自身或最终 ZIP 自身的递归摘要。
以上层级均不包括旧 Round12 父 ZIP 的重放；旧原始字节本轮不可用。
