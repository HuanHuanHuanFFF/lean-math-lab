# FAILURE_BOUNDARIES — 本轮不能被扩大解释的边界

## 原输入、量词、完整性

ROW 定理要求 n−1 恰为 P=p^a 与 Q=q^b 的乘积，底素数不同且为奇数，5≤P<Q。不允许隐藏乘子，不允许用 d|Q 替代 Q=q^b。P=3 不在本轮接口，但公共见证 3 完全保留；P=9=3² 的实际行及完整第三源 3²、3³ 末端均有证书。

原 j 在 4≤j≤floor(n/2)。A=−1 只用 J=n−j 作为同一二项式的对称表达；记录 original_j 与 auxiliary_J，不把 J 当新原输入，不宣称严格下降。

m=2 是规范 P 进制次数，e∈{1,2} 来自继承 Q<3P²。不能把它当旧 QUARTIC/SEPTIC 的次数，也不能给 e≥3 套本轮结论。

## 四个根不等于四个 NC 模型

A|e 只是根索引限制。±2 与实际奇 Q 冲突，不能把偶 Q 弱恢复继续叫“两奇幂 NC”。±1 的完整第三源分析和有限末端才完成排除。

完备末端八行中六行不是实际两不同底素数幂。它们是有界必要整数域，已明确标记；两实际行还会失败于原完整 p-Lucas，本轮也没有把它们称为先前未知的 NC。

## 完整素数幂与孤立 3

F=dvV、J=Qv。若奇素数同时进入 v 和 dV，原完整指数是两边之和，J 仅含 v 的指数，必须反证；禁止先约掉 v。3 在合计指数≥2 时仍活动，窗口用完整 3^a，不是 3^(a−1)。

容量允许的最多一个 3 来自 v₃(dV)=1 的孤立项。报告中的 V≤3·odd(lcm(a,b)) 已保留该项。不能把这个 3 取消后宣称更强常数。

## 充分消费者，不是整个首档闭合

M2-ZERO-BAND2 只关闭首档的零常数行，不关闭非零常数行。与旧 m=1 合并只得到“首档所有剩余常数非零”，RES-LCM 仍是必要条件。

M2-E2-ZERO-NO-BAND 只覆盖 e=2、d≥2、4|n、规范 m=2 的零常数；不覆盖 e=2 全域。

e=1 首档外仍不能套此定理。(P,Q)=(41,2351) 是实际不同底素数幂，n=96392、j=7053，两底 Lucas 通过，d=14、k=16、dH=224>2P=82，R₀=0。`consume.py` 正确拒收该 e=1 首档外行。它不满足全部 NC 源条件，不是反例，也不是声称存在未闭 NC 输入。

(P,Q)=(7,73) 是首档非零常数行，原 j=147；本轮消费者正确拒收。旧第三源已给反证，但不能用该有限例说整个非零域关闭。

## 相对收益与有限性

首档零常数还被本轮证明为完整 p-Lucas 不可能；因此不能说它删除了已通过该必要条件的状态。旧冻结账本的 m=2 零记录为 0，有限未知 NC 净减 0。本轮 76 个实际行样本也都已可由原 n 源逐例拒绝。

结构结果无高度截断，不等于新条件内实际素数幂对已证有无穷多组。未审阅全部更早历史覆盖，不能宣称历史互不重叠。

d≤30、P<960 是 e=1 首档零分支在反证容量下的末端界。其他 NC 分支的 P,d 仍无此界；不能据此做全题有限化。R7 不变。
