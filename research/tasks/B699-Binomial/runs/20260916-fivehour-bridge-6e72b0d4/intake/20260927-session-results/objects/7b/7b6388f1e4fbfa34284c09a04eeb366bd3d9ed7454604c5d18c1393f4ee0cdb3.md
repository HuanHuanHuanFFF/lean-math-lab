# REPLAY

在空目录解压后运行：

```bash
python replay.py
```

需要Python 3.10+，仅标准库；不要使用-O。

程序先核验SHA256SUMS.txt中全部文件与完整成员集合；再接收八份证书；
在独立临时目录重生成所有证书并比较字节；最后确认原包文件未改动。
关闭.pyc写入，不访问网络或仓库，不解压或执行父证明链。

单独接收/生成：

```bash
python -B evidence/verify.py --cert-dir certificates
python -B evidence/generate.py --out /path/to/new/certificates
```

包内CLEAN_REPLAY_RECEIPT.json和logs/clean_payload_replay.log记录在封装最终回执之前，
将全部稳定payload打成ZIP、干净解压并执行上述数学重放的结果。
PAYLOAD_SHA256SUMS.txt精确覆盖该阶段的全部稳定文件。

最终SHA256SUMS.txt覆盖最终包中除其自身外的所有文件，包括内部payload回执。
最终ZIP再做一次独立干净解压，结果写入ZIP外的.validation.json并记录最终ZIP摘要。
这是为避免自引用哈希而区分的两个检查阶段，不把payload摘要冒充最终ZIP摘要。
