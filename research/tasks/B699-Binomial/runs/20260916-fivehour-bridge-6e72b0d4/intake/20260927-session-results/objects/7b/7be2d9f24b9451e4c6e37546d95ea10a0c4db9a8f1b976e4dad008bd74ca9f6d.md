# B699 Pro B — ZERO-SPLIT evidence

阅读顺序：REPORT → PROOFS → FAILURE_BOUNDARIES → HANDOFF。精确状态见 SESSION_STATE.json。

本轮从 NEAR-CARRY2 的零常数恢复支继续；不重复旧近侧或 P>dH 消费者。主恢复支已关闭，首档 m=1 零常数也已全部关闭；一般 i3、整个首档和 R7 未闭合。

Python 3.10+，仅标准库，无网络：

```sh
python3 -B scripts/verify.py --output /tmp/zero-split-verify.json
python3 -B scripts/consume.py --P 149 --Q 2399
python3 -B scripts/consume.py --P 29 --Q 239
python3 -B scripts/replay_archive.py /path/to/evidence.zip --output /tmp/zero-split-replay.json
```

`consume.py` 为只读数学消费者，返回充分证明标签及精确见证；没有标签不等于 NC3 反例。素数幂判定用试除，巨大输入可能较慢。

`discover.py` 重写本轮证书，只在工作副本运行。日常重放只用 verify.py。脚本均不访问或更改仓库。

SHA-256 的两层清单与内部/外部回执安排见 PACKAGING.md。数学正确性不由 ZIP 哈希或同作者重放替代。
