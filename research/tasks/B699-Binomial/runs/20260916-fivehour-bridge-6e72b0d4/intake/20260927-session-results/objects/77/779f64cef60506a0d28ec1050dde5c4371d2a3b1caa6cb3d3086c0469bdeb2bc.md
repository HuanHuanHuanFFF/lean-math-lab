# PROOFS — C 第二轮：真实三幂范数、精确恢复与中央补核

日期：2026-09-26。作者级纸面证明；附确定性整数证书。没有 Lean 或外部独立数学审读。

## 0. 原题、继承合同和新增内容的边界

原题对全部自然数 `1≤i<j≤floor(n/2)` 要求同一个素数 `p≥i` 同除两个二项式系数。本轮只使用原生 i=6，故合格素数恰为 p≥7，没有删去原题端点。令 k=n−j，g=gcd(n,j)，α=n/g，β=j/g，γ=k/g，N=n−1。定义

    s6(x)=2^v2(x) 3^v3(x) 5^v5(x),  q_r=(n−r)/s6(n−r).

NC6 是合法数对没有共同合格素数的否定分支。每个完整 p^e||q_r 在 NC6 下必须满足 j mod p^e∈{0,…,r}。它只是必要条件，反向不成立；更高位仍可产生进位。

本轮继承的最新 C/B-RES10 合同包括 α=3^a、W=N·jk=10Y²、n≡5130 (mod9000)、a≥41、v2(n−2)≥65、v5(n−5)≥27，以及全部原源和全 q5 近侧条件。以上合同在先前来源中的证明不在本轮重做。最新入口蕴含

    n≡14130 (mod18000)，从而 n≡450 (mod720).

此处用 n≡2 (mod16) 与 n≡5130 (mod9000) 做精确 CRT；只是抽取一个较弱的必要同余，没有把当前门槛降回这个同余。

从上一包只调用 B4-SIGN：在 n≡450 (mod720)、NC6、W10 下，若 E4=gcd(q4,jk) 为平方，则 C=gcd(q4,j−2) 满足 χ3(C)=−1。χd 是正奇数分母的 Jacobi 符号。上一轮的 U4-CHAR、落点表、局部反模型不作为本轮新增成果。

本轮的三个研究输出是：严格规范恢复域的全局 O(sqrt X) 计数；不需质量门的按行精确恢复算法和非极大序中精确类阶；中央补核在同一输入上的全源路由。中央精度的一个自然改写被证明与旧完整源缺额相同，明确不计新增约束。

## 1. 从真实原输入到严格范数：等价的是哪个系统

定义严格规范系统 S(n,j)：

    n≥6，6|n，0<j<n/2；g=gcd(n,j)，α=3^a，a≥1；
    N|jk，且 N·jk=10Y²，Y为正整数。

原题允许的 j=n/2 在实际 α 为奇数时不可能出现：该点的 gcd(n,j)=n/2 会给 α=2；故这里的严格不等号没有遗漏本支端点。

它不是 NC6 的等价模型。在粗 B 尾中 N 与 30 互素，NC6 的完整第一源强制 N|jk，所以当前 NC 残域包含于 S。一般 n 上不得无条件以 N 替代 q1。

在 S 中，U=jk/N 是正整数且为十倍平方。若 U=10(s/t)² 且 gcd(s,t)=1，则 t²|10，故 t=1。又 gcd(g,N)=1、g²|jk，故 g²|U；同样的平方自由论证给唯一正整数 z：

    U=10g²z²，βγ=10(gα−1)z².                         (1.1)

反过来，若 g、β、z 为正整数，α=3^a，3∤β，0<2β<α，并满足 (1.1)，则 n=gα、j=gβ 恢复真实 gcd g、N|jk 与 W10。这是 S 的准确恢复，不是 NC6 的恢复。

置 δ=α−2β。等价范数为

    δ²+40(n−1)z²=α²，0<δ<α，3∤δz.                  (1.2)

且 gcd(δ,z)=1：共同素数只能由 (1.2) 整除 α，因而只能是 3，而 δ 不被 3 整除。δ 还与 2、5 互素；前者由 α 奇、后者由 (1.2) 模5得到。因此 gcd(δ,30z)=1。

## 2. SPARSE-B：严格恢复域的全局平方根计数

### 定理 2.1

对每个实数 X≥1，令 B(X) 是全部实际合法数对 (n,j)，满足

    n≤X，n≡14130 (mod18000)，S(n,j)，a≥2。

则

    #B(X) ≤ floor(sqrt(X)/346).                      (SPARSE-B)

不需要 NC6、E4 为平方、全 q5 近侧或质量门。故这些更强条件下的原题剩余数对也受此界控制。它不是 n 的上界，也不证明只有有限多个剩余数对。

### 第一步：真实 g 的一致下界

除以9，粗同余等价于

    g·3^(a−2) ≡1570 (mod2000).

故 g≥G_a，其中 G_a 是 1570·3^(−(a−2)) 模2000 的最小正代表。因为 gcd(1570,2000)=10，只需模200的 3 的幂；3 的阶为20。完整20项列表见证书，G_a 的取值集合是

    {130,310,370,390,530,710,770,790,930,1110,
     1170,1190,1330,1510,1570,1590,1730,1910,1970,1990}.

因此 g≥130。这个小同余推论只用于计数常数，不另计一次前沿推进。

### 第二步：每个 (a,z) 至多一个原数对

将 (1.1) 模 α 约化：

    β²≡10z² (mod3^a).

由于 3∤βz，固定一个平方根 r_a²≡10 (mod3^a) 后，β≡±r_a z。模3有且只有±1两个根，各自逐层唯一提升：若 r²−10 可被3^t整除，则 r+c3^t 的下一位 c 是模3一个非退化线性方程的唯一解。

在 0<2β<α 的原方向下，两根恰给同一个较小剩余 β。然后

    g=[β(α−β)+10z²]/(10αz²)                         (2.1)

唯一决定真实 g、n、j。必须检查其整数性和原同余；未经检查的 (a,z) 不叫候选 NC。

### 第三步：候选槽数的求和

由 βγ≤α²/4 与 (1.1)：

    z²≤α²/[40(gα−1)]≤α/[40(g−1)]≤α/5160.

同时 α≤X/130。故整数 (a,z) 槽数不超过

    Σ_(3^a≤X/130) sqrt(3^a/5160)
      < [(3+sqrt3)/(2 sqrt670800)] sqrt X
      < sqrt X/346.

最后一个严格不等式无需浮点：它等价于

    718296·sqrt3 <1246608，

两侧正，直接检查 1246608²−3·718296²>0。证书保存这个正整数差。取整即得定理。

### 完整有限前缀生成器

`scripts/prefix.py` 对每个允许 a 计算 r_a、G_a，并穷尽

    1≤z≤floor sqrt[α²/(40(G_a α−1))]，3∤z。

利用 (2.1) 恢复并核对 n≤X、真实 gcd、原同余。此过程枚举 S 的粗 B 子域，而不是枚举所有 j 或逐 n 扫描。`--min-a 41 --latest-gates` 保留冻结的三个最低指数门；其余全部 NC 条件仍须随后检查。预算不足明确返回 NOT_RUN_BUDGET，不返回“完成”。任意大的 X 仍是新的输入，绝不能把这个算法叫作全局有限末端。

## 3. NORM-REDUCE：不需质量门、无需分解的按行完备恢复

### 定理 3.1

对任意 n≥6、6|n，令 A=v3(n)、K=10(n−1)。存在一个确定性整数算法，检验最多 A 个正定整二次型，准确输出 S(n,j) 的 EMPTY 或其唯一规范恢复 (g,a,β,z,j)。算法不使用 8g⁴<n，不分解 n−1，也不枚举 j。

“每行至多一个恢复”已见旧 UROW，不是本轮新增数量改进。本轮交付的是下面无需旧质量前置的自包含完备算法与整数变换证书。

### 模根与二次型

对 a=1,…,A，令 Q=3^(2a)，取 r²≡−K (modQ) 且 r≡1 (mod3) 的唯一提升。定义

    F_a(X,Y)=QX²+2rXY+[(r²+K)/Q]Y².                 (3.1)

其判别式为 −4K=−40(n−1)，且

    Q F_a(X,Y)=(QX+rY)²+K Y².                       (3.2)

完整模根只有±r。一个本原规范范数 δ²+K(2z)²=Q，选择 Y=±2z 的符号使 δ≡rY (modQ)，即给整数 X=(δ−rY)/Q、F_a(X,Y)=1。反过来，F_a 表示1就给这个范数。

### 精确约化与否证

仅使用行列式+1的两个整数变换：X→X+mY，以及 (X,Y)→(−Y,X)。前者把中间系数放入 (−a,a]，后者在首系数大于末系数时交换。每次非平凡交换严格降低正首系数；等号只需规范中间系数符号，因此终止。

得到约化型 [A0,B0,C0]，满足 |B0|≤A0≤C0。对任意非零整数 (x,y)：

    A0x²+B0xy+C0y² ≥ A0(x²−|xy|+y²) ≥ A0.

所以若 A0≥2，则该型不表示1，是完整的否证，不是只搜索小向量。若 A0=1，由判别式被4整除、|B0|≤1，必须是 [1,0,K]；它的表示1只有±(1,0)。累计变换矩阵 M∈SL2(Z) 的第一列 (u,v) 就给

    δ=|Qu+rv|，2z=|v|.

Q 为奇平方且 n 偶、N 奇，范数模8强制 v 偶。又 3∤vδ；否则原型模3不可能取值1。恢复 β=(3^a−δ)/2、g=n/3^a、j=gβ，并逐项验证。

接收器不运行发现器的约化算法。它只验 M 的行列式、三个系数变换恒等式、约化不等式，以及输出的原始范数、gcd 和区间。因此每个 EMPTY 证书都有全整数否证理由。

### 唯一性的自包含核对（不重复计功）

设两组本原解的 α1≤α2，虚系数 y_i=2z_i。选择第二个 y 的符号，使两组模 α1² 的根方向一致，则

    α1² | δ1 y2−δ2 y1.

椭圆上两向量的行列式界给绝对值≤α1α2/sqrt K。又 α1≥sqrt K，α2≤n<K，故此绝对值严格小于 α1²，必须为0。本原性 gcd(δ_i,y_i)=1 强制两向量相同，从而 a、z、δ、g、j 相同。这也说明算法没有在不同 a 之间漏掉第二个方向。

### 量词与回传

这精确判定的是 S，不是 NC6。粗 B 尾满足 W10、α三幂的原数对若不在所恢复的输出中，则其完整第一源失败，存在原 q1 素数 p≥7 给出同一 (n,j) 的 Common6。不能据此把一个 B 行的其他平方类、其他 α 或全部合法 j 一并排除。

CANDIDATE 只是严格规范恢复，仍要检查 q2…q5、全近侧、C<A4、质量门与全部高层无进位。程序保留这个状态名，不输出“NC”。

## 4. NORM-ORDER：同一行的非极大序精确类阶

本节提供算法背后的全局算术接口；第3节的完备性不依赖计算整个类群。

令 O=Z[sqrt(−K)]，判别式 D=−4K；不要把它换成同域的极大整环。3∤D，且 −K≡1 (mod3)，故3在此序中分裂为两个互素可逆素理想 P、Pbar。选择与模根 r 一致的 P。

若 S(n,j) 成立，元素

    η=δ+2z sqrt(−K)，Norm(η)=3^(2a)

在3处本原，因而 (η) 只能是 P^(2a) 或 Pbar^(2a)，两种方向互为逆类。令 h 为 P 的类阶，则 h|2a。

若 P^h=(x+y sqrt(−K))，其范数为3^h。y不能为0：一个非单位有理整数的主理想在3处同时含 P、Pbar，不能等于纯单侧 P^h。故

    3^h=x²+Ky²≥K=10(n−1)>n≥3^A.

所以 h>A≥a。2a 的任何真因子都不超过a，得到

    ord_Pic(O)([P])=2a，且 A<2a≤2A.                 (NORM-ORDER)

这不是“某个理想的阶整除2a”的弱必要条件，而是实际原输入指定3理想的精确阶。但它只在此非极大序中成立；进极大整环后的阶可能下降，本轮未控制导子核，也不宣称极大类数必有同样因子。

反过来，在该序中若首次主幂 h≤2A 存在且为偶数，则 h=2a 的主生成元给第3节恢复；若首次主幂是奇数或所有 t≤2A 非主，则无 S 恢复。对偶数 h，模8保证所需的偶虚部。这个解释也给每行至多一解，但本轮不把旧唯一性重复登记为新成果。

## 5. CENTRAL-COMPLEMENT：保留完整指数的范数补核

在 S(n,j) 中定义

    H=(α²−120z²)/3=3^(2a−1)−40z²，
    C=gcd(q4,j−2)，T=H/C.

H>0：由范数和 δ²>0，α²>40(n−1)z²，而 n>4。H 为与30互素的正奇数，H≡11 (mod12)，故 χ3(H)=+1。

### 5.1 精确 gcd 恒等式——以及它的冗余性

范数给出

    3H=δ²+40(n−4)z².                               (5.1)

由 gcd(δ,30z)=1 和 gδ=(n−4)−2(j−2)：

    gcd(H,δ)=gcd(n−4,δ)=gcd(q4,j−2)=C.              (5.2)

因此 T 是实际正整数。再将 (5.1) 除以 C，模 C 使用单位系数 40s6(n−4)z²，可得

    gcd(C,T)=gcd(C,q4/C).                            (5.3)

这是准确等式，不只是共同素数支持相同。右侧是原第四源中央块的既有完整幂缺额。因此“左侧非1给原题共同素数”只是一个新的范数表达式，不是比既有完整源更强的限制。本轮明确拒绝把它另计一次前沿下降。

若该 gcd>1，每个其中的素数 p≥7 都满足 0<v_p(j−2)<v_p(n−4)。j 模p为2，但在完整 p^e 层不为2，也不能等于其他0…4槽。因此原同一个 p 同除 C(n,6)、C(n,j)。三例旧 U4-CHAR 未触发而此 gcd 触发，只证实它不同于旧 Jacobi 测试；不证实它超出旧完整窗口。

在 NC6 下，中央块必须完整，故 C 是 H 的酉因子：

    gcd(C,T)=1，gcd(T,δ)=1.                          (5.4)

对每个 p^e||C，(5.1) 的两项估值分别至少2e与恰e，故 v_p(H)=e。这没有把原源指数从e擅自增成2e。

### 5.2 联立全部来源的新补核路由

以下保留同一原 (n,j)，并假设 NC6、粗 B 同余、E4平方。上一包 B4-SIGN 给 χ3(C)=−1，因此

    χ3(T)=−1.                                       (5.5)

每个 p|H 都满足 p≥7、p∤z，且 α²≡120z² (modp)。因此 χ30(p)=+1，亦即 χ3(p)=χ10(p)。这作用于 H 的所有实际素数，而不只奇指数支持。

设 F=n²−12U=3g²CT。对各源 p≥7，g、n−1 都是相应单位，可按完整槽计算 F 模 p^e：

| 源 | 槽组 | U 模 p^e | F 模 p^e |
|---|---|---|---|
| r2 | 端点/中央 | 0 / 1 | 4 / −8 |
| r3 | 端点/近侧 | 0 / 1 | 9 / −3 |
| r4 | 端点/近侧/中央 | 0 / 1 / 4/3 | 16 / 4 / 0 |
| r5 | 端点/近侧/中间 | 0 / 1 / 3/2 | 25 / 13 / 7 |

分数在 p≥7 时都是单位分母。r4中央用 (5.4) 的精确估值剥去 C。因此

    gcd(T,q2 q3 q4)=1.                              (5.6)

若全 q5 近侧，则 q5|U−1、n≡5 (modq5)，所以 F≡13 (modq5)。又 gcd(3g²C,q5)=1，得到比支持声明更精确的

    gcd(T,q5)=gcd(13,q5).                            (5.7)

没有全近侧时，r5中间槽的常数7不能删：一般只能得 gcd(T,q5)|91。这个边界正是本轮确实用到“全部 q5 近侧”的位置。

### 5.3 一个不能由其余四个粗源吸收的奇指数素数

由 χ3(T)=−1，存在奇数 v_l(T) 的素数 l，使 χ3(l)=−1。由上文还有 χ10(l)=−1、χ30(l)=+1，其完整模120允许类为

    l mod120 ∈ {7,17,19,29,91,101,103,113}.          (5.8)

(5.6) 排除 l|q2q3q4；(5.7) 与 χ3(13)=+1 排除 l|q5。

它也不能整除 n。否则 l≠3、l|g，范数模l与 α²≡120z² 给

    δ²≡160z² (modl),

从而 χ10(l)=+1，矛盾。因此

    l ∤ n(n−2)(n−3)(n−4)(n−5).                     (OUTSIDE-ODD)

仍可能 l|n−1，也可能完全不在原六源中。它不是自动获得的原题共同素数；若不整除原 C(n,6)，不能把它当作见证。

C 本身也含一个奇指数的负 χ3 素数。由 gcd(C,T)=1，它与 l 不同。负特征且 χ30=+1 的最小两个合格素数是7、17，故

    sf(H)=sf(C)sf(T)≥119.                            (5.9)

这里 sf 只取奇指数平方自由核。H 是本轮的辅助范数，绝不是旧 d=sf(E3E4)。不能把119直接代进旧 d² 成本，不能因此声称 E4 已非平方或 d4 已升级。

本节是必要分配/补核结论，不是 NC6 的充分参数化。它排除不满足这些补核约束的条件域，未证明该条件域在全部历史残域中非空或无穷；认证历史净删域仍记0。

## 6. 研究过程中核出的失败边界

### 6.1 真正三幂与全局范数仍不单独排掉中央负核

证书构造 α=3^183，z=1。令 r 为 r²≡10 (modα)、r≡1 (mod3) 的提升，β=min(r,α−r)，按 (2.1) 恢复实际 g、n、j。全部大整数保存在 central_exact_cases.json。

该实际数对满足 S、n≡450 (mod720)、E4=1、C=7、χ3(C)=−1，中央源饱和，旧 U4-CHAR 不触发。但它不满足 n≡14130 (mod18000)，q2…q5 完整源和全 q5 近侧失败，质量门以及65/27高指数门也失败。它只是验证“纯三幂+全局范数+中央负核仍不足”的精确障碍，不是当前 B-RES10 候选，更不是反例。

### 6.2 中央 gcd 的三例非 Jacobi 触发

(a,z)=(1188,4),(1240,4),(1475,1) 的实际偶数三幂恢复分别给中央缺额素数17、7、13；旧 U4-CHAR 均不触发，但完整源失败。所有范数、完整源估值以及原 C(n,j) 的 p估值均由整数证书检查。这三例都不在粗 B 尾，且质量门失败；不能用于认证当前主前沿净删域。等式 (5.3) 已说明它们不超出既有完整源检查。

### 6.3 本轮没有得到的结论

没有证明 E4 必非平方；没有一般 d4 升级；没有完整 B-RES10 的 v_p(U−1) 统一上界；没有绝对 n 界或统一终端；没有保持 NC 的严格下降。a、n、g、z、C、T、q2/q5、粗支持、原素数幂指数和非极大序判别式仍可无界。SPARSE-B 只控制每个有限前缀的数量，不能把 O(sqrt X) 换写成 O(1)。
