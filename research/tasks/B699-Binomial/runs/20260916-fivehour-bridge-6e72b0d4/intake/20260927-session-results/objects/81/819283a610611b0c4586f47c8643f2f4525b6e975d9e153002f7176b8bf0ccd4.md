# Packaging and replay boundary

All source, proof, scripts, certificates and pre-packaging logs are frozen into a payload. `PAYLOAD_SHA256SUMS.txt` lists every payload file, excluding itself and later packaging receipts.

The payload archive is extracted into a newly created empty directory. In that directory the verifier checks payload hashes and executes all exact checks, with no network and no third-party packages. The actual command, return code, output hashes, interpreter version and result are recorded in `REPLAY_RECEIPT.json`. Its stdout is retained in `logs/clean-payload-replay.json`.

The final `SHA256SUMS.txt` hashes all files then present, including the payload manifest, internal receipt and clean replay output, except itself. These bytes form the delivered ZIP.

The delivered ZIP is then extracted into a second new empty directory and verified again. Its **external** final replay receipt records the delivered ZIP SHA-256, final and payload manifest hashes, exit status and result. Keeping this particular receipt external avoids an impossible self-referential archive hash. The internal receipt still attests the exact same mathematical payload that is inside the final ZIP.

Hashes attest bytes, not mathematical truth. Replays are performed by the same author; neither is called external independent review or formal proof. Run the verifier without Python `-O`.
