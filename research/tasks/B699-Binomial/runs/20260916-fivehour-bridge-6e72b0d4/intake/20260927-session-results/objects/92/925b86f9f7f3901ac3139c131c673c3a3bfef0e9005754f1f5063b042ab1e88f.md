# B699 Pro B — K4-GENERAL-SLOTS evidence

入口：REPORT.md → PROOFS.md → FAILURE_BOUNDARIES.md → HANDOFF.md。

本包独立接收本轮k4完备末端和一般u源恒等式，不重放旧根账本或历史全链。验证需Python3.10+，仅标准库，无网络。代码使用整数与有理数，没有浮点数作为数学判定。

```sh
python3 -B scripts/verify.py --output /tmp/k4-general-receipt.json
python3 -B scripts/consume.py --case K4-only-size-pass
python3 -B scripts/consume.py --case NEW-u2-eps1-z4015
python3 -B scripts/replay_archive.py /path/to/evidence.zip --output /tmp/k4-general-replay.json
```

输出路径必须在证据/解压树外。`discover.py`会重写本轮证书，使用SymPy，只在工作副本运行；不是接收依赖。

## 文件分组

- 报告、数学证明、失败边界、交接、状态与来源采用说明。
- certificates/algebra.json：6条T2、2条T0整系数恒等式，du-kz+1的完整余式和正性/零族证书。
- certificates/k4-terminal.csv：44,549条原整数恢复的完整表，不是素数幂或NC列表。
- certificates/k4-summary.json：精确范围、汇总和CSV哈希。
- certificates/examples.json、primality.json：真实完整幂、全Lucas和原公共素数，附递归素性证明。
- certificates/direct-binomial.json、small-row-exhaustive.json：直接整数二项式和完整半行回归。
- scripts/：标准库接收器、双枚举、原输入消费者、干净重放、可选生成器。
- sources/：明确采用的冻结原件，不含旧大扫描，不隐瞒交接版本冲突。
- logs/：实际生成、接收、失败记录及内部干净解压回执。
- SHA256SUMS.payload：稳定payload清单；不含自身或后加的重放回执。
- SHA256SUMS：除自身外全部最终文件清单。

内部CLEAN_REPLAY针对装入回执前的稳定预封包，避免自引用哈希；最终ZIP自身再做一次干净解压重放，其回执和ZIP.sha256放在包外。两次都核对解压树未修改。

证据：作者级论证、精确证书、同作者重放。不是Lean、外部独立审稿或完整B699闭合。
