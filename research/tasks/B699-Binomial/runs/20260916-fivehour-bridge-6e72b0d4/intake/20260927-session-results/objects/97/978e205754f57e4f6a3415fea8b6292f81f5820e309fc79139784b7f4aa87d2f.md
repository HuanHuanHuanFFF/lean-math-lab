# B699 Pro B — K5-SLOTS-CLOSURE

本包的目标是完整两奇幂首档中的k=5，不是完整B699。先读REPORT，再读PROOFS及FAILURE_BOUNDARIES；接续使用HANDOFF与SESSION_STATE。

## 离线接收

Python 3.10+，无第三方依赖，输出放在包外：

```sh
python3 -B scripts/verify.py --output /tmp/k5-verify.json
python3 -B scripts/consume.py --case U2-size-pass-actual
python3 -B scripts/consume.py --case ZERO-t43-actual
python3 -B scripts/replay_archive.py /path/to/B699-ProB-K5-SLOTS-CLOSURE-20260927-evidence.zip --output /tmp/k5-clean.json
```

verify重新生成四个完整有限末端，两种枚举比较字节；核验16条整系数原源式、零族因式与完整估值示例、2个无界阈值多项式、8个真实完整幂行、9个大小通过模型的性质和完整小行回归；验证哈希与读前读后树一致性。不会执行任何旧k4/k3账本。

参数模式`consume --u 2 --epsilon -1 --z 433 --a 606`不自动声称P/Q已证为幂；`--case`模式才验证冻结完整分解和底素性。生成脚本derive_certificates.py需SymPy，仅用于发现/重导，不是接收依赖。

## 哈希与真实干净重放

SHA256SUMS.payload覆盖全部payload文件（不含自身、最终清单及内部回执）；logs/CLEAN_REPLAY.json记录该payload在预发布ZIP中的实际干净解压执行；SHA256SUMS覆盖最终全部其他文件。外部final-replay.json针对最终ZIP自身再次干净重放，并记录最终ZIP SHA-256。这避免任何文件哈希自引用。

完整性、重放与数学证明是不同层次。没有Lean或外部独立数学审读。
