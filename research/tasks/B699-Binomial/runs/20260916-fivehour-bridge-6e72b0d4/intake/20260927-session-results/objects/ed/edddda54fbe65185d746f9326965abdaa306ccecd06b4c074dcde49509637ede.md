# PROOFS — ZERO-RESTORE / ZERO-SLOT-SPLIT / M1-ZERO-BAND2

日期：2026-09-26。作者级纸面证明；附整数多项式检查和确定性有限证书。不是 Lean，不是外部独立数学审读。

## 0. 原题、来源与结论分层

固定原始输入 `(n,j)`，定义

\[
\operatorname{NC}_3(n,j):\quad4\le j\le\lfloor n/2\rfloor,
\quad\forall\ell\ge3\text{ prime},\quad
\ell\mid\binom n3\Longrightarrow\ell\nmid\binom nj.
\]

`Common3(n,j)` 为存在同一奇素数同时整除两个原二项式；允许素数 3。

本轮整行消费者始终要求

\[
n-1=PQ,\qquad P=p^a,\ Q=q^b,\qquad5\le P<Q,
\]

其中 p,q 是不同的奇素数，a,b≥1，**n−1 恰为这两个完整素数幂，没有隐去乘子**。本轮没有把 d|Q 当作 Q=q^b，也没有把素数幂拆成多个源。

来源为 `sources/PREVIOUS_HANDOFF.md`、`PREVIOUS_PROOFS.md`、`TWOPP_BASE_PROOFS.md` 和冻结 Overview。本文不重复此前 P>dH 或近侧数值消费者。

三个新结论：

1. **ZERO-RESTORE-PAIR/ROW**：关闭交接中的整个恢复族，且数对子结论不需要光滑形状或首档门槛。
2. **ZERO-SLOT-SPLIT**：即便某消元常数为零，也可用同一输入的精确 gcd 分拆容量；重叠完整幂不能直接剥掉。
3. **M1-ZERO-BAND2**：首档 P<dH<2P 中，规范数字次数 m=1 的全部零消元常数子域关闭，非零常数子域未关闭。

## 1. 原输入接口与整行提升

### 1.1 活动完整幂窗口

在 F_ℓ[T] 中按 ℓ 进制展开 n，Frobenius 恒等式给

\[
(1+T)^n=\prod_i(1+T^{\ell^i})^{n_i},\qquad
\binom nj\equiv\prod_i\binom{n_i}{j_i}\pmod\ell.
\]

所以若 ℓ^e∥n−r，r∈{0,1,2}，且 ℓ≥3，则

\[
\ell\nmid\binom nj\Longrightarrow j\bmod\ell^e\in\{0,\ldots,r\}.\tag{W}
\]

这里是完整 ℓ^e。因 C(n,3)=n(n−1)(n−2)/6，源上的奇素数 ℓ≥5 一律活动；素数 3 只有在该源赋值恰为 1 时被分母消掉，赋值≥2 时仍保留完整 3^e 作为窗口。

记 odd(M)=M/2^{v2(M)}，η(M)=3（v3(M)=1 时），否则 η(M)=1。活动部分为

\[
T_r=\operatorname{odd}(n-r)/\eta(n-r).
\]

NC3 给 T0|j 和 T2|j(j−1)(j−2)。后一个必要条件按完整奇素数幂分配；三个相邻槽不能分享同一个奇素数幂。

### 1.2 唯一低位候选与继承尺寸

因为 P,Q≥5，其底素数均活动，包含 P=3^a、a≥2 的情形。原 j 必须

\[
j=PX+s=QY+t,\quad s,t\in\{0,1\},\quad
\varepsilon=t-s\in\{-1,1\},\quad PX-QY=\varepsilon,
\]
\[
1\le X\le(Q-1)/2,\qquad1\le Y\le(P-1)/2.
\]

同槽只给合法范围以外的点；异槽 CRT 代表之和为 n，因此半行恰有至多一个候选。排除此原候选即可提升到整行，其余原 j 由 p 或 q 给出公共素数。低位候选不是 NC3 的充分条件。

继承的 NC3 接口为 4|n 和 Q<3P²（完整证明冻结在 `TWOPP_BASE_PROOFS.md` §3）。本轮第一主定理不需要这两个结论；第二主定理仅需其中的 4|n。剩余域说明中才继续保留 Q<3P²。

若 Q=kP+d<P²，1≤d,k<P，记 H=max(d,k)。同一输入的

\[
z=(dY+\varepsilon)/P,\qquad0\le z\le\lfloor d/2\rfloor,
\quad\gcd(z,d)=1.
\]

首档 P<dH<2P 排除 d=1，故 z≥1。完整 p-Lucas 蕴含的分块约束仍保留，但下面零常数排除并不需要把它反向当作充分条件。

## 2. 第一主定理：交接的整个恢复族闭合

### 2.1 ZERO-RESTORE-PAIR

对任意奇整数 d≥3 和正整数 v≥1，定义实际整数

\[
P=dv-1,\quad Q=d(d+1)v-1,\quad n=PQ+1,\quad j=Qv,
\]
\[
W=d(d+1)v-d-2.
\]

则存在某个奇素数 ℓ|W，使 ℓ 同时整除 C(n,3) 与 C(n,j)。

**这是数对子定理，P,Q 在本段不必为素数幂；整行提升另在 §2.4 明确验证完整幂。** 它不是把多因子弱形状冒称两幂 NC3 输入。

### 2.2 精确代数与合法范围

直接展开得

\[
n-2=dvW,\quad Q-W=d+1,\quad\gcd(d,W)=1,\quad\gcd(Q,dW)=1,
\]
\[
\boxed{\gcd(j,n-2)=v},\qquad
\boxed{dj-(d+2)=(dv+1)W}.\tag{2.1}
\]

W 是正奇数。原范围由

\[
n-2j=Q((d-2)v-1)+1>0
\]

保证，且 j≥11，所以 4≤j≤floor(n/2)。

### 2.3 第三源产生矛盾，含重叠完整幂与孤立 3

反设 W 中没有合法公共素数。

若奇素数 ℓ 同时整除 v 和 W，令 a=vℓ(W)≥1、b=vℓ(v)≥1。由于 ℓ∤dQ，原 n−2 的完整赋值是 a+b，而 vℓ(j)=b。于是 j 模 ℓ^{a+b} 既不为 0，也不可能为 1 或 2（它模 ℓ 为 0）。总赋值 a+b≥2，故即使 ℓ=3 也活动，由 (W) 得到公共素数，矛盾。

所以反设下必须 gcd(v,W)=1；W 中每个素数幂现在都是 n−2 中同样的完整幂。对其活动 ℓ^a：

- gcd(j,W)=1，排除槽 0；
- d(j−1)≡2 (mod W)，排除槽 1；
- 因此必须完整落在槽 2，即 ℓ^a|j−2。

由 d(j−2)≡2−d (mod W) 得 ℓ^a|d−2。只可能有一个被分母消掉的孤立 3，因此

\[
\boxed{W/\eta(W)\mid d-2,\qquad W\le3(d-2).}\tag{2.2}
\]

另一方面

\[
W-3(d-2)
=d(d+1)(v-1)+d(d-3)+4>0.\tag{2.3}
\]

矛盾。这排除了所有 v，没有高度截断，也不需要求解指数方程。

### 2.4 ZERO-RESTORE-ROW：回到完整两幂整行

额外要求 v 为正偶数、P,Q 是不同奇素数的完整幂、P≥5。此时 j0=Qv 满足 j0≡1 (mod P)、j0≡0 (mod Q)，且处于原半行，因而它就是唯一低位 CRT 候选。§2.3 用原 n−2 源关闭 j0；其余 j 用源 p/q，故

\[
\boxed{\forall\,4\le j\le\lfloor(PQ+1)/2\rfloor,
\quad\operatorname{Common3}(PQ+1,j).}\tag{RESTORE-ROW}
\]

该整行定理不需要 P<dH<2P，不需要 v≤d−2，不需要 v≡2 (mod 4)，也不需要 n=2^α 或 3·2^α。

因此交接中的受限恢复域及其光滑 n 交集都被严格覆盖。这里没有否定旧 T0=1 必要条件，只是证明第三源已足以产生更强矛盾；没有单独解出或给指数方程的解数。

## 3. 可复用工具：ZERO-SLOT-SPLIT

### 3.1 完整幂分拆引理

设 F=n−2=AB，J=AC，A,B,C 为正整数，gcd(B,C)=1，4|n。J 是原 j 或原 j 的明确对称表达 n−j。后一种使用 C(n,n−j)=C(n,j)，不更换原输入，也不是严格下降。

若原输入满足 NC3，则：

1. gcd(odd(A),odd(B))=1；
2. B 的每个活动奇素数完整幂都不能落在 J 的槽 0，只能落在槽 1 或 2。

证明：若奇 ℓ|gcd(A,B)，则 vℓ(J)=vℓ(A)<vℓ(F)，并且 J≡0 (mod ℓ)。这违反完整窗口；总指数至少 2，故 3 也不能例外。排除重叠之后，B 中奇素数不整除 J，故不能落槽 0。

特别地，如果槽 1、2 有非零完整幂消元常数 R1,R2，则

\[
\boxed{\frac{\operatorname{odd}(B)}{\eta(B)}
\mid\operatorname{odd}(\operatorname{lcm}(|R_1|,|R_2|)).}\tag{SPLIT}
\]

这个结论不能在未检查重叠时直接把 A 从 T2 中约去。重叠导致的是反证，不是“部分素数幂消失”。

### 3.2 两次消元的完整整数恒等式

令 F=kP²+dP−1，A_r=z+d(t−r)，r=0,1,2。原窗口 ℓ^e|F 与 ℓ^e|j−r 给

\[
\ell^e\mid A_rP-\varepsilon.
\]

不除以 d 或 A_r。定义 R(A)=k+εdA−A²，则

\[
A^2F-R(A)=(AP-\varepsilon)\{k(AP+\varepsilon)+dA\}.\tag{3.1}
\]

所以完整 ℓ^e 整除 R(A_r)。两个 ε 给出的三常数具有相同表达式：

\[
R_0=k-z(d+z),\quad R_1=k+z(d-z),\quad
R_2=k-(d-z)(2d-z).\tag{3.2}
\]

R1>0。不能把 R0 或 R2 为零时的 LCM(0,...) 当有限上界；本轮用的是上面的因子分拆。

## 4. 第二主定理：首档 m=1 零常数全部关闭

### 4.1 M1-ZERO-BAND2 的精确陈述

在真实完整两幂整行中，令 j0 是唯一低位 CRT 候选。若

\[
4\mid n,\quad P<Q<P^2,\quad Q=kP+d,\quad
P<d\max(d,k)<2P,
\]

且 j0 的 (3.2) 至少一个常数为零，则该整行满足 Common3。

若 4∤n，已经由继承消费者排除，不计作本定理新增收益。整行结论是充分消费者，不是 NC3 的等价条件。

### 4.2 完备的零位分类与对称表达

R1>0，所以零常数只能在槽 0 或槽 2。

- 若 R0=0，设 w=z，J=j0，ε'=ε，Y'=Y。
- 若 R2=0，设 w=d−z，J=n−j0，ε'=−ε，Y'=P−Y。

第二种只作同一原输入的二项式对称表达：C(n,J)=C(n,j0)。记录中同时保存 original_j 与 auxiliary_J，不声称 J 仍在半行，也不把它作为一个新反例输入。

两种均满足

\[
1\le w<d,\quad\gcd(w,d)=1,\quad
k=w(d+w),\quad Pw=dY'+\varepsilon'.
\]

写

\[
U=wP+1,\quad V=(d+w)P-1,\quad n-2=UV.\tag{4.1}
\]

如果 d 为偶数，则 w 为奇数，U,V 均偶，导致 n≡2 (mod 4)，矛盾。因此 d 为奇数且 d≥3。于是 d−2w≠0。

规范 H=max(d,k)=k，所以首档上半门槛给

\[
\boxed{P>dk/2=d\,w(d+w)/2.}\tag{4.2}
\]

### 4.3 ε'=−1：受控因子 V

此时 U=dY'，J=QY'。取

\[
A=Y',\quad B=dV,\quad C=Q.
\]

有 F=AB、J=AC，且 gcd(C,B)=1：模 V 时 Q≡d+w，而 V≡−1 (mod d+w)；模 d 时 Q≡w²P，且 gcd(d,wP)=1。

归一化零槽的另两常数为

\[
R_1=2dw,\qquad R_2=-2d(d-2w).
\]

由 (SPLIT)，并用 gcd(w,d−2w)=1，消去 d 的奇部分，得到

\[
\operatorname{odd}(V)\mid\eta(dV)\operatorname{odd}(w)\,|d-2w|.
\]

因为 4|n，所以 v2(F)=1，特别地 V 的二部至多为 2。因此

\[
\boxed{V\le6w|d-2w|.}\tag{4.3}
\]

可是 |d−2w|≤d−2，且 (d+w)²≥16。由 (4.2)，

\[
V>\tfrac12dw(d+w)^2-1\ge8dw-1>6w(d-2),
\]

与 (4.3) 矛盾。这是无界参数不等式排除，不依赖扫描。

### 4.4 ε'=+1：受控因子 U

此时 V=d(P+Y')，并且从同一原输入精确恢复

\[
J=QY'+1=w^2P(P+Y').
\]

取 A=P+Y'、B=dU、C=w²P。gcd(C,B)=1，因为 gcd(w,d)=gcd(P,d)=1 且 U=wP+1。由 (SPLIT) 同样得到

\[
\boxed{U=wP+1\le6w|d-2w|.}\tag{4.4}
\]

若 w≥2，则

\[
P>\tfrac12dw(d+w)\ge d(d+2)>6(d-2)\ge6|d-2w|,
\]

其中 d(d+2)−6(d−2)=(d−2)²+8>0，与 (4.4) 矛盾。

仅剩 w=1、d 为奇数。条件变为

\[
\tfrac12d(d+1)<P\le6(d-2)-1,\qquad P=dY'+1,
\]

而 P,d 为奇数，故 Y' 为正偶数。

对于 d≥9，

\[
d^2-11d+26=(d-9)(d-2)+8>0
\]

使上下界不相容。剩 d=3,5,7 的完备整数末端为：

| d | 由严格上下界及 P=dY'+1、Y' 偶数得到的所有 (P,Y') |
|---|---|
| 3 | 无 |
| 5 | 无 |
| 7 | (29,4) |

末端 d=7、P=29 给 Q=239、n=6932、原候选 j=957。这里

\[
A=33,\ B=210,\ \gcd(\operatorname{odd}(A),\operatorname{odd}(B))=3.
\]

原 n−2=6930 有完整 3²，而 j 的 3 赋值只有 1，违反槽窗口。精确二项式赋值为

\[
v_3\binom{6932}{3}=1,\qquad v_3\binom{6932}{957}=5.
\]

末端也关闭。没有遗留 P、d 或指数高度扫描。

### 4.5 整行回传

上述反证处理的是唯一原候选，必要时使用精确对称表达但始终回到原 C(n,j0)。其余合法 j 由完整 p/q 窗口关闭。故 M1-ZERO-BAND2 是整行充分消费者。

## 5. 相对前沿、剩余域及下一接口

交接的 `m=1,k=d+1,z=1,ε=−1` 恢复域已完整关闭；更一般的首档 m=1 零常数域也关闭。无需再把这些分支写成只剩 n=2^α 或 3·2^α 的开放指数族。

但整个首档仍开放。仍可能的 NC3 必须满足继承接口：

\[
4\mid n,\quad2P\le Q<3P^2,\quad P<dH<2P,
\]

完整两底、原 n/n−2 源、至少一个非零进位；且现在：

- m=1 时 R0R1R2≠0，所以旧 RES-LCM 对所有剩余 m=1 状态都合法；
- m=2 未被本轮零常数定理覆盖。零/非零消元常数情况、原素数底与指数等仍开放。

供下一轮用的直接代数接口：m=2 时 Q=eP²+kP+d、e∈{1,2}，

\[
R(A)=e\varepsilon+kA+\varepsilon dA^2-A^3.
\]

若 R(A)=0，则 A|e，故 A∈{±1,±2}（e=1 时只剩 ±1）。这只限制零槽的整数 A，不给 P,d,k,n,j 的绝对界，也不是 m=2 闭合。

R7={3,4,5,6,7,8,9} 不变。P,Q,p,q,a,b,n,j,d,H,k,z 及其余一般 i3 参数仍无统一绝对上界。

## 6. 证据边界

结构结论来自上述纸面论证，而不是有限扫描、哈希或重放。精确证书检验实际整数恒等式、素数幂、原候选、实际二项式赋值和有限域完备枚举；它们未把整个自然语言证明形式化。

PAIR 定理覆盖实际整数参数的无限数对子族；没有证明其中满足两个真实完整素数幂的整行有无穷多组。ROW 的正确表述是无高度截断的条件整行定理，并有明确实际实例。
