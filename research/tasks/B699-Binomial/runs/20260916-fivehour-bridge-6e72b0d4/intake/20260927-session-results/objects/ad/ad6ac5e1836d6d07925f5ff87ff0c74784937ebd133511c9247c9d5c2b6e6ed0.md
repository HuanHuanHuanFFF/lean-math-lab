# Offline replay

Requirements: Python 3.10 or later, GNU g++ supporting C++17, and a filesystem with room for generated certificates. Python dependencies are standard library only. No network, repository checkout, CAS, Lean, or prior ZIP is used by the replay.

After extraction, from this evidence directory:

```sh
python -B code/verify_manifest.py
python -B code/replay.py --out ../fresh_LATE10_replay --jobs 2
python -B code/compare_replay.py --out ../fresh_LATE10_replay
python -B code/verify_manifest.py
```

The output directory must not already exist. A failed/interrupted invocation is not a PASS; use another fresh directory for a complete run. --jobs may be 1..4. The replay regenerates all twelve profile lists using two anchors, reconstructs and receives every nonzero minor for both primes, computes nine full integer determinants, checks every intended DP cell and terminal witness, regenerates complete multisets, and executes six fail-closed negative controls.

REPLAY_RECEIPT.json is emitted only after every positive check and every expected-negative test completes. compare_replay.py requires the exact entire deterministic certificate set and bytes to match; it does not merely compare counts. The output's environment/elapsed-time records are deliberately outside the deterministic certificate set.

Some exploratory scripts under discovery/ contain paths from this session. They are provenance only, not the portable entry point. code/replay.py is the supported portable replay.

Internal and final archive receipts are distinguished. The internal receipt binds a clean extraction of a sealed pre-receipt checkpoint containing the same code, inputs and deterministic certificates. The final external receipt binds the delivered final ZIP and repeats the full extraction, manifest check, replay and certificate comparison. Neither receipt upgrades the adopted mathematical premises to Lean or external independent review.
