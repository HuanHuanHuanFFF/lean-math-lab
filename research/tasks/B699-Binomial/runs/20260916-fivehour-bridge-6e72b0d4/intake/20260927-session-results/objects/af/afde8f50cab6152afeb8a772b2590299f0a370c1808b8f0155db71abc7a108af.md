# Replay

From the extracted evidence directory:

```bash
python3 -B code/replay.py --out /absolute/path/to/new-empty-replay-dir
```

The replay compiles the C++ generators/checkers, regenerates all q=19/20 early-near and q=8 two-Delta7 gates, both prime rank records, independent local-minor receipts, the 508-signature ledger, both Bellman traversals, exact price audits, removed-state list, final frontier and summary. It then SHA-256 compares deterministic outputs with this package.

No Lean or repository operation is used.
