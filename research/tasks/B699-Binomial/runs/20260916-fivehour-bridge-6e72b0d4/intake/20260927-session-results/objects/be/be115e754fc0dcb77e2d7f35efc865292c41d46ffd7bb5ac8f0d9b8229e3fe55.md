# REPLAY

执行python replay.py：

1. 验证SHA256SUMS.txt（若存在）和PAYLOAD_SHA256SUMS.txt。
2. 独立接收9份证书；不调用旧分支数学重放。
3. 临时目录重新生成9份证书，与包内证书逐字节比较。
4. 对故意变更的证书作拒绝测试。

PAYLOAD_SHA256SUMS的排除项：自身、最终SHA256SUMS.txt、CLEAN_REPLAY_RECEIPT.json、logs/clean_payload_replay.log。最终SHA256SUMS包含上述回执和日志，仅排除自身。

干净回执流程：先冻结payload清单并创建临时ZIP，空目录解压、执行同一重放、检查目录树未改变。将真实回执和日志加入包，再生成最终SHA清单/ZIP。最终ZIP在另一个空目录再次重放，ZIP旁validation.json记录最终包摘要、CRC、清单与退出码。回执不能自包含其自身最终摘要。

生成器和接收器都使用标准库整数，不使用浮点近似。根提升证明范围仅73²；全支排除来自FN3+父同一个c。
