## 1. CENTRAL-15：当前中央负支排除一个完整非平方核

### 定理 1（更宽、明确的原输入量词）

对任意满足上述真实第一源和十倍平方恢复的原数对，令 C>1 为任意与30互素、同时整除 n-4 与 j-2 的正整数。暂不需要完整第四源、E4 平方或全第五源。若 chi_C(3)=-1，则

    alpha X 不等于 15 h^2，alpha Y 不等于 15 h^2    (h>=1).       (1.1)

若还满足 chi_C(2)=-1，则两侧亦均不等于 10 h^2。

这里 C 可取当前实际中心块。这个证明消耗的是实际中央落点，不声称新增长度或额外原源指数。

### 证明

在模 C 下，同一 n,j,k 满足 n=4、j=k=2、N=3，所以

    3U = 4,    3gX=3gY=2.

g、alpha、X、Y、z 都在 C 处为单位。由 U=10g^2z^2 得

    30(gz)^2 = 4 (mod C),

所以对每个 p|C 均有 (30/p)=1，且 chi_C(30)=1。进而

    chi_C(10)=chi_C(30)chi_C(3)=-1.                   (1.2)

另一方面 g^2 alpha X=n gX，故

    3g^2 alpha X = 8 (mod C),
    6 alpha X = (4/g)^2 (mod C),                    (1.3)

Y 同样。因此

    chi_C(6 alpha X)=chi_C(6 alpha Y)=1.             (1.4)

若 alpha X=15h^2，则 h 与 C 互素，(1.4) 左侧等于 chi_C(90)=chi_C(10)=-1，矛盾。Y 同理。若 alpha X=10h^2，(1.4) 要求 chi_C(60)=chi_C(15)=chi_C(2)，因此 chi_C(2)=-1 时也矛盾。

对固定、实际普通因子对，此结论覆盖所有平方部 h 以及所有 a,g,z,C、所有粗支持和指数；不是有限模表外推。

### 更强的逐素数版本：偶指数不能藏在 Jacobi 正号里

事实上对每个实际 p|C，(1.3)和范数分别给

    (6 alpha X/p)=(6 alpha Y/p)=1，(30/p)=1.

因此有效核15要求 C 的**每个**素因子满足(3/p)=1；有效核10要求 C 的**每个**素因子满足(2/p)=1。任何一个相反符号的中央素数，无论其在C中指数奇偶，都排除相应有效核。

特别，chi_C(2)=1不是有效10核通过的充分条件。例如普通整数C=7*19^2的chi_C(3)=-1、chi_C(2)=1，但19的(2/19)=-1，仍排除有效10核。这只是完整支持的算术示例，未恢复n,j，绝不是实际候选。不能因19在C中为偶指数，就把它从这个逐素数必要条件中丢掉。

### 与 R8 的区别及精确翻译

R8 的 GAP-CORE 已排除 X,Y 为平方或三倍平方，本轮不重证。新排除的是

    a 偶：X 或 Y =15h^2；
    a 奇：X 或 Y = 5h^2.                            (1.5)

在 chi_C(2)=-1 子支，另外排除

    a 偶：X 或 Y =10h^2；
    a 奇：X 或 Y =30h^2.                            (1.6)

这些类在 R8 已声明的必要小核表中尚未被该表排除。其当前中央不可能性现在由(1.2)-(1.4)证明，而不是重做旧5估值或相邻平方障碍。若 sf(alpha X) 只含2,3,5，R8允许有效核{6,10,15}；本轮中央测试留下6，以及只有在chi_C(2)=1时才未被此测试排除的10。"未排除"不是存在。

对于真实第二源单位分配 X=M u_-、Y=M u_+，应测试的是

    alpha M u_± !=15h^2,

以及(1.6)的有效10类；不可删去 M，也不可假定 M 是平方。本轮未证明全部剩余分配都进入这些被排除类。

### 完整中央幂的核对，不虚增原指数

若 p^e||q4 属于完整中央槽，则 e=v_p(n-4)，p^e|j-2,k-2。精确恒等式

    (n-1)(3U-4)=2(n-4)+3(j-2)(k-2)                 (1.7)

给 v_p(3U-4)=e（第二项估值至少2e，第一项恰e）。这不是 e+1，也没有把(1.1)误称为高层增益。(1.1)本身只需要实际模p的中央信息；(1.7)保证交接的完整源幂仍未被偷换。

## 2. PAIR-ROUTE：同一平方类对约束原第三、第四源的完整去向

此节是原输入的平方类/源窗口消费者，不要求alpha为3幂或U=10g^2z^2。取任意合法 n,j，N|jk，g=gcd(n,j)，g|U，X=(j-U)/g>0、Y=(k-U)/g>0，alpha=n/g。给定普通整数证书

    alpha X=d_X h_X^2, alpha Y=d_Y h_Y^2.

选实际 p^e||q_r，r=3或4，p>=7。此时p不除g和r-1。

### 同一源的精确表

如果原完整窗口 j=b (mod p^e) 通过，

    (r-1)g^2 alpha X = r b(b-1) (mod p^e),
    (r-1)g^2 alpha Y = r(r-b)(r-b-1) (mod p^e).      (2.1)

因此 g^2 alpha X、g^2 alpha Y 的落点分别是：

| r | b | X侧 | Y侧 |
|---|---:|---:|---:|
|3|0|0|9|
|3|1|0|3|
|3|2|3|0|
|3|3|9|0|
|4|0|0|16|
|4|1|0|8|
|4|2|8/3|8/3|
|4|3|8|0|
|4|4|16|0|

分母3是p单位；表来自整数多项式恒等式，不是模素数采样。

### 定理 2（强迫分配与实际偶估值）

若 r=3 且(3/p)=1，或者 r=4 且(2/p)=(3/p)=1，并且(d_X/p)=-1，那么，在该原完整窗口通过的前提下，

    p^e|X， j mod p^e 属于{0,1}，
    v_p(X)为偶数，且 v_p(X)>=2 ceil(e/2).            (2.2)

因为表中所有非零项都是模p平方，而alpha X=d_X h_X^2的非零类为非平方，所以X侧必须落在零槽。原完整表进而给p^e|X。p不除d_X、alpha，故v_p(X)=2v_p(h_X)，得完整偶估值。Y侧对称，强迫j modp^e属于{r-1,r}。

于是如果(d_X/p)=(d_Y/p)=-1，两个被迫原槽集不相交，原完整窗口不可能通过。实际上同一论证已经在模p产生 j modp>r。因此

    p | binom(n,6) 且 p | binom(n,j).               (2.3)

前者估值恰e，因为六个源中只有n-r能被p整除；后者的阶乘层floor(n/p)-floor(j/p)-floor(k/p)为1。高层贡献均非负。原e没有扩大：(2.2)中的向上补偶属于实际X/原j或j-1，不属于n-r。

此消费者既不限p的大小，也不限e、核系数、g或n。它没有证明某个p必满足两侧非平方条件。当前已假定全部原源通过，因此(2.2)是必要分配，(2.3)是检查失败时的原题回传；不能将它重复计为此前完整窗口之外的独立数值方程。

## 3. 任意完整指数的普通原输入回归族

本节仅验证定理2的原输入回传，不是当前残域模型。

令p=13，F(J)=J^2-J-4。模13的根rho_1=8，F'(8)=15为单位。对每个e>=1，令rho_{e+1}为0<=rho<13^(e+1)、rho=8(mod13)的唯一提升根。用CRT选取正J0，满足

    J0 = rho_{e+1}+13^e (mod13^(e+1)),
    J0 = 0 (mod4), J0>=8.

取J=J0+4*13^(e+1)h，h>=0；n=J(J-1)/2+1，j=J。则

    g=1，U=J-2，X=2，Y=(J-2)(J-3)/2，N|jk，
    n奇，7<=j<n/2，v13(n-3)=e，j=8(mod13).

理由：J被4整除，n为奇数，2n=J(J-1)+2保证gcd(n,J)|2，从而g=1。代入可直接核对第一源。F(J)在13处估值恰e（真提升根加13^e，导数单位，二次余项更高），所以n-3=F(J)/2有同一估值。

模13有n=3、X=Y=2，所以alpha X=alpha Y=6，(6/13)=-1；而(3/13)=1。以d_X=alpha X、h_X=1等普通平方类证书即可调用定理2，得到同一13为共同素数，且v13 binom(n,6)=e。

全参数量词由上面的恒等式和估值证明承担。回归证书只取明确的有限e,h样例，不冒称这些样例穷尽无界域。每个成员g=1且n奇，明确不在当前g=10*3^t*c和偶数高门；没有保留十倍平方、全q5近侧或中央负C。本轮没有把此回归族记成当前域删除。
