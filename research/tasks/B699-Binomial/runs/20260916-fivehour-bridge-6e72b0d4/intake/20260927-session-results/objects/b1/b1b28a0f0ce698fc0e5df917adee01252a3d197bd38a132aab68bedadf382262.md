## 重放

Python 3.10+，无第三方依赖、无网络：

```sh
python3 -B scripts/verify.py --output /tmp/negb0-verify.json
python3 -B scripts/replay_archive.py /absolute/path/to/evidence.zip --output /tmp/negb0-replay.json
```

输出必须放在包/解压树之外。接收器不生成缓存，不写证书或日志；哈希快照检查运行前后树完全相同。

```sh
python3 -B scripts/derive_bezout.py
python3 -B scripts/consume.py --case B0-real-beyond-old-z
python3 -B scripts/consume.py --z 1000007 --b 4
```

任意参数模式不会自动把P/Q说成素数幂；返回“整行条件仍需认证”或“必要条件通过，不是NC”。case模式对包内完整素性/分解证书重新接收。

## 哈希与两阶段回执

PAYLOAD_SHA256SUMS固定所有正文、代码、来源、证书和实际日志。CLEAN_REPLAY.json是在新空目录中对该payload预归档的实际重放；它不自引用其自身或最终ZIP哈希。

SHA256SUMS覆盖除自身之外的最终全部文件。最终ZIP的SHA-256及针对最终ZIP的新空目录重放在随ZIP交付的外部`.sha256`和`-final-replay.json`中。两阶段共享同一payload；没有循环哈希。

数学证明没有有限z末端。日志中的数值样本/有限校验不是覆盖区间；旧125,000行账本未重跑。
