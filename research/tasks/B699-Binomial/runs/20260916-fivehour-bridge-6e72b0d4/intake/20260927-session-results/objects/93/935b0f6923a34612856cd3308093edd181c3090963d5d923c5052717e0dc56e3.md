## 离线重放（Python 3.11+，只用标准库）

```bash
python scripts/replay.py --receipt /absolute/path/replay-receipt.json
```

此命令核对PAYLOAD.sha256及最终SHA256SUMS，重新生成5份主证书逐字节比对，运行不导入发现器的accept.py，拒绝8种算术/范围篡改，并重新执行两个有明确有限范围的原始探索（与日志JSON逐字节比对）。不访问网络、仓库或Lean。

最终ZIP干净解压验证：

```bash
python scripts/verify_archive.py /absolute/path/evidence.zip /absolute/path/final-receipt.json
```

包内replay/是从只含冻结载荷的独立ZIP实际干净解压后的回执；最终ZIP的绑定回执在包外，避免自哈希循环。PAYLOAD.sha256不含replay/、两个清单本身；SHA256SUMS覆盖除自己以外的全部最终成员。
