# Packaging and replay

1. 研究文件、来源、证书、脚本、发现日志及构建验证日志先冻结，以 PAYLOAD_SHA256SUMS.txt 覆盖。清单不自哈希。
2. 冻结 payload 被压成 staging ZIP，并在新建的空目录中解压、核验 payload 哈希、离线运行 verify.py。结果保存为 REPLAY_RECEIPT.json 与 logs/clean-payload-verification.json。
3. SHA256SUMS.txt 覆盖最终所有其他文件，包含 payload 清单与内部回执；最终清单不自哈希。
4. 最终 evidence ZIP 再在另一个新空目录解压，核验两个清单，重放全部本轮证书，并确认提取树未被验证器修改。
5. 最终 ZIP 的 SHA-256、字节数和第二次干净重放结果写入 ZIP 外的 `B699-ProB-ZERO-SPLIT-20260926-final-replay.json`。ZIP 外还有 `.zip.sha256`，避免自引用。

内部回执明确指向 staging payload ZIP，而非最终 ZIP。最终 ZIP 回执应同时显示两个清单均存在并 PASS。

重放程序不依赖 staging ZIP 的保留，也不需要旧 evidence ZIP：使用的旧证明和那9条记录所在的冻结有限证书已经包含在 sources 中。
