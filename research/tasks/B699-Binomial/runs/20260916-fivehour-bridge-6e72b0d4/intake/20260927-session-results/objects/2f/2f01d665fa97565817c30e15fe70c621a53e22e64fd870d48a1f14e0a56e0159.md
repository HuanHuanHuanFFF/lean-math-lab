## 1. 完整源窗口与回到整行

Lucas 的所需部分可自含推导：在 F_ℓ[X] 中，把 n 的 ℓ 进制数字 n_i 代入 Frobenius 恒等式，得

    (1+X)^n = ∏(1+X^(ℓ^i))^(n_i),
    C(n,j) = ∏ C(n_i,j_i) (mod ℓ).

因此，若 ℓ^E || n−2，且 ℓ 是 C(n,3) 的活动奇素数，NC3 必须满足

    j mod ℓ^E ∈ {0,1,2}.                                   (1)

这里 E 是 **原 n−2 中的完整赋值**，不是某个因子的截短指数，更不是只取模 ℓ。对 ℓ≥5，所有 n−2 源素数都活动；ℓ=3 仅在 v3(n−2)=1 时被分母6消去。若 4|n，则

    η2 = 3 if v3(n−2)=1, otherwise 1,
    T2=(n−2)/(2η2),

T2 的每个完整素数幂都必须进入 j、j−1、j−2 的一个槽。

原 n 源同理给

    α=v2(n), η0=3 if v3(n)=1, otherwise 1,
    T0=n/(2^α η0), T0|j.                                   (2)

v3(n)≥2 时并不把指数减一：使用完整 3^v3(n)。

在真实两幂整行输入中，源 n−1 的 p,q 都活动：p=3 时 P≥5 保证 P=3^ρ≥9，故 v3(C(n,3))≥1。完整窗口给 j mod P、j mod Q 均在 {0,1}。两个同槽代表0、1不合法；两个异槽代表之和为 n。

本轮显式恢复满足 j≡1(mod P)、j≡0(mod Q)，并验证 4≤j<n/2。故另一异槽代表 n−j>n/2，原半行只有这一名必要 CRT 候选。**把这个原 j 排除即可提升到全部合法 j 的整行 Common3**；不是挑一个新 j，也不是改变 n。
