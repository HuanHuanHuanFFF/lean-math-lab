# B699 C — 2026-09-26 evidence

这是作者级数学研究证据包，不是 Lean、外部同行评审或 B699 闭合。

阅读顺序：REPORT.md → PROOFS.md → FAILURE_BOUNDARIES.md → HANDOFF.md。SESSION_STATE.json 提供机器可读结论；SOURCE_ADOPTION.md 记录来源和采用范围。

## 复现

仅依赖 Python 3.10+ 标准库，不需要网络、CAS、Lean 或原仓库。所有命令从解压后的包根目录执行：

```bash
python scripts/replay.py --receipt /tmp/b699-c-replay.json
```

Windows 可将回执路径改为包外的可写绝对路径。不要把回执写入载荷目录，以免改变文件清单。脚本验证清单，在系统临时目录重新生成 7 个证书，逐字节比较，运行独立文件中的接收程序，保存真实 stdout/stderr/返回码。

手动步骤：

```bash
python scripts/research.py --out /tmp/b699-c-certificates
python scripts/accept.py --certificates /tmp/b699-c-certificates
python scripts/consumer.py 151 16
```

最后一个命令是不分解 q4 的充分判定器。若不满足前提或特征未触发，返回 UNDECIDED，而不是反例。

## 清单与回执

- PAYLOAD.sha256：全部不可变研究载荷；不包含两个清单和 replay/ 收据。
- replay/PAYLOAD_CLEAN_REPLAY.json：实际从阶段 ZIP 干净解压后重算的回执，绑定 PAYLOAD.sha256。
- SHA256SUMS：最终包所有文件（除自身）；包含 PAYLOAD 清单和包内回执。
- 最终 ZIP 外另有 FINAL_REPLAY.json 与 .zip.sha256，前者来自最终 ZIP 的再次干净解压重放，并记录该 ZIP 的真实哈希。

不把最终 ZIP 的自哈希硬塞入 ZIP 内；否则会产生自引用。用户自行运行时，可加 `--archive /absolute/path/evidence.zip`，将收到的 ZIP 摘要记入包外回执。

## 内容

- scripts/core.py：整数工具、根提升、CRT、精确估值。
- scripts/research.py：路线筛查及证书发现/生成。
- scripts/accept.py：接收，包含补充律、平方剩余穷举、进位和实际二项式复核。
- scripts/consumer.py：原始 (n,j) 的 U4-CHAR 判定。
- scripts/replay.py：清单、干净临时重算、逐字节对照。
- certificates/：7 个原始 JSON 证书。
- logs/：实际发现/接收输出及作者量词修订记录；后者不是伪造的执行日志。
- sources/：主源取回全文、补充定义摘录、来源元数据。

无限结论由纸面证明承担；有限证书只验证其明确计算部分。当前全局 R7 和认证历史净删域均未改变。
