# Packaging and replay boundary

1. 生成本轮文档、程序、证书、冻结来源和构建日志。
2. PAYLOAD_SHA256SUMS.txt 覆盖冻结 payload，不包括它自身、后续内部重放日志/回执与最终 SHA256SUMS.txt。
3. 将冻结 payload 压为临时 ZIP，在全新空临时目录解压、逐项验哈希、运行只读 verify.py。真实结果写入 REPLAY_RECEIPT.json，验证输出写入 logs/clean_payload_verify.json。
4. SHA256SUMS.txt 覆盖最终目录中除自身之外的全部文件；生成最终 evidence ZIP。
5. 最终 ZIP 再在另一个全新临时目录完整验哈希、重算证书，并比较解压树前后散列。最终 ZIP 的哈希及结果写在包外 final-replay.json 与 .zip.sha256，以避免自引用。

临时目录实际创建后在返回前删除；回执记录实际目录名用于审计，不要求该临时路径永久可访问。

以上仅认证完整性、有限计算重放与未修改解压树，不把同作者重放声称外部独立证明。
