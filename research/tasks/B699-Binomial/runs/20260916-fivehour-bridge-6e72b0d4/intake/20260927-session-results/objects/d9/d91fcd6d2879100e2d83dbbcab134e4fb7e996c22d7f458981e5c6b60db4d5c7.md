# B699 C Round 9 evidence

从 REPORT.md、PROOFS.md、FAILURE_BOUNDARIES.md、HANDOFF.md 进入。SESSION_STATE.json给可机读状态；sources/保留采用的原件；certificates/为本轮六份确定性证书；scripts/为发现、分离接收、单原输入消费者、篡改测试与重放；logs/保留实际执行记录；replay/保存载荷干净解压回执。

全部主脚本只需Python 3标准库（支持pow(a,-1,m)，推荐Python>=3.10）。没有外部服务、Lean、仓库依赖或自动安装。

```sh
python scripts/replay.py --receipt /absolute/path/receipt.json
python scripts/verify_zip.py /absolute/path/B699-C-central-core15-pair-source-r9-20260927.zip --receipt /absolute/path/final-receipt.json
```

单数对工具：check_input.py读JSON中的n,j,d_X,h_X,d_Y,h_Y,p,r。它要求普通平方类证书恰好等于原alpha X/alpha Y，仅输出原Common6见证或NO_CONCLUSION；不是完整NC测试。示例：n=29,j=8,d_X=58,h_X=1,d_Y=435,h_Y=1,p=13,r=3。该工具的确定性试除实现限制给定p<=10^7，数学定理无此限制。

SHA约定：PAYLOAD.sha256覆盖文档/源件/代码/证书/日志，不包含两份清单或replay/回执。SHA256SUMS覆盖最终ZIP内除自身以外的每个文件。包外FINAL_REPLAY.json绑定最终ZIP实际SHA，避免把ZIP自己的最终哈希塞进ZIP造成循环。

证据等级：作者纸面证明＋确定性精确证书＋同作者分离实现。历史净删域0；没有全条件普通整数模型；R7、B-RES10和E4平方残支未闭。
