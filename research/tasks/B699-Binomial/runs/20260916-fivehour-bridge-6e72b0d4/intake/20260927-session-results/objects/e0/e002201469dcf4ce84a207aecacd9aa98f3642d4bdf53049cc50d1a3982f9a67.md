# Execution notes

本轮从已挂载的R5 ZIP和明确路径的HANDOFF/PROOFS/FAILURE_BOUNDARIES、Overview开始。核对旧ZIP SHA-256。未调用旧SPARSE、NORM恢复或旧余数计数程序。

先作短菜单整数性诊断(menu_probe.py)。初次探索使用SymPy试除接口生成菜单；交付程序替换为标准库完全试除，相同范围JSON随后实际重放逐字节比对。结果没有z平方，属于低E范围诊断，未记成当前覆盖。

随后通过完整N的幂块CRT生成宽原数对，查找新第五源消费者的回归实例(fifth_source_probe.py)。没有用此有限枚举承担无限量词。

发现器的五份主证书与分离接收器实际运行。有限原数对在接收端用math.comb构造原二项式并验精确估值；巨大族实例用独立数字加法，与发现端阶乘地板和对照。局部证书检查全部同模恢复等式、单位、指定完整指数与通过根，并检查“不属于原输入模型”的证据标记。

所有主文件最终冻结后，先制载荷ZIP并在新临时目录干净解压重放；将实际回执放入replay/，再生成最终清单和最终ZIP。最终ZIP再独立解压重放，外部JSON绑定最终SHA-256。
