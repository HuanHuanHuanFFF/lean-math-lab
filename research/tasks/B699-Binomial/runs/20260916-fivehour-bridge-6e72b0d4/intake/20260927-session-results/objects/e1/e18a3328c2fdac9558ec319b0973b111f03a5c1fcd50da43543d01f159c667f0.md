# B699 D / i=3 — PELL-LAURENT-HEIGHT26

本轮核心交付：相对于指定 Overview / Round12 同源必要入口，统一删除 BRIDGE4096。
独立的一般定理：精确 Pell 平方恢复要求配比高度 𝓗≥(2+√3)^(2q/13)/4。
高桥中 𝓗≤108q，而 q≥512；统一实嵌入范数论证给出矛盾。

**先读 REPORT.md，再读 PROOFS.md。** 失败边界见 FAILURE_BOUNDARIES.md，接续见 HANDOFF.md。
SESSION_STATE.json 提供机器可读状态；完整指标 R7 不变。

## 离线接收

解压后在本目录执行：

```bash
python replay.py
```

Python 3.10+ 标准库即可。无需网络、SymPy、Lean 或仓库。
这会检查所有包内文件哈希，再从原 Laurent 目标递推重建平方根系数，复核恒等式、
统一界的精确常数、归纳基础及有限样本证书。

## 文件结构

- REPORT.md / PROOFS.md / FAILURE_BOUNDARIES.md / HANDOFF.md：主要研究正文。
- SESSION_STATE.json / SOURCE_ADOPTION.md / RESEARCH_LOG.md：状态、来源、研究记录。
- inputs/：明确标记的来源采用摘录，不是历史原附件字节副本。
- evidence/：发现程序、生成程序、标准库域算术与接收器。
- certificates/：完整符号证书、统一界证书、样本与大分母边界。
- logs/：实际执行输出；ENVIRONMENT.json：执行环境。
- PAYLOAD_SHA256SUMS.txt：加入自述回执前的科学载荷清单。
- CLEAN_REPLAY_RECEIPT.json：该载荷在新临时目录干净解压并成功重放的实际回执。
- SHA256SUMS.txt：最终全部文件（除本清单自身）的摘要，覆盖内部回执。

最终 ZIP 另附外部 `.validation.json` 和 `.zip.sha256`，记录最终 ZIP 自身的摘要、
CRC 和再次干净解压重放。ZIP 不能在自身内部无循环地包含自身摘要，故分开交付。

证据等级为作者级纸面证明与精确算术；不称 Lean、全 i3/B699 或外部独立审读。
NC3 进入高桥的冻结历史归约没有在本轮全链重证；父 ZIP 原字节也未取得。
