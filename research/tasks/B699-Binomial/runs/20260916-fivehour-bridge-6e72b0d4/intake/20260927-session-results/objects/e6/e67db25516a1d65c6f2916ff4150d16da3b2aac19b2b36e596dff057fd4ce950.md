# REPLAY

环境：Python 3 标准库。推荐 Python 3.10 或更新。

```bash
python replay.py
```

顺序：核对发布清单 → 核对直接父 ZIP 原字节摘要（不运行父证明）→
运行本轮数学接收器 → 在新的临时目录生成9份证书 → 与发布证书逐字节比较。
任何摘要、恒等式、界、模类覆盖、有限诊断或再生成不一致都会非零退出。
重放不写发布目录，不联网，不访问仓库。

单独接收或生成：

```bash
python evidence/verify.py
python evidence/generate.py --output /path/to/new/empty/directory
```

后一个命令不要指向已经发布的 certificates/。

内部回执对先冻结的 PAYLOAD_SHA256SUMS.txt 清单重放；最终外部回执对实际最终 ZIP
重新在空目录解压并运行默认 SHA256SUMS.txt 全量重放。
这两层回执区分了载荷生成与最终容器封装，且不会要求 ZIP 包含自身哈希。

无限数学量词依赖 PROOFS.md 的完整推导，而非901个样本或打包哈希。
