# Hash and replay design

PAYLOAD_SHA256SUMS.txt lists all mathematical payload, scripts, certificates, sources and build logs. It excludes itself, SHA256SUMS.txt and REPLAY_RECEIPT.json to avoid self-reference.

REPLAY_RECEIPT.json records an actual clean extraction replay of a **payload-stage ZIP**, not the final ZIP. Its archive hash refers to that bootstrap artifact.

SHA256SUMS.txt subsequently covers every final internal file except itself, including the payload manifest and the payload-stage replay receipt.

The final evidence ZIP is separately extracted into a new temporary directory and verified. Its final hash and receipt are provided OUTSIDE the ZIP; this avoids pretending that a ZIP can contain its own final cryptographic hash.

Both verifications reject outputs inside the extracted tree and compare the complete file tree before/after verification. The second root algorithm is independently implemented by the same author, not external independent review.
