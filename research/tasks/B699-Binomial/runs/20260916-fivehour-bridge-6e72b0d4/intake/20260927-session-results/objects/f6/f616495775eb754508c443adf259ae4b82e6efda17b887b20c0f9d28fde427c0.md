# REPLAY — 干净解压与身份绑定

## 标准命令

在解压后的包根目录运行：

```sh
python3 code/replay.py --out /tmp/b699-cost4-fresh
```

输出目录须不存在。Python只使用标准库，C++要求17标准。正式证书并不依赖research中的浮点价格发现脚本。

重放会校验采用输入与文件清单，重新生成初始三个状态及后续两个状态的全部费用组合，并与不使用Bellman的C++枚举逐集合核对；生成六个几何分支及两锚点；重算、接收两素数的全部子式；计算19个整数子式；验证完整安全转移与505个整数价格；重算120状态并接收119条剩余弱见证；执行负向控制。

所有确定性证书逐字节比较。运行耗时、命令绝对路径、编译器版本和进程失败码等环境日志单独记录，不作为数学恒等式。

## 两层清单与回执

PAYLOAD.sha256覆盖核心交付文件（不含verification目录及根目录两份清单自身）。MANIFEST.sha256覆盖最终包内所有文件，只有根目录MANIFEST自身除外；归档依赖中同名的旧MANIFEST也被列入。

首次阶段ZIP已从全新目录完整重放成功，原回执与日志保留在verification/CLEAN_REPLAY_*。之后只对“六分支证书不等于六片新增历史未知域”的说明性记账作保守收紧，并补齐归档清单的外层身份记录；数学代码、采用输入与62份证书没有改变。修订记录与前后文档哈希在verification/NOVELTY_ACCOUNTING_REVISION.json。因此内部阶段回执对应其明确记录的阶段PAYLOAD，不冒充最终ZIP的字节绑定。

修订后的最终ZIP本身再次解压到全新目录并完整重放。最终ZIP的SHA-256、压缩包完整性、全部文件清单检查及完整重放结果记录在交付的外部FINAL_ARCHIVE_REPLAY_RECEIPT.json。该最终重放不是只检查哈希，而是重新生成并逐字节核对所有数学证书。

最后一份回执放在ZIP外，是因为把最终ZIP的哈希再写回自身会改变其字节。外部回执绑定准确的最终交付字节。

## 证据等级

干净重放说明可执行证书被重新生成且一致，不说明历史A1–A3已经由外部独立审稿人重新证明。计算证书仍需结合PROOFS的完备枚举、完整有理系数空间和特征零回传；不能将有限辅助模型当作原题候选。
