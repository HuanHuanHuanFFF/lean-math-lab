# B699 Pro B — M2ZERO evidence

入口：REPORT.md → PROOFS.md → FAILURE_BOUNDARIES.md → HANDOFF.md。

Python 3.10+，仅标准库，无网络，无仓库依赖。不要用 `python -O`，验证器使用断言。

```
python3 -B scripts/verify.py --output /tmp/m2zero-verify.json
python3 -B scripts/consume.py --P 25 --Q 1663
python3 -B scripts/consume.py --P 197 --Q 42767
python3 -B scripts/replay_archive.py /path/to/evidence.zip --output /tmp/m2zero-replay.json
```

验证器重算八份证书，并检查整数恒等式、全部有限末端、真正不同底完整幂、原始 j、完整第三源指数、有限整行直接二项式与旧账本零记录。计算结果相同不是外部独立数学证明。

`discover.py` 会写入 `certificates/` 和生成日志，日常重放只运行 `verify.py`。

最终 ZIP 自身的 SHA-256 与重放回执放在包外，以免自引用；包内 `REPLAY_RECEIPT.json` 对应冻结 payload 的真实干净重放。
