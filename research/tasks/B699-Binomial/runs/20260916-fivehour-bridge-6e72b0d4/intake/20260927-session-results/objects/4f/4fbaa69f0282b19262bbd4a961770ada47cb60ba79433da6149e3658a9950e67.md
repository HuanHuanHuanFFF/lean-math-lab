# REPORT — B / i3：两完整幂源的数字间隙整行消费者

日期：2026-09-26。轮次标识：TWOPP-DIGIT-GAP。原输入始终为同一 (n,j)。

## 结论

本轮得到一个可从原题直接调用的**整行充分消费者**：

> n−1=P Q，P=p^a、Q=q^b 是两个不同奇素数的完整幂，5≤P<Q。设 Q 的规范 P 进制数字为 d_i，d=d_0=Q mod P，H=max d_i。若 **P>dH**，则对该 n 的全部 4≤j≤⌊n/2⌋，都有奇素数 ℓ≥3 同时整除 C(n,3)、C(n,j)。

特别地，**P≥H² 足够**。p 或 q 为 3 且完整幂≥9 时没有被排除；较小幂恰 P=3 的孤立情况在 PROOFS §9 单独正确处理。

证明不逐个增加数字次数，不枚举模壳。实际 Q=q^b 的恢复条件把最后分支强制成 ε=−1、z=u、d≥2u+1≥5；第三源给 n−2<24H³，门槛又给 n−2>25H³，直接矛盾。没有留下门槛内的有限末端。

**全局指标前沿没有下降：R7={3,4,5,6,7,8,9} 不变。没有完整 i3 或 B699 闭合。** 本轮新增的是上述精确结构域的纸面整行排除及消费者，不是整个“两底交叉”区域的闭合。

## 真正排除的无界域

排除的是所有满足上述完整分解和数字门槛的 n，及每一行的**所有合法 j**。素数底、完整指数、P、Q、n 不设扫描上界。

该域确实包含无穷多个实际整数行，而不只是形式参数：存在无穷多个相邻素数 P<Q 满足 (Q−P)²≤P，此时 d=H=Q−P。PROOFS §10 给出基于素数倒数和发散的自含证明；未假设孪生素数猜想。

原输入恢复没有折损：s,t 是原 j 的两个低位；X,Y 是原 j 的商；最终 j=(uP+1)² 是对原 j 推得的等式，未换成另一对输入。

## 数学收益

首先得到通用的两幂源必要边界：真实 NC3 必须 4 | n 且 Q<3P²。

随后得到无次数误差的逐系数提升：从 PX−QY=ε、完整 Lucas 数字支配，构造 c_i=d x_i−z d_i+ε d_{i+1}，满足 |c_i|≤dH<P；整数等式 Σc_iP^i=0 强迫所有 c_i=0。

它强迫数字内容恰为最低位 d，并且 d=q^c。内容 1 分支回到 repunit 原行，由 n 源给实际第三素数；非平凡内容分支必须恢复真正 q 次幂，不能把 d|Q 当作充分恢复。最后所有第三源完整素数幂进入非零消元常数，得到 25/24 矛盾。

于是该两幂源中的剩余 NC3 必须满足 **dH>P、H>√P、Q<3P²、4|n**。这些条件仍不是充分条件，参数仍可无界。

## 有用的防误用实例

P=1093、Q=3^9=19683，n=21,513,520，j=4,782,969。p=1093 和 q=3 的完整 Lucas 条件都通过，且 Q 的 P 进制数字为 [9,18]。这**不是反例**：第三源活动完整部分 T2=10,756,759，而对应消元积仅 R=12,032，不可能 T2|R；实际素数 13 同时整除两个原二项式。

该例也满足 P>dH。它排除了“这个门槛仅靠两个底的 Lucas 条件就能闭合”的错误解释；真正第三源消费者是必要步骤。

## 仍开放及下一步

本轮没有给出 n、P、H 或底素数的统一绝对上界。一般原题、n−1 不恰为两个奇素数完整幂的行、数字门槛外 dH>P 的两幂行，以及 Overview 的其他未映射分支仍开放。

下一项可证伪检查：在真正的门槛外原输入上保留整数进位 c_i，而非把它们置零；先研究第一档 P≤dH<2P 的可行进位链，并同步保留 Q=q^b、第三源完整幂和原 j。不得只枚举模类后声称下降。详见 HANDOFF。
