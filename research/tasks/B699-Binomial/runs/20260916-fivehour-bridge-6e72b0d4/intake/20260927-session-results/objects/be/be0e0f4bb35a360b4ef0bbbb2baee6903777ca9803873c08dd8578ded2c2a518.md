## 重放

Python 3.10或以上，标准库即可；不需要SymPy、CAS、网络、GitHub或Lean。不要加`-O`或`-OO`。

    python scripts/replay.py --receipt /absolute/path/receipt.json

它将：核对清单；在全新临时目录重新生成七份主证书；逐字节比较；运行不导入发现器的接收器；检查五种故意篡改均被拒绝。

单步入口：

    python scripts/discover.py --out /absolute/path/new-certificates
    python scripts/accept.py --cert-dir /absolute/path/new-certificates
    python scripts/mutation_test.py --cert-dir /absolute/path/new-certificates

## 内容

- REPORT/PROOFS/FAILURE_BOUNDARIES/HANDOFF：结果、完整条件证明、失败边界与下一门。
- SESSION_STATE.json、SOURCE_ADOPTION.md：准确状态和依赖级别。
- certificates/：七份规范证书；其中局部模型、实际规范输入和另侧弱输入分别标记，绝不混合条件。
- scripts/：独立可运行的发现、接收、变异与重放。
- experiments/、logs/：原始探索轨迹及运行限制；探索原脚本不属于规范重放依赖。
- sources/：指定Overview及本轮采用的前序原件文本、字节接收记录。
- replay/：载荷在干净解压目录中的实跑回执和输出。
- PAYLOAD.sha256、SHA256SUMS：两层清单。最终ZIP外部回执单独绑定最终ZIP的SHA-256，避免自引用。

数学无限量词由PROOFS.md承担；有限样例、算法比对和哈希不代替证明。所有接收代码仍由同一作者编写，不是外部独立数学审读。
