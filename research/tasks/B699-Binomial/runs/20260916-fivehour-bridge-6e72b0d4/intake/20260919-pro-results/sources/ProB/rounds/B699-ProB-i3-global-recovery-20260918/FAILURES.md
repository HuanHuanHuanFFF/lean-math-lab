# 方法边界、未完成项与禁止误用

## 1. 不能删除 vQ0 的平方前提

GSB 中的决定性整数 tau=2m sqrt(vQ0)−X，只在 vQ0 为平方时有该整数性。非平方时可为很小的正无理数，不能再用“正奇整数 tau<kappa a”的矛盾。

精确的单步反例：kappa=1,d=3,a=1,m=1,v=13,V=3 给 M=13、E=1、Q0=103，X=73、D_+=27，且

    4m² vQ0 − X² = 5356−5329 =27。

sqrt(5356)−73 在0与1之间，但不是整数。这只反驳删除平方前提的那一步，不是完整恢复解：例如它没有给出真实 g、正整数 U/zeta 和 alpha 回传，并且 m=1 本来属于旧已排端部。不能据此声称剩余非平方 NC3 域存在全局无限相容族。

## 2. GB 不是一般绝对高度

32a^12 B_*^4 < kappa^8 c^4 d^3 M^3 对全部负根输入成立，但单独只限制 a 相对 d 的增长。消去 d 用到了整数 tau 产生的 M|F²。没有平方前提时后半步缺失，因此不能把 a 的分支绝对界移到一般负根族。

M|F² 是完整赋值整除，但不表示 M|F，也不表示某个既有缺失 B_* 幂必须全部进入 Q0。theta 的原始定义与孤立3修正保持不变。

## 3. 第二范数排除也有严格前提

e0=gcd(uT,z) 后只有当 uTz 是平方，才能把两个互素商分别写成平方。没有这一前提，不能把一般范数参数塞进 X−Y、X+Y 为27的因子表。

6→30→17→0 是这条已证明完备归约的有限末端，不是一般 i3 仅剩17个输入，也不是有限扫描外推。

## 4. 两种三次对象和两种新平方都不相同

P_rho 可约性、Psi 可约性、Disc(P_rho)、Disc(Psi)、vQ0 的平方性、u z T_rho 的平方性是不同命题。没有证明任意两者等价。本轮没有重新做上一轮局部2/3/17相容性实验，也没有把其局部实际 Psi 接成普通整数全局点。

## 5. 本轮没有完成的目标

没有一般可约或不可约 P_rho 的闭合；没有一般 i3 有效有限化；没有保持同一 NC3 的严格下降；没有完整粗支持或指数的全局绝对界；没有覆盖一般两底交叉指数域；没有符合原题的反例。

没有构造满足全部当前全局恢复条件的精确无限相容族。因此不能把本轮结果表述成“全局恢复路线已经被证明不足”。本轮成功排除了两个分裂平方型，剩余非平方问题仍需研究。
