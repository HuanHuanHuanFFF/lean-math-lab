# PROOFS — 偶数平方参数的两底闭环

日期：2026-09-18。作者：本轮 Pro E。证据：作者纸面推导＋完整有限整数证书；无 Lean、无外部独立审读。

## 0. 精确主定理与返回原题

记 Common3(n,j) 为存在同一个奇素数 p（允许 p=3），同时整除 C(n,3)、C(n,j)。合法范围是 4≤j≤⌊n/2⌋。

**定理 ES2（较强的窗口版本）。** 设 x 为正偶数，n=2x²，4≤j≤n/2，k=n−j，gcd(n,j)=2。定义真实孤立 3 参数

    μ=3，当且仅当 v₃((n−2)/2)=1；否则 μ=1。
    N=n−1，K=(n−2)/(2μ)。

假设两个完整窗口

    N | j(j−1)，K | j(j−1)(j−2)。                     (W)

置 β=j/2、γ=k/2、H=gcd(K,j−1)、C=K/H、t=βγ/N。若 u=t/C=1，则

    ω(t)=ω(C) ≥ 3。

这里不假设 α 的形状，也不假设原输入 NC3；这是完整窗口系统自身的结论。下面证明 t、u 是正整数。计算末端同时检查窗口版本与原始二项式版本。

**原输入充分消费者。** 对上面合法原输入，先计算真实 g、μ、N、K；g=2 时，若 t 是正整数，C=gcd(K,t)，且 t=C、ω(t)≤2，则 Common3(n,j)。实现不得把非整数 t 舍入；不命中仅返回 UNKNOWN。

证明：若原输入是 NC3，则 (W) 必须成立，且两种 C 定义一致。于是 ES2 给矛盾。若任一完整窗口失败，则其一个完整源幂直接提供同一对原二项式的共同奇素数。这个消费者不是给定 n 的整行定理。

**幂指数推论。** 对所有 e≥1，在 NC3、g=2、u=1 下，

    n=2^(2e+1) ⇒ ω(t₃)≥3。

e 无上界，两个可能底数及完整指数无上界。e=0 时 n=2 没有合法 j。本结论不覆盖一般两底交叉指数域。

## 1. 完整源窗口、孤立 3 与同一个输入

对每个素数 p，直接从阶乘得到

    v_p C(n,j)=Σ_{h≥1}(⌊n/p^h⌋−⌊j/p^h⌋−⌊k/p^h⌋)。

各项非负，等于 1 恰好当 j mod p^h > n mod p^h。这也说明使用一个完整源幂的进位即可给原二项式整除见证，不需要更换 n,j。

因为平方模 3 只能为 0 或 1，3∤(2x²−1)，故本行的真实 λ 永远等于 1，N=n−1。

N、K 都是奇数，且互素。对 N 中完整 p^a，n mod p^a=1；对 K 中完整 p^a，n mod p^a=2。这些 p 全都整除 C(n,3)：p≥5 时分母 6 不取消 p；p=3 时，孤立一次 3 已在 μ 中移除，仍在 K 中的完整 3 幂指数至少 2，取消一次后仍有正估值。因此 NC3 必须给出 (W)。注意原窗口使用的仍是整个 3^a，不是取消后的 3^(a−1)。

(W) 仅是 NC3 的必要条件；本文不从窗口反推 NC3。

## 2. 同输入规范分配、正性与恢复

x 偶，故 8|n。真实 gcd=2 给 β、γ 为互素奇数，β+γ=n/2=x²。端点 j=n/2 不可能，因为那时 gcd(n,j)=n/2≥4，所以 j<k。

由 n≡1 (mod N)，第一窗口等价于 N|jk；N 奇，所以 t=βγ/N 为正奇整数。

第二窗口把 K 的每个完整奇素数幂完整分配到 j、j−1、j−2 的一个位置。原因是这三个数任意两个的奇数部分互素。令

    L=gcd(K,j)，H=gcd(K,j−1)，R=gcd(K,j−2)。

于是 K=LHR，三块两两互素，C=LR=K/H 为 K 的酉因子。H 同除 j−1、k−1，且 H 与 jk 互素；L|β、R|γ，C|t，C=gcd(K,t)。因此 u=t/C 是正整数。

本轮 u=1，故 βγ=NC。由 β⊥γ、N⊥C 得到完整分配

    β=aL，γ=bR，ab=N。                              (S)

这里 a,b 是第一窗口的完整分块，不是指数。

又有 N|(j−1)(k−1)，H²|(j−1)(k−1)，N⊥H，故

    z=(j−1)(k−1)/(NH²)

为正奇整数。原输入恒等式给

    4C−zH²=1，n=2μCH+2。                            (NORM)

H 为奇数，H|(n/2−1)，因此

    m=(n/2−j)/H

是正偶整数，仍来自原来的 j。准确恢复为

    j=(μC−m)H+1，k=(μC+m)H+1，
    m²=μ²C²−z(2μCH+1)。                              (DISC)

下面所有平方间隙同时使用 NORM 与 DISC，未把单独范数方程当作完整恢复。

## 3. 定向重建高度前置：在本行只需 8|n

这一机制来自入口所指旧 E/P2-POWER 的 §2；此处完整重证，并验证本行可从 16|n 降到 8|n。它不是把旧相对界无证明地扩大到一般 NC3。

置

    D=μH，E₀=μC−zH，A₀=μE₀−2z。

从上节逐项展开得

    E₀²−m²=4Cz，
    A₀²−(μm)²=4z²(D+1)，
    4A₀=z(D²−4D−8)+μ²。                             (SG)

A₀ 与 μm 均为偶整数。

反设 D≥4z+6。z≥1，所以 D≥10，最后一式给 A₀>0；中间一式给 A₀>μm≥0。两个偶整数至少相差 2，故

    4A₀−4 ≤ A₀²−(μm)²=4z²(D+1)。

代入最后一式可得

    z[D²−4(z+1)D−4z−8]+μ²−4 ≤0。

括号内二次式在 D≥4z+6 递增，在左端值为 4z+4。因此左边至少 z(4z+4)+1−4≥5，矛盾。故

    D<4z+6。                                         (SG0)

现在验证本行的模 8 约束。设 α=n/2=x²，则 4|α，β、γ 奇且和为 α。因此

    βγ=β(α−β)≡α−1 (mod 8)。

这是因为 β²≡1 (mod 8)，α(β−1) 是 8 的倍数。又由 u=1 得

    Dβγ=(n−1)(n/2−1)≡−(α−1) (mod 8)。

α−1 为奇数，可逆，故 D≡7 (mod 8)。z 奇，SG0 因而加强为 D≤4z+3，进而 z≥D/8（事实上 D≤7z）。

由 NORM

    n=μ(zH³+H)/2+2 > μzH³/2 ≥ μ²H⁴/16。

所以

    H⁴<16n/μ²，
    D⁴<16μ²n≤288x²，D²<17x。                       (HEIGHT)

最后一步用 μ≤3、n=2x²、288<17²。它只用于当前 λ=1、完整窗口、g=2、u=1 子域；没有得到全 NC3 的 H 或 n 绝对界。

## 4. 不调用旧 L,R≥11 链：本子域两端必须非空

先证明 C≥3 时 L,R 都大于 1。若某一端为 1，另一端即 C；只为算术记号交换 β、γ 的标签，仍是同一原输入的两部分。由 (S) 可写

    ξ=aC，η=b，ab=n−1=2(aC+b)−1。

C|n−2 强迫 b≡1 (mod C)，再由 ab≡1 (mod C) 得 a≡1 (mod C)。置 a=1+Cw、b=1+Cv，w,v≥0，展开得

    (Cw−1)(v−2)=4−w。                                (END)

w=0 强迫 v=−2，不可行。w=1 要求偶数 C−1 整除 3，不可行。w≥2 且 w≠4 时，0<|4−w|<Cw−1，不可整除。因此只有 w=4、v=2。

这时 a=4C+1、b=2C+1，且

    μH=(n−2)/(2C)=4C+3。

H 同除原来的 j−1、k−1，特别 H|2b−1=4C+1；故 H|2，H 奇给 H=1，从而 μ=4C+3>3，矛盾。

所以 C≥3 ⇒ L,R>1。这只是本轮的短前置，不以局部引理数量计为主要进展。

## 5. 两底强迫两个平方差因子分别承载一个完整底

以下设 x≥32。由 HEIGHT，D²<17x<(x−1)²，故

    D<x−1。

同时

    x²−1=DC。

若 x−1 与 C 互素，则 x−1|D，与 D<x−1 矛盾。x+1 同理。因此 x−1、x+1 各自都必须含 C 的素因子。两者为互素奇数。

若 ω(C)≤2，必恰好有两个素数。写完整幂

    C=UV，U=P^ℓ，V=Q^r，P≠Q，ℓ,r≥1，
    x−1=A U，x+1=B V，AB=D。                         (FAC)

第 4 节保证 L,R>1，故 L,R 就是 U,V 的某个顺序。只对同一 β、γ 的算术标签作交换后，可写

    β'=aU，γ'=bV，ab=2x²−1，β'+γ'=x²。

这里没有用 p=i 的错误严格化，也没有拆断任何源幂。A、B 包含各自剩余完整块；μ=3 的孤立 3 自动保留在 D=AB 内。

## 6. 新的奇偶整数恢复：消掉可变指数切片

定义正奇整数

    X=aB，Y=bA。

由 FAC 与原输入分配，准确得到

    X(x−1)+Y(x+1)=Dx²，XY=D(2x²−1)。                (LIN-PROD)

这一步是从同一输入得到的必要表示，不是独立生成反例的充分模型。

置

    T=X+Y−Dx。

X,Y 奇、x 偶，所以 T 偶。线性式给 Y−X=−xT，因此

    2X=Dx+(x+1)T，2Y=Dx−(x−1)T。

X,Y>0 与 D<x−1 给

    −D<T<D+1。

D 奇、T 偶，故

    |T|≤D−1。

乘积式现在精确等价于

    (D²−T²−8D)x²+2DTx+T²+4D=0。                  (Q)

对给定 D,T,x，上述二次式与 LIN-PROD 的乘积部分等价；反向还须检查 X,Y 正奇及原来的所有整除、真实 gcd 等。本文只使用正向必要性。

## 7. 绝对压缩 D≤29

记 F=D²−T²−8D。D 奇、T 偶，所以 F 为非零奇整数。

反设 D≥31。由于 D−|T| 为正奇数，只可能落入以下两类。

**类 I：|T|≤D−5。** 此时

    F≥D²−(D−5)²−8D=2D−25。

由 D²<17x，有 2DT/x>−34，且 (T²+4D)/x²>0。故 Q/x² 的左边大于

    2D−25−34=2D−59≥3，

不能为零。

**类 II：D−3≤|T|≤D−1。** 此时

    F≤D²−(D−3)²−8D=−2D−9。

又 2DT/x<34，且 T²+4D≤(D+1)²<x²。因此 Q/x² 的左边小于

    −2D−9+34+1=−2D+26≤−36，

也不能为零。

D 奇，排除 D≥31 后得到

    D∈{1,3,5,…,29}。

这里的 29 是本子域内真正的绝对常数，不依赖 x、P、Q 或其指数。不是固定一个未界参数之后再声称有限。

## 8. 真正有限的末端及两种算法

现有 |T|≤28、D≤29、F 非零。由 Q

    x²≤|F|x²≤2D|T|x+T²+4D≤1624x+900。

因 x≥32，故 32x≤32·1624+900=52868，整数 x≤1652。

准确系数域为

    D=1,3,…,29；T=−D+1,−D+3,…,D−1。

总共 ΣD=225 个状态。

算法 A（src/generate.py）对每个状态逐个计算所有整数 32≤x≤1652 的 Q 值，共 364725 次精确整数代入，零点数为 0。这里检查所有整数 x，强于仅检查偶数或二幂 x。

算法 B（src/verify.py）不枚举 x。它用

    Disc(Q)/4=T⁴+12DT²−4D³+32D²

和整数平方根，完备重建每个状态的全部整数根。225 个状态中，只有 (D,T)=(7,0) 的判别式是平方，其整数根为 x=−2、2，均不在 x≥32 范围。

两种算法相互独立的是有限末端的算法机制，不是作者身份。输出见 outputs/primary.json、secondary.json；证书见 outputs/certificate.json。二次式首项 F≠0 已在数学证明和检查器中各核一次，未遗漏退化一次式或恒等式分支。
