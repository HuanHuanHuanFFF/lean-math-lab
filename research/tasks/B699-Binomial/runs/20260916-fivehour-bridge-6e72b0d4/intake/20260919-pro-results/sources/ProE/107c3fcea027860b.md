## 重放

Python 3.10+。生成器使用SymPy 1.14.0；第二检查器只用标准库。

```bash
python -m pip install -r requirements.txt
python src/replay.py
```

每次重放写新的verification/UTC时间戳目录，不覆盖outputs/frozen。
单独复核冻结证书无需SymPy：

```bash
python src/check.py outputs/frozen/certificate.json
```

本包不是Lean或外部数学验收；作者纸面证明承担无限量词。
