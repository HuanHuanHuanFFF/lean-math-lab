# B699 Pro E｜偶平方两底闭环

本轮结果：对所有正偶数x，在n=2x²、同一合法原输入、真实gcd(n,j)=2、两个完整窗口与规范u=1下，必有ω(t₃)≥3。

原NC3前沿因此排空g=2/u=1两底切片中的全部n=2^(2e+1)，e≥1；并非全i3、全两底或一般交叉指数域闭合。

## 阅读

先读 `OVERVIEW.md`，然后按需要看 `REPORT.md`、完整 `PROOFS.md`、`FAILURES.md` 和 `SOURCE_ADOPTION.md`。

证据等级：作者纸面＋精确有限证书＋同作者算法独立复核，无Lean/外部独立审读。所有来源与本轮增量分开记录。

## 复验

测试环境：Python 3.13.5；仅标准库。于本目录执行：

```sh
python src/generate.py
python src/verify.py
python src/test_corruption.py
```

主检查会重建 `outputs/certificate.json` 与摘要；第二检查器不调用生成器。正常结果分别是225系数状态无大整数根、4915个原数对全部共同奇素数见证通过、7种损坏证书全部拒绝。

`inputs/parameters.json` 固定有限域；`outputs/*.json` 保存精确结果。`MANIFEST.json` 保存交付时文件大小和SHA-256。重跑后日志格式或运行记录有变化时，清单属于原交付快照，不能擅自把新字节说成旧哈希对应的文件。

`experiments/probe_even_slice.py` 仅为早期方向门检，其输出不承担无限证明。真正的有限末端位于 `src/`。

## 目录

- 根目录：报告、证明、失败与接续。

- `inputs/`、`outputs/`：完整有限输入、证书与实际输出。
- `experiments/`：有限方向门检，明确不是证明。
