## 1. μ29 / 源预算：COVER33 → COVER22

首攻加权 10 / X 五次 / 普通总源重数 μ=29 的“一行缺一重”。

主要结果：
- 完整处理 μ29 结构；不可约残余首一化压成一个明确有理一参数族
  `H = P5 + t W Q`；
- 真正推动全局的是同一个 G 的源重数与 X 次数联合计账：
  `Σ mult_H(G) (deg_w H - 2 deg_X H) ≤ 3`；
- 得到 X 三次可载点分量至多 3 个；
- 分类若干低零余量类别并联合全部竖直因子预算；
- 固定覆盖上界从 33 降到 22；
- 另得到两条带 μ 条件的高门槛 Common9 消费者。

关键失败边界：
- μ29 并非“全部可约”；存在精确不可约辅助例子，所以必须保留真实一参数族；
- 这类辅助多项式不等于 NC9 反例。

## 5. 统一源直线剥离 SAT(1..13)：COVER19 → COVER16

原计划先做 SAT60：
`D=20, e=10, μ=60`。

研究中发现更强统一结构：
对 `1≤q≤13`，
若 `deg_w H=2q, deg_X H=q, μ=6q`，
则不需要 `z≥14`，首一化后都只能是
`∏[X-t_a(N-t_a)]`, `t_a∈{0,1,2,3}`。

核心新剪枝：
- 对 `t=0,1,2,3,4` 看一元限制 `R_t(N)=H(N,tN-t^2)`；
- 若沿该源直线的普通源重数和 `S_t>2q`，则该源线因子整除 H；
- `t=4` 会制造禁止根，`t=0..3` 可剥离；
- 商仍六行饱和，但 z 可能下降，所以必须证明“无 z 下界”的统一归纳命题。

计算压缩：
- q=1..13 共 814,933 个完整根门；
- 807,702 个直接由源线剥离处理；
- 只剩 7,231 个普通 jet 系统；
- 全部精确不相容；
- 新增 SAT60/66/72/78。

把 NF23/NF29/NF35 的单缺重位置也加入同一实际竖直分配：
- 排除 17 分量共存；
- `COVER16`；
- `EDGE16`：达到 16 则全部可载点因子零余量。

## 6. 亏格 + 切向费用 + 高次饱和：COVER16 → COVER13

继续推进 NF41 / 高次 SAT 时得到三类新结构。

### 6.1 近饱和分类
补齐 q=6..9 的 `μ=6q-1`：
- q=6：整个近饱和不可约类关闭；
- q=7、8：出现固定不可约例外 E7/E8，但用精确 Bernstein 符号证书证明在 NC9 大点范围不取零；
- q=9：留下一个明确有理一参数族，普通行重数 `(8,9,9,9,9,9)`，唯一缺重在 r=3；不能把整个族错误说成“所有合法点不取零”。

### 6.2 亏格剪枝
用绝对不可约归约 + 加权曲线亏格/局部 δ 下界：
`Σ_P m_P(m_P-1)/2 ≤ (q-1)^2`。

完成：
- SAT84 (`q=14`)；
- SAT90 (`q=15`)。

大幅压缩：
- SAT84：860,444 根门 → 7,617 直线残余 → 250 jet；
- SAT90：1,634,995 根门 → 14,287 直线残余 → 444 jet；
- 共 694 个 jet，全部精确不相容。

### 6.3 对角源切向费用
在 r=4,6,8 的对角源定义
`κ=2m-w`，
并把普通缺重 Δ 与切向 κ 一起计入同一个 G 的同一竖直分配。

新的联合约束：
`Σ_H(2Δ_r(H)+κ_r(H)) ≤ 2d_r+p_r`（r=4,6,8）。

完整竖直状态压缩到 2,035 个。
最终：
- 最大可允许分量数 = 13；
- 达到 13 的放松记录 411 条；
- 其中含正余量因子的记录 0。

于是：
- `COVER13`；
- `EDGE13`：达到 13 时全部可载点因子都 `D=2e`；若存在正余量因子，则该分支至多 12。
