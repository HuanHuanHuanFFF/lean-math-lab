# 可公开推理摘要

这份摘要不是原始隐藏思维链，而是把本会话实际用于数学推进的关键推理、路线选择和失败诊断整理成可接续形式。完整证明以各轮 `PROOFS.md` 为准。

## 总体策略演化

1. **先从已经极窄但仍无界的 `g=2,u=1` 切片寻找统一指数闭合。** 通过保留同一个原 `j` 的恢复判别式，把固定幂指数切片提升为全部奇指数纯二幂行闭合。
2. **转向两底交叉指数后，优先检查真正可以携带完整素数幂的信息。** 这产生了 `rho-3A*` 的精确完整赋值，并把 `g` 的奇部识别为酉因子。
3. **系统排除伪约束。** 实际 `Psi` 的 content、第三恢复式、`C^2` 关系、`gcd(C,u)` 分拆逐一检查后，确认哪些只是已有窗口/判别式的重写，哪些不能作为酉下降。这样避免后续把冗余等式重复计作独立约束。
4. **把交叉指数翻译为原端点的 q 进制头部位宽。** 高侧完整源块 `q^r`、端点幂 `q^b` 与原第一窗口的合法约去，产生新的整数商；这条路线逐步给出 `n>q^(b+r)`、再到 `n>q^(2b-r)`，把无限指数模板压缩并闭合 `(1,3)`。
5. **从“大小矛盾”转向“高层真实进位”。** 在临界 `(1,2)`，单纯大小界仍随 `q` 无界，于是开始直接计算原素数在 `q^(3r)` 层的 floor-carry。严格取整而非近似根成为关键。
6. **利用真实孤立 3，而不是把它误作共同见证。** `mu=3` 时，孤立 3 在 `C(n,3)` 中已被 `3!` 取消；正确用途是通过端点模 3 和 `t3` 支持计数，强迫 `xi,zeta` 都含 3，从而两底假设出现第三底矛盾。
7. **当前最有效的剩余接口是整数除数而非实根。** 对最小饱和支得到 `v | (Q^3-1)`、`P=Q+hv`、`v nu^2=PQ^2-1`、`n=c2^s`。实数恢复本身存在零进位外壳，所以继续推进必须利用 `v` 的整数除数身份、`P,Q` 为完整素数幂以及真实 `alpha`/其他源进位。

## 关键成功机制

- **完整素数幂/酉因子：** 只有来自真实窗口分配的块才能作酉分拆；`gcd(C,u)` 之类派生 gcd 不能自动升级。
- **同一个原始 `(n,j)`：** 所有恢复、进位和消费者都在原输入上完成；没有用韦达反射等把输入换成较小但非 NC 的新数对。
- **高层进位：** 通过 `floor(n/q^E)-floor(j/q^E)-floor(k/q^E)=1` 直接回传原题共同素数，是后半会话最有效的闭合工具。
- **严格正系数证书：** 对参数无界的根屏障和余式符号，统一转换为平移后全正系数多项式，避免有限扫描冒充无限证明。
- **孤立 3 的精确端点：** 只删一次 3，所有更高 `3^E` 保持完整；`mu=3` 的作用是支持/余数约束，而不是直接给原共同素数。

## 关键失败与为何失败

- **把实际 `Psi` 的二幂首项当成额外独立约束：** 实际上等价于完整源窗口，联立不会新增自由度削减。
- **把 `C^2` 恒等式当新方程：** 它是 norm 与原 `j` 判别式的代数组合。
- **把 `gcd(C,u)` 当酉因子做下降：** 交叉域里共享素数的指数会在 gcd 与余部中同时出现，非法截断完整幂。
- **仅靠实恢复/根位置强迫进位：** 存在精确实代数无界外壳满足恢复但 `q^3` 层零进位；必须引入整数除数、素数幂和真实 `alpha`。
- **仅靠位宽和端点大小：** 有显式整数弱族无进位但第一窗口/强二进条件失败，说明必须保留完整窗口。

## 会话结束时最有价值的下一步

在 `g=1, lambda=1, w=1, xi=2mu` 的临界最小支中，优先使用：

`v=zeta/(2mu) > 0`,
`P=Q+hv`,
`v nu^2 = P Q^2 - 1`,
`v(nu^2-hQ^2)=Q^3-1`,
`gcd(v,PQ)=1`,
`n=P Q nu + 2 = c 2^s`。

当前二次 `h=d^2+2d+5` 高根 `P>=4Q` 已闭合，只剩 `Q<P<4Q`；其他 `h` 也开放。最便宜判别应从 `v | Q^3-1` 的整数因子结构、`P,Q` 完整素数幂和 `n=c2^s` 的联合同余/赋值入手，而不是继续细化实根近似。
