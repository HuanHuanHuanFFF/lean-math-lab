## 0. 新结论与原输入契约

固定原始自然数 n,j，4≤j≤floor(n/2)，k=n−j。NC3 表示原来的
binom(n,3)、binom(n,j) 没有共同奇素数；p=3 包含在内。
始终使用真实 g=gcd(n,j)、α=n/g、β=j/g、γ=k/g。

采用上一轮原始输入契约：NC3⇒4|n、j<n/2，α=c2^s，c∈{1,3}；
c=3 时 v3(n)=1、3∤g。真实孤立项为

    λ=3 iff v3(n−1)=1，否则1；
    μ=3 iff v3((n−2)/2)=1，否则1；
    N=(n−1)/λ，K=(n−2)/(2μ)。

N、K 为互素奇数，与 g 互素；λμ∈{1,3}，A*=λ³μ²∈{1,9,27}。
必要完整窗口是 N|j(j−1)、K|j(j−1)(j−2)。只移除孤立一次3；高次完整3幂不截断。

真实分配 N=A_N B_N、K=LHR、C=LR，L=gcd(K,j)、H=gcd(K,j−1)、
R=gcd(K,j−2)，各窗口内的块互素并保留完整幂。定义

    t3=βγ/N=Cu，z=(j−1)(k−1)/(NH²)，
    δ=(n−2j)/(2gH)，m=gδ=(n/2−j)/H。

必要整数系统保留

    Cu g²−zH²=λ，n=2μCH+2，
    z(n−1)=λ(μ²C²−m²)，m>0。                 (BASE)

没有把这些必要条件反向写成 NC3 的充分刻画。
已完成的 SAT-ETA、实际 Ψ 三条恢复式、C²依赖关系继续保留，但不重证、不重复计数。

**本轮新定理。**

H-CAP：两底域中，把高侧素数记 q、完整端点指数记 b、源指数记 r，
另一素数记 p，其指数 a、ℓ。若 b≥2r，则实际高端商

    A=floor(n/q^b)

满足

    A > (4zg⁴/A*) q^(b−2r) ≥ (32/27) q^(b−2r)。     (HC)

故整个 b>2r 且 n<q^(b+1) 的 NC3 子域排除；更一般 A<q^h ⇒ b−2r<h。
不要求 r、p、q、g、u 或任何指数有上界。

Q-BLOCK：对任意整数 T≥3、1≤t≤A<T、1≤B<T、Y≥1、X≥T⁵，
令 n=AYX²+BX+2，若同一个合法原输入的一个端点 σ∈{j,k} 等于 tYX²，
且4|n，则该输入 Common3。该定理本身不要求两底，也不要求 X、Y 为素数幂。

交叉域合用：若

    n=Aq^b+Bq^r+2，1≤A,B<q，b≥2r，

且高侧端点的真实完整 q 指数为 b，则 NC3 只可能有

    b=2r，1≤r≤4。                                (FOUR)

## 1. 同一输入内重标两端，不交换原 j

对 a<2ℓ、b≥2r 的方向，通常 L=p^ℓ、R=q^r，
β=A_Np^a、γ=B_Nq^b。反向交叉时，只把高侧素数重新命名为 q；

    EF=N，n=λEF+1=g(Eq^b+Fp^a)，

## 2. H-CAP：高端商的完整容量限制

### 2.1 冻结正性接口的短核对

由 BASE 中 m>0、z>0，

    2zH < λμC。

因为 C 含两个不同的非单位奇素数幂，C≥15>2λ。于是

    2ug²=(2zH²+2λ)/C < λμH+2λ/C < λμH+1。

2ug² 为偶数、λμH 为奇数，所以

    λμH>2ug²。

这只是所采用 ε>0 接口的短来源核对，不单独登记为新结果。
代入范数得

    C/u > zH²/(u²g²) > 4zg²/(λμ)²。              (RATIO)

### 2.2 原 N 的两侧分配控制低端幂

令 A=floor(n/q^b)。由 σ=gE q^b<n，gE≤A。
由 EP 的同一 n 等式，

    F(λE−gp^a)=gEq^b−1=σ−1>0。

因 F>0，得到严格不等式

    p^a < λE/g ≤ λA/g²。                          (LOW)

没有把端点互换成一个新的 NC 输入，也没有删除 E、F 的实际含义。

### 2.3 联立得到新限制

令 d=b−2r≥0。由于 a≥ℓ，p^(2ℓ−a)≤p^a。由 RATIO 与 LOW，

    4zg²/(λμ)²
      < C/u = p^(2ℓ−a)/q^d
      ≤ p^a/q^d
      < λA/(g²q^d)。

故

    A > (4zg⁴/A*)q^d。                            (HC-exact)

g 偶时 zg⁴≥16。g 奇时 j、k 奇且4|n，(j−1)、(k−1) 中一项被4整除，
另一项被2整除；NH²奇，所以8|z，因而 zg⁴≥8。
A*≤27 给

    A > (32/27)q^d > q^d。                        (HC-uniform)

全部系数正，严格不等号未被改成近似估算。

### 2.4 实际删除的两个表达

若 A<q，即 n<q^(b+1)，则 d≥1 会给 A>q，矛盾。因此高侧只能 b=2r。

更一般，若 A<q^h，h≥1，则 d≥h 不可能，故

    b−2r ≤ h−1。

这不是 q、n 或 A 的全局绝对界；它是高侧多出的完整指数所需的头部位数约束。
对同一个原输入，触发被排谓词并反设 NC3 即矛盾，故原两二项式有共同 p≥3。

## 3. Q-BLOCK：一个不要求素数底的整数定理

设整数

    T≥3，1≤t≤A<T，1≤B<T，X≥T⁵，Y≥1，
    n=AYX²+BX+2，σ=tYX²。

假设 σ 是原合法输入 j 或 k，且4|n。只需证明

    N 不整除 σ(σ−1)，N=(n−1)/λ，λ为真实孤立3值。   (FAIL-W1)

事实上下面的纯整数论证允许任意 λ∈{1,3} 且 λ|(n−1)；
返回原题时必须采用真实 λ。

定义不与原输入块混名的新多项式

    F1=AYX²+BX+1=n−1，V=BX+1，
    D0=YA(A+2t)−tB²，
    E1=t[D0 V−AtY]，R2=tV(tV+A)。                (NEW)

Y 任意增长；不能在证明中把 Y 固定或吸入一个有界常数。

## 4. 第一窗口的二次主项消去

下列为整数多项式恒等式：

    A²σ(σ−1)
      =F1[t²F1−2t²V−At]+R2，

    AY R2−t²B²F1=E1。                            (REM)

因而在反设 N|σ(σ−1) 下，N|R2，继而 N|E1。
没有模意义下除以 A、t 或 Y；它们即便与 N 不互素，论证仍成立。

合并后的完整证书是

    A³Yσ(σ−1)=F1 Q+E1，
    Q=AY(t²F1−2t²V−At)+t²B²。                   (BEZOUT)

E1 对 X 只有一次，而 F1 对 X 二次。这是本轮消去，不是旧 C² 恒等式的重复添加。

## 5. 必须先排的零余式支：E1≠0

假设 E1=0，则 D0 V=AtY>0；D0 为正整数，所以 D0≥1。
由 NEW 可精确消去 Y：

    t²B²=D0[(A+2t)V−t]。                        (ZERO)

右边严格大于 (A+2t)BX。因此

    X < t²B/(A+2t) ≤ AB/3 < T²/3。

中间不等式由

    A(A+2t)−3t²=(A−t)(A+3t)≥0

得到。与 X≥T⁵ 矛盾。所以对任意 Y≥1，E1≠0。

这一证明覆盖 Y=1（关键 b=2r 边界）、任意大 Y、t=A、A=1、B=1。
不使用有限特化或浮点根；也没有遗留“余式恰好为0”的无界支。

## 6. 非零余式小于 N：统一大小闭环

因为 T≥3、A≤T−1，

    A+2t≤3A≤3(T−1)<T²。

故 YA(A+2t)<YAT²，且 tB²≤AB²<YAT²；两数均正，得到

    |D0|<YAT²。

又 V=BX+1<TX。因此

    |E1|≤t(|D0|V+AtY)
         <A²Y T³X+A³Y
         =A²Y(T³X+A)。                          (SIZE1)

下面的严格差对整个区间成立：

    X²−3AT³X−3A²>0。                            (SIZE2)

理由是

    X−3AT³ ≥ T⁵−3(T−1)T³
             =T³(T²−3T+3) ≥3T³，

而 3T³X>3A²。这里

    T²−3T+3=(T−3)²+3(T−3)+3≥3。

由 λ≤3、SIZE1、SIZE2，

    λ|E1| <3A²Y(T³X+A)<AYX²<F1=λN。

于是 0<|E1|<N，与 N|E1 矛盾。FAIL-W1 得证。
没有新的有限底部：本定理只断言 X≥T⁵；X<T⁵ 不被声称已经处理。

## 7. 回到同一个原始二项式与 p=3

N 为奇数，并且 N|j(j−1) 与 N|k(k−1) 等价，因为 n≡1 mod N。
FAIL-W1 因而直接使原第一窗口失败。
选取 N 中一个完整 p^E，使 p^E 不整除 j(j−1)。相邻两数互素，所以

    j mod p^E 不属于 {0,1}，而 n mod p^E=1。

阶乘估值的第 E 层贡献1，故 p|binom(n,j)。
p≥5 时，p^E∥n−1 给 p|binom(n,3)。
p=3 时，真实 λ 已移除且仅移除孤立一次3；若3仍在 N 中，E≥2，
所以 v3(binom(n,3))=E−1≥1。源层始终使用整个3^E。

因此选出的同一个 p≥3 同时整除两个原二项式。
σ=k 时只是利用 k=n−j 的同一输入对称性，没有更换题目的 n,j。

## 8. 联回完整交叉系统：低宽度高侧的绝对指数模板

在 §1 的真实高侧，令 q^b 是端点 σ 的完整 q 幂，q^r 是 K 中的完整 q 幂，b≥2r。
按 n 除以 q^b，唯一地写

    n=Aq^b+Bq^r+2。

这里 A=floor(n/q^b)≥1；B 为正整数：n≡2 mod q^r，若余部中的 B=0，
就会使 vq(n−2)≥b>r，违背真实源指数。q∤B。

若 1≤A,B<q^h 且 r≥5h，置

    T=q^h，X=q^r，Y=q^(b−2r)，t=σ/q^b。

由于 σ<n，t≤A。X≥T⁵；其余条件均满足 Q-BLOCK。
因此整个该域排除，得到必要限制

    r≤5h−1。                                    (WIDTH-r)

与 H-CAP 合用，还必须

    b−2r≤h−1。                                 (WIDTH-b)

特别 h=1 时，只剩

    (r,b)=(1,2),(2,4),(3,6),(4,8)。               (FOUR)

q=3 时仍必须保留 r≥2 的源资格；本定理不把孤立3升级成合格源。
旧端部≥11还可能排除某些小 q，但本轮不使用、不重做该旧闭合。

FOUR 不是完整交叉域的四个实例：它带 A,B<q 的准确前提，q、A、B、低侧 p、a、ℓ
及 g 等仍可能共同增长。一般头部/余部系数不受此绝对指数模板控制。
