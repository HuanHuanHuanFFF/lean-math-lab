# 可重放证据的范围

生成器generate.py用SymPy在QQ多项式环内生成14个等式和5个正系数证书。
第二检查器check.py不导入SymPy或生成器，自己用标准库Fraction及字典单项式展开固定的证明侧表达式。
它既核对左右相等，也核对证书等于固定公式，拒绝把两边都改成0的伪证书。

证书中的Q是原高側完整源块q^r；只有q_ge_five_gap附属消费者证书中的X对应基底q=5+X。
R变量对应证明中的R_*，不是原K右端块。v对应ν，x在second_window_recovery中对应ξ。
所有被检验的不等式先按证明规定移成非负变量上的正系数多项式；正性域由纸面证明负责。

14项：新商模整除的恒等式、原端点分配、ν的实际公式、h=3的3因子、原n恢复、
第二窗口恢复、h=5线性关系、头部整数差、8/9门槛、正R_*、差量两次变量变换、
EP-SMALL的q≥5间隙、模板头部上界。

5份正性证书的常数项分别为1、7、1、621、1。
18种损坏输入由corruption_tests.py从固定证书确定性构造；精确变更、拒绝原因和变更后字节哈希
保存于corruption_result.json，不涉及任何原数对扫描。

复放首先核对冻结版，再独立生成新版并核对，要求两份证书字节完全相同，最后执行损坏拒绝。
它不证明NC入口、整除取消的语义、整数/奇偶推理的全体形式化或全部无限定理；这些在PROOFS中逐步给出。
因此“PASS”仅代表本文件说明的代数/完整性范围，不提高为外部审稿或Lean。
