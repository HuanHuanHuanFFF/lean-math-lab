# B699 Pro D · 2026-09-18 · 平方类强制触发

入口：`REPORT.md`。完整新证明：`PROOFS.md`。

本包将 i5/H02⁺ 的整个平方/五倍平方规范残量分支，统一归入旧已闭的低底消费者；安全转移到旧D6/H025的1280、1530两尾类，不限v5(n−5)。进一步分类 W=(n−1)jk 的八个235平方类，只余 D=10、n≡18 mod72、α=3^a。

本轮没有闭合完整尾类/指标，没有原题反例，没有Lean/外部独立审读，也没有仓库修改。

## 文件

- `REPORT.md`：覆盖范围、未完成部分、证据状态。
- `PROOFS.md`：完整新推导、零分支、跨指标与原题返回。
- `SOURCE_ADOPTION.md`、`sources/`：旧合同的精确采用与只读来源。
- `FAILURES.md`：仅大小模型、精度损失、RES10边界。
- `HANDOFF.md`：下一轮的两个低成本判别点。
- `proofs/JOINT_U.md`：同一原输入的辅助必要联立，不单独计覆盖。
- `code/`、`certificates/`：标准库确定性复算与实例见证。
- `SHA256SUMS`：包内普通文件校验。

## 重放

需要 Python 3.10 或更新版本，仅标准库。在本目录运行：

    python code/verify.py
    python code/consumer.py 1556730 518322 --i 6 --witness 353

`verify.py`重建本轮证书并逐字节比较，不访问网络、不扫描无界n或指数、不复跑历史链。
`consumer.py`只检查所给原输入是否落在本轮充分消费者内。`applies=false`从来不代表原题反例。

历史合同没有重新打包成旧原件副本；其固定来源、读取范围及作者证据等级在SOURCE_ADOPTION中逐项登记。完整新证明在这些明示前置下成立。
