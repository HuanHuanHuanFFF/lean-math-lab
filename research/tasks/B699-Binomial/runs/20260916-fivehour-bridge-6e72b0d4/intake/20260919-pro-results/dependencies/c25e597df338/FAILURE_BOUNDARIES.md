# 失败边界、拒绝范围与未完成事项

## SAT48没有发现不可约反例

全部5663根列系统均已分类：5544不相容、119唯一可约乘积、0残族。没有为维护路线忽略已发现不可约对象。这个结论只属于D16/e8/z≥14/普通μ48，不属于μ47或九次。

## 哪些推理仍不合法

1. 特化根重数不是一般普通(N,X)重数。此处只在六行容量全部饱和后证明相等。完整Z不能选子集；纯X条件之外的全部普通jet不能省略。
2. 模无解本身不推出Q无解。发现中的模消元仅选子式；最终5544个排除使用非零37阶整数增广行列式，所有119相容解用非零36阶系数行列式与全部方程检查。
3. H0+W B10是完整等价参数化；119产品必须与完整解集相等。只列119个可约样本不能证明SAT48。
4. 竖直因子不能省略，不能让每个分量各自领取整个X余量预算。所有预算使用同一个G、同一个实际V/h/六行分配；正余量类支付a。
5. H|G不是需要假装不存在的公共因子；它本来就是因子研究。本文不对H、G使用非零结式。原K152的两个点值分支仍按旧完整幂链采用，不能把形式非零当合法点值非零。
6. 几何/必要预算点不是NC9。119产品、21分量上界、41放松记录均不是有限原题候选。必要窗口不反推NC9。

## 实际有限范围错误及纠正

acceptance-01完整通过几何重放后，在额外SAT54/K20收益诊断中触发“DP range does not cover a possible configuration”。因为K20的最坏V为305−7·20=165，初始表仅到160。

该执行没有PASS，不是OOM、SAT48失败或不可约边界。最终表明确覆盖V0..165、h60..152，完整重放后acceptance-02通过。日志未覆盖；code_versions记录版本哈希，旧版与新版本质差异是vmax160→165。最终发布版只再增加了EDGE21的a=0显式断言。

输出目录必须不存在；这是为避免旧成功文件残留伪装新通过而设置的保护。`--probe-limit`只输出PROBE_ONLY，不能作为全域接收。

## 为什么本轮不写无条件20

K21在新必要账本中仍有41条放松可行记录；全a=0，但这不意味着每个真实G都存在这些因子。例：14个D12型＋7个D18型、V1、h152、Γ需求和容量均14。

SAT54若成立会排21项，但本轮没有执行九次根列或49参数系统。不能将“成功后计账可行”冒充SAT54定理，也不能把SAT48向任意次数归纳。

本轮没有新增单独低高度原题消费者、一般绝对高度、G恢复、反例、Lean或外部独立全篇审稿。所有采用的旧作者证明仍保留相应核验缺口。
