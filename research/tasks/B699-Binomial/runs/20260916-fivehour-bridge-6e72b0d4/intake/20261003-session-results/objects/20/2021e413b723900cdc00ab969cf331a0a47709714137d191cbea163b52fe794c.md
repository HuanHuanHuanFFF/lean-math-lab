```sh

```

## 可直接用的检查入口

```sh
python -B code/consume.py --u 1/4 --y=-1/2 --r 1
python -B code/consume.py --u 2 --y 2 --r 1 --full
```

新过滤器只给规范必要域的排除/未定，不会宣称 NC3。`--full` 对新过滤器未排的输入调用冻结恢复器，继续检查全部原门、六式、未平方 Q 的两符号和规范恢复。原 affine_audit.py、original_pair_audit.py 也随包保留；没有用虚构原输入调用它们宣称新反例。

可选发现再生需要 SymPy，且输出必须是包外新目录：

```sh
python -B code/generate.py --output /path/to/new-output
```
