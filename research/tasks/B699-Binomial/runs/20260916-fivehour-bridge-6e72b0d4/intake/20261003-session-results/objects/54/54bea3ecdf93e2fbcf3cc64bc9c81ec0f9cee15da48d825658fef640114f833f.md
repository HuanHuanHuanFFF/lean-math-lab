## 干净重放

将本包解压到一个新目录，在包根目录运行：

```bash
python -B replay.py
```

只需要 Python 3.9+ 标准库，无网络、SymPy、Lean、仓库、先前聊天或外部下载依赖。
`replay.py` 校验 `SHA256SUMS`，然后以隔离 Python 运行新精确证明检查器与消费器保护回归。
重放不改动交付文件；可用 `--receipt /新的路径/receipt.json` 另存结果。
`receipts/CLEAN_REPLAY.json` 是组包时在第一次干净解压目录产生的回执，覆盖 `PAYLOAD_SHA256SUMS` 的载荷；
最终 `SHA256SUMS` 同时绑定这份回执。最终 ZIP 又在第二个全新目录重放，外置最终回执绑定最终 ZIP 的 SHA-256。
不使用自引用哈希：任何清单都不哈希自身；内置回执也不声称哈希了自己。

## 代码与证书

`code/verify.py`：独立于生成器的 Python 标准库整数稀疏运算和 Bareiss 行列式。精确验证所有新身份和终端。
`code/build_certificates.py`：SymPy 生成器，重新生成新证书；不是常规重放所需。会重写本包 certificates，需在另一个副本中运行。
`code/recover.py`：有理一般基点消费器，完整检查六多项式、门及未平方恢复；绝不把辅助存活标为 NC3。
`code/original_pair_audit.py`：仅审计用户另给的同一合法(n,j)与来源幂，不补造原输入，不把部分来源通过当NC3。
`code/test_consumers.py`：有限防误用回归，不是无限族证明。

例子：

```bash
python -B code/recover.py --u 271 --y 404 --r 1/269
```

输出是已证同余域的拒绝，不宣称269是原题共同素数。

五份新证书位于 `certificates/`。完整 P5,G4…G0 的系数定义一般消元式 E 的16×16行列式，
E 未展开成单个庞大系数表，但它是完整明确的整数多项式电路，不依赖未保存计算。

## 不成立的结论

“维数≤1”不等于零维、全域有限、整数点有限或全空。固定(u,y)至多5个r也不等于(u,y)有限。
原始尺度/仿射坐标/数字系数/底素数/完整指数/n,j仍未一般有界。历史原题消费者净差0/未认证；完整指标新增0。
