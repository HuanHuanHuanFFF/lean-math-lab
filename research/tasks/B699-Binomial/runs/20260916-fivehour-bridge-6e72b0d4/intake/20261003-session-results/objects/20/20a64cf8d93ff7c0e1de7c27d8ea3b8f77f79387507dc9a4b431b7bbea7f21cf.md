# Discovery provenance only

这些是本轮冻结候选前后的发现脚本与原始诊断数据，不是最终重放入口。它们含当前容器工作路径，部分需要SymPy/未分发大型中间文件；移机无须运行它们。所有真正采用系数都包含在inputs并由标准库code/verify.py从头核验。

原始主核阶段计数235/922后，实际源2返回又排87类×标签；最终233/835以生成证书为准。PROVISIONAL_SOURCE2_DISCOVERY较松使用三个源值的乘积，最终正确且更紧的完整幂界使用三个值粗部的LCM。两者不是两条独立方程。PERIOD_RETURN_DISCOVERY是生成最终SOURCE2_RETURN前的记录，最终验证不信任它。

没有把发现程序的有限样本、浮点近似或LLL结果直接当作证明；最终对完整核、内容、结式及费用进行精确验证。
