## 重放

在任何干净目录解压，使用 Python 3.10 或更新版本：

    python -B replay.py

默认只用标准库，无联网、Lean、Git命令或旧工作目录；不会生成新的数学断言。
重新生成证书（可选，需要SymPy）：

    python code/build_certificates.py

给一个有理三参数，做完整有限尺度消费：

    python code/recover.py --u=-3 --y=1/2 --r=3
    python code/recover.py --u=-3 --y=1/2 --r=3 --original-leading
