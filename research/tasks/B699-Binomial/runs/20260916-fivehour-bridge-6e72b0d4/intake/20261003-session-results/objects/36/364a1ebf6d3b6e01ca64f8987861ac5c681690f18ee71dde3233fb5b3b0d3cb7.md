# PROOFS — REG3-DIM0 / AFFINE-ROOT20 / POSITIVE-MU

日期：2026-10-02。本页 R4。作者纸面论证与确定性精确算术证书；没有 Lean、外部独立数学审读或原题全闭合。

## 0. 定理的对象、范围和冻结输入

本轮只接续 R3 的一般唯一尺度图。不重证 R2 的 S=K_lin=0 例外排除，不重证 R3 的半切片或269进圆柱。

原命题仍是：同一合法自然数 (n,j)，4≤j≤floor(n/2)，要求同一个素数 p≥3 同除 C(n,3)、C(n,j)。p=3 不删。原来源窗口必须保留实际完整素数幂，不能以本轮的辅助有限域素数代替原见证。

冻结 R3 给出整数多项式 P5,G4,G3,G2,G1,G0∈Z[u,y,r]，完整系数在 inputs/generic.json。旧称 B5 的字段就是 P5，不是新多项式。文件的4元指数最后一位恒为0。采用其与完整一般有理残差图在所有明列门内的等价关系；这个等价不是 NC3 的充分参数化。

记 K=K_lin，N=(u−1)Tcal，

    Hcal=u²−uy²+3uy−2u+(y−1)²,
    Jcal=u²+uy²−3uy+y,
    Tcal=4uy² Hcal r−3(u−1)(y−1)² Jcal,
    D=8ru²y²−6(u−1)²(y−1)²,
    λ=N/K.

λ、r以及图坐标α=rλ均不是 n/g。K也不是原恢复的K0。辅助Q_poly不是另一条恰两底路线的完整素数幂Q。

令 Ω⊂C³ 为 u(u−1)y(y−1)rDNK≠0 的开集，定义

    X=V(P5,G4,G3,G2)∩Ω.

完整六式加 Wgate、T4、S 等全部原门后的规范点集是 X 的子集。本轮在较大的 X 上证明：

**定理 R4-DIM0：X 是有限集，可能为空。其不同复点数至多44,415。**

因而完整有理一般 REG4 恢复只剩有限个规范 (u,y,r)，相应 λ、w 也只能取有限多个值。没有计算实际点数、列出点、证明有理点存在或证明全空；没有把原仿射尺度、工作底T或(n,j)有限化。旧R14有理归约不能扩写成“旧全部复REG4已等价归约”。本轮复数结论的对象只限上述明确的多项式开集。

## 1. 新的三个完整特征零投影身份

定义固定 Sylvester 行列式 E_i=DetSylv_r(P5,G_i)，i=4,3,2。固定行序是11个P5降幂系数平移行，接5个Gi降幂系数平移行；矩阵16×16。这里不在参数特化时删除首项零行，因此保留所有次数跌落。

另置

    A5=8u³y−5(u−1)²(y−1)³,
    J=Jcal.

B9是下节 Res_r(K,N) 中双次数(9,10)的88项本原因子，其全部整数系数载于 certificates/branch_factors.json 的 KN 组。本轮没有仅以一个未展开的“结式对象”代替它。

精确身份为

    E4=C0 u^44 y^20 (u−1)^28 (y−1)^4 J A5 B9^8 U4,
    E3=C0 u^44 y^20 (u−1)^28 (y−1)^4 J A5 B9^8 U3,
    E2=C0 u^35 y^20 (u−1)^28 (y−1)^4 J A5 B9^8 U2,

其中 C0=757285924434069159936，三个 Ui 为完整整数多项式。

|对象|项数|deg_u|deg_y|
|---|---:|---:|---:|
|U4|2271|59|39|
|U3|2654|64|43|
|U2|3073|68|48|

不能从三个结式说“每个共同点都在 J A5 B9=0”：Ui仍可能有孤立公共零点。本轮只先判断共同曲线。

### 1.1 Ui 没有公共曲线因子

U4看作Q[y][u]多项式，对u的系数（实际使用下标0至14）在Q[y]中的gcd精确为1，因此U4无纯y因子。

在 y=2、模32003下，U4/U3/U2 的u次数分别59/64/68，U4首项1545≠0，三者一元gcd为1。若它们在Q[u,y]有正u次数公共因子，以Gauss引理取本原整数因子；U4的首项在该特化非零，迫使各因子保持其u次数。于是会给模32003的非恒定公共因子，矛盾。纯y因子已由内容gcd排除。

因此 gcd(U4,U3,U2)=1。扩至C同样没有公共曲线：任一公共绝对因子的全部有理共轭乘积会给Q上的公共因子。

**所以 X 中任一投影为曲线的分量，其投影闭包只能在 J=0、A5=0 或 B9=0 上。**

## 2. 三个投影因子不可约及函数域证书的合法使用

三个因子均在Q[y][u]本原，程序逐个精确核对内容gcd=1。在y=2处作如下保次数特化：

|因子|素数|u次数|模素数不可约性|
|---|---:|---:|---|
|J|7|2|Rabin测试|
|A5|7|3|Rabin测试|
|B9|11|9|Rabin测试|

均实际核对 x^(p^d)=x mod q 和每个素因数ell|d对应的 gcd(q,x^(p^(d/ell))−x)=1，不依赖只保存CAS的布尔“irreducible”。本原性和首项保次数说明三个因子在Q[u,y]不可约。

**函数域秩提升引理。** 设B是上述本原不可约因子。整数多项式矩阵的某个子式在 F_p[u]/(B(u,2)) 非零，则该子式在 Q(u,y)/(B) 中非零。因为如果子式属于Q[u,y]中的(B)，Gauss引理使B整除该整数子式；约化必为零。故有限域秩下界给函数域秩下界，进而给正确实际次数下的多项式gcd次数上界。

这不是“有限域没有若干点，所以特征零没有点”。本轮需要且只使用该秩引理，并逐分支核对真正的次数。也不把单一模数中的点数当作特征零点数。

## 3. J 分支：共同根只能是被禁的 r=0

精确常数项身份：

    [r^0]P5=−9(u−1)^4(y−1)^3 J F0,
    F0=2u²y²−6u²y+5u²+2uy−4u+1.

另有完整整数商证明 J|[r^0]G4。因此在函数域Q(J)中，r同时整除P5、G4。

在F_(7²)的上述保次数特化中，P5/G4实际次数5/11，精确gcd就是r。秩引理给一般gcd次数≤1，已知r因子给下界，故函数域gcd恰为r。

所以任何投影稠密于J曲线的共同分量都必有r=0，违反Ω。只排除了该支的**一般曲线**；特殊有限基点不在此处逐一删除，留给最终有限点集。

## 4. A5 分支：正确降次后互素

精确首项身份为

    [r^5]P5=144u^4(u−1)²y^4(y−1) A5.

G4的r^11首项也被A5整除，完整整数商保存在branch_quotients.json。进入A5函数域后，实际次数降为4和10。其下一首项在F_(7³)特化非零；正确4/10次多项式的gcd=1。

因此它们在函数域上互素。这个分支不能继续用5/11固定结式的零来推断存在有限根；旧投影中的A5因子正包含该降次效应。本轮明确处理后，A5不能承载Ω中的共同曲线。

## 5. B9 分支：共同根只能满足 N=0

完整小结式身份为

    DetSylv_r(K,N)=−48u²y²(u−1)^4 H2 B9,

    H2=1−2y+y²−3u+6uy−2uy²+3u²−6u²y+2u²y².

由于N关于r为一次，程序用无除法身份 −N1³ K(−N0/N1) 重建整个4×4结式，而非仅作有限域探针。

在B9函数域中，N1非零，故上述恒等式强迫N|K。在F_(11^9)保次数特化中还精确核对gcd(N,D)=1，所以在该函数域中也gcd(N,D)=1。

采用R3已经逐系数核验的运输身份：

    aN²+bNK+cK²=(u−1)²(D/2)²P5,
    homogenize(Q4;N,K)=(u−1)²(D/2)^4G4,

其中后一个齐次式关于N,K为四次。N|K使左边分别被N²、N^4整除；N与D互素且u−1非零，因此

    N²|P5,   N^4|G4     in Q(B9)[r].

另一方面，F_(11^9)中特化的P5/G4次数5/11，gcd恰为首一N²。秩引理给一般gcd次数≤2，结合上述整除，函数域gcd恰为N²。

所以该曲线的一般共同根只能满足N=0，违反Ω。这里没有除去一个未经处理的N=0域来冒充完整REG4结论：N≠0本来就是R3一般尺度λ=N/K≠0及其原门的一部分。

## 6. 没有竖直 r 直线；所有次数跌落同时覆盖

投影到一个固定(u,y)的正维代数子集只能使P5关于r恒零。因Ω保留u(u−1)y(y−1)≠0，P5最高项和常数项分别迫使

    A5=0,  J F0=0.

再取p1=[r^1]P5。全部系数同时为零还要求p1=0。本轮精确构造并核验四个一元结式：

    fJ=Res_u(A5,J),    gJ=Res_u(J,p1),
    fF=Res_u(A5,F0),   gF=Res_u(F0,p1).

它们在Q[y]中满足gcd(fJ,gJ)=gcd(fF,gF)=1，使用有理数Euclid算法精确验证。每个结式另有足够次数界下的完整整数Sylvester行列式核验，分别13、35、13、35个值；不是只核对结式摘要。

因此J=0和F0=0两个可能都不容许A5=p1=0，连复数基点也不存在。结论：对每个允许的复(u,y)，P5都不是关于r的零多项式，因而该纤维至多5个r。

这里的每纤维界只是中间引理。它与完整三投影/曲线排除合用，才得到下面的全规范集有限性。

## 7. R4-DIM0 与44,415上界

P5/G4的投影落在非零平面多项式E4上，且§6排除正维纤维，故V(P5,G4)∩Ω至多一维。

若X还有曲线，§6使它的投影也是曲线；§1将投影限到J、A5、B9。§§3—5分别排掉这三种稠密投影曲线，矛盾。因此X无正维分量，是有限型的零维可构造集，故为有限点集，可能为空。

对数量：V(P5,G4)∩Ω只有有限多个曲线分量。对每个分量，G3/G2不可能同时恒零，否则它就是X中的曲线。因此除有限多个常数t外，G3+tG2在每个允许曲线上都非恒零。取一个这样的有理t，所有X点都是

    P5=G4=G3+tG2=0

的孤立复零点。总次数精确为degP5=21、degG4=45，deg(G3+tG2)≤47。采用标准孤立点Bézout不等式，得到

    #X ≤21·45·47=44,415.

这个t是用于数量界的存在性论证，本轮未给出一个具体t，也不据此声称已经枚举出44,415条候选记录。纯粹的DIM0证明不依赖该计数定理；数值上界单独采用标准Bézout孤立点版。公开核对来源：Jan Verschelde, Lecture 1: Introduction, “The Theorem of Bézout”, https://homepages.math.uic.edu/~jan/mcs563/mcs563notes/lec01.html ，2026-10-02读取，说明n个方程的孤立复解数至多次数乘积。没有采用网页中的数值求根算法。

## 8. 原仿射平移的有限选择，仍有无界尺度

对通过完整六式、原门和未平方Q恢复的有理规范点，设恢复出的规范f_*为20次。原仿射恢复写成

    f_original(X)=f_*(aX+b),  a∈Q\{0}, b∈Q.

原f_original(0)=2强迫f_*(b)=2。非恒定20次多项式故至多20个复b，因而至多20个有理b。结合§7，允许规范点与平移b的不同选择至多888,300；仍不是实际列表，也不是原(n,j)数。

原非负整数条件进一步要求每个k的

    a^k f_*^(k)(b)/k! ∈ Z_{≥0},

并对原J保留相同仿射变换和逐位0≤J_k≤f_k。若a>0，则全部导数符号须非负；若a<0，则全部(−1)^k导数须非负。这是精确接回接口，不是本轮对所有有限点完成的检查。

**仍无统一界的是原仿射斜率a、工作奇素数幂T、原系数大小及实际(n,j)、原源素数/指数等。** 规范(u,y,r,λ,w)和平移b已得到有限选择结论，不再称作仍存在无界规范曲线；但没有显式坐标或有效数值高度。

## 9. 可附加的正μ实CUBIC障碍

本节独立于DIM0，且只用于原正首项/未平方Q给出的μ>0有理分支。保持原混合规范

    M=μx(x−1), L(0)=0,L(1)=−4,
    M Q_poly²=L³+4L²−5ML+M².

取

    c_*=(1−5√13)/9∈(−4,0),
    m_*=(−70+26√13)/27>0.

精确Q(√13)身份为

    c_*³+4c_*²+5m_*c_*+m_*²=0,
    2m_*+5c_*=(−125−23√13)/27<0,
    27m_*²+140m_*−144=0.

L连续，所以在某个x0∈(0,1)有L(x0)=c_*。此时m=−M(x0)∈(0,μ/4]。若μ/4<m_*，函数c_*³+4c_*²+5mc_*+m²在[0,m_*)严格为正，而左边M Q_poly²≤0，矛盾。因此μ≥4m_*。μ有理而4m_*无理，等号不可能，得到

    μ>(−280+104√13)/27,
    27μ²+560μ−2304>0.

R3恢复t=3u^4(u−1)^4T4/K²，a0=36u^4(u−1)^4rN²/K²，故

    μ=4t/a0=T4/(3rN²).

因此原正支还必须

    9T4²+560rN²T4−6912r²N^4>0.

这不作用于一般复模型，不代替3T4∈Q_{>0}²和r>0，更不是原源P/Q幂已恢复。该条件关闭了明确的μ小正区间，但未认证其相对所有历史原题消费者的非空差集。

## 10. 完整整数核验而不是模扫描

三个大投影身份的分别次数上界依次为(220,158)、(225,163)、(220,168)。对每个身份，验证器在18个不同实际素数、完整二维网格上比较固定Sylvester行列式与完整因式右端，网格从u=3、y=5开始，区别于生成器使用的0起点网格。

生成器：模Gaussian行列式、二维Newton插值、CRT恢复整数系数。
检查器：不插值；C++17模Bareiss行列式，逐格比较因式右端。以Python任意精度整数算严格系数上界和素性。两者是同作者不同实现，不是外部独立审读。

每个差多项式的整数系数绝对值上界为

    16! ||P5||_1^11 ||Gi||_1^5
    + |C0|2^(e_(u−1)+e_(y−1))||J||_1||A5||_1||B9||_1^8||Ui||_1.

18素数乘积为539位，三个差界分别534、532、533位。模素数的完整次数网格保证每个系数均被该素数整除；互素乘积大于差界，故所有整数差系数为0。这是完整特征零恒等式证明。

共核验1,971,936个16×16行列式，以及96个小结式整数行列式、不可约性/Frobenius、精确gcd、运输商、函数域必要阶等。这些数量是算术检查工作量，不是原题实例数或规范存活数。

纸面部分仍包括函数域秩引理、投影与维数逻辑、Bézout应用和连续性障碍。程序检查它们的明确代数前提，不等于把整篇证明放进形式化内核。
