# B699 D-R08：固定原底的完整两块终端

先读REPORT；完整量词、证明和边界在PROOFS与FAILURE_BOUNDARIES；下一轮使用专属HANDOFF。

独立离线重放（Python 3.10+，标准库，无网络）：

    python -I -B replay.py --output ../R08-replay.json

输出必须在包外。replay先核所有成员/父递归SHA，再在临时目录重新生成新证书和第二接收器回执，逐字节比对。
它不执行父/祖先研究程序；logs/PARENT_R07_REPLAY.json是作者本轮另行实际执行父R07自身程序的记录。祖先q=6未执行。

数学范围是指定原同源平衡核心，不是完整i3。新的A整类排除0，历史净差0/未认证；完整piP终端可判不等于全入口排空。弱模型、完整幂算术模型、模逆表都不是NC3实例。

MEMBERS.json保留每个本轮文件的来源/大小/SHA与递归父成员；SHA256SUMS覆盖MEMBERS和所有其他成员（除自身）。最终ZIP的外部SHA绑定整个归档；CLEAN回执的payload哈希排除自引用文件，具体规则见清单。
