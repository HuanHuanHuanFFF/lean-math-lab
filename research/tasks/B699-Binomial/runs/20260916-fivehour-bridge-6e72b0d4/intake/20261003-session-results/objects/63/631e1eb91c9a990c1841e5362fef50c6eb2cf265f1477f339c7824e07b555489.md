## 重放

```
python scripts/replay.py
```

需要Python≥3.10和C++17编译器(g++/clang++/c++)；也可设置CXX为编译器可执行文件路径。无需联网、Lean、仓库、SymPy或外部Python包。C++源码在scripts/kernel_check.cpp；编译产物只存临时目录。计算为有界整数循环和有理证书，不运行长期后台任务。

`kernel_expected.json` 给完整有限核期望输出；`parameters.json` 给所有参数；`expected_results.json` 给新证书的精确输出；`prime_example.json` 为实际大素数的递归Lucas证书。

`sources/` 是按原字节保存的冻结依赖及方法出处。R2数学结果按纸面等级采用，§9终端按项目登记采用。本轮没有重验旧Lean链。

## 哈希与回执结构

PAYLOAD_SHA256SUMS.txt列全部数学/来源/日志payload成员，不包含自身、最终SHA256SUMS或CLEAN_REPLAY_RECEIPT。
CLEAN_REPLAY_RECEIPT绑定这个payload的独立临时ZIP及干净重放。
SHA256SUMS.txt再列包内除自身以外全部成员，包括payload清单和回执。
最终ZIP的SHA-256与第二次干净解压重放回执在包外提供，避免自指哈希。

这些回执仅认证字节和列明精确计算，不是外部独立数学审读或Lean验收。
