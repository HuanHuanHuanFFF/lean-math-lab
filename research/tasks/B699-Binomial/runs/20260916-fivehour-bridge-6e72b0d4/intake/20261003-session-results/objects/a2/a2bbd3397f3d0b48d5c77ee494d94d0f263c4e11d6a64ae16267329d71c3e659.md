# Experiments / failure log

Successful research is fully reproducible through `code/build_certificates.py` and the independent stdlib `code/verify.py`.
Intermediate exploratory Python scripts have been superseded by this portable generator; their execution logs are retained under logs.
The following optional diagnostics are not part of mathematical acceptance or the default replay:

1. `project_r.py`: attempts to fully expand the general projection E. The executed attempt was stopped without a certified full output;
   see `logs/general_projection_stop.json`. It is not needed: all fixed matrix coefficients and a nonzero exact specialization are certified.
2. `gb_probe.cpp` / `gb_probe_extended.cpp`: modular localizing Buchberger probes over F_32003. Inputs are copied verbatim as
   `gb_input.txt` / `gb_input_extended.txt`. Output was nonterminal budget stop; no unit certificate and no characteristic-zero conclusion.
   The programs take an existing output directory as argv[1] and input on stdin. Do not run without a resource guard.
   Their heuristic factor stripping and modular computations are not used by the proof verifier.

Example optional invocation on a new scratch directory (requires g++, not required for proof replay):

```bash
mkdir /tmp/reg3-probe
# Compile into the scratch directory, never into a repository.
g++ -O2 -std=c++17 experiments/gb_probe.cpp -o /tmp/reg3-probe/probe
/tmp/reg3-probe/probe /tmp/reg3-probe < experiments/gb_input.txt
```

Other retained logs cover the long original-scale factorization, Möbius substitution, and direct QQ reductions.
