# Discovery / experiments

默认replay不需要本目录。paramH.py、H_terminal.py、assemble_certs.py保存本轮发现逻辑；Hresult.sing生成完整有理/整数结式。regenerate.py提供可移植入口，解压固定R6输入到外部工作目录，并使用标准库新检查器验证生成结果：

```
python discovery/regenerate.py --work-dir /path/to/new-work --singular /path/to/Singular
```

需要SymPy与Singular。原发现脚本中的/mnt/data/r7_work由包装器替换。源码构建脚本、satproof.cc和Ncoord_ff.sing只是试算记录，不能据运行退出码认定数学接受，详见FAILURE_BOUNDARIES。第三方Singular源码/二进制不随研究包分发。

N坐标的有限域探针没有完成全局终端。Hbezout.sing未完成完整余因子QQ乘子；它不在采用证明链中。真正采用的是certificates下的完整数据与code/verify.py检查结果。
