## 1. J=0 的完整参数化，不选平方根分支

设 d=u−1、n0=2uy−3u+1，定义 v=n0/d。d≠0。精确恒等式：

```
n0²−(1−4u)d² = 4u J,
2(n0−d)d*y−(n0+d)² = −4J.
```

故 J=0 时 v²=1−4u，且 2(v−1)y=(v+1)²。u≠0 推出 v≠±1；u≠1 推出 v²+3≠0。因此

```
u=(1−v²)/4,
y=(v+1)²/[2(v−1)],
(v−1)(v+1)(v²+3)≠0.
```

反向代回 J 恒零。每个允许实（或有理）基点给唯一相同域内的 v；并未任意取平方根而丢掉另一支。coverage.json 的两个整式身份及完整正向恒等式由检查器核验。

## 2. A5=0 的完整参数化，包含奇异/零系数情形

定义 z=(y−1)/(2u)≠0。A5=0 化为

```
y=5z³(u−1)²,    y=1+2uz.
```

令 w=5z²(u−1)−1，则 w²=10z²+5z+1。置 v=(w−1)/z，得到

```
z(v²−10)=5−2v.
```

如果 v²−10=0，则也要 2v−5=0，不可能。因此 v²−10≠0，且 z≠0 又迫使 2v−5≠0。恢复

```
u=(v³−30v+65)/(2v−5)²,
y=−5(v−4)²/[(2v−5)(v²−10)],
v=[5(y−1)²(u−1)−8u²]/[2u(y−1)].
```

正向可直接验证

```
u−1=(v−4)(v²−10)/(2v−5)²,
y−1=−2(v³−30v+65)/[(2v−5)(v²−10)].
```

所以在原门内 v−4、2v−5、v²−10、v³−30v+65 全部非零。所有 u,y∈Q 的点被此有理参数覆盖；分母为零均已单列，没有遗漏特殊孤立点。

检查器不只检验样本。令 an=5(y−1)²(u−1)−8u²，ad=2u(y−1)，coverage.json 保存以下三个多项式分别是 A5 的明确多项式倍数：

```
(y−1)(an²−10ad²)+2u(2an*ad−5ad²),
u(2an−5ad)²ad−(an³−30an*ad²+65ad³),
y(2an−5ad)(an²−10ad²)+5(an−4ad)²ad.
```

这给无隐含非零首项的可核覆盖身份。

## 8. 四个边界点的精确 RUR：范围与方向

令

```

u=t,
r=−(16t³+24t²+8t+3)/18,
y=(4t³+4t²−2t+1)/3.
```

q 与 q' 的 gcd 为 1（保首项模 101 的精确 gcd 证书），故恰有四个不同复根。检查器在 Q[t]/(q) 中用 Fraction 逐项代回全部六式，余式全为零。并且

```
K=0,
N=−527t³/54+181t²/12−845t/108+113/72 mod q.
```

N 的显式逆为

```
(14009371840t³+25297877856t²−2666087008t−18925087632)/11314793449 mod q.
```

乘法模 q 等于 1，所以所有四点 N≠0。它们恰是清分母后保留而尺度 N/K 不允许的边界点，**全部在 Ω 外**。还验证

```

q(t)=8(t²+t−1/4)²+5/2>0 (t∈R).
```

因此这些点没有实数/有理数版本。此处得到的是四个指定边界点的完整 RUR，证明方向仅为“此 RUR 给出的点满足六式且被 K≠0 排除”。没有证明每个六式零点必由此 RUR 给出，也没有证明 Ω 内点集为空。这四点不属于 R4 的 44,415 上界对象，不能从该上界减四。
