# REPLAY

在全新目录解压，进入包根目录，执行：

```sh
python code/replay.py --receipt REPLAY_LOCAL.json
```

要求：Python 3、NumPy、SymPy、支持C++17的g++。本次实际环境版本写入REPLAY_RECEIPT.json。程序不联网、不安装依赖、不运行Lean、不访问仓库。

先验证PAYLOAD_SHA256SUMS中全部冻结文件，再编译普通C++程序。完整重做47低原像、29剖面/双锚点覆盖、双模素数子式及字面局部卷积接收、五次全有理参数恢复、四组S5商核及不同实现轨迹接收、原系统非零核诊断、70560格的两种容量DP和负向控制。各步骤实际stdout/stderr留在replay_logs/。

本轮交付按以下顺序生成：冻结payload和清单；另建空目录解压payload并执行上述全部流程；把实际回执及日志加入最终ZIP；再次干净解压最终ZIP，验证其所有payload文件与已测试的清单逐字节一致。最终容器核对回执另存于FINAL_CONTAINER_CHECK.json（下载入口旁）。这是同作者重放，不是外部独立数学审读，也未重放历史LOW-T43、K152或原NC9出口整链。

可直接阅读的关键证据：
- `certificates/ledger_verification.json`：47对、T11→128、全部整数格对照；
- `certificates/geometry/verification.json`：29剖面的双模接收；
- `certificates/geometry/rational_exception.json`：唯一余核全参数可约；
- `certificates/s1825_S5quot_*.json`及`.trace.tsv`：1825专属商核；
- `certificates/frontier_reconstruction.json`：历史七删除与本轮一删除分开；
- `REPLAY_RECEIPT.json`：实际干净解压执行回执。

回放会在解压目录内重新生成证书/日志与编译产物，不要直接在唯一原始副本中工作。数学证书除运行秒数字段外是确定性的；模块每一步轨迹要求SHA相同。
