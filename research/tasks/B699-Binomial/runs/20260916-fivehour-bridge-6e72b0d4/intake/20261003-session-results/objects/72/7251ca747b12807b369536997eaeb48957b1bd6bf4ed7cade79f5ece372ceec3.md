# Exploratory only — NOT theorem certificates

These are original local prototypes and logs for the global saturated ideal, not part of accepted replay. They include historical /mnt/data/r5_work paths; review/adapt in a scratch directory, never run them against a repository or the frozen evidence package.

- gb_sat.cpp/colon*.cpp: modular sparse Gröbner / truncated multiplication-kernel colon exploration at p=32003. Iterative checkpoints are incomplete intermediate objects. The final UNIT is a one-prime diagnostic, not a Q-emptiness proof. It is intentionally NOT consumed by verify.py.
- gb_qq.cpp: attempted exact QQ counterpart using GMP; stopped at COEFFICIENT_CAP. Requires g++ and GMP to reproduce the exploratory attempt; neither required for the proof replay.
- colon_driver.py/colon_poly_driver.py: exact run order and working-file conventions of the modular probe. Large transient bases were not made proof dependencies. Selected final checkpoints and raw logs are retained under logs.
- small_boundary.py: reconstruction experiment. The accepted boundary RUR has a separate exact source-remainder certificate in certificates/boundary_RUR.json, checked without these programs.

Missing evidence is explicit: no Q ideal-membership trace lifts the final modular UNIT; no reverse containment says the four boundary points exhaust the original saturated zeros. Do not turn finite-field output into characteristic-zero coverage.
