## Directory layout

- `01_ROUND_ARCHIVES/` — original R1–R7 evidence ZIPs, unchanged.
- `02_KEY_FILES/` — extracted top-level REPORT / PROOFS / FAILURE_BOUNDARIES / HANDOFF / SOURCE_ADOPTION / SESSION_STATE files for quick browsing.
- `03_LOOSE_EXPORTS/` — loose PROOFS, FINAL_REPLAY, and SHA files that were separately shared in chat.
- `04_SOURCE_NAVIGATION/` — frozen project overview/navigation source available in this session.
- `05_ANCILLARY_EXTERNAL/` — external tooling source archive, explicitly not an adopted proof dependency.
- `ROUND_MANIFEST.tsv` — per-round archive size, SHA-256, member count, ZIP integrity result.
- `MANIFEST_SHA256.tsv` — SHA-256 for every file inside this master directory.
