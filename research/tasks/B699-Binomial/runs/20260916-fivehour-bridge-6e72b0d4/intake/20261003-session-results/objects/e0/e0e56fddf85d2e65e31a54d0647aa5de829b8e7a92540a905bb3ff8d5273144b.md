## 重放

Python 3.10+，只用标准库，无网络，无Lean，无CAS或scipy要求：

```sh
python scripts/verify.py
```

该命令只读比较6份新证书的JSON与全部字节，并核验复制的旧包身份。
它不执行旧epsilon<=4096终端，不重证旧单位窗口或外部BFT。

对整个压缩包重新干净解压验证：

```sh
python scripts/replay_archive.py /path/to/B699-C-R2-EVEN-DISTANCE-20261002.zip --receipt /path/to/replay.json
```

MANIFEST.sha256列出除它自身外的所有普通文件。最终ZIP的SHA-256与最终重放回执在下载入口另附，
避免档案把自身最终哈希嵌入自身形成循环。
内部PAYLOAD_REPLAY_RECEIPT属于加入该行政回执前的payload；外部FINAL_REPLAY_RECEIPT绑定最终ZIP。
