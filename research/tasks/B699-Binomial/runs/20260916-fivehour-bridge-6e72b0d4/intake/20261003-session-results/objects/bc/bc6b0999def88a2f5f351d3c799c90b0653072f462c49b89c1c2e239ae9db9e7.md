## 1. 实际内侧源强迫五个整数，而非只强迫一个和式

置 x=j−1,y=k−1,N=x+y=n−2。对 b=0,…,4 置

    a_b=C(x,b) C(y,4−b).

每个 a_b>0，因为 j,k≥7。若实际完整 p^e||I 来自原 r 源的内侧槽 h，则 2≤r≤5、1≤h≤r−1，

    x≡h−1, y≡r−h−1 (mod p^e).

两个非负源余数之和 r−2≤3；对于任意 b，至少一侧的余数小于所取二项式长度。两项乘积的整系数下降阶乘在该源点为零，分母 b!(4−b)! 的素因子只为 2、3，因此在 p≥7 处是单位。于是 p^e|a_b。对各完整幂相乘，得到

    I | a_b  (b=0,1,2,3,4).                         (INNER4)

定义 v_b=a_b/I∈Z_{>0}。这里仅把同一原 (n,j) 的多项式平移；**没有认定 (n−2,j−1) 是 NC4，没有下降到另一原题，也没有扩大原 q_r 的指数。**

R4 仅单列 I|Hodd。本步保留全部五个系数的整数性，不能由一个整数线性组合可整除倒推它。

## 2. 两个精确四次不变量给 I 的严格高度

对 a_0,…,a_4 定义整数

    aInv=12a4a0−3a3a1+a2^2,
    bInv=72a4a2a0+9a3a2a1−27a4a1^2−27a3^2a0−2a2^3.

记 J'=xy、A'=(x−1)(y−1)。本轮从下降阶乘系数完整展开并验证

    8 aInv = J'A'(N−3)(N−2),
    −16 bInv = J'^2 A'(N−3)^2(N−2),
    256(bInv^2−2aInv^3)
      =J'^3 A'^2 (N−3)^3 (N−2)^2 [(N−1)(N−2)−J'].

这些是显式代数身份，不调用曲线整数点软件或未经实现的因子目录。

由 INNER4，aInv/I^2、bInv/I^3 都是整数。因此

    (bInv/I^3)^2−2(aInv/I^2)^3

是正整数：最后一项身份的各因子均正，尤其 N≥12、J'≤N^2/4 使最后方括号>0。它至少为 1。

又 A'<J'、(N−3)^3(N−2)^2<N^5、最后方括号<N^2−J'。取 u=J'/N^2∈(0,1/4]，u^5(1−u) 在该区间递增，端点值 3/4096。因此

    I^6 ≤ bInv^2−2aInv^3
        < [N^17/256] u^5(1−u)
        ≤ 3 N^17/2^20.

即

    2^20 I^6 < 3(n−2)^17.                         (I-HEIGHT)

这里 I 是实际内侧幂乘积，不是上述二次不变量 aInv。该应用不是重做 C24 的四窗模类分类；新输入是第 2–5 源的**内侧**完整块。

## 3. 主定理：真实第一个相位周期的离中心支全部关闭

### 3.1 一个更广的原数对充分消费者

对任意原合法 n,j，另有 4j≤n。按原整数计算 s_r,q_r,Q,g,K6 和 ell。则

    K6 < ell*g*Q  => Common6(n,j).                (SHORT-OFFCENTER)

该命题不要求先给出源分配、不要求 T6 为整数、不要求 r 可解，也不限于 R42。左端中的 K6 是实际六次式，不能替换成形式商乘以分母。没有使用浮点计算。

在 R4 的假想 NC42 必要域内，T6=r+ell*t、0<r<ell，因此 t=0 自动满足 SHORT-OFFCENTER 的左端。故得到本轮主要前沿出口

    NC6, n mod1800∈R42, 4j≤n  => t≥1.           (NO-t0-OFFCENTER)

这不是全部 t=0 闭合，更不是“r 短就闭合”。

### 3.2 先取得绝对 n 界

反设 NC6 且 4j≤n、K6<ell*gQ。先取 n≥128。由于 d≥n/2，直接从 K6 的系数得到

    K6 > d^6−15n d^4−15n^3
       ≥ d^6(1−60/n−960/n^3)
       > d^6/2 ≥ n^6/128.                       (K-LOW)

其中被略掉的 d^2 系数 45n^2−210n+184 为正。函数 1−60/n−960/n^3 随 n 增大，n=128 的精确值已大于 1/2。

NC 的完整端点分拆给 Q=Dend I=beta*gamma I/U。利用 J=jk≤3n^2/16（因为 j≤n/4）和 ell=480g/c，

    K6 < 480g^2 Q/c =480 J I/(cU)
        ≤90n^2 I/(cU).

升六次，使用 I-HEIGHT，得到

    2^20(cU)^6 K6^6 < 3*90^6*n^29.

再接 K-LOW，严格推出

    n^7(cU)^6 < 2^28*3^13*5^6
               =6687075336192000000.            (HEIGHT)

c,U 都是正整数。完全整数比较为

    489^7 < 6687075336192000000 < 490^7.

因此 n≤489。先前 n<128 的出口也全部包含在内；没有先截断 ε、g、活动指数或粗源支持。

### 3.3 证明界定的完整有限末端

本轮检查了**更大的有限集合**：全部 28≤n≤489、7≤j≤floor(n/4)，不加任何模类、相位、gcd、小部或 ε 筛选。n<28 根本没有这些合法 j。

精确共 462 个 n 行、26,912 个原数对。每对都有完整记录

    [n,j,p,v_p C(n,6),v_p C(n,j)]

且 p≥7，后两个赋值均≥1。包含 R42 的有限子集是 11 行/631 对；它们不是“新闭合11类”。

实现 A 从原 n,n−1,…,n−5 的完整试除分解取得源素数，使用阶乘估值选最小共同见证。实现 B 逆序枚举，直接计算两个 math.comb 的整数 gcd，剥去全部 2、3、5，再独立试除其最小素数并核对两边实际整除赋值。两实现比较**整个有序见证集合**，不仅比较数量。26,912 对全部一致，NC 遗留为空。

这个上限 489 来自 HEIGHT，不是任意扫描范围或把旧 4096 条带加宽。有限前缀与历史覆盖可以有重叠，特别含旧 024 范围中的 n=252；不据此登记历史净新增。

### 3.4 同一实际相位商必须增长

在 R42 的一般正相位中，T6=r+ell*t<ell(t+1)。相同证明对 n≥128、4j≤n 给

    n^7(cU)^6 < 2^28*3^13*5^6 (t+1)^6.          (t-GROWTH)

因此在这个角度域中，实际 t 不能随着 n 增长仍保持任意固定值；但这不是 t 的绝对上界，也不是 ε 的上界。最低整层 t=0 的有限末端已完成；本轮没有枚举 t=1,2,…。

## 4. 全42类第一周期仍剩的增长距离走廊

本节采用 R4 已证 d^2>15n。置 x=d^2/n>15，K6/d^6 的 n→∞ 主项为

    f(x)=1−15/x+45/x^2−15/x^3.

f'(x)=15(x^2−6x+3)/x^4>0，f(15)=44/225。原 K6 的两个剩余修正项在 x≥15 时为正。因此

    K6 > (44/225)d^6.

对任意角度，J≤n^2/4；同一真实 T6<ell(t+1)、I-HEIGHT 给

    K6 <120(t+1)n^2 I/(cU).

联立并用整数幂整理为

    2^14*11^6*(cU)^6*d^36
      <3^19*5^18*(t+1)^6*n^29.                  (UPPER-DISTANCE)

因此 t=0 的未闭域已有上侧 d=O(n^(29/36)/(cU)^(1/6))，同时仍须满足 R4 下侧

    d^6000>7^1000(n−5)^3501.

两个指数 1167/2000≈.5835 与 29/36≈.80556 之间仍有空间。没有推出 n 或 ε 有界；不能把本节误说成全部第一周期被排空。

R4 全42类固定 ε 高度 `n^47<2^6486 ε^5125` 保持原值，不是本轮重算，也没有改成无条件统一有限化。

## 5. 原源1/2的完整估值：Vinner不能任意吸收端点或中央高幂

Hodd 是分母只含 2 的四次多项式。实际端点值为

    Hodd(0,r), r=0,…,5: 23,9,9,14,24,48.

所以对原 q1、E2、E4、E5 的每个源素数 p≥7，Hodd 在 p 处是单位。

更关键的是第 2 源中央完整幂。于 (j,k)=(1,1) 平移，Hodd 的一次部分为

    −(9/4)[(j−1)+(k−1)]=−(9/4)(n−2).

若 p^e||C2，j−1、k−1 同时被 p^e 整除，且 v_p(n−2)=e。二阶及以上项至少被 p^(2e) 整除，一次系数在 p≥7 处为单位，因此

    v_p(Hodd)=e,  v_p(Vinner)=0.                 (CENTRAL2-EXACT)

这里用到 n−2 的**实际完整指数恰为 e**；只知道 p^e|n−2 而不保留完整性不能直接得到等号。

总结为

    gcd(Vinner,q1*q2*E4*E5)=1.                   (UNIT12)

原点 p|q0、p≠23 时由常数 23 得单位；E3 的端点常数 14 则必须单列 p=7。定义

    Lunit=q1*q2*E4*E5*(q0/23^v23(q0))*(E3/7^v7(E3)).

则 gcd(Vinner,Lunit)=1。**7 与 23 没有混为一种例外，也没有去掉各自的完整幂后冒充原源。**

下面证明 Vinner>1，因而得到不设指数上限的支持消费者：Vinner 的全部素因子若均来自 Lunit 的素数支持，则同一原输入 Common6。其反证来自实际源的矛盾；不能把 Vinner 新出现的素数本身直接称为共同见证——它还可能是 2、3、5。

## 6. 五个系数的同余及实际 Z 的量化下界

置 m_g=g/gcd(g,24)。对于 a_b=C(j−1,b)C(k−1,4−b)，24a_b 是整数系数多项式，在 j=k=0 的常数为 24。因为 g|j,k，

    24I v_b≡24 mod g,
    I v_b≡1 mod m_g.

故五个正整数 v_b 两两之差都被 m_g 整除。此模数保留实际 g 的高幂，不只使用 q0 的 radical。

当 j<k 时，令 x=j−1<y=k−1，有

    v0>v4,
    v3/v4=4y/(x−3)>1,
    v2/v3=3(y−1)/(2(x−2))>1.

于是

    v0≥v4+m_g,
    v3≥v4+m_g,
    v2≥v4+2m_g.

利用 Vinner=9(v0+v4)+5v2，得到

    Vinner ≥23v4+19m_g ≥19m_g+23.                (V-FLOOR)

因此同一实际正相位须满足

    A−r−ell*t=32g U Vinner
      ≥32g U(19m_g+23).                         (Z-FLOOR)

Z-FLOOR 与 t-GROWTH 可以共同作为同一原输入的上下筛选，但不是两条独立定义方程，更没有取得全局 t 或 ε 的上界。

## 7. 精确处理23取消支的失败边界：原点的所有高层仍不能界住Hodd

本轮不把 v23(g)=1 的取消直接排空。相反，给出一族**真正 n,j,g,alpha 和完整源0都成立**的弱恢复，说明仅强化原点仍不足；缺的原源 1 被精确指出。

### 7.1 实际原输入族

令 a=391+660w，w≥0，取

    n=23*2^a, j=23, k=23(2^a−1),
    g=23, alpha=s0=2^a, q0=23.

这些是真正合法原整数，n≡1504 mod1800、v23(n)=v23(g)=1。因为 a≡6 mod11，2^a≡18 mod23。

对所有原点素数 23 的工作层：h=1 时 j,n 同余0；h≥2 时

所以原 23 在 C(n,j) 的**全部高层**均无进位。这里没有只检查有限层。

### 7.2 无界的精确取消阶

定义整数多项式

    F(X)=23^3[X^4+X^2(X−2)^2+(X−2)^4]
          −15*23^2 X[X^2+(X−2)^2]
          +23[85X^2+40(X−2)^2]−210X+8.

精确身份为 8Hodd=23F(alpha)。令

    G(w)=F(2^(391+660w))/23=8Hodd/23^2.

alpha≡18 mod23 使 G(w) 对每个 w 都为整数。又

    (2^660−1)/23≡4 mod23,
    F'(alpha)≡−210 mod23.

由整数二项式展开归纳，对于全部 m≥0、w≥0，

    G(w+23^m)−G(w)≡14*23^m mod23^(m+1).

14 是模23单位。故对每个 L≥2，逐位唯一恢复 w modulo23^(L−1)，使

    G(w)≡23^(L−2) mod23^(L−1).

于是该原整数准确满足 v23(Hodd)=L。这里是完整 Hensel 归纳，不把证书内 L=2,…,12 的样例当作无界证明。

前几个指数 a 为 8311、65731、5576071、43981471，分别取得准确 L=2、3、4、5。证书用模幂核对精确赋值，不物化这些巨大 n，也不宣称给出了完整原 NC 模型。

### 7.3 原第1源对整个族失败

本族 n mod1800=1504，n−1 的完整小部只有 3 幂：n−1=3^b q1。若原第1源成立，则 q1|j(j−1)=23*22；又 gcd(q1,23)=1，所以 q1∈{1,11}。

但 a≥3，n−1≡7 mod8；而 3^b 或11*3^b 模8只可能为1或3。矛盾。

因此原第1源对这整个族失败，并给同一原 (n,j) 的某个实际源素数共同见证。本族从未被称为 NC6、通过所有原源、或实际 T6/Z 都为整数的模型。它准确否定的是：仅靠真实原点/alpha形状及原23所有高层，就能界住 v23(Hodd) 的命题。

对完整 NC 而言 Vinner=Hodd/I，I 与23互素；仍须用源1/2等缺失条件控制该取消支，不能把本族的 Hodd 赋值当成一个已恢复的完整 Vinner 或 T6。

## 8. 精确收益、历史净差与仍未界量
