# 失败边界与未覆盖内容

## 1. 未完成的东西

- 7i≤n<31i子带中n<2^64的有限底部没有执行。
- 采用R2与Overview后，全高尾反例i<2^1024、n<2^1030的有限集合没有排空；不能称完整i≥4883接受或全B699闭合。
- 对n>32i没有普遍构造本轮来源图；旧H或高比例原题终端给Common不等于给本轮图证书。
- 本轮不推进小指标R7，不修改其前沿。
- 没有证明“任何17个辅助素数”都有效，也没有把R32系数直接外推到R33或4096。

## 2. 三个关键防错点

**(a) 36不是全局核最大值。** 它只是在u≤2^26的首次层级观测；无限尾部使用已证明的M=12288，付出(M−36)/K的主项成本。如果省略这项，就不是有效证书。

**(b) 有符号阶乘比不保证整性。** 核可为负，全部素数和所有高幂都在完整身份内；负项只能在取上界时舍去。不得把负赋值剪掉后仍称相同阶乘比。

**(c) psi的质量不是素数。** 本轮显式支付M sqrt(x)log(x)的全部e≥2贡献，剩余才是theta区间差。不能删除这个费用。

## 3. 实际试过而未采用的方案

先按HANDOFF考虑顶层或二商层、顶层或三商层两个析取的直接供应；没有得到这两个更弱目标各自的简短证书，随后切换到更强的顶部直接供应。

只取32以下的11个辅助素数，初始顶部外层级收费超过主项；在探索头部中观察到73、197、443等早期正层级。单靠粗界2^(s−1)会让追加辅助素数后的无限尾部费用过大。成功方案必须同时做两件事：选择新的辅助素数，使低阶正贡献后移；以及用小核心的**全周期**绝对界替换过松的通用界。不是不断增大原n扫描。

探索程序里的浮点数只用于选候选。最终参数及每个断言重新由整数/有理程序验证。未采用的探索输出不作为数学依据。

## 4. 来源图与原题阈值

原边公式仍为n>(lcm(a,b)+1)max(r,s)。本轮单顶点标签1不需要边，不意味着可以把任意互素商标签直接连边。

原题的p≥i保持不变。构造给p>n−i>n/2≥j>i，因此这次见证恰好不会等于i。R1的p=i迁移失败例仍有效，不因为本轮获得顶部来源而失效。

## 5. 证据等级

R2作者纸面定理与项目登记已接受的原A/§9终端分别采用；没有重编译旧Lean对象。本轮双整数实现是同会话算术核对，不是外部独立审读。Lucas证书认证一个实际例子的素性，不替代全域T32证明。哈希认证字节，不认证定理。

出版来源仅作方法启发，不把其最终素数区间定理作为未展开前提。但本轮也不主张Möbius阶乘方法、素数区间结论或整个B699高指标结果的原创性。

## 6. 下一步可证伪任务

当前无限31比例子带已经移除，不应再派同一来源缺桥。较高收益的是把统一有限化的未执行底部改造成完备且经济的终端，或者用新来源定理与原A做经严格验证的更小指标阈值接口；必须按实际原输入和原接受等级回传，不能只增加R网格或固定n样本。

若尝试将有限核方法推广到更窄区间，首个可否证检查就是完整实断点包络和包含无限尾项的主项余量是否仍正；仅在扫描头部看见很少正层级不够。
