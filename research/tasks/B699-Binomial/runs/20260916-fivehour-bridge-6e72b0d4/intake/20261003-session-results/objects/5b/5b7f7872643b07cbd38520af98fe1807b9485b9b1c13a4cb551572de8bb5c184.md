# E Round 6 — 完整小素数部、未粗化窗口与高尾纸面末端

日期：2026-10-02。新证明等级：作者纸面推导＋同会话精确有理证书。无 Lean、无外部独立数学审读、无仓库修改。本证明不声称完整 B699，只处理 i≥4883 的高指标范围。

## 0. 量词、采用合同与真正改变的信息

`Legal(n,i,j)`：自然数 1≤i<j≤floor(n/2)。
`Common_i(n,j)`：存在同一个实际素数 p≥i 同时整除 C(n,i)、C(n,j)。
`NC_i(n,j)`：其否定。任何矛盾都针对同一个原始 n,i,j；不变换 n 或 j。

本轮采用三个冻结合同：

1. **R5-THETA**：对所有实数 x≥1，psi(x)≤c x，故 theta(x)≤c x，其中 c=10769/10000。theta、psi 都计入全部实际素数，psi 保留全部实际幂。这是 Round5 作者级全域结果，不是本轮重新验收的 Lean 对象。
2. **R4-SOURCE32-ALL**：对 i≥4883 的所有合法 n≤32i，原行有实际 p>n−i，因而 Common；无遗留小 n。367节点、R3核及旧误差本轮不重跑。
3. **OV9-HIGH**：i≥1000、n≥4096i 的全部合法输入 Common。按 SHA固定 Overview §9登记的接受状态采用，本轮未运行其内核或旧对象。

Round5 的 pi 三项界、I151/H64标量门不是下面新证明的输入。原A自身也没有被偷偷加强：我们回到其归一化之前的真实素数部/窗口层，给出独立的纸面推导。固定 ThreeWindowSize 源中的窗口定义与本轮一致，但其 theorem 不作为新证明未经展示的黑箱；第2节直接在所需域证明转移。

新核心定理是：在 R5-THETA 下，所有 i≥4883、Legal(n,i,j)、32i≤n≤4096i 都有 Common。与另外两合同拼接后，本路线全部 i≥4883 纸面成立。

## 1. 全部小素数部，而不是 pi(i−1) 个独立的 n

令 B=C(n,i)，定义真实完整小素数部

    S = product_{p<i, p prime} p^{v_p(B)}.

此处包括每个小素数的全部实际指数；大素数部 P=B/S 也来自 B 的全部实际素因子，没有删源谓词。

完整 Legendre 公式为

    v_p(B)=sum_{e≥1} (floor(n/p^e)−floor(i/p^e)−floor((n−i)/p^e)).

每项为0或1；p^e>n时为0。因此，对任何实际 p，v_p(B)≤floor(log_p n)。对所有 p<i 求和得到

    log S ≤ theta(i−1)+sum_{e=2}^{floor(log_2 n)} theta(n^{1/e}).       (1.1)

右端允许把本来还须 p<i 的高层放大到全部 p。这是上界，不删除原 S 的因子。

由 R5-THETA，

    log S ≤ c [ i + sum_{e=2}^{floor(log_2 n)} n^{1/e} ].              (1.2)

**信息增量**：旧 pi(i−1) log n 把每个 p<i 都按 log n 计费；(1.1)保留第一层的实际 theta(i−1)，只对真实可能存在的二次及以上幂额外收费。此处没有由 psi 的增长推出新素数。

## 2. 在同一原输入上重新证明未粗化的三窗口转移

以下只考虑 i≥4883 且 32i≤n≤4096i。因为 i>4096，严格有 n<i²。

于是对任何合格 p≥i，p²>n，完整 Legendre 的全部 e≥2 层严格为零。若 p=i 为素数，

    v_p C(n,p)=floor(n/p)−1−floor((n−p)/p)=0.

所以 P 的每个实际素因子都严格大于 i，且指数为1。原定义仍保留 p=i；这是本域内的估值结论，不是删去原题阈值或恢复旧的错误迁移规则。

取

    s=floor(4i/5), ell=floor(2i/3), r=i−ell−1,
    lambda=2s−r=2s+ell+1−i > 0.

有 1≤s<i、1≤ell<i、r≥0。定义真实正整数窗口积

    W = product_{h=1}^s C(j,h) C(n−j,h)
        * product_{h=1}^ell C(n−i+h,h).                             (2.1)

原合法性保证全部因子正。

假设同一原输入为 NC。任取实际 p|P，写 a=n mod p。由于 p>i，p|C(n,i) 等价于 0≤a<i。NC 保证 p∤C(n,j)。写 b=j mod p，完整单层估值因此给出 0≤b≤a，而 (n−j) mod p=a−b。

因为 h<i<p，窗口分母没有 p。逐项数真实分子区间中的 p 倍数：

- 第一子窗口贡献 max(s−b,0)；
- 第二子窗口贡献 max(s−(a−b),0)；
- 母窗口贡献 max(ell−i+a+1,0)=max(a−r,0)。母区间中唯一可能的 p 倍数是 n−a，发生条件为 h≥i−a。

因此

    v_p(W) ≥ max(s−b,0)+max(s−(a−b),0)+max(a−r,0)
           ≥ 2s−a+max(a−r,0)
           ≥ 2s−r=lambda.                                         (2.2)

P 的所有实际素因子均在上述证明中，故

    P^lambda | W.                                                  (2.3)

没有把只选若干素数的投影当成完整来源。没有把其他输入的窗口搬到这里。

记 SF(m)=product_{h=1}^m h!，以及

    D=s(s+1)+ell(ell+1)/2,
    Cw=2^{s(s+1)} SF(s)^2 SF(ell).

从 h! C(N,h)≤N^h、j(n−j)≤n²/4、n−i+h≤n，可得

    Cw W ≤ n^D.

合并 (2.3)，得到同一原 NC 必须满足

    Cw P^lambda≤n^D,
    log S ≥ log C(n,i)+(log Cw−D log n)/lambda.                     (2.4)

这是原 A 粗化之前的完整小部版本。下面不使用 pi 近似替换 S。

## 3. 两个自包含积分界保留全部阶乘常数

对整数 m≥1，由 log x 单调递增，

    log(m!)≤m log m−m+1+log m,
    log(m!)≥m log m−m+1.

又因 x log x 在 x≥1 递增，逐项求和第二式给

    log SF(m)≥(m²/2)log m−3m²/4+m/2+1/4.                           (3.1)

说明：sum_{h=1}^m h log h≥integral_1^m x log x dx
= (m²/2)log m−m²/4+1/4；再减 sum h、加 m 即得。m=1端点也成立。

写 t=n/i。在 n>i 下，C(n,i)≥(n−i)^i/i!，所以

    log C(n,i)/i ≥ log t+log(1−1/t)+1−(1+log i)/i.                 (3.2)

这些积分不调用 Stirling 渐近余项、Barnes函数或出版近似定理。

## 4. 把无限指标 i≥4883 压成一个保守的统一实函数

以下固定 I=4883。令

    a=s/i, b=ell/i, v=lambda/i=2a+b−1+1/i.

由 floor 的全域误差，

    a0=4/5−1/I ≤ a ≤ 4/5,
    b0=2/3−1/I ≤ b ≤ 2/3,
    v≥v0=19/15−2/I>0.                                             (4.1)

此外

    D/i² = a²+b²/2+(a+b/2)/i ≤ E0=194/225+17/(15I).                (4.2)

把 (3.1) 展开到 log Cw，并把 D log n 中的 log i 部分准确消去，得到

    (log Cw−D log n)/(lambda i)
    ≥ [D0(a,b)−(a+b/2)log i/i−(D/i²)log t]/v,                    (4.3)

其中

    D0(a,b)=a² log(2a)+(b²/2)log b−3a²/2−3b²/4.

(4.3)只舍去明确非负的

    [(a log2+a+b/2)/i+3/(4i²)]/v.

不能忽略 D log n 中的线性 s、ell 项；它们已保留在 (4.2) 与 (4.3) 的 log i/i 成本中。

a>1/2，故 a² log(2a) 单调递增且为正；b<1，故

    (b²/2) log b ≥ (2/9)log b0.

由此，

    D0(a,b)≥d0:=a0²log(2a0)+(2/9)log b0−24/25−1/3.                (4.4)

d0<0（证书也核对其符号）。对所有 i≥I，log i/i 和 (1+log i)/i 都单调不增。结合 (4.2)—(4.4)，(4.3)的分子下界

    d0−17 log I/(15I)−E0 log t

为负。由于 v≥v0>0，必须按负分子方向除以 v0，得到合法的统一下界。

因此 (2.4) 强迫

    log S/i ≥ Phi_I(t)=alpha log t+log(1−1/t)+beta,               (4.5)

其中

    alpha=1−E0/v0=443648/1391205,
    beta=1−(1+log I)/I+[d0−17 log I/(15I)]/v0.

精确证书给

    0.141206321471567 < beta < 0.141206321471568.

此处 (4.5) 对每个 i≥I 成立，不是把 i=I 的精确 s,ell 计算误当成全域；所有 floor 与 log i/i 损失已统一支付。

## 5. 所有完整高幂的统一尾部；不能冻结未来指数

在 (1.2) 中保留 e=2,…,8。其余全部 e≥9 满足

    sum_{e=9}^{floor(log_2 n)} n^{1/e}
    ≤ log_2 n * n^{1/9}.                                         (5.1)

即使 i 或 n 无界，新出现的指数仍在 (5.1) 中，不以某个有限 n 的指数长度封口。

对固定 t≥32、e≥2，(ti)^{1/e}/i 随 i 递减。

尾部函数

    log_2(ti) (ti)^{1/9}/i

关于 i 的导数符号为 1−(8/9)log(ti)，在 i≥I,t≥32 上严格为负。证书核对 log(32I)>9/8。

所以 (1.2) 对全部 i≥I 给出

    log S/i ≤ U_I(t)
      := c {1 + [sum_{e=2}^8 (It)^{1/e}
                    +log_2(It)(It)^{1/9}]/I}.                    (5.2)

这是完整真实小素数部的上界。有限 e 头部和无界指数尾部都展示出来；没有把 ψ 的高层误认为新素数。 

## 6. 连续比例的核心：在 z=log t 上严格凹，只需两个端点

设

    Delta(z)=Phi_I(exp z)−U_I(exp z),
    log32≤z≤log4096.

alpha z+beta 是线性的；

    d²/dz² log(1−exp(−z)) = −exp(z)/(exp(z)−1)² < 0.

每个被减去的根项是正系数 exp(z/e)，为凸函数。尾项是正系数

    (z+log I)exp(z/9),

其二阶导数为

    exp(z/9)[(z+log I)/81+2/9]>0.

所以 Delta 严格凹。对任何中间 z，Delta(z)至少为两个端点值的线性插值，特别至少为端点最小值。

这一步把整个连续比例带一次覆盖；没有 T 网格，也没有逐(n,i,j)扫描。

## 7. 两个严格有理证书及第二实现

第一实现用40项 atanh 级数、显式几何余项和2^40缩放的整数根证书。根证书逐项核对

    (q−1)^e < (IT) S^e ≤ q^e,

所以 (q−1)/S < (IT)^{1/e} ≤ q/S，不依赖浮点或概率验素。

### 可直接指出见证所在的真实因子集合

其实数值比较不必等反设NC才成立。令P=C(n,i)/S为真实大素数部，(3)—(7)直接给

    log(Cw P^lambda / n^D) > lambda*i/100 > 0.                   (7.2)

对每个原合法j，Cw W≤n^D，故P^lambda>W。由完整真实素因子分解，至少有一个实际p|P满足v_p(W)<lambda。第2节的局部计数说明：若这个p不整除C(n,j)，则必须v_p(W)≥lambda，矛盾。因此这个**同一个实际p**同时整除C(n,i)、C(n,j)。

这给出准确的见证提取判据（从真实P的因子中找欠估值者），不声称大整数分解具有低成本。不同j的W不同，见证可以不同；没有推出固定一个p覆盖整个高带原行。

两计算程序验证数值界与列明有限恒等式。凹性、所有 i 的单调性、完整源转移与原量词回传是上述纸面证明，不称计算机自动验了全实数定理或 Lean。

## 8. 与冻结消费者拼接：高尾纸面末端完成

任取 i≥4883 和同一合法 n,j，分三种（端点可重叠）：

1. n≤32i：冻结 R4-SOURCE32-ALL。
2. 32i≤n≤4096i：本轮第7节的新带定理。
3. n≥4096i：固定 Overview §9 的 OV9-HIGH（i≥4883⇒i≥1000）。

三域穷尽所有合法输入，所以在上述采用等级下，

    对每个 i≥4883、每个同一合法 n,j，
    存在一个实际素数 p≥i，同时整除 C(n,i)、C(n,j)。              (8.1)

高比例带由原 NC 的矛盾给 ∀j∃p；不同 j 的 p 可以不同。没有证明 ∃p∀j，也没有证明 SOURCE64-ALL 或一般 gcd1 来源图。只有 R4 的低比例分支沿用其固定原行素数。

R5 的原剩余矩形 `4883≤i<2^151,32i<n<2^157` 因此在本作者级采用链中为空：不是再把它压成另一个未执行的有限矩形。本范围没有遗留有限 n/i/j 末端或无界原反例参数。
