# REPORT — R5 G0 整支孤立基点终端

## 终点

本轮从 R4 已证明有限的规范模型接续，未重做 DIM≤1/DIM0、已排一般曲线、半切片、269 圆柱域或 S=K_lin=0 例外。

**没有完成整个规范有限集的 RUR 或有理点排空。** 实際严格完成：

1. `J=u²+uy²−3uy+y=0` 上，P5=G4=G0=0 与 `u(u−1)y(y−1)r≠0` 不相容，只要 u,y 是实数（r 甚至可在 C 中）。因此全部允许实/有理规范点退出，包括旧轮未处理的特殊孤立基点。
2. `A5=8u³y−5(u−1)²(y−1)³=0` 上，同样系统无有理基点 u,y，r 甚至可在 C 中。整个允许有理支退出，不宣称整个复支为空。
3. 对旧 B9 因子上的有理基点，新增 `H=u²−uy²+3uy−2u+(y−1)²≠0`。这是安全除数门，不是 B9 整支排空。
4. 四个复点有精确 RUR，全部满足六个清分母多项式，但 **K=0、N≠0**，故全在 Ω 外，也没有实点。它们是明确的边界解，不属于 44,415 个允许点的上界，不能计作“找到了其中四点并删除”。没有证明这四点穷尽整个饱和前清分母零集。

## 与预计目标相比

预计尝试的是完成整个零维六式终端。本轮实际做完两个旧投影上的全部特殊有理基点终端；全局终端仅有模 32003 单位理想诊断，缺少特征零理想成员证书。直接 QQ 算法在 66 个基多项式、最大系数统计 11,632 bits 时触及 10,000-bit 安全限额并退出。

两个新排除是完整的规范域消费者，而不是在小区间逐点扫描。它们不要求先枚举所有规范点，所以统一删除其域中的一切允许孤立点；这些孤立点原来是否实际存在、具体有多少，本轮未计数。

## 已界与仍未界

继续采用 R4 的允许规范复点集有限、不同点数 ≤44,415 的作者级结论；本轮不改变这个安全上界，也不作 44,415 减某个小整数的虚假计数。剩余有理规范点必须 `J*A5≠0`，在 B9=0 时还须 H≠0。它们的坐标、数量和有理性未完全确定。

规范点以及原常数项恢复所允许的平移只有有限选择，是旧 R4 结论；原仿射斜率、整数非负系数、工作素数幂 T、底素数与完整指数、原 n,j,g 等仍没有一般绝对界。原完整 P/Q 源幂不与多项式 Q_poly 混同；一般 REG3 不擅加恰好两个素数底条件。

原题历史消费者净差：**0 / 未认证**。新增完整指标：0。全局 R7={3,4,5,6,7,8,9} 不变。没有原题精确反例，没有同一输入的有效下降。

## 证据

本轮重放 R4 ZIP 后，使用其完整系数原件。新检查器完整检查十二条六式坐标运输、四条大一元结式、B9-H 结式、全部余因子互素和有理根障碍，并在 Q[t]/q 中验证边界 RUR。最终 115 项新主检查，包括 2,074 个固定阶整数 Sylvester 行列式；1,016 个完整 r 系数向量的整数插值值；另 26 项消费器回归。

插值值数量严格超过证明得到的各自次数上界，所以核验整个多项式身份；它们不是 2,074 个或 1,016 个原题实例。生成器用 SymPy，默认检查器只用 Python 标准库的独立整数运算实现；同作者两实现，不是外部独立数学审读或 Lean。
