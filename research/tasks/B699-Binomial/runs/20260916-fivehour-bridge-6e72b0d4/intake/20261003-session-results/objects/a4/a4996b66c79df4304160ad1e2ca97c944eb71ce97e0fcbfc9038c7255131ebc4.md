# Evidence index

- REPORT.md：实际结果与仍未完成的全局目标。
- PROOFS.md：精确域、完整复参数覆盖、两结式与Bézout身份、Jcal实际N身份、N归一坐标。
- FAILURE_BOUNDARIES.md：模/QQ试算失败、错误原型拒绝、次数跌落及原题边界。
- HANDOFF.md：已经关闭的两个复分支与下一最小全局证书目标。
- SOURCE_ADOPTION.md / SESSION_STATE.json：来源采用、实际重放、未验证前置与净差。
- inputs/：固定R6完整证据及按原字节绑定的R14/R5相关原件。
- certificates/：完整H图与结式系数、两个显式有理Bézout证书。
- code/：标准库整数验证、负向回归、坐标计算器。
- discovery/：可选可移植再生成入口与历史试算代码。
- logs/、receipts/：成功/失败日志、实际旧源重放、新核验与干净回执。
- SHA256SUMS / PAYLOAD_SHA256SUMS：完整成员绑定；范围见README。

运行 `python -B replay.py`。没有全局饱和UNIT、完整RUR、原(n,j)恢复、Lean或外部数学独审声明。
