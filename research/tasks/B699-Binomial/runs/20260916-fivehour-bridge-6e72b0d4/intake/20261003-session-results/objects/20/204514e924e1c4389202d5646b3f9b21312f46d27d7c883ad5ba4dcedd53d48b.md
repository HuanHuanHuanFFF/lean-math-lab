## 离线精确重放

需要Python 3及C++17编译器，默认g++；可用环境变量CXX指定编译器可执行文件路径。

```bash
python -B replay.py
```

重放自动校验成员清单、前轮ZIP与采用源，编译临时C++核验器，验证新72项主检查和23项保护回归。输出可写到包外：

```bash
python -B replay.py --receipt /absolute/path/outside/package/receipt.json
```

不需要网络、SymPy、Lean或旧仓库；不改包内任何文件。编译器不是形式化内核，有限域算术经完整次数与系数界论证转成特征零身份。

## 消费器

`code/recover.py --u ... --y ... --r ...` 精确检查全部六式和原门，只能输出规范辅助恢复或拒绝，永远不凭这些式子认证NC3。

`code/affine_audit.py` 的audit函数检查实际提供的共同仿射映射、整数非负系数和同一原输入等式，不把T为整数冒充T为素数幂。

`code/original_pair_audit.py` 为冻结的完整源幂守卫，保留p=3和完整高次3幂，仅审计明确提供的源，不宣称覆盖所有来源。

## 清单回执约定

PAYLOAD_SHA256SUMS覆盖除两清单和内置CLEAN_REPLAY外的静态载荷。先在干净目录重放该载荷得到内置回执，再由SHA256SUMS覆盖其余全部成员（包括内置回执与PAYLOAD清单）。最终ZIP另在新目录校验SHA256SUMS并重放，外置FINAL_REPLAY记录具体ZIP哈希和结果，避免自引用哈希。
