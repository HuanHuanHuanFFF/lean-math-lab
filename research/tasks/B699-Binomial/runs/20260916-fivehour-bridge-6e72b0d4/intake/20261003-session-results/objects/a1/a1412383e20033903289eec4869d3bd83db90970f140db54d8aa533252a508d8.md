## 2. 未加价M7的原像引理与完整费用消费者

令原649安全表的行是(e,b)。每个实际可载因子(q,c)至少支配一行：q≥e,c≥b。定义f0(c)=min{e:b≤c}；无这样的行则该费用无实际因子。M_t^0(D)是原表t项、总代理费用≤D时的最小代理次数和，允许同一代理多次使用；该放松安全，不断言实际因子重复。

若(q,c)来自八因子之一，则其余七因子可各选安全代理，故

```
f0(c) ≤ q ≤ U_s(c):=h−M7^0(C−c).                 (1)
```

给指定代理(e,b)恢复原像时，另要求q≥e,c≥b。遍历0≤c≤C、奇行费用偶及(1)，得到完备必要原像。M7^0始终来自未加价649表，不使用新目录的加价，不从反事实许可证获得约束。

给定精确目录，只删除已经证明为空的精确(q,c)，或在已有本状态家族许可下完全退出的目录项。本轮所有状态许可mask=0，只使用空域。对其余每个费用令f_s(c)为(1)内第一个未排实际次数。若区间为空，该费用不可用于本状态。对可用费用作八项最小次数卷积：

```
M_0(D)=0,
M_t(D)=min_(c≤D){ f_s(c)+M_(t−1)(D−c) }.
```

实际八因子必满足M_8(C)≤sum q_a≤h。因此M_8(C)>h排除整必要状态。由于保留所有未排q，按最低未排q的包络只是放松，没有删除未知高次。

另枚举(1)内**所有实际q**的必要类型，然后枚举总次数≤h、总费用≤C的全部八项无序多重集。这不是仅删低代理行。Python实现按类型后缀DP剪枝递归，C++接收器从原表重建完整类型、用前缀容量/重数递归，比较完整集合。DP数值另由“容量内卷积”与“精确已用容量卷积再取前缀最小”两实现逐格核对。

## 6. 六个精确几何空域：全分拆、全共轭分量、全有理系数

### 6.1 几何必要条件和有限根配置的完备性

本节H仅在首一、Q不可约、D=2q、z≥14及精确费用前提下处理；不用本节条件约束任意可约Gbar。

每条ell_a=X−aN+a²（a=0..8）与H交数至多2q。非中心源贡献至少m，中心贡献至少2m−kappa。若H有d个共轭绝对不可约分量，则d|q且d整除全部m及kappa，存在这样的d满足

```
sum_P binom(m_P/d,2)
+sum_center binom(m_P/d−kappa_r/d,2) ≤ (q/d−1)^2.   (2)
```

这是采用的亏格/交数必要接口。本轮允许全部d|q；不把Q不可约偷换为绝对不可约。

固定精确费用，穷尽c_r=2Delta_r+kappa_r、Delta≥0、奇行kappa=0。每行枚举所有非负m和指定Delta，满足sum m=q−Delta，中心kappa≤m。每个源特化H(r,X)由这些源根及Delta个余根组成。

本轮所有分拆每行Delta≤2且总Delta≤2，至少三行饱和。H的根和S(N)次数≤2，可由三个饱和行确定；枚举全部m后，未饱和行余根之和因此有理且唯一。缺一根时这已确定余多项式；缺二根时利用H的第二基本对称系数T(N)次数≤4，在其余五行已定的值确定该行余根积。允许有理余根及不可约有理二次余因子，没有额外整数根假设。

每个根配置经同一S/T、九条ell交数、z≥14及(2)过滤。两种锚点选取分别枚举完整集合并逐项相等；它们复用基本数学剪枝，不声称两份独立数学推导。对于缺二根的分拆，第二系数使用精确有理插值/整数缩放，不用浮点近似或有限参数扫描。所有未被必要条件排除的配置都进入下一线性系统。

### 6.3 完整有理提升与模子式排除

对固定六个特化F_r(X)，用N的Lagrange插值得H0(N,X)，deg_N≤5。根和二次、第二系数四次的一致性使H0满足所需加权上界。任意完整提升必且可写为

```
H=H0+W R,
W=(N−3)(N−4)(N−5)(N−6)(N−7)(N−8),
deg_w R≤2q−6.
```

所有R单项式N^aX^b满足a+2b≤2q−6，总数(q−2)^2；连同H0列，K=(q−2)^2+1。列空间没有舍弃任何有理参数。

在21源处对H施加全部下闭普通Hasse条件i+j<m；中心同时施加i+2j<2m−kappa的加权条件，取两集合的并集。i=0的特化条件已自动满足，其余条件形成关于R系数的仿射系统。增广列H0与全部R列若在某个K行子矩阵行列式非零，则不可能有系数向量(1,Rcoeffs)落在核，故不存在H。

生成器按二项式/Hasse公式构造；另一接收器按字面局部多项式卷积重建所选各行并反序消元验证行列式。159689配置共319378子式全部通过；所有异常文件空。辅助模素数只是精确线性证书，不是原题共同素数见证。
