# 内容入口

REPORT / PROOFS：实际结论与49项新核验对应的证明。
FAILURE_BOUNDARIES / HANDOFF：未完成终端与唯一幂成员缺桥。
SOURCE_ADOPTION / SESSION_STATE：来源等级、0净删域、R7和真实运行状态。
certificates/：五条 N³V_i=A_iG_i+β_iP5 的全部整数系数。
code/：独立标准库检查器、可移植SymPy生成器、必要模型与原完整来源审计。
inputs/：冻结R5/R1 ZIP、原六式、R14与R4证明/交接。
logs/ / experiments/：实际成功与失败记录；拒绝的UNIT原型明确标注。
receipts/：R5本机重放与本轮干净解压回执。
SHA256SUMS / PAYLOAD_SHA256SUMS：最终成员与证明载荷绑定。
