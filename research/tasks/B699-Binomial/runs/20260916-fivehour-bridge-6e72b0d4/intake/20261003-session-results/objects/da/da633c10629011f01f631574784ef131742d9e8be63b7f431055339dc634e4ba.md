# R6 evidence：精确N³成员证书，但尚无全局UNIT

先读REPORT，再读PROOFS、FAILURE_BOUNDARIES、HANDOFF和SOURCE_ADOPTION。
默认完整新证书重放：

    python -B replay.py

仅需Python 3标准库。它检查所有成员SHA、R5/R1来源绑定、五个完整整数身份、互素/次数证书及保护回归。
不会执行Lean、联网、触碰仓库或启动旧探索程序。R5本轮实际115+26重放回执单独保留。

可选重新运行旧R5数学：

    python -B replay.py --replay-adopted-r5

可选重新生成新身份（需要SymPy，输出必须在包外）：

    python -B code/generate.py --output-dir /tmp/r6-generated

新证书的三个整数变量固定为(u,y,r)；V_i系数不能当作已列出的原题候选。
code/consume.py检查必要模型，code/recover.py、affine_audit.py、original_pair_audit.py保留原恢复接口。

experiments/中的原型源与日志是实际发现过程记录，部分路径保留原研究工作区；不要把它们当验收入口。
其中有已拒绝的解析假UNIT以及TIMEOUT，均在FAILURE_BOUNDARIES中注明。
受篇幅/重复成本限制，临时未完备模基不打包，只在TRANSIENT_OUTPUTS.json保留摘要哈希；没有任何接受结论依赖这些未保留基。
便于重生的正式生成器是code/generate.py，正式验收器是code/verify.py。

PAYLOAD_SHA256SUMS固定实际证明载荷；receipts/CLEAN_REPLAY.json是该载荷全新解压后的实际执行回执。
SHA256SUMS覆盖除自身外的全部成员，含前述回执。最终ZIP还在另一个全新目录实际重放，外置FINAL_REPLAY绑定最终ZIP SHA。
CRC/SHA与重放均不意味着Lean、外部独立审读或完整B699闭合。
