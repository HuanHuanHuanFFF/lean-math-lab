# Discovery notes (not the replay interface)

The exploration used the same 792 residual pair signatures from R7; no new slot-count or remainder cutoff was searched.
The new ingredient is the actual source0/source1 anchored cubic, its g*q1 cost, then a proof-bounded original-row terminal.
Scripts are snapshots of exploration and have original /mnt/data/c_r8_work paths. Formal verification is scripts/verify.py (standard library).
probe_bad_mod.py tests only the already present moduli 8,9,25; its results are not used in the main theorem.
The initial Bernstein sign mismatch came from primitive factor sign vs original cubic sign. Strict verification caught it.
The correction changes only the global sign attached to the same polynomial, and every Bernstein coefficient is then checked exactly.
