## 阅读入口

REPORT.md 是本轮结果和实际范围变化；PROOFS.md 是完整证明；FAILURE_BOUNDARIES.md 说明未证事项、非零门和修正；HANDOFF.md 给精确下一步。SOURCE_AUDIT.md 和inputs/SOURCE_VERSIONS.json登记采用版本与原字节限制。SESSION_STATE.json是机器可读状态。

## 干净重放

解压后进入本目录：

```sh
python -B replay.py
```

仅需Python 3标准库，不用网络、SymPy、Lean或旧仓库。依次校验文件清单，再隔离运行：

```sh
python -I -B code/verify.py
python -I -B code/verify_terminal.py
python -I -B code/test_consumer.py
```

分别是366项原源绑定/新身份检查、20,381项完整例外终端检查、17项消费器与原输入保护回归。检查器使用确定性整数/分数运算；19,635点等网格附足够多项式次数界，是完整恒等式验证，不是原题扫描。

`receipts/CLEAN_REPLAY.json`绑定最终数学载荷，在全新解压目录中实际运行得到。外部最终回执另绑定最后ZIP字节和SHA-256，避免ZIP包含自身哈希的循环。PAYLOAD_SHA256SUMS不包括清洁回执和清单自身；SHA256SUMS包括回执和载荷清单，只排除它自身。

## 证书分层

最终主要数学证书为`certificates/core.json`、`a_zero.json`、`exception_terminal.json`，均由默认重放检查。`finite_bounds.json`及`finite_exception_specialization.json`是本轮中间有限化，仍重放，但已被全空结论取代。

`inputs/prior`是首轮原件依赖；原ZIP另保留在`inputs/PREVIOUS_EVIDENCE.zip`。只采用其已冻结的系数/证明，不在本轮重做首轮有限纤维和旧区间。

其他证书JSON和`experiments`记录探索过程，不单独提升为证明；认可范围以PROOFS和默认重放实际检查为准。探索生成可能使用SymPy；默认重放不运行这些搜索。
