# 路线检查、失败与剩余边界

## 1. 原定短间隔三块没有闭合

本轮先考虑 T(aX²+bX+c) 的两个窗口同余，未得到同一输入的严格下降。不能把当前多项式余式非零升级成所有短间隔值不整除。
以顶部线性表示 T(aX'+B') 处理一般三块时，X'=X²、B'=bX+c；当b>0时，X²≥3a(bX+c)²通常不可能。因此新消费者不伪装成对紧邻三块的解决。

## 2. 被替换的中间界

起初证明路线考虑 X≥T max(B,5)²。随后把第一商压到 0<q<T，强制 q 为 3u(A−u) 的唯一正模代表，得到最终更合适的 X≥3AB²。中间界不是反例推翻，未计作单独成果。
B=1不能沿用B≥2的粗乘积估计；使用 (A−3u)²(4A−3u)≥0 单独证明，未漏小尾块。

## 3. 资源及探针范围

- `probe_prefix.py` 完成15,447,600项小参数检查，第一窗口134项、双窗口0项。仅为探索，不承担任何无限结论。
- `discover_prefix_examples.py` 完成9,198,390个正行列式检查，得到24,502个真实W1输入，其中18,283个B≥T。完整原输出存在 `outputs/prefix_examples.json`。最终接受只抽取96个不同回归输入，不将此抽样视为证书覆盖全部参数。
- `probe_overlap.py` 固定 P<2000、奇 m0≤51、8≤v≤120，未找到符合新门槛且B≥P的 n=P*m0*2^v 输入。这个探针甚至没有门槛命中，不能证明新门槛全被ROW覆盖，也不能认证全历史新增差集。

## 4. 实际开发失败

`verify_rows.py` 首次因测试记录 (P,f,A,B,e)=(5,2,1,4,2) 不满足门槛而退出：25<48。记录在 `failures/invalid-row-sample.txt`，失败源码原字节在同目录。
仅将测试指数改为e=3，没有削弱证明门槛。后续真实接受重放另记。
