# B699 Pro B：三次内容的不可约性与任意头块间隙

## 最强结论与前沿

本轮没有新增整指标，也没有界住一般缺陷。R7={3,4,5,6,7,8,9} 不变。确实补齐了一个此前只在 A<T 下可用的非零性前置，并接成了不限制头块大小的完整消费者。

**新前置 IRR。** 对实际三次 Vandermonde 内容 H，若 n 为4倍数、输入合法且 L=C(n,3)/H 是2的幂，则实际变换三次式 Φ/H 在 Q[Z] 中不可约。完整 NC3 必满足这个条件。证明只用内容、完整2赋值和有理根定理，不需要旧三次判别式或 G4。

**新通用核。** 任意正整数 T,A,B,X，若

    X²≥2AB³，TX≥4A²B，
    n=T(AX+B)，j=T(uX+w)，0≤u≤A，0≤w≤B，

且 4≤j≤⌊n/2⌋，则原题 i3 成立。允许 T=1、偶 T、任意 A≥T；没有把第二窗口弱解等同于 NC3。

**完整整行。** 对任意奇素数 P、f,e≥1、任意正整数 A,B，P∤B，且 P≥5 或 f≥2，令 T=P^f、X=P^e。上述两门槛成立时，n=T(AX+B) 的全部合法 j 均有共同奇素数。

特别地，任意 f,r≥1、任意 1≤A,B<P^r、P∤B，在相同活跃源前提下，

    n=P^f(A P^(3r)+B)

整行成立。两端各有至多 r 个数字，内部数字不受稀疏、段数、周期限制；r 与 f 没有大小关系。

## 新机制

旧零根引理只说明有理根的分母必须等于 L，再借 A<T 与 G4 排除小分母。本轮将实际二次项系数再用一次：全部有理根只能是 3j/n 或 3j/n−1。第一个直接代入非零；第二个若为零，必有

    (4n−9)(n−2j)²=n(3n−8)，因此4n−9|45，

与合法4倍数 n 矛盾。于是所有有理评估都非零，不再需要 A<T。

对 δ=nu−Aj，精确偏差展开把非零整数 E=A³Φ(u/A)/H 分成三个可控项。新门槛给

    1≤|E|<1/2+3/16+1/4=15/16，

完成矛盾。这个非零性模块及新通用核均没有使用判别式、ROW128 或 G4。原题到4|n的初等前置、完整内容桥与全层进位仍保留。

## 这次实际扩大和没有扩大的范围

新核与旧核的数值条件不是全体包含关系；旧成果仍单独保留。新核确实允许 A≥T。

对 P≥5、f=1、r≥2，A=B=P^r−1 的整个新族，旧同源头块核唯一可能的切分仍违反它的尾块门槛。因此新族不是同一消费者的改名。

但是：五个完整回归行都已被旧 ROW-3 排除；针对 n=P^f2^v 的429221个有界候选的探针没有找到通过 ROW-3 的新核例子。两件事都不能外推。**本轮没有认证相对于全部历史覆盖并集的严格新增残余核心。** 最可靠的信息增量是全分母不可约性、依赖删除、任意头块消费者，以及下一段的严格方法诊断。

## 三个短槽位的严格失败诊断

旧未决 (e,f)=(2,1),(3,1),(3,2)，n=P^f(aP^(2e)+bP^e+c)。对同一源的任何切分 X=P^d：

- d≤e 时，TX≥4A²B 必失败；
- e<d<2e 时，X²≥2AB³ 必失败；
- d=2e 时，只要新核通过，旧核已经通过。

这是对所有 P 和数字的完整证明，非扫描结果。因此本轮没有削掉这三个模板，也不建议继续用同一门槛调整切分。它们中的 P,a,b,c 仍无界。
