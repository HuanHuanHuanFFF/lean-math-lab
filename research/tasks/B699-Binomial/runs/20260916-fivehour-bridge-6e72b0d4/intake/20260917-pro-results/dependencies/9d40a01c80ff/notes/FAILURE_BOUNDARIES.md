# 失败与方法边界

1. **两窗口不能反推NC3。** 精确弱模型(76672,26775)满足两个窗口、补商范数和三个非空分配，但α=128·599，失去α=c2^s。599是原始共同素数。其他两个回归弱模型也失去α形状。
2. **补商交换不构成下降。** tg²−zH²=λ的直接交换变成−λ；矩阵的受限二幂坐标X0会换成奇q。尚未找到保持原输入必要条件的新n',j'。z<t不是足够条件。
3. **相对界不能替代绝对界。** n≤3C²和t≤O(C²)保留C无界。没有闭合一般t，更没有全i3闭合。
4. **曲线方程不等于整点完成。** 初期得到四曲线时确实未完成。后续三个分支用完整模筛关闭，最后一条采用原论文完整点分类。没有把未执行的CAS结果写成已经验算。
5. **表中Other points不能漏。** E19的Table10只有5行，另有10个点对在表下；必须合并全部15项才能做本轮回传。只抄对应作者组合问题的解会漏本轮可能相关的X。
6. **有限模数的作用域。** 两个最终周期筛确实排空各自分支；这不否定旧一般mirror模筛障碍。ρ1偶指数仍可沿小解n=4的共同周期保留，最终用了出版高度/整点分类，而非宣称有限筛普适完备。
7. **新颖性未审计。** t素数幂结论和ω(K)≤2整行虽由本轮完整推出，没有查完所有历史消费者。不得把同一旧U改名或样本数量当作原创或全局进度。
