# B699 Pro E：小系数乘任意素数幂子族完成

## 最强结果

本轮完成THIN9：对所有合法 `4≤j≤floor(n/2)`，令 `g=gcd(n,j)`，只要 `j/g` 或 `(n−j)/g` 形如

    dP^a，P任意素数，a≥1，1≤d≤9，

就存在同一个奇素数同除 `binom(n,3),binom(n,j)`。n、j、g、P和指数a都没有上界；不是只检验某个整数范围。

潜在反例的每个约分侧，在去掉任意一个完整素数幂后，余因子必须至少11。一个源窗口的非空分配本身不够；本轮将两个互素源窗口的分配联立，并处理了唯一会留下较小块的端部R=7。

**完整i3未闭合，R7不变。** 这不是全部半素数、全部ω(t)=2或全部平方行闭合；没有全历史覆盖差集/新颖性审计。

## 已完成的链

1. 第一窗口N=(n−1)/λ的两个规范分配a,b都非空；结果式把固定a或b的输入变成有限除子问题。a,b=5,7,9的完整末端为空；孤立3不属于粗块。因此a,b≥11。
2. 旧THREE给L,R>1。本轮对完整端部L/R=5,7,9推导固定系数方程，保留模端部平方的提升同余。58个非空系数类中的57类被全指数周期证书排除；唯一余类是R=7、n=2^v、v≡4 mod2520、7j(j−1)=(n−1)(n−2)。
3. 在这一余类，拆开真实平方行N=[(sqrt(n)−1)/3][sqrt(n)+1]。若某一整块全部落入j或n−j，可化成252个固定三次多项式；全部整数末端仅恢复(16,6)，但它的实际R=1，不是7。故第一窗口的四个交叉分配全部非空，两约分侧各至少有三个不同素因子。
4. 小系数d≤9的素数幂乘积至多有两个不同素因子，先排掉R=7；其余两侧都必须容纳两个互素、至少11的来源块，其中一个只能整除d，矛盾。

## 一般相对高度，不限制n奇部

对同一a,b，有

    8g(n−2)<3μλ³a³，
    27g²(n−2)²<4μ²λ⁶b⁶，
