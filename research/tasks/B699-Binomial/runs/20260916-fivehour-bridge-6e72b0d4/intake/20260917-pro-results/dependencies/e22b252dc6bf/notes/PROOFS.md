# 完整证明：NC3 的不可约三次内容与无头块上限的间隙消费者

研究对象为自然数 n,j，4≤j≤⌊n/2⌋。Common 表示存在奇素数 p≥3 同除 C(n,3)、C(n,j)；NC3 是其否定。日期 2026-09-16。本稿为作者纸面证明；精确代数核验、有限回归、作者第二实现另记，未 Lean、未独立研究者／人类审稿，不声称文献首创。

## 0. 结论、依赖和量词

**IRR。** n 为4倍数，输入合法。令实际 Vandermonde 内容为 H，L=C(n,3)/H。若 L 是2的幂，则 j<n/2，且下述实际三次式 Φ、Ψ=Φ/H 在 Q[Z] 中不可约。特别 NC3 蕴含此结论。

**GAP-HEAD。** T,A,B,X 为任意正整数，

    X² ≥ 2AB³，TX ≥ 4A²B。

令 n=T(AX+B)，j=T(uX+w)，0≤u≤A、0≤w≤B。只要输入合法，则 Common。**不要求 A<T；允许 T=1、偶 T；不使用 ROW、G4 或三次判别式。**

**ROW。** P 为奇素数，f,e≥1，T=P^f、X=P^e，A,B 任意正整数，P∤B，且 P≥5 或 f≥2。满足 GAP-HEAD 两个门槛的 n=T(AX+B)，其全部合法 j 都满足 Common。

**BLOCK。** 任意奇素数 P、f,r≥1，P≥5 或 f≥2，1≤A,B<P^r、P∤B，则

    n=P^f(A P^(3r)+B)

的全部合法 j 成立。头尾各可有 r 个数字，r 与 f 没有大小约束，内部数字可任意。

R7 未变；一般三短槽位、二幂行、规范缺陷、F、min C_s 未受界。新核不是旧核全部参数条件的超集，旧核保留。§7证明新核也不能接着排空旧三个标准短槽位模板。

## 2. 实际内容与整数变换

置 k=n−j，

    F(Y)=Σ_(r=0)^3 C(j,r)C(k,3−r)Y^r，
    H=gcd(F 的四个整数系数)，L=C(n,3)/H。

四个系数均正。Vandermonde 给 H|C(n,3) 和 L≥4。阶乘身份

    C(n,3) C(3,r) C(n−3,j−r)=C(n,j) C(j,r)C(k,3−r)

除去 H 后，对四个系数商作整数 Bézout 组合，给 L|C(n,j)。所以 L 是两个原始二项式的共同除子。NC3 使 L 只能是2的幂。

定义

    Φ(Z)=Z³ F(1−1/Z)
        =C(n,3)Z³−j C(n−1,2)Z²+C(j,2)(n−2)Z−C(j,3)，
    Ψ=Φ/H∈Z[Z]。

反变换 F(Y)=(1−Y)³Φ(1/(1−Y)) 也整系数，故 Φ 与 F 内容相同。这里只需其整数性。

若 n 为4倍数，v=v2(n)、t=v2(j)，直接检查四个系数给

    v2(H)=min(v,t)。

完整情况：t<v 时 j,k 的2赋值都是t。t=0 两者中有一个为3 mod4，相应端系数奇；t=1 两个中间系数2赋值恰为1；t≥2 端系数2赋值恰为t，中间系数不更小。t≥v 时 j,k 之一2赋值恰为v，另一个不更小，端系数的最小赋值为v。

又 v2 C(n,3)=v。若 L 是2的幂，L=2^s，其中 s=v−min(v,t)。因为 L≥4，s≥2，所以 t<v；Ψ 的二次项系数为奇数，因为 v2(j C(n−1,2))=t。尤其 j=n/2 会给 s=1，与 L≥4 矛盾；故严格 j<n/2。

令 g=gcd(n,j)。2^s 恰为 n/g 的2部分。因此

    η=n/(gL)

是正奇整数，并有

    H=ηg(n−1)(n−2)/6。                              (H)

完整 NC3 还知道 η∈{1,3}，但以下新核只用 η≥1，不用它的特殊取值。

## 3. 全部分母的排除：实际 Φ 不存在有理根

### 3.1 一般分母引理

整系数三次式首系数为 2^s、二次项系数奇。任何非整数有理根 a/b（既约，b>0）都有 b=2^s。

证明：有理根定理给 b|2^s，写 b=2^d，1≤d≤s。清除 b³ 后，四项的2赋值分别为 s、d、至少2d、至少3d。若 d<s，二次项是唯一最低赋值项，不可能相消。所以 d=s。这个一般条件本身不推出不可约；(2Z−1)(Z²+Z+1) 就是反向例。

### 3.2 将实际系数再用一次

若 Φ 有有理根 z，则 z∈(0,1)：z<0 时 1−1/z>1，F 为正；z>1 时 1−1/z∈(0,1)，F 仍正；Φ(0)=−C(j,3)≠0，Φ(1)=C(k,3)≠0。

因此 z=a/L，1≤a<L，a 为奇数。记 Ψ 二次项系数为 b2=−3Lj/n，整数性由§2保证。将根代入并除去一个 L，模 L 得

    a²(a+b2)≡0 mod L。

a 与 L 互素，所以 a≡−b2 mod L。由于 0<3j/n<3/2，根只能是

    z=3j/n，或 z=3j/n−1。

第一种直接代入：

    Φ(3j/n)=j(j−1)[4jn−9j+n]/(3n)>0。

第二种令 d=n−2j>0，精确式为

    24n Φ(3j/n−1)=−d[(4n−9)d²−3n²+8n]。

为零就要求

    (4n−9)d²=n(3n−8)。

但

    16n(3n−8)=(4n−9)(12n−5)−45，

所以 4n−9|45。n≥16 时 4n−9>45，不可能；合法4倍数的小端 n=8,12 分别给23、39，都不整除45。根不存在。

有理三次式可约必有一个一次因子，也就是有理根。所以 Φ、Ψ 不可约。IRR 得证。

**边界。** 不可约性需要 L 为2幂这一 NC3 后果。实际 (n,j)=(68,34) 的 Φ 在1/2取零，L=134，真实 gcd=268。不能对全部合法输入直接宣称 Φ 不可约，也不能由“不可约”逆推 NC3。

## 4. 以偏差展开：一次控制任意头块

对任意整数 a、正整数 b，置 δ=na−bj。直接展开有

    6b³ n² Φ(a/b)
       =(n−1)(n−2)δ³
        −3b²j(n−j)(n−2)δ
        −2b³j(n−j)(n−2j)。                         (CENT)

若反设 GAP-HEAD 输入是 NC3，则§1–3成立。取 a=u、b=A，

    δ=nu−Aj=T(Bu−Aw)， |δ|≤TAB， g≥T。

整数 E=A³Ψ(u/A) 不为零，所以 |E|≥1。由(H)、(CENT)及 j(n−j)≤n²/4、|n−2j|≤n，得到

    |E| ≤ |δ|³/(ηg n²)
          +3A²|δ|/[4ηg(n−1)]
          +A³n/[2ηg(n−1)(n−2)]。

逐项保留 η≥1、g≥T、n>TAX、n−1≥TAX（最后允许 TB=1）和 n≥8：

1. 第一项 < AB³/X² ≤1/2。
2. 第二项 ≤3A²B/(4TX) ≤3/16。
3. n/[2(n−2)]≤1，故第三项 ≤A³/[T(n−1)]≤A²/(T²X)≤1/(4TB)≤1/4。

因此

    1≤|E|<1/2+3/16+1/4=15/16，

矛盾。GAP-HEAD 得证。δ=0、u=0、u=A、T=1、偶 T 和所有等号端点均已包含，不需要逐个符号／模提升分类。

## 5. 奇素数的完整整行回传

ROW 门槛使 X²≥2AB³>B²，所以 X>B。P∤B 使 vP(n)=f。若 P≥5 或 f≥2，则 P|C(n,3)（P=3 时指数为 f−1，保留分母取消）。

对任意合法 j，若 P|C(n,j)，直接完成。否则所有P进制层都无进位，j 的每一位不超过 n 的对应位。由于 X=P^e>B，源表示的头尾不重叠；所以同一个 j 可写成

    j=T(uX+w)，0≤u≤A，0≤w≤B。

实际逐数字限制更强，但用这个完整超集即可进入 GAP-HEAD，得到 Common。并未假定用于表示 n 的 P 一定是最终见证。

BLOCK 中 X=P^(3r)，A,B<P^r。因此

    2AB³<2P^(4r)≤P^(6r)=X²，
    4A²B<4P^(3r)≤P^f P^(3r)=TX，

因为活跃源条件保证 P^f≥5，且 P^(2r)≥9。所有 f,r 同时覆盖。

还可用于任意共同数字间隙的单输入：T 可以是1或2的幂，只要实际 n,j 的同一头尾分拆满足 GAP-HEAD。此时没有奇源自动强迫 T|j 和 w≤B，故不宣称整行。

## 6. 可认证的扩大与不能认证的扩大

固定 P≥5，f=1，r≥2，A=B=P^r−1，X=P^(3r)。新 BLOCK 覆盖整行。

对同一个源 P，旧核必须使头块 1≤A'<P，因此唯一可能的切分为 X'=P^(4r−1)、A'=P−1。余尾 B' 至少含 (P−1)P^(4r−2)，故

    A'(B')³≥(P−1)^4 P^(12r−6)>P^(8r−2)=(X')²。

这违反旧核所需 (X')²≥A'(B')³[1+2/(PB')]。所以它严格扩大了**该同源旧消费者**的适用输入，而非只把同一分拆改名。

## 7. 三个短槽位不能靠继续换切分解决：完整方法诊断

考虑上一轮剩余标准模板

    n=P^f(aP^(2e)+bP^e+c)，1≤a,b,c<P，
    (e,f)∈{(2,1),(3,1),(3,2)}。

在相同源 T=P^f 下，尝试任何整数切分 X=P^d，1≤d≤2e，A=floor((n/T)/X)，B=(n/T) mod X。

- 若 d≤e，则 A≥P^(2e−d)、B=c≥1。新条件 TX≥4A²B 要求 P^(f+d)≥4P^(4e−2d)。但 f+3d≤f+3e≤4e，矛盾。
- 若 e<d<2e，则 A≥P^(2e−d)、B≥P^e。新条件 X²≥2AB³ 要求 P^(3d)≥2P^(5e)。对 e=2,3 的全部这些 d，都有3d≤5e，矛盾。

因此唯一可能的 d 为2e，此时 A=a<T、B=bP^e+c。
若新核在这里成立，则 X²≥2aB³，且 2B>a，故 X≥aB。又 TB≥5，使 2≥1+2/(TB)，所以旧核的第二门槛也成立。

**结论：本轮新核不能通过同源重新切分再削掉这三个短模板。** 这是对全部P和数字的证明，不是增加P扫描上限。模板仍未闭合。下一步必须加入新条件，而非继续用这两条门槛调切分。
