# 失败与未解决边界

## 本轮证实的限制

1. 低N次数引理必须保留deg_N≤3。`(N²−4X)²−N=0`给出满足所有引理大小条件、次数为4的无界合法整数输入；11为实际共同素数。这是引理过强推广的反例，不是B699反例。
2. 纯平方消费者不能删掉共素、次数与系数高度范围。对每个未知n选取巨大系数拟合方程不受本定理覆盖。
3. 一般二次式A(N)X²+B(N)X+C(N)不等于本轮已经完成的纯平方式；完成平方改变了变量和源点，不能直接移植288表。
4. 非恒定正次系数内容的结式约束只在deg C_0≤9deg A闭合。内容常数、或常数项次数更高时本轮没有统一矛盾。
5. 例H*=100(N⁴+1)X²+(N⁴+N+1)X−N²∏(N−r)通过本轮保留的几何条件且有合法正实分支。它未被证明为固定核因子，没有给出整数NC点。

## 已比较但没有计作成果的路线

- 再次机械剥离当前预因子：检查当前边界消失负荷，没有获得新严格次数矛盾；未重跑旧核或原样巨型矩阵。不存在新的“所有因子均已剥净”证明。
- 仅凭六条源点命中推断不存在高次曲线：被H*这样的几何模型否证，不能替代整点分析。
- 任意曲线统一整点界：未获得能低于本轮入口的适用常数，未采用额外出版输入，也未把固定曲线有界/有限改称全局完成。

## 仍无界

源n、外层a,b、g=gcd(n,j)、β和粗素数身份／数量／完整指数。每行152是原固定关系的计数上界，不是一个已执行的候选生成器。57族与R7不变，不能由新因子类型筛选推算减少的实际因子数。

## 可重启的判别点

剩余X二次因子必有非零一次项。可对实际二次分量的判别式、平方因子和同一输入各q_r全幂分配建立严格必要条件，或先恢复一个实际小系数因子。任何有理参数化必须保留变分母；任何整数高度必须保留全部系数常数。只有完成这些义务才可登记新的整位置或整族闭合。
