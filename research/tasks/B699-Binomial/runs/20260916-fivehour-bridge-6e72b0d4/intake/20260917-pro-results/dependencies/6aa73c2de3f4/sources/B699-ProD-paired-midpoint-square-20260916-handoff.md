# 可接续断点

## 新接口

1. 同一NC_i中，偶源行2a的中点块有平方精度

   M_(2a)² | (2a−1)²L−s a(a−1)n−s a²。

   第一源行成立时，这对任意Q|q_(2a)等价于Q|j−a。线性候选gcd可能丢失一半的幂精度，不能把它直接当完整中心块。

2. n≥80、3j≠n+2：

   56 T0 h0 h4 (gM2)²M4 < s1³s3s4 n，

   h0为L−s完整p<i部分，h4为|9L−2s(n+2)|完整p<i部分。准确整数商没有n≥80的截断，但必须非零。

3. 两底t且H02⁺/i5可令M2=q2，得112T0(gq2)²M4<375n；原生D6/i6常数为3n。两底接口的旧端点前置不可删。

4. 前轮R=f3M4V=sα−3gt，再有

   M4 | s s_i(n−4)e4f4−3g f3 V。

   这是同输入的第二层约束。要判断能否使V4=K4/M4²、U0=(L−s)/(M2²f3f4)中的某个值域真正受控，或者形成合法下降。

## 不应重复或夸大

- 不能宣布两底t已经闭合；本轮只排除违反联合界的条件区域。
- 中点平方的等价重写不是新增原反例数量；真正的充分消费者还需要非零、整数商与上界。
- 3j=n+2时新六次式为零。H02⁺避开它；一般目标必须单独处理。
- i4不支持第五源行；i5和i6的小部不同。原生D6要求额外模5条件。
- i7/H023的M6²上界不是H023末端已完成。
- 新旧G/PAIR不包含。只做了指定有限域比较，未做全部历史并集审计。
- 形式量级模型没有真实j和源gcd，不是反例，也不否定加入真实整除后的下降。
