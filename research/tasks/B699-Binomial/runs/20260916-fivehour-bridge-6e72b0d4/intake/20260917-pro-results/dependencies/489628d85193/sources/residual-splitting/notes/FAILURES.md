# 失败、反向控制和不可扩大结论

## 1. 合法域正性修正

第一次生产生成尝试对X=6+x,Y=6+y检查全系数非负，发生断言失败。这不是合法域下的反例，只说明所选表示不能直接给出全矩形正系数证书。最终改用准确半行X=6+x,Y=6+x+y，三核全部260系数严格正，并用另一实现重建。辅助Q也另有15项正展开，防止只知Q<上界却错误推Q²界。

最终证书不使用失败展开；未将中断/失败记为PASS。PROOFS保存了准确平移及上界的独立解析证明。

## 2. 其他分配组没有闭合

occupancy_probe尝试row3其他二元集合及row4三元集合；某些核有负系数或合法零曲线。部分计算到row4的{0,1,2}、D36时触发工具超时。部分日志、发现核保留；未完成的探针不是完整搜索，也不证明任意次数不可能。

新定理只排三条明确分配组，不宣称row4内部组也必须非空。

## 3. 严格历史差集没有证明

strict_example_probe只在给定小域寻找首行模型：g为37≤g<600的素数，2指数3..30、3指数2..20等脚本明示域。过滤后6行，首行合法模型0，展示点0。该结果不证明无严格差集，也没有把有限诊断当新全域排除。

本轮没有完成与全项目所有已交付消费者的差集审计。新逻辑比上一轮“至少两个余数位置非空”更强，但不能凭这个语法差异就宣称存在逃过全部旧消费者的原整数输入。

## 4. 已知弱模型不是反例

n155648,j65303,g19,t105,L37905通过第一行规范身份，但完整r2被实际共同素数8647排除。该模型来自已给定旧材料；本轮重新核对。它不能作为原反例，也不提供保持NC的较小行L和新j′。

本轮回归中的部分避免输入只是对真正不整除C(n,j)的源素数幂做加权整除；其它源素数可以成为真实见证。不能把这些非真空检验叫作NC反例样本。

## 5. 目标、完整幂与转移边界

n56,j12给t4=3/5、t5=3；规范参数依目标变化。未使用NC5=>NC4或NC4=>NC5。

n128,j26,row3,Q125和n704,j6,row4,Q25的实际目标进位，在错误降一次指数后消失。端点5不得根基化或降低一次幂。

i5→i6另要求n mod25≥5保证见证不是5；没有这个条件，不可仅凭相邻二项式恒等式提升素数阈值。

## 6. 剩余无限量词

omega5*(t)≥2仍允许两个或更多底数及其指数共同无界。t≥77是必要下界，不是把全部剩余区域变为有限。精确两底时q2²|L−s仍没有t上界；不构成保持NC的下降。i4/i5整指标以及i6/i7/i8一般区域均未闭合。
