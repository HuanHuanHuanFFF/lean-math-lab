# 失败、修正与能力边界

## 1. 一个已修正的发现器错误

首次通过q≡3u(A−u) (mod T)反求n时，错误地断言这保证n≡0 (mod T)。
但q可能与T不互素；不得取消q。实际执行得到AssertionError，失败源码存为
`notes/probe_first_window_failed.py.txt`。最终生成器显式检查n%T==0，不以该错误逆推作数学前提。

## 2. 清分母的方程不是原第一窗口

1,111,112个小参数q测试恢复2941个经过A²清分母的候选；其中只有881个通过原来的n−1|3j(j−1)。
例n=27622,j=4620,A=6通过清分母式却不通过原式。正式回归输出只把881项标为真实W1。
这一差别不会影响KERNEL证明：其使用方向始终为原W1⇒清分母式。
没有将第一窗口兼容点称作两个窗口解或NC3。

## 3. 已放弃的较重接法

初步准备先处理E5的Q=1/2并做二次曲线归约；精确多项式除法显示新余式还含完整因子T，
因此转为直接整数大小矛盾。没有进行相应曲线/对数计算，也无需按P扩表。

## 4. 未解决范围

- 至少三处非零数字，或块间隔不够长，尚不能归入本核。
- 一般二幂行没有奇素因子P，不能使用RADIX2的存在前提。
- 三窗口规范缺陷、F、min C_s、四个平方邻数分配仍可共同无界。
- 尚未证明任意NC3必有一个奇素因子使n在其进制下足够稀疏。
- 未完成与全部历史ROW/TW/子族消费者并集的严格差集审计；新增可登记的是无界模板的完整证明、
  变量商约消及完整T增益，不用样例数量宣称新增全局区域有多大。

## 5. 证据等级

无限证明由PROOFS的整数推导承担。程序的符号身份可精确核对有限代数事实；小行扫描只是回归。
不同实现由同一会话编写，不等于第二独立研究者或人类审稿。没有Lean、人工审稿、新颖性认证。
