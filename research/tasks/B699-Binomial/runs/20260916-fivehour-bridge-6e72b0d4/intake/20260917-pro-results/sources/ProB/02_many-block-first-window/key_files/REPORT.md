# Pro B：任意多块的首窗口代数禁形与整行排除

日期：2026-09-16。R7={3,4,5,6,7,8,9}不变；本轮没有新增整指标闭合、一般i3绝对有限性或Lean验收。

## 最强新结论

令P为奇素数、f≥1、T=P^f，并要求P≥5或f≥2。任意k≥1、0≤a_i<T，端点a_0,a_k为非零P单位，置

    S=Σa_i，S₂=Σa_i²，x=P^e，n=TΣa_i x^i。

只要满足下列任一明确条件，这一行的全部合法4≤j≤⌊n/2⌋均有同一个奇素数同时整除C(n,3),C(n,j)：

1. 一般路径（全部f,k）：

       x ≥ 6S(TS+1)(TS)^(k+1)。

2. 较短路径（gcd(k,f)=1）：

       2x ≥ 3T²S₂²。

k、f及各个数字块均可增长；复杂度并未限制为三位或另一张有限档位表。新模块统一覆盖任意多块，但要求明确的大间隔。

这不是整个i3的有限化。短间隔输入、一般二幂行和一般规范缺陷仍未处理。与全历史消费者并集的差集没有审计，不按样例数量声称削掉了新的完整指标或已认证的残余核心块。

## 本轮最有价值的信息增量

上一轮的两块核使用两个窗口作二次约消，获得完整T(n−2)大除子。本轮检查三块后改走另一条路：先严格排除首窗口的“恒等相消”，再用整数伪除法或结式直接结束。

设A(X)=Σa_iX^i，B(X)=Σb_iX^i，0≤b_i≤a_i、B≠0,A。对全部次数和全部f证明

    T A−1 ∤ (T B)(T B−1) 于Q[X]。

关键是固定源P的加权赋值。最低权项的最小/最大下标在乘法下相加。当最高数字b_k被P整除时，乘积的最低下标跨度小于k；不被P整除时，首窗口的假定整除迫使b_k≡a_k modP，转到补块A−B即进入前一种矛盾。

这个证明不需要TA−1不可约。特别补上了“余式可能作为多项式为零”的完整分支，而不是依靠有限次数实验。

一般路径把非零整数余式的系数范数界写成显式x阈值；快速路径在gcd(k,f)=1时证明不可约，并用Sylvester结式和Hadamard行范数界，将所有数字分配一起控制。

## 返回原题的全部量词

NC3⇒4|n和W1:n−1|3j(j−1)。P≥5或f≥2保证P|C(n,3)。若它不是第二二项式的因子，全部P幂层必须无进位。阈值保证x>T，块互不重叠，因此同一个j必须写成T B(x)，0≤b_i≤a_i。合法性排除两个端点；两个代数路径均证明W1失败。

不匹配数字支配的j由P本身作共同素数，匹配者由首窗口的完整奇除子

    Z₁=(n−1)/gcd(n−1,3j(j−1))>1

结束。没有在不同j之间替换输入，也没有删掉p=3或完整幂。P=3,f=1不属于这次多块消费者；旧两位行中的该支仍有其原来的独立证明。

## 相对旧链的真实变化

- 至少三个非零块时，不再要求把它强塞入上一轮的两个宽块形状；块数k+1可以无界。
- 对f=1，较短路径允许任意k；充分条件只按S₂及T计算，不枚举(P进)数字分配。
- 一般路径甚至不要求gcd(k,f)=1；但它的间隔阈值更大，不能混用较短阈值。
- 新链不使用第二窗口、ROW128、α形状、旧有限高度表、BFT/Padé/BEG/对数形式/素数分布输入。它是一个更独立的行消费者，不等于已经测得Lean工程成本下降。
- 没有证明所有旧ROW行界允许的输入都能被新模块处理，也没有证明新模块与所有旧结论的差集非空。可确定登记的是新全次数代数前置及其完整整行连接。

## 失败边界

- 小间隔确有第一窗口兼容输入：n=1180,j=525；第二窗口失败、实际gcd=417012，不是NC3。
- f,k不互素时快速结式可能为零：9(X²+3X+1)−1=(3X+1)(3X+8)。一般非零余式路线仍有效。
- 最高块小于T和源P的条件不能不经证明删除。
- 一个泛化“两个二次多项式窗口只有六模板”的候选被准确的额外二次族否证；未采用该错误命题。
