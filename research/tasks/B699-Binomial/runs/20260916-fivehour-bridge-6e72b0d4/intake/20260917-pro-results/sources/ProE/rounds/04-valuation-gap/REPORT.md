# B699 Pro E：相对估值条带 r≤8 闭合报告

## 本轮最强交付

对全部合法 4≤j≤floor(n/2)，证明

    NC3(n,j) ==> v2(n)≥4v2(j)+9.

因此 v2(n)≤4v2(j)+8 的整个数对子族闭合，n,j 不设上界。全局 R7 仍是 {3,4,5,6,7,8,9}；没有完整指标新增，没有一般 i3 有限化。

这是一个**相对估值**消费者，不是“只验证 n 到某个上限”，也不是把已有无条件 v2(n) 下界再作为新贡献。尚未做与全部历史消费者的覆盖差集审计，不能据此声称具体新整数或文献首创。

## 路线变化与实际贡献

最初目标是 ω(t)=2。保留两窗口分配的整数因子表后，没有从中得到消去两个粗素数的一般矛盾；不登记该目标完成。

实际转向 r=v2(n)−4v2(j)。旧 ROW 的乘积恒等式使 r≤8 下的规范余量系数 u,z 有绝对上界；结合完整分母 α=c2^s、高估值奇偶结构及模3条件，e=v2(j)≥2 时首先强迫 gcd(n,j) 的奇部 m=1，再仅留下37个固定三次方程：

    μzH³+μλH = uc2^(r−1)Y³−uY，Y=4^e.

这时不是研究变系数 Pell 方程，而是**固定系数三次式 + 二幂序列的完整模周期覆盖**。37个方程全部由周期60/180/360的精确证书排除，最大模数673。所有 e≥2 均覆盖。e=0,1 的完整小末端也已排空。

最强新方法接口是：先用原题的乘积质量界压缩可变系数，再对全部固定系数方程作全指数模覆盖。若只把问题写成一簇曲线而系数不受控，这条路不能启动。
