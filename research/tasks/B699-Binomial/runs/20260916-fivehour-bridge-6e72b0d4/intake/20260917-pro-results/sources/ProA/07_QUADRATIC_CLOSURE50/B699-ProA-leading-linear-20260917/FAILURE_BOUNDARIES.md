# 失败、改法及仍未知的边界

1. **不能随意删实际根。** 在算术转移中Z_r必须是全部实际零值；把一个真实零点当“非命中”会令E_r=0、失去所有高度控制。五双一单子模式只用于11条独立线性方程识别系数，未用于改变E_r。源值0/1的简单根模型足以显示这个错误。
2. **只有四行双命中时系数仍连续。** 原线性首系数问题不是一张四行有限表能直接解决；本轮先用改紧后的范数与两个小核排除秩≤10，再转为完整11点模式。没有把一个有理参数铅笔冒称有限候选集。
3. **发现程序曾出现浮点污染。** 初次分数自由回代的空sum产生int0，随后除法引入float；真实失败日志为`logs/weight5_probe_initial_error.txt`。改成明确Fraction零后重跑，当前接收也强制整数/Fraction；未用失败结果。
4. **模秩下降不是有理秩下降。** 72个低秩模式有额外精确整数核/独立性补证；91+2个六双点模式的模秩不足处也做Fraction复核。辅助素数1000003不成为原题支持上界。
5. **常数首项/首两行不为零并不足以单独覆盖所有关系。** 199+3个模式真正消费旧C31。3个模25和5个最高项定号模式由各自精确证书处理，不把全体笼统登记成PC排除。
6. **大n有效界路线被替代。** 曾得到统一g界后借U25形成巨大n上界；其底部未扫描。最终通过普通二重插值直接消掉二次分量，两支均闭合，不把未扫描有限界算成整类已完。
7. **对角条件不能偷弱化。** 最后一轮插值对对角点也要求F_X=0。只用权2的对角二重条件会允许F_X≠0，无法推出除去光滑H后的商在该点为零。四重引导阶段可用权2，最终阶段不行。
8. **没有恢复旧未知G。** 本轮16,440个小关系是低次数模式的完整分类，不是旧152目标核的实际因子。新辅助由确定的最大子式/Cramer选择存在，不声称已验全部未知系数。原G与其实际因子、逐行候选求根器仍未恢复。
9. **三次以上仍有几何空间。** 证明§9的显式三次模型有15个源命中、五次评价满秩12，并在N=10^8处有合法尺度的正实根。模型不是整数NC9反例，也没有被认定为实际G因子，更不声称满足全部历史算术条件。
10. **当前未界量。** 57个α模板与R7不变；一般n、a,b,g,β及粗素数支持仍无绝对界。真正剩余的是X次数至少3且至少13命中，或12命中含奇点的分量上的整数点。分量上界50不能替代每行152目标，也不是50个有限n。

下一便宜判别：按普通源点重数/奇点分别研究13及以上命中的最低三次关系；必须先检验新的加权空间能否给出严格大小增益，并完整处理共同因子。不要重跑已闭合的18,900个模式、旧50型或历史大矩阵来冒充推进。
