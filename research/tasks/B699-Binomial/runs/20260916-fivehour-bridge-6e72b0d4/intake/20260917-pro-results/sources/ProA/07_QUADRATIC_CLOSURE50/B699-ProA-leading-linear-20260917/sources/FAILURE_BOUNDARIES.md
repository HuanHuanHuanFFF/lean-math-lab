# 失败边界与剩余量

1. 新“至少四行双命中”不是充分NC条件；它只排除至少三行单命中的旧几何模型。未知核因子仍可能有高次、多命中分量。
2. 完整非命中粗部分必须通过`E_r=∏非零H(r,v)`剥离，不能直接认定全部q_r集中在零根。TRANSFER保留q_r/gcd(q_r,E_r)，全幂诊断包括被部分剥离和全部剥离的实例。
3. MQ4保留X²首系数为**常整数**、N次数≤4及l1高度≤2^1290000。一般A(N)X²+B(N)X+C(N)未闭合，不能不加证明套用50型。
4. 新覆盖分量上界61来自加权次数下界5；不是恢复出的61条曲线，不是实际删掉恰好15个因子。152个潜在目标/行与57个α模板、R7仍不变。
5. 新PROOFS §8给出不可约几何模型H_*，一行单命中/五行双命中、变首系数、正次系数gcd常数、合法尺度的正实分支。没有整数NC9点，也没有证明它是实际核因子；不是原题反例。
6. 常数小到中等的18型/50型检查不是n扫描。没有执行巨大整数核恢复或实际曲线整点算法。

## 路线探针

对3240个“每行恰取两个值”的模式，仅用横纵边界线因子作LP发现探针，浮点解中523个有正次数差，其余没有这个数值信号；最小报告差约−1/7。该输出是有限数值诊断，不是精确LP上限证明，更不是任意多项式路线的否证。脚本、完整数值输出和日志保留，不进入数学接收。

曾考虑加入其他合法域正斜线；未执行该扩池搜索。转向三单行与有理系数插值后取得了完整消费者，因此没有继续大规模扩池。

## 仍无界

n、a、b、g、β与粗素数身份、数量、完整指数。未知共同零集中的变首系数/更高N次数混合分量尚未控制；无整个H012有限候选集，无NC保持的下降。
