# B699 · Pro B：两窗口唯一模商与任意尾块整行

## 最强结论与前沿

令 P 为奇素数，f,e≥1，1≤A<P^f，B≥1，P∤B。若 P≥5 或 f≥2，并且

    P^e ≥ 3AB²，

那么 n=P^f(AP^e+B) 的全部合法 4≤j≤⌊n/2⌋ 都存在同一个奇素数 p≥3，同除 C(n,3)、C(n,j)。

B 没有位数或结构上限，不要求 B<P^f；A 也可以含多位，不要求其为P单位。门槛保证 B<P^e，因此真实源数字分块没有重叠。用于表示的P不必是最终共同素数。

没有新增完整指标。R7={3,4,5,6,7,8,9}；一般 i3 仍无绝对有限化。本轮证据等级为作者纸面推导、确定性代数与算术检查、作者另一实现；未Lean、未独立研究者或人类审稿。

## 1. 相对上一轮，真正改变的是哪个前置？

上一轮 many-block 有全次数的首窗口多项式禁形，但数值消费者要求等槽位和大系数阈值；更早两窗口核还要求两个块都小于T，并用X≥T³。

本轮保留同一个输入的第一窗口商，不再只给它一个大小上界：

    q=3y(y−A)/(n−1),   q≡3u(A−u) (mod T),
    0<q<T。

它被迫等于该剩余类的唯一正代表，故

    q=3r−Th,   r=u(A−u),   h≥0,   Th<3r。

于是第二窗口的同一线性余式恰为

    R=−T L,
    L=12rΔ+2h(TΔ+4u−2A),   Δ=Aw−Bu>0。

正文证明 0<L<n−2；因T是奇数且T|n，两个窗口却要求 n−2|L，矛盾。

由此得到纯整数核：

    T≥3奇，1≤A<T，B≥1，X≥3AB²，
    n=T(AX+B), z=T(uX+w), 0≤u≤A,0≤w≤B,0<z<n

不能同时满足 n−1|3z(z−1)、n−2|6z(z−1)(z−2)。

它无需素性、ROW128、α形状或完整NC3。q的模约化和完整T消去是新连接；旧的三次除二次恒等式不重复计功。
零Δ、u=0/A、A=1均显式结束；B=1不能套用粗界，另外用了一个三次正分解。不存在未列出的有限底部。

## 2. 回到完整原题与新增形状

源P出现于C(n,3)时，NC3强迫所有P幂层无进位，因而同一个j必有j=P^f(uP^e+w)，u≤A,w≤B。其余不满足数字支配的j已由P本身给出共同素数。两个集合合起来覆盖全部合法j。
P=3,f=1不包含在ROW中；该素数可能被3!取消，不能假装有无进位约束。完整p=3高幂保留。

### 任意复杂尾块的显式族

    n=P^f[(P−1)P^(2b+2)+(P^b−1)], P≥5, f,b≥1。

这个整个行族成立；尾块有b个非零数字，b可无界。
f=1,b≥2时，若固定同一源P，上一轮等槽位消费者只能取槽距1、x=P，其两个阈值都不成立。因此确有相对上一轮这两个特定消费者的严格扩展。
没有证明它超出全部历史ROW/TW或换其他素数的消费者并集；不能把每一行都计成全局未知域的新删除。

### 最高位的必要限制

设NC3且P|n为活跃源素数，最低位指数f、最高E、次高F、最高数字a，则

    P^(E−f)<3aB²，尤其 E+f≤2F+3。

它对任意复杂尾部成立，不只针对恰好三位。不过F仍无界，绝不是绝对高度。

### 高次幂之后的算术行区间

P≥5，1≤a<P，E≥2，若r为正P倍数、r<P^E且3ar²≤P^(E+1)，则n=aP^E+r整行成立。
它不要求整个区间采用同一个v_P(r)，原题消费者逐一采用实际完整指数。

## 3. 第一窗口兼容不是空话

B=8t+4,t≥0，取T=11,A=8,u=3,w=B，

    X=(825B²−31B−4)/8,
    n=11(8X+B), j=11(3X+B)。

全部参数合法，n为4倍数，X≥24B²，第一窗口恒成立，商q=1；第二窗口余式给 L=1340B−32∈(0,n−2)，故全部排除。
B从12起超过T，不能套旧的双小块限制。t、B、n,j均无界。这个族不是Π解，更不是反例。

展示t=1：n=1,302,796，j=488,631，X=14,803。实际共同素数651397的素性已完全试除，两个原二项式的赋值已精确计算；没有构造巨大的第二二项式。
该展示可能已被其他旧消费者处理，不额外计作严格残余核心差集。
