# Pro B：实际内容非零性、带符号商与更宽的整行尾块

## 最强结果与当前前沿

作者纸面证明得到：P 为奇素数，f,e≥1，T=P^f，1≤A<T，B≥1、P∤B；要求 P≥5 或 f≥2。令 X=P^e。如果

    X≥AB，TX²≥AB²(TB+2)，

则 n=T(AX+B) 的全部合法 4≤j≤⌊n/2⌋ 均有同一个奇素数 p≥3 同除 C(n,3)、C(n,j)。简单充分条件是 X≥AB、X²≥2AB³。尾块 B 的位数、非零数字个数不受限，所有原始素数和指数均未固定。

它包含上轮同一源表示的 X≥3AB²，并在固定A的尾部长度上由平方根量级推进到2/3次幂量级。显式族

    n=P^f[(P−1)P^(3b+1)+P^(2b)−1]，P≥5，f,b≥1，

全域满足新判据，却全域不满足上一轮同源门槛。没有审计全历史消费者并集的严格差集，不能据此宣称每个行都是此前残余核心中的新删除。

进一步，n=P^f(aP^(2e)+bP^e+c)，1≤a,b,c<P 的等距三位行，全部 e≥4 已闭合；P=3 时全部 e,f≥1 闭合。若 P≥5 仍有反例，(e,f)只可为 (2,1)、(3,1)、(3,2)。它们的P、数字系数仍无界，未被排空。

没有新增完整指标，没有整个 i3 的绝对有限化。R7={3,4,5,6,7,8,9} 不变。未Lean、未独立研究者或人类审稿；不主张文献首创。

## 本轮最有价值的连接

旧商法依赖 q<T，短间隔会出现负的 h=(3u(A−u)−q)/T。本轮没有假设这种提升仍非负，而是返回实际三次多项式F、系数内容H及L=C(n,3)/H。

在完整NC3下，变换 Ψ(Z)=Z³F(1−1/Z)/H 的首系数为2的幂L，二次系数为奇数。每个非整数有理根的既约分母因此必须恰好等于L。

当头块分母A<T|g时，旧g⁴<3n与L=n/(cg)共同排除这样的根。对同一个原输入，第一窗口商约出的余式 R 满足

    R=−6cg(n−2) A³Ψ(u/A)。

所以它是6cg(n−2)的非零整数倍，不再只知道W2的较小除子。另一方面，新门槛对全部正负提升给 |R|<6T(n−2)。g≥T，矛盾。

新NC3核甚至允许T为偶数；用于奇素数整行时，再通过完整无进位表示恢复同一个j。不把两个投影等同于NC3，不将L等同于实际gcd。

## 最小依赖闭包

Legendre完整层→原NC3的4|n、α=c2^s与W1；实际四个系数的Bézout/内容桥；旧实际三次判别式及直接2赋值→L与g⁴<3n；新根分母与内容余式→带符号大小界→原题消费者。

三位的极低3分支另外调用并在证明中重列旧ROW-3。P=3,f=1从不被错误地送入数字支配；仅在特定三位结构中单列消去。

没有BFT、Padé、BEG、对数形式、椭圆/超椭圆求解或素数分布输入。官方mathlib文档仅用来核对Legendre/进位的标准陈述，不等于新Lean验收。旧原ZIP按原字节保留，未运行旧全链。

## 失败与探针

1. 不加NC3的零余式禁形是假的：n=28,j=14,T=7,A=3,B=X=u=w=1 给R=0；实际Ψ在1/3取零。必须用L为2幂的原题后果。
2. n=3916,j=1045是真实W1例，q=53,h=−4，旧非负提升论证不可用。它有实际共同素数3，且违反完整α形状；不是Π或NC3见证。
3. 新两个门槛不覆盖全部短间隔三位。P=11、f=1、e=3、a=b=c=10 是门槛未通过的精确例，不能将e≥4删除。
4. 在P≤1000和剩余三个指数模板中，按旧ROW-3先压缩奇部，再作1,670,147个有限参数检查，只找到P=181的三行；v2(n)为30或31，没有落在已读D的v2(n)≥37残余核心。该探针不证明更大P无行，也不构成新的整域覆盖证书。它提示下一轮不应再单纯扩大数字系数。
5. 探针初版误将大候选数组打印到工具，显示被截断；磁盘结果已写完。随后改为摘要并完成重新运行。这个显示失败没有作为接受链证据；默认重放不执行探索脚本。
