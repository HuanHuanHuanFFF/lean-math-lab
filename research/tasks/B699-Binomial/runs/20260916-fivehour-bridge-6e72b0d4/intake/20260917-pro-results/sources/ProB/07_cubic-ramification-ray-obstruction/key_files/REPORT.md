# Pro B：三次分歧支持与两个规范分支的排除

## 最强结论与R7

本轮转向实际三次式的分裂域，不再给固定C_s扩表。完成了全参数的局部分歧分类，并在两个底域上接回原题。**没有新增整指标闭合，没有一般绝对高度；R7={3,4,5,6,7,8,9}不变。**

对全部合法n,j，计算实际三次内容

    F(Y)=Σ_(r=0)^3 C(j,r)C(n−j,3−r)Y^r，H=content(F)，
    Ψ(Z)=Z³F(1−1/Z)/H=LZ³−bZ²+cZ−d，
    I=b²−3Lc，J=2b³−9Lbc+27L²d，Δ=Disc(Ψ)>0。

令G6为gcd(I,J)去掉全部2、3幂后的整数。本轮证明：

> **G6为整数立方，且Δ为平方或5倍平方 ⇒ 存在共同奇素数p≥3。**

这些条件不固定n,j或C_s。接受这个消费者时，只需四数gcd、整数多项式、整数平方/立方判断，不必分解n或巨大C(n,j)。但其无限证明新增使用标准全局类域论，不能称为初等证明或廉价Lean前置。

等价的NC3规范分支排除是：

    R=3^a w³，3∤w，且3λU=z²或5z²，整个分支不可能。

a,w,z,g与三个C_s都可无界；这不是“只算两个固定C”。条件依赖j，不宣称它给每个指定n的整行。

## 1. 本轮真正改变的接口

NC3的实际Ψ不可约，L为2幂、b奇。用原规范残量R,U,F0=C0C2,t=(γ−β)/(2C1)，新接口为

    I=9RF0/(cα²λ)，J=54Rt/(cα³λμ)，
    Δ=27R²U/(cα⁴λ³μ²)，gcd(RF0,t)=1。

因此p≥5的共同不变量赋值恰为v_p(R)。若该指数为3的倍数，把根除以相应p幂后得到可分约化；若不是3的倍数，根赋值分母为3，产生三次全分歧。

令S={p≥5: 3∤v_p(R)}、q_R=∏S。对Ψ的分裂域E与二次预解底域K（Δ平方时K=Q），本轮严格证明：

- E/K是非平凡循环三次扩张；
- p≥5处的三次分歧恰来自S；
- 2上方全部分裂，p≥5且p|U上方也全部分裂；
- 导子整除27q_R O_K。

**R中的任意整立方倍数不再进入导子，U的平方因子不改变底域。** 这是在数域分类接口中取消指数，而不是声称原始n,j或这些因子已经受界。

类域论将此变成一个有限射线类群的必要条件：必须存在一个非平凡三阶特征，杀掉上述完全分裂素理想，并在二次自同构下取逆。对给定K与S这是有限群问题；K和S本身仍可无界，有限候选扩张也不等于有限候选整数输入。

## 2. 完整消费者怎样结束

当S为空，导子只需模27。

- K=Q：2生成模27的单位群及其符号商；完全分裂要求杀掉2，三阶特征只能平凡。
- K=Q(√5)：先用范数欧几里得除法证明普通类群为1，不调用类数表。模27的648个单位全部由18个理性单位与φ=(1+√5)/2的72个幂生成，交为±1。理性单位又由2生成，而2完全分裂、φ是全局单位，故整个三阶特征平凡；不存在所需扩张。

两条支路覆盖所有相关指数；没有用n或C_s的扫描上限。完整有限单位群的证书附648个分解见证，另一实现用2×2矩阵重新核对。

此外完成一个可变素数消费者：Δ平方、3∤Δ，S={p}时，NC3必须有p≡1(mod3)且2^((p−1)/3)≡1(modp)。反向不成立即可证明原题。p没有固定上限；并未宣称所有p都不满足此同余。

## 3. 严格失败边界：不能只依赖一般三次式

确切多项式

    16Z³−23Z²+9Z−1

不可约、有三个(0,1)内实根，首项为2^4、二次系数奇、模2倒数有单根、gcd(I,J)=1、判别式229；反变换甚至为正系数的1+8Y+6Y²+Y³。

它的Q(√229)上非平凡循环三次扩张表明：一般二次域的反变射线三阶部分确实可能非空，不能把前面两个底域的结论推广为所有域。

**它不是B699反例，也不是同一n,j的投影弱解。** 实际系数必须满足

    nI=3L(b−c)，jI=b(b−c)。

该多项式恢复出672/97、322/97，非整数。这是下一步必须保留的额外算术，不是可以忽略的坐标变化。

原始n≤1000、4|n回归中的三个新谓词命中，全部是已由历史结果覆盖的中心输入。**本轮没有认证与全部历史消费者并集的非空差集。** 确定增量是一般分歧支持公式、有限类群必要接口与完整分支证明；不以这三个例子累计新增未知覆盖。
