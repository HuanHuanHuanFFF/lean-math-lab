# Discovery record

The final proof uses only the explicit K30 factorization, not any claim about exhaustive search.

interpolation_seed.json records a degree30 target with origin/source1 order10 and source2..5 minimum orders10,7,6,5. The forced line factors are x^5 y^5 (x-1)^4(y-1)^4(x-2)^3(y-2)^3. The remaining degree6 polynomial is HUV.

Run `python3 -S -B discovery/interpolation.py` to verify the 33×28 residual system, its exact rational rank27, and the recovered integer polynomial. This optional discovery check is separate from the proof replay, which re-expands and validates the final kernel without trusting the seed.

Earlier finite catalogue checks did not find a sufficient growth certificate. They do not rule out other kernels, combinations, or methods and are not used as impossibility results.
