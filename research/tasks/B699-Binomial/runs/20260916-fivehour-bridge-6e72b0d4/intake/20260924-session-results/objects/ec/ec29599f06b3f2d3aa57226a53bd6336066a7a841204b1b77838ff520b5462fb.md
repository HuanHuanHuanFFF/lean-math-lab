## 0. 定理、原始量词与范围

固定自然数 n,j，令 k=n-j，7≤j≤floor(n/2)。定义 Common6(n,j) 为存在
同一个素数 p≥7 同除 C(n,6)、C(n,j)，NC6 为该命题的否定。

**定理 C16-TAILS。** 若 n≡1280 或1530 (mod1800)，则 Common6(n,j)。

两模类分别称 A 尾、B 尾。本定理不限制 q2/q5 分配，不假设十倍平方、
RES10、纯槽或混合槽。p≥7 与原题 p≥6 等价，因为6不是素数。
“整行”是 ∀j∃p；不宣称存在一个与j无关的p覆盖整行。

反设同一个原 (n,j) 为NC6。以下所有必要条件都保留这个输入，没有NC下降或
替换数对。令

```
s6(m)=2^v2(m)3^v3(m)5^v5(m), q_r=(n-r)/s6(n-r),
g=gcd(n,j), alpha=n/g.
```

## 1. 完整源层与原生 alpha 模板

对每个素数p，阶乘计数给

```
vp C(n,j)=Σ_{e≥1} [j mod p^e > n mod p^e].
```

若p^e是q_r的完整幂（0≤r≤5），则p≥7；6!不含p，所以p|C(n,6)。
NC6使其原完整层无进位，因此

```
j≡b, k≡r-b (mod p^e), 0≤b≤r.                 (SRC)
```

不同q_r的素数支持互斥，因为其素数大于窗口差5。r>0时q_r与g互素。
没有把SRC反向当作充分NC条件；更高目标层未被虚构成更大原源幂。

这里直接重证所需 alpha 模板，不借NC5或旧LCM合同。
由 j*C(n,j)=n*C(n-1,j-1)，以及 gcd(j/g,alpha)=1，得

```
alpha | C(n,j).
```

若p≥7整除alpha，则p|n并且p|C(n,6)，违反NC6。故alpha只含2、3、5。
A尾满足3∤n、v5(n)=1；B尾满足v2(n)=v5(n)=1。因此

```
A: alpha=c*2^a, c∈{1,5}, a≥0;
B: alpha=c*3^a, c∈{1,2,5,10}, a≥0.            (ALPHA)
```

a可以为零，g可以继续含相同底数；BFT不要求余因子与底数互素。
主证明只用g≥1，不采用旧g≥7、unit-coarse或G7结论。

## 3. 原生QIG的自含重证

本节不直接把旧QIG当成未解释的黑箱。
令V=q0q1q2q3、T4=∏_{r=0}^3 s6(n-r)，于是

```
V=n(n-1)(n-2)(n-3)/T4.
```

定义五个整数 a_t=C(j,t)C(k,4-t)，t=0,...,4。
对任何p^e||q_r，r≤3，(SRC)给j≡b、k≡r-b；因4>r，两个下降积中至少
一个含一个完整p^e，且t!、(4-t)!不含p。因此p^e|a_t。所有源互素，所以V|a_t。

定义整数四次不变量

```
I = 12a4a0 - 3a3a1 + a2²;
B = 72a4a2a0 + 9a3a2a1 - 27a4a1² - 27a3²a0 - 2a2³.
```

置J=jk、R=J-n+1=(j-1)(k-1)、D0=(n-1)(n-2)。逐系数身份为

```
8I   = J R (n-3)(n-2),
-16B = J² R (n-3)²(n-2),
256(B²-2I³) = J³R²(n-3)³(n-2)²(D0-J).          (QIG-ID)
```

三个身份在本轮由标准库有理多项式算术完整重验。
I/V²和B/V³为整数；而J,R,n-3,n-2,D0-J都正，故

```
G=(B/V³)²-2(I/V²)³ ∈ Z_{>0},  G≥1.
```

因为0<J≤n²/4，R随J递增，且J³(D0-J)的导数为J²(3D0-4J)>0
（n≥14）。因此可把J推到n²/4。将V表达式代入并准确约分，得到

```
G ≤ T4^6 (3n²-12n+8) / [2^20 (n-1)^6 (n-3)^3].
```

所以任何NC6必须满足

```
T4^6(3n²-12n+8) ≥ 2^20(n-1)^6(n-3)^3.          (QIG-NC)
```

其严格反向是原输入充分消费者，不要求额外平方条件或任何源纯分配。

## 4. 关键终止引理：不是继续枚举j，而是恢复原n

定义实际完整幂：

```
A: u=v2(n),   v=v3(n-2), P=2^u, Q=3^v;
B: u=v2(n-2), v=v3(n),   P=2^u, Q=3^v.
```

这里u,v不是alpha模板指数a；g可以继续含同一底数。两尾都有u≥3、v≥2。
由准确小部：

```
T4=10PQ (A),     T4=30PQ (B).                    (T4)
```

**引理。** n≥8192的尾部NC6必须PQ>n。

反设PQ≤n。用n≥8192，

```
(n-1)^6(n-3)^3≥n^9(1-15/n)>n^9/2,
3n²-12n+8<3n².
```

(QIG-NC)和(T4)使

```
2^19 n^9 < 3·30^6 n^8,
n < 3·30^6/2^19 < 8192,
```

最后严格不等式由3·30^6=2187000000<2^32直接验证，矛盾。

若(r2,r3)=(0,2)用于A，或(2,0)用于B，则

```
n≡r2 (modP), n≡r3 (modQ), 0≤n<PQ.
```

两模数互素，故原n唯一恢复为

```
n = [r2 + P*((r3-r2)*P^(-1) modQ)] mod(PQ).      (REC)
```

没有遗漏模PQ的整数提升，因为PQ>n已经证明。计算出的代表还必须满足
高度、尾类和精确估值；这些过滤每一项都由原假想反例满足。

## 6. 完整回传与范围

任取原始尾部合法(n,j)。若NC6，则(HEIGHT)把n界住。
n≥8192时，第四节把它送入唯一的指数对恢复行；n<8192时它在八个低段行中。
所有恢复行都违反(QIG-NC)，故NC6不存在。

得到两尾全部j的Common6。没有要求Q52=1、Q52=q5、M2单位或任何混合形状。
C15剩下的纯中央/混合q2及所有中央/非中央混合q5因此同时退出。
