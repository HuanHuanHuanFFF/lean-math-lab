## 0. 冻结对象与采用范围

```math
\mathcal S=\{(r,s(r-s)):3\le r\le8,\ 0\le s\le\lfloor r/2\rfloor\}
```

共有21点。对非零 `H`，在源点 `P` 的普通阶为 `m_P`；第 `r` 行总普通阶为 `μ_r`，`μ=Σμ_r`，真实非零重数源点数为 `z`。

```math
u=N-r,\qquad t=X-s^2-su.
```


## 1. 新定理的精确陈述

### 定理 A：KSAT37–42

对 `37≤q≤42`，任意满足上述条件的 `Q[N,X]`-不可约 `H` 都满足

```math
\kappa_4+\kappa_6+\kappa_8\ge1.
```

### 定理 B：KSAT²31

对 `q=31`，任意满足上述条件的 `Q[N,X]`-不可约 `H` 都满足

```math
\kappa_4+\kappa_6+\kappa_8\ge2.
```

冻结 KSAT31 已排除总κ为0；本轮排除总κ恰为1。

## 2. 绝对不可约归约

### 2.1 q=37,…,42 且总κ=0

若 `H` 在代数闭包分成 `d≥2` 个共轭绝对因子，则每个绝对因子的 `X` 次数为 `q/d≤q/2≤21`。因为六行饱和、源普通阶及κ对乘法可加，并且共轭因子在有理源点有相同局部阶，每个绝对因子自身也是六行饱和且三个对角κ为0。

冻结复系数 `SAT≤24` 强迫该绝对因子含一条源直线 `ell_t=X-t(N-t)`。这条直线有有理系数，因而也整除 `H`，与 `H` 的 `Q`-不可约性矛盾。故 `H` 绝对不可约。

### 2.2 q=31 且总κ=1

若有 `d≥2` 个共轭绝对因子，则在每个有理对角源，共轭因子的普通阶和加权阶相同；所以每个 `κ_r` 及其总和都被 `d` 整除。但总κ等于1，不可能。故这一分支自动绝对不可约。

## 3. 加强亏格费用

把绝对不可约 `H` 加权齐次化为 `P(1,1,2)` 中次数 `2q` 的曲线。非零 `X^q` 项使曲线避开环境奇异顶点；虚亏格为

```math
(q-1)^2.
```

普通源点贡献至少 `C(m,2)`。

- 若对角κ=0，普通吹起后指定无穷近点仍有普通阶至少 `m`，故该对角额外贡献 `C(m,2)`。
- 若指定对角κ=1，普通 `m` 阶首部含 `u t^(m-1)`，吹起后指定点普通阶至少 `m-1`，故额外贡献 `C(m-1,2)`。

因此根门使用：

```math
\sum_{P\in\mathcal S}\binom{m_P}{2}
+\sum_{\kappa_r=0}\binom{m_r}{2}
+\sum_{\kappa_r=1}\binom{m_r-1}{2}
\le(q-1)^2.
```

总κ=1时恰有一个指定对角使用最后一项。

## 4. 完整根门

因 `H` 首一且第 `r` 行饱和，`H(r,X)` 的全部 `q` 个根（计重数）均为该行源值 `s(r-s)`，普通阶恰等于对应特化根重数。故每个真实对象唯一落入程序枚举的六组非负整数分拆。

设第 `r` 行根和、平方和为

```math
S_r=\sum_s m_{r,s}s(r-s),
\qquad M_{2,r}=\sum_s m_{r,s}[s(r-s)]^2.
```

首一式的 `X^(q-1)` 系数的 `N` 次数至多2，故六个 `S_r` 必须位于同一二次多项式；前三行决定后三行。`X^(q-2)` 系数次数至多4；因 `M_2=S^2-2e_2`，六个 `M_{2,r}` 的五阶差分为0。

对源直线 `ell_t`，限制次数至多 `2q`。非对角源贡献 `m`；κ0对角贡献 `2m`；总κ=1的指定对角贡献 `2m-1`。若总交数严格超过 `2q`，则 `ell_t|H`，与不可约性矛盾。

## 5. 六行插值与完整 jet 系统

固定六行首一式 `P_r(X)=H(r,X)`。对每个 `X^b` 系数在 `N=3,…,8` 作次数至多5的 Lagrange 插值，得到 `H0`。

根和与第二幂和门保证顶部两项满足更强的 `N` 次数≤2、≤4；其余系数的加权允许 `N` 次数至少6。因此

```math
\deg_w H_0\le2q.
```

任意具有相同六行特化的候选恰为

```math
H=H_0+WQ,
\qquad W=\prod_{r=3}^{8}(N-r),
\qquad Q\in B_{2q-6}.
```

`B_{2q-6}` 的单项式数为 `(q-2)^2`。

对每个非对角源加入全部 `i≥1,i+j<m` 的普通 Hasse jet；对κ0对角加入全部 `i≥1,i+2j<2m` 的加权 jet；对总κ=1的指定对角改为 `i+2j<2m-1`。`i=0` 条件已由固定行式满足。

将 `Q` 的 `(q-2)^2` 个系数列与 `H0` 的一列合并，得到

```math
K=(q-2)^2+1
```

列的齐次系统。首一解对应最后一列系数非零；若矩阵满列秩则不存在这种解。

全部系统在 `F_257` 上满列秩。六点插值分母整除120，而 `257∤120`；故模257非零的 `K×K` 子式对应清分母整数子式非零，严格推出 `Q` 上满列秩。由此证明定理A、B。

## 6. 同一-G 账本的安全收费

上一轮证明九分量必有 `E=0`，且完整弱账本的幸存集恰为六状态、12条 terminal query。加强任一费用不能让旧失败状态重新进入。

新签名仅作以下替换：

1. `q=25,…,31` 饱和因子：实际 `e=q≥25`，总κ≥2；账本统一收 `e=25` 和任意两单位实际κ。
2. `q=32,…,42` 饱和因子：实际 `e=q≥32`，总κ≥1；统一收 `e=32` 和一单位κ。
3. `q≥43`：统一收 `e=43`，忽略全部源费用。

其它签名保持冻结。每个真实剩余因子都能映射到一个费用不超过自身、次数不超过自身的签名，因此 Bellman 最低次数是实际总次数的安全下界。

对每条查询，正序 Pareto 123签名递推与逆序全部446签名递推相同。最终12条最低次数均严格超过可用次数；最小缺口为1。故九分量无状态可实现。

## 7. COVER8 的逻辑链

反设同一固定 `G` 有九个不同可载点不可约因子。冻结 EDGE9 强迫它进入六个 `E=0` 状态之一；冻结特殊因子枚举与 TRACE 又强迫它进入12条 terminal query 之一。第6节证明每条查询的最小所需 `X` 次数都超过同一状态可用次数，矛盾。

因此

```math
|\mathcal C_G|\le8.
```

这里没有恢复任何实际因子，也没有从必要资源状态反推原题点。
