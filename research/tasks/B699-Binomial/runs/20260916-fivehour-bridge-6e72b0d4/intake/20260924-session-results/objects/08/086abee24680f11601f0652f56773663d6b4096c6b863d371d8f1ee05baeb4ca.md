# Discovery only

`kernel_lp.py` enumerated a finite catalogue of positive quadratic factors and selected existing high factors; numerical linear programming suggested combinations. `factors.json`, `lp_results.json`, and `kernel_lp.log` preserve those observations.

The catalogue is not all possible kernels; an LP zero or nonpositive result is not an impossibility theorem. Discovery depends on SymPy/NumPy/SciPy. The certified proof does not import or trust these files. It directly reconstructs two explicit sixth-degree polynomials using standard-library integer arithmetic.

The earlier K12 fixed-divisor observation was superseded by the two sixth-degree factors; no K12, K16, K20, BFT, QIG, or old unit-window closure is a mathematical premise of the new 18-class theorem.
