# 重放说明

所有命令在本包根目录执行。默认只需 Python 3.11+ 标准库；完整重生成另需 SymPy 1.14.0。
已实际测试环境：Python 3.13.5 / SymPy 1.14.0。无网络、仓库或 Lean 依赖。
不要使用 `python -O`，检查器拒绝关闭断言的运行方式。

## 1. 校验原始文件

```sh
sha256sum -c SHA256SUMS
```

清单不包含自身，且历史输入以冻结原字节保存。

## 2. 默认：不信任符号系统，直接检查原方程和全部证书

```sh
python3 -B src/replay.py --output-dir /tmp/b699-m2-no14-fresh
```

目录必须尚不存在；省略 `--output-dir` 则生成新的临时目录。
首先独立构造四个原图的平方剩余，然后验证理想归属 DAG 的每个有理多项式线性组合。
之后检查两个原三次变换身份、三个巨大原行的整行消费者前提、宽 CUBIC 的恢复失败及五类坏证书拒绝。
不会扫描巨大行的 j，不会访问仓库，也不修改冻结输出。

## 3. 分步重生成（与默认证书检查分开）

独立执行下列命令。已在本轮从原公式成功生成四张证书，并逐字节相同。

```sh
PYTHONHASHSEED=0 python3 -B src/derive.py --out /tmp/b699-m2-no14-regenerated
python3 - <<'PY2'
from pathlib import Path
old=Path('certificates'); new=Path('/tmp/b699-m2-no14-regenerated')
for name in ('all0_center','all0_noncenter','all4','mixed'):
    assert (old/(name+'.json')).read_bytes()==(new/(name+'.json')).read_bytes(), name
print('CERTIFICATES_BYTE_IDENTICAL=PASS')
PY2
```

需要 SymPy 1.14.0；先确认版本和新目录不存在。生成器记录 Buchberger 运算的有理多项式恒等式。
程序本身不需要网络，不会访问仓库。标准库检查器不导入 SymPy。

**复现限制如实保留：**尝试将标准库检查和生成器封装进同一个 Python 调度命令时，
多次完整流程在 mixed 图超时，尚未定位嵌套运行与独立运行的差异。
因此最终交付采用上面已经成功的分步命令；不声称那些超时的整套重生成已完成。
默认 `src/replay.py` 只执行已完成的证书和应用检查，不触发符号重生成。
原证书的有效性由完整标准库 DAG 核验承担，不以生成器耗时或超时判定数学真假。

## 4. 证据的数学作用

这不是用有限点外推无限结论。四个无界参数图的矛盾由明确的特征零理想归属证书承担。
无限分支穷尽、原题前置、图坐标合法性和原题回传由 PROOFS.md 承担。
默认检查与重生成都不是 Lean、外部独立数学审读或 B699 全题证明。
外部几何定理仅用于合并上轮 m=2 次数上界；本轮 M2-NO14 及 GATE14/a13zero 消费者不使用它。
