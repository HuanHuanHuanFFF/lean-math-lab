# REPLAY

环境：Python 3；精确生成器依赖SymPy 1.14.0；第二检查器只用Python标准库。
不需要网络、随机数、仓库、Lean、外部付费CAS。

完整重放：

```bash
bash replay.sh
```

分别运行：

```bash
python3 src/hash_check.py
python3 src/replay.py --output-dir /tmp/nonic-fresh-certificates
python3 src/independent_check.py /tmp/nonic-fresh-certificates/exact.json --output /tmp/nonic-independent.json
cmp certificates/exact.json /tmp/nonic-fresh-certificates/exact.json
cmp certificates/independent.json /tmp/nonic-independent.json
```

生成器拒绝覆盖非空输出目录。完整脚本用mktemp，不覆盖冻结证书。

精确检查涵盖：全部六个2+1、a=0、重复二次根、共振分母、三线q=64/275、单槽有效链。
第二实现验证13个完整结式身份：147次有次数界的Sylvester/Bareiss求值；12份完整有限域证书；
单槽完整因式分解和mod3单位类别，以及360个仅作回归的赋值例。
损坏测试拒绝错误结式系数、错误有限域表、包含零根的多项式。

这不是把原题扫描147点或360点后外推；见PROOFS §10中的显式次数上界。
CAS的Groebner逻辑仍由精确生成器和纸面分支论证承担，不升级为Lean或外部人审。
