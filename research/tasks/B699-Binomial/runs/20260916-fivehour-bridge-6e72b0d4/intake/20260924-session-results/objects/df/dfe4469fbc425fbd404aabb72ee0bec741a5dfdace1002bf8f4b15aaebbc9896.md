# B699 新会话 C — q4 三落点统一因子与前沿压缩

日期：2026-09-22（Asia/Tokyo）。范围仅为当前 **B/RES10、真实全近侧、`C<A4`、低残量、大缺欠** 的同一原始 `(n,j)` 分支。没有修改、提交或发布仓库；没有 Lean 或外部独立审读。

## 本轮结论

本轮先对两条指定路线做低成本判别：

1. `p≥31 | q5` 的纯局部 `v_p(U-1)` 路线不具备上界潜力。只用 `(10/p)=+1` 与 `U=10(gz)^2` 时，Hensel 简根允许 `v_p(U-1)` 取任意预定正值；第5源近侧局部判别式也在任意层保持相容。因此没有继续做固定素数或固定精度枚举。
2. `q4` 三落点路线产生了严格新结构。把已有间距写为

   ```text
   A4 - C r = K,
   K=(45/4) g^3 d v^2 L3>0,
   E4=d4 h4^2,
   q4=E4 A4 C.
   ```

   在当前 B 尾中 `v2(g)=1`，故 `90|K`。若 `d4>1`，所有粗素数至少为7，直接有 `d4≥7`。若 `d4=1`，则 `E4` 是平方；由 `A4≡Cr (mod 2,3,5)`、`q4≡1 (mod3)`、`q4≡3 (mod5)` 得

   ```text
   r odd,
   r≡1 (mod3),
   r≡2 or 3 (mod5),
   hence r≡7 or 13 (mod30).
   ```

   所以两种情况统一为

   ```text
   r d4 ≥ 7.                                  (UF7)
   ```

这完整消费了 `q4` 非平方内容可能落在 `E4/A4/C` 的三个位置：落在 `E4` 时由 `d4` 供给粗因子；`E4` 为平方、奇指数落在 `A4` 或 `C` 时，由同一原输入的精确间距把粗增益转移到 `r`。
