# 重放本轮

依赖：Python 3.10+标准库、支持C++17的g++。不需要网络、SymPy、NumPy、SciPy、Lean或仓库。

在证据包根目录执行：

```sh
python3 -B code/replay.py --out /absolute/path/to/a-new-output-directory
```

输出目录必须不存在。程序会验证所采纳输入字节，编译两套锚点生成器、两素数jet发现器和费用程序，完整重生成9个根门及所有子式，再运行独立局部接收、q5整数Bareiss、全部124项费用、13122费用格和7项负控制。

最后应输出PASS_DOUBLE457_MOD4_FRONTIER123。比较新输出certificates/与包内certificates/的全部59个文件；重放日志/运行时间不是确定性证书，不要求字节相等。

未修改的冻结历史数学链不会由本命令重证。最后ZIP的实际SHA与最终解压重放终点以包外CLEAN_REPLAY_RECEIPT.json为准。
