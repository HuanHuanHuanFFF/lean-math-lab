# REPLAY · Round24

## 环境
Python 3.10 或以上；精确符号检查使用 SymPy 1.14.0。生成器、有限末端核验器和全有理区间回归只使用 Python 标准库。

```bash
python3 -m pip install -r requirements-symbolic.txt
bash replay.sh
```

本包已经在 Python 3.13、SymPy 1.14.0 环境执行。其他环境若符号输出版本号不同，逐字节输出比较会拒绝；这不自动表示数学恒等式错误。使用固定版本可重现本轮输出。

## 脚本实际做什么

`replay.sh` 先核验文件字节，随后在临时目录中重新生成两份证书。它把新证书与交付证书逐字节比较，再以不同算法验证有限末端，重算18条符号恒等式、50项有理预算、28个完整正实根区间回归，并将全部确定性 JSON 输出逐字节比较。临时目录最终删除，交付文件保持不变。

- 生成算法：在 AB=3(d−1) 上枚举分配，解二次 h；Pell 坐标采用有限环二进幂。
- 核验算法：完整整数线性 Pell 递推；逐 nu 线性恢复 h，d=0 单独完整遍历，直接检验 DIVNORM。保留所有 A/B/d/v 为零的模素数投影。
- 原 n=2^s 或3·2^s 的模素数投影完整保留。
- 覆盖对象：q≤276、0<V≤q² 的全部必要网格，不是原(n,j)实例或随机扫描。
- 区间回归允许 B 有理、h/C/V 非整数；它仅核对解析估计，不能替代纸面证明。

## 证据边界
本轮没有运行 Lean、旧 Matveev/CZ 或历史海量 campaign，也没有重新证明 NC3 到冻结必要核心的全部历史桥。两个算法均由同一作者实现，不是外部独立全篇审读。
文件 SHA-256 和 ZIP CRC 只检查字节身份/完整性。脚本 PASS 核验列出的有限计算，不自动证明纸面估计的全部无限量词，更不是完整 B699 闭合。
