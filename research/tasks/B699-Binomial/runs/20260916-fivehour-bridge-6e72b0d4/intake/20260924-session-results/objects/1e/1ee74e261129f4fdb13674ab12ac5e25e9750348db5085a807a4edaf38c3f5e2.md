# REPLAY

需要Python 3；符号检查需要SymPy，版本记录在requirements-symbolic.txt。标准库核验器不需要SymPy、NumPy、网络、仓库或Lean。

```bash
bash replay.sh
```

步骤：检查本包哈希；在临时目录重新生成两份周期证书；要求字节一致；用遍历nu/线性h的第二算法核验全部模p像与完整周期覆盖；执行6种坏证书拒绝；重算赋值、范数gcd和失败投影；核验12条符号恒等式；比较确定性输出。

两份有限证书：
- certificates/defect_235_periodic.json：48值、q mod1260。
- certificates/two_seven_tails.json：2族、q mod45、e mod240。

直接标准库核验：
```bash
python3 -B code/verify.py certificates/defect_235_periodic.json   --seven certificates/two_seven_tails.json --out /tmp/round25-replay.json
```

`PASS`表示所列恒等式、有限局部像、周期完备覆盖及回归通过，不表示无限纸面论证由形式化内核检查，也不是NC3入核全历史独立验收。
