# REPLAY

## 默认独立算术检查

已测试Python 3.13.5；默认只需Python标准库。输出目录必须不存在，不覆盖冻结证据。

```bash
python3 -B src/replay.py --output-dir /tmp/b699-mix-dw-new
```

默认执行：从原混合P重建十残差、两步比例变换、两端点全部清分母/因子剥离，
核验两份DAG的179节点、三条结式的6682个有完整次数界的整数行列式，
最终518次整数多项式逐系数分解与71个有限域值，检查失败模型与坏证书拒绝。
最后比较机器结果与冻结outputs/check.json逐字节一致。

## 原公式重生成（可选）

还需要SymPy 1.14.0、g++的C++17支持及GMP开发头文件/链接库。

```bash
python3 -B src/replay.py --output-dir /tmp/b699-mix-dw-regenerated --regenerate
```

除默认检查外，重新从原公式生成algebra.json和两套端点输入；重新构造精确结式，
检查已保存的三个一元因子乘积等于最终结式；本地编译gbtrace.cpp并生成两份DAG。
所有产物仅进入输出目录。计算不需要仓库、网络、Lean或随机数。
编译得到的二进制不随本证据ZIP分发。

## 不能从重放推出什么

- 不证明采用的NC3上游或外部几何前置；
- 不证明D_w≠0的剩余普通图不存在；
- 不把6682个行列式求值称为6682个原题实例；
- 不把哈希、CRC或字节一致解释为完整B699或Lean。
