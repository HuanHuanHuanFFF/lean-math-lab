# 重放

需要Python 3.10+、支持C++17的g++。不需要网络、Lean、FLINT、SymPy或原仓库。

完整重算到一个不存在的输出目录：

    python3 -B code/replay.py --out /absolute/new-output
    python3 -B code/replay.py --out /absolute/new-output --stage compare

为避免某个工具单次执行时限，可以分段，但不能把某段称为全部通过：

    python3 -B code/replay.py --out /absolute/new-output --stage init
    python3 -B code/replay.py --out /absolute/new-output --stage prepare
    python3 -B code/replay.py --out /absolute/new-output --stage modules --prime 257 --start 0 --stop 50
    python3 -B code/replay.py --out /absolute/new-output --stage modules --prime 257 --start 50 --stop 100
    python3 -B code/replay.py --out /absolute/new-output --stage modules --prime 257 --start 100 --stop 141

再把上述三段的prime改为263，最后运行：

    python3 -B code/replay.py --out /absolute/new-output --stage finish
    python3 -B code/replay.py --out /absolute/new-output --stage compare

finish要求全部282份完整源模块记录，无截断项；它重新运行39600格独立费用核对并重建205前沿。
compare只比较确定性certificates文件，不要求时间/机器路径等运行元数据相同。

小系统独立矩阵/负控接收器：先把qmod257/qmod263编译到verification/bin（命令同init），再运行

    python3 -B code/check_small_and_negative.py /absolute/new-small-tests

编译产物没有收入最终ZIP；均可由代码重新生成。
