# PROOFS · Round 19 odd--odd 端点化与双侧有效化

## P0. 冻结前置与符号

固定同一个原始合法 `(n,j)`，反设其处于 `NC3`，且位于规范最小临界两底、真实 `mu=1`、平衡 `D_v=D_W=y` 必要核心。采用：

```math
P=Q+hv,
\quad 2\nu=h(Q-v)-Q,
\quad v\nu^2=PQ^2-1,
\quad n=PQ\nu+2=c2^s,
```

```math
d=Q-v,
\quad d^2+d+1=3y^2,
\quad v=Ay,
\quad W=By,
\quad AB=3(d-1),
```

```math
t=8q+1,
\quad U=U_{4q+1}=2u,
\quad X=X_{4q}=2^\rho x,
\quad AB=9UX.
```

这里 `u,x,y` 为奇数，`rho=v2(q)+3>=3`，`gcd(U,X)=2`，`3∤t`，并有

```math
s\le18t+15=144q+33.
```

令

```math
\alpha=2+\sqrt3,
\qquad Z=\alpha^{4q},
\qquad E=Z^{-2}.
```

Pell 坐标：

```math
X=\frac{Z-Z^{-1}}{2\sqrt3},
```

```math
y=\frac{\alpha Z^2+\alpha^{-1}Z^{-2}}4,
```

```math
d=\frac{\sqrt3(\alpha Z^2-\alpha^{-1}Z^{-2})-2}{4}.
```

完整平方恢复：

```math
Y^2=S
=v^4+5dv^3+10d^2v^2+10d^3v+5d^4+d^2W,
```

其中 `Y=d nu-Q^2`。

## P1. 全平衡 2-adic 端点

置

```math
\alpha_2=v_2(A),\qquad\beta_2=v_2(B).
```

`U=2u`、`X=2^rho x` 给

```math
\alpha_2+\beta_2=\rho+1.                         \tag{1}
```

冻结入口已有 `v` 偶，而 `y` 奇，所以 `alpha_2>=1`。

`d,Q` 奇、`nu=2H`，故

```math
Y=d\nu-Q^2
```

为奇数。将平方式模 2 化简：全部含 `v` 的项为偶，`5d^4` 为奇，所以

```math
1\equiv Y^2\equiv1+W\pmod2.
```

故 `W` 偶；`y` 奇，故 `beta_2>=1`。

### P1.1 排除 `beta_2=1`

由 `(1)`，`alpha_2=rho>=3`。模 8，全部含 `v` 的项消失，而

```math
S\equiv5+d^2W\equiv3\text{ 或 }7\pmod8,
```

不是奇平方。

### P1.2 排除中间层

若 `alpha_2>=2` 且 `beta_2>=3`，全部含 `v` 的项模 8 消失，`d^2W` 也消失，所以

```math
S\equiv5\pmod8,
```

矛盾。

由 `(1)`，余下仅有

```math
\boxed{\beta_2=2}
```

或

```math
\boxed{\alpha_2=1,\ \beta_2=\rho}.                \tag{ODD-END}
```

## P2. 规范有理分配

令 `e=beta_2`，定义

```math
\lambda=\frac{2^{e-1}A}{X}=\frac ab
```

为既约正分数。由 `v2(A)=rho+1-e` 与 `v2(X)=rho`，`lambda` 的 2-adic 赋值为零，所以 `a,b` 均奇。

直接整理：

```math
A=2^{1-e}\lambda X,
```

并由 `AB=9UX`：

```math
B=2^{e-1}\frac{9U}{\lambda}.                       \tag{2}
```

把 `X=2^rho x` 代入第一式。因 `A` 为整数、`gcd(a,b)=1`、`b` 奇，得到 `b|x`。第二式同理给 `a|9U`。写

```math
x=bx_1,\qquad9U=au_1,
```

则

```math
\boxed{
A=2^{\rho+1-e}a x_1,
\qquad
B=2^{e-1}b u_1.}                                    \tag{3}
```

若 `b=1`，低端和高端分别成为 Round 11 的 pure-low 与 pure-high 参数，现已由 Round 18 累计排空。因此 odd--odd 中 `b>1`。

### P2.1 比值走廊

冻结的 `J` 格点界给：

```math
e=2:\quad d<8B^2,
```

```math
e=\rho:\quad d<4B^2.
```

并有统一下界

```math
d>6U^2/13.
```

低端由 `B=18U/lambda`：

```math
\lambda^2<8\cdot18^2\cdot13/6=5616<75^2.
```

高端由 `B=2^(rho-1)9U/lambda`：

```math
\lambda^2<702\,2^{2\rho-2}<27^2 2^{2\rho-2}.
```

因此

```math
0<\lambda<75\quad(e=2),                             \tag{4}
```

```math
0<\lambda<27\,2^{\rho-1}\le108q\quad(e=\rho).     \tag{5}
```

## P3. 通用主项

```math
r=v/d,\qquad \omega=Y/d^2.
```

## P4. 直接分配的有效化

由 `(2)` 的第一式，

```math
v=2^{1-e}\lambda Xy.
```

定义

```math
N_0=\frac{\lambda^6\alpha^{48q+3}}
          {2^{6e+3}3^{9/2}}.                        \tag{7}
```

令

```math
R_X=1-E,
\quad R_y=1+\alpha^{-2}E^2,
```

```math
R_d=1-\alpha^{-2}E^2-
       \frac{2E}{\sqrt3\alpha}.
```

逐项代入得到精确式

```math
\boxed{M/N_0=R_X^6R_y^6R_d^{-3}.}                   \tag{8}
```

### P4.1 `H(lambda)<=q` 给指数大 `r`

若 `a,b<=q`，则 `lambda>=1/q`。又 `e<=rho` 且

```math
2^rho=8\,2^{v2(q)}\le8q,
```

同时 `y>d/2`、`X>Z/8`。于是

```math
r>A/2=2^{-e}\lambda X>Z/(64q^2).                   \tag{9}
```

对 `q>=5`，右侧大于 100；`q<5` 已在最终数值界内。

Round 16 对 `(8)` 的估计给

```math
|M/N_0-1|\le6E.
```

与 `(6)`、`(9)` 合并：

```math
\boxed{
\left|n/N_0-1\right|
<1000q^2\alpha^{-4q}.}                              \tag{10}
```

### P4.2 三对数

写 `c=3^kappa`，`kappa in {0,1}`，并令

```math
\eta=9+2\kappa,
\qquad
\zeta=\frac{(2\lambda)^6}{(\sqrt3)^\eta}.
```

则

```math
\Gamma=n/N_0
=2^{s+6e+9}\alpha^{-(48q+3)}\zeta^{-1}.            \tag{11}
```

`Gamma!=1`：非平凡共轭把 `alpha` 送到 `alpha^-1`，而 `eta` 奇使 `zeta` 变号；等式 `Gamma=1` 共轭后右侧为负。

采用 Round 16 已冻结的 Matveev 形式。三个代数数为 `2,alpha,zeta`，次数 `D=2`。取

```math
A_1=A_2=7/5.
```

若 `lambda=a/b`，则 `zeta` 满足

```math
b^{12}3^eta T^2-(2a)^{12}=0.
```

当 `a,b<=q` 时，

```math
A_3=12(\log q+2)
```

同时控制 `2h(zeta)` 与 `|log zeta|`。由 `s<=144q+33`、`e<=rho`，可取 `B=200q`。沿 Round 16 的常数账本：

```math
\log|\Gamma-1|
>-C(\log q+2)(\log q+7),                            \tag{12}
```

```math
C=23137949116800.
```

由 `(10)`、`log1000<7`：

```math

```

```math
F_D(x)=2\log x+7+C(\log x+2)(\log x+7).            \tag{13}
```

且


故 `F_D(x)/x` 递减。

```math
<99742492603973723/22517998136852480
```

```math
\boxed{H(\lambda)\le q\Longrightarrow q<2^{53}.}   \tag{DIRECT}
```

## P6. 固定多项式高度的一般接口

若 `H(lambda)<=q^K`，则 `(9)` 改为

```math
r>Z/(64q^{K+1}),
```

`(10)` 改为 `1000q^{K+1}alpha^(-4q)`，而 `A3` 可取 `12(K log q+2)`。因此真实状态满足显式不等式

```math
4q\log\alpha
<(K+1)\log q+7
 +C(K\log q+2)(\log q+7).
```

右边为 `O_K((log q)^2)`，所以可算法求出绝对 `q` 界。

同理，`H(theta)<=q^K` 时得到

```math
4q\log\alpha
<K\log q+5
 +C(K\log q+3)(\log q+7).
```

因此每个固定 `K` 的直接／互补多项式高度子域都有效有限。

由 `(4)`、`(5)`：若 `b<=q^K`，则低端 `a<75q^K`，高端 `a<108q^{K+1}`；增大固定次数后均落入 DIRECT 的一般接口。因此固定多项式分母子域也有效有限。

## P7. 奇素数幂的 unitary 门

设奇素数 `p|gcd(A,B)`。冻结条件 `gcd(y,3(d-1))=1` 给 `p∤y`。若 `p!=3`，由 `AB=3(d-1)` 得 `d≡1 mod p`；若 `p=3`，因 `p` 同时整除 `A,B`，`v3(AB)>=2`，同样有 `3|(d-1)`。

于是 `v=Ay` 与 `W=By` 均被 `p` 整除，平方式模 `p` 为

```math
Y^2\equiv5d^4\pmod p.                              \tag{22}
```

若 `p!=5`，则 `(5/p)=1`。由二次互反律（`5≡1 mod4`）：

```math
p\equiv1\text{ 或 }4\pmod5.                        \tag{23}
```

所以 `p≡2,3 mod5` 的完整指数不能同时出现在 `A,B`；特别地 `p=3` 不共享。

### P7.1 共享素数 5

若 `5|gcd(A,B)`，则 `d≡1 mod5`。`U_n` 模 5 的周期为 `1,2,2`；`3∤t`，故 `U_t≡2 mod5`。由 `U_t=2y`：

```math
y\equiv1\pmod5.                                    \tag{24}
```

设 `b5=v5(B)`。若 `b5>=2`，平方式六项的 5-adic 赋值依次至少为

```text
4, 4, 3, 2, 1, 2,
```

其中 `5d^4` 是唯一最低项，所以 `v5(S)=1`，矛盾。故 `b5=1`。

为使 `v5(S)` 为偶数，必须 `S/5≡0 mod5`。模 5：

```math
S/5\equiv d^4+d^2(W/5).
```

用 `(24)`、`d≡1`、`W=By`：

```math
\boxed{B/5\equiv4\pmod5.}                          \tag{25}
```

## P8. 回传与证据边界

所有排除都发生在同一个原始 `(n,j)` 的 NC3 必要核心内。必要状态不存在时，回传为原输入具有某个真正的共同素数 `p>=3`；本轮不辨识该见证。
