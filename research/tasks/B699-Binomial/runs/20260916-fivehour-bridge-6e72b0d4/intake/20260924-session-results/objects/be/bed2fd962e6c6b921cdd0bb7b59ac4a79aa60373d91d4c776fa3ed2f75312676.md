Scope: this archive covers the current Pro A / i=9 fixed-G conversation from its initialization through the final archive request on 2026-09-24.

- 12 research-round evidence ZIPs, preserved byte-for-byte.
- The earlier session-wide interim archive ZIP, preserved byte-for-byte.
- A cross-round SHA-256 object store containing every recoverable extracted ZIP member and directly mounted standalone file.

- Round index, file inventory, SHA-256 list, evidence-level notes, unresolved-problem notes and missing/recovery-boundary notes.

- Project reference input `OVERVIEW-2026-09-22.md.txt`.

## Evidence boundary

The project source explicitly requires that author paper arguments, necessary conditions, deterministic finite certificates, scans/replays and AI deliveries must not be called Lean verification, independent external review, complete i=3 closure or complete B699 closure. This archive preserves that distinction.

No Lean was run for this archiving task. No repository was modified, committed, pushed or published.

## Deduplication

Original ZIP artifacts are preserved unchanged even if their internal members duplicate bytes elsewhere.  
For unpacked/standalone material, bytes are deduplicated *only* when SHA-256 is identical. See `DEDUP_SOURCE_MAP.tsv`.

## Conversation limitation

The platform did not expose a raw chat/UI export API. `conversation/` is an explicit reconstruction from the visible conversation context available during this archive turn. It is not claimed to be a byte-exact export of ChatGPT UI messages or raw tool-event payloads.
