# 证明细节

## P1. POWER 判别式与平方范数同源

Round 12 的多项式 `L` 展开后直接整理为

```math
L=(3d+4v)(d+v)^5-2d^2v.
```

令 `Q=d+v`。直接展开验证

```math
vL^2+d^3R=Q^6(d+4v)^2(Q^5-d^2).       (1)
```

由完整平方范数 `Q^5-d^2=vY^2`，(1) 化为

```math
L^2+d^3R/v=(Q^3(d+4v)Y)^2.             (2)
```

而 `n=c2^s` 将 Round 12 POWER

```math
R=cv2^(s+1)(cd^3 2^(s-1)-L)
```

化为

```math
R=vn(d^3n-2L).                          (3)
```

(3) 是 `d^3 n^2-2Ln-R/v=0`。其判别式为

```math
4(L^2+d^3R/v),
```

由 (2) 已是平方。这证明普通判别式/resultant 不提供独立约束。

## P2. 模 y 的同源根

平方目标为

```math
Y^2=v^4+5dv^3+10d^2v^2+10d^3v+5d^4+d^2W.
```

`y|v` 且 `y|W`，故

```math
Y^2=5d^4 (mod y).                       (4)
```

若素数同时整除 `d,y`，由 `d^2+d+1=3y^2` 得 `1=0`，矛盾；所以 `gcd(d,y)=1`。

同一原输入满足

```math
Q=d+v,
P=Q+hv,
n-2=PQnu,
Y=dnu-Q^2.
```

模 `y` 有 `P=Q=d`，且由 `d^2+d+1=0 (mod y)` 得 `d^3=1 (mod y)`。因此

```math
n-3=d^2 nu-1 (mod y),
```

```math
d^2(n-3)=d^4nu-d^2=dnu-d^2=Y (mod y). (5)
```

将 (5) 代入 (4) 并消去可逆的 `d^4`：

```math
(n-3)^2=5 (mod y).                      (6)
```

由

```math
(n-2)^2-2n=n^2-6n+4=(n-3)^2-5,
```

再得

```math
n/2=((n-2)/2)^2 (mod y).                (7)
```

## P3. y=U_t/2

令 `U_k+X_k sqrt(3)=(2+sqrt(3))^k`。旧平衡参数有

```math
y=U_(4q+1) U_(4q)-1,
t=8q+1.
```

乘法公式

```math
2U_aU_b=U_(a+b)+U_(a-b)
```

取 `a=4q+1,b=4q`，并用 `U_1=2`：

```math
y=(U_t+2)/2-1=U_t/2.                   (8)
```

## P4. 奇素因子必为 1 mod 12

设奇素数 `ell|U_t`，`t` 奇。Pell 方程给

```math
-3 X_t^2=1 (mod ell),
```

故 `(-3/ell)=1`，于是 `ell=1 mod3`，即 `ell=1` 或 `7 mod12`。

反设 `ell=7 mod12`，则 `(3/ell)=-1`。在 `F_(ell^2)` 中令 `alpha=2+sqrt(3)`。Frobenius 给 `alpha^ell=alpha^(-1)`，所以 `ord(alpha)|ell+1`。又 `ell|U_t` 等价于

```math
alpha^(2t)=-1,
```

而 `t` 奇，故 `v2(ord(alpha))=2`。

另一方面

```math
alpha=(1+sqrt(3))^2/2.
```

利用 `(1+sqrt(3))^ell=1-sqrt(3)`，得到

```math
alpha^((ell+1)/2)=-(2/ell).             (9)
```

- 若 `ell=7 mod24`，则 `(2/ell)=1`，(9) 为 `-1`，故 `ord(alpha)` 的 2 部至少为 8；
- 若 `ell=19 mod24`，则 `(2/ell)=-1`，(9) 为 `1`，故 `ord(alpha)|(ell+1)/2`，而后者的 2 部只有 2。

两者都与 `v2(ord(alpha))=2` 矛盾。因此

```math
ell=1 mod12.                             (10)
```

## P5. SPLIT60 / SPLIT120-even

由 (6)，对每个 `ell|y` 有 `(5/ell)=1`；由 (10)，`ell=1 mod12`。CRT 给

```math
ell=1 or 49 mod60.
```

若 `s` 偶，(7) 与 `n/2=c2^(s-1)` 给 `(c/ell)(2/ell)=1`。由 `ell=1 mod12`，有 `(3/ell)=1`；无论 `c=1` 或 `3`，均推出 `(2/ell)=1`。再做 CRT：

```math
ell=1 or 49 mod120.
```

## P6. BAD-RANK

若奇数 `r|t` 且 `ell|U_r`，由于 `t/r` 为奇数，

```math
alpha^r+alpha^(-r)=0
```

推出

```math
alpha^t+alpha^(-t)=0,
```

故 `ell|U_t`。若该 `ell` 不在 `1,49 mod60`，与 P5 矛盾。

对 `t=8q+1`，`r|t` 等价于

```math
q=-8^(-1) (mod r).
```
