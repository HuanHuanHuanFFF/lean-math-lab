只重算本轮的相位保留有限环证书。不会运行旧的大规模扫描、Lean或仓库工具。

环境：Python 3；`sympy==1.14.0` 仅用于9项符号检查，生成器和独立核验器均只用标准库。

```bash
python3 -B code/check_hashes.py
bash replay.sh
```

`replay.sh` 在新临时目录生成证书与输出，并与交付件逐字节比较，不覆盖包内输入。

- 生成器：以二次式 EH 求全部 h，保留 (V,n) 而不只保留 V；全周期相位交集用 Python 大整数位集。
- 核验器：全枚举 A,B,nu 并线性恢复 h（d=0 时单独处理）；直接检查 DIVNORM 和原范数；V 用另一整数公式计算。全周期交集通过显式剩余类的全部 CRT 提升，不使用位集。
- 所有辅助素数、Pell首返周期、2和7的乘法阶重新求出。
- e>=1 的 e mod720=0 表示720、1440等正指数，不允许在模7处用7^0=1代替。
- 证书缺失一项乘子、伪造局部像、缩短周期、改错c0或篡改覆盖账本都必须被拒绝。
