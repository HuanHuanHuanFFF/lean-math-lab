# PROOF — OCTIC-35 与 4+4 廉价前沿

## 0. 采用接口与作用域

固定同一个原始自然数输入 `(n,j)`，`4≤j≤floor(n/2)`，`k=n-j`。Common3 / NC3 均指同一个原输入。数字多项式 `f,J,U,V,W,R` 不是实际内容三次 `Psi`、恢复三次或其他支路的 `P,Q`。

采用既有 GATE8 大进制提升：若

```text
f∈Z[X], f_i≥0, f(0)=2, deg f=8, H=f(1),
T=p^e odd prime power,
T≥[2(H+2)]^20,
n=f(T) even,
```

而同一输入满足 NC3，则必要地

```text
f-1 | J(J-1),
f-2 | J(J-1)(J-2)                  in Q[X].
```

完整第一源分配可写成

```text
f-1=UV,  U(0)=V(0)=1,
sigma=VW,  U | VW-1,
W(W-U)(W-2U)=(UV-1)R,
gcd(U,W)=gcd(U,R)=1.                (I)
```

并有

```text
U | W R' - R(3W'-2U').              (DIFF)
```

既有 `PRIMARY-≥2/3` 给

```text
8/3 < deg U,deg V < 16/3,
```

故只有 `3+5` 或 `4+4`。

由 `VW=1+UQ` 与 (I) 模 `U^2` 展开：

```text
W^3-3UW^2 ≡ -R+UVR        (mod U^2),
VR ≡ -VW^3 ≡ -W^2         (mod U),
```

所以

```text
U^2 | W^3+R-2UW^2.                   (U2)
```

该推导不要求 `U` 平方自由。

## 1. 3+5 的端点边界

换用另一原端点可交换两个完整块，故取

```text
deg U=3, deg V=5, deg W≤3.
```

`U,V` 的首项为正；两个原数字端点非负，故首项比 `t=lc(W)/lc(U)` 满足 `0≤t≤1`。

### 1.1 t=0

令 `s=deg W≤2`。若 `s≤1`，(I) 左侧次数至多 7，小于 `deg(UV-1)=8`，矛盾。若 `s=2`，则 `R` 为非零常数。DIFF 迫使

```text
3W'-2U'=0,
```

但左侧二次首项来自 `-2U'`，非零，矛盾。

### 1.2 t=1

令 `D=W-U`，`deg D≤2`。若 `deg D≤1`，次数不足；若 `deg D=2`，`R` 为常数，而 DIFF 迫使

```text
U'+3D'=0,
```

二次首项仍非零。

所以必有 `0<t<1`、`deg W=3`。三个槽都恰三次，故 `deg R=1`。

## 2. 一次商的两系数矛盾

把 `R` 的有理根移到 0，写 `R=ell*x`。将 `U,W` 同比例规范为

```text
U=x^3+A x^2+B x+C,
```

其中 `C≠0` 来自 `gcd(U,R)=1`。

在 `x=0`，(I) 给 `W(0)=kU(0)`，`k∈{0,1,2}`。DIFF 的被除式次数不超过 3；在 0 求值确定商为 `k ell`，所以

```text
3xW'-W=2xU'-kU.                      (2.1)
```

逐项比较得到

```text
W=(6-k)x^3/8 +(4-k)A x^2/5 +(2-k)B x/2 + kC.   (2.2)
```

令

```text
P=W^3+ell*x-2UW^2.
```

由 (U2)，`P` 除以 `U^2` 的余式为零。精确长除法给，若

```text
epsilon_0=1, epsilon_1=-1/8, epsilon_2=-8,
```

则

```text
[x^0] rem(P,U^2)
 =epsilon_k*C^2(2A^3-25AB-1125C)/4000,          (2.3)

[x^5] rem(P,U^2)
 =epsilon_k(3A^4-40A^2B-150AC+125B^2)/8000.    (2.4)
```

比例均非零。于是

```text
2A^3-25AB-1125C=0,                               (2.5)
3A^4-40A^2B-150AC+125B^2=0.                     (2.6)
```

若 `A=0`，(2.5) 给 `C=0`，矛盾；故 `A≠0`。置

```text
b=B/A^2, c=C/A^3.
```

由 (2.5)

```text
c=(2-25b)/1125.
```

(2.6) 除以 `A^4`，代入并乘 15，得到

```text
1875b^2-550b+41=0.
```

判别式

```text
550^2-4*1875*41=-5000<0.
```

故没有有理解。`3+5` 全部排除。

## 3. 整行因子判据与显式族

在 GATE8 下，NC3 的第一源分配现在只能是 `4+4`。所以若 `f-1` 没有次数 4 的完整有理因子子积，则 NC3 不可能。

对奇素数 `a,b`，令

```text
f-1=(1+2aX^3)(1+4bX^5).
```

倒数多项式 `X^3+2a` 在 `a` 处 Eisenstein，`X^5+4b` 在 `b` 处 Eisenstein；两因子不可约，唯一非平凡分配为 `3+5`。另外奇 `T` 下

```text
f(T)=2+2aT^3+4bT^5+8abT^8 ≡0 (mod4).
```

故这给出系数和工作进制均可无界的整行族。

## 4. 4+4 内部单槽

现在 `deg U=deg V=4`。在 `0<t<1` 时 `deg R=4`。若整个 `R` 进入槽 `k`，写

```text
W-kU=cR.
```

DIFF 写成 `US`，`deg S≤3`。模 `R` 有 `S≡kR'`，次数界给 `S=kR'`。代回：

```text
(3k-2)U'+2cR'=0.                                 (4.1)
```

比较首项得到

```text
t=(2-k)/2.
```

内部只许 `k=1`。于是

```text
W=U/2+c0.
```

在原数字坐标 `U(0)=V(0)=1`，`c0=W(0)-1/2`。由主身份先模 `U` 再展开，得到

```text
c=-1/c0^2,
V=3U/(4c0^2)+1/c0.
```

代 `X=0`：

```text
4c0^2-4c0-3=0,
```

故 `c0=-1/2` 或 `3/2`。分别得到 `V=3U-2` 或 `U=3V-2`，统一为

```text
f=3Z^2-2Z+1.
```

整数 `Z(T)` 偶时该值为 `1 mod4`，奇时为 `2 mod4`；与同一 NC3 的 `4|n` 矛盾。

## 5. 4+4 边界次数 ≤2

### 5.1 t=0

令 `s=deg W`。由主身份 `deg R=s`。`s=0` 时常商 DIFF 的三次首项非零；`s=1` 时将一次商根移到 0，(2.1) 的 `x^4` 系数要求 `8-k=0`，而 `k∈{0,1,2}`。故只需处理 `s=2,3`。

对 `s=2`，规范

```text
U=x^4+A x^3+B x^2+C x+D,
W=ax^2+bx+c,  a≠0.
```

(U2) 的商只能是常数 `-2a^2`，所以

```text
R=2UW^2-W^3-2a^2U^2.                             (5.1)
```

要求 `deg R≤2`。从 `x^7,x^6,x^5,x^4` 依次得到

```text
A=2b/a,
B=-a/2+2c/a+b^2/a^2,
C=b(4c-a^2)/(2a^2),
D=(4c^2-2a^2c-a^4)/(4a^2).
```

即

```text
U=W^2/a^2-W/2-a^2/4,
R=-(a^4/8)(a^2+4W).                               (5.2)
```

取 `R` 的根 `alpha`，有

```text
W(alpha)=-a^2/4,
U(alpha)=-a^2/16,
W(alpha)/U(alpha)=4.
```

但主身份在该根要求比值为 `0,1,2`，矛盾。

### 5.2 t=1

令 `D0=W-U`，`s=deg D0`。`s=0,1` 同样由 DIFF 首项排除。对 `s=2` 写

```text
D0=ax^2+bx+c.
```

展开 (U2)：

```text
W^3+R-2UW^2
 =-U^2(U+D0)+UD0^2+D0^3+R.
```

故

```text
R=a^2U^2-UD0^2-D0^3.                              (5.3)
```

高次系数依次给

```text
U=D0^2/a^2+D0-a^2,
R=a^4(a^2-2D0).                                   (5.4)
```

在 `R` 的根上 `D0=a^2/2`，于是

```text
U=-a^2/4, W=a^2/4, W/U=-1,
```

再次与槽值 `0,1,2` 矛盾。

因此边界只剩两侧的三次临界商。

## 6. 不能越界的结论

本文没有处理：内部多槽四次商、两侧三次临界商、门槛以下八次、九次以上、两底 low/low、负向三槽或一般多底。必要多项式系统没有被反向当作 NC3 的充分参数化。
