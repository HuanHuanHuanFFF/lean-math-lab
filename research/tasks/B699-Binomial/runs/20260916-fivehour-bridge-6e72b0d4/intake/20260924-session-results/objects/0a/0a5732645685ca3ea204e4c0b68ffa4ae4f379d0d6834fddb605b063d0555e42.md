# PROOFS — GATE8 的边界三次与内部 `3+1` 全排除

## 0. 作用域与冻结输入

固定同一个原始自然数输入 `(n,j)`，`4≤j≤floor(n/2)`，`k=n-j`。Common3 表示存在同一个奇素数 `p≥3` 同除 `C(n,3),C(n,j)`；NC3 是完整否定。

采用上一轮已经定向展开的 GATE8 必要系统：

```text
f∈Z[X]，f_i≥0，f(0)=2，deg f=8，H=f(1)，
T=p^e 为奇素数幂，T≥[2(H+2)]^20，n=f(T) 偶。
```

NC3 必要地给数字多项式 `J`，其与 `f-J` 系数非负，并给

```text
f-1 | J(J-1)，
f-2 | J(J-1)(J-2)                  in Q[X]。
```

第一源完整分配写作

```text
f-1=UV，U(0)=V(0)=1，
σ=VW，U|VW-1，
W(W-U)(W-2U)=(UV-1)R，             (M)
gcd(U,W)=gcd(U,R)=1。
```

这里 `σ` 是原 `j` 或 `k`；本轮在 `4+4` 中固定 `σ=j`。DIFF 与二阶同余为

```text
U | W R' - R(3W'-2U')，             (D)
U^2 | W^3+R-2UW^2。                 (U2)
```

上一轮 OCTIC-35 已排除 `3+5/5+3`，故本文只处理 `deg U=deg V=4`。冻结前置 `NC3⇒4|n` 只在最终模 4 回传中使用。

## 1. 完整槽分解与 DIFF 商的闭式

三个槽多项式 `W,W-U,W-2U` 两两互素：任意公因子也整除 `U,W`。因此 `R` 的每个不可约因子连同完整重数只能进入一个槽。写

```text
R=R0 R1 R2，Ri | W-iU，di=deg Ri。
```

`Ri` 两两互素。将 (D) 写成

```text
W R' - R(3W'-2U')=US，deg S≤deg R-1。             (1.1)
```

模 `Ri` 有

```text
S≡iR' (mod Ri)。                                  (1.2)
```

定义

```text
S*=R0 R1' R2 + 2R0 R1 R2'。
```

直接计算：

```text
S*-R'  =R1(R0R2'-R0'R2)，
S*-2R'=-R2(R0R1'+2R0'R1)，
```

且 `R0|S*`。所以 `S*` 满足三组同余；`deg(S-S*)<deg R` 而 `R|(S-S*)`，故

```text
S=R0 R1' R2 + 2R0 R1 R2'.                         (SLOT)
```

这对重因子同样成立，没有平方自由假设。

## 2. BOUNDARY-3：两个三次临界边界退出

### 2.1 `t=0, deg W=3`

此时 `deg R=3`：主身份左侧次数是 `3+4+4=11`，右侧除数 `UV-1` 次数为8。设 `r=lc(R),u=lc(U)`。

由 (SLOT)，`lc(S)=(d1+2d2)r`。在 (1.1) 左侧，`WR'` 与 `RW'` 次数至多5，唯一六次首项来自 `2RU'`，系数为 `8ur`。右侧 `US` 的六次首项为 `u(d1+2d2)r`。因此

```text
d1+2d2=8。                                         (2.1)
```

然而 `d0+d1+d2=3`，所以

```text
d1+2d2≤2(d1+d2)≤6，
```

矛盾。

### 2.2 `t=1, deg(W-U)=3`

置 `Q=(VW-1)/U`。互补原端点

```text
τ=f-σ=U(V-Q)，
τ-1=V(U-W)。
```

所以交换 `U,V` 后得到同型表示，新的 `W*=V-Q`。当当前 `t=1` 且 `deg(W-U)=3` 时，`τ=V(U-W)+1` 次数为7，故 `deg W*=3`，正落入上一支，矛盾。

因此所有幸存者都有

```text
0<t<1，deg W=4，deg R=4。                          (2.2)
```

## 3. WEIGHT8 与较小端点定向

在内部令 `lc(W)=tu`。设 `r=lc(R)`。由 (SLOT)，`lc(S)=(d1+2d2)r`。比较 (1.1) 的七次首项：

```text

-3RW'     : -12tur，
+2RU'     :  8ur。
```

所以

```text
d1+2d2=8(1-t)。                                    (WEIGHT8)
```

在 `4+4` 中可把进入原 `j` 的第一源块命名为 `V`，故固定 `σ=j`。`J` 与 `f-J` 是同一工作进制的非负数字多项式；`j≤n-j` 的最高数字比较给

```text
t≤1/2，亦即 d1+2d2≥4。                             (3.1)
```

对 `3+1` 分配，六个有序槽型中只剩


即三次因子槽/一次因子槽分别为


## 4. 统一坐标与 DIFF 线性解

令一次因子的根为 `0`，三次完整因子为

```text

R=rho*x*A。
```

将 `U` 规范为首一四次。若三次因子进入槽 `k`、一次因子进入槽 `l`，(SLOT) 化为

```text
S=k(xA)' +(l-k)A。
```

联立 (1.1)、`A|(W-kU)`、`W(0)=lU(0)`，线性地解出 `U,W`。

### 4.1 `(k,l)=(2,0)`

令 `q=U(0)≠0`：

### 4.2 `(k,l)=(2,1)`
