# REPORT — C21：分离的两个活动底数，新增72类完整闭合

## 1. 准确主结论

令 F20 是 C20 账本中的184个必要模1800类。在完整六窗口 n,...,n-5 中，
以8、9、25为2、3、5的阈值。选取下述原行：

- 恰有两个底数达到阈值，分别在位置0和位置r；
- 第三个底数在全部六窗口均没有达到其阈值；
- r=2时两个底数任意；r=3时两个底数之一必须是2；
- 原行模1800在F20中。

这样的类恰有72个。本轮证明，对于全部这些n及每个合法
7<=j<=floor(n/2)，存在同一个素数p>=7同除C(n,6)、C(n,j)。
整行意为 forall j exists p，不要求一个固定p覆盖整行。

这72类与此前采用的1616类严格不交；本轮第一次在本会话账本中给出其有效高度并完成有限末端。
因此账本从184个必要剩余类降至112类，采用式总覆盖从1616增至1688类。
不是完整i6或完整B699；R7仍为{3,4,5,6,7,8,9}。

## 2. 方法变化

没有把“n有高幂”错当成“alpha=n/g有同样高幂”。直接在原完整源第0行用
q0|g，配合两个实际完整幂P,Q，得到BFT的余因子界。
没有采用NC5、G7、SAT、unit-coarse；g和所有粗块只用>=1。

旧正核F16重新验证后，源最低阶为
r1:8,8；r2:3,4,3；r3:4,4,4,4；r4:3,3,3,3,3；r5:2,2,1,1,2,2。
本轮没有声称新发现F16。

设w2=3,w3=4。恰两个活动底数位于0,r时，其余源小部都是固定整数m_h。
F16给出

    g^4 q_r^w_r < C_a n^(w_r-3),
    C_a=(17/64) product_(h=1..5,h!=r) m_h^w_h。

若位置0的底数为p、位置r为q，BFT给

    max(m0*g, m_r*q_r)>(n-5)^lambda(p,q)。

所以对D_a=max(m0^4,m_r^w_r)，

    g^4 q_r^w_r > (n-5)^theta / D_a,
    theta=min(4,w_r)*lambda(p,q)。

r=2时余次数0，全部底数对都取得高度；r=3时余次数1，
(2,3)、(2,5)的theta分别1.140、1.032，严格超过1。
(3,5)仅theta=.864，所以4个相应原模类明确不计入本轮成功。
