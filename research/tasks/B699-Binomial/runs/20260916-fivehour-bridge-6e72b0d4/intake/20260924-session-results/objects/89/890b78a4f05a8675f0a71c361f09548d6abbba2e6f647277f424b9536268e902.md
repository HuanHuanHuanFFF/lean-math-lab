## 0. 范围与采用前置

本轮只在同一个原始合法 `(n,j)` 的规范最小临界两底、真实 `mu=1`、平衡 `D_v=D_W=y` 必要核心内工作。继续保留：

- 完整平方范数；
- `P=p0^a,Q=q0^r` 为不同奇素数的完整幂；
- `n=c*2^s,c in {1,3}`；
- 原始 `(n,j)` 不替换、不拼接；
- BRIDGE4096 的全部旧条件。

采用 Round 13 已证明的同源接口

```math
(n-3)^2 \equiv 5 \pmod y,
\qquad y=U_t/2,
\qquad t=8q+1,
```

其中

```math
U_k+X_k\sqrt3=(2+\sqrt3)^k.
```

Round 13 的八个 BAD-RANK 种子已重新重放并按其冻结 SHA-256 采用。本轮没有修改仓库，不是 Lean，不是完整 `i=3`，也不是完整 B699 闭合。

## 1. 先得到统一的 t-高度与 POWER 赋值走廊

本轮先把 Round 13 的 `y=U_t/2` 接回原始范数大小，而不是立刻增加 rank 表。

### 1.1 全平衡核心的线性高度

由

```math
(n-3)^2\equiv5\pmod y,
\qquad y=U_t/2,
```

以及 `n=c2^s,c<=3`，得到

```math
y\le(n-3)^2-5<n^2.
```

写 `alpha=2+sqrt(3)`，则

```math
y=(alpha^t+alpha^(-t))/4>alpha^t/4.
```

故

```math
\boxed{s\ge(t-5)/2.}
```

反向，利用同一核心中的

```math
AB=3(d-1),
v=Ay,
Q=d+v,
P=Q+hv,
2nu=hd-Q,
vnu^2=PQ^2-1,
```

可统一估计

```math
v<3d^2,
Q<4d^2,
h<100d^2,
nu<50d^3,
P<304d^4,
```

从而

```math
n<2^16 d^9.
```

又 `U_t=2y` 与 `d^2+d+1=3y^2` 给

```math
3X_t=2d+1,
```

所以 `d<alpha^t<4^t`。因此

```math
\boxed{s\le18t+15.}
```

也就是说，整个平衡核心的新必要走廊为

```math
\boxed{(t-5)/2\le s\le18t+15.}       [T-HEIGHT]
```

它同时约束 pure-two 与 odd--odd；这不是绝对高度，但删除了 `s/t` 的两个无界外侧扇区。

### 1.2 BRIDGE4096 的强下界

在纯二高桥中，Round 12 还有

```math
n>32d^3.
```

而 `t=8q+1=1 mod8`、`alpha^8>2^15`。由 `d>alpha^t/8` 得

```math
\boxed{s\ge(45t-61)/8.}
```

Round 12 的精确 POWER 赋值为

```math
v2(R)=s+2.
```

故 BRIDGE4096 必须满足新的同源门

```math
\boxed{45q\le v2(R)\le144q+35.}       [Q-POWER]
```

其中下界使用 `t=8q+1`，上界来自 T-HEIGHT。旧下界只有 `3rho+9`；Q-POWER 直接删除所有

```math
rho>=12,
\qquad v2(R)<45q
```

的无界高桥状态。固定 Pell 行的唯一 Hensel 乘子现在必须命中模 `2^(45q-3)` 的唯一奇类，而不只是模随 `rho` 线性增长的低精度类。

## 2. 新的一般接口：RANK–EXPONENT

Round 13 只使用了 `(5/ell)=1`。本轮保留完整的

```math
n=c2^s.
```

若奇素数 `ell|y`，取 `z^2=5 (mod ell)`，则

```math
c2^s = 3+z  or  3-z  (mod ell).          (RE)
```

令 `o_ell=ord_ell(2)`，定义

```math
E_(ell,c)={e mod o_ell : c2^e=3±z mod ell}.
```

真实输入必须满足

```math
s mod o_ell in E_(ell,c)
```

并且同一个全局 `c`、同一个全局 `s` 必须同时通过 `y` 的所有素因子。

若奇数 `r|t` 且 `ell|U_r`，因为 `t/r` 为奇数，所以 `ell|U_t`。因此任意若干 `U_r` 素因子给出的指数类必须有共同 CRT 解。这比 SPLIT60 严格；即使所有 `ell` 都位于允许的 `1,49 mod60`，指数类仍可能完全不相容。

## 3. 四个整秩无界域被完全删除

本轮得到

```math
\boxed{17\nmid t,\quad29\nmid t,\quad37\nmid t,\quad49\nmid t.}
```

等价地，BRIDGE4096 的真实状态必须避开

```text
q =  2 mod 17,
q = 18 mod 29,
q = 23 mod 37,
q =  6 mod 49.
```

这些是横跨每个 `rho>=12` 的完整无界算术级数删除。

### 3.1 `17|t` 完整排除

```math
U_17/2=1321442641
```

是素数。对 `ell=1321442641`，

```math
ord_ell(2)=66072132,
```

而 `E_(ell,1)=E_(ell,3)=empty`。所以 `(RE)` 没有任何指数 `s`，故 `17|t` 不可能。

### 3.2 `29|t` 完整排除

两素数

```math
349|U_29,
\qquad6961|U_29
```

给出：

```text
ell=349:  E1={113,237} mod348, E3={87,211} mod348;
ell=6961: E1=empty, E3={926} mod1160.
```

`c=1` 被第二素数直接排除；`c=3` 时 `gcd(348,1160)=116`，前者残类为 `{87,95}`，后者为 `{114}`，不相交。

### 3.3 `37|t` 完整排除

```text
ell=2221:  E1={991,1231}, E3={463,703} mod2220;
ell=99901: E1={14803,85099}, E3={25007,95303} mod99900.
```

`gcd(2220,99900)=2220`。第二行约化后：

```text
E1={1483,739}, E3={587,2063} mod2220,
```

与第一行分别不相交。

### 3.4 `49|t` 完整排除

```text
ell=2521:   E1={22,1240}, E3={690,732} mod1260;
ell=197569: E1=empty, E3={474,37997} mod49392.
```

`c=1` 直接退出；`c=3` 时 `gcd(1260,49392)=252`，两侧分别为

```text
{186,228}  and  {222,197} mod252,
```

不相交。因此不仅不能有第二个 `7` 因子，真实状态必须满足

```math

```

## 8. 失败边界

### 8.1 秩筛仍不能统一闭合

令

```text
M=703603718111238643043345
```

为本轮及上一轮全部有限秩模数的乘积（`7` 侧使用 `49`）。对每个 `rho>=12`，取

```math
q=3\cdot2^{rho-3}M(2k+1),
\qquad t=8q+1.
```

则 `v2(q)=rho-3`、`3|q`、`t=1 mod4096`，而且 `t=1` 模每个已用秩。因此存在无穷多**形式 Pell 行**避开全部当前有限秩筛。

它们没有通过平方、POWER、`m|9u`、完整 `P/Q` 或原 `(n,j)` 恢复，所以不是 NC3 或反例；它们只证明有限秩列表不能冒充统一闭合。

### 8.2 本轮没有处理的关键接口

- 没有证明 VROW1 唯一乘子强制某个坏秩；
- 没有把 `m|9u` 接入指数类；
- 没有使用完整 POWER 奇部取得 `q` 或 `rho` 的绝对界；
- 没有构造保持同一 NC3 输入的严格下降；
- 没有恢复新的合法 `(n,j)`。
