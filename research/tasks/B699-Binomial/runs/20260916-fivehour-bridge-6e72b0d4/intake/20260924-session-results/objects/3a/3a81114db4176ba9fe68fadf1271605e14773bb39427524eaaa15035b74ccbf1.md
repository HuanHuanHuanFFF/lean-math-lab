# PROOFS — C11：正十六次核与 B/RES10 完整闭合

## 0. 原始量词、方向和采用前置

固定同一个合法原输入

```text
n≡5130 (mod9000), 7≤j≤floor(n/2), k=n-j,
g=gcd(n,j), alpha=n/g=3^a,
(n-1)jk=10Y^2.
```

反设它是 NC6。任何完整源窗口失败都会由失败粗素数给出同一原 `(n,j)`
的 Common6，因此以下可保留全部完整源分配。

沿用 C10 已证明的必要结论。令 `X=n-5`，则

```text
n>10^24,
q2>X^(57/200),
q5>X^(27/125),
g≥10,
d=sf(E3E4)≥7.                                      (0.1)
```

BFT 的40对显式例外及付款者判别已在C9/C10确定性重放；本轮不把外部定理
重新登记成新证明。

## 2. 完整源幂逐槽收费

定义当前指标自己的完整块：

```text
q2=E2 M2,
q3=E3 I3,
q4=E4 A4 C,
q5=Q50 Q51 Q52.
```

各块对应：

- 第2源：端点 `E2`、中心 `M2`；
- 第3源：端点 `E3`、内部 `I3`；
- 第4源：端点 `E4`、近侧 `A4`、中心 `C`；
- 第5源：端点 `Q50`、近侧 `Q51`、中央 `Q52`。

并置

```text
epsilonE=sf(E2), d=sf(E3E4), tau50=sf(Q50).
```

### 2.1 普通Taylor阶

由§1表，完整源幂直接贡献

```text
q1^8,
E2^3 M2^4,
q3^4,
q4^3,
Q50^2 Q51^2 Q52.
```

### 2.2 十倍平方的端点偶精度

第一源恢复

```text
U=jk/(n-1)=10g^2z^2.
```

所有粗源素数与 `n-1`、`10g` 互素，所以在任何端点粗素数处
`vp(J)=vp(U)` 为偶数。

核中端点的 `J^2` 因子因此给：

```text
E2^3 epsilonE^2 M2^4
  =q2^3 M2 epsilonE^2,

q3^4 sf(E3)^2,

q4^3 sf(E4)^2,

Q50^2 tau50^2 Q51^2 Q52
  =q5 Q50 Q51 tau50^2.
```

不同源粗块两两互素，且与 `g` 互素；`J^2` 又给 `g^4|F16`。合并得

```text
q1^8 q2^3 q3^4 q4^3 q5
 M2 Q50 Q51 epsilonE^2 d^2 tau50^2
   | F16(j,k)/g^4.                                  (K16-DIV)
```

每个指数都来自原完整层或实际目标赋值；没有工作层升格。

## 3. 统一大小界

`H8` 的原系数绝对值和为

```text
L=1388988.
```

因 `0<x,y≤n`：

```text
H8(x,y)≤L n^8.
```

又

```text
J≤n^2/4, 0<A<J,
```

故

```text
0<F16(j,k)<(L/256)n^16.                             (3.1)
```

当前 B尾准确小部为

```text
q1=n-1, q3=(n-3)/3, q4=(n-4)/2.
```

所以

```text
q1^8q3^4q4^3
 =n^15[(1-1/n)^8(1-3/n)^4(1-4/n)^3]/648.
```

Bernoulli乘积给括号至少 `1-32/n`；由 `(0.1)` 它严格大于 `1/2`。因此

```text
q1^8q3^4q4^3>n^15/1296.                            (3.2)
```

将 (3.1)、(3.2) 代入 K16-DIV：

```text
16g^4 epsilonE^2 d^2 tau50^2
 M2 Q50 Q51 q2^3q5
   <81L n.                                           (K16-MASS)
```

## 4. 最终矛盾

由 (0.1)：

```text
q2^3 q5
 >X^(3*57/200+27/125)
 =X^(1071/1000).                                    (4.1)
```

K16-MASS 中使用

```text
g≥10, d≥7,
epsilonE,tau50,M2,Q50,Q51≥1,
```

得到

```text
q2^3q5
 <[81L/(16*10^4*7^2)]n
 =(28127007/1960000)n.                              (4.2)
```

函数

```text
f(n)=(n-5)^(1071/1000)/n
```

的对数导数分子为

```text
1071n-1000(n-5)=71n+5000>0,
```

故严格递增。重放以纯整数验证在 `N=10^24`：

```text
1960000^1000 (N-5)^1071
  >28127007^1000 N^1000.                            (4.3)
```

由 `n>N`，(4.1) 与 (4.3) 反驳 (4.2)。所以不存在假想 NC6。

## 5. 回到原题

任取 B/RES10 原始合法 `(n,j)`：

- 若某完整源窗口失败，失败粗素数 `p≥7` 是真实共同见证；
- 若窗口全成立，§§1–4产生严格整数矛盾。

因此

```text
B/RES10 ==> Common6
```

对全部原始数对成立。证明没有构造新 `n,j`、没有指标交换，也没有把必要窗口
反向识别为NC6。
