## 1. UF7：三落点统一成 `r*d4>=7`

### 1.1 `d4>1`

`d4` 是 `E4` 的平方自由核，其素因子均来自 `q4` 的粗块，因此都至少为7。于是

```text
d4>1 => d4>=7 => r*d4>=7.
```

### 1.2 `d4=1`

此时 `E4` 是整数平方。

B尾有 `n≡2 (mod8)`，而 `alpha=3^a` 为奇数，所以 `v2(g)=1`。写 `g=2g0`，则

```text
K=(45/4)*(2g0)^3*d*v^2*L3
 =90*g0^3*d*v^2*L3,
```

故 `90|K`。由 `A4-Cr=K`：

```text
A4≡Cr (mod2,3,5).                                (1.1)
```

`q4` 与30互素，故 `E4,A4,C` 都与30互素。

- 模2：`A4,C` 都奇，(1.1) 给 `r` 奇。
- 模3：`n≡0`，故 `q4=(n-4)/2≡1`。又 `E4` 和 `C^2` 是非零平方模3，所以

  ```text
  q4=E4*A4*C≡E4*C^2*r≡r (mod3),
  r≡1 (mod3).
  ```

- 模5：`n≡0`，故 `q4≡3`。`E4*C^2` 是非零平方模5，等于1或4，因此

  ```text
  r≡3 或 2 (mod5).
  ```

在模30完整联立：

```text
r≡7 或 13 (mod30).
```

所以 `r>=7`，即 `r*d4>=7`。

综上：

```text
r*d4>=7.                                          (UF7)
```

这个论证无需再区分非平方内容落在 `A4`、`C` 或二者同时；它也没有声称一般 `d4>=7`。

## 3. 固定三移位多项式的 S-part 下界

定义

```text
F(X)=X(X-2)(X-5),
S={2,3,5}.
```

对非零整数 `m`，记 `[m]_S` 为其所有 `S` 中素数的完整幂部分。

当前准确小部给：

```text
3^a=n/g,
2^b=(n-2)/q2,
5^E=(n-5)/q5.
```

其中 `q2,q5` 与30互素。`g` 可以含额外 `S`-部分，但这只会增大 `[n]_S`，所以

```text
[n]_S>=3^a=n/g,
[n-2]_S=2^b=(n-2)/q2,
[n-5]_S=5^E=(n-5)/q5.
```

S-part 对乘积的赋值可加，因此

```text
[F(n)]_S
 =[n]_S[n-2]_S[n-5]_S
 >=F(n)/(g*q2*q5).                                (3.1)
```

置

```text
P=g*q2*q5.
```

## 5. BEG 定理消灭整个无界前沿

采用 Bugeaud–Evertse–Győry Theorem 2.1(i)：若整数多项式 `f` 无重根、`S` 是固定有限非空素数集，则对任意 `epsilon>0`，

```text
[f(x)]_S <<_{f,S,epsilon} |f(x)|^(1/deg(f)+epsilon),
```

隐常数一般非有效。

本轮 `F=X(X-2)(X-5)` 有三个互异整数根，故满足前提。取 `epsilon=1/6`，存在非有效常数 `C_BEG>0`，只依赖 `F,S`，使

```text
[F(n)]_S<=C_BEG*|F(n)|^(1/2)<C_BEG*n^(3/2).       (5.1)
```

与 CENTER-SPART 比较已经得到

```text
(sqrt(300)/4)n^(5/2)<C_BEG*n^(3/2),
n<4*C_BEG/sqrt(300).
```

与更强的 RGAP-SPART 比较则得到

```text
(55930^(1/3)/4)n^(8/3)<C_BEG*n^(3/2),
n^(7/6)<4*C_BEG/55930^(1/3).                     (5.2)
```

所以存在绝对常数 `B_RES10`，使当前分支的所有 NC6 输入都满足

```text
n<=B_RES10.
```

`B_RES10` 非有效：本证明不能计算它。

对每个固定 `n`，合法 `j` 只有有限多个，因此当前整条分支只含有限多个原始 `(n,j)`。换言之，它不再有任何无界参数族或无界序列。

## 6. 有效化门槛与便宜否证检查

假设有有效估计

```text
[F(n)]_S<=kappa2*|F(n)|^(1-kappa1).
```

因为右侧增长至多 `n^(3(1-kappa1))`，RGAP-SPART 产生显式矛盾所需且在增长指数层面充分的条件是

```text
3(1-kappa1)<8/3,
kappa1>1/9.                                       (6.1)
```

CENTER-SPART 单独对应门槛 `kappa1>1/6`。

BEG Theorem 2.2 的声明形式中，对分裂域次数 `d=1`：

```text
kappa1=(c1^s*(P0*product(log p in S)))^-1,
```

其中这里用 `P0` 表示 `S` 中最大素数，避免与本稿粗余因子 `P` 混淆。

用同一多项式、`S0={2}`、`x=2^m (m>=3)`：

```text
[F(x)]_{S0}=2x,
F(x)~x^3.
```

因此有效估计不可能有 `3(1-kappa1(S0))<1`，故

```text
kappa1(S0)<=2/3.
```

而

```text
kappa1(S0)=1/(2*c1*log2),
```

所以

```text
c1>=3/(4log2).
```

对 `S={2,3,5}`：

```text
kappa1
 <=64(log2)^2/[135 log3 log5]
 ≈0.12881856220645893.
```

该上界仍严格大于 `1/9`，所以这项最便宜诊断没有排除有效化；它也没有证明实际 `kappa1>1/9`。

## 7. 回到原题和范围边界

本轮不构造新数对、不改变 `(n,j)`，也不把必要系统反向当作 NC6。

- 违反 UF7、RGAP7 或新指数门时，冻结完整源合同返回同一原输入的 Common6 见证；
- 满足全部必要条件的当前分支，由 BEG 定理证明只能落在一个非有效有限集合；
- 该有限集合尚未生成或核验，所以未闭合当前 i6 分支；
- 结论不自动覆盖 A尾、非全近侧、非低残量、小缺欠或一般 i6。
