# REPLAY

环境：Python 3.10+；仅符号脚本需要SymPy 1.14.0。其余使用标准库、任意精度整数、Fraction和isqrt，无网络、无随机数、无仓库要求。

```bash
sha256sum -c SHA256SUMS
bash replay.sh
```

replay.sh在临时目录重新计算：13条符号关系；864状态/430空单元证书；有理预算、不同根算法检查、Pell线性递推、原n模16回归、坏证书拒绝；28个全有理区间回归。所有结果逐字节比对后删除临时目录，不修改证据源。

完整有限末端只有q≤25，边界来自PROOFS P6；不是扫描任意小q后外推。程序不证明PROOFS全部实数不等式量词，不重证冻结桥，也不验证Lean。
