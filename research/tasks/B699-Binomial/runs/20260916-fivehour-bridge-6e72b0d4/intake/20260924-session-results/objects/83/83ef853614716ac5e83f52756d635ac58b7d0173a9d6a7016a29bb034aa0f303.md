## 结论摘要

本轮没有继续机械放大 CRT。先用二次特征判别处理 `q4=E4 A4 C` 的三个奇指数落点，再检查真实 `p>=31|q5` 的下一 `p` 进层。

### 1. q4 的三落点压缩为两落点

当前高指数壳给

```text
n ≡ 210 (mod 240),
q4=(n-4)/2 ≡ 103 (mod 120), 特别 q4≡23 (mod40),
(10/q4)=-1.
```

对每个 `p|A4`，真实近侧槽给 `U≡1 (mod p)`；而 `U=10g^2z^2`，故 `(10/p)=+1`。因此

```text
(10/A4)=+1,
(10/(E4 C))=-1.
```

写

```text
E4=d4 h4^2,      C=c4 t4^2,
tau4=sf(E4 C)=d4 c4.
```

则

```text
tau4>=7.
```

所以整个“`E4` 与 `C` 都是平方、`q4` 的全部奇指数只落在 `A4`”无界分支被排除。剩余只有：

```text
sf(E4)>1，或 sf(C)>1
```

（两者可同时发生）。这不能误写成无条件 `d4>=7`。

### 2. 用完整中心块 C 得到统一粗因子

置

```text
kappa4=d4*C.
```

因为 `C=c4 t4^2`，有

```text
kappa4=d4 c4 t4^2 >= tau4 >=7.
```

同一原输入上证明新的严格必要不等式

```text
n > 300*g^4*d*(d4*C)*q2^2*sigma2*q5^2.       (CENTER-SF)
```

特别

```text
n > 300*g^4*d*tau4*q2^2*sigma2*q5^2
  > 2100*g^4*d*q2^2*sigma2*q5^2.
```

这不是把旧 GAP-SF 中的 `d4` 偷换成 `tau4`；它是一条使用完整中心块 `C` 的新不等式。分支解释为：

- 若 `d4>=7`，旧 GAP-SF 已直接获得额外粗因子；
- 若 `d4=1`，本轮强迫 `sf(C)>=7`，并由 CENTER-SF 消费完整 `C`。

因此三落点获得了完整、合法的二分压缩。

### 3. p>=31|q5 的第一额外 p 进层无收益

取 `Q=p^e||q5`，全近侧写

```text
n=5+Qh, j=1+Qy, U=1+Qxi.
```

精确关系为

```text
(4+Qh)xi = y(3+Q(h-y)).
```

故若 `s=vp(eta)>0`，则

```text
vp(y)=vp(xi)=s,
vp(U-1)=e+s.
```

对原核心 `K,H7,T` 精确展开后：

```text
K   ≡ 20   (mod p),
H7  ≡ -13  (mod p),
T/Q ≡ 16h  (mod p)       (s>=1).
```

对 `p>=31` 三者均为单位（`T` 只含原来的 `Q`）。于是 `L4,L6,L7` 在 `p` 上仍全为单位；额外指数只进入 `eta`。而

```text
5^E - T/(48 q3 q4 q5)
 = 5^E (U-1)H7 / [8(n-5)(n-4)(n-3)]
 = eta*ell7
```

是恒等式，不能再独立约束 `s`。`q2` 的平方自由精度与 `q5` 互素，也不会改变这个局部结论。

所以“只沿 `L4/L6/L7` 和下一工作层约束 `vp(U-1)`”被判定为低收益路线；本轮没有由此删除真实 NC6 域。
