# Replay

## 环境
Python3；第一个实现需要SymPy（实际环境记录见ENVIRONMENT.json）。
第二实现check.py只用标准库。无需网络、仓库、随机数或编译。

## 冷重放

```bash
bash replay.sh
```

该命令先检查包内哈希，在全新临时目录生成两份JSON，要求与冻结证书逐字节一致，并退出删除临时目录。
它不覆盖冻结证据，不修改仓库。

- derive.py：完整DIFF符号恒等式、完整因子形式模型、实际原行应用和失败原输入。
- check.py：独立稀疏多变量系数检查、Fraction长除法、D的直接除数算法、完整有重因子槽模型、以数字和复核5赋值。
- gate.py：可复用充分判据；失败返回INCONCLUSIVE，绝不返回“反例”。素性采用精确试除，巨大p可能成本高。
