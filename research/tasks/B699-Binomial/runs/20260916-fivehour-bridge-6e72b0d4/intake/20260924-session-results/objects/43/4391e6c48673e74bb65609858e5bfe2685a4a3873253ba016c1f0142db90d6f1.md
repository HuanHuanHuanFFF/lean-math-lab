# HANDOFF — C12

## 当前准确前沿

两个旧 H025 尾类已经没有无界 NC6 前沿：

```text
A: n≡1280 mod1800, NC6 => n<2^291;
B: n≡1530 mod1800, NC6 => n<2^523.
```

模板细界：

```text
A:
 alpha=2^a     -> n<2^223;
 alpha=5*2^a   -> n<2^291.

B:
 alpha=3^a     -> n<2^336;
 alpha=2*3^a   -> n<2^392;
 alpha=5*3^a   -> n<2^467;
 alpha=10*3^a  -> n<2^523.
```

不要再把这些尾类描述为参数无界；准确说法是“显式有限末端未完成”。

## 最值得继续的方向

### 方向1：压缩精确最坏付款壳

最坏增长只发生在：

```text
BFT由q2与q5分别付款，
K16中M2=1且Q50=Q51=1
```

即第2源全端点、第5源全中央。首检它是否与既有 D25、缺欠、
`Q52|2U-3` 或 alpha 模板产生额外冲突。成功可显著降低高度甚至闭合；
失败应给同一原输入的精确相容壳。

### 方向2：把 K16 移出两尾

对一般 i6 模类，先计算真实小部 `(s1,s2,s3,s4,s5)` 和可用 alpha 模板，
再求

```text
degree - (8+4+3)
```

对应的付款矩阵。不要默认 A/B 尾的小部常数。

### 停止点

直接枚举到 `2^291` 或 `2^523` 不可取；机械增加有限模数也不是末端方法。
