# B699 C11 evidence

This package proves a new positive degree-16 source kernel and uses it to
close the full **B-tail RES10** branch for `i=6`.

The proof retains the same original `(n,j)` and every complete prime power.
It uses the already replayed C10 payer gates and the published
Bennett–Filaseta–Trifonov input fixed in C9/C10.

Replay:

```bash
python3 -B code/replay.py
```

Evidence level: author paper proof + deterministic exact-integer replay +
published BFT theorem input. This is not Lean verification, not an external
independent review, and not a complete proof of B699.
