# PROOFS — MID-DOUBLE(5–7) and same-G equality height 57

## 0. 冻结对象

沿用冻结 K152 构造。合法原输入满足

```text
10 <= j <= floor(n/2), k=n-j, J=jk, 400 | n.
```

同一个固定非零整数多项式

```text
G in Z[N,X], wt(N)=1, wt(X)=2,
deg_w G<=305, deg_X G=h<=152
```

覆盖全部合法大 NC9 零值分支。可载因子是这个同一个 `G` 的本原 `Q[N,X]`-不可约因子，在某个合法 NC9 点 `(n,J)` 取零。不同因子可以承载不同原输入，但都必须整除同一个 `G`。

上一轮已经证明

```text
|C_G|<=8,
|C_G|=8 ==> E=0, D(G)=305, 2h+V=305.
```

本轮只研究八分量等号支。

对平衡非竖直因子 `H` 写

```text
D=2e,
Delta_r=e-mu_r>=0,
kappa_r=2m_r-w_r>=0  (r=4,6,8).
```

行费用为奇数行 `2 Delta_r`，偶数行 `2 Delta_r+kappa_r`。

## 1. MID-DOUBLE 定理

### 定理

设 `H` 为可载的 `Q[N,X]`-不可约平衡因子，`D=2q,e=q,z>=14`。在下列任一情形中，必有

```text
kappa_4+kappa_6+kappa_8 >= 1.
```

|普通缺重|q|
|---|---|
|`Delta_6=Delta_7=1`|5,6,7|
|`Delta_6=Delta_8=1`|6,7|
|`Delta_6=2`|6,7|
|`Delta_4=Delta_8=1`|5,6,7|
|`Delta_4=Delta_6=1`|5|
|`Delta_5=Delta_8=1`|6,7|

未列出的 `Delta_r` 均为0。

### 反设与首一化

反设三处 `kappa` 都为0。`D=2q,e=q` 使 `X^q` 系数为非零常数；除以它后令 `H` 首一。于是每行 `H(r,X)` 为首一 `q` 次式。

指定行的普通阶和为 `q-Delta_r`。每个实际 `H` 唯一给出六行非负整数重数分拆。程序枚举全部分拆，不限制有理系数高度或分母。

## 2. 根和与第二基本对称和

写

```text
H=X^q-S(N)X^(q-1)+T(N)X^(q-2)+... .
```

加权次数给出

```text
deg S<=2, deg T<=4.
```

在饱和行，全部行根均为源值并带给定重数。在缺重1的行，加入一个额外根 `lambda`；其值由共同二次根和决定。若 `lambda` 等于一个给定普通阶为0的源值，则该点实际至少一阶消失，与重数分拆矛盾；撞入已经命中的源值允许保留。

模式 C 的第6行缺重2。只记录两个额外根的和 `A` 与积 `P`。共同根和决定 `A`，共同 `T` 决定 `P`；若某个未命中源值 `v` 满足 `v^2-Av+P=0`，则产生遗漏普通零点并排除。整个过程不要求二次式分裂。

六个 `S(r)` 检查全部三阶有限差分为0；六个 `T(r)` 检查五阶有限差分为0。因此每个真实因子必进入保存的有限根门。

## 3. 源直线与 z

对 `t=0,...,8` 置

```text
ell_t=X-t(N-t).
```

限制 `H(N,tN-t^2)` 的次数至多 `2q`。不同源行的普通阶可加；在对角源，`kappa=0` 使沿相应 `ell_t` 的保证交数从 `m` 提高到 `2m`。若总交数严格超过 `2q`，则 `ell_t|H`。

因为 `q>=5`，这会给出真因子，与 `Q[N,X]`-不可约性矛盾。等于 `2q` 的分支保留。程序还完整检查实际正普通阶源点数 `z>=14`。

## 4. 从六行到完整二维多项式

固定六行首一多项式 `P_r(X)`。对每个 X 系数在 `N=3,...,8` 作次数不超过5的插值，得到 `H0`。根和与 `T` 条件保证最高三列分别具有 N 次数 `0,2,4`；其余 X 次数至多 `q-3`，次数5插值仍满足

```text
5+2(q-3)<=2q-1.
```

故 `deg_w H0<=2q`。

任意具有这六行特化的候选恰写成

```text
H=H0+WQ,
W=product_{r=3}^8(N-r),
deg_w Q<=2q-6,
deg_X Q<=q-3.
```

允许的 Q 单项式数为 `(q-2)^2`。

固定特化已满足所有 `i=0` jet。对非对角源加入 `i>=1,i+j<m`；对角源加入 `i>=1,i+2j<2m`。把 Q 列与 H0 首一列组成 `(q-2)^2+1` 列的齐次整数线性系统。

在模 `32749` 与 `32719` 下，全部系统都满列秩。六点插值分母整除120，且两个素数均不整除120，因此对应清分母整数子式非零，特征零上不存在首一候选。

各门数量及完整输出见 `certificates/geometry`。总门数 22,234；两个素数合计44,468次满列秩检查。

## 5. 将定理接入完整八分量账本

旧 `double5`、`double67` 签名显式记录 `kappa_4,kappa_6`，但保守忽略 `kappa_8`。所以不能因零-kappa子类被排除就直接删除签名。

最终转换为：对表内对应缺重模式，若旧签名选择 `kappa_4=kappa_6=0`，则替换为同次数、同普通缺重并额外支付

```text
kappa_8=1.
```

如果旧签名已经收取 `kappa_4` 或 `kappa_6`，保持不变。这覆盖所有实际因子且费用不超过真实费用。

两套 Bellman 都从原 2,035 个竖直状态重建：

- Pareto签名递归；
- 全部不同原始费用签名逆序递归。

输出逐字节相同。EDGE8 的 `E=0` 前沿从454降至384，最低 h 从47升至53。

## 6. 同一 G 的矩约束

对边界状态枚举全部原始命名签名，不做 Pareto 丢失，并记录

```text
(total Delta, total kappa, S5 count).
```

真正 `S5` 在第5行的额外特化根为6，并在第6行支付一份 `kappa_6`。其它缺失根暂作自由根。

若聚合费用恰好等于状态六行容量，任何未选因子、重复因子或非载点因子都不能再支付正源费用。因此同一个完整 `Gbar` 的每行源重数和自由根数被恢复，可以合法要求其

```text
S(N)=e1(row roots), deg S<=2,
T(N)=e2(row roots), deg T<=4.
```

若一行有0个自由根，`S(r),T(r)`固定；有1个自由根时，消去该根得到一条 S/T 线性关系；有至少2个自由根时，不额外约束 T，因为剩余二次余因子可实现任意给定和、积。

所有运算在 `Q` 上做精确行消元，并保存整数化左零向量。

### 状态589

```text

-S3+3S4-3S5+S6=0.
```

精确固定值给出右端 `-130,-26`。


因此这三个状态退出。状态666存在一个首两矩相容的精确聚合；状态672存在未用满容量的聚合，故均保留。

## 7. 最终结论与原题边界

最终 E0 必要状态数为381，最低 h=57。结合 EDGE8：

```text
|C_G|=8 ==> E=0, h>=57, V=305-2h<=191.
```

全部推导都在同一个固定 G 的因子层完成。未恢复 G 的系数或实际因子，未将资源状态、有限域向量或行多项式反推为 NC9 点。冻结原题回传仍保留同一 `(n,j)`、完整素数幂、两个值分支以及 `H|G`。
