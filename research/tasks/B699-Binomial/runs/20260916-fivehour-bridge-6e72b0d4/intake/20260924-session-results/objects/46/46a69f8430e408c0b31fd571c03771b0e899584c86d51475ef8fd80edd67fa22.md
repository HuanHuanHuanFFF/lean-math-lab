# FAILURES · Round 17

## F1. `rho<=27` 仍有巨大有限底部

本轮把纯二桥从 `rho<=55` 推到

```math
12<=rho<=27,
```

但在施加其他条件以前仍有

```math
2^44-2^28=17,591,917,608,960
```

个形式 `q` 行。不能把高层排空写成纯二桥已经闭合。

## F2. `INDEX-RANK-GAP` 只是必要条件

```math
P^-(4q+1)<=27*2^(rho-3)
```

删除粗糙索引行，但不说明具有小素因子的行真实存在，也不恢复 `m`。它不是充分条件或反例生成器。

## F3. 不能把 `4q+1` 素数子域闭合扩大成一般合数索引闭合

素数索引时，秩只有一个非平凡选择，故可把 `m` 压回小乘子分支。合数索引可从真因子继承旧 Pell 素因子；本轮没有排除这些分配。

## F4. campaign 依赖 Round 16 的有效高度

`rho=28,...,55` 的枚举使用

```math
q<2^53.
```

它不是一个独立于 Round 16 的、对任意大 `q` 成立的统一 `v2(R)<=68` 定理。不得把有限 campaign 外推到被 Matveev 已排除的范围。

## F5. `2^80` 门不是原共同素数见证

模 `2^80` 仅用于否定 POWER 必要赋值。返回原题的逻辑是：必要 `NC3` 状态不存在，因此原输入必须有某个真实共同素数 `p>=3`。本轮没有辨识该素数。

## F6. 计算证据边界

- C++ campaign 使用精确 `2` 幂模运算，不是浮点扫描；
- Python 任意精度实现完整覆盖 `rho=40,...,55`；
- 252 项双实现交叉核验不能单独替代完整 campaign，但与完整分片收据、覆盖审计和源码哈希共同构成重放证据；
- 程序 PASS 不是 Lean 或外部独立数学审读。

## F7. 未处理区域

本轮没有有效化平衡 odd--odd，也没有触及：

- 非平衡两底；
- 一般 low/low 与交叉指数域；
- 非最小临界支；
- 负向三槽、真三槽、一般多槽；
- 其他恢复三次。
