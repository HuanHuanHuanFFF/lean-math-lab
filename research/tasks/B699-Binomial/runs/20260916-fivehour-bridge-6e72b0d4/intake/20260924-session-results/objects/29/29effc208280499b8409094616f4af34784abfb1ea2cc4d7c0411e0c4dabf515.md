## 主结果

对全部自然数 n,j，

```
n mod1800 ∈ {1280,1530}, 7≤j≤floor(n/2)
  ==> ∃ prime p≥7, p|C(n,6) and p|C(n,j).
```

不需要RES10、十倍平方、纯第5源、单位第2块或指定粗素数支持。
C15仍开放的中央混合尾域在本轮全部退出。

整行结论是对每个j分别存在p，不要求同一行的所有j共用一个固定p。
这是两个准确模类，不是一般H025、一般i=6或完整B699。

## 本轮改变的不是核，而是有限末端的恢复方式

C12已给A尾n<2^291、B尾n<2^523。C13–C15继续按源块分配缩小区域。
本轮初查纯中央/混合q2后，转而寻找整个尾盒的完备恢复。

关键是原生QIG：令T4为前四项的完整235小部之积，任何NC6必须

```
T4^6(3n²-12n+8)≥2^20(n-1)^6(n-3)^3.
```

两尾恰有

```
T4=10PQ (A), T4=30PQ (B),
P=实际最大完整2幂, Q=实际最大完整3幂.
```

当n≥8192时，QIG强迫PQ>n。因此n是两条真实同余的唯一最小代表，
不允许任意CRT提升；在既有高度下只需枚举两个指数，不需枚举n、g、j、
q5支持或第2/5源混合分配。
