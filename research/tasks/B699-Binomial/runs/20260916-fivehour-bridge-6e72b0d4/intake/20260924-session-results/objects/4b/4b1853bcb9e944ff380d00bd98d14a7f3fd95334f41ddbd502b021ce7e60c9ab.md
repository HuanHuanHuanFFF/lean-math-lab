# REPLAY

环境：Python 3，`sympy==1.14.0`。不需要网络、仓库或随机数。

```bash
python3 -B src/replay_nonic.py
python3 -B src/derive_111.py
python3 -B src/independent_check.py
python3 -B src/cost_probe_21.py
```

- `replay_nonic.py`：重建槽权枚举、单槽 Groebner 分类、形式点、完整 3 源恒等式及 `1+1+1` 的结式证书。
- `derive_111.py`：从 DIFF、三个槽值和二次插值商重新导出 `1+1+1` 的原始商系数。
- `independent_check.py`：只用标准库核对模 5/7/17 值表、判别式与尺度 gcd。
- `cost_probe_21.py`：重建六个剩余 `2+1` 图的线性秩与自由参数数目。

完整重放：

```bash
bash replay.sh
sha256sum -c SHA256SUMS
```

所有 PASS 只验证明确的有限代数证书；无限量词由 `PROOFS.md` 承担。
