# PROOFS — C12：K16 对 H025 两尾的统一有效有限化

## 0. 原始量词与冻结合同

固定原始合法 `(n,j)`，置

```text
k=n-j, g=gcd(n,j), alpha=n/g.
```

讨论

```text
A: n≡1280 (mod1800),
B: n≡1530 (mod1800),
7≤j≤floor(n/2).
```

反设 NC6。冻结合同给 `NC6=>NC5`，且

```text
A: alpha=c*2^a, c∈{1,5}, a≥3;
B: alpha=c*3^a, c∈{1,2,5,10}, a≥2;
g≥7.
```

这些是 NC 的必要条件，不作反向使用。

完整小部：

```text
A:
 q1=n-1,
 n-2=2*3^b*q2  (b=v3(n-2)≥2),
 q3=n-3,
 q4=(n-4)/4,
 n-5=3*5^E*q5;

B:
 q1=n-1,
 n-2=2^b*q2   (b=v2(n-2)≥3),
 q3=(n-3)/3,
 q4=(n-4)/2,
 n-5=5^E*q5.
```

## 1. 一般 K16 整除

使用 C11 的同一个严格正核。完整源槽阶为

```text
r1: 8,8
r2: 3,4,3
r3: 4,4,4,4
r4: 3,3,3,3,3
r5: 2,2,1,1,2,2.
```

定义第2源端点/中央块 `q2=E2M2`，第5源三块
`q5=Q50Q51Q52`。逐完整素数幂收费：

```text
E2^3M2^4=q2^3M2,
Q50^2Q51^2Q52=q5Q50Q51.
```

第3、4、1源各槽阶恒定，且 `J^2` 给 `g^4|F16`。所以

```text
q1^8 q2^3 q3^4 q4^3 q5 M2 Q50 Q51
  | F16(j,k)/g^4.                                    (1.1)
```

若任一源窗口失败，则失败粗素数已经给 Common6，不进入后续必要链。

## 2. 统一大小界

C11 精确证书给

```text
F16>0,
F16<(L/256)n^16,
L=1388988.
```

两尾共同有

```text
(1-1/n)^8(1-3/n)^4(1-4/n)^3
 ≥1-32/n>1/2,
```

因为 `n≥1280`。

### 2.1 A尾

```text
q1^8q3^4q4^3
 =(n-1)^8(n-3)^4(n-4)^3/4^3
 >n^15/128.
```

代入 (1.1)：

```text
2g^4M2Q50Q51q2^3q5<L n.                             (2.1A)
```

### 2.2 B尾

```text
q1^8q3^4q4^3
 =(n-1)^8(n-3)^4(n-4)^3/(3^4*2^3)
 >n^15/1296.
```

故

```text
16g^4M2Q50Q51q2^3q5<81L n.                          (2.1B)
```

## 3. BFT 例外检查

令 `X=n-5`。采用冻结的 BFT Theorem 2.1。

40对显式例外按绝对差分组：

```text
difference 2: none;
difference 5:
(1029,1024), (1215,1210), (30618,30613).
```

我们的相邻对的大分量都是 `n`。三个差5大分量既不为
`1280 mod1800`，也不为 `1530 mod1800`。故以下 BFT 门对全部尾输入成立。

## 4. A尾

真实表示：

```text
n=2^a(cg),
n-2=3^b(2q2),
n-5=5^E(3q5).
```

因此

```text
max(cg,2q2)>X^A, A=57/200;
max(cg,3q5)>X^B, B=129/500.
```

对每个 max 选择一个付款者，共四种：

|第一门|第二门|`g^4q2^3q5` 下界|
|---|---|---|
|`cg`|`cg`|`X^(4A)/c^4`|
|`2q2`|`cg`|`X^(3A+4B)/(8c^4)`|
|`cg`|`3q5`|`X^(4A+B)/(3c^4)`|
|`2q2`|`3q5`|`X^(3A+B)/24`|

四个指数分别为

```text
1.140, 1.887, 1.398, 1.113.
```

置

```text
deltaA=1113/1000,
D_A(c)=max(8c^4,24).
```

因 `X>1`，四支统一为

```text
g^4q2^3q5>X^deltaA/D_A(c).                          (4.1)
```

由 (2.1A) 丢掉 `M2Q50Q51≥1`：

```text
g^4q2^3q5<(L/2)n.                                   (4.2)
```

联立 (4.1)–(4.2)：

```text
X^1113 < [D_A(c)L/2]^1000 n^1000.
```

又 `X=n-5≥n/2`，所以

```text
n^113 <2^113[D_A(c)L]^1000.                         (4.3)
```

精确整数比较：

```text
c=1, D_A=24:
  2^113(24L)^1000 <2^(223*113),
  but not <2^(222*113);

c=5, D_A=5000:
  2^113(5000L)^1000 <2^(291*113),
  but not <2^(290*113).
```

因此 A 表成立。

## 5. B尾

真实表示：

```text
n=3^a(cg),
n-2=2^bq2,
n-5=5^Eq5.
```

BFT 门：

```text
max(cg,q2)>X^A, A=57/200;
max(cg,q5)>X^C, C=27/125.
```

四支指数为

```text
4A=1.140,
3A+4C=1.719,
4A+C=1.356,
3A+C=1.071.
```

故统一

```text
g^4q2^3q5>X^(1071/1000)/c^4.                       (5.1)
```

由 (2.1B)：

```text
g^4q2^3q5<(81L/16)n.                                (5.2)
```

联立并用 `X≥n/2`：

```text
2^2929 n^71 <[81Lc^4]^1000.                         (5.3)
```

精确整数比较给：

```text
c=1  -> n<2^336;
c=2  -> n<2^392;
c=5  -> n<2^467;
c=10 -> n<2^523.
```

每个所列 `K` 均满足

```text
(81Lc^4)^1000 <2^(2929+71K),
```

而换成 `K-1` 时失败。

## 6. 参数界与原题回传

由 `g≥7` 和 `alpha=c p^a=n/g`，逐模板得到报告中的 `a` 上界。
由

```text
A: 3*5^E≤n-5<n,
B: 5^E≤n-5<n,
```

得到报告中的 `E` 上界。

因此每个原始整数 `n,j,g,q_r` 与全部完整指数都进入显式有限盒。

若源窗口失败，已经有同一原 `(n,j)` 的真实共同素数；若窗口全成立，
上述高度界适用。故对所有尾部 NC6 输入均成立，而没有改变原输入。
