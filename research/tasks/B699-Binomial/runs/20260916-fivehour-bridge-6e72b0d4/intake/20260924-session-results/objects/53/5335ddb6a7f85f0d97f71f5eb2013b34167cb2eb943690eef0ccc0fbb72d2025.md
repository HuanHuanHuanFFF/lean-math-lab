# REPLAY

## 快速证书核验

```bash
python3 -B code/verify_existing.py
```

该命令会：

- 核对全部文件哈希；
- 逐个重算4933个根配置的行和、第二幂和、源直线负载、z与亏格费用；
- 检查每个模257满秩输出的列数、非零行列式和全部枢轴jet是否合法；
- 检查所有chunk对完整根门的多重集覆盖；
- 从源码重新生成COVER8账本、独立Bellman和阶段收益表，并与证书比较。

它不重新执行4933次矩阵消元。

## 完整干净重建

```bash
python3 -B code/replay_full.py --out /absolute/new/output --jobs 16
```

或：

```bash
./replay.sh /absolute/new/output 16
```

输出目录必须不存在。该命令会：

1. 从包内C++源码重新编译四个程序；
2. 重新生成 `KSAT²31` 与 `KSAT37–42` 的完整根门；
3. 并行重新计算全部4933个模257 jet 满秩系统；
4. 以“根配置＋去掉本地序号后的完整满秩输出”多重集与冻结证书逐项比较；
5. 重建三个账本JSON并逐对象比较。

依赖：Python 3.10+、g++ C++17。无需网络、NumPy、SymPy、旧仓库或原始ZIP。

`PASS_FULL_CLEAN_REPLAY` 只说明本包有限计算从干净目录可复现；不把冻结无限纸面前置提升为 Lean 或外部独立审稿。
