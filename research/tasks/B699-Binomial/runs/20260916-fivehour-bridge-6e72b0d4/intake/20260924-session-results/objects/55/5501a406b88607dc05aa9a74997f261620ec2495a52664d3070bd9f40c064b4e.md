# REPLAY

## 环境

快速重放需要：

- Python 3；
- 支持 `unsigned __int128` 的 C++20 编译器；
- `sha256sum`。

不需要网络、仓库、随机数或第三方 Python 包。

## 快速重放

```bash
bash replay.sh
```

快速重放执行：

1. 核对包内所有静态文件 SHA-256；
2. 审计 28 层收据的数量、无缝覆盖、聚合计数和最大赋值；
3. 从零重算 `m=1,3,9` 的 132 个候选与 `w=1,3,5` 的 129 行；
4. 编译独立 C++ 单行 oracle；
5. 对 252 个边界/确定性伪随机样本逐行比较 Python 与 C++ 的 `m_q`、大小判断和 `v2(R)`。

预期尾行：

```text
ROUND17_QUICK_REPLAY=PASS
```

## 完整 campaign 重放

```bash
JOBS=5 bash full_replay.sh
```

它会重新生成 `rho=28,...,55` 的全部

```math
2^28-1=268435455
```

行，并与冻结聚合证书逐字段比较。该过程是高成本确定性有限 campaign；`JOBS` 只控制并行度，不改变枚举范围或结果。

## 关键输出

快速重放生成：

- `outputs/quick_receipts.log`；
- `outputs/quick_small.log`；
- `outputs/quick_crosscheck.log`；
- `outputs/quick_replay.log`。

全量重放另生成 `outputs/full_campaign_replay.log`。

## 边界

程序只验证本轮有限环/覆盖账本，不重证上游纸面推导，也不是 Lean。`2^80` 是 POWER 必要赋值的否定门，不是原题共同素数见证。
