# PROOFS — C17：高3幂位于第5行的两个新模类

## 0. 原题、范围和采用方向

固定自然数 `n,j`，`k=n-j`，`7<=j<=floor(n/2)`。
定义 `Common6(n,j)` 为存在同一个素数 `p>=7` 同除 `C(n,6),C(n,j)`。
因为6非素数，这与原题阈值 `p>=6` 等价。

本轮定理：

```
n mod1800 in {752,50} => Common6(n,j).
```

“整行”意为每个合法j各有见证p，不声称每行必有一个统一p。
全程保持同一个原始(n,j)。令

```
s6(m)=2^v2(m) 3^v3(m) 5^v5(m), q_r=(n-r)/s6(n-r),
g=gcd(n,j), alpha=n/g.
```

以下反设 NC6，仅从 NC6 推出必要条件，不以窗口反向定义NC6。

## 1. 原生完整源与alpha

阶乘估值逐幂给

```
vp C(n,j)=sum_{h>=1} [j mod p^h > n mod p^h].
```

若 `p^e||q_r`，则p>=7，6!不取消p，p|C(n,6)。NC6迫使原完整层

```
j=b mod p^e, k=r-b mod p^e, 0<=b<=r.
```

不同q_r的素数支持互斥；r>0时gcd(q_r,g)=1。若某窗口失败，该p本身是
原题的真实共同见证。Taylor系数在整数点仍为整数，因此w重消失带来完整
`p^(we)`整除，不截断指数，不把工作层放大成新的源。

由 `j C(n,j)=n C(n-1,j-1)` 和 gcd(alpha,j/g)=1，得到

```
alpha | C(n,j).
```

若p>=7整除alpha，则p|n且p|C(n,6)，矛盾。因此alpha只含2、3、5。
不需要旧NC5转移、unit-coarse、G7或g>=7。

## 2. 新小部；不得沿用C16的2/3位置

定义 `P=2^u, Q=5^v, R=3^w` 为相应原行的实际完整幂。

|模1800类|P的位置|Q的位置|R的位置|准确小部(s0,s1,s2,s3,s4,s5)|alpha|
|---|---|---|---|---|---|
|752|n|n-2|n-5|(P,1,6Q,1,4,R)|2^a|
|50|n-2|n|n-5|(2Q,1,3P,1,2,5R)|c5^a, c=1或2|

两类都有 `u>=3,v>=2,w>=2`。

证明只需模8、9、25：两类分别为 `(0,5,2)`、`(2,5,0)`。
模9的5使v3(n-2)=1且v3(n-5)>=2；模8给非最大2幂的准确1/2层；
模25给n或n-2至少含25，其他出现的5只有一次。
这些同余识别任意大指数，未从有限样本推断无限周期。

特别：

```
T4=prod_{r=0}^3 s6(n-r)=6PQ                       (both classes).
```

alpha指数a不等于实际完整指数u或v，g仍可含同一底数；本证明没有混用。

## 3. K16的有效大小出口

从 sources/kernel16.json 逐项重建

```
F16(x,y)=(xy)^2((x-1)(y-1))^2 H8(x,y).
```

全部实际Taylor阶为

```
r0:4; r1:(8,8); r2:(3,4,3); r3:(4,4,4,4);
r4:(3,3,3,3,3); r5:(2,2,1,1,2,2).
```

H8(7+X,7+Y)的45个非零系数全正，最小34，因此合法域F16>0。
原系数绝对值和 `L=1388988`。令J=jk，A=(j-1)(k-1)，有

```
0<A<J<=n^2/4, 0<F16<(L/256)n^16.
```

完整源阶和g^4整除给较弱但充分的

```
q1^8 q2^3 q3^4 q4^3 q5 | F16/g^4.
```

n>=1006时，
`(1-1/n)^8(1-3/n)^4(1-4/n)^3 >=1-32/n >1/2`。
据第2节的小部：

```
752: q1^8 q3^4 q4^3>n^15/128,
     g^4 q2^3 q5 < (L/2)n.                        (K752)

50:  q1^8 q3^4 q4^3>n^15/16,
     g^4 q2^3 q5 < (L/16)n.                       (K50)
```

n<=1005自动低于后面所有高度上界，故无需在这些小值使用BFT或上述1/2界。

## 4. BFT出版输入及八个确定性分支

采用 Bennett--Filaseta--Trifonov, On the factorization of consecutive integers,
Theorem 2.1（原PDF印刷第4页）。本轮已查看该页图像。
所需lambda(2,3)=57/200、lambda(2,5)=129/500、lambda(3,5)=27/125。
定理作用于相差<=100的两个 prime-power × 非负整数余因子；余因子不要求
与底素数互素。n>=1006使所有使用的原值n,n-2,n-5均>1000。

完整40对例外中，差2和差3均无例外；差5只有
(1029,1024),(1215,1210),(30618,30613)，其大分量都不在本轮两个模类。

置X=n-5。

### 4.1 类752

```
n=2^a*g, n-2=5^v*(6q2), n-5=3^w*q5.
```

BFT给

```
max(g,6q2)>X^(258/1000), max(g,q5)>X^(285/1000).
```

对两门分别选择达到下界的余因子。规范乘积
`g^4(6q2)^3 q5`的四个增长指数为1.140、1.317、1.914、1.059。
因此

```
g^4 q2^3 q5 > X^(1059/1000)/216.                  (L752)
```

### 4.2 类50：第三边不可遗漏

```
n=5^a*(cg), n-2=2^u*(3q2), n-5=3^w*(5q5).
```

记 `x0=cg,x1=3q2,x2=5q5`。三条同一原输入BFT门为

```
max(x0,x1)>X^.258, max(x0,x2)>X^.216,
max(x1,x2)>X^.285.                                 (TRIANGLE)
```

前两边的原差为2、5，第三边为3。分别选择每条边的一端，八种选择的
`x0^4 x1^3 x2`增长指数为

```
1.887,1.317,2.103,1.317,1.719,1.923,1.071,1.059.
```

这些数由每个变量承担的lambda最大值乘以权重4/3/1后相加得到；重放用
Fraction枚举全部8支。于是

```
g^4 q2^3 q5 > X^(1059/1000)/(135c^4).             (L50)
```

若只使用前两条边，最弱指数为.990，不能与线性K50推出高度。
第三边确实增加独立来源信息，不是重复计算同一个素数或因子。

## 5. 两个绝对有效高度

由 `X>=n/2`，若 `g^4q2^3q5<Cn` 且 `>X^(1059/1000)/D`，则

```
n^59 < 2^1059 (CD)^1000.
```

全部以有理数和整数幂比较：

|原域|C|D|认证界|
|---|---|---|---|
|752|L/2|216|n<2^479|
|50,c=1|L/16|135|n<2^416|
|50,c=2|L/16|2160|n<2^484|

每项K向下减1时同一算术比较均失败；不使用浮点对数取整。
取统一入口752<2^479、50<2^484。n<=1005也显然被包含。

## 6. 原生QIG与没有低段遗漏的PQ>n

令V=q0q1q2q3，a_t=C(j,t)C(k,4-t)。原完整源层使V|a_t。
四次整数不变量定义为

```
I=12a4a0-3a3a1+a2^2,
B=72a4a2a0+9a3a2a1-27a4a1^2-27a3^2a0-2a2^3.
```

置J=jk、A=J-n+1、D0=(n-1)(n-2)。本包逐系数重新核验

```
8I=JA(n-3)(n-2),
-16B=J^2 A(n-3)^2(n-2),
256(B^2-2I^3)=J^3 A^2(n-3)^3(n-2)^2(D0-J).
```

由合法区间，右侧为正；故G=(B/V^3)^2-2(I/V^2)^3为正整数。
在J<=n^2/4上单调放大得到

```
G <= T4^6(3n^2-12n+8)/[2^20(n-1)^6(n-3)^3].
```

因此NC6必须QIG左侧>=右侧；其严格反向是整行消费者。

现在两类最小合法n分别是752、50，均>=50。若PQ<=n，因T4=6PQ，

```
(n-1)^6(n-3)^3 >= n^9(1-15/n)>n^9/2,
3n^2-12n+8<3n^2
```

使NC6必须 `n<3*6^6/2^19<1`，矛盾。因此

```
PQ>n                                                 (all domain values).
```

本轮无需另外假设n>=8192；不是忘记低段。n=50、752也包含在该引理中。

## 7. 完备的原行恢复

752类(r2,r5)=(0,2)；50类为(2,0)。原n满足

```
n = [r2 + P*((r5-r2)*P^(-1) mod Q)] mod(PQ),
0<=n<PQ.
```

P、Q是实际完整2、5幂，不是alpha幂。高度得到

```
752: 3<=u<=478, 2<=v<=206, 97580个幂对;
50:  3<=u<=483, 2<=v<=208, 99567个幂对.
```

过滤只有原NC已满足的高度、模1800类和精确估值。没有遗漏模PQ提升，因为
PQ>n已严格证明。

|类|模类命中|不同完整原行|严格QIG排除|QIG未排原行|
|---|---:|---:|---:|---|
|752|5788|2145|2143|18752,41418752|
|50|5624|2187|2184|50,781250,9781250|

合计4332行，其中4327行严格QIG，五行需原题终端。

第二实现逆序枚举v,u；用独立扩展欧几里得求Q^{-1} modP；使用相反CRT；
分开用模8/9/25识别域；2估值用lowbit、5估值反复整除；T4用6PQ重算。
两套原行集合和QIG未排集合逐项完全相同。

## 9. 原题回传与可选跨指标桥

任取新模类原始(n,j)。反设NC6，第1--5节得到有效高度，第6节给PQ>n，
第7节把原n送入完整恢复表。4327行违反QIG；其余五行也有原题共同素数。
因此NC6不存在，两个新模类整行关闭。

若额外n≡6(mod7)，则7不整除前六窗口任何一项，7∤C(n,6)；因此所得p>=11。
对i=7,8,9及i<j<=n/2，

```
(i!/6!) C(n,i)=C(n,6) product_{t=6}^{i-1}(n-t).
```

分母只含<=7的素因子，不取消p。于是相同原(n,j)、相同p给Common_i。
额外同余恰为 `n mod12600 in {6152,9050}`。
这只是严格过滤后的推论；没有与其他会话所有消费者做净差审计。
