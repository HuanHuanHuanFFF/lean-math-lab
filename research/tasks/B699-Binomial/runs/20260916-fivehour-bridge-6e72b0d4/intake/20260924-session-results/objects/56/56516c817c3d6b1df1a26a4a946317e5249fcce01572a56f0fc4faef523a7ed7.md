# FAILURE BOUNDARIES

1. **不是 OCTIC-ALL。** `4+4` 仍有内部多槽 `3+1 / 2+2 / 2+1+1` 与两侧三次临界商。
2. **不是门槛以下结论。** GATE8 是 `T≥[2(f(1)+2)]^20`；系数增长时其下方不是有限底部。
3. **不是两底或多底结论。** 本轮始终使用单一工作奇素数幂 `T=p^e` 的非负数字行。
4. **没有反推 NC3。** `POLY12`、DIFF、U2 都只作 NC3 必要后果。
5. **没有丢弃完整素数幂。** 工作底 `T` 不等于实际原源的完整指数；采用的旧提升保留实际源。
6. **4+4 成本探针不是排除证书。** `cost_probe.py` 只记录首个未解多槽分支通用非退化坐标图的系统规模；分母退化图仍须另列，它也不证明这些系统有解或无解。
7. **显式 `3+5` 族未做全历史净差审计。** 它确实由本轮 GATE8 因子判据闭合，但不声称每个实例此前绝无其他消费者。
8. **无 Lean、无外部独立审稿。** 符号脚本是精确重放，不是形式化全链。
