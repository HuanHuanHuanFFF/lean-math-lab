# FAILURES — C7

## F1. 不能把 tau4 放进旧 GAP-SF 的同一位置

旧 GAP-SF 的 `d4` 来自 `E4=d4h4^2` 与 `Delta4`。若奇指数只落在 `C`，没有合法理由把 `c4` 直接替换进旧式。正确交付是：

```text
d4>=7  -> 旧 GAP-SF 加强；
d4=1   -> sf(C)>=7，并使用新的 CENTER-SF。
```

## F2. 中心落点没有被二次特征排空

`p|C` 只强迫 `(30/p)=+1`。素数7已满足 `(30/7)=+1` 而 `(10/7)=-1`，故 C-only 负特征落点局部相容。块级相容不是完整 NC6 模型，但足以否定“同一字符立即推出 d4>=7”。

## F3. CENTER-SF 不是绝对有限化

它给 `d4*C` 相对于 `n,g,q2,q5` 的上界，却没有界住 `n`。平方部分、支持和三移位指数仍可同步增长。

## F4. p>=31 路线的第一额外层是恒等输运

当 `s=vp(eta)>0` 时，`L4,L6,L7` 均为 p 单位；纯5幂关系的 p 估值恰由 `eta` 承担。只重复工作层或模 p^r 展开不会产生独立方程。

## F5. 弱样例不是原题反例

包内 `(p,e,E,s)=(31,1,4,3)` 样例失败第一源 `n-1|jk`，也不满足当前 `alpha=3^a` 恢复。它只作为低收益路线的精确反模型，不能计入 frontier reduction。
