# REPLAY

在 Linux、Python 3.10+、g++ C++17 环境中运行：

```bash
bash replay.sh /absolute/path/to/new-output-directory
```

输出目录必须不存在。重放会：

1. 编译六组根门和 jet 程序；
2. 重建13个 `(模式,q)` 根门；
3. 在32749、32719上重算全部44,468个满列秩系统；
4. 重算修正后的直接与raw-reverse八分量账本；
5. 重算七个阶段账本；
6. 重算五个边界状态的原始签名聚合和精确矩条件；
7. 与包内50个确定性证书文件逐字节比较。

最终应输出：

```text
PASS_FULL_CLEAN_REPLAY_MIDDOUBLE5_7_TRACE_H57
```

重放不访问网络、不读取仓库、不写入仓库，也不运行Lean。
