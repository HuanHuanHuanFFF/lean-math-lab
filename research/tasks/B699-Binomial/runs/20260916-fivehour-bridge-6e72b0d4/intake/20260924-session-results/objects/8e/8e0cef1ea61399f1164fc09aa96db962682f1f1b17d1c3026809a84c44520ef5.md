# REPORT · B699 D / i=3 · Round 19 odd–odd 端点化与双侧有效化

## 结论摘要

本轮从 Round 18 已排空的 pure-two 分支转入平衡 `odd--odd`。取得四项结构进展：

1. **全平衡 2-adic 端点定理**：不只 pure-two，而是整个平衡 `BLOCK-MIX` 必须满足
   \[
   v_2(B)=2\quad\text{或}\quad v_2(A)=1.
   \]
   因而所有中间 2-adic 分配全部退出。

2. **规范有理分配**：每个状态唯一对应约分正有理数
   \[
   \lambda=\frac ab=\frac{2^{v_2(B)-1}A}{X},
   \qquad a\mid9U,\quad b\mid x,
   \]
   以及互补分配
   \[
   \theta=\frac{x_1}{u_1},\qquad
   x=bx_1,\quad9U=au_1.
   \]
   odd--odd 强制 `b>1`；`b=1` 恰回到已经排空的 pure-two 端点。

3. **双侧 Matveev 有效化**：
   - 若 `H(lambda)=max(a,b)<=q`，则 `q<2^53`；
   - 若约分后的 `H(theta)<=q`，同样 `q<2^53`；
   - 更一般地，对每个固定 `K`，`H(lambda)<=q^K` 或 `H(theta)<=q^K` 的 odd--odd 子域都可显式有效有限化。

4. **完整奇素数幂分配门**：若奇素数 `p` 同时整除 `A,B`，则除 `p=5` 外必须
   \[
   p\equiv1\text{ 或 }4\pmod5.
   \]
   所以全部 `p≡2,3 (mod 5)` 的完整指数不得在两侧拆分。若 `p=5` 被拆分，则必须
   \[
   v_5(B)=1,\qquad B/5\equiv4\pmod5.
   \]

这些是平衡 odd--odd 的严格 frontier reduction 和条件有效有限化；未排空 odd--odd，也未减少全局 `R7`。

## 2. ODD-END：全平衡只有两个 2-adic 端点

令

```math
\alpha_2=v_2(A),\qquad \beta_2=v_2(B).
```

由 `AB=9UX`：

```math
\alpha_2+\beta_2=\rho+1.
```

冻结入口给 `A` 偶。又令 `Y=d nu-Q^2`；`d,Q` 奇、`nu=2H` 且 `H` 奇，所以 `Y` 奇。完整平方式

```math
Y^2=v^4+5dv^3+10d^2v^2+10d^3v+5d^4+d^2W
```

模 2 强迫 `W` 偶，故 `B` 偶。

模 8 分类：

- `beta_2=1` 时 `alpha_2=rho>=3`，右端为 `3` 或 `7 mod 8`；
- `alpha_2>=2, beta_2>=3` 时右端为 `5 mod 8`；
- 只有 `beta_2=2` 或 `alpha_2=1` 不被奇平方余数立即排除。

因此

```math
\boxed{\beta_2=2\quad\text{或}\quad\beta_2=\rho\;(\alpha_2=1).}
```

这删除了全部 `beta_2=1` 与 `3<=beta_2<=rho-1` 的分配域。

## 6. UNITARY-5：完整奇幂不得任意拆分

若奇素数 `p|gcd(A,B)`，则 `p∤y`，且由 `AB=3(d-1)` 得 `d≡1 mod p`（`p=3` 时使用 `v3(AB)>=2`）。模 `p` 的平方式退化为

```math
Y^2\equiv5d^4\pmod p.
```

故若 `p!=5`，必须 `(5/p)=1`，即

```math
\boxed{p\equiv1\text{ 或 }4\pmod5.}
```

所以所有 `p≡2,3 mod5` 的完整源指数只能整体进入 `A` 或整体进入 `B`；特别地 `3∤gcd(A,B)`。

若 `p=5` 同时进入两侧，则 `d≡y≡1 mod5`。设 `b_5=v5(B)`。若 `b_5>=2`，平方式中 `5d^4` 是唯一 5-adic 最低项，给 `v5(S)=1`，不可能为平方。因此

```math
b_5=1.
```

再模 25 除以 5，平方要求

```math
B/5\equiv4\pmod5.
```
