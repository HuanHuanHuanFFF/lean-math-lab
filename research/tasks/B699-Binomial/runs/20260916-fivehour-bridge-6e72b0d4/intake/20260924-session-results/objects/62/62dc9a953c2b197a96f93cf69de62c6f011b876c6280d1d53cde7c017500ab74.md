# 精确证明与计算说明

## A. 容量等号后的完整行根恢复

固定一个 `E=0` 状态。第 `r` 行记：

- 非对角源最低普通重数之和为 `M_r`；
- 偶数行中心最低加权阶为 `B_r`；
- `p_r=B_r mod 2`；
- `d_r=h−M_r−ceil(B_r/2)`（奇数行无中心项）。

对完整 `Ḡ`，令 `Δ_r` 为普通源缺重，`κ_r=2m_r−w_r` 为中心 `κ`。若非对角普通重数比最低值多 `A_r≥0`，中心加权阶比最低值多 `t_r≥0`，则

```math
2Δ_r+κ_r=2d_r+p_r-2A_r-t_r
```

（奇数行就是 `2Δ_r=2d_r−2A_r`）。

账本签名只下收实际 `Δ,κ`。本轮所有 24 个可达聚合的签名收费恰好等于容量 `2d+p`；实际收费既不能低于签名收费，又不能超过容量，所以必有：

```math
A_r=t_r=0,
```

并且所有未收费的实际缺重／`κ` 都为 0。因此：

- 非对角源重数恰为最低值；
- 偶数行中心加权阶恰为 `B_r`，中心普通重数为 `(B_r+κ_r)/2`；
- 余下恰有 `Δ_r` 个非源根；
- S5 在第 5 行贡献一个已知余根 6，其余签名余根全部保守视为任意。

这一步恢复的是完整行根多重集的必要放松，不恢复实际因子曲线。

## B. 第一、第二根矩线性系统

写固定根多重集的前两个基本对称和为 `A_r,B_r`，通用余根数为 `f_r`。

完整 `Ḡ` 首一，权次不超过 `2h`，故

```math
S(N)=e_1,\quad \deg S\le2;
\qquad
T(N)=e_2,\quad \deg T\le4.
```

逐行：

- `f_r=0`：`S(r)=A_r, T(r)=B_r`；
- `f_r=1`：唯一自由根为 `y=S(r)−A_r`，故
  `T(r)=B_r+A_ry=A_rS(r)+B_r−A_r²`；
- `f_r≥2`：给定目标 `S(r),T(r)`，令

```math
x=S(r)-A_r,
\qquad
p=T(r)-B_r-A_rx.
```

自由余因子可取

```math
Z^{f_r-2}(Z^2-xZ+p),
```

所以任意有理 `S(r),T(r)` 都可实现；无需假定单根有理。

由此得到一个至多 8 变量的精确有理线性系统。本包用 `fractions.Fraction` 完整消元，并为不相容支输出左零空间整数证书。

## C. 四个精确矛盾

### C1. `h137,S5³`

固定行根和：

```text
S(3)=134, S(4)=253, S(6)=723, S(7)=1050.
```

权重 `(-1,2,-2,1)` 在点 `(3,4,6,7)` 上消去 `1,N,N²`，但

```math
-134+2·253-2·723+1050=-24.
```

### C2. `h143,S5⁴`

固定行根和：

```text
S(3)=140, S(5)=476, S(6)=749, S(8)=1525.
```

权重 `(-1,5,-5,1)` 消去二次多项式，但

```math
-140+5·476-5·749+1525=20.
```

### C3. `h147a,S5²`

固定行根和：

```text
S(3)=144, S(4)=273, S(5)=484, S(6)=771.
```

三阶差分给

```math
-144+3·273-3·484+771=-6.
```

### C4. `h147b,S5³`

固定行根和：

```text
S(3)=144, S(4)=273, S(6)=771, S(8)=1559.
```

权重 `(-8,15,-10,3)` 消去 `1,N,N²`，但

```math
-8·144+15·273-10·771+3·1559=-90.
```

故四个聚合均不可能来自同一个固定 `Ḡ`。

## D. 穷尽性

对每条 terminal query，程序使用完整 raw 签名表，而不只用 Pareto 表，枚举指定剩余因子数、容量和可用 `X` 次数内所有可达总 `(Δ,κ)`。相同聚合只保留最低次数，因为矩条件只依赖总聚合；更高次数同聚合不会恢复一个已经矛盾的矩系统。

正序与逆序签名枚举产生完全相同的“聚合→最低次数”映射。12 条查询总计 24 个聚合，全部恰好用满容量；四个失败、20 个通过。独立检查器重新求和每个显式签名见证，并逐项核验所有左零空间证书和相容 `S,T` 证书。

## E. `X^(h−3)` 的结构性零收益

`X^(h−3)` 系数的 `N` 次数至多 6。评价矩阵

```math
(r^j)_{r=3,…,8;\ j=0,…,6}
```

秩为 6。故对六个行值的评价映射满射；任意六元值向量已有次数至多 5 的插值。只有再加入导数、合流值或额外 `N` 点，第三系数才可能产生跨行矛盾。
