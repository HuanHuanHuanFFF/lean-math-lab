# D-same-origin · complete conversation archive

Archive date: 2026-09-24.

This package collects all currently recoverable research outputs delivered in this conversation from initialization through Round 27, plus the earlier Round 13–22 complete archive as a preserved original artifact. No new mathematics was performed while building it.

## Contents

- `conversation/` — visible-chat reconstruction and artifact/tool-result ledger.
- `original_artifacts/round_zips/` — all 15 original Round 13–27 evidence ZIPs and SHA sidecars, byte-preserved.
- `original_artifacts/previous_archive/` — the previously delivered Round 13–22 complete archive, validation receipt, and SHA sidecar, byte-preserved.
- `objects/sha256/` — content-addressed unique payloads for all extracted round members / standalone aliases. Exact duplicate payloads are stored once.
- `rounds/round-XX/FILES.md` — logical round member maps into the object store.
- `validation/` — standalone validation receipts delivered alongside rounds where available.
- `sources/` — project input source used by this conversation; not reclassified as a session-generated proof.
- `indexes/ROUNDS.md` — complete round index and latest unresolved-frontier summary.
- `indexes/LOGICAL_FILE_MANIFEST.tsv` — every logical/delivered path mapped to SHA-256 and canonical bytes.
- `indexes/DEDUP_MAP.tsv` — exact-SHA dedup provenance.
- `SHA256SUMS.txt` — hashes for every physical file in this outer archive tree (except itself while generated).
- `MISSING.md` — explicit recovery limits and non-claims.

## Dedup policy

Only byte-identical payloads with identical SHA-256 are deduplicated in the content-addressed object store. Every logical source path remains recorded in the manifest and dedup map. Original evidence ZIP containers are retained verbatim even though their internal members also exist in the object store; this duplication is intentional because preserving the original container bytes is part of the request.

## Evidence levels

This is an archive, not a new verification pass. The per-round evidence levels remain exactly those stated in the original reports: combinations of author paper proof/reduction, deterministic finite certificates/replays, and in some rounds external published theorems. They are **not** upgraded to Lean, external independent full review, complete i=3 closure, or complete B699 closure.
