# 重放

Python3.10+，不需要网络、Lean、NumPy、SciPy、SymPy或旧仓库。
从解压后的包根目录运行：

```sh
python3 -B code/replay.py /absolute/path/to/new-output-directory
```

输出目录必须不存在。程序核对输入哈希，再重建347状态源线下降、全部原始签名和商容量双算法，重新检查四个h73边界，逐字节比较6个确定性结果文件，并运行单独整数证书接收器。

本命令不重新计算冻结历史几何门。干净重放验证的是本轮新证明及其显式采用的数据，不是原题的Lean验证或外部独立数学审稿。

主计算和单独接收器可分别调用：

```sh
python3 -B code/source_descent.py /absolute/path/to/another-new-directory
python3 -B code/check_certificates.py /absolute/path/to/another-new-directory
```

正式接收文件：source_descent_all347.json、strictness_tests.json、h73_boundary_diagnostics.json、final_E0_frontier.tsv、summary.json、state1027_all_multisets.json。
