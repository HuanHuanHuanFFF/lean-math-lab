# PROOFS — C9：BFT 三平移余因子门关闭 B/RES10 全近侧

## 0. 原输入和准确目标

记 `k=n-j`、`g=gcd(n,j)`。本轮只固定 B尾 RES10：

```text
n≡5130 (mod9000),
7≤j≤floor(n/2),
alpha=n/g=3^a,
(n-1)jk=10Y^2.
```

按 i=6 的完整小部定义

```text
b=v2(n-2),       q2=(n-2)/2^b,
E=v5(n-5),       q5=(n-5)/5^E.
```

目标是证明：若第5源全近侧 `Q51=q5`，则该原始 `(n,j)` 有 Common6。

所有改写均保留同一 `(n,j)` 和完整素数幂。

## 1. 从全近侧 NC6 进入 D25 核心

反设该输入为 NC6。

完整源窗口若失败，失败粗素数已经给出原 Common6。故可使用冻结完整源分配。
全近侧的冻结消费者又给：

1. `C≥A4` 时已有中心消费者，故幸存者必须 `C<A4`；
2. 高残量时已有残量消费者，故幸存者必须进入低残量；
3. 若

   ```text
   Delta3≤90g^3D25  或  Delta4≤10g^2D25,
   ```

   则已有缺欠消费者，故幸存者必须同时满足两个严格反向不等式。

这正是 C5 的 D25-COMP 适用域。于是

```text
n > 27000 g^7 d^2 q2^3 q5^2.                       (1.1)
```

同一冻结证明还给

```text
n > 4,360,912,290,000,000,000.                     (1.2)
```

置

```text
P=g*q2*q5.
```

因为 `g,d,q2` 均为正整数，(1.1) 可写成

```text
n > 27000 P^2 · g^5 d^2 q2 ≥ 27000 P^2,
```

从而

```text
P^2 < n/27000.                                      (1.3)
```

## 2. 外部显式输入：BFT Theorem 2.1

采用 Bennett–Filaseta–Trifonov, *On the factorization of consecutive integers*,
Theorem 2.1。

对表中素数对 `(2,3),(2,5),(3,5)`，其指数分别为

```text
lambda23=0.285,
lambda25=0.258,
lambda35=0.216.
```

若非负整数 `r,s,x1,x2` 满足

```text
|p^r x1-q^s x2|≤100,
```

则除 `p^r x1≤1000` 和一个明确的40对例外表外，有

```text
max(x1,x2)>min(p^r x1,q^s x2)^lambda(p,q).
```

例外表的最大分量为 `1,771,561`。

## 3. 三次真实代入

令

```text
X=n-5.
```

### 3.1 `(2,3)`

取

```text
2^b q2=n-2,
3^a g=n.
```

两者相差2，最小值 `n-2>X`。由 (1.2)，小门和例外表均不可能，故

```text
max(q2,g)>X^(285/1000).                              (3.1)
```

### 3.2 `(2,5)`

取

```text
2^b q2=n-2,
5^E q5=n-5.
```

两者相差3，故

```text
max(q2,q5)>X^(258/1000).                             (3.2)
```

### 3.3 `(3,5)`

取

```text
3^a g=n,
5^E q5=n-5.
```

两者相差5，故

```text
max(g,q5)>X^(216/1000).                              (3.3)
```

注意 BFT 定理不要求余因子与底素数互素，因此这里没有把 `g` 非法替换成其3自由部分。

## 4. 三余因子乘积门

由 (3.1) 分两种情况。

- 若 `g>X^(285/1000)`，则由 (3.2)，`q2`、`q5` 中至少一个大于
  `X^(258/1000)`，故

  ```text
  P>X^(543/1000)>X^(501/1000).
  ```

- 否则 (3.1) 强迫 `q2>X^(285/1000)`；再由 (3.3)，`g`、`q5`
  中至少一个大于 `X^(216/1000)`，故

  ```text
  P>X^(501/1000).
  ```

所以统一有

```text
P>X^(501/1000).                                      (4.1)
```

这正是 BFT 论文中 `0.285+0.216>1/2` 的同一收费机制，但本轮代入的是
同一 B699 输入的三个真实平移余因子。

## 5. 精确终矛盾

由 (4.1)：

```text
P^2>X^(1002/1000)=X^(501/500).                       (5.1)
```

与 (1.3) 合并：

```text
(n-5)^(501/500)<n/27000.                             (5.2)
```

当前 `n>10`，故 `n-5>n/2`。因此 (5.2) 会推出

```text
(n/2)^(501/500)<n/27000.
```

两边提升到500次方并约去 `n^500`：

```text
n*27000^500<2^501.                                   (5.3)
```

但

```text
27000^500>2^501,
```

且 `n≥1`，与 (5.3) 矛盾。

所以 D25 核心中不存在 NC6。

## 6. 返回整个全近侧分支

任取 B/RES10 的合法全近侧原输入：

- 若任一完整源失败，已有真实粗素数见证 Common6；
- 若中心、残量或缺欠消费者触发，已有 Common6；
- 否则进入 D25 核心，而 §§2–5 已证明该核心为空。

因此整个

```text
B/RES10 ∧ Q51=q5
```

分支闭合。

本证明没有换 `(n,j)`，没有把工作层升级为更大的原源幂，也没有依赖
BEG 的非有效常数。
