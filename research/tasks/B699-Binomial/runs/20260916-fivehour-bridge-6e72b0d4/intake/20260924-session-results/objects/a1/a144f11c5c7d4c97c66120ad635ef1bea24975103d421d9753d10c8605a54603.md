# REPORT — B / i3 八次临界区：BOUNDARY-3 与 NO-31

日期：2026-09-22。范围：B699 的 `i=3`，只研究 GATE8 严格大进制数字行；不修改仓库；无 Lean；不声称完整 `i=3`、OCTIC-ALL 或完整 B699 闭合。

## 1. 本轮最强新增结论

沿用上一轮 GATE8：

```text
f∈Z[X]，系数非负，f(0)=2，deg f=8，H=f(1)，
T=p^e 为奇素数幂，T≥[2(H+2)]^20，n=f(T) 为偶数。
```

假想同一个原始 `(n,j)` 满足 NC3。上一轮已证明第一源完整分配不能是 `3+5/5+3`，故只剩 `4+4`。写

```text
f-1=UV，σ=VW，U|VW-1，
W(W-U)(W-2U)=(UV-1)R，gcd(U,W)=gcd(U,R)=1，
U | W R' - R(3W'-2U')。
```

本轮得到两个真正的无界域删除。

### BOUNDARY-3

`4+4` 的两条三次临界边界全部不可能：

```text
t=0, deg W=3；
t=1, deg(W-U)=3。
```

因此任何 GATE8-NC3 幸存者都必须处在内部 `0<t<1`，其中 `t=lc(W)/lc(U)`。

### OCTIC-NO31

内部四次商 `deg R=4` 的全部 `3+1` 槽分配不可能。这里“3+1”允许三次因子可约、重根或不可约；完整因子重数始终留在同一个槽。

结合原始较小端点 `σ=j≤n/2`，内部商只剩四个槽度数组合：

```text
(d0,d1,d2)=(0,2,2),  t=1/4；
(d0,d1,d2)=(2,0,2),  t=1/2；
(d0,d1,d2)=(1,1,2),  t=3/8；
(d0,d1,d2)=(1,2,1),  t=1/2。
```

前两项是 `2+2`，后两项是 `2+1+1`。八次严格平衡的未知前沿已从

```text
边界三次 + 内部单槽 + 3+1 + 2+2 + 2+1+1
```

压到仅

```text
2+2 + 2+1+1 的四个定向槽型。
```

这不是单纯“必要条件又多一条”：被删除的边界和 `3+1` 中，原系数、底素数、指数、`n,j` 均可无界。

## 2. 统一槽加权次数律

将 `R` 的完整因子按进入 `W,W-U,W-2U` 分成两两互素的

```text
R=R0 R1 R2，di=deg Ri。
```

DIFF 的商不是自由未知量，而精确为

```text
S=R0 R1' R2 + 2 R0 R1 R2'.
```

在内部 `deg U=deg W=deg R=4`，比较最高项得到

```text
d1+2d2 = 8(1-t).                     (WEIGHT8)
```

取 `σ=j`；大进制数字多项式 `j` 与 `n-j` 的系数均非负，且 `j≤n-j`，故最高数字给 `t≤1/2`，即 `d1+2d2≥4`。

在边界 `deg W=deg R=3`，同一最高项比较却要求

```text
d1+2d2=8，
```

而左边至多 `2(d1+d2)≤6`，矛盾。这一次排掉整个三次边界，不需要逐个槽型消元。另一边界由交换原端点得到同样矛盾。

## 3. 三个 `3+1` 槽型的完整分类

`WEIGHT8` 与 `t≤1/2` 将六个有序 `3+1` 分配只留下：

```text
三次槽/一次槽 = (2,0), (2,1), (1,2).
```

把一次根送到 `x=0`，写

```text
R=rho*x*A3，A3=x^3+a x^2+b x+c，c≠0，
U 首一四次。
```

DIFF、`A3|(W-kU)`、`x|(W-lU)` 是线性系统，精确解出 `U,W`。若 `a=0`，对 U2 余式的 `x^0,x^5,x^6,x^7` 四式作合法饱和后，三个槽型的精确 Gröbner 基都包含 `c^3`，与 `c≠0` 冲突。

若 `a≠0`，以有理缩放令 `a=1`，置 `r=q/c`，其中 `q` 是相应非零常数参数。四个高次余式的精确饱和 Gröbner 基分别为：

| 三次槽/一次槽 | 精确基 |
|---|---|
| `(2,0)` | `30b-7, 60r-49, 6750c-49` |
| `(2,1)` | `1956242b-555665, 3956r-75, 1934723338c-39858075` |
| `(1,2)` | `3384006b-968635, 4506r+25, 22872496554c-487179275` |

其余四个余式统一确定 `rho`，没有剩余正维形式族。

### `(2,0)`：首项符号退出

唯一形式解有

```text
rho=-40353607/10497600000000 < 0，t=1/4。
```

而恢复的 `f=UV+1` 首项为

```text
t(t-1)(t-2)/rho = -492075000000/5764801 < 0，
```

不可能是非负数字多项式。

### `(2,1)`：整数恢复后恒为 `2 mod 4`

唯一形式解的 `rho>0`。恢复 `f-2` 后，只有两个有理数字原点：

```text
x=-10/989，x=-325/989。
```

第二个原点处，一阶 Taylor 系数为正而二阶为负；任一有理方向都不能产生非负数字多项式。

在第一个原点置 `y=989x+10`。恢复出的 `F(y),Σ(y),Τ(y)` 系数均非负，其中

```text
[y]F=64/315， [y]Τ=1/30。
```

若回到原整数数字变量 `y=sX`，`Τ(sX)∈Z[X]` 先迫使 `s=30m`；再由 `F(sX)∈Z[X]` 迫使 `21|m`。所以 `s=630h`，`h∈Z_{>0}`。精确恢复为

```text
F(630z)=147456z^8+524288z^7+745472z^6+540672z^5
       +211200z^4+43008z^3+4032z^2+128z+2。
```

全部非常数系数被 4 整除，因此原 `n≡2 (mod4)`，与同一 NC3 的冻结前置 `4|n` 矛盾。

### `(1,2)`：两个数字原点均有符号障碍

恢复的 `f-2` 只有两个有理根：

```text
x=-10/2253，x=-725/2253。
```

第一处一阶、二阶 Taylor 系数均为负；正方向在一次项失败，负方向在二次项失败。第二处一阶、四阶系数均为负；两种方向同样分别失败。因此不存在非负数字恢复。
