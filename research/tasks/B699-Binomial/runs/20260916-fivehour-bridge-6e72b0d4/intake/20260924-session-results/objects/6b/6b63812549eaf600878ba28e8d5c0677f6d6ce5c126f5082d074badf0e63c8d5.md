# PACKAGE CONTENTS

- `REPORT.md` — 中文主报告、真实删除域、剩余参数与下一步。
- `PROOFS.md` — MID-DOUBLE、账本接入和同一-G矩约束的完整推导。
- `HANDOFF.md` — 当前前沿与下一轮最低状态。
- `FAILURE_BOUNDARIES.md` — 不能外推的范围。
- `SOURCE_ADOPTION.md` — 冻结来源、哈希和采用范围。
- `EVIDENCE_LEVEL.md` — 证据等级。
- `REPLAY.md`, `replay.sh` — 干净全量重放入口。
- `code/` — 六组有限分类、三套账本、矩分析及验证器。
- `certificates/geometry/` — 22,234个根门与两个素数的满秩输出。
- `certificates/ledger/` — 阶段账本、直接/raw-reverse账本及最终381状态。
- `certificates/moment/` — 五个边界状态的完整聚合和精确矩证书。
- `certificates/summary.json` — 机器总览。
- `CLEAN_REPLAY_RECEIPT.json` — 50个确定性文件逐字节重放回执。
- `logs/` — 作者运行摘要与验证输出。
- `sources/` — Overview和上一轮证据包哈希。
- `notes/` — 研究日志与实现修正。
