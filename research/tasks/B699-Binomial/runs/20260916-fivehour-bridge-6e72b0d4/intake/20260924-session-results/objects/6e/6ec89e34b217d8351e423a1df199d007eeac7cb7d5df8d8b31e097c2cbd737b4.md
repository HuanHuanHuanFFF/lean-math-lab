# Visible tool-result preservation ledger

This archive preserves every recoverable conversation attachment and every member of every recoverable ZIP. That includes validation JSON, replay stdout/logs, certificates, console excerpts already saved in the earlier full archive, and generated data files.

The platform does **not** expose a raw export of every streaming commentary/tool-result message from the chat UI. Exploratory tool outputs that were never written to a file are therefore not reconstructable byte-for-byte. They are not silently claimed as present; see `MISSING.md`.

Primary machine-result sources are indexed in `SOURCE_MAP.csv`, `ORIGINAL_ZIPS.md`, and each round index.
