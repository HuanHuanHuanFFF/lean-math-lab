# REPORT — B699 新会话 C / C14

日期：2026-09-22。

## 1. 主结果：六种纯位置分配全部关闭

固定两个旧 H025 尾类之一：

```text
A: n≡1280 (mod1800),
B: n≡1530 (mod1800),
7≤j≤floor(n/2).
```

完整第2源只有两组槽：

```text
E = endpoint {0,2},
C = center   {1}.
```

完整第5源只有三组槽：

```text
E = endpoint {0,5},
N = near     {1,4},
C = central  {2,3}.
```

本轮统一证明六种笛卡尔积位置壳全部 Common6：

```text
EC, EN, EE, CC, CN, CE.
```

换言之，若 `q2` 的全部完整素数幂只占一个槽组，且 `q5` 的全部完整素数幂
也只占一个槽组，则不存在 NC6 原输入。

C13 已关闭 EC；本轮重新重放 EC，并新增关闭 EN、EE、CC、CN、CE 五支。
所有底素数、素数个数和完整指数均可变化。

因此任何尚存 NC6 必须满足：

```text
第2源真正混合（E2>1 且 M2>1），
或者第5源真正混合（Q50,Q51,Q52 至少两个>1）。       (MIXED-GATE)
```

这是一条新的完整 frontier reduction，不是有限高度本身。

## 3. 六个精确互补门

置

```text
s2=(n-2)/q2,
s5=(n-5)/q5.
```

逐壳从第一源整数 `U=j(n-j)/(n-1)` 和真实槽同余推出：

|壳|完备必要界|
|---|---|
|EC|`2q2<s5`, `2q5<s2`|
|EN|`q2<s5`, `q5<s2`|
|EE|`3q2≤s5`, `3q5≤s2`|
|CC|`q2<s5`, `q5<s2`|
|CN|`4q2^2≤s5`, `4q2q5<s2`|
|CE|`q2≤2s5`, `4q5<7s2`|

其中：

- EC 是 C13 的互补恒等式；
- EN 来自 `U=q2R, U-1=q5h`；
- EE 来自 `q2q5|U<n/3`；
- CC 使用 `q2^2|U-1, q5|2U-3`；
- CN 使用 `q2^2q5|U-1`；
- CE 使用 `q2^2|U-1, q5|U`。

代入两尾的准确小部和相邻式：

```text
A: 2*3^(b-1)q2 - 5^E q5 = 1;
B: 2^b q2 - 5^E q5 = 3,
```

把无限参数压成由证明界定的有限原行。

## 6. 失败边界

MIXED-GATE 不意味着 `M2Q50Q51≥49`。例如端点/中央混合的第5源可以只有
一个大小为7的非中央块，故 C13 的统一最小附加因子7不能直接再提高。

本轮未排：

```text
E2>1 and M2>1;
或 q5 至少两个 Q5-block 非单位。
```

这些区域已经处于显式有限盒，但末端仍过大，不能直接逐n扫描。
