## P1. 每行只需一个短 Hensel 候选

固定 `q`，把

```math
v=2\chi M
```

代入 `R`，定义

```math
F_q(M)=\frac{R(d,2\chi M)}8.
```

Round 12 已证明：

1. `F_q(M)` 对奇 `M` 是整数；
2. 对每个奇 `M`，

   ```math
   F_q'(M)\equiv1\pmod2.
   ```

因此对每个 `K>=1`，同余

```math
F_q(M)\equiv0\pmod{2^K}
```

在奇数中恰有一个模 `2^K` 的解类。

本轮取

```math
K=\rho+4.
```

由于

```math
27\,2^{\rho-1}<2^{\rho+4},                    \tag{1}
```

若真实乘子 `m` 通过 `(QP)`，则它必等于该唯一解类在区间

```math
0<m<2^{\rho+4}
```

中的代表，记作 `m_q`。若 `m_q>=27*2^(rho-1)`，该行立即退出。

若 `m_q` 位于大小界内，则只需检查

```math
R(d,2\chi m_q)\pmod{2^{80}}.
```

若该余数非零，则

```math
v_2(R)<80,
```

而当前最小 `q=512` 已有 `45q>80`，故与 `(QP)` 矛盾。

因此，一行的完整排除只需要：

1. 逐位提升唯一奇根到 `2^(rho+4)`；
2. 检查大小界；
3. 在大小界内时，检查 `R mod 2^80`。

不需要枚举全部 `m`，也不需要计算巨大整数 `R`。

## P3. 固定乘子 `m=1,3,9` 全排

后面的索引秩论证需要先知道真实乘子不可能只含 `3`。

对固定

```math
m\in\{1,3,9\}
```

和固定 `rho`，写

```math
q=2^{\rho-3}w,
\qquad 1\le w<2^{56-\rho},
\qquad w\text{ 奇}.
```

考虑

```math
G_{\rho,m}(w)=\frac{R(d(w),2m x(w)y(w))}{8}.
```

对每个 `m` 和每个 `rho=12,...,55`，证书从模 `2` 开始，在每一位同时计算两个可能提升，验证恰有一个提升继续满足同余。因此模

```math
2^{56-\rho}
```

恰有一个奇根 `w_{rho,m}`，而它就是允许区间中的唯一可能 `w`。

总共 `3*44=132` 个候选全部直接计算；最大

```math
v_2(R)=52,
```

远小于 `(QP)` 所需值。故

```math
\boxed{m\notin\{1,3,9\}.}                         \tag{NO139}
```

这是一份依赖 `(Q53)` 的确定性有限证书，不冒充一般符号 Hensel 定理。

## P4. 新的索引秩缺口

令

```math
N=4q+1,
\qquad U_N=2u.
```

### P4.1 `3` 不整除 `u`

Pell 余弦序列满足

```math
U_{k+2}=4U_{k+1}-U_k,
\qquad U_0=1,
\qquad U_1=2.
```

模 `3` 可归纳得

```math
U_k\equiv
\begin{cases}
1 & k\text{ 偶},\\
2 & k\text{ 奇}.
\end{cases}
```

`N` 为奇数，所以

```math
u=U_N/2\equiv1\pmod3.                              \tag{5}
```

### P4.2 任一非 `3` 乘子素因子产生小索引因子

由 `(NO139)`，真实 `m` 有某个奇素数

```math
p\ne3,
\qquad p\mid m.
```

由 `m|9u` 和 `(5)`，有 `p|u`，即

```math
p\mid U_N.
```

在 `F_{p^2}` 中置

```math
\alpha=2+\sqrt3.
```

`p|U_N` 等价于

```math
\alpha^{2N}=-1.
```

故 `ord_p(alpha)` 的 `2` 部恰为 `4`，可以写成

```math
ord_p(\alpha)=4r,
\qquad r\mid N.
```

因 `U_1=2`，有 `r>1`。若

```math
\ell=P^-(N)
```

为 `N` 的最小素因子，则

```math
r\ge\ell.                                           \tag{6}
```

另一方面：

- 若 `(3/p)=1`，则 `alpha in F_p^*`，所以 `4r|p-1`；
- 若 `(3/p)=-1`，Frobenius 给 `alpha^p=alpha^{-1}`，所以 `4r|p+1`。

统一写成

```math
4r\mid p-(3/p).
```

于是

```math
4r\le p+1.                                          \tag{7}
```

又 `p<=m<27*2^(rho-1)`，且右端是 `4` 的倍数，所以

```math
p+1\le27\,2^{\rho-1}.
```

结合 `(6)`、`(7)`：

```math
\boxed{
P^-(4q+1)\le27\,2^{\rho-3}.
}                                                    \tag{INDEX-RANK-GAP}
```

这使用的是索引 `N=4q+1`，不同于 Round 13–14 对 `t=8q+1` 的 BAD-RANK / RANK--EXPONENT 筛。

所以，当前剩余 `rho=12,...,27` 中的全部

```math
P^-(4q+1)>27\,2^{\rho-3}
```

行一次性退出。

## P5. `4q+1` 为素数的完整子域退出

若

```math
N=4q+1
```

为素数，则 `P^-(N)=N`。由 `INDEX-RANK-GAP`：

```math
4\,2^{\rho-3}w+1\le27\,2^{\rho-3}.
```

故

```math
w<27/4,
```

而 `w` 为正奇数，所以只剩

```math
w\in\{1,3,5\}.                                     \tag{8}
```

本轮另对 `(8)` 中在 `q<2^53` 下合法的全部 `129` 行执行 P1 的短根与 `2^80` 检查；最大 `v2(R)` 为 `62`，无一通过。

因此：

```math
\boxed{4q+1\text{ 为素数的纯二 BRIDGE4096 子域为空。}} \tag{PRIME-INDEX}
```

这是条件子域闭合，不是整个纯二桥闭合。
