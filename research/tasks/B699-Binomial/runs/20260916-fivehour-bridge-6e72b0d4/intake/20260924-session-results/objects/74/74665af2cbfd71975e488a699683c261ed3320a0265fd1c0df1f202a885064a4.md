# 离线重放

依赖：Python 3.10+（标准库）、g++ C++17。无需网络、旧仓库、SymPy、NumPy或Lean。

在解压目录运行：

    python3 -B code/replay.py --out /absolute/path/to/nonexistent-output

输出目录必须不存在。程序在输出目录编译、保存日志和新证书，不改输入目录。

它会重生成七批完整根门，重做两个素数下全部19156系统、另重构32719的19156子式、检查有理根/源线/z/亏格/矩条件、拒绝损坏证书、重跑两个完整粗账本、重建定向聚合及状态666全部五多重集合，再输出347状态。

比较certificates下全部本轮确定性文件的字节。实际时间和版本仅存输出目录REPLAY_RECEIPT.json，不进入确定性比较。

inputs/SOURCE_MANIFEST.json与MANIFEST.sha256分别绑定采用前置和包内全部文件。外部CLEAN_REPLAY_RECEIPT.json记录实际从包解压后执行的结果及最终ZIP身份。

证明范围：重放本轮有限计算及代数证书，未重新机器证明纸面无限量词桥、出版亏格定理或历史B699原题消费者。
