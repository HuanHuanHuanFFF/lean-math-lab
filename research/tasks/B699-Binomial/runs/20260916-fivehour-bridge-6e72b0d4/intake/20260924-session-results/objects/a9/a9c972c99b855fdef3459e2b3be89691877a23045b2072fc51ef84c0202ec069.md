# FAILURES — C12

## F1. 有效有限化不等于闭合

本轮只证明：

```text
A尾 NC6 => n<2^291,
B尾 NC6 => n<2^523.
```

没有生成、扫描或排空这些巨大有限盒；不能写成两个尾类完整闭合。

## F2. 不能删除尾类和 alpha 模板前提

BFT 付款矩阵使用了真实表示

```text
A: n=2^a(cg), n-2=3^b(2q2), n-5=5^E(3q5);
B: n=3^a(cg), n-2=2^bq2, n-5=5^Eq5.
```

一般 i=6 的其他模类不具备这些同一表示，不能直接继承本轮界。

## F3. BFT 是外部出版输入

重放验证指数、40对显式例外和全部巨大整数比较，不重新证明 BFT。

## F4. 当前最坏付款壳

A尾最弱支是 `2q2` 与 `3q5` 分别付款，指数 `1.113`。
B尾最弱支是 `q2` 与 `q5` 分别付款，指数 `1.071`。

同时，K16 的最弱槽费用发生在第2源端点、且第5源中央时，
即 `M2=Q50=Q51=1`。若要继续缩小有限盒，应首攻这个精确壳；
扩大固定素数表不会改变增长指数。

## F5. 没有 NC 保持下降
