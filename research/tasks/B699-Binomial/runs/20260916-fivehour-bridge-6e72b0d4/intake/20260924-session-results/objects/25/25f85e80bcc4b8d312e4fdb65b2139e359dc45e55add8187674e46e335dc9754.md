## P0. 范围与同一原输入

固定**同一个原始合法数对** `(n,j)`，令 `k=n-j`，反设其处于 `NC3`。本轮不重建历史，只采用第九轮冻结的规范最小临界两底必要核心：

```text
g=lambda=w_old=1，b=2r，xi=2mu；沿冻结出口取真实mu=1。
```

仍有

```math
P=Q+hv,
\qquad 2\nu=h(Q-v)-Q,
\qquad v\nu^2=PQ^2-1,
```

```math
n=PQ\nu+2=c2^s,
\quad j=(P+\nu)Q^2,
\quad k=(Q^2+v\nu)P.
```

原 `P=p^a,Q=q^r` 是不同奇素数的完整幂；`Q>=11`，`h>=15` 为奇数，`v` 为正偶数，`nu=2H` 且 H 奇。置

```math
d=\Delta=Q-v\ge17,
\quad d\equiv1\pmod{16},
\quad Q/3<v<Q,
\quad W=(d^3-1)/v.
```

本轮继续第九轮的**平衡域**

```math
D_v=D_W=y,
\quad d^2+d+1=3y^2,
\quad v=Ay,
\quad W=By,
\quad AB=3(d-1),                                      \tag{BAL}
```

其中 `A>=2` 为偶数，`B>=1`，`y` 可合数，且

```math
\gcd(y,3(d-1))=\gcd(y,d)=1.
```

Pell 规范为

```math
U_t+X_t\sqrt3=(2+\sqrt3)^t,
\quad U_t=2y,
\quad d=(3X_t-1)/2,
\quad t\equiv1\pmod8.
```

本轮新增结果仅排除此必要系统的若干无界条件域。它们不是一般两底、真三槽、多槽或整个 `i=3` 的结论；任何必要系统中的形式解也不能反向称作 NC3。

## P1. B 侧四次界降为二次界 BICOF2

第九轮已经在同一正根上证明

```math
R_0=\frac{12(d^2-d)}{B^2}+\frac{30y}{B}+\frac{27}{4},
```

```math
\left|h-R_0+\frac{10\sqrt3}{B}\right|
<\frac{2B+11/B+12/B^2}{d}.                             \tag{IRR}
```

这次利用了一个此前未消费的整数因子。由 `AB=3(d-1)`，

```math
4BR_0=16Ad+120y+27B.
```

因此

```math
J:=16Ad+120y+27B-4Bh\in\mathbb Z,
```

且将 IRR 乘以 `4B` 得

```math
|J-40\sqrt3|
<\frac{8B^2+44+48/B}{d}.                               \tag{1}
```

### P1.1 到最近整数的精确距离

有

```math
69^2=4761<4800=(40\sqrt3)^2<4900=70^2,
```

又因 `(139/2)^2>4800`，故 `40sqrt3<69.5`，最近整数是 69。于是对任意整数 J，

```math
|J-40\sqrt3|
\ge40\sqrt3-69
=\frac{39}{40\sqrt3+69}
>\frac{39}{139}.                                       \tag{2}
```

对 `B>=1`，

```math
8B^2+44+48/B\le100B^2.
```

由 (1)、(2)，

```math
d<\frac{13900}{39}B^2<357B^2.
```

所以得到本轮第一条新无界区域排除：

```math
\boxed{d<357B^2.}                                      \tag{BICOF2}
```

这比旧 `d<32768B^4` 严格降低了 B 的次数；没有固定 B 或 d，也没有有限末端。

### P1.2 新相对高度

由 `AB=3(d-1)` 与 BICOF2，

```math
A^2=\frac{9(d-1)^2}{B^2}<3213d<2^{12}d.                \tag{3}
```

沿用第九轮的 `y<3d/5` 与 `A>=2`，

```math
Q=d+Ay<\frac{11}{10}Ad,
```

故

```math
\boxed{Q^2<2^{12}d^3.}                                 \tag{4}
```

同一原范数已有

```math
\nu<3Q^2/d,
\quad P<7Q^3/d^2,
\quad n<22Q^6/d^3.
```

代入 (4)，得到

```math
\boxed{n<2^{41}d^6.}                                   \tag{5}
```

又 `d<(2+sqrt3)^t/2` 且 `(2+sqrt3)^10<2^19`，所以

```math
n^{10}<2^{114t+350}.
```

对于同一个原 `n=c2^s`，有

```math
\boxed{s\le\left\lfloor\frac{114t+349}{10}\right\rfloor.} \tag{6}
```

这些仍是相对界；t、d、B 本身没有绝对界。

## P2. TRI3：Pell 指数不能被 3 整除

原平方范数的无除法形式为

```math
Y^2=S:=v^4+5dv^3+10d^2v^2+10d^3v+5d^4+d^2W.           \tag{7}
```

在平衡域 `y|v,W`，且 `gcd(d,y)=1`，故

```math
Y^2\equiv5d^4\pmod y.                                  \tag{8}
```

若 `3|t`，Pell 递推

```math
U_{m+2}=4U_{m+1}-U_m
```

在模 5 下的完整周期是

```text
1,2,2,1,2,2,...
```

因此 `U_t=1 mod5`，从而

```math
y=U_t/2\equiv3\pmod5.
```

此时 5 与 y 互素。(8) 强迫 Jacobi 符号 `(5/y)=1`；但因 `5=1 mod4`，二次互反律给

```math
(5/y)=(y/5)=(3/5)=-1,
```

矛盾。所以

```math
\boxed{3\nmid t.}                                      \tag{TRI3}
```

写 `t=8k+1`，便等价于

```math
\boxed{k\not\equiv1\pmod3.}                           \tag{9}
```

后面的有限状态证书均显式保留这个条件。

## P3. 相邻 Pell 块的准确乘积

置

```math
a=(t+1)/2=4k+1,
\qquad b=(t-1)/2=4k.
```

Pell 加法式和行列式恒等式给

```math
X_t=U_aX_b+X_aU_b,
\qquad X_aU_b-U_aX_b=X_{a-b}=1.
```

因此

```math
X_t-1=2U_aX_b,
```

再由 `d=(3X_t-1)/2` 得

```math
\boxed{3(d-1)=9U_aX_b.}                                \tag{10}
```

与 `AB=3(d-1)` 合并：

```math
\boxed{AB=9U_aX_b.}                                    \tag{11}
```

本轮的目标是证明 B 不能全部来自等式右边任意一个相邻块。

## P4. X 块单侧分配全部退出

### 定理 XBLOCK

在本轮必要核心中，

```math
\boxed{B\nmid9X_b.}                                    \tag{XBLOCK}
```

反设 `B|9X_b`，定义正整数

```math
m=9X_b/B.
```

由 (11)，

```math
A=mU_a.                                                 \tag{12}
```

### P4.1 乘子统一界 m<=39

当前 `d>=17` 排除 k=0，所以 `k>=1,b>=4,X_b>=56`。由

```math
U_b^2=3X_b^2+1>(5X_b/3)^2,
```

有

```math
U_a=2U_b+3X_b>19X_b/3.
```

于是

```math
d=1+3U_aX_b>19X_b^2.                                  \tag{13}
```

BICOF2 与 `B=9X_b/m` 给

```math
m^2<\frac{28917X_b^2}{d}<\frac{28917}{19}<1522,
```

所以

```math
\boxed{1\le m\le39.}                                   \tag{14}
```

这个有限范围由无界参数证明推出，不是任意扫描上限。

### P4.2 m=1：原 Q 的模 9 矛盾

此时 `A=U_a`。对 `k mod3=0,1,2`，完整 Pell 递推模 18 给

```text
(d mod9, U_a y mod9, Q mod9)
=(1,2,3), (4,8,3), (7,8,6).
```

TRI3 排除中间类。余下两类均有 `3|Q` 但 `9∤Q`。原 `Q=q^r>=11` 是奇素数幂，因此若 3 整除 Q，必须为 `3^r`；`v_3(Q)=1` 又迫使 `Q=3`，矛盾。

### P4.3 m=2：原 Q 强制分解为两个互素大因子

令 `c=b/2=2k`，写

```math
U_c=u,
\qquad X_c=x,
\qquad u^2-3x^2=1.
```

直接在环 `Z[u,x]/(u^2-3x^2-1)` 中展开，可得

```math
Q=(u+3x)^2C,                                            \tag{15}
```

其中

```math
C=u(18x+72x^3)+5+60x^2+144x^4.
```

置 `R=u+3x`。模 R 有 `u=-3x` 且 `6x^2=1`，所以

```math
C\equiv5+6x^2-72x^4\equiv4\pmod R.
```

c 为正偶数，故 u 奇、x 偶，R 为奇数；于是 `gcd(R,C)=1`。同时 `R>1,C>1`。由 (15)，Q 含有两个互素的非平凡因子，不可能是素数幂。

### P4.4 3<=m<=39：完整有限状态非剩余证书

对每个固定 m，条件 `m|9X_b` 以及所有 Pell 坐标，只依赖于

```math
\beta_k=(U_{4k},X_{4k})=(2+\sqrt3)^{4k}
```

在有限环中的状态。对证书中列出的每个奇素数 p，使用模 `mp` 的**首返周期**；若 `m|9X_b`，则由 `9X_b mod mp` 可以准确恢复商

不是在模 p 中非法除以 m。随后按 (7) 计算 S。若 S 是整数平方，则模任意 p 必为平方或零；证书在每个允许状态给出某个 p 使


每个周期从单位状态开始迭代到第一次返回；乘法可逆，故这是完整周期，不是前缀采样。结合 (14) 与 m=1,2 的纸面证明，XBLOCK 得证。

## P5. U 块单侧分配全部退出

### 定理 UBLOCK

```math
\boxed{B\nmid9U_a.}                                    \tag{UBLOCK}
```

反设 `B|9U_a`，定义

```math
m=9U_a/B,
```

则由 (11)

```math
A=mX_b.                                                 \tag{16}
```

### P5.1 乘子统一界 m<=250

仍取 `b>=4`。因为 `X_b>4`，

```math
U_b^2=3X_b^2+1<(7X_b/4)^2.
```

所以

```math
U_a=2U_b+3X_b<13X_b/2,
\qquad X_b>2U_a/13.
```

从而

```math
d=1+3U_aX_b>6U_a^2/13.                                \tag{17}
```

BICOF2 与 `B=9U_a/m` 给

```math
m^2<\frac{28917U_a^2}{d}<\frac{28917\cdot13}{6}<251^2.
```

故

```math
\boxed{1\le m\le250.}                                  \tag{18}
```

### P5.2 m=2：第二个原 Q 强制分解

仍令 `c=b/2`、`u=U_c,x=X_c`。准确展开给

```math
Q=(u+x)C_2,                                             \tag{19}
```

```math
C_2=72ux^4+42ux^2+u+216x^5+126x^3+15x.
```

置 `R=u+x`。模 R 有 `u=-x`，Pell 关系给 `2x^2=-1`，于是

```math
C_2\equiv8x\pmod R.
```

而 `gcd(R,x)=gcd(u,x)=1`，R 为奇数，所以 `gcd(R,C_2)=1`。两因子均大于 1，Q 再次不可能是素数幂。

`evidence/verify.py` 使用一个只含整数系数的微型符号环，逐系数重放 (15)、(19)，不依赖 SymPy。

## P6. 真混合结论 BLOCK-MIX

从 (11)，B 整除 `9U_aX_b`。定义两个准确缺额块

```math
B_U:=\frac{B}{\gcd(B,9X_b)},
\qquad
B_X:=\frac{B}{\gcd(B,9U_a)}.
```

逐素数比较赋值可知

```math
B_U\mid U_a,
\qquad B_X\mid X_b.
```

XBLOCK 与 UBLOCK 分别给

```math
\boxed{B_U>1,
\qquad B_X>1.}                                         \tag{BLOCK-MIX}
```

所以剩余 B 必须真正消费相邻两个 Pell 块，不能整体来自任意一边。这是本轮第二个真实 frontier reduction。

必须保留边界：`B_U,B_X` 不一定互素，也不保证含两个不同奇素数；同一个 2 的完整指数可能跨越两侧。BLOCK-MIX 是完整赋值缺额结论，不是“两个指定粗素数成为原题共同见证”。

## P8. 原题回传与证据等级

反设同一原 `(n,j)` 处于 NC3，并采用冻结桥进入 P0。若其平衡线性系数 B 整体来自 X 块或 U 块，则分别由 P4、P5 得矛盾；因此该原数对不能处于这些条件域，按反证返回原题：存在某个同一素数 `p>=3` 同除 `C(n,3)` 与 `C(n,j)`。

本轮没有指定辅助证书素数为原题见证；证书素数只用于否定平方必要条件。没有换 `(n,j)`、没有把必要条件反向当充分条件，也没有构造原题反例。

本轮新增：

1. `d<357B²`，以及 `Q²<2^12d³`、`n<2^41d^6`、新的原指数相对界；
2. `3∤t`；
3. `B∤9X_b` 与 `B∤9U_a` 两个无界 one-block 条件域全部退出；
4. 剩余 B 必须满足 BLOCK-MIX。

仍未闭合：混合平衡域、非平衡多底、一般两底 low/low 与交叉、真三槽/多槽，以及其他恢复三次/实际内容三次区域。t、d,y,A,B、原 P/Q 指数、n 等仍无统一绝对界。

证据等级是：冻结作者级入口＋本轮纸面证明＋精确首返周期/非剩余证书＋离线重放。它不是 Lean，也不是外部独立审读；全仓库历史消费者并集的净差未审计。
