# 完整、分段及负控制重放

Python 3.10+、g++ C++17；标准库；不运行Lean，不联网，不接触仓库。
以下OUT必须是不存在的绝对路径。命令从解压后的包根目录运行。

## 一次性运行

```sh
python3 -B code/replay.py --out /absolute/new-output
python3 -B code/replay.py --out /absolute/new-output --stage compare
```

## 工具有单次超时限制时

分段没有削弱范围；每段指定相邻不重叠case索引，最终finish强制验证两个素数的全部46个系统。

```sh
python3 -B code/replay.py --out "$OUT" --stage init
python3 -B code/replay.py --out "$OUT" --stage geometry
python3 -B code/replay.py --out "$OUT" --stage fees
python3 -B code/replay.py --out "$OUT" --stage modules --prime 257 --start 0 --stop 23
python3 -B code/replay.py --out "$OUT" --stage modules --prime 257 --start 23 --stop 46
python3 -B code/replay.py --out "$OUT" --stage modules --prime 263 --start 0 --stop 20
python3 -B code/replay.py --out "$OUT" --stage modules --prime 263 --start 20 --stop 36
python3 -B code/replay.py --out "$OUT" --stage modules --prime 263 --start 36 --stop 46
python3 -B code/replay.py --out "$OUT" --stage reference
python3 -B code/replay.py --out "$OUT" --stage finish
python3 -B code/replay.py --out "$OUT" --stage compare
```

不是读取预置PASS字符串：
- geometry完整重生成两个锚点的474门、948次满列秩与474个局部卷积子式；
- fees重建原源状态和173条当前查询，用新签名双算法得到3+46目标；
- modules重建全部商条件，重新计算每个discrepancy及完整截断核；
- reference执行46494费用格交叉、80小型稠密矩阵比较、S5整数符号界及11个负控制；
- finish不允许缺少第二素数、遗漏任何目标或缺终端权次；
- compare对本包全部确定性证书作字节一致比较，同时禁止多出或少掉证书文件。
