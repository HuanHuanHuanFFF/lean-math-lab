# 证明细节 · RANK–EXPONENT / 小秩反链

## P0. 冻结前置

继续同一原始 `(n,j)` 的平衡必要核心。Round 13 已给

```math
n=c2^s,
\qquad c\in\{1,3\},
```

```math
(n-3)^2\equiv5\pmod y,
\qquad y=U_t/2,
\qquad t=8q+1.
```

这里 `U_k+X_k sqrt(3)=(2+sqrt(3))^k`。本轮不放松完整平方范数、`P/Q` 完整素数幂或原输入条件。

## P1. 全平衡核心的 T-HEIGHT

### P1.1 下界

由 Round 13，

```math
(n-3)^2-5\equiv0\pmod y.
```

在当前高桥范围 `n>6`，左侧为正，故

```math
y\le(n-3)^2-5<n^2.                    (1)
```

令 `alpha=2+sqrt(3)`。因

```math
U_t=(alpha^t+alpha^(-t))/2,
\qquad y=U_t/2,
```

有

```math
y>alpha^t/4.                            (2)
```

又 `n=c2^s,c<=3`，所以

```math
alpha^t<4n^2\le36*2^(2s)<2^(2s+6).
```

由于 `alpha>2`，

```math
t<2s+6.
```

`t` 为奇数，故

```math
\boxed{s\ge(t-5)/2.}                   (3)
```

### P1.2 上界

从

```math
d^2+d+1=3y^2
```

且 `d>1`，有

```math
d/2<y<d.                               (4)
```

`A,B` 为正整数且 `AB=3(d-1)`，于是

```math
A\le3(d-1),
\quad v=Ay<3d^2,
\quad Q=d+v<4d^2.                      (5)
```

由

```math
vnu^2=PQ^2-1,
\quad P=Q+hv,
```

得到

```math
nu^2<(Q/v+h)Q^2<(h+3)Q^2,              (6)
```

其中使用 `v>d/2`，故 `Q/v<3`。

另一方面 `2nu=hd-Q>0`。置 `R0=Q/d`，由 (6)：

```math
h<R0(1+2sqrt(h+3)).                     (7)
```

令 `x=sqrt(h+3)`，则

```math
x<R0+sqrt(R0^2+R0+3)<2R0+2.
```

由 `R0<4d`，

```math
h<4(R0+1)^2<100d^2.                    (8)
```

于是

```math
nu<hd/2<50d^3,
```

```math
P=Q+hv<4d^2+100d^2*3d^2<304d^4.
```

所以

```math
n-2=PQnu<60800d^9,
```

从而

```math
n<2^16d^9.                              (9)
```

再由 `U_t=2y` 与 Pell 方程：

```math
U_t^2-3X_t^2=1,
```

配合 `d^2+d+1=3y^2` 得

```math
3X_t=2d+1.                              (10)
```

故 `d<alpha^t<4^t`。将其代入 (9)：

```math
2^s\le n<2^(18t+16),
```

即

```math
\boxed{s\le18t+15.}                    (11)
```

(3)、(11) 合为 T-HEIGHT。

## P2. BRIDGE4096 的 Q-POWER

纯二高桥已有

```math
n>32d^3.                                (12)
```

由 (10) 及

```math
X_t=(alpha^t-alpha^(-t))/(2sqrt3),
```

有

```math
d=\frac{\sqrt3}{4}(alpha^t-alpha^{-t})-\frac12.
```

为避免数值近似，可用 `5/3<sqrt(3)<2`。当 `t>=2` 时，

```math
d-alpha^t/8
> (5/12-1/8)alpha^t-\frac12alpha^{-t}-\frac12
> \frac7{24}alpha^t-1>0.
```

当前 `t>=4097`，故严格得到

```math
d>alpha^t/8.                            (13)
```

又 `t=8k+1` 且

```math
alpha^8=18817+10864sqrt3>2^15.
```

所以

```math
alpha^t>2^((15t-7)/8),
\qquad d>2^((15t-31)/8).                (14)
```

把 (14) 代入 (12)，并用 `c<4`：

```math
2^s=n/c>2^((45t-69)/8).
```

因 `t=1 mod8`，右侧指数为整数，故

```math
\boxed{s\ge(45t-61)/8.}                (15)
```

Round 12 的精确赋值 `v2(R)=s+2` 与 `t=8q+1` 给

```math
v2(R)\ge(45t-45)/8=45q.                (16)
```

由 (11) 还得

```math
v2(R)\le18t+17=144q+35.                (17)
```

这就是 Q-POWER。

## P3. 指数类门

设奇素数 `ell|y`。由

```math
(c2^s-3)^2\equiv5\pmod ell
```

知 `5` 在 `F_ell` 中为平方。任取 `z^2=5`，则

```math
c2^s\equiv3+z
```

或

```math
c2^s\equiv3-z\pmod ell.                 (1)
```

令

```math
o=ord_ell(2),
```

并定义

```math
E_(ell,c)=
{e in Z/oZ : c2^e=3+z or 3-z mod ell}. (2)
```

于是同一个真实输入必须有

```math
s mod o in E_(ell,c).                    (3)
```

若 `E_(ell,c)=empty`，该 `c` 分支退出。若两个素因子 `ell1,ell2` 同时整除 `y`，则同一个 `s` 必须满足两组同余；其充要相容条件是存在

```math
e1 in E_(ell1,c), e2 in E_(ell2,c)
```

满足

```math
e1=e2 mod gcd(o1,o2).                   (4)
```

## P4. 从 `r|t` 向素因子传递

置

```math
alpha=2+sqrt(3).
```

在任意含 `sqrt(3)` 的剩余域中，

```math
2U_r=alpha^r+alpha^(-r).
```

若 `ell|U_r`，则

```math
x:=alpha^r
```

满足 `x+x^(-1)=0`，即 `x^2=-1`。若 `t=kr` 且 `k` 为奇数，则

```math
alpha^t+alpha^(-t)=x^k+x^(-k)=0.
```

故

```math
ell|U_t.                                 (5)
```

本轮所有 `r,t` 都是奇数；因此 `r|t` 自动保证 `t/r` 为奇数。

## P5. 证书如何证明完整性

对每个表中素数 `ell`，证书检查：

1. `ell` 的确定性素性；
2. 给定 `ell-1` 分解逐项乘回；
3. `2^o=1 mod ell`，且对每个素数 `p|o` 有 `2^(o/p)!=1`，所以 `o=ord_ell(2)`；
4. `z^2=5 mod ell`；
5. Pell 对坐标精确计算给 `U_r=0 mod ell`；
6. 对每个根 `x=3±z`：
   - 若给出指数 `e`，核验 `c2^e=x mod ell`；
   - 若记为 `empty`，核验 `(x/c)^o!=1`，所以 `x/c` 不在唯一的阶 `o` 子群 `<2>`。

因此表中的 `E_(ell,c)` 是完整集合，而非搜索截断。

## P6. `17|t` 的排除

精确整数递推给

```math
U_17/2=1321442641.
```

证书证明它为素数，并给

```math
ord_ell(2)=66072132.
```

两个根 `x=3±sqrt(5)` 对 `c=1,3` 的四个目标均不属于 `<2>`：对应的 `o` 次幂为

```text
101030474,
210043663,
1321442640,
402961008,
```

均不等于 `1 mod ell`。故 `(1)` 无解，结合 (5) 得 `17∤t`。

## P7. `29|t` 的排除

取 `ell1=349,ell2=6961`，两者均整除 `U_29`。

```text
E_(349,1)={113,237} mod348,
E_(349,3)={87,211} mod348;
```

```text
E_(6961,1)=empty,
E_(6961,3)={926} mod1160.
```

`c=1` 无解。对 `c=3`，

```math
gcd(348,1160)=116,
```

且

```text
{87,211} mod116={87,95},
{926} mod116={114}.
```

由 (4) 不相容，故 `29∤t`。

## P10. 小秩反链

选取：

```text
r=5:  ell=181;
r=7:  ell=2521;
r=11: ell=489061;
r=13: ell=6811741;
r=19: ell=18405321661.
```

其完整指数类见 REPORT 表。

`r=7` 的指数类全部为偶数；其余四秩的指数类全部为奇数，所以含 `7` 的四对全部不相容。

余下六对：

- `(5,11)`：模60，`c=1` 两侧 `{33,29}` 与 `{35,27}` 无交；`r=11` 的 `c=3` 为空；
- `(5,13)`：模20，`{13,9}` 与 `{19,3}` 无交；`r=13` 的 `c=3` 为空；
- `(5,19)`：模180，`c=1` 的 `{33,149}` 与 `{49,133}` 无交，`c=3` 的 `{93,157}` 与 `{49,133}` 无交；
- `(11,13)`：模20，`{15,7}` 与 `{19,3}` 无交；两者 `c=3` 均空；
- `(11,19)`：模60，`{35,27}` 与 `{49,13}` 无交；`r=11` 的 `c=3` 为空；
- `(13,19)`：模20，`{19,3}` 与 `{9,13}` 无交；`r=13` 的 `c=3` 为空。

因此任意两个不同的 `r` 同时整除 `t` 都矛盾，证明

```math
#\{r in {5,7,11,13,19}:r|t\}\le1.       (6)
```

## P11. 无界域与 q 余类

对任意奇数 `R`，

```math
R|t=8q+1
```

等价于

```math
q=-8^(-1) mod R.                         (7)
```

这给出 REPORT 中四个单秩和十个二秩余类。

固定 `rho>=12`，写 `q=2^(rho-3)w`，其中 `w` 奇且 `3|w`。由于所有 `R` 都与 `6` 互素，(7)、`w` 奇、`3|w` 可由 CRT 同时满足，且有无穷多 `w`。所以每一项都是真正横跨所有 `rho` 的无界域删除。

## P12. 精确密度

对集合 `{5,7,11,13,19}`，还要加入 `49∤t`。令 `B={5,11,13,19}`。允许状态为：

1. 五个素数均不整除 `t`：

```math
(6/7) product_(p in B) (p-1)/p;
```

2. 只有 `7` 整除且 `49∤t`：

```math
(6/49) product_(p in B) (p-1)/p;
```

3. 只有某个 `p in B` 整除：

```math
sum_(p in B) (1/p)(6/7) product_(r in B,r!=p)(r-1)/r.
```

再乘以

```math
16/17 * 28/29 * 36/37
```

得到本轮存活比例

```math
1364262912/1734627895,
```

故删除比例

```math
370364983/1734627895.
```

Round 13 的八个秩与本轮模数互素；乘存活比例后得到累计删除

```math
132101365092535013/391420459405495013.
```

## P13. 返回原题的逻辑边界

本轮只排除 NC3 必要状态：若同一原 `(n,j)` 落入上述秩域，则它无法满足由完整平方范数推出的 `(RE)`，故不可能是 NC3；于是原输入必有某个真实共同素数 `p>=3`。

证书中的 Pell 素因子只用于反证必要恢复，不被称作原题共同见证。
