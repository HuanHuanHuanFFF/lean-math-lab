## P1. 从完整平方范数恢复精确主项

置

```math
Y=d\nu-Q^2.
```

由冻结核心直接展开：

```math
vY^2-(Q^5-d^2)
=d^2(v\nu^2-PQ^2+1)=0.
```

所以

```math
\boxed{vY^2=Q^5-d^2.}                              \tag{1}
```

令

```math
r=\frac vd,
\qquad \omega=\frac{Y}{d^2}.
```

由 `(1)`：

```math
\omega^2=\frac{(1+r)^5}{r}-\frac1{rd^3}.           \tag{2}
```

另一方面，由 `2nu=hd-Q`：

```math
2Y=hd^2-dQ-2Q^2
=d^2(h-3-5r-2r^2),
```

故

```math
\boxed{h=3+5r+2r^2+2\omega.}                       \tag{3}
```

再把

```math
P=d(1+r+hr),
\quad Q=d(1+r),
\quad \nu=\frac d2(h-1-r)
```

代入 `n-2=PQnu`，得到精确式

```math
\boxed{
n-2=\frac{d^3}{2}(1+r+hr)(1+r)(h-1-r).
}                                                    \tag{4}
```

这些等式没有更换原始 `(n,j)`。

## P2. 纯二分配使 `r` 指数级大

由 `q=2^(rho-3)w`，有

```math
2^\rho\le8q,
\qquad m<27\,2^{\rho-1}\le108q.                    \tag{5}
```


所以

```math
x=\frac{X}{2^\rho}>\frac{Z}{64q}.
```

进而

```math
r=\frac{2mxy}{d}>mx\ge x>\frac{Z}{64q}.             \tag{6}
```

`alpha>2` 且 `q>=512`。函数 `2^(4q)/q` 在正整数上严格递增，而

```math
2^(4*512)>2^22>6400*512.
```

故 `(6)` 特别给出

```math
\boxed{r>100.}                                       \tag{7}
```

## P3. 原 `n` 与 `8v^6/d^3` 的相对误差

令

```math

```

由 `(2)`：

```math
T^2=\left(1+\frac1r\right)^5-\frac1{r^5d^3}.       \tag{8}
```

对 `r>=100`：

```math
1-r^{-5}\le T\le1+\frac5r.
```

上界可令 `z=1/r<=1/100`，并检查

```math
(1+5z)^2-(1+z)^5
=z(5+15z-10z^2-5z^3-z^4)>0.
```

因此

```math
|T-1|\le\frac5r.                                    \tag{9}
```

由 `(3)`、`(9)`：

```math
|h-4r^2|
\le5r+3+2r^2|T-1|
<16r.                                                 \tag{10}
```

把 `(4)` 的三个因子写为

```math
1+r+hr=4r^3(1+e_1),
```

```math
1+r=r(1+e_2),
```

```math
h-1-r=4r^2(1+e_3).
```

由 `(10)`、`r>=100`：

```math
|e_1|\le\frac5r,
\qquad |e_2|=\frac1r,
```

所以

```math
\left|
\frac{n-2}{8d^3r^6}-1

\le\frac{11}{r}+\frac{35}{r^2}+\frac{25}{r^3}

```

记


因 `2/M<1/r`，由 `(11)` 得


## P4. Pell 主项及指数小误差

由 P0 的三个精确 Pell 式，定义

```math
N_0=
\frac{m^6\alpha^{48q+3}}
     {8\,3^{9/2}\,2^{6\rho}}.                       \tag{13}
```

再置

```math
E=Z^{-2},
```

```math
R_X=1-E,
```

```math
R_y=1+\alpha^{-2}E^2,
```

```math
R_d=1-\alpha^{-2}E^2
      -\frac{2}{\sqrt3\alpha}E.
```

直接约去主项得到精确恒等式

```math
\boxed{
\frac{M}{N_0}=R_X^6R_y^6R_d^{-3}.
}                                                    \tag{14}
```

由于 `alpha>2`，已有 `E<1/256`。并且

```math
\frac{2}{\sqrt3\alpha}<\frac23.
```

于是

```math
0<1-R_d<E^2+\frac23E<\frac34E.
```

当 `0<=x<=3/1024` 时，精确多项式检查给

```math
(1-x)^{-3}\le1+4x.
```

故

```math
R_d^{-3}\le1+3E.
```

另有

```math
R_y^6\le(1+E^2)^6\le1+63E^2\le1+E/4,
```

以及 Bernoulli 不等式

```math
R_X^6=(1-E)^6\ge1-6E.
```

因此 `(14)` 给出

```math
\boxed{
\left|\frac{M}{N_0}-1\right|\le6E.
}                                                    \tag{15}
```

将 `(12)` 与 `(15)` 相乘。因 `r>100`，交叉项小于 `E`，所以

```math
\left|\frac n{N_0}-1\right|
<\frac{13}{r}+7E.
```

再用 `(6)` 与 `E=Z^{-2}`：

```math
\frac{13}{r}<\frac{832q}{Z},
\qquad 7E<\frac{7q}{Z}.
```

最终得到本轮的有效主项：

```math
\boxed{
\left|
\frac{n}{N_0}-1
\right|
<1000q\alpha^{-4q}.
}                                                    \tag{MAIN}
```

## P6. Matveev 显式下界的参数

采用 Matveev 对正实代数数乘积的标准显式形式。若

```math
\Lambda=\gamma_1^{b_1}\cdots\gamma_k^{b_k}-1\ne0,
```

所有 `gamma_i` 位于次数 `D` 的实数域，且

```math
A_i\ge\max\{D h(\gamma_i),|\log\gamma_i|,0.16\},
```

```math
B\ge\max_i|b_i|,
```

则

```math
\log|\Lambda|
>-1.4\,30^{k+3}k^{4.5}D^2(1+\log D)(1+\log B)
  A_1\cdots A_k.                                    \tag{M}
```

对 `(16)` 取

```math
K=\mathbf Q(\sqrt3),
\qquad D=2,
\qquad k=3,
```

```math
(\gamma_1,\gamma_2,\gamma_3)=(2,\alpha,\beta),
```

```math
(b_1,b_2,b_3)=(s+6\rho+9,-(48q+3),-1).
```

### P6.1 指数界

由 `(H)`：

```math
b_1\le144q+6\rho+42.
```

对 `rho>=12`，有 `2^(rho-3)>rho+7`，故 `q>rho+7`。于是

```math
b_1<150q.
```

同时 `48q+3<49q`，所以可取

```math
B=150q.                                               \tag{18}
```

### P6.2 高度界

精确有

```math
h(2)=\log2,
\qquad h(\alpha)=\frac12\log\alpha.
```

利用 `log2<7/10` 与 `alpha<4`，可取

```math
A_1=A_2=7/5.                                         \tag{19}
```

`beta` 是整系数多项式

```math
3^\eta X^2-(2m)^{12}
```

的根。由该多项式的 Mahler measure：

```math
2h(\beta)
\le\max\{\eta\log3,12\log(2m)\}.
```

同时

```math
|\log\beta|
\le\max\{\eta\log3,12\log(2m)\}.
```

故可取

```math
A_3=\max\{\eta\log3,12\log(2m)\}.                  \tag{20}
```

由 `eta<=11`、`log3<6/5`、`2m<216q`、`log216<6`，以及 `q>=512`：

```math
A_3<12(\log q+6).                                    \tag{21}
```

### P6.3 常数账本

使用

```math
3^{4.5}=81\sqrt3<567/4,
```

```math
1+\log2<17/10,
```

以及 `(19)`，`(M)` 中除 `A_3(1+log B)` 外的常数严格小于

```math
\frac75\,30^6\,\frac{567}{4}\,4\,
\frac{17}{10}\left(\frac75\right)^2
=1,928,162,426,400.
```

结合 `(18)`、`(21)`：

```math
\boxed{
\log|\Gamma-1|
>-C(\log q+6)(\log q+7),
}                                                    \tag{22}
```

其中

```math
\boxed{C=23,137,949,116,800.}                        \tag{23}
```

## P7. 显式绝对界 `q<2^53`

由 `(17)`：

```math
\log|\Gamma-1|
<\log(1000q)-4q\log\alpha.
```

与 `(22)` 合并，并用 `log1000<7`：

```math
4q\log\alpha
< F(q),                                               \tag{24}
```

其中

```math
F(x)=\log x+7+C(\log x+6)(\log x+7).
```

对 `x>1`：

```math
F(x)-xF'(x)
=\log x+6+C((\log x)^2+11\log x+29)>0.
```

因此 `F(x)/x` 严格递减。

置

```math
q_0=2^53.
```

由 `log2<7/10`：

```math
\log q_0<371/10.
```

确定性有理数计算给

```math
\frac{F(q_0)}{q_0}
<\frac{439785312657929721}{90071992547409920}
<\frac{26}{5}.                                      \tag{25}
```

另一方面，`sqrt3>17/10`，故 `alpha>37/10`。精确 Taylor 余项证书给

```math
e^{13/10}
<\sum_{j=0}^{5}\frac{(13/10)^j}{j!}
 +\frac{(13/10)^6/6!}{1-13/70}
=\frac{15058990969}{4104000000}
<\frac{37}{10}.
```

所以

```math
\log\alpha>13/10,
\qquad 4\log\alpha>26/5.                            \tag{26}
```

若 `q>=q_0`，由单调性、`(25)`：

```math
F(q)/q<26/5<4\log\alpha,
```

与 `(24)` 矛盾。故

```math
\boxed{q<2^{53}.}                                    \tag{Q53}
```

## P8. 有效有限化与返回原题

由 `(Q53)` 立即得到

```math
\boxed{t=8q+1<2^{56}},
```

```math
\boxed{12\le\rho\le55},
```

```math
\boxed{m<2^{60}},
```

```math
\boxed{s<2^{61}}.
```

其中最后一式使用 `s<=144q+33` 和整数 `q<=2^53-1`。

因为 `512|q`，`q<2^53` 下的形式 Pell 行少于

```math
2^44.
```

再用冻结的 VROW1：每个固定 `q` 至多一个正乘子 `m` 能通过 POWER 赋值门；一旦 `m` 固定，`s=v_2(R)-2` 也唯一确定，之后只需检查 `c=1,3`、完整 POWER 奇部、平方范数、`P/Q` 完整素数幂以及原 `(n,j)` 恢复。

因此纯二 `BRIDGE4096` 已从无界参数域变成一个**显式、可判定、但极其巨大的有限问题**。

若某个状态违反 `(Q53)`，则它不可能来自同一原始 `NC3` 输入；于是原输入必须具有某个真正共同素数 `p>=3`。本轮没有辨识这个原见证。

证据等级：冻结作者级前置＋本轮纸面推导＋Matveev 已发表显式下界＋确定性符号/有理数重放。没有 Lean，也没有完成有限末端。
