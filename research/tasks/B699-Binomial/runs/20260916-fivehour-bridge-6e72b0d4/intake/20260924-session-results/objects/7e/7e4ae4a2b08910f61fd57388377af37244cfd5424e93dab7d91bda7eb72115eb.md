# REPLAY

默认只需Python 3标准库；不访问网络或仓库，不运行Lean。

    python3 -B src/replay.py --output-dir /tmp/b699-mix-regular-fresh

输出目录必须不存在。默认程序验证内部哈希，从原混合公式重建全部残差，逐节点核验五份QQ证书，拒绝故意损坏的证书，再比较冻结机器JSON。不要使用python -O。

可选从原公式重生成：需要SymPy 1.14.0、C++17编译器及GMP开发库。

    python3 -B src/replay.py --output-dir /tmp/b699-mix-regenerate --regenerate

生成器不信任已有输入方程快照，而从原P构造。默认每张图300秒进程终止器；若机器资源差异导致失败，不可将其记录为PASS。五张图均已在本轮实际独立重生成并与冻结证书逐字节一致。

普通REG5只可重建开放方程，不含闭合承诺：

    python3 -B src/regular_chart.py --output-dir /tmp/b699-mix-regular-open

档案完整性不是数学证明；程序不形式化无界图覆盖和NC量词。两算术实现由同一会话编写，不是外部独立数学审阅。
