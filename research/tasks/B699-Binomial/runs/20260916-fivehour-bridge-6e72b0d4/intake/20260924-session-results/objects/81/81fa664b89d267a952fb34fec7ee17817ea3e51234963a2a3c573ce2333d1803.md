# FAILURES · Round 19

## F1. 没有统一有效化 odd--odd

DIRECT 与 DUAL 只处理分配有理数 `lambda` 或互补有理数 `theta` 具有固定多项式高度的子域。现有冻结恒等式不能推出该高度条件。

## F2. 精确无限形式壳

对任意 `q mod3 in {0,2}` 的 Pell 行，置

```math
A=2^{rho-1},\qquad B=18Ux.
```

则 `AB=9UX`，处于低端 `v2(B)=2`，并且

```math
B_U=U/2,\qquad B_X=2x
```

均含非平凡奇部分；一块排除和 `d<8B^2` 也成立。其分配参数为

```math
lambda=1/x,\qquad theta=1/(9U),
```

两侧高度都随 `q` 指数增长。

这只是形式分配壳；它没有通过完整平方、POWER、`P/Q` 完整素数幂或原 `(n,j)` 恢复，不是 NC3 或反例。它精确说明：端点、BLOCK-MIX 与乘积恒等式本身不足以推出多项式高度。

## F3. `UNITARY-5` 不排除整源分配

对 `p≡2,3 mod5`，本轮只证明完整 `p`-幂不能被拆到 `A,B` 两侧。整个幂仍可合法地全部进入一侧，故不能把这条局部门称为 odd--odd 闭合。

## F4. 素数 5 仍有残余

共享 5 只被压到

```math
v5(B)=1,\qquad B/5=4 mod5.
```

这不是矛盾；还需接 Pell 源指数或 POWER 奇部。

## F5. Round 15 的有限例外仍不可计算

Corvaja--Zannier 只给平衡 odd--odd 的非有效绝对有限性。本轮没有提取其有限异常集，也没有给所有 odd--odd 一个统一数值 `q` 界。

## F6. 证据等级

程序 PASS 只重放本轮恒等式、模类和 Matveev 参数账本；不重证外部超越定理，不是 Lean 或外部独立审读。
