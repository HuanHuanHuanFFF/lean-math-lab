## 0. 两层结论与准确量词

固定自然数 n,j，7≤j≤floor(n/2)，k=n−j。Common6(n,j) 表示存在同一个
素数 p≥7 同时整除 C(n,6)、C(n,j)；这与原题 p≥6 等价。
定义

    A(n)={r∈{0,1,2,3}: 8|(n−r) 或 9|(n−r) 或 25|(n−r)}。

**C19-G（本轮自含新证明）。** 若 |A(n)|≤1，则 Common6(n,j)。此条件
恰对应1380个模1800类。结论不假设 alpha 模板、平方类、源纯分配、n奇偶、
G7、unit-coarse或任何外部无限定理。

**C19-H025（采用冻结依赖的推论）。** 在完整六窗口 n,...,n−5 中，
每个 p∈{2,3,5} 的最大完整幂至少可在{0,2,5}之一取得（允许并列），则
Common6(n,j)。该定义精确对应200个模1800类。推论采用旧H6-02的108类
作者级定理和C16–C18的六类作者级结果；它们未在本轮重新运行完整旧证明。

两个结论都保持同一个原始(n,j)。整行意为∀j∃p，不要求一行统一一个p。

## 1. 原完整源与原生 QIG

反设同一个输入为NC6。定义

    s6(m)=2^v2(m)3^v3(m)5^v5(m), q_r=(n−r)/s6(n−r),
    V=q0q1q2q3, T4=∏_{r=0}^3 s6(n−r)。

对任何完整 p^e||q_r，p≥7，6!不取消p，故p|C(n,6)。阶乘倍数计数给

    vp C(n,j)=Σ_{h≥1}[j mod p^h > n mod p^h]。

全部项非负。NC6在原完整层必须有

    j≡b, k≡r−b (mod p^e), 0≤b≤r。

这是必要条件而不是充分NC模型；不把目标高工作层变成更大的原源幂。
不同q_r素数支持互斥。

置 a_t=C(j,t)C(k,4−t)，t=0,...,4。因4>r，两个下降积至少有一个完整p^e，
而分母均不含p≥7，因此V|a_t。

定义整数四次不变量

    I=12a4a0−3a3a1+a2²,
    B=72a4a2a0+9a3a2a1−27a4a1²−27a3²a0−2a2³。

令 J=jk，R=J−n+1=(j−1)(k−1)，D0=(n−1)(n−2)。本轮标准库从a_t的
有理多项式精确展开并重验：

    8I=JR(n−3)(n−2),
    −16B=J²R(n−3)²(n−2),
    256(B²−2I³)=J³R²(n−3)³(n−2)²(D0−J)。

I/V²和B/V³均整数。n≥14且j,k≥7使所有最后一式的因子严格为正，所以

    G=(B/V³)²−2(I/V²)³∈Z_{>0}, G≥1。

J≤n²/4，R随J递增，且J³(D0−J)的导数J²(3D0−4J)>0；将J放大到n²/4，
使用 V=n(n−1)(n−2)(n−3)/T4，准确约分得到

    G ≤ T4^6(3n²−12n+8)/[2^20(n−1)^6(n−3)^3]。

故必要条件为

    T4^6(3n²−12n+8) ≥ 2^20(n−1)^6(n−3)^3。       (QIG)

严格反向是同一原输入的整行充分消费者；不是将有限扫描反向当作NC。

## 2. 聚集小部全参数分解

记 c2=8,c3=9,c5=25。每个c_p>3，因此在前四窗中至多整除一个位置。
称p为活动底数，当存在r_p∈{0,1,2,3}使c_p|(n−r_p)。令其实际完整幂为
P_p=p^v_p(n−r_p)。定义M=∏活动p P_p；若无活动底数则M=1。

若r_p存在，对于h≠r_p有

    v_p(n−h)=v_p(r_p−h)，

因为v_p(n−r_p)≥log_p(c_p)>v_p(r_p−h)。若p不活动，则前四窗中每项的
p估值均小于log_p(c_p)，由n modc_p精确确定。这证明存在只依赖
n mod1800的正整数C，使

    T4=C M。                                         (COST)

这是完整指数的距离证明，而不是有限模表外推。

|底数|活动时移除P_p后的贡献|不活动时的贡献|
|---|---|---|
|2|2|8|
|3|端点r=0/3时3，内部r=1/2时1|3或9|
|5|1|1或5|

因此无活动底数时C≤360；至少一个活动底数时C≤120。

在|A(n)|≤1条件下，所有活动底数同在一个原位置r*，所以

    M | n−r*, 从而 M≤n。

没有把不同原输入的因子相乘；所有P_p来自同一个n−r*。

## 3. 一般绝对界与每个模类的精确边界

n≥32时，Bernoulli给

    (n−1)^6(n−3)^3 ≥ n^9(1−15/n)>n^9/2，
    3n²−12n+8<3n²。

所以QIG必须满足

    2^19 n^7 <3T4^6。                               (QIG-SIZE)

### 3.1 至少一个活动底数

由T4=CM≤Cn得

    n < 3C^6/2^19 ≤ 3*120^6/2^19
      =17085937.5 <2^25。

### 3.2 无活动底数

此时T4=C≤360。故

    n^7 <3C^6/2^19 ≤3*360^6/2^19 <32^7。

与n≥32矛盾，所以该类所有候选均在n<32。

对任一合格模类a，设e=1（有活动底数）或7（无活动底数），精确边界定义为

    B_a=max(32, min{B≥1:2^19 B^e≥3C(a)^6})。

于是任何NC6都必须 n<B_a。n<32的原值没有被忽略；它们包含在这个最大值中。
全部候选是

    n≡a (mod1800), 14≤n<B_a。

同一必要域的不同n只枚举一次；这是先证明有限高度再完成有限末端。

## 4. 1380模类的完全分类

各p在前四窗不活动的余数个数分别为

    8−4=4，9−4=5，25−4=21。

无活动底数类数为4*5*21=420。
若活动位置固定为某r*，每个p或者在r*活动（1种），或者不活动（上述种数），
且不能全不活动，因此该r*给

    (1+4)(1+5)(1+21)−4*5*21=240

个模类。四个r*互斥，共960类。合计

    420+4*240=1380。

code/certify.py第一实现直接遍历模1800，第二实现遍历模8/9/25的笛卡尔积，
以独立扩展欧几里得CRT恢复同一分类。C分别由距离估值和截断乘积除活动阈值
两种方法计算；不是预填一个1380常数便算完成。

## 7. 完整 H^{(6)}_{025} 的采用式推论

H^{(6)}_{025} 的定义：每个p∈{2,3,5}在完整六窗口的最大完整幂可在
{0,2,5}取得，允许并列。对于阈值c_p>5：

- 若某项被c_p整除，其位置唯一，且严格高于其他位置；
- 若无项被c_p整除，所有估值均由模c_p精确确定。

故其准确周期识别为

    n mod8∈{0,2,5,6}，
    n mod9∈{0,2,5,6,8}，
    n mod25∈{0,2,5,7,10,12,15,17,20,22}。

共4*5*10=200类。

采用冻结H6-02（108类）和C16–C18六个精确高幂排列后，尚余86类。
若一个H025输入不在H02中，至少一个阈值高幂唯一落在第5行。若同时
|A(n)|≥2，则另外两种底数必须分别在第0、第2行：这是三种底数在0/2/5上的
六种双射排列，恰为{50,477,752,1280,1325,1530}。否则|A(n)|≤1，已由新定理关闭。

因此200类全部闭合。相对明确的108+6基线，H025中新86类的有限末端共89,862行，
QIG只留下32、45、125、245、405；它们已包含在第6节的原题证书中。

本轮没有重新执行旧108类或C16–C18全部末端。完整200类推论的依赖等级必须
与本轮自含1380类定理区分。
