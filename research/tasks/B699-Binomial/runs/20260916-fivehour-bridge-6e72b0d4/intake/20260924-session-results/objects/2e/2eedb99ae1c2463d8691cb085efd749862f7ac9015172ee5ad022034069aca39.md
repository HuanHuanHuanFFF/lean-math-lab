# PROOFS — 固定 G 的源线强制因子与 H73

## A. 冻结对象与采用范围

采用上一轮 H63 的原题覆盖、COVER8、EDGE8、347个必要E0状态及472条原始安全因子签名；不重新证明这些前置。
原题入口为400|n、10<=j<=floor(n/2)、k=n-j、J=jk，NC9为不存在同一素数p>=11同时整除C(n,9),C(n,j)。i=9合数，p>=11与原题素数p>=9等价。

原G属于Z[N,X]，权 wt(N)=1,wt(X)=2，D(G)<=305，deg_XG<=152。
同一个G中剥去六条N-r的全部幂v_r，得到Gbar，h=deg_XG，V=sum v_r，E=305-2h-V。
八分量时采用EDGE8给E=0。加权次数乘法可加且任何X次e多项式权次>=2e，故D(G)=305，D(Gbar)=2h，其每个不可约因子都平衡。
Gbar的X^h系数是非零常数，可首一化，所有N=r特化保持h次。

## B. 源线限制与真因子

令 ell_t=X-tN+t^2，t=0,...,8。设非零H首一，X次e，D(H)<=2e。

B1. H(N,tN-t^2)的一元次数至多2e。
逐个单项式N^aX^b代入后的次数至多a+b<=a+2b<=2e即可。

B2. 若非对角源(r,s(r-s))满足t=s或t=r-s，普通消失阶下界M在限制上给至少(N-r)^M。
因为局部代换X-s(r-s)=t(N-r)，每个局部单项式的限制阶至少其普通总阶。

B3. 若r=2t是中心源，则ell_t的局部方程正是t_local=0。权阶至少B意味着限制中只有u^i项且i>=B，所以限制阶至少B。
不需要kappa=0；这里用的是原有真实加权阶下界B，而不是把2m强加给任意kappa。

所以定义

    L_t = sum_(off-source P on ell_t) M_P + (B_(2t) if 2t in {4,6,8} else 0).

各项来自互不相同的N=r。若L_t>2e，非零一元多项式不可能有这么高的总零阶，故限制恒零。
把H视为Q[N][X]的多项式，对X首一的ell_t作除法，其余式就是该限制。因此ell_t|H。
整个论证不需要相交理论、亏格、绝对不可约性、系数高度界或有限域秩。

严格 > 不能改为 >=。例H=X-(N-4)(N-5)，e=1。沿ell0限制为-(N-4)(N-5)，两源行总阶恰2=2e，但ell0不整除H。

## C. 严格辅助次数下降

已知ell_t|H时，写H=ell_t Q。因两者均X首一，deg_XQ=e-1；加权次数可加给D(Q)<=2(e-1)。

非对角源：ell_t经过该源时普通阶恰1，否则0。
中心源：若r=2t，ell_t=t_local的加权阶恰2，否则局部常数为(t-r/2)^2非零，加权阶0。
局部普通阶、正权阶对非零多项式乘法均相加。因此可安全更新

    M_P <- max(M_P-1_(P on ell_t),0),
    B_r <- max(B_r-2*1_(r=2t),0),
    e <- e-1.

每一步X次数严格减少，最多初始h次便终止。程序停止只代表此组已知下界不再强迫指定源线；不证明残余多项式或原题点存在。
任一步若某行的下界根数sum M+ceil(B/2)>e，则特化仍首一e次而被更高次数乘积整除，矛盾。

对任何原合法点，恒等式

    ell_t(n,jk)=jk-t(j+k)+t^2=(j-t)(k-t)>0

对t0..8成立，因为j,k>=10。所以剥除这些因子保留同一个原始点的辅助零点，且不会删掉任何可载NC9不可约因子。
这是从原来的固定G求出的约数，不是为不同因子另选G，也不是改变原n,j。
H(n,J)=0 iff Q(n,J)=0不等于“辅助零点 iff NC9”；后者未被使用。

## F. 商多项式的同一源容量

对任意平衡因子A，e_A=deg_XA。各行真实普通总重数mu_r<=e_A，Delta_r=e_A-mu_r>=0。
中心kappa_r=2m_r-w_r>=0；在奇数行置0。
Q的所有因子连同重数都平衡，Delta和kappa均对乘积相加。

奇数行：sum 2Delta_r <= 2e_Q-2 sum_off M。
偶数行：

    sum(2Delta_r+kappa_r)
      =2e_Q-2 sum_off m_P-w_r
      <=2e_Q-2 sum_off M_P-B_r.

右侧就是表中c_r。丢弃未选因子或重复份数的非负费用，只会放松。
因ell3、ell4不可载，若原G有八个不同可载因子，这八个因子都还在Q里。
每个按冻结分类映射到一个安全签名(e,c3,...,c8)，实际次数和源费用至少为签名费用。
签名条件不要求因子等于某个费用代理；允许重复使用类型并不声称有对应不同曲线。

## G. 96 次的整数对偶证书

只要一个签名可单独装入C=(0,0,4,2,6,13)，便有c3=c4=0。全部472条冻结原始签名中满足c<=C的99条，逐项整数检查

    e + 14c5 + 8c6 + 8c7 + 8c8 >= 40.

这99条包含每一个可能出现在八因子配置里的签名；其余签名单独就不能放入C。
因此八个签名相加得

    sum e >= 320-14*4-8*(2+6+13)=96.

这里价格均非负，所以使用容量上界减去价格之和方向正确。
实际八因子的次数至少该下界，却不能超过Q的70次，矛盾。

为核对整数下界没有松弛误差，存在达到96的纯资源见证：

    2*S5 (e4 each),
    2*(2Delta8, e8),
    1*(Delta7+Delta8, e8),
    2*(Delta7, kappa8=1, e16),
    1*(saturated, kappa8=1, e32).

次数8+16+8+32+32=96，容量恰C。这只是签名见证，不是实际曲线分解。
递归Bellman和exact-used-capacity前推算法在所有子容量和因子数上吻合；证明排除其实只需要99条价格不等式。
