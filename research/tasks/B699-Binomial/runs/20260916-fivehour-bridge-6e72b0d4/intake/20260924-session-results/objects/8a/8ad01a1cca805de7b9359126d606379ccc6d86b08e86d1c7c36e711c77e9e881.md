# PROOFS — C13：端点 q2 / 中央 q5 最坏源壳闭合

## 0. 原始域与冻结前置

固定同一个原始合法 `(n,j)`：

```text
k=n-j, g=gcd(n,j), 7≤j≤floor(n/2),
n mod1800 ∈ {1280,1530}.
```

反设 NC6。冻结 H025 合同给同一输入上的 NC5、六个 `alpha=n/g`
模板和 `g≥7`；冻结 H02 合同给

```text
g^7<2^22 n.                                         (G7)
```

完整源窗口失败时，失败粗素数已经给同一个 `(n,j)` 的 Common6。
因此只需研究全部完整窗口成立的必要系统。

写

```text
q2=E2*M2,
q5=Q50*Q51*Q52.
```

本轮目标壳为

```text
M2=1, Q50=Q51=1.
```

即第2源全部端点、第5源全部中央。

## 1. 正二十次核

定义

```text
F20=x^2*y^2*(x-1)*(y-1)*G6*H8.
```

`G6,H8` 系数在 `outputs/kernel20.json`。逐整数Taylor展开给：

```text
origin: 4
r1: 10,10
r2: 4,2,4
r3: 5,5,5,5
r4: 4,4,4,4,4
r5: 2,1,1,1,1,2.
```

`G6(7+X,7+Y)` 与 `H8(7+X,7+Y)` 的全部非零系数严格为正，
所以 `F20>0` 于全部合法域。

目标壳在 r2 只使用端点阶4，在 r5 只使用中央阶1。因此

```text
q1^10*q2^4*q3^5*q4^4*q5 | F20(j,k)/g^4.             (1.1)
```

所有因子均为原完整源幂，不含人为工作层。

令 `N=x+y,J=xy≤N^2/4`。精确对称展开给

```text
|G6|≤(64819/64)N^6,
|H8|≤(4569685/32)N^8.
```

又 `x^2y^2(x-1)(y-1)<J^3≤N^6/64`，故

```text
F20<C20*n^20,
C20=296202412015/131072.                             (1.2)
```

A尾：

```text
q1^10 q3^5 q4^4 > n^19/512,
g^4q2^4q5 < (296202412015/256)n.                    (1.3A)
```

B尾：

```text
q1^10 q3^5 q4^4 > n^19/7776,
g^4q2^4q5 < (71977186119645/4096)n.                 (1.3B)
```

Bernoulli损失使用 `10+15+16=41`，而 n≥1280，故乘积严格大于1/2。

## 2. 统一高度 2^65 / 2^68

令 `X=n-5`。

### 2.1 A尾

```text
alpha=c*2^a, c∈{1,5},
n=2^a(cg),
n-2=3^b(2q2),
n-5=5^E(3q5).
```

BFT：

```text
max(cg,2q2)>X^(57/200),
max(cg,3q5)>X^(129/500).
```

若第一门由 `cg` 付款，G7给

```text
X^(399/200)/c^7 < 2^22 n,
```

对应 `c=1,5` 的 dyadic 界 `2^25,2^41`。

若第一门由 `2q2` 付款：

- 第二门由 `cg` 付款：
  ```text
  g^4q2^4q5 > X^(543/250)/(16c^4);
  ```
  K20给 `2^31,2^39`。
- 第二门由 `3q5` 付款：
  ```text
  g^4q2^4q5 > (2401/48)X^(699/500);
  ```
  K20给 `2^65`。

故 A 壳 `n<2^65`。

### 2.2 B尾

```text
alpha=c*3^a, c∈{1,2,5,10},
n=3^a(cg), n-2=2^bq2, n-5=5^Eq5.
```

BFT：

```text
max(cg,q2)>X^(57/200),
max(cg,q5)>X^(27/125).
```

第一门由 `cg` 付款时，G7最弱界为 `2^48`。

第一门由 `q2` 付款：

- 第二门由 `cg` 付款：
  ```text
  g^4q2^4q5 > X^(501/250)/c^4,
  ```
  最弱界 `2^50`；
- 第二门由 `q5` 付款：
  ```text
  g^4q2^4q5 >2401 X^(339/250),
  ```
  给 `2^68`。

故 B 壳 `n<2^68`。

所有 dyadic 指数均由完整整数幂比较重新验收，不依赖浮点取整。

## 3. 互补恒等式与候选行完备性

第一源 `q1=n-1` 的完整窗口给

```text
U=j(n-j)/(n-1)∈Z_{>0}.
```

第2源全端点给 `q2|U`，写 `U=q2R`。
第5源全中央时，每个完整 `p^e||q5` 上

```text
n≡5, j,k≡2,3, n-1≡4,
```

故 `2U≡3 (mod p^e)`，于是

```text
2U-3=q5h, h>0.
```

置

```text
s2=(n-2)/q2,
s5=(n-5)/q5.
```

将 `n-5=n-2-3` 代入：

```text
q2(2Rs5-hs2)=3(s5-h).
```

`gcd(q2,3)=1`，所以 `s5-h=ell*q2`。代回并约去 `s5`：

```text
s2-2R=ell*q5.                                       (3.1)
```

合法域有

```text
U≤n^2/[4(n-1)]<(n-2)/2,
```

所以 `ell>0`。两尾均有 `s2` 偶、`q5` 奇，故 `ell` 偶：

```text
ell≥2,
q2<s5/2,
q5<s2/2.                                            (3.2)
```

A尾：

```text
s2=2*3^b, s5=3*5^E,
2*3^(b-1)q2-5^Eq5=1.
```

因系数互素，`q2` 模 `5^E` 唯一；结合 `q2<3*5^E/2`，
只可能是最小正代表或再加一次 `5^E`，至多两项。

B尾：

```text
s2=2^b, s5=5^E,
2^bq2-5^Eq5=3,
q2<5^E/2.
```

故 `q2` 是唯一模 `5^E` 代表，若超过半模则无候选。

按 §§2 的高度枚举全部 `(b,E)`，再验证完整小部、粗部与尾同余，
准确得到 A 96 行、B 24 行。代码从公式重建列表，不信任预填行表。

## 4. 完整有限末端

对每个候选行定义

```text
q_r=(n-r)/s6(n-r), r=0,...,5.
```

因所有粗素数至少7，不同 `q_r` 两两互素。对完整 `p^e||q_r`，
NC6 的源层无进位必要条件为

```text
j mod p^e ∈ {0,...,r}.
```

目标壳将 r2 限为 `{0,2}`，r5 限为 `{2,3}`。

证据包保存696个不同粗整数的完整分解，共1029个不同质数。
最大质数小于 `2^64`，标准库重放用确定性的64位 Miller–Rabin基组
重新核实所有质数与乘积。

两套独立枚举：

1. prime-power DFS：逐完整素数幂做CRT，按合法区间动态剪枝；
2. row-block CRT：先在每个 `q_r` 内构造全部允许剩余类，再按六行CRT。

两者都完整覆盖 `7≤j≤n/2`，都返回零终端：

```text
A 96行: 0
B 24行: 0.
```

因此目标壳中不存在 NC6。

## 5. 关闭后的尾盒更新

C12 一般 K16 整除包含乘子 `M2Q50Q51`。目标壳关闭后，
任何剩余 NC6 必有

```text
M2Q50Q51≥7.
```

把它放回 C12 高度账本，得到：

```text
A:
 alpha=2^a    -> n<2^198,
 alpha=5*2^a  -> n<2^266;

B:
 alpha=3^a     -> n<2^296,
 alpha=2*3^a   -> n<2^353,
 alpha=5*3^a   -> n<2^427,
 alpha=10*3^a  -> n<2^484.
```

这些是剩余分支的有效有限盒；本轮没有排空它们。
