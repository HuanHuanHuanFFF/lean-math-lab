### A. 完整排空 `rho=28,...,55`

对每个固定 Pell 行，先利用 POWER 多项式对乘子 `m` 的奇 Hensel 根唯一性，把

```math
0<m<27*2^(rho-1)
```

压成至多一个短候选；随后检查该候选下的 `R mod 2^80`。

本轮完整覆盖

```math
\sum_{rho=28}^{55}2^{55-rho}=2^{28}-1=268435455
```

个形式 Pell 行。没有一行达到 `2^80|R`，全 campaign 的最大实际赋值只有

```math

```

而真实输入必须满足

```math
v2(R)>=45q.
```

因此

```math
\boxed{28\le rho\le55\text{ 全部退出}.}
```

结合 Round 16 已删除的 `rho>=56`：

```math
\boxed{12\le rho\le27.}
```

并得到更小的乘子绝对界

```math
\boxed{m<27*2^26=1811939328<2^31.}
```

### B. 新的 `INDEX-RANK-GAP`

置

```math
N=4q+1,
\qquad U_N=2u.
```

确定性证书先完整排除

```math
m=1,3,9.
```

故任一幸存输入的 `m` 含有某个非 `3` 素因子 `p|u`。由 `p|U_N` 的 Pell 阶，若 `r=ord_p(2+sqrt3)/4`，则

```math
r|N,
\qquad 4r|p-(3/p).
```

因此，若 `P^-(N)` 表示 `N` 的最小素因子，

```math
\boxed{P^-(4q+1)\le27*2^(rho-3).}
```

所以所有违反该界的粗糙指数行一次性退出。

特别地，本轮再用 129 个小 `w` 行的精确 POWER 证书排除最后入口，得到

```math
\boxed{4q+1\text{ 为素数的纯二桥子域为空}.}
```
