# HANDOFF — B / i3：NONIC-REDUCE6

## 新冻结前沿

GATE9：

```text
f∈Z[X] 非负，f(0)=2，deg f=9；
T=p^e odd prime power；
T≥[2(f(1)+2)]^22；
n=f(T) even。
```

同一 NC3 输入的第一源只能为 `4+5`。本轮已关闭：

- `t=0,1` 全边界；
- 三个单槽三次商；
- 三线三槽 `(1,1,1)`。

现在只剩六个定向 `2+1`：

```text
(d0,d1,d2)  t
(2,1,0)     7/9
(1,2,0)     2/3
(2,0,1)     2/3
(0,2,1)     4/9
(1,0,2)     4/9
(0,1,2)     1/3
```

不要把这六项写成有限整数候选，也不要把本轮写成 NONIC-ALL。

## 可复用接口

1. 槽商闭式：
   ```text
   S=R0 R1' R2+2R0 R1 R2'。
   ```
2. 九次槽权：
   ```text
   d1+2d2=8−9t。
   ```
3. 单槽规范的唯一正形式族有完整 3 源缺额 5 层；该结论依赖原整数尺度与完整源，不能作为任意三次商的纯形式判据。


```text

```
