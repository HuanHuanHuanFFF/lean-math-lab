## 1. 主结果：第5源无中央块的整个域关闭

固定两个旧 H025 尾类之一：

```text
A: n≡1280 (mod1800),
B: n≡1530 (mod1800),
7≤j≤floor(n/2).
```

写完整第5源分配

```text
q5=Q50*Q51*Q52,
```

分别对应端点 `{0,5}`、近侧 `{1,4}`、中央 `{2,3}`。

本轮证明：

```text
Q52=1  ==> Common6(n,j).
```

结论不限制第2源如何分配；`q2=E2*M2` 可以全端点、全中心或真正混合。
也不要求 `Q50,Q51` 都非单位。因此它同时包含：

- q5 全端点；
- q5 全近侧；
- q5 在端点/近侧之间任意完整混合；
- 上述三类与任意 q2 分配的组合。

C14 已关闭其中 pure/pure 部分；本轮真正新增的是全部 mixed-q2 子支以及
q5 端点/近侧混合支，并将它们统一成一个原输入消费者。

## 3. SAT 将 q5 压到极小剩余类

冻结源饱和消费者定义

```text
D25=[j*k*(j-1)*(k-1)]_(q2*q5),
q2*M2*Q50*Q51 | D25.
```

在 `Q52=1` 时：

```text
D25≥q2*q5.
```

任何 NC6 幸存者必须满足：

```text
A: Delta3>15*g^3*D25;
B: Delta3>3*g^3*D25.
```

而 `Delta3≤E3≤q3`。写 `n-2=s2*q2`，得到

```text
A: 15*g^3*q5 < s2;
B:  9*g^3*q5 < s2.
```

采用 `g≥7`：

```text
A: 5145*q5 < s2;
B: 3087*q5 < s2.                                    (SAT-SQUEEZE)
```

## 4. 完整指数证书直接排空

### A尾

准确小部：

```text
n-2=2*3^b*q2, b≥2;
n-5=3*5^E*q5, E≥2.
```

令 `A0=2*3^(b-1)`，相邻式为

```text
A0*q2-5^E*q5=1.
```

SAT-SQUEEZE 给

```text
q5<A0/1715<A0,
```

所以 q5 必等于唯一的最小正剩余

```text
q5 ≡ -5^(-E) (mod A0).
```

高度 `n<2^43` 完整限制为

```text
2≤b≤26, 2≤E≤17,
```

共400对。全部不满足 `5145*q5<3*A0`。
最接近者 `(b,E,q5)=(15,4,30611)`，仍有

```text
5145*q5 / (3*A0)=52497865/9565938 >1.
```

### B尾

```text
n-2=2^b*q2, 3≤b≤47;
n-5=5^E*q5, 2≤E≤20;
2^b*q2-5^E*q5=3.
```

SAT-SQUEEZE 使 q5 成为唯一最小正剩余

```text
q5 ≡ -3*5^(-E) (mod 2^b),
q5<2^b/3087.
```

855个完整指数对全部失败。最接近者 `(b,E,q5)=(7,3,1)`，已有

```text
3087*q5/2^b=3087/128>1.
```

该扫描甚至放宽了真实 `q5≥7` 与尾同余过滤；所以零结果严格覆盖原域。
