# PROOFS — C10：通用低残量平方自由输运与中央块支配

## 0. 原始量词与定义

固定同一个合法原输入

```text
n≡5130 (mod9000), 7≤j≤floor(n/2), k=n-j,
g=gcd(n,j), alpha=n/g=3^a,
(n-1)jk=10Y^2.
```

反设该输入为 NC6。任一完整源窗口若失败，失败粗素数已经给同一原
`(n,j)` 的 Common6；故以下只在完整源分配成立时推导必要条件。

按 `i=6` 删除完整2、3、5部：

```text
q2=(n-2)/2^b, q3=(n-3)/3, q4=(n-4)/2, q5=(n-5)/5^E.
```

粗块两两互素，其素因子均至少7，且与 `g` 互素。第一源给

```text
N=n-1 | jk,
U=jk/N=10g^2z^2,
t=U/g^2=10z^2.
```

定义完整槽块

```text
q2=E2*M2,
q3=E3*I3,
q4=E4*A4*C,
q5=Q50*Q51*Q52.
```

第5源的三块依次对应端点 `{0,5}`、近侧 `{1,4}`、中央 `{2,3}`，
并两两互素。置

```text
d=sf(E3E4), tau50=sf(Q50),
epsilonE=sf(E2), epsilonM=sf(M2),
sigma2=sf(q2)=epsilonE*epsilonM.
```

以及通用残量

```text
zeta=t/gcd(t,E3E4Q50),
nu=(U-1)/gcd(U-1,I3A4Q51),
Mass=g^4Q50^2Q51^4zeta^2nu^3.
```

这里 `sf` 只保留奇指数素因子，不是 radical。

## 1. 两个统一平方自由下界

### 1.1 `sigma2≥7`

若 `q2=s^2`，则 `n-2=2^b s^2`。模3有 `n-2≡1`，而 `s` 是3单位，
故 `b` 为偶数，于是 `n-2` 是整数平方。但 `n-2≡3 (mod5)`，而3不是
模5平方，矛盾。所以 `q2` 不是平方，且其全部素因子至少7：

```text
sigma2=sf(q2)≥7.                                    (1.1)
```

### 1.2 `d≥7`

当前

```text
q3=(n-3)/3≡29 (mod40),
```

故 `chi10(q3)=(10/q3)=-1`。若 `p|I3`，第3源内部槽给 `U≡1 (modp)`。
由 `U=10g^2z^2` 且 `p∤gz`，有 `(10/p)=+1`。因此

```text
chi10(E3)=-1.
```

所以 `E3` 不是平方，`sf(E3)≥7`，从而

```text
d=sf(E3E4)≥7.                                      (1.2)
```

此外 `alpha=3^a`，而当前 `v2(n)=v5(n)=1`，故

```text
10|g, in particular g≥10.                          (1.3)
```

## 2. 完整第2源和第5端点的偶估值输运

取 `p^e||E2`。端点槽使 `p^e|U`；因 `p∤g`，有 `p^e|t=10z^2`。
`t` 在 `p` 处的估值为偶数，所以至少为 `e+(e mod2)`：

```text
E2*epsilonE | t.                                   (2.1)
```

同理，对 `Q50`：

```text
Q50*tau50 | t.                                     (2.2)
```

又 `E3E4|t`，且其奇指数内容是 `d`，故

```text
E3E4*d | t.                                        (2.3)
```

`E2,Q50,E3E4` 两两互素，且都与10互素。将 (2.1)–(2.3) 相乘，
再除去 `gcd(t,E3E4Q50)=E3E4Q50`，得到完整整除

```text
10*d*tau50*E2*epsilonE | zeta.                     (2.4)
```

第2源中央槽给

```text
M2^2 | (j-1)(k-1)=N(U-1).
```

而 `M2` 与 `N I3 A4 Q51` 互素，故在定义 `nu` 后仍有

```text
M2^2 | nu.                                         (2.5)
```

由 (2.4)–(2.5)：

```text
zeta^2 nu^3
 ≥100d^2tau50^2(E2 epsilonE)^2 M2^6
 ≥100d^2tau50^2 q2^2 sigma2^2.                     (2.6)
```

最后一步的整数比值为 `M2^4/epsilonM^2≥1`。

## 3. 通用低残量压缩 GLR-SF

当前 `g` 为偶数，所以 `j=g*(j/g)` 为偶数。冻结残量消费者说明，
B尾偶数 `j` 若

```text
1152 Mass ≥125n
```

则已经 Common6。因此 NC6 必须严格满足

```text
1152 Mass <125n.
```

代入 (2.6)，约去25，得到

```text
4608 g^4 d^2 tau50^2 q2^2 sigma2^2 Q50^2 Q51^4 <5n. (GLR-SF)
```

这条式子不假设 `Q51=q5`，所以可进入全部第5源分配。

## 4. BFT 两个付款者被强制确定

令 `X=n-5`。采用 C9 已固定的 BFT Theorem 2.1 和40对例外表。

- 对 `2^bq2=n-2` 与 `3^ag=n`，差为2。例外表没有差2项，故
  ```text
  max(q2,g)>X^(57/200).                             (4.1)
  ```
- 对 `3^ag=n` 与 `5^Eq5=n-5`，差为5。差5例外的大分量仅为
  `1029,1215,30618`，都不满足 `n≡5130 (mod9000)`，故
  ```text
  max(g,q5)>X^(27/125).                             (4.2)
  ```

若 (4.1) 由 `g` 付款，则 `g^4>X^(57/50)>X`，而 GLR-SF 左侧
已大于 `4608X>5n`，矛盾。因此

```text
q2>X^(57/200).                                      (4.3)
```

若 (4.2) 由 `g` 付款，则

```text
g^4q2^2>X^(108/125+57/100)=X^(717/500)>X,
```

仍与 GLR-SF 矛盾。故

```text
q5>X^(27/125).                                      (4.4)
```

相乘：

```text
q2q5>X^(501/1000).                                  (4.5)
```

## 5. 自动基础门 `n>10^24`

从 GLR-SF 丢掉只会增大左侧之外的因子，并使用
`g≥10,d≥7,sigma2≥7`：

```text
4608*10^4*7^4*q2^2 <5n.                            (5.1)
```

由 (4.3)，若 `n≤10^24`，函数

```text
4608*10^4*7^4*(n-5)^(57/100)/(5n)
```

在当前区间递减，因此最弱点是 `n=10^24`。重放以纯整数验证

```text
(4608*10^4*7^4)^100*(10^24-5)^57
  >(5*10^24)^100.
```

这与 (5.1) 矛盾。所以

```text
n>10^24.                                            (5.2)
```

## 6. CENTRAL32

记

```text
D=g^2*d*tau50*sigma2*Q51,
B0=g^4d^2tau50^2q2^2sigma2^2Q50^2Q51^4.
```

由 `q5=Q50Q51Q52` 有精确恒等式

```text
(q2q5)^2=B0*(Q52/D)^2.                              (6.1)
```

反设 `Q52≤32D`。GLR-SF 与 (6.1) 给

```text
(q2q5)^2 < (5*32^2/4608)n.                         (6.2)
```

另一方面 (4.5) 给

```text
(q2q5)^2>X^(501/500).                               (6.3)
```

函数 `X^(501/500)/n` 的导数符号由

```text
501n-500(n-5)=n+2500>0
```

确定，所以它随 `n` 递增。在 (5.2) 的入口，重放以纯整数验证

```text
(10^24-5)^501*4608^500
  >(5*32^2*10^24)^500.                              (6.4)
```

(6.2)–(6.4) 矛盾。因此

```text
Q52>32g^2d tau50 sigma2 Q51.                        (CENTRAL32)
```

同一入口对33的对应整数比较失败；故本方法认证的最大整数常数是32。

## 7. 指数锥和粗数值门

由 (4.3) 与 GLR-SF：

```text
g<X^(43/400),                                       (7.1)
Q50Q51^2<X^(43/200).                                (7.2)
```

否则相应平方乘积与 `q2^2` 已至少贡献 `X`，触发残量消费者。

由 (4.4)、(7.2) 及 `Q51≥1`：

```text
Q52=q5/(Q50Q51)
    ≥q5/(Q50Q51^2)
    >X^(27/125-43/200)
    =X^(1/1000).                                    (7.3)
```

又

```text
alpha=n/g>X^(1-43/400)=X^(357/400).                 (7.4)
```

CENTRAL32 与统一最小值给

```text
Q52>32*10^2*7*7=156800.                             (7.5)
```

若 `Q50` 非平方，则 `tau50≥7`，从而

```text
Q52>1097600*Q51.                                    (7.6)
```

## 8. 返回原题

任取 B/RES10 原输入：

- 任一完整源失败时，失败粗素数直接见证 Common6；
- 若残量消费者触发，已有 Common6；
- 否则 GLR-SF 成立，§§4–7 给 CENTRAL32。

所以 CENTRAL32 的逆否是同一原 `(n,j)` 的充分消费者：

```text
Q52≤32g^2d tau50 sigma2 Q51  => Common6.
```

尤其 `Q52=1` 的全部端点/近侧分配关闭。没有换输入、没有放大源幂，
也没有从必要窗口反向定义 NC6。
