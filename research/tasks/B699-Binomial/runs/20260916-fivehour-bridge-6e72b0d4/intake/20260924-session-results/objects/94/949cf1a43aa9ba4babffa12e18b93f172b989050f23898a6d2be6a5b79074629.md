# Evidence levels

- **Author paper proof**: mathematical argument written in the round materials; not formally checked by Lean.
- **Deterministic exact certificate**: exact rational/integer polynomial identity, ideal-membership DAG, resultant identity, finite-field no-root certificate, or similar finite proof object with a checker.
- **Replay / same-author second implementation**: a separate arithmetic implementation written in the same research conversation; useful cross-check, **not external independent review**.
- **External theorem dependency**: an explicitly cited theorem used as an input; notably the Ulmer–Urzúa tangency/intersection estimate in CENTER-11/13. The theorem itself was not formalized here.
- **Archive verification**: CRC/SHA/byte-identity checks; says nothing by itself about mathematical truth.
- **Lean**: **none of the research rounds in this archive are claimed as Lean proofs. Lean was not run in the archive-only passes.**
- **Complete B699 / complete i=3**: **not achieved**.
