# REPLAY

环境：Python 3.10+；SymPy 1.14.0仅用于多项式恒等式展开。有限域生成、不同算法核验、周期与覆盖、失败对象、素性、坏证书测试均只用标准库。不需要网络、仓库或任何密钥。

完整重放：

```bash
sha256sum -c SHA256SUMS
bash replay.sh
```

replay.sh 在临时目录从零生成证书，要求与交付证书逐字节一致；然后执行符号核验及另一算法的完整局部检查，再要求两份输出逐字节一致。不改写交付目录或源附件。

仅标准库数学证书检查：

```bash
python3 -B code/verify.py \
  --certificate certificates/nonnegative_J_cover.json \
  --output /tmp/round21-verify.json
```

证明链分工：
- PROOFS P1–P4 给从无界原状态进入有限J/周期表的纸面归约；
- certificates/nonnegative_J_cover.json 存储24个素数、精确首返周期及全部需要的排除类；
- 生成器解二次h，检查器线性解h并验证DIVNORM；保留所有零模因子；
- 全部周期整除1260。有限格点数不等于原(n,j)数量；
- 不重放旧campaign，也不将PASS称为Lean或外部独立审读。
