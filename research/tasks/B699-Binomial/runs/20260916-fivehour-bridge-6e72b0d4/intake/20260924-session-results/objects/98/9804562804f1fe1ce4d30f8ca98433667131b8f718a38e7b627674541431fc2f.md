# 探索记录的作用和缺项

这些文件是本轮受控探索的原始快照，不是额外验收结论。

- probe_zero20 / cpp_alt / order_probe：零槽参数化与单项式序诊断。
- zero20_weighted_python：原公式特征零重生成的探索版本日志；最终验收输出以 ../outputs 为准。
- all4_d20_eqs.txt / mixed_d20_eqs.txt：一般四槽与分裂槽的完整方程快照，供下轮起点。
- mod_all4 / mod_mixed：模1000003探针，只作启发；它们不证明特征零不存在性。
- all4*_attempt / mixed*_attempt / *_long：未完成有理消元的部分日志，没有可接受证书。

本包不声称包含每个临时文件或进程的完整退出状态；没有保存的退出码不补造。
探索性C++源码不是最终重放依赖，未在此包提供完整探索环境。
接受链仅为 src/check_standard.py、certificates/zero20.json 与 PROOFS.md 的准确范围。
