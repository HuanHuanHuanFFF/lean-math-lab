# PROOFS — C14：六种纯位置源壳统一闭合

## 0. 原量词与定义

固定同一个原始合法 `(n,j)`，置 `k=n-j,g=gcd(n,j)`，并在两个旧尾类之一：

```text
n≡1280 or1530 (mod1800), 7≤j≤floor(n/2).
```

反设 NC6。冻结 unit-coarse 合同给所有 `q_r≥7` 和 `g≥7`；源窗口失败时，
失败粗素数已给同一个原 `(n,j)` 的 Common6。

写

```text
q2=E2*M2,
q5=Q50*Q51*Q52.
```

`E2/M2` 对应第2源端点/中心；`Q50/Q51/Q52` 对应第5源端点/近侧/中央。

本文件处理六种“恰一个 q2-block、恰一个 q5-block 非单位”的纯壳。

## 1. 高度核

K16 与 K20 的精确整数 Taylor 阶及合法域正性由包内标准库重放。

若核在第2、第5目标槽阶为 `(a,b)`，除去 q1/q3/q4 后都有

```text
g^4 q2^a q5^b < C_tail*n.                            (1.1)
```

A尾 BFT 门：

```text
max(cg,2q2)>X^(57/200),
max(cg,3q5)>X^(129/500).
```

B尾：

```text
max(cg,q2)>X^(57/200),
max(cg,q5)>X^(27/125).
```

若第一门由 `cg` 付款，统一使用 `g^7<2^22n`；否则再按第二门付款者将
(1.1) 收费。纯整数幂比较给报告中的高度表。

差2无BFT例外；差5三个例外大分量 `1029,1215,30618` 均不在两个尾类。

## 2. EC：端点 q2 / 中央 q5

这是 C13 壳。写

```text
U=q2R,
2U-3=q5h.
```

联立 `s2q2-s5q5=3` 得

```text
s2-2R=ell q5,
s5-h=ell q2.
```

`U<n/3` 及奇偶给 `ell≥2`，故

```text
2q2<s5, 2q5<s2.                                     (EC)
```

K20 给 A/B 高度 `2^65/2^68`。

## 3. EN：端点 q2 / 近侧 q5

此时

```text
U=q2R,
U-1=q5h.
```

由两式常数差和相邻式：

```text
q2(s2-3R)=q5(s5-3h).
```

`U<n/3` 给 `s2-3R≥0`。若为0，则 `U=(n-2)/3`，而原 j 判别式

```text
n^2-4(n-1)U=(-n^2+12n-8)/3
```

在 n≥1280 时为负，矛盾。因此存在 `ell≥1`：

```text
s2-3R=ell q5,
s5-3h=ell q2,
```

故

```text
q2<s5, q5<s2.                                       (EN)
```

K16 给 A/B 高度 `2^43/2^53`。

## 4. EE：端点 q2 / 端点 q5

`q2q5|U`，而合法域恒有 `U<n/3`。于是

```text
3q2q5<n=s2q2+2=s5q5+5.
```

因 `q2,q5≥7`：

```text
3q5≤s2,
3q2≤s5.                                             (EE)
```

K20 给 A/B 高度 `2^43/2^50`。

## 5. CC：中心 q2 / 中央 q5

中心第2源给完整平方：

```text
U-1=q2^2R.
```

中央第5源给

```text
2U-3=q5h.
```

三倍第二式与相邻式联立：

```text
q2(s2-6q2R)=q5(s5-3h).                              (5.1)
```

判别式上界给

```text
U-1≤(n-2)^2/[4(n-1)]<(n-2)/4,
4q2R<s2.                                             (5.2)
```

另

```text
h < (s5+1)/2,
```

且 s5 奇，所以 `h≤(s5-1)/2`。因此 (5.1) 两侧系数的绝对值分别小于
`s2,s5`。

零分支：`s2=6q2R` 会迫使 `q2|s2`；`s5=3h` 在B尾因3不整除s5不可能，
在A尾则给 `U=(n+4)/6` 和 `q2^2|(n-2)/6=3^(b-1)q2`，同样矛盾。

故

```text
q2<s5, q5<s2.                                       (CC)
```

K16 给 A/B 高度 `2^41/2^48`。

## 6. CN：中心 q2 / 近侧 q5

这里

```text
q2^2 q5 | U-1.
```

由 `U-1<(n-2)/4`：

```text
4q2q5<s2.
```

又 `U-1<n/4=(s5q5+5)/4`，所以

```text
q5(4q2^2-s5)<5.
```

用 `q5≥7` 得

```text
4q2^2≤s5.                                           (CN)
```

K16 给 `2^41/2^48`；代入尾相邻式后候选集合已经为空，无需CRT。

## 7. CE：中心 q2 / 端点 q5

写

```text
U=q5h,
U-1=q2^2R.
```

由常数差与相邻式：

```text
q5(3h+s5)=q2(s2+3q2R).
```

故存在 `ell≥1`：

```text
3h+s5=ell q2,
s2+3q2R=ell q5.                                    (7.1)
```

由 `U<n/3`，有 `3h≤s5`；由 (5.2)，有 `4q2R<s2`。代入 (7.1)：

```text
q2≤2s5,
4q5<7s2.                                            (CE)
```

K16 给 `2^41/2^48`。

## 8. 原行恢复

两尾总有

```text
A: 2*3^(b-1)q2-5^Eq5=1,
B: 2^bq2-5^Eq5=3.
```

对固定 `(b,E)`，`q2` 在模 `5^E` 下唯一；§§2–7 的大小门只允许有限个
相邻代表。结合各壳高度、准确尾同余、完整小部和 `gcd(q2q5,30)=1`，恢复报告中的
473个壳—行义务。

## 9. 完整CRT末端

对每个候选和每个完整 `p^e||q_r`，原源层无进位要求

```text
j mod p^e ∈ {0,...,r}.
```

再把 r2/r5 限到该壳的具体槽组。所有 q_r 两两互素。

包内保存完整分解并由确定性64位 Miller–Rabin重验。两算法分别按 prime power
和整行 block 做完备CRT，均对每个壳返回零合法 j。故六壳全部 Common6。

## 10. 回到前沿

如果 q2 纯且 q5 纯，就属于六壳之一并已关闭。因此任何幸存 NC6 至少满足：

```text
E2>1 and M2>1,
或者 Q50,Q51,Q52 至少两个>1.
```

没有换原输入、没有指标交换，也没有把必要窗口反向当作NC充分刻画。
