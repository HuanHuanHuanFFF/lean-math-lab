# REPLAY

环境：Python 3；`sympy==1.14.0`。不需要网络、仓库或随机数。

```bash
python3 -B src/close_022.py
python3 -B src/close_202.py
python3 -B src/independent_check.py
```

- `close_022.py`：重建 `(0,2,2)` 的退化中心不同图、同中心 generic/退化图、数字原点分类与整数块恢复。
- `close_202.py`：重建 `(2,0,2)` 的中心不同 generic/分母退化图及同中心图。
- `independent_check.py`：只用标准库核对判别式、模 11 值表、模 Bézout 及整数恢复的有限算术部分。

完整包重放：

```bash
bash replay.sh
sha256sum -c SHA256SUMS
```

所有 PASS 只验证明确的有限代数证书；无限量词由 `PROOFS.md` 承担。
