# PROOFS — OCTIC-NO211 与 `022` generic 削减

## 0. 采用前置与量词

全文固定同一个原始自然数输入 `(n,j)`，`4≤j≤⌊n/2⌋`，`k=n−j`。`Common3` 表示存在同一个奇素数 `p≥3` 同除 `C(n,3),C(n,j)`；`NC3` 为其否定。

采用上一轮已经展开的 GATE8 必要系统：

```text
f−1=UV， U(0)=V(0)=1；
σ=VW， U | VW−1；
W(W−U)(W−2U)=(UV−1)R；
gcd(U,W)=gcd(U,R)=1；
U | WR'−R(3W'−2U')；
U² | W³+R−2UW²。
```

其中 `deg U=deg V=4`；`σ` 仍是原 `j` 或 `k`。上一轮在固定较小端点后已将未解槽型压到

```text
(0,2,2),(2,0,2),(1,1,2),(1,2,1)。
```

本文的 `U,V,W,R,Q,a,b,p,q,s` 都是数字多项式分类变量，不是实际内容三次 `Ψ`、恢复三次 `Pρ` 或两底路线的同名参数。

## 1. 二次商插值引理

令

```text
Z=W−tU， t=lc(W)/lc(U)。
```

直接展开：

```text
W³−2UW²
=Z³+(3t−2)UZ²
 +U²[(3t²−4t)Z+(t³−2t²)U]。
```

故 `U² | W³+R−2UW²` 等价于存在 `deg Q≤2` 使

```text
Z³+(3t−2)UZ²+R=U²Q。                 (TQ)
```

若完整因子 `R_i` 进入槽 `W−iU`，则模 `R_i`

```text
Z≡(i−t)U，
Q≡κ_i(t)U，
κ_i(t)=(i−t)²(i+2t−2)。              (INT)
```

把归一化槽积记作 `R_*`，实际 `R=ρR_*`。由 `(INT)` 构造二次 `Q` 后，

```text
H=Z³+(3t−2)UZ²−U²Q
```

被 `R_*` 整除。完整 `(TQ)` 恰等价于

```text
K=H/R_*
```

是常数 `−ρ`。因此只需排除 `K` 的非恒定系数。

## 2. 图 A：`(d0,d1,d2)=(1,1,2)`

两个线性因子互素且有理，经有理仿射坐标送到 `0,1`。令

```text
R_*=x(x−1)A， A=x²+ax+b；
b≠0， A(1)=a+b+1≠0； t=3/8。
```

由 `(INT)`：

```text
256Q≡−45U (mod x)，
256Q≡−25U (mod x−1)，
256Q≡507U (mod A)。                  (A-INT)
```

### 2.1 `E=18a+15b+20≠0`

DIFF 与三个槽条件的线性解只留 `s=w1`。完整系数由 `src/replay_no211.py` 直接重建并代回核验。四个 `(A-INT)` 标量条件的唯一兼容式为

```text
 +(10928a+30040b+6560)s
```


不是平方。

若 `C≠0`，由 `F=0` 消去 `s`。构造 `Q` 后，记 `K=H/[x(x−1)A]`。只需 `K_5=K_6=0`；它们关于 `a` 的结式为


`B2` 已无有理根。`H9` 首项不被 `19` 整除，且在 `F19` 的值表无零，故也无有理根。

### 2.2 `E=0`

置 `a=−(15b+20)/18`。除 `b=0` 外，generic 线性解只留 `c=w2`。插值兼容式为

```text
(3b−2)F_E=0，
F_E=114075b³−5562297b²
 +(5086800b−1356480)c
 +606420b+628000。
```

`3b−2=0` 等价于 `A(1)=0`，删除。

当 `b=4/15`，八个 DIFF 系数的显式线性组合直接为 `256/15`，所以线性系统不相容。

否则消去 `c`。`K_1,K_2` 化为两个整系数八次式；模 `7` 为报告中的 `P1,P2`，显式 Bézout 等式给 `1`。因两首项模 `7` 非零，若在 `Q[b]` 有非恒定公因子，其模 `7` 次数不会消失，矛盾。

故图 A 无有理解。

## 3. 图 B：`(d0,d1,d2)=(1,2,1)`

令

```text
R_*=xA(x−1)， A=x²+ax+b；
b≠0， A(1)≠0； t=1/2。
```

由 `(INT)`：

```text
4Q≡−U (mod x)，
Q≡0 (mod A)，
4Q≡9U (mod x−1)。                   (B-INT)
```

因 `deg Q≤2=deg A`，有 `Q=qA`。

### 3.1 `D=15a²+18ab+8a−8b≠0`

线性系统只留 `s=w1`。`(B-INT)` 兼容式为

```text
−9a²+3ab+(18a+4b)s−3a+6b²+14b=0。
```

若 `9a+2b=0`，只得非法 `(0,0)` 或落入 `D=0` 的 `(2/3,−3)`。故可消去 `s`。

此时 `K` 的 `x^6` 系数原始分子为

```text
−(9a+2b)(9a²−174ab−32b²)。
```

第一因子非零；以 `r=a/b∈Q` 得

```text
9r²−174r−32=0，
Disc=31428=18²·97，
```

无有理解。

### 3.2 `D=0`

除不存在的 `a=4/9` 外，参数化

```text
b=a(15a+8)/(8−18a)。
```

`b=0`、`A(1)=0` 的值按槽互素删除。generic DIFF 解只留 `c=w2`，兼容式为

```text
1143a³+(1188a²−1320a+352)c
−192a²+652a−400=0。
```

`a=2/3` 时左侧恒为 `288`，直接退出。其余 generic 图消去 `c` 后，`K_1,K_2` 模 `7` 的 Bézout 等式见报告，故无共同根。

参数化线性解的合法特殊点 `a=8/3,b=−16/5` 单列：兼容式迫使 `w3=97/66`，随后 `K_6=−7870500`。

故图 B 无有理解。

## 4. 结论 OCTIC-NO211

图 A、B 覆盖两个 `2+1+1` 定向槽型的全部有理仿射、重根、不可约二次及退化分母图。故 GATE8 下只剩

```text
(0,2,2), (2,0,2)。
```

## 5. `022` distinct-center generic 图

若 `(0,2,2)` 的两个二次因子中心不同，有理仿射规范为

```text
A=x²+p， B=x²+x+q。
```

在 `D022≠0`，DIFF 与槽条件只留 `s=w0`。插值兼容式的第一因子

```text
p²−2pq+p+q²
```

正是 `Res(A,B)`，故第二因子为零并消去 `s`。

`p≠q` 时，`K_5,K_6` 是报告给出的两条线性式，唯一形式点恢复出的 `f−2` 三因子均无有理根。`p=q` 时两条线性式不相容。

该命题只关闭 `D022≠0` 且中心不同的子图，不处理 `D022=0` 或同中心图。

## 6. 同中心 generic 图的精确失败边界

为避免把开放图误说成空集，本包还重放同中心规范

```text
A=x²+p， B=x²+q， p≠q， 4p−3q≠0。
```

线性 DIFF 图只留常数参数 `s`。二次商的非恒定系数迫使

```text
s=(−36p²+63pq+98q²)/500。
```

代回后

```text
rho=4084101(p−q)^4/500000000
```

并精确恢复

```text
f−2 = 4(6p+119q+125x²)(111p+14q+125x²)
       (-36p²+63pq−9px²+98q²+259qx²+125x⁴)
       /[194481(p−q)^4]。
```

该恒等式由 `src/probe_022.py` 逐项核验。取 `p=-14,q=111` 得

```text
f−2=4x²(x²+105)(x⁴+231x²+8820)/24310125，
```

显示非负形式弱外壳确实非空。它没有证明原整数数字系数、原窗口、完整素数幂或 NC3，因此仅是方法失败边界。`4p−3q=0` 的同中心退化图仍未处理。
