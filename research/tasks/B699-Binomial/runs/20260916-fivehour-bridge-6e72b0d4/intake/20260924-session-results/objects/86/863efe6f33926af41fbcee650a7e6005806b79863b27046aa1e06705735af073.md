# PROOFS · Round 18 · 纯二 BRIDGE4096 完整排空

```math
q=2^{\rho-3}w,
```

```math

```

```math
v=2mxy,
\qquad y=U_{4q+1}U_{4q}-1,
\qquad d=3U_{4q+1}X_{4q}+1.
```

POWER 多项式为

```math
\begin{aligned}
R(d,v)={}&Q^{10}-12Q^7+15dQ^6-4d^2Q^5-4dQ^3\\
```

## P1. 固定 `(rho,m)` 时的 2-adic 唯一根

固定 `rho` 与允许的奇数 `m`，定义

```math
\Phi_{\rho,m}(w)
=\frac{R(d(w),2m x(w)y(w))}{8}
```

于奇 `w`。

### P1.1 整性与解析性

Round 12 已证明对奇乘子 `m`，`R(d,2mxy)` 被 `8` 整除。又

```math
(2+\sqrt3)^{4q}
=\left((2+\sqrt3)^{2^{\rho-1}}\right)^w,
```

而括号中的单位同余 `1 (mod 2^rho)`。所以 `x(w),y(w),d(w)` 以及 `Phi` 是 `w` 上的整数值 2-adic 解析函数。

### P1.2 单位导数

Round 12 的统一低位展开为

```math
x\equiv32+7w\pmod{64},
\qquad y\equiv1\pmod{64},                           \tag{1}
```

以及

```math
d\equiv1\pmod{2^{\rho+1}}.                         \tag{2}
```

置

```math
a=mxy.
```

已有精确恒等式

```math
R(1,2a)=8aG(a),                                     \tag{3}
```

其中

```math
\begin{aligned}
G(a)={}&128a^9+640a^8+1440a^7+1728a^6+1128a^5\\
&+344a^4-10a^3-44a^2-11a-1.
\end{aligned}
```

模 `4`：

```math
G(a)\equiv2a^3+a+3\pmod4.
```

当 `a` 为奇数时，`a^2≡1`、`a^3≡a (mod4)`，故

```math
aG(a)\equiv3-a\pmod4.                              \tag{4}
```

`R(d,2a)-R(1,2a)` 被 `d-1` 整除。由 `(2)`、`rho>=12`，除以 `8` 后该差仍被 `2^(rho-2)` 整除，特别地模 `4` 消失。

由 `(1)`：

```math
a=mxy\equiv-mw\pmod4.
```

代入 `(3)`、`(4)`：

```math
\boxed{
\Phi_{\rho,m}(w)\equiv3+mw\pmod4.
}                                                    \tag{5}
```

为确认这不是只停留在模 `4` 的函数值观察，直接看 2-adic 解析导数。令

```math
\beta_\rho=(2+\sqrt3)^{2^{\rho-1}}.
```

由

```math
(2+\sqrt3)^4=1+8(12+7\sqrt3)
```

的二项式展开，得到

```math
\beta_\rho
\equiv1+7\cdot2^\rho\sqrt3
\pmod{2^{\rho+1}}.
```

所以在

```math
\beta_\rho^w=V(w)+2^\rho x(w)\sqrt3
```

中，作为 `w in Z_2` 的限制幂级数有

```math
x'(w)\equiv1\pmod2.
```

同时 `V'(w)`、`y'(w)` 为偶数，而 `y(w)` 为奇数。故

```math
a'(w)=m(x'(w)y(w)+x(w)y'(w))\equiv1\pmod2.
```

`d-1` 及 `d'` 均被 `2^(rho+1)` 整除，因而在 `R/8` 的导数模 `2` 中可以置 `d=1`。于是

```math
\Phi'_{\rho,m}(w)
\equiv (G(a)+aG'(a))a'(w)
\equiv1\pmod2,                                  \tag{6}
```

这里用了奇 `a` 时 `G(a)≡0`、`G'(a)≡1 (mod2)`。

所有奇 `w` 在模 `2` 下同属根类 `w=1`，而 `(6)` 是单位导数。因此普通 Hensel 引理给出：对每个 `L>=1`，`Phi=0 (mod 2^L)` 在奇 `w` 中恰有一个剩余类模 `2^L`。

## P2. `q<2^53` 把唯一 2-adic 类变成唯一整数候选

由 `(Q53)` 与 `q=2^(rho-3)w`：

```math
1\le w<2^{56-\rho},
\qquad w\text{ 奇}.                                \tag{7}
```

置

```math
L=56-\rho.
```

区间 `(7)` 恰好包含每个奇剩余类模 `2^L` 的唯一正代表。

所以，对固定 `(rho,m)`，真实行若存在，其 `w` 必是 P1 唯一 Hensel 类的该代表；没有第二个整数候选。

允许的奇 `m` 数为

```math
\#M_\rho
=\frac{27\,2^{\rho-1}}2
=27\,2^{\rho-2}.                                   \tag{8}
```

故剩余全部候选数为

```math
\begin{aligned}
\sum_{\rho=12}^{27}27\,2^{\rho-2}
&=27(2^{26}-2^{10})\\
&=1,811,911,680.
\end{aligned}                                      \tag{9}
```

## P3. Newton doubling 的精确恢复

实现从模 `2` 的根开始。若当前 `w` 满足

```math
\Phi(w)=0\pmod{2^k},
```

取

```math
h=\min(k,L-k),
```

并计算

```math
A=\frac{\Phi(w)}{2^k}\pmod{2^h},
```

```math
D=\frac{\Phi(w+2^k)-\Phi(w)}{2^k}\pmod{2^h}.
```

由 `(6)`，`D` 为奇数，故可逆。令

```math
c\equiv-AD^{-1}\pmod{2^h},
\qquad
w'=w+2^k c.
```

2-adic Taylor 展开给

```math
\Phi(w')=0\pmod{2^{k+h}}.
```

每步程序重新直接计算并断言该同余；精度按 `1,2,4,8,...` 翻倍，直到 `L`。这与逐位 Hensel 给出同一个唯一根。

## P4. 弱 `2^80` 门已经足够

由 `rho>=12`，有 `q>=512`。真实门 `(QP)` 给

```math
v_2(R)\ge45q\ge23040.                              \tag{10}
```

因此真实候选必满足

```math
\frac R8\equiv0\pmod{2^{80}}.                     \tag{11}
```

本轮对 `(9)` 的每个候选计算 `(R/8) mod 2^80`。所有余数均非零；由最低非零位恢复出的准确 `v2(R)` 最大仅为

```math
\boxed{64}.                                        \tag{12}
```

`(12)` 与 `(10)` 矛盾。因此：

```math
\boxed{12\le\rho\le27\text{ 不可能}.}            \tag{L12--27}
```

## P6. BRIDGE4096 分支闭合

```math

```

全部退出；Round 16 给

```math
\rho\ge56
```

统一退出。所以

```math
\boxed{\text{BRIDGE4096 必要核心为空}.}            \tag{BRIDGE-CLOSED}
```

Round 12 已排空 `rho=8,...,11`，Round 11 已排空其更低前层。因而在采用这些冻结分类完整性的前提下，平衡 BLOCK-MIX 的 pure-two 一侧没有剩余状态。

## P7. 回到原题

本轮始终从同一原始 `(n,j)` 的 `NC3` 必要核心出发。`BRIDGE-CLOSED` 说明该原输入不可能落在 pure-two 分支；于是对任何被该分支分类捕获的原输入，`NC3` 反设失败，故存在某个真正素数 `p>=3` 同时整除原始 `C(n,3)` 与 `C(n,j)`。

本轮没有辨识该共同素数，也没有处理 odd--odd 或其他 `i=3` 分支。

证据不是 Lean：它是冻结纸面前置、本轮纸面降维和确定性有限证书的组合。
