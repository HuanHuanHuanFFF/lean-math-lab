## 完整离线重放

要求Linux/POSIX、Python 3.10+、支持C++17的g++。不需要SymPy、NumPy、网络、仓库或Lean。
输出目录必须不存在，且不要放在这个证据目录内。

```sh
python3 -B code/replay.py --out /absolute/new-output-directory --compare
python3 -B code/negative_tests.py --run /absolute/new-output-directory \
  --out /absolute/new-output-directory/negative_tests.json
```

支持明确分段，不把单个切片PASS当作完整覆盖：

```sh
python3 -B code/replay.py --out /absolute/new-output-directory --stage init
python3 -B code/replay.py --out /absolute/new-output-directory --stage modules
python3 -B code/replay.py --out /absolute/new-output-directory --stage covers --start 0 --stop 2
python3 -B code/replay.py --out /absolute/new-output-directory --stage covers --start 2 --stop 4
python3 -B code/replay.py --out /absolute/new-output-directory --stage covers --start 4 --stop 6
python3 -B code/replay.py --out /absolute/new-output-directory --stage covers --start 6 --stop 8
python3 -B code/replay.py --out /absolute/new-output-directory --stage extensions
python3 -B code/replay.py --out /absolute/new-output-directory --stage check
python3 -B code/replay.py --out /absolute/new-output-directory --stage finish
python3 -B code/replay.py --out /absolute/new-output-directory --stage compare
```

`finish`必须看到六个射影空间的完整集合、两个扩域方向、无重复无缺口；缺项会拒绝。
`check`不相信发现器的因子数，独立检验完整模基、分解乘积、Frobenius和gcd。
核的完备性依赖PROOFS中已列的模块不变量，不能仅从基向量满足方程推断。
