# REPLAY

环境：Python 3；`sympy==1.14.0` 仅用于精确有理多项式、Groebner 基、因式分解与 Taylor 系数重放。独立检查器只用 Python 标准库。

从包根目录运行：

```bash
sha256sum -c SHA256SUMS
python3 -B src/replay.py
python3 -B src/independent_check.py
python3 -B src/next_probe.py
```

其中：

- `replay.py` 重建 SLOT 闭式、BOUNDARY-3、WEIGHT8、三个 `3+1` 图的精确 DIFF 解、高次余式、Q-Groebner 基、全部恢复和退出条件；
- `independent_check.py` 不调用 SymPy，在模 `13,17,19` 下完整枚举三个图的饱和高次方程，交叉检查唯一剩余类和四个最终槽度型；
- `next_probe.py` 只诊断两个 `2+1+1` generic 图的线性参数维数及退化分母，**不承担排除证明**。

输出中的 `PASS` 只表示这些确定性重放项目通过，不表示 Lean、外部独立数学审稿、完整 `i=3` 或 B699 闭合。
