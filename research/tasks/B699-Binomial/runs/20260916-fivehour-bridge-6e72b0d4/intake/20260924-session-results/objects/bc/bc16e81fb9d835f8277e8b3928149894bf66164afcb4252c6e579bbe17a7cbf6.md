# REPLAY

环境：Python 3，`sympy==1.14.0`。不需要网络、仓库或随机数。

```bash
python3 -B src/replay_no211.py
python3 -B src/probe_022.py
python3 -B src/independent_check.py
```

- `replay_no211.py` 重建两个 `2+1+1` 图的 DIFF/槽参数化、二次商插值、退化图、结式与模 Bézout 证书。
- `probe_022.py` 重建 `(0,2,2)` distinct-center、`D022≠0` 子图及唯一形式点的无有理原点证书。
- `independent_check.py` 只用标准库重新核对判别式、Horner 值表与两份模 `7` Bézout 身份。

所有输出仅验证明确的有限代数证书；无限量词由 `PROOFS.md` 承担。
