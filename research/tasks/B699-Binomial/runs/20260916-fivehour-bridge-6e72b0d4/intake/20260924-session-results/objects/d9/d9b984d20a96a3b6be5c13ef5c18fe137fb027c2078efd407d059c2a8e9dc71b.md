# HANDOFF · Round 16 后

## 当前新增主结论

在同一原 `(n,j)` 的规范最小临界两底、真实 `mu=1`、平衡纯二 `BRIDGE4096` 必要核心中：

```math
\boxed{q<2^53}.
```

因此

```math
\boxed{t<2^56,
12<=rho<=55,
m<2^60,
s<2^61.}
```

这把纯二桥从 Round 15 的非有效有限性升级为显式有效有限化。证据不是 Lean。

## 可直接采用的主项

```math
N0=m^6 alpha^(48q+3)/(8*3^(9/2)*2^(6rho)),
qquad alpha=2+sqrt3,
```

```math
\boxed{|n/N0-1|<1000q alpha^(-4q).}
```

写

```math
c=3^kappa,
eta=9+2kappa,
beta=(2m)^6/(sqrt3)^eta,
```

则

```math
Gamma=n/N0
=2^(s+6rho+9) alpha^(-(48q+3)) beta^(-1)
```

且 `Gamma!=1`。三对数 Matveev 常数账本给

```math
log|Gamma-1|
>-23137949116800 (log q+6)(log q+7).
```

## 当前纯二有限前沿

- `512|q` 且 `q<2^53`，故形式 Pell 行少于 `2^44`；
- 固定 `q` 至多一个 POWER 乘子 `m`；
- `s=v2(R)-2` 唯一；
- 每行只余 `c=1,3`、POWER 奇部、平方范数、完整 `P/Q` 幂和原 `(n,j)` 恢复。

## 仍开放

1. 纯二桥的巨大有限末端；
2. 平衡 odd--odd：Round 15 仅给非有效有限性；
3. 非平衡两底、low/low、非最小、三槽、多槽。

## 下一轮优先级

1. **纯二末端的结构降维，而不是枚举 `2^44` 行。** 首攻 `m|9u` 与唯一 Hensel 根，尝试证明 `m` 必含某个 primitive-rank 坏因子，或把 `q` 再降到可扫描高度。
2. 尝试对三对数形式做 Baker--Davenport / LLL 约化；但 `beta` 随 `m` 变化，必须先利用 `m|9u` 把可变高度压成有限模板。
3. 若纯二停滞，转 odd--odd：首个可证伪目标是证明奇分配乘子的高度为 `O(log q)`；一旦成立，本轮 Matveev 链可原样推广并给显式 `q` 界。
