# REPLAY · Round 20

## 依赖

- Python 3 标准库：有理区间、整数平方根、Pell坐标、精确POWER赋值、14个末端及坏证书拒绝。
- SymPy：仅用于独立符号展开检查；本次环境版本记录在 ENVIRONMENT.json。
- 不需要网络、仓库、GPU、历史海量枚举或随机数。

## 默认完整本轮重放

```bash
bash replay.sh
```

顺序：哈希核验 → 15个小A有理间隙 → 大A统一常数 → 14个必要末端 → 坏证书拒绝 → 与冻结JSON一致性 → 同源恒等式/导数/Taylor核验。

## 单独检查

```bash
python evidence/replay.py --output /tmp/round20-replay.json
python evidence/symbolic_verify.py
```

`--generate` 只用于重建本轮证书，不是默认验收路径。默认运行会重算结果并要求与 certificates/round20.json 完全相同。

程序没有穷举所有 A 或 q；无限范围由 PROOFS P2–P5 的纸面界和单调性覆盖。程序通过不等于 Lean 或外部独立数学审读。
