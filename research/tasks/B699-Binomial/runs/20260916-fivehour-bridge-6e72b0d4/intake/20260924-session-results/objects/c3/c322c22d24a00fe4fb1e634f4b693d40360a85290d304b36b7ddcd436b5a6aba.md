# REPLAY

## 环境

- Python 3 标准库；
- SymPy 用于显式多项式恒等式；
- 无网络、无随机数、无仓库写入。

## 运行

```bash
bash replay.sh
```

重放内容：

1. 全部 2-adic 端点余数；
2. 规范 `lambda/theta` 恒等式；
3. 直接／互补主项精确约分；
4. 两个 `2^53` Matveev 有理比较；
5. `UNITARY-5` 的小模完整检查；
6. `t=41` 弱模型的源分配与非平方目标；
7. 无限形式壳的有限样本回归；
8. 证书逐字节再生成。

重放不重证 Matveev 或 Corvaja--Zannier 定理。
