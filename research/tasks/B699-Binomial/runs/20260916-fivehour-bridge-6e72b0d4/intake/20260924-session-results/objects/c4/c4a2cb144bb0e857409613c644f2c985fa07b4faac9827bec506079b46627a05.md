# PROOFS — C15：整个第5源非中央域闭合

## 0. 原量词与定义

固定同一个原始合法 `(n,j)`，置

```text
k=n-j, g=gcd(n,j), 7≤j≤floor(n/2),
n mod1800 ∈ {1280,1530}.
```

反设 NC6。冻结 unit-coarse 合同给 `g≥7` 及所有粗窗 `q_r≥7`。
完整源窗口失败时，失败粗素数已经给同一个原 `(n,j)` 的 Common6。

写

```text
q2=E2*M2,
q5=Q50*Q51*Q52.
```

本轮研究整个 `Q52=1` 域，不限制 `E2,M2,Q50,Q51` 是否单位。

## 1. K16 的统一高度

正十六次核的精确源阶为

```text
r1: 8,8
r2: 3,4,3
r3: 4,4,4,4
r4: 3,3,3,3,3
r5: 2,2,1,1,2,2.
```

一般完整源整除：

```text
q1^8 q2^3 q3^4 q4^3 q5 M2 Q50 Q51 | F16/g^4.
```

若 `Q52=1`，则 `Q50Q51=q5`，故

```text
q1^8 q2^3 q3^4 q4^3 q5^2 M2 | F16/g^4.             (1.1)
```

核的严格正性与 `L=1388988` 给：

```text
A: g^4 q2^3 q5^2 < (L/2)n;                          (1.2A)
B: g^4 q2^3 q5^2 < (81L/16)n.                       (1.2B)
```

令 `X=n-5`。BFT 门：

```text
A:
 max(cg,2q2)>X^(57/200),
 max(cg,3q5)>X^(129/500), c∈{1,5};

B:
 max(cg,q2)>X^(57/200),
 max(cg,q5)>X^(27/125), c∈{1,2,5,10}.
```

差2无例外；差5的三个例外大分量不在两个尾类。

若第一门由 `cg` 付款，冻结 `g^7<2^22n` 给相应高度。
否则第一门由 q2 付款：

- 第二门由 `cg` 付款时，以 `q5≥7` 补足；
- 第二门由 q5 付款时，以 `g≥7` 补足。

完整整数幂比较得到：

```text
A: c=1,5 均 n<2^43;
B: c=1,2,5,10 分别 n<2^45,2^45,2^45,2^48.
```

所以统一采用 `A<2^43, B<2^48`。

## 2. SAT-SQUEEZE

冻结合同：

```text
D25=[J*(j-1)*(k-1)]_(q2*q5), J=jk,
q2*M2*Q50*Q51 | D25.
```

在 `Q52=1` 时

```text
D25≥q2*M2*q5≥q2*q5.                                 (2.1)
```

又

```text
Delta3=E3^2/gcd(E3^2,J)≤E3≤q3,                      (2.2)
```

因为完整第三源端点块 `E3|J`。

A尾 NC 必有 `Delta3>15g^3D25`，而

```text
q3=n-3=s2*q2-1.
```

由 (2.1)–(2.2)：

```text
s2*q2-1 > 15g^3q2q5,
15g^3q5 < s2.                                       (2.3A)
```

B尾 NC 必有 `Delta3>3g^3D25`，且

```text
q3=(n-3)/3=(s2*q2-1)/3,
```

故

```text
9g^3q5 < s2.                                        (2.3B)
```

用 `g≥7`：

```text
A: 5145q5<s2;
B: 3087q5<s2.                                       (SAT-SQUEEZE)
```

## 3. A尾完整指数排空

准确小部：

```text
n-2=2*3^b*q2, b≥2;
n-5=3*5^E*q5, E≥2.
```

令 `A0=2*3^(b-1)`。相邻差3给

```text
A0*q2-5^E*q5=1.                                     (3.1)
```

因此

```text
q5 ≡ -5^(-E) (mod A0).                              (3.2)
```

又 `s2=3A0`，SAT-SQUEEZE 强迫

```text
q5<A0/1715<A0.                                      (3.3)
```

所以实际 q5 必须是 (3.2) 的唯一最小正代表。

高度 `n<2^43` 给精确范围

```text
2≤b≤26, 2≤E≤17.
```

标准库重放全部400对，并直接检验

```text
5145*r_A(b,E) < 3A0.
```

零对通过。

## 4. B尾完整指数排空

```text
n-2=2^bq2, b≥3;
n-5=5^Eq5, E≥2;
2^bq2-5^Eq5=3.                                      (4.1)
```

故

```text
q5 ≡ -3*5^(-E) (mod 2^b).                           (4.2)
```

SAT-SQUEEZE 给 `q5<2^b/3087<2^b`，所以仍是唯一最小正代表。
高度 `n<2^48` 给

```text
3≤b≤47, 2≤E≤20.
```

完整855对全部违反 `3087q5<2^b`。

## 5. 返回原题与严格范围

任取两个尾类中的原始输入：

- 任一完整源窗口失败时，已有真实共同素数；
- 窗口全成立且 `Q52=1` 时，§§1–4矛盾。

所以

```text
Q52=1 => Common6(n,j).
```

没有换输入、没有扩大源幂、没有把必要窗口反向定义成NC6。
