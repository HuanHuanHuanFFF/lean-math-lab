# 归档范围与原件保留规则

本包仅整理本会话可见交付记录中、已在当前运行环境实际取回的九轮产物。没有检索或纳入其他会话的独立研究 ZIP，没有调用仓库或联网补材料。

## 两层存放

- `rounds/*/originals/`：九个本会话生成的证据 ZIP、九份原始 ZIP 哈希侧件、八份已交付的原始归档检查记录。文件字节全部不变。
- `rounds/*/files/`：从对应原 ZIP 提取的本会话文件阅读镜像。保留名称、相对目录和内容字节，包括重复命名的证明、失败说明、当轮旧哈希表、同会话的上游包和前轮文档副本。
- `rounds/*/standalone/`：本会话单独交付且目前取回的八个证明/交接/勘误附件。即使与 ZIP 内成员相同也保留，并记录相等性。

## 来源输入不混同为本会话成果

原始 ZIP 当初已内嵌来源输入。为了同时保留证据 ZIP 原始字节，不能从其内部删除这些成员；它们仅作为原件固有内容保留。

八份 `inputs/OVERVIEW-2026-09-22.md.txt` 和一份 `inputs/two_base_excerpt.md` 不在阅读镜像中另行展开，逐项映射见 `audit/SOURCE_MEMBERS.json`。它们不是恢复失败，也不是本会话新增研究结论。原包中的来源采纳记录及本会话编写的 `EXTERNAL_SOURCE_MAP.md` 正常保留。

本包不额外放入当前挂载的 Overview 9月21日/22日独立文件，不放入其他会话的证据包，也不下载外部论文或声称收录未生成的 PDF/截图。原 ZIP 中嵌套的四份前轮 ZIP 均与本会话对应原件 SHA-256 相同。

## 数学状态不因归档改变

索引只描述各轮原报告的声明，不新作数学研究、核对推导或修正原文。所有前置、门槛、未闭合参数与证据等级以当轮原件及后续明确勘误为准。第05轮存在第06轮明确指出的常数项错误；旧原件和旧 PASS 均保留，但不因此恢复为有效证明。

历史研究脚本与重放日志是归档对象；本次一个也没有执行。本次 PASS 仅指 ZIP CRC、字节一致性与 SHA-256 完整性，不是 Lean、外部独立数学审稿或完整 B699 闭合。

## 重放路径提示

阅读镜像有意不展开九份非本会话来源副本，因此其中旧 `SHA256SUMS` 或重放脚本可能仍引用未展开的输入。不要改写这些旧清单。需要原有完整目录时，解压该轮 `originals/` 下的原始 ZIP；这会恢复当初的全部目录及输入。归档本身的校验使用 `python audit/verify_archive.py`，不需要运行数学脚本。
