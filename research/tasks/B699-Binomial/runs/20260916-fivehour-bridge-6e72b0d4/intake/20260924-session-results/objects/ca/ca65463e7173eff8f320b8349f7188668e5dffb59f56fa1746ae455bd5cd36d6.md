# PROOFS — NONIC-REDUCE6

## 0. 作用域与采用前置

固定同一个原始自然数输入 `n,j`，`4≤j≤floor(n/2)`，令 `k=n−j`。Common3 表示存在同一个奇素数同除 `C(n,3),C(n,j)`；NC3 是其否定。

本轮采用上一轮已经冻结的一般大进制提升：对 `deg f=d`，门槛

```text
T≥[2(f(1)+2)]^(2d+4)
```

使同一 NC3 输入必要满足

```text
f−1 | J(J−1)，
f−2 | J(J−1)(J−2)                 in Q[X]。
```

第一源完整分配可写为

```text
f−1=UV， U(0)=V(0)=1，
σ=VW， U|VW−1，
W(W−U)(W−2U)=(UV−1)R，
gcd(U,W)=gcd(U,R)=1。
```

并有

```text
U | WR'−R(3W'−2U')                (DIFF)
U² | W³+R−2UW²                    (U2)
```

（`R` 的非零有理比例可另行吸收。）这些都是 NC3 必要条件，不反向刻画 NC3。

冻结的 `PRIMARY-≥2/3` 给每个第一源完整块严格次数区间

```text
d/3 < block degree < 2d/3。
```

在 `d=9` 时只能是 `4+5`。交换原端点会交换两个第一源块，所以可取

```text
deg U=4，deg V=5，deg W≤4。
```

## 1. 槽分解与精确 S 公式

三个槽多项式 `W,W−U,W−2U` 两两互素。将 `R` 的每个不可约因子连同完整重数分给它实际整除的槽：

```text
R=R0 R1 R2， dr=deg Rr。
```

写 DIFF 的精确商为

```text
WR'−R(3W'−2U')=US， deg S≤deg R−1。
```

模 `R0,R1,R2` 分别计算，唯一得到

```text
S=R0 R1' R2 + 2R0 R1 R2'。        (SLOT-S)
```

若 `R` 的首项为 `r`，则 `S` 的最高可能系数为

```text
(d1+2d2)r。
```

该公式保留重因子，不要求 `R` 平方自由。

## 2. 所有边界退出

令 `t=lc(W)/lc(U)`；两个原数字端点非负给 `0≤t≤1`。

### 2.1 `t=0`

令 `s=deg W≤3`。`s=0` 时主身份左边次数至多 8，小于 `deg(UV−1)=9`。

若 `1≤s≤3`，则 `deg R=s−1`。在 DIFF 中，`WR'` 和 `3RW'` 次数至多 `2s−2`；唯一 `s+2` 次项来自 `2RU'`，系数为 `8ur`。右边 `US` 的同次系数为 `(d1+2d2)ur`。故

```text
d1+2d2=8。
```

但 `d0+d1+d2=s−1≤2`，左边至多 4，矛盾。

### 2.2 `t=1`

令 `D=W−U`、`s=deg D≤3`。`s=0` 同样次数不足。若 `1≤s≤3`，则 `deg R=s−1`。

DIFF 写成

```text
(U+D)R'−R(U'+3D')=US。
```

其 `s+2` 次首项给

```text
d1+2d2=s−5<0，
```

与左边非负矛盾。

所以必须 `0<t<1`。

## 3. 内部槽权公式与十种槽型

此时 `deg W=4`，三个槽都为四次，故

```text
deg R=12−9=3。
```

比较 DIFF 的六次首项：

```text
WR' : 3tur，
−R(3W'−2U') : (8−12t)ur，
US : (d1+2d2)ur。
```

因此

```text
d1+2d2=8−9t。                     (WEIGHT9)
```

由 `d0+d1+d2=3` 得到十种定向类型：

```text
(3,0,0), t=8/9;  (2,1,0), t=7/9;
(1,2,0), t=2/3;  (0,3,0), t=5/9;
(2,0,1), t=2/3;  (1,1,1), t=5/9;
(0,2,1), t=4/9;  (1,0,2), t=4/9;
(0,1,2), t=1/3;  (0,0,3), t=2/9。
```

以下删除三个单槽和 `(1,1,1)`。

## 4. 三个单槽型

设整个三次 `R=ρA` 进入槽 `k∈{0,1,2}`。因 `W−kU` 为四次，写

```text
W−kU=AC， deg C=1。
```

将 `C` 的有理根移到 0，并规范 `A,U` 首一：

```text
A=x³+a x²+b x+c， C=mx。
```

由 SLOT-S，单槽时 `S=kA'`。DIFF 精确化为

```text
(3k−2)U' + 2A'C + 3AC'=0。
```

比较首项并积分：

```text
m=4(2−3k)/9，
U=x⁴+28a x³/27+10b x²/9+4c x/3+d。   (4.1)
```

### 4.1 U2 的完整分类

将

```text
W³+ρA−2UW²
```

除以 `U²`。最高四个余式系数对于三个 `k` 只差非零标量。

- `a=0` 的精确 Groebner 基包含 `b^5,c^3`，并由其余式强迫 `d=0`；于是 `A=x³,U=x⁴`，违反 `gcd(U,R)=1`。
- `a≠0` 时用 `x↦ax` 规范 `a=1`。精确 reduced Groebner basis 是
  ```text
  27b−8， 6561c−160， 531441d−256。
  ```

低次余式随后唯一确定

```text
ρ0= 2^23/3^33，
ρ1=−2^20/3^33，
ρ2=−2^26/3^33。
```

三个形式点都满足主身份和原逆关系；所以还必须恢复原数字原点，而不能在 U2 层提前宣布矛盾。

### 4.2 有理数字原点

三个 `f−2` 分解为

```text
k=0:
2187 x(9x+4) C3(x) Q0(x)/2^19；

k=1:
−2187 x Q0(x) Q1(x)/2^18；

k=2:
−2187 x(9x+4) C3(x) Q2(x)/2^21，
```

其中

```text
C3=6561x³+5832x²+1296x+64，
Q0=295245x⁴+314928x³+104976x²+11520x+256，
Q1=767637x⁴+787320x³+244944x²+23040x+256，
Q2=413343x⁴+393660x³+104976x²+5760x−256。
```

`C3,Q0,Q1,Q2` 分别在模 `5,7,5,5` 下无根，因此有理原点只可能是 `0`，或在 `k=0,2` 时还有 `−4/9`。

Taylor 符号直接删除：

```text
k=0, x0=−4/9:  [z]f=2187/8>0, [z²]f=−59049/32<0；
k=1, x0=0:     [z]f=−2187/4, [z²]f=−295245/4；
k=2, x0=0:     [z]f=2187/32>0, [z³]f=−13640319/256；
k=2, x0=−4/9:  [z]f=−2187/16, [z³]f=12577437/512>0。
```

任一变量方向均出现负数字系数。

### 4.3 唯一正外壳被完整 3 源删除

只剩 `k=0,x0=0`。固定有理缩放和块常数后，规范为

```text
U=1+60Y+540Y²+1512Y³+1296Y⁴，
V=1+183Y+3060Y²+15444Y³+29808Y⁴+19440Y⁵，
W=40Y+432Y²+1296Y³+1152Y⁴。
```

若原变量为 `Y=mX`、`m=u/v` 既约，则原 `U,V,W` 的线性系数整数要求 `v` 同时整除 `60,183,40`；其 gcd 为 1，所以 `m∈Z`。非负性给 `m>0`。

置原输入 `y=mT`。令

```text
A3=72y³+72y²+18y+1，
A4=720y⁴+864y³+324y²+40y+1。
```

精确恒等式为

```text
n−2=3^5 y(2y+1)A3 A4，
Σ=8y(144y³+162y²+54y+5)V，
Σ−1=(2y+1)(6y+1)(120y−1)A3
     (216y³+216y²+54y+1)，
Σ−2=2A4(15552y⁵+22680y⁴+10800y³+1800y²+60y−1)。
```

按 `y mod3`：

- `y≡0`：`E=v3(n−2)=5+v3(y)`，而 `v3(Σ)=v3(y)`；
- `y≡1`：`E=5+v3(2y+1)`，而 `v3(Σ−1)=v3(2y+1)`；
- `y≡2`：`E=5+v3(A4)`，而 `v3(Σ−2)=v3(A4)`。

每次合法槽都少整整 5 层。由于 `E≥5`，这是完整高次 3 源，不能按孤立一次 3 删除。故 `3^E|n−2` 没有进入 `Σ,Σ−1,Σ−2` 任一槽，与 NC3 冲突。

三个单槽型全部退出。

## 5. 三线三槽 `(1,1,1)`

用有理仿射坐标将槽 0、1、2 的根分别规范为

```text
0, 1, q， q∈Q\{0,1}，
R∝x(x−1)(x−q)， t=5/9。
```

SLOT-S 给

```text
S=x(3x−q−2)。
```

DIFF 与三个根值条件是线性系统。generic `q≠10/9` 时只余两个参数 `A=w1,B=w2`。构造二次插值商 `Q`：

```text
Q(0)=−200U(0)/729，
Q(1)=  16U(1)/729，
Q(q)=1690U(q)/729。
```

令

```text
H=(W−5U/9)^3−U(W−5U/9)^2/3−U²Q。
```

插值保证 `x(x−1)(x−q)|H`；完整 U2 要求商 `H/[x(x−1)(x−q)]` 为常数。

其常数项含

```text
L²M，
L=81Aq+54A−81Bq²+162Bq+104q³−160q²。
```

而

```text
U(0)=2L/[27q(9q−10)]，
```

故 `L≠0`，必须 `M=0`，其中

```text
M=−177147Aq²+34398Aq+9936A
  −103572Bq²+29808Bq
  +50700q⁴+17680q³−29600q²。
```

`A` 的系数为 `−27D(q)`，

```text
D(q)=6561q²−1274q−368。
```

`Disc D=11280868` 不是平方，所以 `D(q)≠0` 对有理 `q` 成立。消去 `A` 后，商的一次和七次系数给两个关于 `B` 的二次式。其 resultant 为

```text
1721868840000 D(q)^4 P8(q)，
```

其中

```text
P8(q)=1874243735045157411q^8
−7588066639400463060q^7
+5976533651595972543q^6
−6182115393344250334q^5
+6112773480199388080q^4
−2506338132652428256q^3
+347123565112271360q²
−258046700361728q
+45804108713984。
```

其模 17 全值无零，且首项不被 17 整除，所以无有理根。

### 5.1 特殊 `q=10/9`

重新解未除该因子的线性系统。`U(0)≠0` 后，商常数项给

```text
3188646A−4316895B−5281900=0。
```

代入七次系数得到

```text
354294B²−127705005B−164557100=0。
```

模 7 全值为 `6,1,2,2,1,6,3`，无零，故无有理解。

因此 `(1,1,1)` 全部退出。

## 6. 当前精确终点

十个内部定向槽型中，三个单槽和 `(1,1,1)` 已删除。只剩六个 `2+1` 型：

```text
(2,1,0),(1,2,0),(2,0,1),
(0,2,1),(1,0,2),(0,1,2)。
```

对每一型，将一次因子根送到 0、二次因子写为 `x²+ax+b` 后，DIFF 与槽整除在线性层的秩均为 6，在八个 `U,W` 系数中留下两个自由参数。U2 随后成为四参数非线性系统。本轮没有把这一成本诊断称为有限化或排除。
