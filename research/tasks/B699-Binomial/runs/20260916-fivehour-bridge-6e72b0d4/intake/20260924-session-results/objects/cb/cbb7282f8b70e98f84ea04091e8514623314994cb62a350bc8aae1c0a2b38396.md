# PROOFS — q4 特征落点、CENTER-SF 与 q5 下一 p 进层

## 0. 固定前提与记号

固定当前 B/RES10 全近侧、中心较小、低残量、大缺欠的同一原输入。使用：

```text
n≡5130 (mod9000), alpha=n/g=3^a,
U=jk/(n-1)=10g^2z^2, 1<U<n/3,
q2=(n-2)/2^b, q3=(n-3)/3, q4=(n-4)/2, q5=(n-5)/5^E,
q4=E4 A4 C,  C<A4,
E3=A4 q5 eta+g C L3,
E3E4=d h^2, z=d h v,
E4=d4 h4^2,
Delta4=(h4/gcd(h4,v))^2>10g^2D25.
```

另有第2源精度

```text
q2=E2 M2, gcd(E2,M2)=1,
epsilonE=sf(E2), epsilonM=sf(M2),
sigma2=epsilonE epsilonM,

D25 >= E2 epsilonE M2^2 q5,
v^2  >= E2 epsilonE,
eta  >= M2^2.
```

以下均是当前 NC6 反证系统的必要后果，不能反向当作 NC6 的充分刻画。

## 1. q4 的整体二次特征

当前 `b>=65`、`E>=27`，所以

```text
n≡2 (mod16), n≡0 (mod5), n≡0 (mod3).
```

唯一模240解是

```text
n≡210 (mod240).
```

故

```text
q4=(n-4)/2≡103 (mod120),
q4≡23 (mod40).
```

对奇数且与10互素的整数写 `chi10(m)=(10/m)`（Jacobi 符号）。模40特征表给

```text
chi10(23)=-1,
```

于是

```text
chi10(q4)=-1.                                      (1.1)
```

## 2. A4 的每个素因子均为正特征

取任意素数 `p|A4`。因 `A4` 是第4源近侧块，在完整原层

```text
n≡4, {j,k}≡{1,3} (mod p),
N=n-1≡3 (mod p).
```

所以

```text
U=jk/N≡1 (mod p).
```

又 `p>=7`、`p∤g`。若 `p|z`，则 `U=10g^2z^2≡0`，与 `U≡1` 矛盾；故 `p∤gz`，并有

```text
1≡10(gz)^2 (mod p).
```

因此

```text
chi10(p)=+1
```

对每个 `p|A4` 都成立，完整指数相乘仍给

```text
chi10(A4)=+1.                                     (2.1)
```

由 `q4=E4A4C` 三块互素，(1.1)、(2.1) 得

```text
chi10(E4C)=-1.                                    (2.2)
```

所以 `E4C` 不是平方。规范写

```text
E4=d4h4^2, C=c4t4^2,
tau4=sf(E4C)=d4c4.
```

所有粗素数至少为7，故

```text
tau4>=7.                                          (2.3)
```

这排除 `d4=c4=1`；但允许 `d4=1,c4>1`，所以不能推出一般 `d4>=7`。

### 中心落点确实局部相容

对 `p|C`，中心槽给 `n≡4,j≡k≡2`，故 `U≡4/3`。由 `U=10g^2z^2`：

```text
30(gz)^2≡4 (mod p),
```

只强迫 `(30/p)=+1`，不强迫 `(10/p)=+1`。例如块级数据

```text
E4=1, A4=13^2=169, C=7, q4=1183≡103 (mod120)
```

满足 `C<A4`、`chi10(A4)=+1`、`chi30(C)=+1`、`chi10(C)=-1`。这不是完整原数对，只说明中心落点不能被同一个二次特征判别误删。

## 3. CENTER-SF

由

```text
E3=A4q5eta+gCL3
```

和 `A4>C`：

```text
E3>Cq5eta.                                        (3.1)
```

乘 `E4` 并用 `E3E4=dh^2`：

```text
dh^2>CE4q5eta.                                    (3.2)
```

又

```text
U=10g^2z^2=10g^2*d*(dh^2)*v^2<n/3,
```

故

```text
n>30g^2 d C E4 q5 eta v^2.                        (3.3)
```

由 `E4=d4h4^2` 及

```text
(h4/gcd(h4,v))^2=Delta4>10g^2D25
```

得到

```text
E4>10d4g^2D25.                                    (3.4)
```

代入 (3.3)：

```text
n>300g^4 d d4 C D25 q5 eta v^2.                   (3.5)
```

第2源精度给

```text
D25*v^2*eta
 >= E2^2 epsilonE^2 M2^4 q5
 = q2^2 sigma2 q5 * (epsilonE M2^2/epsilonM)
 >= q2^2 sigma2 q5.                               (3.6)
```

因此

```text
n>300g^4 d (d4C) q2^2 sigma2 q5^2.                (CENTER-SF)
```

令 `kappa4=d4C`。由 `C=c4t4^2`：

```text
kappa4=d4c4t4^2=tau4*t4^2>=tau4>=7.
```

故还有统一版本

```text
n>300g^4d tau4 q2^2sigma2q5^2
 >2100g^4d q2^2sigma2q5^2.                        (3.7)
```

使用最小值 `g>=10,d>=7,q2>=7,sigma2>=7,q5>=31`，(3.7) 单独只给

```text
n>48,454,581,000,000,
```

弱于旧 C6 的统一入口，因此本轮不据此继续机械 CRT 放大。CENTER-SF 的真正增量是控制可无界的完整 `C`。

## 4. q5 的下一 p 进层

取当前真实 `p>=31`，令

```text
Q=p^e||q5,
n=5+Qh, j=1+Qy, k=4+Q(h-y),
U=1+Qxi,
p∤h.
```

由 `jk=(n-1)U` 精确展开：

```text
(4+Qh)xi=y(3+Q(h-y)).                              (4.1)
```

两个括号都是 `p` 单位，故

```text
vp(xi)=vp(y)=s,
vp(U-1)=e+s.                                       (4.2)
```

全近侧中 `s=vp(eta)`。

定义旧核心

```text
K =10n^2-36nU-34n+27U^2+81U+12,
H7=16(n-3)(n-4)-36(n-3)U+27U^2,
T =8(n-5)(n-4)(n-3)-(U-1)H7.
```

代入 `n=5+Qh,U=1+Qxi`，得到精确展开

```text
K =20
   +Q(30h-45xi)
   +Q^2(10h^2-36hxi+27xi^2),

H7=-13
   +Q(12h-18xi)
   +Q^2(16h^2-36hxi+27xi^2),

T =Q(16h+13xi)
   +Q^2(24h^2-12hxi+18xi^2)
   +Q^3(8h^3-16h^2xi+36hxi^2-27xi^3).             (4.3)
```

若 `s>=1`，则 `p|xi`。对 `p>=31`：

```text
K≡20, H7≡-13, T/Q≡16h (mod p),
```

三者均为单位。因此：

- `p∤L4`；
- `p∤L7`；
- `vp(T)=e`，除去原 `Q|q5` 后 `p∤L6`。

写 `ell6=L6/48,ell7=L7/48`，仍有 `p∤ell6ell7`。

并且

```text
E3C ell6 = T/(48q3q4q5).
```

由 `q3=(n-3)/3,q4=(n-4)/2,q5=(n-5)/5^E`：

```text
5^E - T/(48q3q4q5)
 =5^E[8(n-5)(n-4)(n-3)-T]/[8(n-5)(n-4)(n-3)]
 =5^E(U-1)H7/[8(n-5)(n-4)(n-3)]
 =eta ell7.                                        (4.4)
```

最后一等号使用

```text
U-1=I3A4q5eta,
H7=E3E4CL7,
q3=E3I3, q4=E4A4C, ell7=L7/48.
```

所以 (4.4) 正是原归一化和式；在 `p` 上只陈述

```text
vp(eta ell7)=s.
```

由于 `p∤ell7`，它没有给 `s` 新上界。额外工作层只是把指数输运到 `eta`，不能冒充更大的原 `q5` 源幂，也不产生 NC6 下降。

## 5. 弱精确诊断样例

取

```text
p=31,e=1,E=4,s=3,
h=5^E(2p^s+5), y=5^E p^s,
n=5+p^e h, j=1+p^e y.
```

则

```text
n=1154498130≡5130 (mod9000),
j=577200626<=floor(n/2),
vp(n-5)=1, vp(j-1)=4, vp(k-4)=1,
vp(U-1)=4,
vp(K)=vp(H7)=0, vp(T)=1,
vp(5^E-T/(48q3q4q5))=3.
```

但 `gcd(n,j)=2` 且 `(n-1)∤jk`。所以它只精确诊断局部 `p` 进恒等输运；不是当前 RES10 候选、NC6 模型或 B699 反例。
