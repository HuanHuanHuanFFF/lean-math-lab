```math
\boxed{q<2^{53}}.
```

从而

```math
\boxed{t<2^{56},\quad 12\le\rho\le55,
       \quad m<2^{60},\quad s<2^{61}.}
```

特别地，纯二桥中的全部

```math

```

以及全部

```math

```

被统一删除。这是对真正无界尾部的排除，不是继续枚举固定 `rho`。

## 三对数 Matveev 门

写 `c=3^kappa`，`eta=9+2kappa`，并定义

```math
beta=(2m)^6/(sqrt3)^eta.
```

则

```math
Gamma=n/N0
=2^(s+6rho+9) alpha^(-(48q+3)) beta^(-1),
```

且 `Gamma!=1`。这是 `Q(sqrt3)` 中的三个正实代数数 `2,alpha,beta` 的乘积。

Matveev 显式下界配合

```math
s<=144q+33,
2m<216q
```

给出

```math
log|Gamma-1|
>-23137949116800 (log q+6)(log q+7).
```

与指数小上界比较，再用精确有理常数审计，在 `q0=2^53` 处得到


且 `F(q)/q` 对 `q>1` 严格递减，故所有 `q>=2^53` 矛盾。
