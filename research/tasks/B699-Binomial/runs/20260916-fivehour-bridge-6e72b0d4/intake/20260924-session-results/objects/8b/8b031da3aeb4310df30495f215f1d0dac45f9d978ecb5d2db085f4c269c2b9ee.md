# REPORT — B699 新会话 C / C12

日期：2026-09-22。

## 1. 本轮准确结论

本轮把 C11 的正十六次核推广到两个旧 H025 尾类，得到统一、显式、有效的
绝对高度：

```text
A尾: n≡1280 (mod1800), NC6  ==> n<2^291;
B尾: n≡1530 (mod1800), NC6  ==> n<2^523.
```

更精确地，令 `alpha=n/g`：

|尾类|alpha 模板|绝对界|
|---|---|---:|
|A|`2^a`|`n<2^223`|
|A|`5*2^a`|`n<2^291`|
|B|`3^a`|`n<2^336`|
|B|`2*3^a`|`n<2^392`|
|B|`5*3^a`|`n<2^467`|
|B|`10*3^a`|`n<2^523`|

因此两个尾类内部不再存在任何无界 NC6 参数族。剩余只是上述显式有限盒；
本轮没有完成这些巨大有限末端，所以不是两个尾类的完整闭合。

## 2. 原输入与模板

固定同一个原始合法 `(n,j)`，`k=n-j,g=gcd(n,j)`。冻结 H025 合同给：

- 两尾中 `NC6=>NC5`；
- NC5 的 `alpha=n/g` 属于六模板；
- A尾 `n≡1280 mod1800` 只剩 `alpha=c*2^a,c∈{1,5}`；
- B尾 `n≡1530 mod1800` 只剩 `alpha=c*3^a,c∈{1,2,5,10}`；
- `g≥7`。

准确小部为

```text
A: q1=n-1, n-2=2*3^b*q2, q3=n-3, q4=(n-4)/4,
   n-5=3*5^E*q5;

B: q1=n-1, n-2=2^b*q2, q3=(n-3)/3, q4=(n-4)/2,
   n-5=5^E*q5.
```

所有 `q_r` 保留当前 i=6 的完整粗素数幂。

## 3. K16 的一般完整源接口

C11 的正核

```text
F16=x^2y^2(x-1)^2(y-1)^2H8(x,y)>0  (x,y≥7)
```

具有源阶

```text
r1: 8,8
r2: 3,4,3
r3: 4,4,4,4
r4: 3,3,3,3,3
r5: 2,2,1,1,2,2.
```

不使用 RES10 的十倍平方增益，只使用一般完整窗口，即得到

```text
q1^8*q2^3*q3^4*q4^3*q5*M2*Q50*Q51
    | F16(j,k)/g^4.                                  (K16-GEN)
```

其中 `M2` 是第2源中央块，`Q50,Q51` 是第5源端点/近侧块。
任一完整窗口失败时，失败粗素数已经是同一原 `(n,j)` 的 Common6 见证。

`H8` 的 l1 范数仍为 `L=1388988`，并有

```text
0<F16(j,k)<(L/256)n^16.
```

Bernoulli 乘积给：

```text
A尾: 2*g^4*M2*Q50*Q51*q2^3*q5 < L*n;
B尾: 16*g^4*M2*Q50*Q51*q2^3*q5 < 81*L*n.
```

所以丢掉附加正整数后，

```text
A尾: g^4*q2^3*q5 < (L/2)n;                           (KA)
B尾: g^4*q2^3*q5 < (81L/16)n.                        (KB)
```

## 4. A尾付款矩阵

写 `alpha=c*2^a,c∈{1,5}`，令 `X=n-5`。真实三平移为

```text
n=2^a*(c*g),
n-2=3^b*(2*q2),
n-5=5^E*(3*q5).
```

BFT 给

```text
max(cg,2q2)>X^(57/200),
max(cg,3q5)>X^(129/500).
```

差2没有显式例外；差5的三个例外大分量
`1029,1215,30618` 均不在 `1280 mod1800`。

四种付款选择中，`g^4q2^3q5` 的最弱增长指数是

```text
3*(57/200)+129/500=1113/1000>1.
```

令

```text
D_A(c)=max(8c^4,24).
```

逐付款分支统一有

```text
g^4q2^3q5 > X^(1113/1000)/D_A(c).
```

与 (KA) 联立，再用 `X≥n/2`，得到精确整数界

```text
n^113 < 2^113 [D_A(c)L]^1000.                        (A-HEIGHT)
```

纯整数重放给：

```text
c=1: D_A=24   ==> n<2^223;
c=5: D_A=5000 ==> n<2^291.
```

## 5. B尾付款矩阵

写 `alpha=c*3^a,c∈{1,2,5,10}`。真实三平移为

```text
n=3^a*(c*g),
n-2=2^b*q2,
n-5=5^E*q5.
```

BFT 给

```text
max(cg,q2)>X^(57/200),
max(cg,q5)>X^(27/125).
```

最弱付款指数是

```text
3*(57/200)+27/125=1071/1000>1.
```

逐付款分支统一有

```text
g^4q2^3q5 > X^(1071/1000)/c^4.
```

与 (KB) 联立：

```text
2^2929*n^71 < [81L*c^4]^1000.                       (B-HEIGHT)
```

纯整数重放给模板表中的四个界，最弱为 `c=10` 的 `n<2^523`。
