# FAILURES — 正规混合域仍开放

1. 本轮只排除四个准确的系数退化域。不能将普通混合图、d20、整个m2或i3称为已闭。
2. 普通比例图与REG5五参数图均探索过有理消元，但没有产出可验收的特征零证书。保留日志的两次REG5运行使用120秒终止器，未留存其退出码；只能断言它们没有生成证书，不能伪造退出状态。
3. 系数位数上限的试验会跳过部分归约；其无结果不证明无解。本轮正式五份证书全部使用无系数截断的QQ运算生成，并另由标准库逐项核验。
4. 仅最高混合残差相容不充分；本轮每个已闭图都保留完整十条原残差，只有恒零/唯一解出的高项被显式消去。
5. 正规系数弱模型：H=x³+1，ell=1,eta=2,nu=0,a=1，t=2；它满足四个非零条件，但E9=-17/4。不是混合解、NC3或原题反例。
6. 早期小图检查器把用于单独边界核验的局部变量w遮蔽了目标式中的w，导致“wrong target”。源方程重建及节点线性组合没有变化；修复局部变量命名后，小证书与整批冷重放通过。两个实际日志保留，未将失败流程标为PASS。
7. u=1最初获得183节点约26MiB的冗余证书，也经过检查；最终采用三参数小图的129节点证书。归档不重复附冗余DAG。
8. 辅助仿射规范、比例变换和平方根截断没有产生新原输入，不能称NC保持下降。
9. 外部UU-INT和NC3=>4|n仅作为冻结合成边界采用，没有本轮外部独立复核或Lean。
