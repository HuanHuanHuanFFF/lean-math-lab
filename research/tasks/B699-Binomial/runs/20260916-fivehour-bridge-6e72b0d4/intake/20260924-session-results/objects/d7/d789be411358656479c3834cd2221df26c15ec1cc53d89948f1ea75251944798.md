# B699 D / i=3 · 本轮报告

日期：2026-09-22

## 0. 范围

只在同一个原始合法 `(n,j)` 的规范最小临界两底、真实 `mu=1`、平衡 `D_v=D_W=y` 必要核心内工作。保留：

- 完整平方范数；
- `P=p0^a, Q=q0^r` 为不同奇素数的完整幂；
- `n=c*2^s, c in {1,3}`；
- 原始 `(n,j)` 不替换、不拼接；
- BRIDGE4096 的全部旧条件。

没有修改仓库。本包不是 Lean，不是完整 `i=3`，也不是完整 B699 闭合。

## 1. 本轮结论

### 1.1 POWER 与平方范数的精确依赖

令 `Q=d+v`，沿用 Round 12 的 `L,R`。先有简化：

```math
L=(3d+4v)Q^5-2d^2v.
```

并有恒等式

```math
vL^2+d^3R=Q^6(d+4v)^2(Q^5-d^2).
```

完整平方范数写成

```math
Q^5-d^2=vY^2.
```

故

```math
L^2+d^3R/v=(Q^3(d+4v)Y)^2.
```

另一方面 `n=c2^s` 将 POWER 精确改写为

```math
R=vn(d^3n-2L).
```

所以其关于 `n` 的判别式已经由原平方范数强制为平方。结论：继续把“POWER 奇部”和同一个平方范数做普通 resultant，并不会产生独立的第二约束；这条低收益路线本轮停止。

### 1.2 同一原输入的 SPLIT5 投影

完整平方目标可写成

```math
Y^2=v^4+5dv^3+10d^2v^2+10d^3v+5d^4+d^2W,
```

其中 `v=Ay, W=By, AB=3(d-1)`，且 `d^2+d+1=3y^2`。
模 `y` 得

```math
Y^2 = 5d^4 (mod y).
```

又 `gcd(d,y)=1`。利用同一原输入

```math
n-2=PQ nu,
Q=d+v,
P=Q+hv,
Y=d nu-Q^2,
```

可得

```math
Y=d^2(n-3) (mod y).
```

于是得到新的统一接口

```math
(n-3)^2 = 5 (mod y),
```

以及

```math
n/2=((n-2)/2)^2 (mod y).
```

它同时保留 `n=c2^s`：`c*2^(s-1)` 必须是模 `y` 的平方。

### 1.3 Pell 素因子支持

令

```math
U_k+X_k sqrt(3)=(2+sqrt(3))^k.
```

平衡 Pell 参数满足 `t=8q+1`，并且

```math
y=U_t/2.
```

对任意奇素数 `ell | U_t`（`t` 奇），可证明

```math
ell = 1 (mod 12).
```

再由 `(n-3)^2=5 (mod ell)`，有 `(5/ell)=1`。因此每个 `ell | y` 必须满足

```math
ell = 1 or 49 (mod 60).                  [SPLIT60]
```

若 `s` 为偶数，则 `n/2=c*2^(s-1)` 为平方又迫使 `(2/ell)=1`，从而进一步有

```math
ell = 1 or 49 (mod 120).                 [SPLIT120-even]
```

### 1.4 BAD-RANK 一般筛

若奇数 `r | t`，且存在奇素数 `ell | U_r` 不满足 SPLIT60，则该平衡状态不可能存在。因为 `t/r` 为奇数，`ell | U_t`，与 SPLIT60 冲突。

本轮给出八个确定性种子：

| `r` | `ell` | `ell mod 60` | 排除的 Pell 行 `q mod r` |
|---:|---:|---:|---:|
| 23 | 277 | 37 | 20 |
| 31 | 373 | 13 | 27 |
| 47 | 1693 | 13 | 41 |
| 59 | 31153 | 13 | 22 |
| 61 | 733 | 13 | 38 |
| 67 | 3217 | 37 | 25 |
| 71 | 853 | 13 | 62 |
| 101 | 1213 | 13 | 63 |

每行均精确验证：`ell` 为素数、`U_r=0 (mod ell)`、`5^((ell-1)/2)=-1 (mod ell)`，且表中同余等价于 `r | 8q+1`。

因此 BRIDGE4096 中上述八个 `q` 算术级数全部退出；相同排除也作用于平衡 odd--odd 分支。

这些 `r` 两两互素，八个种子在形式 Pell 行参数上删除的精确自然密度为

```math
397149830551 / 2519393030551
= 0.1576371077... .
```

这只是进入 `m,P,Q` 等后续恢复前的行参数密度，不冒充真实 NC3 候选密度。

## 2. 真正消灭的无界域

对每个固定 `rho>=12`，写 `q=2^(rho-3) w`，`w` 奇。对每个表中 `(r,a)`，CRT 给出无限多个奇 `w` 同时满足

```math
2^(rho-3) w = a (mod r),
2^(rho-3) w = 0 (mod 3).
```

故对应排除域在 `rho` 与 `q` 上都无界，并横跨每一层 `rho>=12`；它不是有限层扫描。

最小的两个明确无界删除为

```math
q=20 (mod 23),
q=27 (mod 31).
```

任何满足其余 BRIDGE4096 条件的真实状态，只要落入其中之一，就被完整平方范数直接否定。

## 3. 额外的奇偶压缩

SPLIT120-even 还给出条件压缩。例如：

- `5 | t`（等价 `q=3 mod 5`）时，`181 | U_5 | U_t`，而 `181=61 mod120`，所以 `s` 必为奇数；
- `29 | t`（等价 `q=18 mod29`）时，`349 | U_29 | U_t`，而 `349=109 mod120`，所以 `s` 必为奇数。

这不是整行排除，但把这些无界行的 `s` 偶分支全部删除。

## 4. 仍剩无界参数

没有得到 `rho`、`q` 或 `t` 的绝对界。剩余 BRIDGE4096 必须避开 BAD-RANK 筛，并满足其 `y=U_t/2` 的全部素因子落在 `1,49 mod60`；若 `s` 偶，则落在 `1,49 mod120`。以下仍无界：

```text
q,t,rho,m,d,y,A,B,h,P,Q,v,nu,n,s,
P/Q 的原底素数与完整指数，odd--odd 的两侧奇部分。
```

固定 `q` 至多一个 POWER 乘子候选的旧结论保持不变。

## 5. 失败边界

1. **未统一消灭 `rho>=12`。** SPLIT60 是必要支持条件；尚未证明每个允许的 `t=1 mod4096` 都含一个 BAD-RANK 因子。
2. **POWER + 平方范数判别式路线代数冗余。** 需再接 `m|9u`、完整 `P/Q` 素数幂、或新的独立局部/全局输入。
3. **八个种子不是有限覆盖。** 例如令 `q` 同时为这些 `r` 的倍数即可避开八个被排余类；所以 15.76% 行筛不能外推成全部高桥。
4. **辅助素数不是原题共同见证。** 它们仅否定必要平方恢复。
5. **未构造新 `(n,j)`，未做 NC3 保持下降。**

## 6. 下一可证伪目标

优先把 VROW1 的唯一乘子 `m_*(q)` 接到 SPLIT60：寻找一个由 `m|9u` 或完整 POWER 奇部强制的 BAD-RANK 除数 `r|t`。若失败，则在 odd--odd 分支中分别对两侧奇缺额寻找同类 rank/support 强制，而不是继续按 `rho=12,13,...` 枚举。
