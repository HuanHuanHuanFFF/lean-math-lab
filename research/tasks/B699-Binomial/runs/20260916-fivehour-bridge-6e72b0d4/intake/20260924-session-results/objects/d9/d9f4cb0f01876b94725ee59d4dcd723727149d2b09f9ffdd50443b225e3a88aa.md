# REPLAY

Requirements:

- Python 3.10+
- SymPy
- a C++17 compiler (`g++` by default)
- approximately 100 MB free working space; the replay itself stays well below the earlier full-grid ledger memory use.

Run from any directory, using an output path that does not yet exist:

```bash
bash replay.sh /absolute/new-output-directory
```

The script:

1. compiles two independent eight-factor Bellman implementations;
2. regenerates the 2,035-state frontier;
3. reconstructs the two positive-E states and one-source-unit payoff;
4. runs q3/q4/q5 at primes 32749 and 32719;
5. receives all q3/q4 low-rank endpoints exactly over Q;
6. verifies ODD-SAT3–5 and EDGE8;
7. compares deterministic outputs byte-for-byte with `certificates/`.

Expected final line:

```text
PASS_FULL_ODD_SAT3_5_EDGE8_REPLAY
```

The replay does not use the network or write to a Git repository.
