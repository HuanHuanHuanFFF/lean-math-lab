# FAILURES · Round25

## 1. 未取得一般odd–odd闭合或新绝对高度
排空的是正235光滑缺陷及两条7尾族。V必须含ell≥7不限制该prime或其完整指数的一般上界；A的1/3至20/47走廊没有改善。不能把固定48值的有限化写成一般V有限化。

## 2. 真Θ范数并不自动吸收源幂
NormTheta含交叉项。精确同余NormTheta≡7203N0^7 modV使其与V的gcd固定受控。
若某个ell≥11整除V，结论反而是ell不整除NormTheta。没有证明原P/Q整除V。
模11两份投影分别有11|P、11|Q而NormTheta=4、7 mod11。它们通过同源Pell、AB、线性nu、完整范数、DIVNORM和n的2幂投影，故局部自动传递规则不成立；缺正整数全局恢复、原P/Q完整幂和(n,j)，不否定可能更强的全球结论。

## 3. 一般7-primary剩余仍开放
(q,V)=(99,9·7^22344)通过15个已列辅助素数的必要V像。不同素数处允许不同模p模型，未共同恢复整数A,B,C,h或原(n,j)。不是NC3、不是原题反例、不是通过全部历史消费者的候选。
正式交付只把两条完整7指数族登记为闭合，不把探索中其他必要状态筛减混称全球结论。

## 4. 有限周期不是有限q扫描
证书完整性依赖逐一核实gamma=alpha^8的首返周期，以及7在辅助域内的乘法阶。2维证书不能把e=0类仅解释成指数0：它也覆盖所有正的周期倍数。本轮验证了这一点。
