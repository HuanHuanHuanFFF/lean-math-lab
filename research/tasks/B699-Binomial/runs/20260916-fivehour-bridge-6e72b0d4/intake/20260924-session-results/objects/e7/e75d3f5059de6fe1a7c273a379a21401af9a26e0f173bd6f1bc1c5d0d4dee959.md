## 重放

依赖 Python 3.10+ 标准库和支持 C++17 的 g++；主重放不依赖 SymPy、NumPy、SciPy、FLINT、网络、Git 或 Lean。

```bash
python3 -B code/replay.py --out /absolute/path/to/a-new-directory
```

输出目录必须不存在。默认重生成六批完整根门（两种锚点）、两素数全部秩记录、独立子式、完整账本、奇偶价格证书以及6项损坏测试。默认与包内39个确定性证书逐字节比较。

仅重放阶段也可使用 `--phase geometry` 或 `--phase ledger`；阶段通过不冒称整轮通过。日志含实际运行时间，因此不作字节一致比较。
`verification/FULL_REGENERATION_RECEIPT.json` 是首次完整重生成记录；最终ZIP的完整重放与ZIP哈希绑定见包外同名 `.CLEAN_REPLAY_RECEIPT.json`。

`discovery/` 是本轮探索快照，不是正式接收入口，里面可能有当时的绝对工作目录；不需要执行它们。它们不承担当前末端穷尽性。
`verification/negative_tests/` 中的损坏样本是故意构造的负例，不是有效数学证书。

`inputs/` 保留所采用的前轮字节，不把历史报告重新计算所得等级升级。当前173状态不是实际曲线，也不是原题有限候选点。
