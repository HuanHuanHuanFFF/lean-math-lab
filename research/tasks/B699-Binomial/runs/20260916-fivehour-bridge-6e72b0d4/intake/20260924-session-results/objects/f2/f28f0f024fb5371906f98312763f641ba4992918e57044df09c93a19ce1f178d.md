# B699 Pro A / i=9 — ODD-SAT3–5 与同一固定 G 的 EDGE8

日期：2026-09-22。范围：冻结 K152 构造中的同一个固定非零整数多项式 `G`。
本轮未修改、提交、推送或发布仓库；没有 Lean 核验或外部独立全链数学审读。

## 1. 实际终点

采用上一轮已经取得的同一固定 `G` 的

```text
|C_G| <= 8
```

其中 `C_G` 是不同本原 `Q[N,X]`-不可约、能够承载合法 `400 | n` 的 NC9 点的因子集合。
本轮新增等号结构：

```text
|C_G| = 8  ==>  E = 0.
```

因此达到八分量时

```text
D(G) = 305,
2 h + V = 305,
```

并且剥去六条源竖线全部幂后的 `Gbar` 的每个非恒定不可约因子均满足 `D = 2e`。
换言之，本轮得到 **EDGE8**。

这是一个真实的无限代数等号域删除：同一个固定 `G` 拥有八个不同可载因子、同时仍含正加权余量的整个域被排除。
本轮没有得到 `COVER7`，没有排空原始 NC9 的全部 `(n,j)`，也没有闭合完整 `i=9` 或 B699。

## 2. 完备八分量必要账本

沿用冻结源阶、B22/S/L 特殊签名以及上一轮的平衡因子门：

- 饱和 `25 <= e <= 31` 至少支付两份对角 `kappa`；
- 饱和 `32 <= e <= 42` 至少支付一份对角 `kappa`；
- `e >= 43` 暂按零源费用的自由高次类放松；
- 其余缺重 1、2、3、至少 4 的类别采用冻结的完整弱签名。

重新遍历全部 2,035 个竖直状态。对正余量可载因子作最有利放松：每个只收

```text
e = 3, source cost = 0, excess cost = 1.
```

这只会扩大可行集，因为任何真实正余量因子都有 `e >= 3`、非负源费用，并至少消耗一份 `E`。

两种精确 Bellman 实现完全一致：

1. 116 个 Pareto 签名的递归记忆化求解；
2. 全部 460 个去重原始签名、逆序枚举的递归求解。

八分量必要前沿为：

```text
456 states = 454 states with E=0 + 2 states with E=1.
no state with E>=2 survives.
h ranges from 47 to 152.
```

两个正余量状态恰为：

```text
state 1980:
  h=145, E=1,
  v=(3,3,3,2,1,2),
  d=(0,0,3,0,0,3),
  p=(0,1,0,1,0,0),
  cap=(0,1,6,1,0,6).

state 1999:
  h=147, E=1,
  v=(2,2,2,2,1,1),
  d=(0,0,2,2,2,0),
  p=(0,0,0,1,0,1),
  cap=(0,0,4,5,4,1).
```

因为总余量只有 `E=1`，任何实际八因子分解若落入其中，都必须恰有一个正余量可载因子，且它满足

```text
D - 2e = 1.
```

在状态 1980，七个平衡因子的最低总 X 次数为 140，因此正余量因子必须有 `e <= 5`；
在状态 1999，该最低次数为 144，因此正余量因子必须有 `e <= 3`。
结合一般 `e >= 3`，只需处理 `e=3,4,5`。

## 3. 新几何接口 ODD-SAT3–5

令 `H` 为可载的 `Q[N,X]`-不可约因子，满足

```text
D = 2e+1,
e in {3,4,5},
mu_r = e  for r=3,...,8,
z >= 14,
kappa_4 = kappa_6 = kappa_8 = 0.
```

本轮证明这样的 `H` 不存在。等价地：上述小 X 次数的奇权正余量因子必须支付至少一单位真实源费用。

### e=3，D=7

六行重数分拆、九条源直线、`z>=14` 与全部普通/加权 jet 后，在模 32749 和模 32719 下都留下相同 16 个低秩配置。精确有理接收得到：

- 4 个系统在 `Q` 上实际满秩；
- 11 个一维空间的唯一多项式明确可约；
- 1 个固定多项式未由几何因式分解删除，但其本原整数系数 `l1=987183<2^20`，权次为 7。

冻结的小系数原输入消费者适用于权次不超过 11、`l1 <= 2^24980` 的非零整数式；因此这个唯一固定例外不能在合法 NC9 点取零，不能成为可载因子。

### e=4，D=9

两个素数下均留下相同 17 个低秩配置。精确有理秩全部为 29，故每个解空间一维；17 个唯一多项式全部具有非平凡有理因子。因此不存在不可约候选。

### e=5，D=11

除源直线、`z` 和 jet 外，加入首两项系数的必要相容性。若

```text
H = A(N) X^5 + B(N) X^4 + ...,
deg A <= 1, deg B <= 3,
```

则六行饱和时的根和 `S_r` 满足 `A(r) S_r = -B(r)`；所以六个 `A(r)S_r` 来自同一个三次多项式。程序完整检查相应两个四阶差分，并排除 `A(r)=0` 的竖线因子分支。

修正后的完整遍历在两个素数上统计一致：

```text
nodes       75,706
row-8 tests 19,447
line rejects 1,051,900
z rejects       10
root-sum rejects 35,215
leading rejects   3,058
full-rank rejects 824,561
residual             0
```

因此不存在特征零候选。

## 4. ODD-SAT3–5 如何关闭两个正余量状态

若正余量因子源费用为零，状态 1980 和 1999 分别允许最低总次数 143 和 147，正是粗账本留下它们的原因。

ODD-SAT3–5 证明该因子必须在某一行支付至少一单位源容量。仍对它采用最有利的 `e=3`，逐坐标重算七个平衡因子的 Bellman 下界：

```text
state 1980, h=145:
  pay row 4 -> total >=151
  pay row 5 -> total >=167
  pay row 6 -> total >=155
  pay row 8 -> total >=151

state 1999, h=147:
  pay row 5 -> total >=175
  pay row 6 -> total >=157
  pay row 7 -> total >=164
  pay row 8 -> total >=157
```

两状态均严格超过可用 X 次数，故全部退出。完整必要账本已证明没有其它正 `E` 八分量状态，于是得到 EDGE8。

## 8. 失败边界与下一步

- 没有证明 `COVER7`；454 个 `E=0` 八分量必要状态仍存。
- ODD-SAT3–5 只处理 `D=2e+1`、`e=3,4,5`、六行饱和且零切向费用的分支；未证明一般奇权饱和定理。
- q3 的唯一非可约删除例外依赖冻结小系数消费者，不是纯几何分类。
- 账本是完备必要放松，不恢复实际系数或不可约因子。

EDGE8 的价值在于：八分量等号支现在也能合法使用 `E=0` 的同一-G首一系数结构。下一项最便宜的可证伪检查是：

1. 对 454 个 `E=0` 状态重新枚举八因子的真实 B22/S/L 特殊选择；

3. 接入同一个 `Gbar` 的二次根和、四次第二基本对称和及更高 TRACE；
4. 测试能否形成新的 EDGE8 高度门或进一步得到 COVER7。

不应先机械继续刷高次 KSAT；当前主要未知域已经转为低/中次混合因子和同一-G系数一致性。
