## 本轮直接采用

### ODD-END

```math
v2(B)=2\quad\text{或}\quad v2(A)=1,\ v2(B)=rho.
```

### RATSPLIT

令

```math
lambda=2^{v2(B)-1}A/X=a/b,
```

则

```math
x=bx1,\quad9U=au1,
```

```math
A=2^{rho+1-v2(B)}a x1,
\quad
B=2^{v2(B)-1}b u1.
```

odd--odd 强制 `b>1`。

比值：

```math
v2(B)=2: lambda<75;
```

```math
v2(B)=rho: lambda<27*2^(rho-1)<=108q.
```

### POLYHEIGHT

```math
H(lambda)<=q  => q<2^53,
```

```math
H(theta)<=q, theta=x1/u1 reduced => q<2^53.
```

任意固定 `K` 的 `q^K` 高度子域均可有效有限化。因此若要继续 Matveev 路线，真正缺口仅是：证明 `b` 或互补分配高度被某个固定多项式控制。

### UNITARY-5

共享奇素数 `p!=5` 必须 `p=1 or4 mod5`。所有 `p=2 or3 mod5` 的完整幂不得拆分。共享 5 必须

```math
v5(B)=1,
B/5=4 mod5.
```
