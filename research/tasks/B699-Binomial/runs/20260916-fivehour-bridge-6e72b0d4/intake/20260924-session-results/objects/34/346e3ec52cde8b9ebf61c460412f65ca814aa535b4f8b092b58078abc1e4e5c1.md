# REPORT — B / i3：NONIC-REDUCE6

日期：2026-09-22。范围仅为 B699 的 `i=3`。

## 1. 最强新增结论

设

```text
f∈Z[X]，系数非负，f(0)=2，deg f=9；
H=f(1)；
T=p^e 为奇素数幂；
T≥[2(H+2)]^22；
n=f(T) 为偶数。
```

假设同一个原始合法 `(n,j)` 满足 NC3。采用冻结的大进制提升与 `OCTIC-ALL` 上游一般接口后，第一源的两个完整分配块只能为 `4+5`。选择 `deg U=4,deg V=5`，写

```text
f−1=UV，σ=VW，U|VW−1，
W(W−U)(W−2U)=(UV−1)R。
```

本轮证明：

1. `t=0` 与 `t=1` 的全部边界分支不可能；
2. 内部 `0<t<1` 时 `deg R=3`，并有槽权公式
   ```text
   d1+2d2=8−9t；
   ```
3. `R` 全部进入一个槽的三个单槽型全部不可能；
4. `R` 分成三个线性因子并分别进入槽 `0,1,2` 的 `1+1+1` 型全部不可能。

因此 GATE9 下任何可能 NC3 只剩六个定向 `2+1` 槽型：

```text
(d0,d1,d2)  t
(2,1,0)     7/9
(1,2,0)     2/3
(2,0,1)     2/3
(0,2,1)     4/9
(1,0,2)     4/9
(0,1,2)     1/3
```

这里 `dr` 是完整三次商中进入槽 `W−rU` 的因子总次数。六项仍是带无界参数的族，不是六个整数输入。

本轮结论命名为 **NONIC-REDUCE6**。它是严格的 frontier reduction，不是 `NONIC-ALL`、完整 `i=3` 或完整 B699。

## 2. 真正消灭的无界域

删除了 GATE9 中：

- 全部首项边界；
- 三个单槽三次商域，包括不可约、可约及重根三次商；
- 全部三线三槽域。

这些域中 `f` 的系数、工作奇素数、指数、`T,n,j` 都可无界，所以不是有限扫描。

## 3. 单槽域的终端

DIFF 将任意单槽型统一压成

```text
A=x^3+a x^2+b x+c，
C=4(2−3k)x/9，
U=x^4+28a x^3/27+10b x^2/9+4c x/3+d。
```

二阶同余最高四个余式系数给出：

- `a=0` 时强迫 `b=c=d=0`，违反 `gcd(U,R)=1`；
- `a≠0` 归一为 `a=1` 后，唯一形式点为
  ```text
  b=8/27，c=160/6561，d=256/531441。
  ```

三个槽号的其他有理数字原点均由符号障碍排除。唯一正系数外壳可规范为整数多项式

```text
U=1+60Y+540Y²+1512Y³+1296Y⁴，
V=1+183Y+3060Y²+15444Y³+29808Y⁴+19440Y⁵，
W=40Y+432Y²+1296Y³+1152Y⁴。
```

原整数尺度必为 `Y=mX,m∈Z_{>0}`。置 `y=mT`，则

```text
F(y)−2=3^5 y(2y+1)
        (72y³+72y²+18y+1)
        (720y⁴+864y³+324y²+40y+1)。
```

对应原端点 `Σ=VW` 的 `Σ,Σ−1,Σ−2` 精确分解表明：按 `y mod 3`，合法槽的 3 进赋值总比 `v3(F(y)−2)` 少整整 5 层。完整第二源 `3^E` 因此不能进入任一槽，单槽正外壳也退出。

## 4. `1+1+1` 的终端

将三个有理根按槽规范为 `0,1,q`。generic 图 `q≠0,1,10/9` 只剩两个线性参数 `A,B`。商为常数的低/高系数先给一个线性式 `M=0`。若其 `A` 系数

```text
D(q)=6561q²−1274q−368
```

为零，则判别式 `11280868` 不是平方；否则消去 `A,B` 后得到必要八次式 `P8(q)=0`。`P8` 模 17 的全部值为

```text
12,12,2,3,6,6,9,3,14,5,16,2,10,4,1,2,12，
```

无零，故无有理 `q`。

特殊图 `q=10/9` 化为二次式

```text
354294B²−127705005B−164557100=0，
```

其模 7 值为 `6,1,2,2,1,6,3`，同样无有理解。
