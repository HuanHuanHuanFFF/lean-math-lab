# REPLAY · Round27

## 环境
Python 3（支持内置模逆元）；SymPy版本以ENVIRONMENT.json为准。除symbolic_verify.py外全部只用标准库。代码不使用网络、随机数、仓库或证明助手。

## 完整本轮重放

```bash
bash replay.sh
```

该脚本先检查SHA256SUMS，在mktemp临时目录中重新生成两份证书，执行显式恒等式检查和不同算法验证，并要求新证书、replay.json和symbolic.json逐字节等于已交付版本。临时目录退出时删除；不会写入sources或原证据文件。

局部生成器枚举h并检查EH；核验器枚举nu，线性恢复h，检查DIVNORM和原范数。缺陷同时由原Z/F定义交叉核验，保留所有零模因子。p=3,5,7的分类为完整有限环，不是局部抽样。

boundary_search.py的确定性CRT搜索只重新构造一个有限模像相容的失败对象；它不搜索或证明原题反例。

## 定向入口

```bash
python -B code/generate.py --out /tmp/r27-certificate.json
python -B code/verify.py --certificate /tmp/r27-certificate.json --out /tmp/r27-replay.json
python -B code/symbolic_verify.py --out /tmp/r27-symbolic.json
python -B code/boundary_search.py --out /tmp/r27-boundary.json
```

没有重跑旧的q小基例、七主部或BRIDGE campaign。重放PASS不重证NC3进入规范核心的历史桥，也不等于Lean或外部独立数学审读。
