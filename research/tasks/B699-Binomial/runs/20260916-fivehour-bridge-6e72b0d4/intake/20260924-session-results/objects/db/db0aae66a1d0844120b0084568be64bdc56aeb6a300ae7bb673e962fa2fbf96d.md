## 结论

对任意自然数 `n,j`，若

```
n mod 1800 ∈ {1280,1530}, 7≤j≤floor(n/2),
```

则存在同一个素数 `p≥7` 同时整除 `C(n,6)` 和 `C(n,j)`。

第2/5源允许任意混合，不假设 RES10、十倍平方、指定 g 或粗素数支持。
这是两个准确模类的整行结论，不是一般 i=6 或所有 H025 位置族闭合。
