## 4. 精确互补恒等式

第一完整源给

```text
U=j(n-j)/(n-1) ∈ Z_{>0}.
```

目标壳给

```text
q2|U,
q5|(2U-3).
```

写

```text
U=q2*R,
2U-3=q5*h,
s2=(n-2)/q2,
s5=(n-5)/q5.
```

直接消元得到某个整数 `ell`：

```text
s2-2R=ell*q5,
s5-h=ell*q2.
```

合法域给 `U<(n-2)/2`，所以 `ell>0`。两尾中 `s2` 偶、`q5` 奇，
故 `ell` 偶，因而 `ell≥2`。于是

```text
q2<s5/2,
q5<s2/2.                                            (COMPLEMENT)
```

代入准确小部：

```text
A:
  2*3^(b-1) q2 - 5^E q5 = 1,
  q2 < 3*5^E/2,
  q5 < 3^b;

B:
  2^b q2 - 5^E q5 = 3,
  q2 < 5^E/2,
  q5 < 2^(b-1).
```

因此固定 `(b,E)` 后，A尾的 `q2` 只有至多两个模 `5^E` 代表；
B尾的 `q2` 只有至多一个代表；`q5` 随后唯一恢复。

结合高度、完整小部和尾类同余，恰剩：

```text
A: 96个原行 n;
B: 24个原行 n.
```

这是由证明界定的完整有限末端，不是任意扫描范围。

## 5. 两套独立完整 CRT 末端

对每个候选 `n`，完整分解

```text
q_r=(n-r)/s6(n-r), r=0,...,5.
```

所有质因子均以完整素数幂保留。NC6 在原源层必须满足：

```text
r0: j mod p^e =0;
r1: j mod p^e ∈{0,1};
r2: j mod p^e ∈{0,2};
r3: j mod p^e ∈{0,1,2,3};
r4: j mod p^e ∈{0,1,2,3,4};
r5: j mod p^e ∈{2,3}.
```

其中 r2/r5 正是本轮源壳；其他行保留全部允许槽。

证据包运行两个独立枚举器：

1. 按完整 prime-power 模数从大到小递归 CRT，并作区间剪枝；
2. 先在每个 `q_r` 内构造整行允许剩余类，再按六个行块做 CRT。

结果：

```text
A候选行: 96
B候选行: 24
算法1合法j终端: 0
算法2合法j终端: 0
```

共保存696个不同粗整数的完整分解，涉及1029个不同质数；
最大质数为 `1345109642766796877<2^64`。重放用确定性64位
Miller–Rabin基组重新证明全部质数，再重建两套枚举。

因此最坏源分配壳完整关闭。
