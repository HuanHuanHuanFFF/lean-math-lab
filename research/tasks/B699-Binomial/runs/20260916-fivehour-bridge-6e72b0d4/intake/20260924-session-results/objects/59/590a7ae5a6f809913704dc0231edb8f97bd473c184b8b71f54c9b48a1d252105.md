# Replay

```bash
python3 evidence/replay.py
```

The replay checks exact polynomial identities, deterministic primality for all seed primes, Pell-coordinate divisibility, quadratic characters, excluded q residues, and CRT compatibility with every sampled `rho=12..32`. The all-rho CRT statement itself is proved symbolically in `PROOFS.md`; samples are regression checks, not the proof.
