# PROOFS · Round 15 CZ-GCD 平衡核心绝对有限化

## P0. 冻结前置

固定同一个原始合法 `(n,j)`，处于规范最小临界两底、真实 `mu=1`、平衡 `D_v=D_W=y` 必要核心。采用：

```math
n=c2^s,
\qquad c\in\{1,3\},
```

```math
y=U_t/2,
\qquad U_t+X_t\sqrt3=(2+\sqrt3)^t,
\qquad t=8q+1,
```

```math
y\mid (n-3)^2-5,
```

以及 Round 14 的

```math
(t-5)/2\le s\le18t+15.                 \tag{H}
```

Round 13 还证明：每个奇素数 `ell|y` 都满足

```math
ell\equiv1\text{ or }49\pmod{60}.       \tag{S60}
```

因此这些素数在 `Q(sqrt3,sqrt5)` 中完全分裂。

## P1. 固定有限生成群

置

```math
K=\mathbf Q(\sqrt3,\sqrt5),
\quad \alpha=2+\sqrt3,
\quad \delta_\pm=3\pm\sqrt5.
```

对真实状态定义

```math
u_t=-\alpha^{2t},
\qquad z_\pm=\frac{n}{\delta_\pm}.
```

固定 `c` 与符号后，

```math
(u_t,z_\pm)
=(-1,1)(\alpha^2,1)^t(1,2)^s(1,c/\delta_\pm),
```

故它属于固定有限生成子群

```math
\Gamma_{c,\pm}
=\langle(-1,1),(\alpha^2,1),(1,2),(1,c/\delta_\pm)\rangle
\subset\mathbf G_m^2(K).                \tag{1}
```

取 `S` 包含全部无穷位及 `2,3` 上方的有限位，则这些坐标均为 `S`-units。

## P2. 每一对均乘法独立

假设存在整数 `a,b`，使

```math
u_t^a z_\pm^b=1.                         \tag{2}
```

令 `tau` 固定 `sqrt5`、发送 `sqrt3 -> -sqrt3`。于是

```math
tau(nu_t)=-\alpha^{-2t},
\qquad tau(z_\pm)=z_\pm.
```

把 `(2)` 除以其 `tau` 共轭，得到

```math
\alpha^{4ta}=1.
```

`alpha>1` 不是单位根，所以 `a=0`。随后 `z_±^b=1`。在实嵌入下 `z_±>0`，且整数 `n` 不可能等于 `3±sqrt5`，所以 `z_±` 不是单位根，故 `b=0`。

因此每个 `(nu_t,z_±)` 都是乘法独立点。

## P3. 广义 gcd 的定义与外部上界

对 `x,z in K` 定义

```math
\mathcal G_K(x,z)
=-\sum_{w\in M_K}\log^-\max(|x|_w,|z|_w).             \tag{3}
```

Corvaja--Zannier 的 Corollary 1 给出：对固定有限生成群 `Gamma` 与任意 `epsilon>0`，除有限多个乘法独立点外，

```math
\mathcal G_K(u-1,v-1)
<\epsilon\max\{h(u),h(v)\}.                            \tag{CZ}
```

本轮分别在四个固定群 `Gamma_(c,±)` 上使用 `(CZ)`。

## P4. 精确同源因子

由

```math
U_t=(\alpha^t+\alpha^{-t})/2,
\qquad U_t=2y,
```

有

```math
\alpha^{2t}+1=2U_t\alpha^t=4y\alpha^t.
```

因此

```math
u_t-1=-(\alpha^{2t}+1)=-4y\alpha^t.                   \tag{4}
```

另外

```math
(n-\delta_+)(n-\delta_-)
=n^2-6n+4
=(n-3)^2-5.                                            \tag{5}
```

由冻结同余，`y` 整除 `(5)` 的右侧。

## P5. 局部估值合计保留完整 y

固定 `ell^e || y`。由 `(S60)`：

- `ell notin {2,3,5}`；
- `ell` 在 `K` 中完全分裂；
- 对每个 `p|ell`，标准归一化权重为 `1/4`。

由 `(4)` 且 `alpha` 是单位，

```math
ord_p(nu_t-1)=e.                                       \tag{6}
```

由 `(5)`，

```math
ord_p(n-\delta_+)+ord_p(n-\delta_-)\ge e.             \tag{7}
```

`delta_+delta_-=4`，所以二者在 `p` 上均为单位，且

```math
ord_p(z_\pm-1)=ord_p(n-\delta_\pm).                   \tag{8}
```

由 `(6)--(8)`，

```math
min(ord_p(nu_t-1),ord_p(z_+-1))
+min(ord_p(nu_t-1),ord_p(z_--1))\ge e.                \tag{9}
```

把 `(9)` 乘归一化局部权重 `(log ell)/4`，并对 `ell` 上方四个素理想求和，得到 `e log ell`。再对所有 `ell^e||y` 求和：

```math
\boxed{
\mathcal G_K(nu_t-1,z_+-1)
+\mathcal G_K(nu_t-1,z_--1)
\ge\log y.}                                           \tag{10}
```

注意 `(10)` 使用的是 `ell` 的完整指数 `e`。

## P6. 高度预算

绝对对数高度满足

```math
h(nu_t)=h(\alpha^{2t})=t\log\alpha<2t.                \tag{11}
```

对 `z_±`，

```math
h(z_\pm)\le h(n)+h(\delta_\pm).
```

由 `(H)`、`c<=3`，并用粗界 `log2<1, log3<2, h(delta_±)<log6<2`：

```math
h(z_\pm)
<(18t+15)+2+2
=18t+19
<38t.                                                   \tag{12}
```

所以

```math
H_\pm:=\max\{h(nu_t),h(z_\pm)\}<38t.                 \tag{13}
```

## P7. 矛盾与有限性

取

```math
\epsilon=1/200.
```

除四个群各自的有限例外点外，由 `(CZ)`、`(13)`：

```math
\mathcal G_K(nu_t-1,z_+-1)
+\mathcal G_K(nu_t-1,z_--1)
<2*(1/200)*38t
=19t/50.                                                \tag{14}
```

另一方面，

```math
y=(\alpha^t+\alpha^{-t})/4>\alpha^t/4.
```

由于 `alpha>3>e` 且 `4<e^2`，

```math
\log y>t\log\alpha-\log4>t-2.                         \tag{15}
```

对 `t>=4`，

```math
t-2\ge t/2>19t/50.                                    \tag{16}
```

`(10)` 与 `(14)--(16)` 矛盾。若存在无穷多个真实状态，则由 `(H)` 必有 `t -> infinity`，故除有限多个小 `t` 外均有 `t>=4`；这些状态都必须让至少一个符号点落入相应的有限例外集。

固定 `c` 时两个例外集的并集有限；`c` 只有两个值。因此 `(t,s,c)` 只取有限多个值。

## P8. 完整状态有限

固定 `(t,s,c)` 后：

1. `q=(t-1)/8` 固定；
2. Pell 关系固定 `y,d`；
3. `AB=3(d-1)` 的正整数分配有限；
4. 每个 `A` 固定 `v=Ay,Q=d+v`；
5. `n=c2^s` 固定，而

```math
2(n-2)=Q(Q+hv)(hd-Q)                                  \tag{17}
```

是关于 `h` 的二次方程，所以 `h` 只有有限多个值；
6. `P=Q+hv, nu=(hd-Q)/2, W=By` 随之固定；
7. `n` 固定时合法 `j` 有限。

故整个冻结平衡核心只含有限多个整数状态。

## P9. 回传边界

本轮证明的是 NC3 必要核心的非有效绝对有限性。它不自动排除有限例外状态；也不辨识原题共同素数。只有在未来把有限底部全部排空后，才能把该平衡分支称为闭合。
