# B699 / i=3 严格平衡与临界区：OCTIC-35 与 4+4 廉价前沿压缩

日期：2026-09-22。范围：只研究 i=3 的大进制严格平衡数字行；不修改仓库；无 Lean；不声称完整 i=3 或 B699 闭合。

## 1. 本轮最强新增结论

设

- `f ∈ Z[X]` 系数非负，`f(0)=2`，`deg f=8`，`H=f(1)`；
- `T=p^e` 为奇素数幂；
- `T ≥ [2(H+2)]^20`；
- `n=f(T)` 为偶数。

在同一个原始 `(n,j)` 的 NC3 假设下，沿用既有大进制提升，第一源完整因子分配只能为 `3+5` 或 `4+4`。

### OCTIC-35

`3+5`（以及交换后的 `5+3`）完整分配不可能发生。

因此，GATE8 下任何可能的 NC3 输入都必须具有一个完整的次数 4 第一源块。特别地：

> 若 `f-1` 在 `Q[X]` 中不存在次数 4 的完整因子子积，则该原行全部合法 `j` 满足 Common3。

这是真正的无界域删除：系数、工作奇素数、指数、原 `n,j` 均可无界；没有扫描 `n` 或 `j`。

一个显式整行无界族是

```text
f_{a,b}(X)=1+(1+2aX^3)(1+4bX^5)
          =2+2aX^3+4bX^5+8abX^8,
```

其中 `a,b` 为任意奇素数。两个因子分别由倒数多项式 `X^3+2a`、`X^5+4b` 的 Eisenstein 判据不可约，故没有次数 4 子积；且对奇 `T` 有 `4|f_{a,b}(T)`。在声明门槛以上整行退出。

## 2. 决定性两系数证书

对 `3+5`，换用另一原端点后可取

```text
deg U=3, deg V=5, deg W≤3.
```

端点首项比 `t=lc(W)/lc(U)` 的 `t=0,1` 均由次数与 DIFF 排除，故 `0<t<1`，第二源商 `R` 恰为一次。

将其有理根移到 `x=0`，写 `R=ell*x`，并规范

```text
U=x^3+A x^2+B x+C,  C≠0.
```

根进入槽 `k∈{0,1,2}`。DIFF 精确给

```text
W=(6-k)x^3/8 +(4-k)A x^2/5 +(2-k)B x/2 +kC.
```

原第一逆关系和第二源身份给二阶必要同余

```text
U^2 | W^3 + R - 2 U W^2.
```

把右侧除以 `U^2`，只取余式的常数项和 `x^5` 项；三个槽仅差非零比例 `epsilon_k∈{1,-1/8,-8}`：

```text
r_0 = epsilon_k*C^2*(2A^3-25AB-1125C)/4000,
r_5 = epsilon_k*(3A^4-40A^2B-150AC+125B^2)/8000.
```

故两括号同时为零。第一式与 `C≠0` 推出 `A≠0`。令

```text
b=B/A^2,  c=C/A^3=(2-25b)/1125.
```

第二式化为

```text
1875 b^2 - 550 b + 41 = 0,
```

判别式为 `-5000`，在 `Q` 上无解。三种槽号同时排空；没有进入 Gröbner 分类。

## 3. 4+4 的廉价精确压缩

本轮没有得到 OCTIC-ALL，但把 `4+4` 的便宜部分精确删掉。

### 3.1 内部单槽四次商退出

若 `0<t<1`，则 `deg R=4`。若整个 `R` 进入一个槽 `W-kU`，DIFF 强迫内部唯一可能 `k=1`，并恢复

```text
f=3Z^2-2Z+1
```

其中 `Z` 是原整数多项式块 `U` 或 `V`。对整数 `Z(T)`，该值模 4 只能为 1 或 2，与同一 NC3 的 `4|n` 冲突。因此内部单槽商整片退出。

### 3.2 两端次数 0、1、2 全部退出

令 `t=0` 时 `s=deg W`；令 `t=1` 时 `s=deg(W-U)`。次数 0、1 分别由常商/一次商的 DIFF 首项直接排除。

对 `t=0,s=2`，规范 `U` 首一、写 `W=ax^2+bx+c`。二阶同余和 `deg R≤2` 的高次系数逐次强迫

```text
U=W^2/a^2-W/2-a^2/4,
R=-(a^4/8)(a^2+4W).
```

在 `R` 的任一根上，`W/U=4`，但主身份要求该比值为 `0,1,2`，矛盾。

对 `t=1,s=2`，写 `D=W-U=ax^2+bx+c`；同理得到

```text
U=D^2/a^2+D-a^2,
R=a^4(a^2-2D).
```

在 `R` 的根上 `W/U=-1`，仍不属于 `0,1,2`，矛盾。

所以 `4+4` 真正剩余被压成：

1. `0<t<1`，四次 `R` 至少占两个槽，槽总次数只有 `3+1`、`2+2`、`2+1+1`；
2. `t=0, deg W=3` 的三次临界商；
3. `t=1, deg(W-U)=3` 的三次临界商。

## 4. 高次数路线的成本判定

继续升次数仍是有限槽分类，但不再是本轮 `3+5` 的低成本状态。

对剩余内部 `4+4 / 3+1`，固定线性根为 0、三次因子首一、`U` 首一后，有 6 个有序槽对。在各槽对的通用非退化坐标图中，精确解 DIFF 与槽条件后仍有 5 个有理参数（含 `R` 的比例）；二阶同余给 8 个方程。分母退化图必须另列，只会增加分支，不能被这份成本统计吞掉。清分母展开的通用图精确统计为：

- 最高总次数：12；
- 单方程最多 37 个单项式；
- 每个有序槽对合计 200–209 个单项式。

这不是“不可能继续”，但已失去两系数负判别式的廉价结构。本轮在此止损，不把尚未做完的多槽消元称为有限分类完成。
