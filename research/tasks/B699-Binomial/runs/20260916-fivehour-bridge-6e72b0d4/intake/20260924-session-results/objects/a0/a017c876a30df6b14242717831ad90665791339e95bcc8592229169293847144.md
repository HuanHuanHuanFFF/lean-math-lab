## 2. 两组同源 S-unit 对

置

```math
K=Q(sqrt(3),sqrt(5)),
alpha=2+sqrt(3),
delta_+=3+sqrt(5),
delta_-=3-sqrt(5).
```

对每个真实状态定义

```math
u=-alpha^(2t),
qquad v_+=n/delta_+,
qquad v_-=n/delta_-.
```

固定 `c in {1,3}` 与符号后，`(u,v_±)` 落在固定有限生成子群

```math
Gamma_(c,±)=<(-1,1),(alpha^2,1),(1,2),(1,c/delta_±)>
             subset G_m^2(K).
```

每一对都乘法独立：若 `u^a v_±^b=1`，对 `sqrt(3)` 取共轭并相除，得到 `alpha^(4ta)=1`，故 `a=0`；随后 `v_±^b=1`，而 `v_±` 为正的非单位根，故 `b=0`。

## 3. 两个广义 gcd 的统一下界

令

```math
G_K(x,z)=-sum_w log^- max(|x|_w,|z|_w).
```

由 `U_t=2y` 有精确恒等式

```math
u-1=-(alpha^(2t)+1)=-2U_t alpha^t=-4y alpha^t.       (1)
```

另一方面

```math
(n-delta_+)(n-delta_-)
=n^2-6n+4
=(n-3)^2-5,
```

而 Round 13 已给

```math
y | (n-3)^2-5.                                      (2)
```

若 `ell^e || y`，Round 13 的 SPLIT60 已保证

```math
ell=1 or 49 mod60.
```

所以 `ell` 在 `K` 中完全分裂，且 `ell` 不属于 `{2,3,5}`。在每个 `p|ell` 上：

- `(1)` 给 `ord_p(u-1)=e`；
- `(2)` 给两个因子 `n-delta_+`、`n-delta_-` 的估值和至少为 `e`；
- `delta_±` 在 `p` 上为单位。

于是两个 gcd 的局部贡献相加至少为 `e`。按标准归一化对 `p|ell` 求和，再对全部 `ell^e||y` 求和，得到

```math
\boxed{G_K(u-1,v_+-1)+G_K(u-1,v_--1) >= log y.}      (3)
```

这一步保留了 `y` 的完整素数幂；不是只做支持集合计数。

## 4. Corvaja--Zannier 上界

采用的外部接口是：对固定有限生成 `Gamma subset G_m^2(K)` 及任意 `epsilon>0`，除有限多个乘法独立点外，

```math
G_K(u-1,v-1)<epsilon*max(h(u),h(v)).                  (4)
```

分别把 `(4)` 用于 `Gamma_(c,+)` 和 `Gamma_(c,-)`，取

```math
epsilon=1/200.
```

Round 14 的 `s<=18t+15` 给出统一粗界

```math
h(u)<2t,
qquad h(v_±)<38t.                                     (5)
```

所以除四个固定群中的有限例外点外，

```math
G_K(u-1,v_+-1)+G_K(u-1,v_--1)<19t/50.                (6)
```

但

```math
y=(alpha^t+alpha^(-t))/4>alpha^t/4,
```

故

```math
log y>t log(alpha)-log4>t-2.                          (7)
```

任何无界状态序列都满足 `t -> infinity`，因而最终 `t>=4`；而

```math
t-2>19t/50.
```

`(3)`、`(6)`、`(7)` 矛盾。因此不可能存在 `t -> infinity` 的真实平衡状态序列。

## 5. 从 `(t,s,c)` 有限回到完整状态有限

若 `(t,s,c)` 只取有限多个值，则：

- `q=(t-1)/8` 固定；
- Pell 坐标给定 `y,d`；
- `AB=3(d-1)` 只有有限个正整数分配；
- `v=Ay, Q=d+v, W=By` 随之固定；
- `h` 必须满足

```math
2(n-2)=Q(Q+hv)(hd-Q),
```

这是关于 `h` 的固定二次方程；
- `P=Q+hv`、`nu=(hd-Q)/2` 随之固定；
- `n` 固定后原合法 `j` 也只有有限多个。

所以不仅 `t,s`，而是整个冻结平衡核心的整数状态都只有有限多个。
