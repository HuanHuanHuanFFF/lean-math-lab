# B699 Pro A / i=9 — MID-DOUBLE(5–7)、同一 G 矩约束与 EDGE8 高度 57

日期：2026-09-22。范围：冻结 K152 构造中的**同一个固定非零整数多项式** `G`。
本轮未修改、提交、推送或发布仓库；没有 Lean 核验，也没有外部独立全链数学审读。

## 1. 本轮实际终点

采用上一轮已经取得的

```text
|C_G| <= 8,
|C_G| = 8  ==>  E=0, D(G)=305, 2h+V=305,
```

其中 `C_G` 是同一个 `G` 的不同本原 `Q[N,X]`-不可约、能够承载合法 `400 | n` 的 NC9 点的因子集合，`h=deg_X G`，`V=sum v_r`。

本轮证明了新的等号高度：

```text
|C_G| = 8  ==>  h >= 57, V <= 191.
```

同时，EDGE8 的完备 `E=0` 必要状态从

```text
454  ->  381.
```

因此，**同一固定 G 拥有八个不同可载不可约因子且 `h<=56` 的整个域被排除**。这是实际无界代数域删除：因子系数、可载整数点及原始输入高度均未被预先截断。

本轮没有证明 `COVER7`，没有排空原始 NC9 的全部 `(n,j)`，没有减少 `R7={3,4,5,6,7,8,9}`，也没有闭合完整 `i=9` 或 B699。

### 2.1 完备有限化

对固定 `q` 与缺重模式，六行普通重数是有限个非负整数分拆。由于 `D=2q`，首一化后六行均为首一 `q` 次多项式。

程序完整检查：

- 六行普通重数和；
- 实际源命中数 `z>=14`；
- 首一多项式的根和来自同一个次数不超过 2 的多项式；
- 第二基本对称和来自同一个次数不超过 4 的多项式；
- 九条源直线交数不超过 `2q`；
- 缺失根撞入此前未命中的源值时产生的真实普通零点；
- 三处 `kappa=0` 的全部普通／加权 jet。

模式 C 的第6行有两个缺失根；程序只用它们的和与积编码，允许二次余因子不可分裂，不假定缺失根为有理数或整数。

### 2.2 完整 jet 系统

固定六行特化多项式后，写

```text
H = H0 + W Q,
W = product_{r=3}^8 (N-r).
```

根和与第二基本对称和条件保证 `H0` 的加权次数不超过 `2q`。于是

```text
deg_w Q <= 2q-6,
deg_X Q <= q-3,
dim Q = (q-2)^2.
```

把 `Q` 的全部系数列与首一 `H0` 列组成增广齐次矩阵，共 `(q-2)^2+1` 列。普通源加入全部 `i+j<m` 且 `i>=1` 的 jet；对角源加入全部 `i+2j<2m` 且 `i>=1` 的 jet。`i=0` 的条件已由固定行多项式满足。

矩阵在模素数下满列秩，说明某个清分母整数子式非零，从而特征零上不存在首一解。六点插值公共分母整除 120，而两个采用素数均不整除 120。

源直线超容量分支只用于判定 `ell_t|H`；由于 `q>=5`，这与 `Q[N,X]`-不可约性矛盾。证明没有使用亏格、绝对不可约归约、系数高度盒或原输入高度盒。

## 3. 账本中的合法使用：强制 kappa_8，而不是删除签名

本轮探索阶段曾暂时把“零 `kappa` 模式被排除”实现成直接删除相应弱签名。审计发现这不够严谨：旧 `double5/double67` 签名只显式记录 `kappa_4,kappa_6`，会保守忽略实际可能存在的 `kappa_8`。

最终账本采用正确替换：

```text
若对应普通缺重模式、kappa_4=kappa_6=0，
则由 MID-DOUBLE 强制收取 kappa_8>=1。
```

而不是声称该因子完全不存在。若实际 `kappa_4` 或 `kappa_6` 已经为正，则继续使用旧签名。

最终证书、两个账本与以下所有计数均只采用这个修正模型；探索版“直接删除”输出没有进入证据包。

## 5. 同一 G 的首两系数再删除三个状态

新几何后最低粗状态为 `h=53` 的状态 589。为避免只用费用账本，本轮对边界状态完整枚举**全部原始命名签名**，保留实际 `S5` 数量，并以

```text
(total Delta, total kappa, number of S5)
```

作为聚合键。只有当聚合恰好用满六行容量时，才恢复同一个 `Gbar` 的完整行根数据；有剩余容量的聚合不使用 TRACE。

若

```text
Gbar = X^h - S(N) X^(h-1) + T(N) X^(h-2) - ...,
```

则

```text
deg S <= 2,
deg T <= 4.
```

真正 `S5` 的缺失根在第5行为 6；其它缺失根保持自由变量。程序对 `S,T` 的 8 个有理系数建立精确线性系统。

### 5.1 状态 589：唯一聚合被二阶系数排除

```text

cap=(0,2,14,6,0,2).
```

所有八因子配置只有一个聚合：

```text
6*S5
+ 1 个 e>=8、(Delta_5,Delta_8)=(1,1) 因子
+ 1 个 16<=e<=24、Delta_4=1 因子。
```

最低次数为 48，且恰好用满六行容量。第一根和仍相容：

```text
S(N)=133-(251/3)N+(56/3)N^2.
```

但加入 `T(N)` 后，9 条方程对 8 个未知量不相容。证书给出的整数左零向量为

```text
[67,-3,15,-30,-9220,30,7065,-15,3]
```

对应标签

```text
S(3), T(3), T-onefree(4), T-onefree(5),
S(6), T(6), S(7), T(7), T-onefree(8),
```

线性组合左端系数全消，右端为 `-1801 != 0`。因此状态 589 完整退出。

### 5.2 状态 667：两个聚合均有根和矛盾

两个可能聚合都用满容量。相应二次根和必须满足的消去关系分别给出

```text

-S(3)+3 S(4)-3 S(5)+S(6) = -26.
```

左侧权重都消去 `1,N,N^2`，对任意二次多项式本应为零，因此两个聚合均排除。

### 5.3 状态 792：两个聚合均有根和矛盾

两个可能聚合也都用满容量，得到

```text

-S(3)+6 S(5)-8 S(6)+3 S(7) = -32.
```

同样与 `deg S<=2` 矛盾。状态 792 退出。

因此在 384 个粗 `E=0` 状态中再删除 3 个，最终剩余：

```text
381 个必要资源状态，最低 h=57。
```

本轮无条件删除的是：

