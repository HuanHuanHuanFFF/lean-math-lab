# REPLAY

## Quick replay

Requirements:

- Python 3;
- SymPy;
- a C++20 compiler with OpenMP for rebuilding sample tools.

Run:

```bash
bash replay.sh
```

It performs:

1. package SHA-256 verification;
2. symbolic identity and modulo-4 verification;
3. 256-sample Python bit-by-bit / C++ Newton-doubling cross-check;
4. an independent complete Python replay of all 27,648 candidates at `rho=12`;
5. receipt coverage audit over all 1,811,911,680 campaign candidates.

Expected final line:

```text
ROUND18_QUICK_REPLAY=PASS
```

## Full campaign replay

```bash
OMP_NUM_THREADS=8 bash full_replay.sh
```

This regenerates every layer/chunk for `rho=12,...,27`. Runtime depends strongly on CPU. It does not rerun Round 16's Matveev derivation or Round 17's `rho=28,...,55` campaign.

## Evidence boundary

The programs verify the finite POWER campaign and its algebraic interfaces. They do not formalize the upstream paper proofs or the original B699 theorem in Lean.
