# C 原生 i6：R11 → R12 → R13

以下是对 2026-10-02 三个 C 包中报告、交接和来源说明的整理；我没有运行附件程序、检查大证书、复算结论或执行 Lean。这是来源摘要，不是数学接受记录。ZIP 与成员映射见 [MEMBERS.json](../MEMBERS.json)。

## 采用次序和当前范围

R11 从总览 §3E/§3F 的原生 C24 i6 链取 42 个明列模 1800 类作来源范围，在其中使用六类中点核，并报告完成原输入条带 `d=n−2j≤4096`。R11 明确保留旧 R10 窄 B-RES10/E4 状态；另一条 C24/1758 类作者采用链只支持“42 类是全局剩余全集”的身份，R11 的逐类结论不依赖该链。不能把两条 C 链合并或由此接受 1758 类覆盖。

R12 采用 R11 的六类距离核和小 `d` 分支，不重跑 STRIP4096。它改用实际 `g=gcd(n,j)`、归一化距离 `ε=d/g` 和原第一源的正整数商，完成 `ε≤4096` 的六类原输入末端。R13 接 R12 的同一 `g, ε, τ, h`，再把原第一、第三、第五源联立；不重跑前两轮的有限末端。

当前 R13 范围仍是同一合法原数对 `(n,j)`、`i=6`、`n mod 1800` 属于 `{252,704,850,954,1100,1552}`，原素数幂保持完整。令 `d=n−2j=gε`、`α=n/g`，并令 `s=S1, S3, S5` 为实际完整 235 小部。R12 的源商 `τ=βγ/q1∈ℕ+` 与

```text
h = sα − 4τg > 0
```

来自六类前置下的同一原输入；R13 的 `h>0` 不能无条件搬到其余 36 类。

## R12 接口与 R13 高度

R12 以 `ρ` 表示 `sα mod 4` 的最小正代表（余数为 0 时取 4），报告 NC6 必要界

```text
s(d²−n) ≥ ρg(n−1),   α ≤ ⌊(sε²−4)/ρ⌋,
g ≤ ⌊(sα−ρ)/4⌋,       n < s³ε⁴/(4ρ²).
```

该界固定 `ε` 时控制 `n,g`，但 `ε` 未获绝对上界。R12 的 `ε≤4096` 恢复仅余两对 `(n,j)=(6250,2083),(6250,2084)`，各自的完整第二源在 11 层失败；其报告称完整六源末端没有剩余输入。初次运行的额外包含断言失败，最终两消费者各守自己的范围；回归中两个消费者之间的 243 个差例不等于历史并集净差。

R13 使用真实 `S3,S5`，定义

```text
Z13  = βγ(d²−1)/(q1²q3)
     = S3τ(gh+s)/(n−3) > 0,
Z135 = βγ(d²−1)(d²−2n+1)/(q1³q3q5)
     = S3S5τ(g²h²−s²)/((n−3)(n−5)) > 0.
```

令 `m=sS3`、`C=s²S3`、`κ=sS3S5`。R13 报告的同一原输入必要界为

```text
mh ≥ 4g,   gh > s,
4n < Cε²,  g < Cε/4,
4(n−3)(n−5) < κnh²,
n < 8+κh²/4,
4(n−5)³ < s³S3S5 g²ε⁴.
```

六行常数 `(s,S3,S5; C,κ)` 为：252 `(1,3,1; 3,3)`；704 `(1,1,3; 1,3)`；850 `(3,1,5; 9,15)`；954 `(1,3,1; 3,3)`；1100 `(1,1,15; 1,15)`；1552 `(3,1,1; 9,3)`。相对 R12，报告称 `n` 关于 `ε` 的高度从四次降为二次、`g` 从二次降为一次，并得到对既有正商 `h` 的高度；`h, ε` 仍均无绝对上界。

作者还报告 `h≤1024` 时的 1118 份预平方菜单均未恢复普通 `ε`，因此在本六类前置下推得 `h≥1025`。这是参数子域的有限末端，不是全局 `h` 界。704 类另有通过前两轮明列距离消费者但被 R13 新消费者触发的族；其第一源失败，不能当作 NC6 模型或历史净收益。

## 当前账本、缺口和下一门

三轮报告均登记 `R7={3,4,5,6,7,8,9}`、历史并集净删域 `0`；没有删除完整模类，也没有闭合六类、42 类或 B-RES10。R11 的 `d≤4096`、R12 的 `ε≤4096`、R13 的 `h≤1024` 是各自明确的参数域，不能互换成全局有限化。仍无界的有 `ε,h,n,j,k,d,g,α,β,γ,τ`、活动 235 小部的指数、粗素数支持和完整源指数；`S4` 仍为实际无界小部。其余 36 类与旧 B-RES10/Pell 路线没有由 R12/R13 统一控制。

下一可执行数学检查按 R13 HANDOFF：在 `n<8+κh²/4` 与 `mh≥4g` 内，把实际 `A4|h`、`C4/M2` 的完整平方精度、原单高底 `α` 和同一输入的 `Z13/Z135` 整性联立，尝试得到 `h` 的反向界或完整源支持矛盾。不要单纯扩大 `h` 终端，也不要把两个商当成可分别选输入的独立方程。作者报告的证据等级是纸面论证、有限证书和同作者分离接收/重放；无外部独立审读、无 Lean，本摘要没有新数学验收。
