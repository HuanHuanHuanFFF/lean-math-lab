# REPLAY

在解压后的根目录运行，输出目录必须尚不存在，并放在包根之外：

```bash
python code/verify_manifest.py
python code/replay.py --out ../fresh-run
python code/compare_replay.py --out ../fresh-run
python code/verify_manifest.py
```

Python不得使用`-O`，代码主动拒绝禁用断言的解释器模式。只依赖标准库与C++17编译器，不需要联网、仓库、Lean或CAS。重放重新编译源码，完整生成两个锚点的根配置，接收全部双素数子式，计算整数补核，重建并接收五次自身商模块，重做全部DP格与多重集，执行负测试。不是只检查已有证书哈希。

`compare_replay.py`对`certificates/`全部确定性输出逐文件字节比较。运行耗时、环境、命令绝对路径保存在输出目录的logs/runs/environment中，不拿这些环境相关字段作确定性字节要求。不同实现核验仍由同一个作者会话完成，不是外部独立审读。

内部`verification/CLEAN_EXTRACT_REPLAY_RECEIPT.json`绑定一个真实创建、干净解压并完整重放的载荷检查点，记录其容器SHA、全部证书SHA、代码/输入绑定及退出码。把这张回执收入交付包后，再创建最终ZIP；最终ZIP的独立外部回执另行绑定最终容器SHA并重做完整流程。此方式避免将某个最终ZIP的哈希递归写回自身。内部检查点哈希不能冒充最终ZIP哈希。

本轮只重做新的七对排除、选定状态自己的商核和账本。采用的历史NC9→G/COVER8/LOW-T43前置不由离线重放重新证明。
