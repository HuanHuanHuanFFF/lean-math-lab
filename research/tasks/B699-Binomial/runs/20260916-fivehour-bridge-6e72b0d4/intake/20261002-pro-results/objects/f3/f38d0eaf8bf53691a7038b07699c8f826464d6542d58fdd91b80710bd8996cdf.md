# PROOFS — C Round 11 / MIDPOINT-COLD · STRIP4096

## 0. 原题、来源和本轮的独立合同

原题要求对 1≤i<j≤⌊n/2⌋ 存在同一个素数 p≥i 同除 C(n,i)、C(n,j)。本轮固定 i=6，故合法输入为自然数 n,j，7≤j≤⌊n/2⌋，见证素数阈值 p≥7 与 p≥6 等价。

记 k=n−j、d=n−2j≥0，并定义实际完整小部

    S_r = 2^{v2(n−r)}3^{v3(n−r)}5^{v5(n−r)},
    q_r = (n−r)/S_r,       r=0,…,5.

本轮不要求纯三幂 α，不要求 N|jk、十倍平方、E4平方、中央负核，也不要求人为额外的全q5近侧。因此本轮不得沿用旧B-RES10的固定小部，且所得原输入消费者不以旧1758类闭合链为前提。

“42类是全i6必要剩余包络”属于新Overview的另一条作者采用链；本轮只把明列的42个余数作为定理范围。本页R10旧窄域状态与该采用链分别登记，未复核或撤销旧链。后面的每个42类定理，无论旧链是否接受，都作为独立的原输入充分消费者成立。

## 1. 完整源幂与中点距离

### 引理1（完整窗口，保持同一原数对）

若 p≥7，p^e∥n−r，0≤r≤5，则 v_p(C(n,6))=e。原因是p不除6!，且p只能整除六个连续分子项中的一项。

阶乘估值给

    v_p(C(n,j)) = Σ_{a≥1} [⌊n/p^a⌋−⌊j/p^a⌋−⌊(n−j)/p^a⌋],

每项为0或1。若 p∤C(n,j)，所有项为0，特别在 Q=p^e 时，由 n mod Q=r 有 j mod Q=b∈{0,…,r}。于是

    d=n−2j ≡ r−2b (mod Q).

因此，在NC6下，对每个实际完整p^e∥q_r，都存在 h∈H_r={−r,−r+2,…,r} 使 p^e|(d−h)。

反之，某个实际完整p^e窗口失败，就使对应阶乘估值项为1，返回同一个原p的共同整除。完整窗口通过并非NC6充分条件：更高层仍可能进位。

### 引理2（MIDPOINT-LCM）

不同q_r两两互素：任何公共素数≥7必须整除非零差 r−s，其绝对值≤5，不可能。

任取 I⊆{0,…,5}。令 H_I=∪_{r∈I}H_r。若 d≠h 对全部 h∈H_I，定义

    L_I(d)=lcm_{h∈H_I} rough235(|d−h|),

rough235剥掉全部2、3、5幂，并取正值。在NC6下有

    ∏_{r∈I} q_r | L_I(d).                         (1)

证明：引理1逐个保存完整源指数，给每个p的指数不超过上述lcm中该p的最大指数；再用不同q_r互素。绝非只把rad(q_r)放进目标。

特别对d≥6，所有 h∈{−5,…,5} 非零差都可用。并有每个实际粗源完整幂 p^e≤d+5。这里的e仍是v_p(n−r)，没有增加源指数。

## 2. 42类的准确冷源费用

对Overview明列42个a，模8、9、25各在0,…,5中指定唯一活动位置h2、h3、h5。取

    J_a={0,…,5}\{h2,h3,h5}.

每个r∈J_a都不满足8|(n−r)、9|(n−r)、25|(n−r)，所以该源的完整235小部完全由a mod1800决定。记这些真实固定小部为s_{a,r}，κ_a=∏_{r∈J_a}s_{a,r}。本轮没有把任何活动源的无界幂吸收到常数里。

由(1)得到全参数必要整除

    [∏_{r∈J_a}(n−r)]/κ_a | L_{J_a}(d).          (2)

其反向失败、或下式反向大小，都是同一原数对的Common6充分消费者：

    ∏_{r∈J_a}(n−r) ≤ κ_a L_{J_a}(d).          (3)

此式不要求已知α模板、真实g的特殊形状、旧范数或因子核。

### 固定小部归一化（不得剥掉7或11）

令 F_a(d)=∏_{h∈H_{J_a}}(d−h)，ε=a mod2，D_a=deg F_a，m_a=|J_a|。d≥6时F_a(d)>0。取

    G_a=gcd_{u=0,…,D_a} F_a(2u+ε),
    Δ_a=完整235小部(|G_a|).

对整数多项式P(u)=F_a(2u+ε)，Newton展开

    P(u)=Σ_{k=0}^{D_a} (Δ^kP)(0) binom(u,k)

具有整数差分系数。初始值的gcd整除每个差分系数，因此整除每个整数u≥0处的值。故Δ_a整除F_a(d)的完整235小部。L_{J_a}(d)只含≥7的素数，其指数不超过F_a(d)的相应指数，从而

    L_{J_a}(d) ≤ F_a(d)/Δ_a.

G_a中即使还有7、11也绝不在这里剥除：那些可能是实际原源幂。程序只取Δ_a的235部分。

42条精确证书给κ_a|Δ_a。置λ_a=Δ_a/κ_a，则

    λ_a ∏_{r∈J_a}(n−r) ≤ F_a(d) < d^{D_a}.    (4)

所有根成±对，可能再有0，因此最后严格不等式对d≥6直接成立。每个n−r≥n−5，遂有

    λ_a(n−5)^{m_a} < d^{D_a}.                 (5)

完整42条固定数值与Newton系数在frontier42.json，人工表在FRONTIER42_TABLE.md。按最小λ分组：

* 6类：3(n−5)^3<d^6；
* 12类：648(n−5)^3<d^9；
* 18类：17280(n−5)^3<d^11；
* 6类：4320(n−5)^4<d^11。

实际单类常数常更强。给定d就得到n的有效高度，但d全局仍无界；(5)不是全i6统一有限化。

## 3. 六类的明确二次距离界

对a∈{252,704,850,954,1100,1552}，三个活动位置为{0,2,4}，冷源恰为{1,3,5}。这些a都是偶数，d也是偶数。

冷源小部乘积：

    κ_a=3  对 a∈{252,704,954,1552};
    κ_a=15 对 a∈{850,1100}.

六个因子d−5,d−3,d−1,d+1,d+3,d+5均为正奇数（d≥6）。其中至少两个含3，至少一个含5，故乘积的235小部至少45。定义

    F6(d)=(d²−1)(d²−9)(d²−25).

于是必要条件精确为

    λ_a(n−1)(n−3)(n−5) ≤ F6(d),               (6)

λ_a分别为15或3。特别

    n < 5 + d²/λ_a^{1/3}.                    (7)

(6)的反向严格不等式就是原数对充分消费者，无需把三次根转成浮点。

### 一个n和d同时无界的真实原输入族

对这六个a、每个普通整数m≥3，取

    n=a+1800m², d=2m, j=n/2−m.

它们都是合法原数对，n mod1800=a。因为a>5，n−5>1800m²，而

    F6(2m)<64m^6,
    λ_a(n−1)(n−3)(n−5)>3·1800³m^6>64m^6,

(6)矛盾，故每个成员均有同一个p≥7同除两个原二项式。这是全参数普通整数消费者，不是投影族，也不通过样例外推。

30个记录只作回归，包含m=10^9。例如a=252时，n=1800000000000000000252，j=899999999999000000126，p=7给v_p(C(n,6))=1、v_p(C(n,j))=15。本族不声称满足旧B-RES10的范数或α模板。

## 4. 对所有n的固定中点距离：完备有限恢复

本节不限于42个余数类。

若n偶，取r∈{1,3,5}；若n奇，取r∈{0,2,4}。三个n−r均为大于1的奇数，并且两两互素，因为两两差的绝对值为2或4。素数3和5最多各占一个项，所以至少有一项n−r完全与30互素。该项的实际q_r就是n−r。

令

    L_*(d)=lcm rough235(|d−h|),

其中d偶时h∈{−5,−3,−1,1,3,5}；d奇时h∈{−4,−2,0,2,4}。这些h都与d异奇偶，所以任意d≥0都不会出现零因子。

在NC6下，由引理1必须有

    n=v+r,  v|L_*(d),

r取上述对应的三个原位置，并保留n≥d+14。这个恢复覆盖每个真实NC6原输入，不只覆盖某个最小CRT代表。d固定时，n≤L_*(d)+5（偶n）或+4（奇n），但生成器直接枚举完整除数，不逐n扫描。

对于同奇偶h，任意两线性因子相差2,4,…,10。它们不可能共享素数≥7：这样的素数乘以2最小为14。因此这些rough部分彼此互素，L_*(d)也等于它们的乘积。发现器用lcm的逐素数最大指数；接收器独立用乘积、素数筛和递归除数恢复。

所有因子的绝对值≤d+5。因此当d≤4096，只需精确分解≤4101的普通整数，所有大n由其完整除数恢复；没有大整数素性猜测或概率分解依赖。

### 完整源终端

对每个恢复的n，设j=(n−d)/2，测试全部r=0,…,5的

    q_r | ∏_{b=0}^r(j−b).                      (8)

因为q_r的全部素数≥7>r，不同线性项不共用这些素数，(8)准确等价于每个实际完整源幂有一个原槽。某个r失败即存在实际p≥7、p^e∥q_r，其完整窗口失败；引理1返回同一原p的共同整除。没有把所有窗口通过反推NC6。

发现器使用模q_r的乘积；分离接收器使用逐槽gcd除去完整q_r，并逐个比较每个d的规范恢复流SHA-256。两条路径均用精确整数，不使用浮点或只检radical。

结果：

    d=0,…,4096 全部覆盖；
    3,962,560 个不同的(d,n)恢复对；
    最大恢复n=103717466424210426816；
    首个失败源r=0,1,2,3,4,5的计数：
      3,958,919; 3,480; 159; 2; 0; 0；
    所有完整窗口通过的恢复对：0。

因此得到完整原输入条带定理：

    ∀n,j∈N,
    7≤j≤⌊n/2⌋ 且 0≤n−2j≤4096
    ⇒ ∃素数p≥7, p|C(n,6) 且 p|C(n,j).         (STRIP4096)

这不是“扫描到n约10^20”。无论n多大，未进入完备除数表就已经违反必要源条件；表内再用原完整窗口逐项排除。

小距离也有直接证明：d=0,1时L_*=1；d=2,3,4,5时L_*=7，给出的n上界≤12，和n≥d+14冲突。证书保留这些d的空恢复表。

## 5. 不能越过的边界

1. 42类整体仍未关闭。(5)仅把n与d联立，d可增长；STRIP4096不允许丢掉4096上界。
2. “所有窗口通过”不等价NC6。例如n=56,j=14,p=7,r=0，完整7层通过，但49层进位，v7(C(56,14))=1。
3. 模p通过不能替代完整p^e。n=53,j=14，实际q4=49；模7是槽0，模49却是14>4，v7(C(53,6))=2、v7(C(53,14))=1。
4. 固定小部成本只用于表中真正冷源。活动高幂未受本轮绝对控制，不能把它们放进κ常数。
5. 剥除固定多项式公因子时，只剥2、3、5，不剥实际源素数7、11。
6. 历史并集差没有审计，认证净删域登记0。本轮证明了明确的原输入充分消费者，但没有认证其与全部历史消费者的非空差。
7. LCM与除数恢复没有生成新的原输入或下降；始终测试同一原n,j。无严格NC下降，无Lean，无外部独立数学审读。
