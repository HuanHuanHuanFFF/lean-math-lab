入口：REPORT.md → PROOFS.md → FAILURE_BOUNDARIES.md → HANDOFF.md。

## 重放

Python 3.10+，仅标准库。解压后在包根执行：

```sh
python scripts/replay.py --receipt /absolute/path/replay-receipt.json
```

重放先检查SHA256SUMS.payload.txt，再在临时目录重新生成5个主证书；分离接收器完整重新恢复3,962,560个原数对并核对流哈希、42条Newton费用和9种篡改。临时输出不修改包内来源或证书。

要直接检查原数对，可运行：

```sh
python scripts/check_pair.py 16452 8223
```

消费者只返回“由本轮定理证明Common6”或“未触发本轮消费者”，绝不把未触发称NC6。n,j要满足7≤j≤floor(n/2)。
