# GENERAL-ZERO-HEIGHT evidence

阅读顺序：REPORT.md → PROOFS.md → FAILURE_BOUNDARIES.md → HANDOFF.md。
SESSION_STATE.json是机器可读前沿；scripts与certificates为本轮独立接收材料。

本轮得到一般零C闭合及关于k的统一多项式高度，不是k的绝对界或完整i3。

## 验证

Python 3.10+标准库、无需网络/SymPy：

    python3 -B scripts/verify.py --output /tmp/general-zero-receipt.json

输出必须在本目录之外。不要运行diagnostic.py或derive_certificates.py来“接收”：它们是重建材料的发现工具；verify只读。

    python3 -B scripts/replay_archive.py /path/to/evidence.zip --output /tmp/general-zero-replay.json

内部CLEAN_REPLAY.json为最终清单生成前的完整载荷解压验证；包外final-replay.json针对最终ZIP，包含其自身哈希与最终完整清单验证。二者阶段明确，不制造自引用。

本包不含旧证据ZIP，不运行旧k≤6或Hensel账本，不运行Lean、不修改仓库。
