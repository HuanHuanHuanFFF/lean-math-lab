# 完整离线重放

要求：Python 3（标准库）与支持C++17的g++。无需网络、仓库、Lean或外部数学软件。
请在解压后的根目录运行：

```sh
python3 -B code/verify_manifest.py .
python3 -B code/replay.py --out ../U10-LATE11-replayed
python3 -B code/compare_replay.py certificates ../U10-LATE11-replayed/certificates
python3 -B code/verify_manifest.py .
```

`--out`必须是尚不存在的目录。重放只写该输出目录，编译产物不会写回证据包。
`compare_replay.py`比较完整证书文件集合及逐文件SHA，不只比较汇总数字。运行日志和实测耗时不是确定性证书。

也可对最终ZIP本身执行干净检查：

```sh
python3 -B code/check_clean_archive.py /path/to/package.zip /tmp/new-unpack-and-replay /tmp/final-receipt.json
```

这个脚本要求新目录，安全解压并检查CRC和完整清单，执行本轮全部几何枚举、子式生成/接收、整数补核、三阶段全DP、关键多重集和10个负控制，比较完整确定性输出，最后再检查包内文件未改变。

本轮不会重跑旧TAIL8/COST2、S5商核或历史全链。输入前置的正确性仍保持作者级采用边界；回放通过不是外部独立审读。

内部`verification/CLEAN_REPLAY_RECEIPT.json`绑定打包前检查点载荷，外部最终回执绑定最终ZIP字节。因为内部回执本身成为载荷，不能让它循环声称包含自身的最终ZIP哈希；最终SHA以外部文件为准。
