# REPLAY

```bash
python replay.py
```

1. 逐个核对SHA256SUMS.txt（负载阶段使用PAYLOAD_SHA256SUMS.txt）。
2. 运行evidence/verify.py。它从父ZIP重新提取静态快照，对六份证书用另一公式核验。
3. 在临时目录运行生成器，对所有六份JSON证书逐字节比对，不修改原包。

单项：
```bash
python evidence/verify.py
python evidence/generate.py --out /path/to/empty/temp
python evidence/negative_tests.py
```

普遍p/e定理由PROOFS P2的纸面论证承担，脚本核对其有限实例、秩和应用证书；不要把有限诊断说成对所有素数做完枚举。
主流程不复跑旧A分支，不运行Lean，不访问仓库。
