# REPLAY — 本轮完整离线再生成

## 运行环境

Python 3标准库、g++支持C++17。无第三方Python依赖，无Lean、无仓库、无网络。完整矩阵与清单属于当前五剖面，历史几何不运行。程序用两个并行工作线程处理两个素数；其余主流程顺序完成。

```sh
python3 -B code/verify_manifest.py .
python3 -B code/replay.py --out ../TAIL13-MIX12-new-run
python3 -B code/compare_replay.py certificates ../TAIL13-MIX12-new-run/certificates
python3 -B code/verify_manifest.py .
```

指定输出目录必须不存在。replay检查INPUT_SHA256、完整Δκ五剖面、共轭分量除数、28状态及容量；编译源码，重新枚举两锚点，逐门生成双素数子式并由另一实现接收。然后做10个完整整数行列式、三阶段全部容量格、Python/C++完整多重集、低原像/M7交叉检查与11个负控制。

输出日志与编译命令、返回码保存在新目录logs/runs，环境在environment.json；确定性证书在certificates。平台/耗时/绝对输出路径不参与证书逐字节一致性，数学输入与代码精确字节由RUN_INPUT_HASHES绑定。

## 最终ZIP本身的检查

```sh
python3 -B code/check_clean_archive.py \
  ../B699-ProA-TAIL13-MIX12-FRONTIER27-20261002-evidence.zip \
  ../TAIL13-MIX12-final-clean-check \
  ../TAIL13-MIX12-final-receipt.json
```

工具拒绝已有输出目录，检查重复成员/路径穿越/符号链接与CRC，解压到新目录；核验完整成员清单，再执行完整replay，比较全部确定性证书，再核验解压载荷清单未改变。回执绑定实际传入ZIP的SHA-256。

## 内部回执与最终外部回执

为避免自引用，包内verification/CLEAN_REPLAY_RECEIPT.json记录尚未加入该回执自身的载荷检查点容器；加入回执后更新MANIFEST并形成最终ZIP。最终ZIP另外再完整干净解压重放，结果在交付外部FINAL_ARCHIVE_REPLAY_RECEIPT.json。两次均必须有实际exit0和逐字节证书比较，不能用检查点哈希冒充最终容器哈希。

哈希、CRC、两实现、满秩子式与干净重放提高可复现性，不替代旧NC→G契约或外部亏格定理的数学接受。此包不声称Lean或外部独立审读。下一步LOW-T目录及T反事实只在明确诊断权限下重放，不生成新几何许可证。
