# 证明与精确边界

证据等级：本会话作者纸面证明。代数和具体整数由同会话程序精确复算；未作 Lean 或外部独立审读。以下不用未取到的 ell6/ell7 原稿作为隐含前提。

## P0. 题目、指标与所有零分支

始终 i=6，7≤j≤⌊n/2⌋，k=n-j，g=gcd(n,j)，α=n/g。NC6 指不存在同一个素数 p≥6 同时整除 C(n,6)、C(n,j)。因为6不是素数，合格见证实际均≥7。

当前重建的假设为：NC6，n≡5130 mod9000，α=3^a（a≥2），(n-1)jk 为10倍平方，且 Q51=q5。低残量不等式、缺欠阈值和完整邻行条件没有被删除：只是本轮以下恒等式不需要它们；我们没有由这些较弱假设得出整个目标无解。

s6 删除全部 2、3、5 幂，q_r=(n-r)/s6(n-r)，0≤r≤5。不存在把孤立素数端点5混入i6见证的问题，也不调用NC5或NC7。

合法性给 n≥14，j,k>0，故 J=jk>0。以后出现的粗块、g、d,h,v 都为正整数。E3=1、E4=1、C=1等单位情况不作除零或遗漏；相应的素数断言为空。我们将证明 U>0、n-3U>0、P0>0，因此 U、n-3U、P0、r 的零分支都不存在。所有分母 n-1、n-3、g、I3、E4、C 非零。

## P1. 从原二项式恢复完整源窗口

由阶乘计数，对素数p有

```
v_p C(n,j) = Σ_{H≥1} [ floor(n/p^H)-floor(j/p^H)-floor(k/p^H) ].
```

每个被加项为0或1。设 p≥7，p^e 是 n-r 的完整p幂，0≤r≤5。分母6!不含p，窗口中也只有n-r可被p整除，所以 p|C(n,6)。NC6使上述每项为0。特别在H=e，令Q=p^e，必有 j modQ=b、k modQ=r-b，其中0≤b≤r。

这只是必要条件。各q_r的支持彼此不交，因为p≥7不可能整除两个差距≤5的窗口整数。r>0时 gcd(q_r,g)=1，因为共同素因子将同时整除n和n-r，从而整除r。

B尾的准确小部为

```
q1=n-1,  q3=(n-3)/3,  q4=(n-4)/2,  q5=(n-5)/5^E.
```

理由：n≡2 mod8、n≡0 mod9、n≡5 mod25。于是v2(n)=1、v5(n)=1、v3(n-3)=1、v2(n-4)=1；这些行没有其他2/3/5因子。又因α=3^a，v2(g)=v5(g)=1，特别10|g。

## P2. 第一行、完整分配与平方规范

q1源使n-1|J，因此U=J/(n-1)为正整数。由g²|J及gcd(g,n-1)=1，U=g²t，t为正整数。

设(n-1)J=10Y²。代入J=(n-1)U，按每个素数的奇偶估值比较可知U=10W²；又g²|10W²，因10平方自由，g|W。故有唯一正整数z使

```
U=10g²z².
```

注意这不是只保留radical，而是逐素数完整指数的结论。

按原槽分组，

```
q3=E3 I3,
q4=E4 A4 C,
```

E3、E4是端点块，I3是第3源的两个近侧槽，A4是第4源两个近侧槽，C是第4源中央槽。定义与Overview一致：E_r=gcd(q_r,J)，C=gcd(q4,j-2)，A4=gcd(q4,(j-1)(k-1))。源必要条件保证每个完整素数幂全在一个槽，故这些是完整互素分配。

模完整源幂计算：端点给 E3 E4|U；I3、A4以及全近侧q5给 I3 A4 q5|U-1；中央块给 C|3U-4。各块互素。

写E3E4=d h²，d平方自由。因为gcd(E3E4,10g)=1且E3E4|U，必有E3E4|z²。逐素数写指数m=δ+2b、δ∈{0,1}，则v_p(z)≥b+δ，所以z=d h v，v为正整数。d与h可以共享素数，不曾假定二者互素。

因此

```
U=10g²dv²E3E4,
η=(U-1)/(I3 A4 q5) ∈ Z_{>0}.
```

U≥10g²≥1000，故η不为0。并且

```
U≤n²/[4(n-1)]<n/3              (n>4),
```

从而n-3U>0。

## P3. L3、r的准确恢复及整数性

置

```
L3=(n-3U)/(3g I3 C).
```

因为α/3为整数、U=10g²z²，3g|n-3U。模I3，n≡3、U≡1，故I3|n-3U。模C，n≡4、3U≡4，故C|n-3U。I3、C与3g互素，所以L3为正整数。

由E3I3=(n-3)/3、A4q5η=(U-1)/I3，直接相减得到

```
E3-A4q5η = (n-3U)/(3I3)=gCL3.             (3.1)
```

置

```
P0=4(n-3)(n-4)-9nU+27U²,
r=P0/(24q3 E4 C²).
```

q3|P0：第3行n≡3，端点U≡0、近侧U≡1，代入均得0。E4|P0：n≡4、U≡0。

C²整除要保留完整精度。对每个完整p^e|C，令x=n-4、y=j-2，则p^e同时整除x,y。J=(2+y)(2+x-y)，n-1=3+x是p单位。直接展开

```
(n-1)² P0
= 4x⁴-9x³y+10x³+36x²y²+45x²y+6x²
  -54xy³-45xy²+108xy+27y⁴-108y².
```

所有单项式总次数≥2，因此p^(2e)|P0。各中央素数全部相乘给C²|P0，不降幂。

再看小素数。v2(U)≥3，n≡2 mod8使第一项4(n-3)(n-4)的2估值恰3，其余两项估值≥4、≥6，所以v2(P0)=3。n≡0 mod9使第一项3估值恰1，其余项至少4、3，所以v3(P0)=1。故24|P0。q3、E4、C彼此互素且与24互素，因此r是整数。

正性：

```
P0=27(U-n/6)² + (13/4)n²-28n+48.
```

后二次式在n≥14严格为正（n=14时为293，之后严格递增）。所以r≥1；另有r奇且3∤r。本段只计算了一次C²精度；不将另一种V4整数写法重复计作新增信息。

## P4. 间距恒等式：本轮首路线的准确结论

从q4=E4A4C=(n-4)/2，有

```
8CE4(n-3) A4 = 4(n-3)(n-4),
8CE4(n-3) Cr = P0.
```

相减并展开，得到

```
Dgap:=A4-Cr=9U(n-3U)/(8CE4(n-3)).          (4.1)
```

另一方面，因I3=(n-3)/(3E3)，

```
L3=E3(n-3U)/(gC(n-3)).                   (4.2)
```

故对这些有理表达式恒有

```
Dgap-(45/4)g³dv²L3
 = 9(n-3U)(U-10g²dv²E3E4)/(8CE4(n-3)).   (4.3)
```

在P2的规范关系下右边恰为0，恢复Overview间距式。Dgap>0，且r≥1，因此A4>Cr≥C。

结论限定：在本组真实参数的恢复关系中，间距等式的数值部分不增加方程秩。它可以是有用的估计表达式，但不能在已有U平方规范后作为第二条独立约束再次做消元。r、L3的整数性仍必须保留；本证明没有判定ell6/ell7链、其他完整源或实际NC6条件冗余。

## P5. 全部列明的粗素数估值

本节只讨论p≥7，不把结论误套到2、3、5。

### P5.1 p|g

q3、q4、q5与g互素，所以E3,E4,I3,A4,C,q5都为p单位；d、h也是p单位。写s=v_p(g)>0、w=v_p(v)。由n=g3^a、U=10g²d²h²v²得

```
v_p(n)=s,  v_p(U)=2s+2w,
v_p(n-3U)=s.
```

因此v_p(L3)=0；由(4.1)得

```
v_p(Dgap)=3s+2w.
```

这是完整相消后的准确等式，不是只给下界。

### P5.2 p|E3或E4

设m=v_p(E_r)，u=v_p(U)。端点完整分配给u≥m，平方规范给u为偶数。

若r=3，n≡3 modp，n-3U为p单位，v_p(n-3)=m，其余(4.1)分母为单位。若r=4，n≡4 modp，n-3U为单位，v_p(E4)=m，其余分母为单位。两种情形均有

```
v_p(Dgap)=u-m,  v_p(L3)=0.               (5.1)
```

### P5.3 p|q5，全近侧

此时n≡5、U≡1 modp，所以n-3U≡2、n-3≡2。E3,E4,I3,A4,C,g均为单位。于是(4.1)、(4.2)给Dgap、L3为单位。又P0≡-10 modp，r分母为单位，所以r为单位。这里没有隐藏的p=2或5异常，因为p≥7。

### P5.4 中央完整幂p^m|C

写x=n-4、y=j-2。**完整性**给v_p(x)=m，而v_p(y)≥m。恒有

```
(n-1)(n-3U)=x+x²-3xy+3y².
```

右边x的估值恰m，另外三项估值至少2m>m。因此

```
v_p(n-3U)=m,
v_p(L3)=0.
```

这说明中央源在L3分母中的精度被准确取消，而非提供额外的高次L3因子。A4源也使n-3U≡1 modp，故p|A4时L3为单位。

上述g、E3、E4、q5支持互不相交，不能制造不存在的“同一个p同时在两个块”的冲突。

## P6. 真实缺欠的等价平方分拆

令Δ_r=E_r²/gcd(E_r²,J)，r=3,4。对p|E_r有p∤n-1，因此v_p(J)=u。故

```
v_p(Δ_r)=max(2m-u,0).
```

Dgap是整数，(5.1)给v_p(Dgap)=u-m≥0，于是

```
v_p(E_r/gcd(E_r,Dgap))
 =m-min(m,u-m)=max(2m-u,0).
```

逐素数相乘得到

```
Δ_r=E_r/gcd(E_r,Dgap).
```

u为偶数，所以Δ_r为平方。E3、E4互素，所以Δ3、Δ4互素。

对E3E4上的每个素数，45/4、g、L3都是单位，间距式给

```
gcd(E3E4,Dgap)=gcd(E3E4,dv²).
```

再用E3E4=d h²：

```
gcd(dh²,dv²)=d gcd(h,v)²,
Δ3Δ4=(h/gcd(h,v))².
```

此式无需d与h互素。它不界住h或v，不把两项实际大缺欠变成绝对有限化。

## P8. 一个源的全部高层：精确剥离与无界障碍族

### P8.1 单素数的全高层恒等式

设p≥7，Q=p^e是n-5的完整p幂，原近侧槽取σ≡1、τ≡4 modQ，其中{σ,τ}={j,k}。写

```
n=QA+5,  σ=QB+1,  τ=Q(A-B)+4.
```

原题合法性给σ,τ≥7，故1≤B≤A−1；特别B与A−B均非零。又p∤A。对H≤e，各层没有进位；对H=e+h，三个floor分别等于A、B、A-B除以p^h的floor，因为1,4,5均小于Q。逐层求和给

```
v_p C(n,j)=v_p C(A,B).                  (8.1)
```

这是等价的**单素数估值**恒等式，不是NC6的等价下降。

在第一行U为整数的真实全近侧输入上，还可写

```
U-1=Q B[Q(A-B)+3]/(QA+4).
```

两方括号中的单位分别模p为3和4，所以

```
v_p(U-1)=e+v_p(B),  v_p(η)=v_p(B).      (8.2)
```

第二式用到q5中p指数恰e且I3,A4与p互素。这允许运输实际η精度，但不使v_p(B)有统一上界。若U不是整数，第一式作为有理数恒等式仍成立，不能再把其商叫作NC的η。

### P8.2 无界整数族

对任意整数t≥1，取

```
L=2+1500t,
p=53,
j=53^L+1,
n=26342j+110,
k=n-j.
```

记K=26342=53·497+1。

**合法性与真实g。** n>2j、j≥7。gcd(n,j)=gcd(110,j)。L≡2 mod4使5|j；j为偶数。模11，53≡9而9的阶是5，因此9^L不可能为-1，故11∤j。于是gcd(n,j)=10，且g⁴<n。这里没有将任意标量冒充gcd。

**目标尾类与完整5层。** 精确计算

```
53^1500≡1 mod9000,     53^1500≡1 mod625.
```

因此n同余于L=2的基值

```
n0=26342(53²+1)+110=74021130.
```

该数模9000为5130，模625为505。所以n≡5130 mod9000且n-5≡500 mod625，v5(n-5)=3。这是用两个明确周期证明所有t，不是从样本外推。

**原始完整53源幂。** 置

```
A=(n-5)/53=497·53^L+53^(L-1)+499,
B=(j-1)/53=53^(L-1).
```

A≡499≡22 mod53，故v53(n-5)=1。由于5与53互素，q5中完整53幂也恰为53。这个指数从未被扩成L。

原槽为j≡1、k≡4 mod53，且v53 C(n,6)=1。

**全部高层无进位。**

```
A-B=497·53^L+499.
```

因为t≥1，所以499<53^(L-1)。B只有第L-1位为1；A-B在该位为0，其高部从第L位开始，低部位于第L-1位以下。两者相加没有任何进位。因此v53 C(A,B)=0，由(8.1)得到

```
v53 C(n,j)=0
```

在所有层成立，包括高于原始源指数1的任意层。不需要把有限多层验证冒充全层证明。

又A≡22 mod53，A≥6，所以v53 C(A,6)=0。原见证源53在剥离后不再属于C(A,6)的素因子集合。因此不能从(8.1)声称一个保留全部原见证结构的NC6下降。

**残量估值可以无界，但这里只是有理数。** 在该整数族上，U_rat=jk/(n-1)不是整数，然而(8.2)的有理数版本给

```
v53(U_rat-1)=1+v53(B)=L.
```

这不能叫作实际NC参数η的无界反例。

**为何不是原题反例。** 模7，53的阶为3，1500是3的倍数，故53^L≡2、j≡3。K≡1、110≡5，故n≡1、k≡5。第7进第一位相加3+5产生进位，且7|n-1；6!不含7。因此对所有t

```
7 | C(n,6),   7 | C(n,j).
```

同一观察也直接给7∤jk、7|n-1，所以U_rat不是整数，第一源行失败。

作为另一个准确整数检查，令x=j、D=110，则

```
K² x[(K-1)x+D]
 -(Kx+D-1)[K(K-1)x+K+D-1]
 =-(D-1)(K+D-1)=-2883159.
```

n-1>2883159也独立排除n-1|jk。它不是丢失小例外的渐近论证。

### P8.3 精确方法边界

该族否证：正确尾类、真实gcd及g⁴<n、一个新支持完整近侧源幂，足以强迫该源在某个更高层进位。

它不满足第一源行；全q5近侧、α=3^a、十倍平方、真实η、低残量、L4/L7逃逸条件及全部邻行链均未建立。特别不声称p∤L4L7，因为该族没有当前原输入的这些整数定义。

本族不否证“把所有这些条件联合起来后，可以强迫某个源进位”。下一轮不能把这一较弱方法边界扩大成区域不可证明。
