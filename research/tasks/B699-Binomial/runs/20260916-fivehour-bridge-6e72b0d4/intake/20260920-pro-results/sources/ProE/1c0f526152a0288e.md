# B699 Pro E — PLUS-SQUARE

入口：REPORT.md → PROOFS.md → HANDOFF.md。

核心结论：n=2(p^h+1)² 的全部合法 i3 数对；以及 n=2(mp^h+1)²、gcd(m,p)=1、p^h≥72m³ 的全部合法数对。

重放（无网络，只需 Python 标准库）：

```bash
python3 replay.py
```

条件消费者（原行结论，不要求两底）：

```bash
python3 consumer.py --p 31 --h 3
python3 consumer.py --m 5 --p 1009 --h 2
```

consumer 精确检查小型素数底，主动拒绝超过实现资源护栏的底数/输出尺寸；这些护栏不是定理限制。未触发消费者时不是反例，也不是全历史消费者的否定。

certificate.json 包含30个 m=1 数字模板、全参数多项式及全部30106个原始有限末端见证。

`generate_certificate.py` 可独立重建数值证书，但重建会写入证书文件；正常只读重放不调用它。

SHA256SUMS 覆盖除自身外的全部成员。无限数学论证的证据等级及来源缺口见 SOURCE_ADOPTION.md；失败和剩余边界见 FAILURES.md。
