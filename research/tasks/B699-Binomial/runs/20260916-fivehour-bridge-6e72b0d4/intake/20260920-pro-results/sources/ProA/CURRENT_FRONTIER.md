# 当前真实前沿（本会话结束）

## 已证明的同一-G结论

对原 K152 的**同一个固定非零整数多项式 G**：

```math
|C_G| ≤ 10.
```

若剥去六条源竖线全部幂，记 `h=deg_X G`、`V=Σv_r`、`E=305-2h-V`，则：

- `E≥1 ⇒ |C_G|≤9`；
- 若 `|C_G|=10`，必须 `E=0`；
- 此时 `D(G)=305`；
- `Gbar` 的全部非恒定不可约因子都必须零余量 `D=2e`，不只可载点因子；
- 第4轮 LOC89+TRACE 后，达到10的必要竖直状态只剩 **71个**；最大放松记录只剩 **390条**；且 `h≥107`。

这些71个状态、390条记录只是必要预算状态，不是实际G分解或原题候选。
