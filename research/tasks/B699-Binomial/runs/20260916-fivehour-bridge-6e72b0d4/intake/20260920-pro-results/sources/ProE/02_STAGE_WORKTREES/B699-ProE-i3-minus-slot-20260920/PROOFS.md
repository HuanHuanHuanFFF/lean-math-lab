# PROOFS — MINUS1 与负号聚合单槽整行消费者

日期：2026-09-20。作者研究轮次；无 Lean，无外部独立数学审稿。

## 0. 精确结论与原题语义

Common3(n,j) 表示存在同一个奇素数 q，同时整除 C(n,3) 与 C(n,j)。合法区间为 4≤j≤floor(n/2)。本轮证明：

**MINUS-SLOT（数对子域充分消费者）。** X≥2 为偶整数，n=2X²。若原合法 j 满足

    j mod (X+1) ∈ {0,1,2}，

则 Common3(n,j)。X+1 可以是任意合数，不要求是素数幂；本条件确切地表示整个聚合整数 X+1 整除 j、j−1、j−2 中的某一个。

**MINUS1（完整整行）。** p 为任意奇素数，h≥1，P=p^h，n=2(P−1)²。则每个原合法 j 均满足 Common3(n,j)。不要求两个底数、最小 ξ、任何 g,w 或指数高侧。

核心是下面一个纯整数定理。其假设是必要模型，不能反向视作 NC3 充分条件；核心定理本身不涉及素性。

**整数核 NEG-INT。** 对每个奇整数 P≥3，置 N=2(P−1)²−1。不存在整数 j 同时满足

    4≤j≤(P−1)²，N | j(j−1)，j mod P ∈ {0,1,2}。

符号约定：§1—§3 的 b,c,r,K,k,t,y,z 均是整数核的局部变量；特别是局部 k（亦记 κ₂）不是原互补指标 n−j。原输入的互补指标在本证明中始终写成 n−j，不修改 Overview 的任何原定义。代码中的同名变量仅编码这个局部整数核。

§1—§3 完整证明整数核；§4—§6 从原二项式推导必要条件并回传。所有商都来自同一原始 (n,j)，没有改换输入。实际内容三次 Ψ 与恢复三次 Pρ 均不在本轮使用，未被混同。

## 1. 整数核的统一范围与互素性

写

    j=bP+c，c∈{0,1,2}。

因为 4≤j，必有 b≥1。由于

    (P−1)²=(P−2)P+1，

当 c=0,1 时，b≤P−2；当 c=2 时，b≤P−3，因而此支 P≥5。

N=2P²−4P+1≡1 (mod P)，所以 gcd(N,P)=1。这允许在 N 的整除关系中约掉整个 P，即使 P 为合数。还注意到

    N−[(P−2)P+1]=P(P−2)>0。

因此对 c=0,1 的全部 b 范围，均有 0<bP−1<bP+1<N。

## 2. 末位0和1：整数商与完整互素分拆

### 2.1 末位1

j=bP+1。由 N|j(j−1) 及 gcd(N,P)=1，得到

    N | b(bP+1)。

定义实际整数商 r=b(bP+1)/N。§1 严格给出 0<r<b<P。但模 P 有 r≡b，矛盾。

这里没有把数值整除误写成多项式整除；r 是原数值上的正整数。

### 2.2 末位0

j=bP。类似地，实际商

    r=b(bP−1)/N

满足 0<r<b<P，且 r≡−b (mod P)。所以只能 r=P−b。精确代回有

    b(bP−1)−(P−b)N
      =P[(b+P−2)²−(P−1)(3P−5)]。

由 P>0，得到

    (b+P−2)²=(P−1)(3P−5)。                 (2.1)

令 z=(P−1)/2≥1，则右边等于 4z(3z−1)，所以 y=(b+P−2)/2 是整数，并有

    y²=z(3z−1)，gcd(z,3z−1)=1。

对任意素数 ℓ，互素性意味着 ℓ 的全部赋值只能出现在一个因子中；乘积为平方则该因子的赋值也必须偶。因此 z 与 3z−1 均为正整数平方。但

    3z−1≡2 (mod 3)，

不可能是平方。

这一步保留完整素数赋值。它是一个完整的互素分拆证明，不需要枚举 Pell 轨道、不依赖任何待求整数点集，也没有把非酉因子假定成酉因子：互素性已由 3z−(3z−1)=1 直接证明。

## 3. 末位2：实际商只产生两个平方剩余类

j=bP+2，1≤b≤P−3，P≥5。令

    K=j(j−1)/N∈Z_{>0}。

因为 N≡1、j(j−1)≡2 (mod P)，必 K=Pk+2，其中 k≥0 为整数。展开并约掉 P，得到

    kN=(b²−4)P+3b+8。                       (3.1)

我们先证明 k<b，而不预设 k 的大小。精确恒等式为

    bN−[(b²−4)P+3b+8]
      =P[b(2P−b−4)+4]−2b−8。

写 b=B+1、P=b+3+D，B,D≥0，右侧精确展开成

    B³+3B²D+8B²+2BD²+14BD+21B+2D²+15D+18>0。

故 0≤k<b。由 (3.1) 模 P，k≡3b+8 (mod P)，所以

    t=(3b+8−k)/P

为正整数。而

    0<3b+8−k≤3b+8≤3P−1，

故 t∈{1,2}。这个两值结论是对全部 P,b 的严格有限化，不是试扫 P 后观察到的模式。

代入 k=3b+8−tP，再利用精确恒等式

    [(b²−4)P+3b+8]−(3b+8−tP)N
      =P[(3P−6−b)²−((9−2t)P²+(4t−20)P+8−t)]，

得到

    t=1:  (3P−6−b)²=7P²−16P+7；
    t=2:  (3P−6−b)²=5P²−12P+6。

P 为奇数，第一右侧模8为6，第二右侧模8为7。整数平方模8只可能是0、1、4，两个状态全部不可能。

§2 与本节穷尽 c=0,1,2，NEG-INT 对所有奇 P≥3 证明完毕。P=3 的 c=2 分支根本没有合法 b；c=0,1 的论证仍适用。不存在未处理的小 P、半行端点或符号分支。

## 4. 从原二项式到第一窗口（必要条件，自包含）

对任意素数 q 和正整数 n，阶乘中 q^e 倍数的计数给出

    v_q C(n,j)=Σ_{e≥1}[floor(n/q^e)−floor(j/q^e)−floor((n−j)/q^e)]。

每项均为0或1。若 q 不整除 C(n,j)，则所有项为0；特别地，对每个 e≥1，

    j mod q^e ≤ n mod q^e。                   (4.1)

这里只使用这一层层的必要条件，不将弱源窗口倒推成无 q 进位。

现在 n=2X²，X 为正偶数，N=n−1。N 为奇数；模3，X²为0或1，所以 N≡2或1，特别地 3∤N。于是 N 的每个素数 q 都至少为5，且

    v_q C(n,3)=v_q(N)>0。

若原合法数对为 NC3，则 q 不整除 C(n,j)。对于 q^e∥N，n≡1 (mod q^e)，由 (4.1) 得

    j mod q^e ∈{0,1}。

因此 q^e|j(j−1)。将 N 的所有完整幂相乘，得到必要条件

    N | j(j−1)。                              (4.2)

这里真实 λ=1 是由原 n 自动推出，不是擅自忽略一次3。

## 5. MINUS-SLOT 的同输入回传

令 P=X+1，因 X 偶而 P 为奇整数≥3。原合法半行即

    4≤j≤X²=(P−1)²。

若 j mod P∈{0,1,2} 且 NC3，则 §4 给 N|j(j−1)，与 NEG-INT 矛盾。

实际上可以从第一窗口本身选出见证：由于 NEG-INT 表明 N 不整除 j(j−1)，存在某个 q^e∥N 使 q^e 不整除 j(j−1)。因为 gcd(j,j−1)=1，j mod q^e 不是0或1，故至少为2。在 n mod q^e=1 的层上，原 binomial 的进位为1，所以 q|C(n,j)。又 q≥5 且 q|C(n,3)。因此此消费者的见证可选自 n−1 的一个原素数。

注意 P 可以合成，但这并不是对合成基数使用 Kummer：本节的假设已经直接给出整个 P|j−c。不同素数幂若进入不同槽，则此假设不成立，不能合并。

## 6. MINUS1 的完整源、原3端点与整行回传

P=p^h，p 为奇素数，h≥1；n=2(P−1)²。精确分解

    n−2=2P(P−2)，gcd(P,P−2)=1

说明原 p 的完整幂恰为 P。p 不整除 n 或 n−1，故

    v_p C(n,3)=h                 (p≥5)，
    v_3 C(n,3)=h−1               (p=3)。

当 P≥5 时这个赋值总是正：若 p=3，则 h≥2。所以对每个原合法 j：

- 若 p|C(n,j)，p 就是同一个合法共同奇素数；
- 若 p∤C(n,j)，则 (4.1) 在完整层 p^h=P 给出 j mod P≤n mod P=2，此时调用 MINUS-SLOT，得到 n−1 中的共同素数 q≥5。

整个证明甚至不需要原 p 在更高层的无进位条件。高次3幂 P 仍整块保留，没有根据 v_3 C(n,3)=h−1 把源截成 3^{h−1}。

唯一剩余 P=3 是真实孤立一次3例外，此时 n=8，唯一合法 j=4，

    C(8,3)=56，C(8,4)=70，gcd=14。

共同奇素数7直接结束端点，不把3误称作源见证。

综上，所有奇素数 p、所有 h≥1、所有原合法 j 都包含在 MINUS1 中。不需要固定指数末端或 n 扫描。

## 7. 准确更新的前沿与旧结果的采用等级

MINUS-SLOT 与 MINUS1 的证明均自包含，不依赖旧 L/h13、类群、分圆、SQ-HIGH、PLUS1 或任何源下界11。原 Ψ、Pρ、g、α 等不被改写；由于直接从原数对矛盾出发，不必用它们产生更多冗余方程。

结合上一轮作者等级的 PLUS1（n=2(p^h+1)² 整行），任意仍可能的 NC3、n=2X²、X正偶，必须

    ω(X−1)≥2，ω(X+1)≥2。

X=2 已由 n=8 的唯一端点排除。又 gcd(X−1,X+1)=1，所以

    ω((n−2)/2)=ω(X²−1)≥4。

但这不是 ω(t3)≥4，因为原 H 可以含额外底数。对于真实 K=(n−2)/(2μ)，只能直接得到

    μ=1: ω(K)≥4；
    μ=3: ω(K)≥3。

孤立一次3被删除时不能错误地仍保留四底结论。

还有一个不需要旧 PLUS1 的新必要条件：整个 X+1 不得整除 j、j−1、j−2 中任何一个。若 X+1 不含被删除的孤立一次3，则 NC3 下它的全部源幂必分配到至少两个不同槽。若 3∥X+1，应保留真实孤立3例外，不能自动把上述槽数结论施加到 (X+1)/3。

一般两底低/低、X±1都有至少两底的行、最小支 2^{6t} 与 3·2^s 仍未闭合。没有一般绝对高度、NC3保持下降或全i3结论。全R7不变。
