# 本轮报告：完整素数幂加一的二倍平方整行

## 最强新增结论

**PLUS1（完整整行）。** 对任意奇素数 p、整数 h≥1，置 P=p^h，则

    n=2(P+1)^2

的每一个合法 4≤j≤floor(n/2)，都存在同一个奇素数 q 同时整除 C(n,3)、C(n,j)。

不假定 g=1、w=1、最小 ξ、ω(t3)=2、任何高/低指数侧、α 的具体分支或某个位宽。特别地，这不是只给一个二倍平方行的两底数对子域；它确实是所列 n 的全部合法 j。

**PLUS-DOM（变动余因子整行）。** 任意正整数 m、奇素数 p、h≥1，若 gcd(m,p)=1 且

    P=p^h ≥72m^3，n=2(mP+1)^2，

则该 n 的全部合法 j 同样满足 Common3。m、p、h 都可无界变化；72 是已证明消费者的门槛，不是对一般 NC3 参数的绝对上界。

m=1 的 PLUS1 不留 P<71 的缺口：纸面尾部覆盖 P≥71，全部更小的奇素数幂已经逐一完成原始二项式验证。没有待求整数点或待做的有限末端。

## 相对于上一轮的前沿变化

上一轮 SQ-HIGH 只在 n=2X²、ω(t3)=2 中排除了至少一侧高指数，留下两侧低指数。
本轮最先检查这个低/低域的双奇商；未取得一般矛盾，见 FAILURES.md 与 PROOFS.md §8。

因此在仍可能的 NC3、n=2X²（X正偶）中：

    ω(X−1)≥2；
    对 X−1 的每个完整奇素数幂 P，写 X−1=mP，则 P<72m³。

X=2 的 n=8 唯一合法 j=4 由共同素数7直接排除。
这个结论同时约束两底低/低与更多底数输入；但并没有关闭全部二倍平方行或全部两底低/低域。

没有把所有 p,h 或 m 的例子重复计数；没有完成与全部历史消费者并集的非空差集审计。新证明独立于此前 SQ-HIGH、L/h13、类群、分圆、g≤2 等作者链。全 i3 和 R7={3,4,5,6,7,8,9} 不变，没有发现原题反例。

## 机制

1. 原 n−1=2(mP+1)²−1 为奇数且不被3整除。NC3 下，其每一个完整奇素数幂的无进位迫使 n−1 | j(j−1)。本轮自包含推导，不需要未展开的作者窗口定理。
2. P 是 n−2 中原 p 的完整幂。p=3 时保留真实 v3(C(n,3))=h−1；尾部确保它为正，h=1 的例外在有限整行核验中保留。
3. n 的基 P 数字为 (2m²,4m,2)。无 p 进位把 j 限制成 uP²+vP+c，其中 0≤u≤m²、0≤v≤4m、c∈{0,1,2}。
4. 精确恒等式 4m⁴j(j−1)=(n−1)L(P)+R1P+R0。R1、R0 是整数，|R1|≤144m⁵、|R0|≤89m⁴，非零 R1 是4m的倍数。P≥72m³ 时余数非零而绝对值小于 n−1，矛盾。
5. 余数恒等为零只可能给 j=0 或1；不可把这两个非法输入纳入原题。m=1 的精确表把尾部降到 P≥71；原始有限末端完成全部22行、30106个合法数对。

末端数量仅记录验证范围，不是本轮主要进展或原题剩余规模。
