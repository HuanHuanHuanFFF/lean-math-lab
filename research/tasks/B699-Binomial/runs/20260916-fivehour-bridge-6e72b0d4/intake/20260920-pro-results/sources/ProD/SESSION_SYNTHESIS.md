## 1. 阶段 01 · i6 precision boundaries

原包：`original_archives/B699-ProD-i6-precision-boundaries-20260920.zip`

### 真正得到的结构

在全近侧低残量同一原输入上，重建间距量并证明

```text
D_gap = A4 - C r
```

与已有规范恢复之间存在准确因式分解；代入真实规范关系后，间距数值等式恒等成立。因此它不能被第二次当作独立方程计入消元。

完成了对应的 p 进估值账本，明确区分 `p|g`、`p|E3/E4`、`p|q5` 等来源，并把两侧缺欠重写成完整指数关系；没有把 `C²` 与 `V4` 整数性重复计权。

### 精确失败边界

构造两个无界弱模型：

1. 满足真实 `alpha=3^a`、真实 gcd、十倍平方和尾类的一部分条件，但违反全近侧/低残量；因此只否证较弱“全局恢复子系统已经无解”。
2. 具有集合外 q5 源素数且全部高层不进位的无界族，但第一源行失败并存在真实共同见证；因此只否证“单独追踪一个新支持素数足以闭合”。

### 未解决

全近侧、真实第一源、全部 q2/q3/q4/q5 分配、纯 3 幂、邻行与低残量的联合系统仍开放。

## 2. 阶段 02 · joint recovery + terminal transfer

```text
H = 16(n-3)(n-4) - 36(n-3)U + 27U²
T = 8(n-5)(n-4)(n-3) - (U-1)H
L6, L7, ell6, ell7
```

及实际两正项纯 5 幂恢复。

证明第三恢复式与原邻行/`U-1` 恢复有显式线性组合关系；因此在那些恢复已使用后，第三数值等式也不能再当成独立消元方程。

```text
X5 + Y5 = 5^E,
X5,Y5>0,
gcd(X5,Y5)=1,
```

## 3. 阶段 03 · q2 discriminant + shift obstruction

原包：`original_archives/B699-ProD-q2-discriminant-and-shift-obstruction-20260920.zip`

### q2 完整源精度的准确缺额

定义

```text
E2 = gcd(q2,U)
M2 = gcd(q2,j-1)
D2 = q2/(E2 M2)
```

证明完整 q2 源窗口等价于 `D2=1`，并得到原判别式

```text
A2² - B2² = (n-1)(U-1)/M2².
```

这说明仅有真实 gcd 与 `M2² | U-1` 仍不足以恢复完整 q2 源幂；完整缺额 `D2` 不能被判别式自动消掉。

### 无界弱反模型

构造保留真实 gcd、正确尾类、第一源、十倍平方、判别式、低残量若干条件的无界原整数族，但其完整 `31²` q2 源层发生真实进位。它缺少 `alpha=3^a`/全近侧等关键条件，因此不是 NC6 反例。

### 平移失败边界

系统检查 `(n,j)->(n-2,j-1)`：新数对合法且更小，但新见证可能全部来自 `v_p(jk)`，不能直接回传原目标。给出全参数 11 进反例族，准确说明直接下降为何失败。

## 4. 阶段 04 · ternary support recovery

原包：`original_archives/B699-ProD-ternary-support-recovery-20260920.zip`

### 三进制支持消费者

在真实 B 尾、`alpha=3^a` 与十倍平方恢复下，对实际分量 `x in {beta,gamma}` 建立

```text
x² = alpha H_x + t,
H_x = floor(x²/alpha),
t = x² mod alpha,
g = (x-H_x)/t.
```

由此完整分类并证明：

```text
wt_3(beta) <= 3  or  wt_3(gamma) <= 3
=> Common6.
```

又关闭较小侧四个彼此充分分散的非零位支持族。

### 失败边界

识别一个真实无界三位恢复例外；它满足真实 gcd、纯 3 幂、第一源与合法区间，但不满足 B 尾和 W10。该例外被明确保留并正确排除，没有用有限扫描替代证明。

## 6. 阶段 06 · signed denominators + periodic blocks

原包：`original_archives/B699-ProD-signed-denominator-and-periodic-blocks-20260920.zip`

### DEN± 原输入消费者

对任一实际分量 `x in {beta,gamma}` 定义规范约分分母

```text
Q_-(x) = (alpha-1)/gcd(alpha-1,x)
Q_+(x) = (alpha+1)/gcd(alpha+1,x).
```

证明条件消费者

```text
Q_-³ <= alpha
or
(Q_+-1)³ <= alpha
=> Common6.
```

加号零分支 `(g+1)x=alpha+1` 被单独恢复，并由第三源完整排除。

### 无界重复块族

关闭普通完整重复块 `m>=3` 的全部参数：块值、块长、重复次数都可无界。也关闭奇数次交替几何块。

所以在这类实际完整重复表示的 NC 分支中，重复次数统一满足 `m<=2`。

### 失败边界

给出一个真实零分支的无界原整数族，证明该退化并非空形式；它不满足 W10 且有真实第三源共同见证。这样准确否证“加号余式总非零”的错误简化。

## 7. 阶段 07 · one-candidate norm lattice

原包：`original_archives/B699-ProD-one-candidate-lattice-20260920.zip`

### UROW：同一 n 至多一个真实恢复

保留真实 gcd、`alpha=3^a`、第一源与 W10。定义

```text
delta = alpha - 2 beta,
D = 40(n-1).
```

得到本原范数恢复

```text
delta² + 40(n-1) z² = alpha²,
gcd(delta,z)=1,
3 does not divide delta*z.
```

证明：**固定同一个 n，满足这些真实恢复条件的合法 j 至多一个**，即使同时允许所有可能的 `g,a`。

证明利用两个恢复之间模较小 `alpha²` 的单位平方根刚性与严格大小界，不是固定 g 的简单单调性。

### LROW：单格完整恢复候选

在当前 NC6 冻结质量出口 `8g^4<n` 下，选择最小允许 3 指数，构造一个二维整格与正二次型。证明短向量严格共线，原恢复的本原性进一步强制候选必须是精确最短向量。

因此对每个固定 n：

- `EMPTY`：该 n 的真实恢复不存在，可由原完整源缺额回传 Common6；
- `CANDIDATE`：至多一个原 `(g,a,z,beta,j)` 需要继续检查全部 q2/q3/q4/q5、全近侧、中心较小、缺欠和高层无进位。

这不是 NC6 的等价算法；它只压缩了 F1+W10+真实 3 幂商+低质量恢复。

### 未完成

尚未证明所有可能出现 `CANDIDATE` 的无界 n 行最终都被完整源条件排除，因此没有统一有限末端。

## 8. 本会话累计可直接复用的核心结论

### 8.1 不能再重复计作独立信息

- `A4-Cr=(45/4)g^3dv^2L3` 的数值等式在规范恢复后有精确依赖关系。
- 第三纯 5 幂恢复式在三个邻行和 `U-1` 恢复之后也有精确依赖关系。
- `C²` 整除与 `V4` 整数性仍是同一中心平方约束，不能重复计权。

### 8.2 已完成的条件支持族

- 任一 `beta/gamma` 的真实三进制非零位数 <= 4：Common6。
- 规范有符号分母进入立方门槛：Common6。
- 完整普通重复块 `m>=3`：Common6。
- 完整交替奇重复块 `m>=3`：Common6。

### 8.3 原输入恢复压缩

- q2 完整源的准确缺额参数 `D2` 已分离。
- 固定 n 下，纯 3 幂+第一源+W10 的真实候选 j 至多一个。
- 在 `8g^4<n` 下可由一个二维格完整恢复该唯一候选或证明为空。

### 8.4 已经明确失败的方法

- 仅用间距/第三恢复的数值方程继续做结果式：会重复已有恢复信息。
- 仅追一个 q5 新支持素数的全部高层：存在无界弱族。
- 仅真实 gcd + q2 中心平方，不足以恢复完整 q2 源。
- `(n,j)->(n-2,j-1)` 直接运输共同素数：目标估值可能全部来自 `v_p(jk)`。
- 删除 W10 后的稀疏/零分支加强：存在真实无界原整数弱模型。
- 把固定有限模筛、扩大指数扫描或样本无反例当成无界证明：全部明确禁止并未采用。

主前沿仍是 i6/H025 两尾中真实 RES10、全近侧、`C<A4`、低残量支。至少仍需同时控制：

```text

第一源与 W10
```

结合本会话新增结论，任何仍存 NC 候选还必须避开：

```text

Q_-³ <= alpha
(Q_+-1)³ <= alpha
完整重复块 m>=3
格恢复 EMPTY
```

因此当前最准确的剩余缺口是：

1. **对出现格 `CANDIDATE` 的无界 n 行，接回完整 q2/q3/q4/q5 条件并统一排空。**
2. **证明真实源分配是否强迫某个 `Q_-`/`Q_+` 进入已闭立方门槛。**
3. **控制两侧都至少 5 个三进制非零位、非周期、规范分母都大的输入。**
4. **仍未证明也未否证**：正确 5130 尾 + 真实 `alpha=3^a` + 第一源 + W10 是否已经强迫 `g^4>=n`。
5. 尚无 `n,E,a,g,q5,v,eta` 的统一绝对界；尚无保持 NC6 的严格数对下降。
6. 一般 i5、i7、i8 的未解决粗块区域没有被本会话整体接管或闭合。
