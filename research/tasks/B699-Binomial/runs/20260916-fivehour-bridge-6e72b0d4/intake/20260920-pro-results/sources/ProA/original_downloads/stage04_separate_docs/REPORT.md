## 3. 新TRACE约束为什么有效

同一实际竖直分配下，E=0使Gbar权次恰2h，X最高系数是非零常数。首一化后

    Gbar(N,X)=X^h−S(N)X^(h−1)+…，deg S≤2。

对某源行，如果扣除已知S/L因子的普通缺重和对角费用后，剩余普通缺重容量恰为0，那么完整Gbar在该行的普通阶、额外特化根都可能被精确确定。

关键是对角κ：某行的普通额外重数不能随意放在任一源点。预算等号会迫使它全部放在对角中心。另有冻结S4、S5的缺1分别是碰撞根3、6；本轮以完整多项式恒等式重新核对，适用于全部非零有理参数。

由此恢复若干行的**完整特化根多重集**，不只是普通阶之和；它们的根和必须落在同一个二次多项式S(N)上。接收器用整数4×4 Vandermonde增广行列式，发现器用有理插值，两者逐记录一致。

对于缺重在r3且额外根尚未知的S3/L，不强行填入根和；未耗尽普通容量的行也不强行固定。E>0时不使用首一零余量结论。
