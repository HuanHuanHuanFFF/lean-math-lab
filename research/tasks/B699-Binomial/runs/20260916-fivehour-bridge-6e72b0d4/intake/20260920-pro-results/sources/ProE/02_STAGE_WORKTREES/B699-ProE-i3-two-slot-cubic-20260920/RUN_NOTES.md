# 本轮研究记录（结论、尝试及证据，不是聊天重建）

## 资源与范围

当前运行环境观测：cgroup内存上限4GiB；开始时使用约271MiB；CPU配额4核；/mnt/data所在磁盘约30GiB可用。串行执行有限检查，无大型并发、Lean或仓库任务。

## 路线目标与结果

1. 目标：从上一轮已闭的单槽进入真正混槽；若一般两槽不可能，可提升每侧槽数，减少真实无界域。首个否证接口为同一W1/W2的有限诊断及固定真余因子恢复。它们没有提供一般证明，结果不外推。
2. 转向：保留上一轮真实整数商，将对侧的完整源逐槽送入不同小整数，而非只记三因子乘积。成功时会删除“本侧大槽块且对侧至多两槽”的整个区域；一般三槽及所有阈值下方参数仍无界。
3. 结果：两槽最多乘两个非零表达式，得到m⁴而非m⁶；中心对端点的两列相同，只保留一次，得到m²。所有零表达式由互素平方模3单独排空。形成TS-CUBIC和CENTRAL-BOTH。
4. 真实原行实例：从二进因子诊断找到X=2^41，将全部因子重新制成确定性证书，完成n=2^83的整行消费者。诊断软件素性本身不作为证明。
5. 失败边界：构造无界三槽互素因子族，证明旧三因子整除不能单独支持新的立方上界。保存第一原合法弱点和真实共同素数5；不是NC3族。

## 实际新增与未做到

新增：明确的无界两槽大块区域排除、双侧中心缺槽消费者、支持数条件推论及一个完整原行实例。

未做到：全i3、一般三槽域、所有二倍平方行、阈值以下的有限化、一般绝对高度、NC3保持下降。原最小支2^{6t}与3·2^s仍开放。
