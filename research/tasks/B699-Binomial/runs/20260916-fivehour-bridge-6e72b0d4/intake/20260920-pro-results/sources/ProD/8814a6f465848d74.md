# 冻结上源消费者：规范契约转录

这不是上游原字节副本；准确源路径、版本及 Git blob SHA 见 SOURCE_ADOPTION.md。

共同原题：对各自合法的 i<j≤floor(n/2)，存在同一个素数p≥i同除C(n,i)、C(n,j)。所有指数为任意非负整数，没有大小上限。每个定理使用自己的 s_i；完整素数幂不能降为 radical。

## U6

    n=2^A3^B5^C+h，h∈{0,1,2,3,4,5}。

原题 i6 的全部合法 j 成立，实际 p≥7。原接收稿采用 QIG/SIXG、两对数、二维整数格及全末端；不需要旧位置前提。本轮不重跑上游无限链。

## U7

    n=d2^A3^B5^C+h，d∈{1,7}，h∈{0,1,2,3,4,5,6}。

原题 i7 的全部合法 j 成立，p≥7。d=7 仅为一次7；s7删除孤立一次7，但高次7部留在粗部。原接收稿的双高幂无界区采用旧 two-position 作者纸面/证书，单幂和末端有相应接收。本轮不将这一等级升级为独立全链数学核验。

## U8

    n=2^A3^B5^C7^D+h，h∈{0,...,8}。

原题 i8 的全部合法 j 成立，实际 p≥11。原接收稿包含全部零/一/二/三/四高指数情况、Yu输入、完整格终止和有限末端。本轮只采用该冻结结论，不再主攻 i9 或复跑这些旧计算。

## 本轮用法

只取 h=i（目标为i，上源为m=i+1）的终端位置，证明其源素数安全向下运输，并单独处理 j=m。上源合法目标区间不自动包括 j=m；该边界是本轮另行证明的。没有把必要窗口系统当作上游全 NC 的等价系统。
