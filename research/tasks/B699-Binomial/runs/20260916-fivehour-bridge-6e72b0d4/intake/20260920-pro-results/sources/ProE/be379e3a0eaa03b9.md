# B699 Pro E · 联合分圆源容量

入口：REPORT.md → PROOFS.md；直接接续用 HANDOFF.md。

本轮关闭规范最小支的二进指数条件：

- v2(s−1)=2或3；
- 20|(s−1)或28|(s−1)；
- 存在奇平方自由S，3∤S、4S|(s−1)、8S−9φ(S)≥14。

仅对 n=2^s 的同一原输入、既定规范最小支，不是整行定理。全i3未闭，R7不变。

## 离线只读重放

```bash
python3 replay.py
```

需要Python 3.10或更新版本的标准库，不需要安装第三方库。默认不运行旧ZIP中的代码，只核对它的来源字节。哈希检查要求保留包内全部文件；不要将控制台重定向进包内，否则只读快照会如实报告内容变化。

## 条件性消费者

```bash
python3 consumer.py --s 81
python3 consumer.py --s 113
python3 consumer.py --s 2289 --S 143
python3 consumer.py --s 17
```

最后一项返回没有本轮新排除，不代表存在反例。消费者不构造2^s，不认证当前(n,j)是否满足规范最小支。

## 证据文件

`certificates/certificate.json` 是新有限证书；`check_exact.py` 用整数系数运算，`check_independent.py` 用独立有理插值和递归分圆值；`check_bad_certificates.py` 实际损坏证书并送两者拒绝。

`verification/` 保存实际新检查输出；`sources/` 保存冻结前置与来源哈希；`FAILURES.md` 保存失败命题与精确诊断；`SOURCE_ADOPTION.md` 区分旧作者链、新论证及外部背景。

`generate.py` 是显式写入的再生成入口，不在只读重放中运行。重放以当前SHA256SUMS为准，不自动重写哈希。
