# 失败、适用边界及重试条件

这些是公开可复核的数学诊断，不是隐藏思维过程或聊天记录。

## F1. 单靠容量式不能排除整个四次域

待否证命题：对所有 x=2^t，两个完整源必满足 `(PQ)³≤(x⁴−1)²`。

反例于该辅助命题：x=16，M=65535=3·5·17·257，P=257，Q=17。两个数均为 M 中不同底的完整幂且≥11，有

    M²=4294836225 < (PQ)³=83396175409。

所以旧乘积大小法本身并未覆盖这个输入。真实 ν 恢复为30，但

    (PQ²−1) mod ν² = 472。

因此它不是完整整数恢复，更不是 NC3 反例；还没有恢复原 j/k、真实 gcd 和 h 等条件。本轮 VM4 正是用新的同输入平方模数接入解决这个缺口。

重试边界：只有增加真实恢复、原源估值或完整 j 条件时才能进一步排除，不能把容量反向不等式当成 NC3。

## F2. 十次域的旧小型弱分解诊断已经被消费

x=2，M=1023=3·11·31，P=31，Q=11：

    M²=1046529 < (PQ)³=39651821；
    ν=6，v=(PQ²−1)/ν²=625/6。

这个弱分解满足原 n 为二幂、源底不同、完整源幂和容量式，但 v 不是整数，也没有完整原 j/k 恢复。它不代表 NC3 点。VM10 的完整有限末端已把两个有序状态全部排除；不要再把它作为开放末端重扫。

## F3. 把十次域的“κ小于模数”推论直接移到十四次域是假的

局部命题：当 `M=(x²−1)Φ7(x)Φ14(x)` 且只有商容量约束

    W³ < Φ7(x)Φ14(x)/(x²−1)²

时，必有 `κ=UV²<(x²−1)²`。

这个从容量式单独推出的小量断言不成立。对于任意偶 x≥2，取弱商模型

    U=1，V=x²+1，W=UV。

精确恒等式为

    Φ7(x)Φ14(x)−(x²−1)²(x²+1)³
      = x¹²+3x⁶+3x⁴ >0，

故整个无界模型都通过容量约束；但

    κ=(x²+1)²>(x²−1)²。

它保留正性、奇数商和容量约束，却**没有要求 V 整除真实对应的分圆块，更没有原 P/Q 素数幂、ν/v/h 整数恢复、原 j/k 或 NC3**。因此只是精确反驳“容量单独保证小于模数”，不反驳加入真实除数信息后的十四次闭合可能性。

值得重试的新增条件：保留 U|Φ7、V|Φ14 的实际完整因子信息，或用同一 h 恢复、另一原源高层进位，再控制可能的余数绕圈商。不能仅把 VM10 的次数比较复制到 D=14。

## F4. 范围外不能擅自宣称已闭合

- VM4/VM10 只对 c_α=1 的规范最小支使用，c_α=3 不满足本轮 `M=x^D−1` 分解。
- 两项指数消费者都不排除 s 偶的剩余区域。
- 证明中必须保留有序源，AB² 与 BA² 的余式不同。
- 原底5在 x¹⁰−1 中可能跨线性块和四次块；完整赋值是 v5(x²−1)+1。漏掉这一层得到的证明无效。
- 本轮没有证明 v 为酉因子，也没有引入保持 NC3 的下降。
