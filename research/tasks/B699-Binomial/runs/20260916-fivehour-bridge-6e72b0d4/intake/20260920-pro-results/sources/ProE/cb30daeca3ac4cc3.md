# 完整证明：PLUS1 与 PLUS-DOM

日期：2026-09-20。固定原 i=3，不改变同一个原始 (n,j)。本文的 q 作为共同素数时始终 q≥3。
所有 NC3 变换均是必要条件；最后的矛盾给原题充分消费者。辅助整数/数字模板不是 NC3 的充分模型。

## 0. 精确陈述

**定理 PLUS-DOM。** 设 m≥1、p 为奇素数、h≥1、gcd(m,p)=1，P=p^h≥72m³，n=2(mP+1)²。对每个 4≤j≤floor(n/2)，Common3(n,j) 成立。

**定理 PLUS1。** 设 p 为任意奇素数、h≥1，P=p^h、n=2(P+1)²。对每个 4≤j≤floor(n/2)，Common3(n,j) 成立。

这些是完整整行，不假定 ω(t3)=2、最小 ξ、g,w、两底高侧、λμ 已有规范或任何 n 高度。
PLUS-DOM 的 m 可为任意正整数；m 偶时 X=mP+1 为奇数，定理仍成立，虽然这部分与已知浅层消费者可能重叠。

## 1. 从原二项式到完整源的无进位（必要条件，自包含）

记 k=n−j。对素数 q，用 v_q(a!) 中每个 q^e 倍数的计数，直接得到

    v_q C(n,j)=Σ_(e≥1) [floor(n/q^e)−floor(j/q^e)−floor(k/q^e)]。

每一项为0或1；它为1当且仅当 (j mod q^e)+(k mod q^e)≥q^e。
因此 q∤C(n,j) 时，每一层都没有进位，特别地

    j mod q^e ≤ n mod q^e。                              (1.1)

逐个基 q 数字也无进位，所以每个 j 数字不超过对应的 n 数字。
把连续 h 位分成一组，得到基 P=q^h 中的同样逐数字上界。
这是由无 q 进位推出的必要条件；不能把基 P 的弱数字盒倒推成无 q 进位。

令 X=mP+1，N=n−1=2X²−1。N 为正奇数，而且模3不为0。
对 N 中每个完整素数幂 Q=q^e，q≥5，均有 q|C(n,3)，且 n mod Q=1。
若 NC3，则 q∤C(n,j)。由 (1.1)，j mod Q 只能为0或1。
所以每一个完整 Q 都整除 j(j−1)，从而

    N | j(j−1)。                                         (1.2)

这一步保留 N 的全部完整幂，绝不是仅乘入各个素数底。第一窗口的真实 λ 自动为1，但本文并不需要调用 Overview 的窗口证明。

另一方面

    n−2=2mP(mP+2)，p∤m，p∤(mP+2)，

所以 P=p^h 恰是 n−2 中的完整 p 幂；p∤n(n−1)。因而

    v_p C(n,3)=h             （p≥5），
    v_3 C(n,3)=h−1           （p=3）。                    (1.3)

对 PLUS-DOM 的尾部 P≥72m³，p=3 时必 h≥4；对 PLUS1 的尾部 P≥71，p=3 也必 h≥4。
故所有尾部中的原 p 都确实整除 C(n,3)。NC3 迫使 p∤C(n,j)，于是适用整个基 P 的数字上界。
没有删除合法端点 p=3，也没有把高次3幂截成较低源幂。P=3 的孤立一次3例外由 §6 的原始二项式整行末端处理，不对它错误调用 (1.3) 的正性。

## 2. 真实数字盒（必要条件）

当 P≥72m³，显然

    2m²<P，4m<P，2<P，P²>2mP+1。

于是原 n 的基 P 展开是

    n=2m²P²+4mP+2。

无 p 进位及 j≤n/2 给

    j=uP²+vP+c，
    0≤u≤m²，0≤v≤4m，c∈{0,1,2}。                       (2.1)

本节及以下多项式中的 u,v,c 只表示这三个局部数字，**不是**原 u=t3/C、最小支的 v、或 α=cα2^s 的系数。
高位界 u≤m² 用了原合法半行：j≤m²P²+2mP+1<(m²+1)P²。
数字盒可能包含 j>n/2 或其他无 p 进位失败者；保留这些额外状态只扩大必要模型，不漏掉原合法输入。

## 3. 精确除法与变动 m 的整数余数

置 N=2m²P²+4mP+1，j=uP²+vP+c。以下是整数多项式恒等式，不是新独立方程：

    4m⁴j(j−1)=N L(P)+R1 P+R0，                          (3.1)

其中

    L(P)=2P²m²u²+4Pm²uv−4Pmu²+4cm²u−2m²u
         +2m²v²−8muv+7u²，

    R1=−4m(2u−vm)(3u−2vm+(2c−1)m²)，

    R0=−7u²+8uvm−4ucm²+2um²−2v²m²+4c(c−1)m⁴。

该恒等式分别由整数系数运算和完整坐标次数网格核验。
由 (1.2)，必须有

    N | (R1P+R0)。                                        (3.2)

在数字盒 (2.1) 内，

    −4m² ≤ 2u−vm ≤2m²，
    −9m² ≤3u−2vm+(2c−1)m²≤6m²。

故

    |R1|≤144m⁵。                                         (3.3)

R0 的六个项组分别满足 7m⁴、32m⁴、8m⁴、2m⁴、32m⁴、8m⁴ 的绝对值上界；最后一组用 c∈{0,1,2}，不是任意实 c。
因此

    |R0|≤89m⁴。                                          (3.4)

并且 R1 是4m的整数倍。

## 4. 非零性与严格大小矛盾（完整无限尾部）

### 4.1 余数恒等为零的全部状态

固定整数 m,u,v,c 后，把 (3.1) 视作 Q[P] 中的除法。N 的判别式为 8m²，不是有理平方，所以 N 在 Q[P] 中不可约。
若 R1=R0=0，则 N | j(j−1)，在 Q[P] 中必 N|j 或 N|(j−1)。
设 j−d=tN，其中 d∈{0,1}。由于 deg j≤2，t 是有理常数，且

    t=u/(2m²)，c−d=t。

c,d 为整数，因此 t 为整数；又 0≤t≤1/2，只能 t=0。
所以全部恒零状态仅为

    j=0 或 j=1，

均不在原合法区间。这里是在证明多项式恒零的分类，不把数值整除误写成多项式整除。

### 4.2 非恒零余数也不能在尾部消失

若 R1=0，则 R0≠0，余数非零。
若 R1≠0，则 |R1|≥4m。P≥72m³ 给

    |R1P|≥288m⁴>89m⁴≥|R0|，

所以 R1P+R0≠0。没有只画根图或用浮点根判断整数。

### 4.3 余数绝对值严格小于 N

写 P=72m³+t，t≥0。精确计算得

    N−(144m⁵P+89m⁴)
    =2m²t²+144m⁵t+4mt+199m⁴+1>0。                    (4.1)

由 (3.3)、(3.4)，原必要条件要求一个满足

    0<|R1P+R0|<N

的整数被 N 整除，矛盾。
因此 PLUS-DOM 的每个原合法 (n,j) 都满足 Common3。m、p、h 都没有被固定或扫描。

## 5. m=1 的完整尾部 P≥71

此时局部数字盒只有

    u∈{0,1}，v∈{0,1,2,3,4}，c∈{0,1,2}。

certificates/certificate.json 给出每个有序模板的整数余数；生成公式是 §3 的 m=1 特化。完整模板检查证明

    |R1|≤144，|R0|≤32；
    R1≠0 ⇒ |R1|≥4；
    R1=R0=0 仅在 j=0 或1。

P≥71 时非恒零余数不可能数值为零，因为 4P>32。写 P=71+t，t≥0，有

    N−(144P+32)=2t²+144t+111>0。

所以全部 P≥71 的奇素数幂已闭合。
这里的30个模板是由完整进位和合法区间严格产生的完备盒，不是对原 P 或 h 的任意扫描。

## 6. P<71 的原始整行末端：全部完成

全部奇素数幂 P<71 恰为

    3,5,7,9,11,13,17,19,23,25,27,29,31,37,41,43,47,49,53,59,61,67。

生成器和第一检查器通过完整试除独立生成这个集合；第二检查器使用筛法和逐幂乘法再次生成，不信任提交的枚举覆盖。
对每个 P 都取原 n=2(P+1)²，逐个检查

    j=4,...,n/2，

**包括原中点、包括 P=3 的孤立3例外**。

第一算法用 C(n,j)=C(n,j−1)(n−j+1)/j 实际生成每个原二项式，计算 gcd(C(n,3),C(n,j))，选择其最小奇素因子作见证。
第二算法独立分解 n(n−1)(n−2)/6，并用基 q 完整进位计算 v_q C(n,j)，从全部原奇素数中选择同一个最小见证。

总计22行、30106个合法数对；两套算法的见证列表逐项相同，其统一 SHA256 为

    6a53f4c20337e9a2f061487d939d68dc73083744e11643059babbe4f06fa78e6。

每一行的完整见证列表、每行哈希及输入范围都在 certificate.json 中，而非只保存“PASS”。
这个有限末端是在 §5 先严格证明 P≥71 排除之后产生的；没有从“扫描没有反例”推出无限结论。

综上 PLUS1 全部完成。

## 7. 原题回传、来源独立性及当前前沿

对于尾部：原 p 若整除 C(n,j)，它就是同一个共同奇素数；否则必须符合局部数字盒。NC3 还会要求 N 的全部完整源无进位，进而给不可能的 (3.2)。所以至少原 p 或 N 的某个奇素因子满足原题。
有限末端直接给同一个原奇素数见证。没有把辅助解叫反例，没有更换原 n,j，没有孤立3偷换，也不需要使用实际 Ψ 或恢复 Pρ；它们始终是不同对象，本文没有混用它们。

**推论。** 在任何 NC3、n=2X²（X正偶）中，X−1 不可能是奇素数幂。X=2 的唯一合法 j=4 有共同素数7。因此必须 ω(X−1)≥2。
对 X−1 的每个完整奇素数幂 P，写 X−1=mP，则 gcd(m,p)=1，PLUS-DOM 进一步给

    P<72m³，等价于 P⁴<72(X−1)³。

这是剩余输入的必要条件，不是其充分模型，也不是一般绝对高度。

本轮的无限证明只用 §1 自行给出的阶乘计数、整数除法、数字界与不可约二次式。Overview 用于原题与研究前沿定位，而不是新定理未展开的数学前置。此前作者链的证据等级不因本轮而改变。

## 8. 两底低/低路线的额外接续接口（非一般闭合）

以下只在上一轮同输入两底必要模型中使用，沿用其来源等级，不是 PLUS1/PLUS-DOM 的前置。
写 W=p^(a−ell)、V0=q^(b−r)，D=p^ell、Q=q^r，原完整源分居

    DU=X+ε，QV=X−ε，T=UV，ε=±1。

上一轮已得

    DQ=A V0 Q+B W D+ηUV，ηU²V²=g²W V0 DQ−1，
    D | (2A V0U+ε)，Q | (2B W V−ε)。

定义真正的正奇整数

    k0=(2A V0U+ε)/D，l0=(2B W V−ε)/Q。

把主恢复乘2UV，代入这两个等式、DU−QV=2ε 和范数，得到

    2UV=k0V+l0U+2g²W V0。                              (8.1)

因此 1≤k0<2U、1≤l0<2V。
在低/低域 W|D、V0|Q；将两个定义式分别乘 U、V 后按 V0、W 约去，可得

    V0 | U−2k0，W | V−2l0。                              (8.2)

这是保留剩余完整幂分母的双侧整除，没有把有理高侧恢复商假定为整数。

若 U=1，则 k0=1，(8.2) 给 V0=1；(8.1) 给 l0=V−2g²W，再用 W|V−2l0 与 gcd(W,V)=1，得到 W=1。
同理 V=1 也给 W=V0=1。故

    min(U,V)=1 ⇒ u=t3/C=W V0=1。

一般 U,V≥3 的低/低域没有被这些等式排空；没有据此声称下降或有限化。FAILURES.md 给出仅满足 (8.1) 的无界弱外壳，说明不能将它反向当成完整恢复。
