## 1. 本轮真正检查的优先问题

目标原为：把间距的完整 p 进精度与真实原输入联立，强制一个消费者、控制无界参数，或排除全近侧低残量支。

对当前原输入记

```

q3=E3 I3, q4=E4 A4 C,
```

这里 `h` 是 Overview 的 `hD`，`z` 是 Overview 的 `zD`，不用 B/E 的同名符号。

## 2. p 进与缺欠：精确，但没有额外缩域

以下 p 均为 ≥7 的素数，m、u 分别为完整端点源指数和实际 `v_p(U)`。

| p 所在块 | 精确结果 |
|---|---|
| p\|g | `v_p(L3)=0`，`v_p(Dgap)=3v_p(g)+2v_p(v)` |
| p\|E3 或 E4，m=v_p(E_r),u=v_p(U) | u 为偶数且 u≥m；`v_p(L3)=0`，`v_p(Dgap)=u-m` |
| p\|q5，且 Q51=q5 | `v_p(L3)=v_p(Dgap)=v_p(r)=0` |
| p\|C，m=v_p(C) | `v_p(n-3U)=m`，`v_p(L3)=0`；不是只得到 ≥m |

g、E3、E4、q5 的这些粗素数支持彼此不交；不能把不同表行看作同一素数上的互相竞争的估值。

对真实缺欠

```
Δ_r=E_r²/gcd(E_r²,J), r=3,4,
```

有等价式

```
Δ_r=E_r/gcd(E_r,Dgap),
Δ3 Δ4=(h/gcd(h,v))².
```

Δ3、Δ4 各自都是平方，且互素。这是完整指数的准确重写，不是绝对高度，也没有控制 `h/gcd(h,v)`。

## 3. 两次换路与失败证据

### 路线 B：真实 α + 十倍平方 + 尾类能否自行排除？

成功将排除包含当前目标的一片更大区域。仍无界的变量是 a、g、z、β；最便宜的反证实验是直接解原判别式，而不是扫描 `(n,j)`。

使用

```
α=3^a,
m²=α²-40z²(gα-1),
β=(α-m)/2.
```

先进行 a≤14 的小型路线探针，没有找到满足所筛 g 条件的弱解；**未由此作无限推断**。随后用平方根的逐级精确恢复，在 a=132,z=1 找到反模型。完整整数在 `outputs/hensel_recovery.json`。核验结果：

- g 是真实 gcd，α 确为 3^132；
- `(n-1)j(n-j)=10[(n-1)g]²`；
- `n≡5130 mod9000`，`v5(n-5)=3`；
- `v7(C(n,6))=1`，`v7(C(n,j))=69`。

它满足第一源行，但 `7|q5` 且 j≡3 mod7，处在第5源中央槽，不是全近侧；同时 g⁴>n，因此也不在低残量域。故只否证“上述更弱全局子系统已经无解”，不否证本轮完整目标。

### 路线 C：追踪一个新支持源素数的所有高层能否强迫进位？

成功将消灭一个真实逃逸源所承载的剩余分支。待控制的是源外其他粗块、α、平方条件、低残量和所有邻行条件。最便宜检验是构造具有精确数字块的整数族，检查全部高层，而非仅检查固定模数。

取 t≥1，

```
L=2+1500t,
j=53^L+1,
n=26342j+110.
```

全族满足真实 gcd=10、合法 j、n≡5130 mod9000、E=3、g⁴<n。53 不属于 `{13,17,23,61}`，并且它在 q5 中的完整原源幂恰为 53，而不是 53^L。

53 的原槽为 j≡1、k≡4；所有高层无进位：

```
v53(C(n,j))=0,  v53(C(n,6))=1.
```

若剥离成 A=(n-5)/53、B=(j-1)/53，则 A≡22 mod53，因而 `v53(C(A,6))=0`。这不是保持原全部见证结构的下降。

但是整个族有 n≡1 mod7、j≡3 mod7，故 7 同时整除两二项式系数；而 U=J/(n-1) 不是整数。它不是 NC6，也不满足当前全近侧低残量全部条件。不得借此声称已排除“联合所有源”的高层方法。
