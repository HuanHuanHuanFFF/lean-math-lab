## 1. NF59 全可约是错的

本包 A10(0,0)、B10(0)、E10 都有保持次数的有限域不可约证书，分别为 (N,p)=(1,109),(2,103),(1,101)。它们具有D20/e10/z21/μ59。因此不能把NF59分类改写成“μ59不可能”或“全可约”。证据在 `auxiliary_boundaries.json`；接收重新做全部Rabin检验。

正确成果是：两个固定例外在NC9大点范围排除，其余可载点NF59成员支付足够的S3费用。二参数族和一参数族仍有无界有理参数。

## 2. 一般参数签名不能代表全部参数

B10的t0=−21/25满足κ=(3,0,2)，精确证伪“B10统一κ6≥1”。其余两个取消参数−549/350、−274977/168350也已分别处理。A10有三条取消直线、三个两两交点而无三重交点；只算一般点会把统一Σκ下界从正确5误报为7。

本轮没有维护这个错误引理：直接把B10(−21/25)作为固定多项式，给出全合法区间n≥2^52的非取零证书。没有用一般参数或几个随机样本替代它。

## 3. 全参数合法点非零也是错的

两个新参数族都在(n,j)=(400,10),J=3900有精确有理参数零点，完整参数见证书。例如A10取t1=0，并取

```

     /1139850515358706981384022987756953429223125
```

B10取

```
t0 = -291673228646879576346823561309277098030569
      /185950678018680103169809942960934042568350
```

两者都有真实共同素数11同除C(400,9)、C(400,10)，所以都不是NC9。没有证明这些成员H|G。原题反例不能由辅助多项式零点、参数族不可约或必要窗口相容性代替。

这些小点只反驳“所有合法点非零”的全参数命题；不反驳两个**指定固定式**的大点非取零定理，也不证明任意大点具有NC9。

## 4. 普通阶、特化阶、权阶必须区分

单缺重结构由六行容量推导之后才引入额外特化根。枚举保留额外根与源根碰撞，最终三空间逐点核对真实普通阶；λ在V3之外保证所有参数无升μ60情况。z21只是这三空间的结论，一般因子最低z仍14。

对角坐标u=N−r、t=X−s²−su的wt(1,2)阶不是原(N,X)普通阶。κ与Δ不同；在偶数行只能通过2Δ+κ的正确联合预算收费。

## 5. 有理不可约不是天然绝对不可约

亏格预算前必须执行PROOFS §2的归约。NF59可用新的共轭整除引理；SAT16/17用冻结SAT≤15的复系数扩展。可约饱和X^16有μ96，却有源δ下界和720>225；它是“把亏格界用于任意饱和式”的精确反例，不是饱和分类反例。

## 6. 有限域秩错误的边界

方程65521x=1在模65521下不相容，但在Q有解1/65521。故仅靠模p增广秩大于模p系数秩不能证明Q不相容。本轮只接收**满未知数列再加增广列**的非零子式；三个非满秩相容项另恢复有理解和完整齐次基。重复子式行、删掉一个候选、改变多项式常数都会被接收拒绝。
