# 失败命题、精确反模型与重新投入门槛

本文件记录三条**有限范围的方法结论**。不声称当前完整 RES10 系统有解，不声称任何真实 NC6 区域不可证明。三条路线都没有给出原题反例，也没有带来本轮 frontier reduction。

## F1. 间距等式能否作为独立新方程？

### 原目标与最便宜检查

目标：在同一原输入的全近侧低残量支，将间距的完整估值联立到其他恢复关系，消灭该无界支或控制一个无界参数。仍可能无界：n,E,a,g,q5,d,h,v,η及所有源支持。首个低成本检查：将间距左边完全代回原始n,j，而不是先对新符号作独立估计。

### 实际失败的期待

失败的是以下**独立性期待**：已知

```
q3=(n-3)/3=E3 I3,
q4=(n-4)/2=E4 A4 C,
U=10g²dv²E3E4,
L3=(n-3U)/(3gI3C),
r=[4(n-3)(n-4)-9nU+27U²]/(24q3E4C²),
```

之后，再加入

```
A4-Cr=(45/4)g³dv²L3
```

会增加一个独立的数值方程。

精确证书是恒等式

```
[A4-Cr]-(45/4)g³dv²L3
 =9(n-3U)[U-10g²dv²E3E4]/[8CE4(n-3)].
```

这里不是宣称间距公式本身为假；恰恰是它成立但依赖于已有关系。完整原输入给出的整数性、正性、互素性及精确估值仍然保留。证明见 `PROOFS.md` P1—P6；程序检查代数展开和336个诊断性有理代入。

### 没有被否证的内容

本轮没有取到ell6、ell7、L6、L7的冻结原定义，因此没有完整联立第三恢复式或所有邻行等式。也没有证明这些条件冗余。对q2实际平方精度与其他源的联合运用仍然开放。不能以F1声称“p进方法不可能工作”。

### 何种新信息值得重启

取得实际ell6/ell7定义及其完整整数恢复，并证明一个**不由上述恒等式生成**的跨源精度限制；或使同一素数的实际指数在两个不同来源条件中出现不可相容要求。不得把本来互斥的g、E3、E4、q5支持假设成重叠来制造矛盾。

## F2. 真实α、gcd、十倍平方和尾类本身是否已经无解？

### 换路目的

F1的初步独立性检查失败后，转向更全局的原j判别式。若这个更弱子系统无解，将覆盖当前目标；仍有a,g,z,β无界。最低成本否证实验：逐级恢复判别式平方根，直接检验真实整数g，而非扫描n或j。

### 被反模型否证的命题

> 不存在合法n,j满足g=gcd(n,j)、n/g=3^a（a≥2）、(n−1)j(n−j)=10Y²、n≡5130 mod9000、v5(n−5)≥3。

该命题是假的。令A=3^132，R为 `PROOFS.md` P7指定的模3^132平方根40，m取R和A−R中的奇者。置

```
g=(A²-m²+40)/(40A),
β=(A-m)/2,
n=gA,
j=gβ.
```

全部整数值见 `outputs/hensel_recovery.json`；完整十进制值也写入P7。重放程序从模3的根开始独立重建这些常数，不依赖探针的搜索上限。

### 条件账本

| 条件 | 该具体整数对 |
|---|---|
| 7≤j≤n/2、同一原n,j | 成立 |
| g是实际gcd | 成立 |
| α=3^132 | 成立 |
| 第一源n−1整除J | 成立；J=10g²(n−1) |
| 十倍平方 | 成立，Y=g(n−1) |
| n≡5130 mod9000、E=3 | 成立 |
| 全q5近侧Q51=q5 | **失败**：7完整源在b=3中央槽 |
| 当前低残量必要g⁴<n | **失败**：g⁴>n |
| 完整NC6 | **失败**：共同素数7 |
| 全部其他源分配、全部邻行等式 | 未建立；不能从前几项补出 |

精确排除证书：v7(C(n,6))=1，v7(C(n,j))=69。因此它不是原题反例，也不是当前完整残域的反模型。

### 再次尝试门槛

必须加入能实质约束此类全局恢复的真实源信息，尤其q5全近侧与低残量。继续增加a或z扫描范围不会恢复已经被否证的弱命题；本包不给这些参数任何绝对界。

## F3. 一个逃逸支持素数是否必在某个高层进位？

### 换路目的

F2否证后，转向真实原源素数的全部高层。成功需要把一个在当前剩余支持中的源强制成共同见证；其他源、α、平方与邻行条件仍可能无界。最低成本检查：构造可对所有高层证明的精确数字族，避免只测固定模数。

### 被无界弱模型否证的命题

> 只要合法n,j有正确尾类、真实gcd、g⁴<n，并有一个p∉{13,17,23,61}的完整第5源幂处于近侧，那么该p必在某个更高层出现进位。

反族（t为任意正整数）：

```
L=2+1500t,
j=53^L+1,
n=26342j+110.
```

全族满足真实gcd=10、n≡5130 mod9000、E=3、g⁴<n；原第5源完整53幂恰为53，j≡1、k≡4 mod53。数字分解

```
A=(n−5)/53=497·53^L+53^(L−1)+499,
B=(j−1)/53=53^(L−1),
A−B=497·53^L+499
```

使所有高层无进位，因此v53(C(n,j))=0。指数L没有被冒充q5中的完整源指数。

### 精确缺失项和非反例证书

第一源行失败：n≡1 mod7、j≡3 mod7、k≡5 mod7，故7|n−1而7∤jk。也因此原题有共同素数7。U_rat=jk/(n−1)不是整数；尽管v53(U_rat−1)=L无界，不能称它为实际NC残量η。

未建立全q5近侧、α=3^a、十倍平方、q2/q3/q4全部完整分配、全部残量与邻行条件。尤其**没有声称53∤L4L7**，这些变量在此弱族中没有当前NC输入的规范整数恢复。

### 数字剥离不是已证下降

单素数估值恒等式v_p(C(n,j))=v_p(C(A,B))可以逐层证明，但该族还满足v53(C(A,6))=0。原53源在辅助行消失。它阻止我们从这一恒等式直接宣布完整NC6运输；因为原族不是NC6，它也不能反过来作为“所有可能NC6下降都失败”的反例。

### 再次尝试门槛

需将其他真实源及第一源行、全q5分配、α和平方恢复共同强制到数字B上。有效的新结果应控制所有可行B或直接给某个原源进位，不能只重新证明单素数剥离公式或放大工作层。

## 结算

三个精确诊断没有删除当前未知无界区域。完整强系统仍然是本轮未解决的问题：**frontier reduction = 0**。
