# 新证据的验证范围

默认入口 `python3 replay.py` 先核对全部成员SHA256，再逐项核对冻结依赖的原字节；随后重放两种新有限算法、坏证书拒绝、已记录的诊断和指数消费者输出，最后再次比较全目录字节，要求只读。

第一实现：稀疏多项式逐系数运算，Möbius商式的精确分圆值，试除分解与乘积φ。第二实现不导入第一实现或消费者：有理Vandermonde插值、满足明确次数界的完整张量网格、递归分圆值、独立筛式分解及剩余类计数φ。两者的无限命题都由PROOFS.md而不是有限样本保证。

九类坏证书用内存副本修改，不改写任何原文件。默认检查器使用Python断言，不能以`-O`或`PYTHONOPTIMIZE`禁用；replay会在这种情况下主动拒绝运行。

`outputs/finite_checks.json`、`outputs/consumer_examples.json`和`outputs/six_capacity_probe.json`来自本轮实际执行，不是预写PASS。诊断中的九个x值不承担无限证明；正式小端点只有x=2、4，并已由数学证明穷尽。

源依赖L、h13和旧Q/4<v的整个历史链不在本次默认重放范围。字节核对不等于旧数学复审；没有Lean、外部审稿或仓库级验收。

最终ZIP由实际解压后再次运行默认入口验证，原ZIP哈希、成员数、命令输出和前后字节一致性记录在包外的archive-validation.json，以免产生文件自引用哈希。
