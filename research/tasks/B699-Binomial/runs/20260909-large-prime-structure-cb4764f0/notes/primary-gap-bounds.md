# 主线程新推导：偏离中心的统一界（纸面候选）

2026-09-08 首轮推导；来源：主线程独立整数估计，valuation-transfer 提供并交叉核对实际 prime-power 零格/非零格定位。尚未 Lean 接受，尚未独立全链审阅，不主张新颖性。所有结论须在此文最终核对后更新状态。

## 共同定义与依赖

原题合法 n,i,j，d=n−2j≥0，V=V_i(n)。反例假设只用于令每个 p≥i 的实际因子均避开 C(n,j)。对 e=v_p(C(n,i))>0，令 δ=1 若 p=i 否则0，Q=p^(e+δ)>i。母窗口定位 a=n mod Q<i、两子窗口余数 r=j mod Q、s=(n−j) mod Q 满足 r+s=a，因此 Q | d+r−s。完整推导由同批 notes/valuation/ 提供，p=i 多一指数不能忽略。

两类：
- 非零 d+r−s，其绝对值≤d+i−1，且 Q>i。
- 零格 s=d+r，2r+d<i；共有 z=max(0,ceil((i−d)/2)) 个 r，所选完整幂积与 z! 互素，故整除 C(j,z)。

EEES1978（精确十二例外由已采用顶端素数处理）给任意原题反例 C(n,i)<V²。这是出版定理纸面依赖，非新增 Lean axiom。

## A：2≤d≤i 的统一二次界

候选精确结论：所有合法反例若 2≤d≤i，则

  j < ceil(i/2)*(i+d)−1，
  n < 2*ceil(i/2)*(i+d)+d−2。

证明义务与推导：

令 z=ceil((i−d)/2)、h=i−2z（等于 d 或 d−1，h≥1），u=floor(i/2)、t=ceil(i/2)，M=i+d−1。由于 d≤i，非零格的 Q≤2i−1，而 p≥i 且 Q>i；故 Q 为 p>i 的一次幂，p=i 的平方不可能。所有非零格素数的积 R 属于区间 i<p≤M 的不同素数之积。

所有这些 p 为奇数。按 i,d 的四种奇偶组合，区间最多 floor(h/2) 个奇数，故 R²≤M^h。边界 i=d=2 给唯一 p=3、h=2，也成立。

由零格与非零格的真实分配，V≤R*C(j,z)。Vandermonde 保留 u,t 项，得到 C(n,i)≥C(j,u)*C(j,t)。两个 binomial 从 z 分别增长到 u,t；每一步的比值 (j−k+1)/k 至少 A=(j−t+1)/t>0，总增量 h。因而

  C(n,i) ≥ C(j,z)²*A^h，
  A^h < R² ≤ M^h。

h>0 推出 A<M，即 j<t(M+1)−1。原关系 n=2j+d 给第二式。

预期前沿收益：对全部无界 i，同时排除 2≤n−2j≤i 且 n 至少该显式二次门槛的无限区域。实际仍有 i 无界、n=O(i²) 的残区，不能称全部有限化。不需要固定 i 的穷举或 prime-gap 猜想。

## B：d≥i 的 LCM 统一界

此时没有零格，实际 V 整除 L=lcm(d−i+1,…,d+i−1)，从而也整除 lcm(1,…,d+i−1)。若使用已核对的初等 LCM bound lcm(1,…,m)≤4^m，则

  (n/i)^i ≤ C(n,i) < V² ≤ 16^(d+i−1)，

即 n/i <16^((d+i−1)/i)。这迫使反例离中心的 d/i 随 log(n/i) 增长；全体 i,n 仍可无界。初等 LCM 来源/证明由 notes/sources/ 核对，未核对前保持候选。

特别若 i≤d≤2i，则 n<4096*i。结合精确 Dusart 短区间素数定理，可能进一步把这一整比例带有效约束到 n<793476；这是待核对推导，尚未声称有限检验完成。任何新的短区间来源要标明出版定理假设及数值门槛，不视作已有 Lean 验收。
