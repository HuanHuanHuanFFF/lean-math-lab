# 首个判别实验

候选不是原题重新扫描：比較实际 V_i(n) 的完整整除、两侧子窗口整除、已知完整幂的低余数条件之间的区别。完整量词暂为指定的小范围所有原合法输入且 3i<2j。若发现整除幸存但原 gcd 有大公共素数，明确证明必要条件不能作充分条件，并定位其被遗漏的 carry；若无幸存，只记录测试域而不声称全局排除。使用 Python 标准库原始 comb/gcd 独立核对候选，结果源码与输出同目录。

预期收益：决定投入哪种强化，避免形式化没有实际增加信息的重述。所有 n,i,j 的未测试域仍无界。首次上限 n=200，结果有判别价值后才考虑改变对象；不以提高 n 上限填充预算。
