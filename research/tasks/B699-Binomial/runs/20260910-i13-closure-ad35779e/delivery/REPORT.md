## 2. 为什么这一轮选13，而不是机械扩旧CRT

首先读取固定原件的三窗口、四项位置加权与非对称Padé推导。初始检查并不预设13必有收益：针对18、20的既有边图，位置权重的净指数仍为负；指定有限直线／圆锥族的线性规划也没有给出所需改进。11、16、21已有高度且由另一个独立任务推进，未重复其末端。

把固定Padé种子池的非对称阈值重新计算后，13首次出现足够的**位置加权**增益。这里只是设计信号，最终重新冻结11行整数输入，以两种精确算法核验其适用于全部大参数的常数，并重新穷尽2048种方向。浮点设计输出未进入最终接受链。

两个实际失败决定了后续连接，而不是被略过：旧3/4大幂阈值在13处的净指数恰为0，必须换成7/10；旧两类末端见证仅留下n=126，必须补它的全部j，不能称零残余后忽略这一行。失败源码、输出与修复理由保留在 [failures](failures/README.md)。

## 3. 新的绝对高度：11条非对称约束＋位置权重

令 S={2,3,5,7,11}，U为`C(n,13)`的p<13完整部分，V为其余完整部分。对每个p∈S选择窗口内一个最大赋值位置，写

`n−r_p=Q_p A_p，Q_p=p^{max v_p(n−a)}，Y=n−12`。

初等逐层赋值比较给出 `U≤∏Q_p≤n^5/∏A_p`；若两位置碰撞，互素性直接给 `A_pA_q≥Y`。没有删除同位置或零指数分支。

本轮11条约束具有如下形式：当Y≥2^8191、两个素数幂乘余因子均在[Y,2Y]、差的绝对值≤24时，

`A_p≥Y^(w_p/1000) 或 A_q≥Y^(w_q/1000)`。

它们全部由 BFT Lemma 4.1 的近似式界及 Proposition 5.1 的7组固定公因子增长常数推出，具体种子、方向、权重、严格m>m₀和完整整数近似消元在证明第3节。没有引入新的未证数论假设，没有调用隐藏阈值C₀。论文原文范围、公式和表格核查见 [SOURCE_AUDIT](sources/SOURCE_AUDIT.md)。

对实数 `x_p=1000log(A_p)/log(Y)`，2048种方向的枚举是完备的：每个方向只给坐标下界，单调目标在其整数下角点达到最小，**不是把实际实数指数误当整数**。得到

- 标量最小值934，小于旧标量法需要的1000，故单纯相乘仍失败；
- 按位置权重16,15,14,13,12排序后的最小值12183，大于12000；
- 若任一位置碰撞，标量统一最小值1309。

所有最大位置不同时，取 `w_a=16−a (0≤a≤12)`。保留每个位置的完整大素数部分V_a，noCommon给出加权整除，右端次数72。余下小素数的赋值损失由 `(13!)^16` 控制，重排不等式给

`n^183 < (13!)^16000 · 2^142183 < 2^670183`。

碰撞分支由标量约束与三窗口给

`K^1000 n^4326 < (13!)^14000 · 2^32326`，

其中 `K=2^90(∏_{h=1}^9 h!)²(∏_{h=1}^8 h!)`。

n≥2^8192时源约束全部适用，且两式分别矛盾；n<2^8192直接保留。因此得到真正**绝对有效高度**。这里的8192不能仅凭最终代数余量再降低，因为源约束自身有阈值。

## 4. 不展开天文余因子：先指数分块，再CRT

三窗口实际参数为 `(r,s,λ,E)=(4,9,14,126)`。旧3/4阈值的净指数为0，不是适用于13的引理。本轮改用7/10：若至多一个小素数完整部分≥n^(7/10)，则U^10≤n^38。noCommon将推出

`K^10 n^28≤(2·13!)^140`。

精确证书在n=2^67已给反向严格不等式；于是n≥2^67的反例必有两种不同小素数，对应 `A³,B³≤Y`。这是一条新消费者，不是旧阈值的直接套用。

对每对素数，把高指数区间整块排除：选择P=p^K、Q=q^B，满足Q³≤(P−12)²；对全部d∈[−12,12]检查最小正余数R_d的平方是否大于p^(K+3L)。若成立，就排除整段K≤a≤K+L，不枚举另一素数指数或余因子。零余数取Q作为最小正代表，d=0仍覆盖。10对素数的块均无断口，小指数明确转成高度，最大目的高度是2^134。

有了较小高度H，再取满足

`K M^56 ≥ (2·13!)^14 H^14`

的最小M。任何反例要么落在完整低端分支，要么落在两个不同颜色的短区间 `[Ap^h,Ap^h+12]` 的交集中。区间交转成 `QA−RC=d` 的全部CRT参数z；直接算整族最大z，而不逐个枚举巨大A,C。

完整下降链为

`2^134 → 571470219398308339106192 → 16162672751935499 → 609080049668 → 5107613699 → 1051721741 → 86484388 → 57656263`，

再检查固定点。M由121532712443降到872。直到末端预计区间数上界117720、在预设2000000安全上限以内，才显式建立37273个原始区间。大JSON都写文件，正文不展开。

这条链覆盖原始全部反例域。表中最大候选n不是“扫到这里”的截止值，CRT固定点也不是原题证明：必须继续排除所有候选。

## 5. 最后唯一例外行怎样处理

顶端素数与大除子证书排除29746行，唯一留下的是n=126。它不是反例。

`C(126,13)=170737530940919250`，其素因子17、19、23、29足以给12个进位余数区间，无断口覆盖 `14≤j≤63`。每段p都整除第一二项式，且整段j不跨p的倍数并有 `j mod p>126 mod p`，所以p也整除第二二项式。检查器又逐个j用Legendre公式复核这50项。
