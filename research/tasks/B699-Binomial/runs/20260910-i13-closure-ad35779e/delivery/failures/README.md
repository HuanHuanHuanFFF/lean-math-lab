# 本轮失败与诊断（不混入已闭合结论）

## 1. CLI fetch失败

`outputs/git-fetch.log`保存真实exit128/DNS失败。GitHub连接器读取PR已合并与固定树成功，故只读启动仍完成；未假称CLI成功、仓库被克隆或重建过。

## 2. 旧标量余因子乘积不足

新13的11条cut若只求sum(x_p)，精确最小值934<1000。因此旧标量三窗口高度路线仍不能得到正净指数。位置权重目标最小12183>12000才有收益，碰撞分支另由1309处理。两个目标不能互换或只报较好者而漏掉位置条件。

## 3. 旧3/4阈值在13处失效

净指数精确为0。新的7/10阈值给净指数28，n≥2^67即可矛盾，并保持两余因子的立方小界。检查器显式检验旧指数=0、新指数=28及完整整数证书；未复用不满足假设的旧指数块消费者。

## 4. 末端两类见证真的留下126

`first_terminal_attempt.log`及`first_terminal_unresolved.json`记录首个终端生成器失败；相应源码为`code/generate_i13_terminal_first_attempt.py`。残余只有n=126。它不是反例，因为当时只是两个必要条件过滤器无法判定。

修复：为126的全部合法14≤j≤63生成12段余数进位见证，检查每段的p整除C(126,13)、段不跨模数、j mod p>126 mod p，再以独立Legendre计算复核50个j。正式证书中此行标为residue_cover_rows，不藏入topprime或divisor计数。当前`outputs/i13_terminal_check.json`为0残余，旧非空残余只保留在本failures目录，不冒充当前状态。

## 5. 邻近指标与有限种子池的强度障碍

固定旧边、有限Padé种子池和固定位置权重族的诊断输出分别见outputs/weighted_asymmetric_probe.json、neighbor_diagnostic.json。后者对12、14、15、18、20，在设计高度8192、65536、1048576位的15个组合中都保留负净指数见证。增加同一池的高度，不会据现有结果自动闭合这些项。

这些Padé常数在诊断阶段使用浮点计算；未保留为主结果的cut没有逐条精确接受，因此不能把该实验说成全体Padé方法或所有种子的严格不可行性证明。

## 6. 固定有限圆锥族未带来足够收益

code/probe_conics.py只枚举其明示的二次型系数、有限线性项范围与三方向直线。保存的线性规划目标和对偶数据是浮点诊断，不是全局代数几何障碍。没有据此否定所有高次曲线或把“没有找到”当作不可能。

## 7. 尚未证明的下一条边

outputs/next_condition.json严格标注CONDITIONAL_GRAPH_ONLY。对18号固定旧边增加(11,17)对称129/1000约束，会使不同位置分支目标24008>24000；128/1000仍不足。这只检查有限图。共同数值阈值、真实余因子不等式和碰撞连接未完成，不据此登记18号高度。
