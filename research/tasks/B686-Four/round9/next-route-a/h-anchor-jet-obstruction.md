# 严格负号H与grid jets：可明确停止的乘法路线

状态：2026-09-08第九轮纸面判断，主任务接受停止直接乘法路线；未Lean化。只排除下述自动桥接，不声称一般辅助式方法不可能，也未排除新的原解长度族。

## 1. 目标与精确对象

令k=4s、r=k/2。沿[已接受纸面的四分之一指数证明](quarter-runge-bound.md)，q是B(t)=∏_{i=1}^{r}(t−(2i−1)²)平方根的多项式部分，degree q=s；L=2^(2s)，A(U)=Lq(U²)。在原曲线正点、m>n且倍率4时，

```text
H(n,m)=A(2m+k+1)−2A(2n+k+1)<0， H(n,m)∈Z。
```

考察原曲线的canonical网格点(n,m)=(-j,-i)，1≤i,j≤k。记

```text
v_i=Lq((k+1−2i)²)， H_grid(i,j)=v_i−2v_j。
```

这些网格来自真实的连续绝对位置，不是把原题因子换成非连续数字的运输模型。

## 2. 稀疏、大匹配且H没有任何免费接触的模板

k个平方(k+1−2i)²恰有k/2=2s个不同值，每个出现两次。非零首一q只有s个根，所以v_i=0的索引至多2s=k/2。

将每个零值索引z与一个不同的非零值索引t配对，交换z、t；其余非零值索引固定。这给一个排列σ。对应k格(i,j)=(σ(j),j)上：

- 固定的非零值索引给H_grid=−v_j≠0；
- 零值行映到非零值列给H_grid=v_t≠0；
- 对应非零值行映到零值列给H_grid=−2v_t≠0。

故存在仅k格、最大匹配ν=k且全格H_grid非零的支持模板。

还可去掉singleton：令τ(i)=k+1−i。因k偶，τ无不动点，且v_(τ(i))=v_i。σ与τ∘σ是两条边不交的匹配；其并有2k格、每行列度恰为2、ν=k且所有H_grid≠0。当k≥16时它甚至满足2k≤k²/8。

**边界：**此为网格几何及支持模板，不声称这些格能被赋予满足原式的canonical素数幂、残余、行列绝对值。原式额外数值关系可能排除它。它准确说明：单靠当前稀疏度、大匹配和“没有singleton”信息，不能强迫H在支持上供应任何符号上的jet消失。

## 3. 局部单位与已知非零锚的次数障碍

原曲线P_k(m)−4P_k(n)=0在每个网格点光滑，因为两边一元连续乘积在这些根的导数都非零。H_grid≠0时，H在该点的有理局部环中是单位。因此对任意局部函数F，

```text
ord_P(HF)=ord_P(F)。
```

这首先是特征零的沿曲线接触结论。模素数意义还需p不整除H_grid；不能把有理非零偷换成所有rough素数下都是单位。

令U(n)=P_k(n)/k!=binom(n+k,k)，在正整数点为正整数，在每个网格点有简单零。对上述模板，已知非零单项锚

```text
U^a H^b， a,b≥0
```

的沿曲线消失阶恰为a；若要供应μ阶，必须a≥μ。其普通多项式次数为ak+br，因此D≥kμ，无法取得增长比较需要的D<kμ。

这一最高次数也不能通过原曲线关系自动降低：曲线最高齐次项为(m^r−2n^r)(m^r+2n^r)，锚的最高项为非零常数乘n^(ak)(m^r−2n^r)^b。第二个因子与n以及第一个因子互素，故曲线最高项不整除锚最高项。

对保持各项显然正值而只做这些锚的平方和，局部最低阶的正平方系数也不能靠相消提高。允许其他加法相消可能改变局部阶，但随后仍须另证正点非消失及高度，不能沿用锚的显然非零性质。

## 4. H的无穷远衰减不能免费支付高度

四分之一指数证明给

```text
0<|H(n,m)|<2L ε((2n+k+1)²)
 ≤ 2L k^(r+2)/(π((2n+k+1)²−k²))。
```

但存活整数解点同时满足|H|≥1。乘H^b不能仅凭这条上界把一个已有非零整数值变小；其因子小于1的区域就是已经排掉的Runge尾部。

在n约为k³的低端，上界的量级是2^r k^(r−4)，而不是趋于0。若只在幂次账本上记省去n²，却不记k^(r+2)系数，就会产生虚假收益。使用n/k的integer-valued尺度也相同：对应因子为约L k^r/(n/k)²。

这不排除H与局部算术之间另有尚未证明的相消或除法结构；它否定的是现有估计直接相乘即可跨越整个剩余区间。

## 5. 非乘法余项关系给出的实际接口

在原曲线上恒有

```text
H(n,m) · (A(2m+k+1)+2A(2n+k+1))
 = E(2m+k+1)−4E(2n+k+1)。
```

第二因子在正点为正，故右侧也是明确非零的负整数，次数至多r−2。这给较低次数的已知非零函数，但没有自动得到grid jets：在上述交换/对角模板上，H的和因子也非零，所以右侧仍是局部单位。

因此目前没有由该恒等式产生一个同时具备“较低高度、μ阶局部消失、正点非零”的新接口。把未知的局部消失或生成族藏入一个乘子，等于把原缺口重新命名。

## 6. 与主任务大owner稀缺输入的关系

主任务提出的高高度/Farey间隔路线有望排除实际rough纯匹配，并限制singleton行数；统一常数与完整适配由主任务继续核查。这里不把其候选推导升级成已接受定理。

即使该输入闭合，2k格的度二模板没有singleton，所以这一类支持数量信息仍不能强迫H零格上有足够质量。真正有用的下一桥必须使用同一n下的实际共因子、比例及素数幂大小，把这些模板排掉，或改用不依赖H乘法的非公共零构造。

**停止判断：**不再为直接H乘法、非零锚单项或其显然正平方和投入Lean。该判断没有改变全题未知范围。转向主任务给出的主逆支/Pick–Markov与多重正交候选，先核对它是否匹配全部网格jets和u→4u的几何条件。
