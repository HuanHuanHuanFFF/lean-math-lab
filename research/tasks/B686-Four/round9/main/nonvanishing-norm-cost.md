# 正点非零性：代数范数的成本检查

2026-09-08，第九轮主任务。状态：纸面成本核算，B正在独立复核；不是新的原题排除结果。

## 为什么值得检查

整数值 jet 基已经降低辅助多项式的构造成本，但一个短多项式仍可能在假设的原解处等于零。若能用原方程的大正整数点性质，以足够低的成本保证非零，就可能把支持稀疏性连接到对全部充分大偶数长度的排除。这里先检查最直接的代数范数估计是否够用。

## 范数估计实际给什么

令中心坐标 `X=2n+k+1`、`Y=2m+k+1`，并置 `alpha=4^(1/k)`。中心乘积写成 `R_k(T)=T^epsilon*prod(T^2-a_i^2)`，其中 `0<a_i<k`、因子数至多k/2。对X>=2k，用 `-log(1-u)<=2u`（0<=u<=1/4），得中心修正项的负对数至多 `k^3/X^2`。乘积修正项 `prod(1-a_i^2/T^2)` 随T递增，故原方程给

```text
1 < Y/X <= alpha <= 2,
0 <= log(alpha/(Y/X)) <= k^2/X^2,
0 <= alpha-Y/X <= 2k^2/X^2.
```

这里只保留足够宽松的多项式误差，不优化常数。

先给予路线有利条件：假设 H 已是普通整数系数多项式，总次数 D、系数高度 B，且顶次齐次部分 `h(T)=H_D(1,T)` 满足 `h(alpha) != 0`。取 `C=(D+1)B 2^D`。alpha 的最小多项式为奇数 k 时的 `T^k-4`，偶数 k 时的 `T^(k/2)-2`；次数记为 s。所有共轭根的绝对值均为 alpha，因此非零整数范数给

```text
|h(alpha)| >= C^(-(s-1)).
```

设 `|Y/X-alpha| <= K_k/X^2`，可取K_k=2k^2。低次部分除以 `X^D` 后为 `O(C/X)`，顶次部分的比值误差为 `O(D C K_k/X^2)`。所以仅靠这组估计保证 H 在目标点非零，需要一个形如

```text
X > O(C^s + sqrt(D K_k C^s))
```

的充分阈值。即便 D=O(k mu)、B=exp(O(k mu))，其对数仍是 O(k^2 mu)。把整值 U/binomial 基清成普通整数系数后，通常还需要计入阶乘分母成本，不能直接套用整值基的系数高度。

奇数 k 时，Q(alpha)=Q(2^(1/k))，由2和k互素得到该域等式，再对T^k-2使用Eisenstein判据可知次数为k。若 H 已约化为 `degree_Y < k`，顶次 h 的次数也小于 k，因此 h(alpha) 自动非零。偶数 k 时最小多项式次数只有 k/2，这个保证不存在；顶次抵消还需额外分析。

## 取舍与边界

当前希望同 `n>k^3/192` 冲突，目标是将 n 的上界压到低于三次的量级。上述现成范数下界只在指数尺度保证非零，不能完成这一连接；已有偶数 Runge 上界也不意味着候选点进入该非零阈值以上。

因此不为这条粗范数桥启动 Lean 工程，也不把它列为已排除大长度。该判断只否定这里的定量成本，**不证明所有范数法或本题特殊多项式结构都不可行**。若今后能给特殊 h 的显著更强下界，或构造在正支路具有确定符号的辅助族，才有重新投入的理由。
