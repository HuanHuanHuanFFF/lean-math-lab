# B686 第七轮辅助：连续块 rad 支持有限搜索

本文件记录一个有界、精确、可复现的辅助实验，不作原题无解声称。

## 范围与方法

脚本 [search_rad_support.py](search_rad_support.py) 对以下范围搜索：

* k=2,…,12；
* 0≤n,m≤20000；
* m≥n+k（两块不重叠）。

连续块定义为 Pₖ(t)=∏ᵢ₌₁ᵏ(t+i)。脚本先用 SPF 预处理到 20012 的素因子，再把每个 Pₖ(t) 的 rad 支持表示成精确整数掩码；只在相同掩码的起点组内生成配对，并用二分跳过重叠起点，没有枚举全部起点对。每个比例都用 Python Fraction 计算；比例 4 若出现，再用直接整数乘积核对。

完整机器输出见 [rad-support-search.json](rad-support-search.json)。复现命令：

    python research/tasks/B686-Four/round7/support/search_rad_support.py

输出中的 pair count 是该有限范围内所有“整块支持相同且不重叠”的配对数；每个 k 的五个最小代表例子分别保存在 ratio_1_lt_ratio_le_10_examples、position_support_mismatch_examples 和 ratio_4_examples 字段。最小反例的排序标准为 (k,d=m−n,n,m)。

## 结果摘要

| k | 同支持不重叠配对 | 比例在 (1,10] | 其中逐位置不匹配 | 比例 4 |
|---:|---:|---:|---:|---:|
| 2 | 311 | 135 | 304（区间内 135） | 0 |
| 3 | 15 | 6 | 15（区间内 6） | 0 |
| 4 | 5 | 0 | 5 | 0 |
| 5 | 2 | 0 | 2 | 0 |
| 6–12 | 0 | 0 | 0 | 0 |

按 (k,d,n,m) 的全局最小逐位置支持反例是：

    k=2, n=4, m=8, d=4, P₂(8)/P₂(4)=90/30=3

两块分别为 (5,6) 与 (9,10)，整块素因子支持都是 {2,3,5}，但逐位置支持为：

    ( {5}, {2,3} )  对比  ( {3}, {2,5} ).

因此“rad(Pₖ(n))=rad(Pₖ(m))”不能替换成同一位置逐一拥有相同素因子支持。k=3、4、5 也各有此类例子，详见 JSON 的 mismatch 样本。该结论只针对给定有限范围；比例 4 在 k=2,…,12、0≤n,m≤20000 范围内没有命中，因而没有原题见证。

代表样本另用独立的直接试除因子分解核对：27 行样本的整块支持、逐位置支持和 Fraction 比例均一致；比例 4 命中数为 0。有限搜索和独立核对都不构成对无界 k、n、m 的排除。
