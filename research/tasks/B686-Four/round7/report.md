## 2. 可复用的数学工具

对k≥2、n≥0、d=m−n≥k的任意两块，有

```text
gcd(P_k(m),P_k(n))
 ≤ (k−1)! (n+k)^{π(2k−1)} binom(d+k−1,2k−1)。
```

这不要求比例恰为4。关键是小素数的重复赋值由阶乘控制，大素数的公共幂必须出现在某个跨块差里。将其与本题的因子大小关系结合，再分m≥k³和m<k³两种情况，得到显式二次界。

这是对既有Erdős/Saradha–Shorey方法的整理与特化，首次性未调查。它提供后续形式化和其他固定比例问题的复用入口，而不是新通用理论的声明。

## 3. 覆盖范围与实际限制

对任意固定B≥1，附加d≤Bk时，所有候选必须满足

```text
k < 250000B，d < 250000B²，
m < (4/3)·250000² B³，n=m−d。
```

因此距离至多为长度固定倍数的区域，已化为明确有限范围。本轮没有枚举该巨大范围。新下界主要在k>250000时才比已有d≥k更强，不把它说成对小k有效的大幅搜索缩减。

满足d>k²/250000的无界距离仍未排除；全k=5、其他未处理长度、构造合法见证和全题否定都未完成。不能据此估算总体完成百分比。

## 4. 其他探索及负面信息

主任务尝试把原题转到两块具有相同素因子支持的问题。BSW1989较强的指数距离定理要求逐位置支持相同，原题只给整块支持相同。辅助精确搜索给出诊断例：两块(5,6)与(9,10)整体支持相同，逐位置不同，比值为3。这个例子排除了一种误用文献的方式，并非原题见证。
