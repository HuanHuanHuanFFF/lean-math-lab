# B686：显式全长度二次距离下界（纸面）

**精确结论。** 设k,n,m为整数，k≥2，n≥0，m≥n+k，且P_k(m)=4P_k(n)，其中P_k(t)=∏_{i=1}^k(t+i)。令d=m−n，则

    d > k² / 250000。

下文实际得到d>k²/(4e^10)>k²/236196。选250000作为易用保守分母；不再优化常数。该结论是采用已知素数计数定理及Saradha–Shorey gcd结构的纸面特化，**尚未Lean验证，不声称新颖性或全题无解**。

## 外部输入

仅使用Rosser–Schoenfeld1962原69页Corollary1式(3.6)：对所有实数t>1，π(t)<1.25506 t/logt。来源和实际阅读证据见[source-audit.md](source-audit.md)。以下gcd、因子大小及组合数估计均给出证明；无需使用素数间隙定理、Baker/Yu线性对数形式或未算出的C17。

## 1. 两个因子大小界

d≥k>0，m>0。首先证明m>kd/2。若m≤kd/2，则n+k≤m≤kd/2。因i↦1+d/(n+i)严格递减，k≥2，得到

    4 = ∏_{i=1}^k (1+d/(n+i))
      > (1+d/(n+k))^k
      ≥ (1+2/k)^k
      ≥ 1+2+2(k−1)/k = 5−2/k ≥ 4，

矛盾。最后一步仅为二项式前三项，k=2也成立。

其次，对0≤a_i≤1有∏(1−a_i)≥1−∑a_i，可由归纳证明。取a_i=d/(m+i)，因n+i≥1，每个a_i在(0,1)中。因此

    1/4 = P_k(n)/P_k(m)
        ≥ 1−∑_{i=1}^k d/(m+i)
        > 1−kd/m。

故d>3m/(4k)，等价于m<4kd/3。

若m≥k³，上式直接给d>3k²/4，强于目标。以下只需考虑m<k³。

## 2. 通用gcd不等式

令Q=2k−1≥3，G=gcd(P_k(m),P_k(n))。分G=S·L，其中S包含G中所有p≤Q的素数幂，L包含p>Q的部分。实际原题G=P_k(n)，但本节gcd上界不需要系数比为4。

### 小素数部分

固定p≤Q，在下块n+1,…,n+k选一个p进赋值最大的项，最大赋值记a_p。对每个r≥1：若r≤a_p，长度k块中p^r的倍数至多floor((k−1)/p^r)+1个；删除所选项后至多floor((k−1)/p^r)个。若r>a_p，则原块没有这类倍数。逐r相加得到

    v_p(P_k(n)) − a_p ≤ v_p((k−1)!)。

同时p^{a_p}≤n+k（无该素因子时a_p=0仍成立）。因为G整除P_k(n)，对p≤Q相乘给

    S ≤ (k−1)!·(n+k)^{π(Q)} ≤ k^k m^{π(Q)}。

利用n+k≤m<k³、Q>k≥2和显式素数计数界，

    π(Q)logm < 3·1.25506 Q (logk/logQ)
              < 3·1.25506·2k = 7.53036k < 8k。

于是S<(e^8 k)^k。这里没有“大k”阈值。

### 大素数部分

设p>Q且p^a为G中的完整p幂。因p>k，上下块各至多一个p倍数，记为m+i和n+j；故a=min(v_p(m+i),v_p(n+j))。于是

    p^a | (m+i)−(n+j)=d+i−j。

该差值是d−k+1,…,d+k−1中的一个正整数。由于p>Q，分母Q!不含p；将每个p>Q的赋值合并可得

    L | Δ， Δ=∏_{u=−k+1}^{k−1}(d+u)/Q!
             = binom(d+k−1,Q)。

因此得到可复用的精确上界

    gcd(P_k(m),P_k(n))
      ≤ (k−1)!(n+k)^{π(2k−1)} binom(d+k−1,2k−1)。

这对所有k≥2,n≥0,d≥k的两块都成立，不需要原题等式。

## 3. 组合数估计及合并

对整数N≥Q≥1，由log(Q!)≥∫_1^Q logt dt>QlogQ−Q可得

    binom(N,Q) < (eN/Q)^Q。

取N=d+k−1。因为d≥k，

    (d+k−1)/(2k−1) ≤ d/k，

交叉相乘后恰为(k−1)(d−k)≥0。又ed/k>1，所以

    Δ < (ed/k)^Q < (ed/k)^{2k}。

由第2节和m<k³，

    G=S·L < (e^8 k)^k (ed/k)^{2k}
            = (e^10 d²/k)^k。

回到原题：G=P_k(n)，且m^k<P_k(m)=4G，故

    m < 4^{1/k} e^10 d²/k ≤ 2e^10 d²/k，

这里k≥2保证4^{1/k}≤2。结合第1节m>kd/2，并约去正的k、d，得到

    d > k²/(4e^10)。

由e<3，4e^10<4·3^10=236196<250000，目标成立。e<3可由级数e=∑1/j!及j!≥2^{j−1}（j≥2，j≥3时至少一处严格）直接证明。

## 4. 覆盖和剩余范围

对任意固定实数B≥1，若还要求d≤Bk，则

    k<250000 B，
    d<250000 B²，
    m<4kd/3 < (4/3)·250000² B³。

n=m−d随之有界。因此“距离至多长度固定倍数”的区域被化成明确有限范围；本轮没有枚举这个巨大范围。对k≤250000，新界通常弱于已有d≥k；没有声称对小k带来实用搜索增益。

剩余目标仍包括无界k和满足d>k²/250000的无界距离。该定理不排除远距解、不提供任何合法见证，也不证明原题4不可表示。
