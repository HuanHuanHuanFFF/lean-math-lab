## 锁定的完整声明

对自然数 `k n m`，令

```lean
def product (k t : ℕ) : ℕ := ∏ i ∈ Finset.Icc 1 k, (t + i)
```

最终公开根声明必须从以下全部且仅有的数学前提推出结论：

```lean
theorem uniform_distance_bound (k n m : ℕ)
    (hk : 2 ≤ k) (hsep : n + k ≤ m)
    (hratio : product k m = 4 * product k n) :
    (k : ℚ) ^ 2 < 250000 * ((m - n : ℕ) : ℚ)
```

以上是待证接口草案，没有占位 Lean 文件，也没有把此声明注册为已证定理。优先在自然数中证明等价根结论 `k ^ 2 < 250000 * (m - n)`，然后用显式类型转换给出有理数版本。

题面对照：`k,n,m : ℕ` 已包含 `n ≥ 0`；乘积索引恰为 `1,…,k`，故每个因子正。`hsep` 推出 `n ≤ m` 及 `k ≤ m-n`，因此自然数截断差与原题整数差、有理数差相同。结论也等价于 `((m-n : ℕ) : ℚ) > (k : ℚ)^2 / 250000`。不得额外假设 `m < k^3`、大 `k`、互素或素数计数估计后声称完成；这些只能是根声明内部的分支或已证明引理。

这是原方程的必要距离界，仍不等于原题无解。
