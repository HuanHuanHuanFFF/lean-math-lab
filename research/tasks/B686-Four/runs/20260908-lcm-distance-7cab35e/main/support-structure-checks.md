# 支持结构检查：大owner稀缺、匹配与正系数边界

2026-09-08 06:55 Asia/Shanghai；主任务纸面推导。目的：检查哪些实际算术条件可能补上稀疏支持路线的非零缺口。以下没有完成全题或新的整类长度无解证明；不为这些局部接口单独启动Lean工程。

## 1. 高高度下至多两个大owner

设原解k≥16，取实数C≥1，并假设 `n>4C²k³`。考虑所有格(i,j)∈[1,k]²，其中存在正整数q同时整除n+j及m+i，且 `a=(n+j)/q≤Ck`。则这样的格至多两个。

证明如下。所有比值 `r_ij=(m+i)/(n+j)` 落在同一区间

`[(m+1)/(n+k),(m+k)/(n+1)]`。

原产品比为4，所以 `(m+k)/(n+k)≤4^(1/k)<1+3/(2k)`。最后的不等式来自 `(35/32)^16>4` 及 `(1+c/k)^k` 对整数k单调增加；可逐二项式展开验证该单调性。唯一常数的精确差为 `35^16−4*32^16=235239496443979639065921>0`。

于是m<2n，且共同区间宽度为

`(k−1)(m+n+k+1)/((n+1)(n+k)) <4k/n<1/(C²k²)`。

每个目标格的比值又是整数b/a，其中a≤Ck。两个不同的此类有理数相差至少1/(C²k²)，故全部比值相同，记既约值A/B>1。

上界还给

`r_ij < (1+3/(2k))(1+(k−1)/(n+1)) <1+2/(k−1)`，

所以B>(k−1)/2。由 `B(m+i)=A(n+j)`，任意两个格的下侧位置差都被B整除；同一行或同一列不可能出现两个不同格。三个格会占用跨度至少2B>k−1，矛盾。

这只限制足够大的单个共因子；不排除每行由多个较小owner共同组成的情形。

## 2. 对rough低度行的后果

沿用k≥16、C≥1、n>4C²k³及原解假设，只保留>k素数的canonical格。设T为其中度数至多1的下侧行。对每个p≤k删除一个具有最大p进赋值的下侧位置，删去的行数至多π(k)。剩余行的小素数部分之积整除(k−1)!，这是已验小素数集中界的直接用途。

在T中，度数1时该行的全部rough部分都属于一个owner；度数0时小素数部分就是n+j>Ck。故删除上述至多π(k)行后，至多两行的小素数cofactor≤Ck。由第1节及乘积界，

`(Ck)^max(0, |T|−π(k)−2) ≤(k−1)!`。

特别，若全部rough行度数≤1，则 `k≤π(k)+2+log((k−1)!)/log(Ck)` 是必要条件。由π(k)=O(k/log k)，选固定足够大的C可知：所有充分大k在 `n>4C²k³` 时不可能有这种纯匹配/孤立行支持。这里没有求实际起始K，也不把定性有限余段说成可立即枚举。

**投入判断。** 这排除一个跨全部大k的支持子类，但仍允许两边度数2的2k格模板，与已有1/8或1/4的二次规模上界相距很远。A已经构造这样的连续网格几何模板，且所有新Runge函数格值非零；它不是原方程见证。当前不把本节当作完整的非零机制，也不单独形式化。

B已独立核对第1–2节的区间宽度、未约分有理数间距、既约分母和三格跨度，以及删除最大小素数赋值行后的乘积整除；未发现算术漏洞。按其建议在本节显式重复条件，防止将条件后果误读成无条件结论。这仍是AI交叉纸面复核，不是Lean或外部同行验收。

## 3. 最大匹配数量的另一必要条件

设rough支持图最大匹配数为ν。由二部图顶点覆盖定理，可用ν个行/列顶点覆盖所有owner。每个rough素数幂因此出现在这些顶点的乘积中，得到

`roughMass≤(m+k)^ν< [2(n+1)]^ν`。

结合一次小素数损失，

`(n+1)^(k−π(k)−ν)≤2^(π(k)+ν)(k−1)!`。

在三次高度以上它迫使ν约至少(2/3−o(1))k；在 `log n~(k/4)log k` 的尺度上约至少k−π(k)−4。它是质量界的结构读法，不是新全局排除。无权大匹配也不保证局部jet行列式中的二项式势因子自动抵消。

## 4. 一个不能免费保障正性的系数锥

考虑B的新整数值基 `U(X)^q binom(X+a,a)binom(Y+b,b)`，0≤a,b<k。所有这些基函数在原正整数区域为正，但不能要求核向量的系数全部非负来廉价保障非零。

在格(-1,-1)，令局部x=X+1、y=Y+1。原曲线分支为 `y=4x+O(x²)`；U(-1+x)的首项为x/k，而a>0时 `binom(-1+x+a,a)` 的首项为x/a。因此每个基函数的首个非零jet次数为

`q+1_(a>0)+1_(b>0)`，且系数严格正。

非负系数的非零组合不会消去该最低项，接触阶至多floor(D/k)+2。所以支持若含(1,1)，且μ>floor(D/k)+2（例如μ=100,D=40k），这个具体正系数锥无解。它不否定其他基、允许负系数的正性证书或不含此格的支持。

## 5. 保留的未测试连接

二项式规范化斜率中的C_i/C_j是行列顶点势之比，在完整匹配乘积中会抵消。若特殊全基的最大子式能利用这种可分离性，可能优于把每个格的exp(k)损失独立相乘。但高阶jets与次数截断未证明保留该抵消，已有截断网格还会产生>k的新分母。共同参数u=U(X)确实消除了首jet的势因子，后续Schur部分仍需独立处理；目前仅作为动机明确的未完成方案保留。
