# 一个更强的可证伪候选：平方根倍率与块长

主任务在独立刷新阶段提出，尚非定理：若P_k(m)=h²P_k(n)、k≥2、n+k≤m、整数h≥2，是否总有h≥k？若成立，则倍率4只剩k=2，再用已知k=2排除即可关闭686。它具有明确的全局收益，但目前没有理由断言比原题更容易。

先做[有限反例探针](square_multiplier_probe.py)，精确范围为3≤k≤40、0≤n,m≤5000、2≤h<k。每个k递推原始整数乘积并用字典匹配h²倍数；任何命中均须重新用原始连续乘积代入和核对不重叠条件。结果见[square-multiplier-probe.json](square-multiplier-probe.json)：没有命中。这只说明候选未被这个小范围立即否定。

正对照包括k=3的(n,m,h)=(11,25,3)和(4,13,4)，检验倍率9、16确能被同一乘积与查找流程识别；重叠对照(3,0,1,2)确有倍率4，但被m≥n+k条件拒绝。不把重叠构造当作原题见证。

本探针未提高本仓既有倍率4排除界，不证明h≥k，也不提供成功概率。后续只有找到可用的一手定理、结构证明或反例构造后才提高投入；通过小样本不是启动长期证明的理由。尚未进行新颖性审查或Lean化。
