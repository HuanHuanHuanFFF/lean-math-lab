# 共同U参数与正系数锥的边界

本笔记承接06:45冻结的整值基，不改动冻结输入。

令u=U(X)=P_k(X)/k!。曲线上U(Y)=4u。在网格(-j,-i)分别取逆支X_j(u)、Y_i(4u)，则

`U(X)^q B_a(X)B_b(Y)`

的第q阶首jet恰为`B_a(-j)B_b(-i)`；不再带以x=X+j为参数时的`(1/(k C_j))^q`。完整tensor网格因此给同一个整数三角评价块，首jet的行列势可以精确消掉。

换参的高阶系数分母仍只含≤k素数。可先在Z[1/Λ_k]处理完整层，再清有限Λ幂，不能把每个格的阶乘或binomial势独立相乘收费。此事实不消除总次数截断后缺少新U层的高阶Schur complement。

另一个主任务提出并已直接核对的边界：在(-1,-1)的正向分支y=4x+O(x²)，有U(-1+x)=x/k+O(x²)，a>0时B_a(-1+x)=x/a+O(x²)。所以每个基函数的最低阶是

`q+1_(a>0)+1_(b>0)`，

且最低系数为正。非负整数系数的非零组合不能消掉该最低项，接触阶至多floor(D/k)+2。因此当支持包含该格且μ超过该数时，不可能用这个基中的全非负系数来同时保障高阶接触和正点非零。

这只封住一个特定系数锥，不封住允许负系数的正性论证、其他基或不含该格的支持。
