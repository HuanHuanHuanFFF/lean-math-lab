# k≡0 mod4：割线交错和给出k^(k/4+1)高度界

状态：2026-09-08第九轮有界检查。A提出并核对具体割线表示与正区间平移，主任务独立复核符号、核及阈值。以下为完整纸面论证，未Lean化；不作新颖性声明，也不把有限负系数样本当作通性。

## 1. 目标与已知边界

设k=4s≥4、n,m为自然数、m>n，且P_k(m)=4P_k(n)。则

```text
n < 2^s k^(s+1)，             s=k/4，
n+k < 2^(s+1) k^(s+1)。                                  (Q)
```

原题的n+k≤m保证m>n，因此(Q)适用于所有合法解。它不排除(Q)以下的有限高度区间，更不提供k上界。

中心化、多项式部分与“若误差单侧且单调则可排除整数零值分支”的思路已见[第八轮初始备忘](../../../round8/independent/first-memo.md)。第八轮[真实格距诊断](../../../round8/independent/README.md)证明三次尺度上的自动取整猜测为假。本轮新增的是针对k=4s的无符号猜测证明、具体积分上界和全k包络；新阈值没有被说成k³，不与旧反例冲突。

## 2. 分支、无穷处与整数多项式

令r=2s=k/2、b_i=(2i−1)²（1≤i≤r），置

```text
B(z)=∏_{i=1}^r(z−b_i)， R(U)=B(U²)，
X=2n+k+1， Y=2m+k+1。
```

有R(X)=2^kP_k(n)、R(Y)=2^kP_k(m)，所以B(Y²)=4B(X²)，且Y>X>k−1。

在复平面去掉s条割线

```text
I_j=[b_(2j−1), b_(2j)]，1≤j≤s
```

后，取f(z)=sqrt(B(z))的分支，使f(z)∼z^s于无穷处，并使f(t)>0于t>b_r。具体可先在上下半平面取∏_i sqrt(z−b_i)的主值乘积：在不属于I_j的实区间，其上下值一致，故可解析粘合。所有根简单，割线成对，且无穷处总次数2s为偶数。

展开

```text
f(z)=z^s∑_{j≥0}c_j z^(−j)，  c_0=1，
q(z)=∑_{j=0}^s c_j z^(s−j)。
```

于是g(z)=f(z)−q(z)=O(1/z)，不是O(1)或仍含多项式项。平方递推2c_j=f_j−∑_{0<h<j}c_hc_(j−h)给2^(2j−1)c_j∈Z（j≥1）。因此

```text
L=2^(2s)，   A(U)=L q(U²) ∈ Z[U]。
```

不使用最大integer-valued格距，也不假设某个遗漏系数非零。

## 3. Cauchy表示及其符号

在I_j内部，B(t)<0；上半平面边界恰有2(s−j)+1个负实因子，因此

```text
f_+(t)= i(-1)^(s−j) sqrt(|B(t)|)，
f_-(t)=-i(-1)^(s−j) sqrt(|B(t)|)。
```

q没有跳跃。对g(w)/(w-z)应用Cauchy公式，在大圆内沿每条割线挖去细管。大圆积分因g(w)=O(1/w)而趋于0；沿细管上沿从左向右、下沿从右向左，所以得到

```text
g(z)=(1/π)∑_{j=1}^s(-1)^(s−j)∫_(I_j) sqrt(|B(t)|)/(t−z) dt。
```

故对实z>b_r，误差ε(z)=q(z)−sqrt(B(z))满足

```text
ε(z)=(1/π)∑_{j=1}^s(-1)^(s−j)J_(j,1)(z)，             (C)
J_(j,p)(z)=∫_(I_j) sqrt(|B(t)|)/(z−t)^p dt。
```

**端点与微分检查。** 每个端点是简单根，f的大小为O(sqrt|w−b_i|)，q有界，所以小端点圆弧对Cauchy积分的贡献趋于0。跳跃密度sqrt|B(t)|在端点连续趋于0，因而可积。固定z>b_r时分母与割线有正距离；核及其z导数由可积有界函数控制，因此可在积分号下微分：

```text
ε'(z)=−(1/π)∑_{j=1}^s(-1)^(s−j)J_(j,2)(z)。          (C')
```

这说明最右割线项为正，ε前面的符号为正。仅说“交错积分”不足以得出该方向；无穷处减q和细管方向都已纳入。

## 4. 连续绝对位置使正核积分严格递增

改变量t=u²，则

```text
J_(j,p)(z)=∫_[4j−3,4j−1] 2u sqrt(|R(u)|)/(z−u²)^p du。
```

R的k个根是等间距奇数−k+1,−k+3,...,k−1，直接消去公共因子给

```text
R(u+2)/R(u)=(u+k+1)/(u−k+1)。                           (S)
```

在每个相邻有效区间的内部，1≤u<k−5且R(u)≠0，(S)及其u+2版本说明

```text
|R(u+4)|>|R(u)|。
```

其中两次移位的绝对值比都大于1。端点处因R为0不影响积分比较。

对p=1,2，正核2u/(z−u²)^p随u∈(0,k−1)严格递增。因此把第j个有效区间平移4到第j+1个，整条开区间上的正被积函数严格增加，故

```text
0<J_(1,p)(z)<J_(2,p)(z)<...<J_(s,p)(z)。
```

从最大项向下两两分组，任意严格递增正数序列的交错和
J_s−J_(s−1)+...+(-1)^(s−1)J_1严格为正。s=1时直接为J_1>0。结合(C)、(C')得到

```text
ε(z)>0， ε'(z)<0， 对全部实z>b_r成立。                (M)
```

这里使用的是连续根的真实绝对位置及精确移位恒等式，不是从样本系数负号外推。无需证明每个Laurent尾系数的符号或寻找其算术下界。

## 5. 统一误差上界

若z>k²，则所有割线在(0,k²)内，每个因子|t−b_i|≤k²，所以sqrt|B(t)|≤k^r。割线总长度≤k²，故由(C)丢弃符号可得

```text
0<ε(z)≤k^(r+2)/(π(z−k²))。                            (U)
```

只需这一总上界；不需高阶系数范数、首遗漏项非零猜测或额外阶乘损失。

## 6. 严格非零整数差与高度阈值

在原方程上sqrt(B(Y²))=2sqrt(B(X²))。所以

```text
H=A(Y)−2A(X)=L(ε(Y²)−2ε(X²)) ∈ Z。
```

由Y²>X²及(M)，

```text
−2L ε(X²)<H<−L ε(X²)<0。                              (N)
```

因此零值分支自动排除；这不是假设“某个小向量恰好不在目标超平面”。

令

```text
X0=2^(s+1)k^(s+1)。
```

若X≥X0，则X²≥4L k^(r+2)，且

```text
X²−k²>2L k^(r+2)。
```

后一式只需2Lk^r>1，对k≥4成立。由(U)和π>1，2Lε(X²)<1。于是(N)给−1<H<0，与H为整数矛盾。因此X<X0，继而

```text
n<2^s k^(s+1)，
2(n+k)=X+k−1<2X0，故n+k<X0。
```

这正是(Q)。

## 7. 后继收益与仍需的接口

采用给定canonical矩阵性质，若有s_owner个非单位格，则(s_owner+1)!≤P_k(n)≤(n+k)^k。由(Q)，沿k≡0 mod4、k→∞，

```text
log P_k(n)≤(k²/4+k)log k+O(k²)，
limsup s_owner/k²≤1/8。
```

这是高度与配置约束，不是全部大k≡0mod4无解。k≡2mod4仍可用[前一份全偶k纸面界](centered-runge-bound.md)得到1/4密度门槛。

(N)另提供一个在所有原曲线正点上有明确负号的整数值函数H。但它没有自动满足指定canonical格的局部jet消失，不能拿来替代尚缺的低高度、无公共零section族。

主任务已纠正先前关于平方和的口头成本说明：若每个H_i具有μ阶局部整除，∑H_i²同时具有2μ阶，而次数变为2D，所以α=D/(kμ)不变。真正未解决的是获得足够生成族的最大高度与非公共零；1/8密度的价值是减少约束、增加自由度，不能宣传为“抵消平方和把α翻倍”。
