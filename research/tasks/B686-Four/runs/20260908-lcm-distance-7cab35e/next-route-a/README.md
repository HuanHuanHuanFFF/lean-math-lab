## 起始投入判定与路线

1. 先以C_k: P_k(Y)=4P_k(X)的沿曲线jets核算次数、属和高度。几何上若支持数s≈c k²，degree D≈αkμ，则RR型基点自由条件约为μ(α−c)≥1；这是需要证明/适配的候选机制，不把维数计数当非消失证明。
2. 统一大小界只给n≳k³。若整数系数高度≤k^(a kμ)，即使已有正点非零且(P/G)^μ整除，也须(a+1)/(1−α)<3才可能跨越剩余高度。普通全基Cramer界预期过大，需明确替代构造。
3. 主任务新优先输入：改中心变量X=2n+k+1、使用平方根展开的加权余项，检查能否把Runge上界从k^k降至k^(k/2+O(1))，k≡0 mod4时甚至k^(k/4+O(1))。先核实首遗漏阶、2-adic分母和Q(Y)−2Q(X)=0分支。若成立，canonical密度门槛可下降，但仍不直接排除全大偶k。
