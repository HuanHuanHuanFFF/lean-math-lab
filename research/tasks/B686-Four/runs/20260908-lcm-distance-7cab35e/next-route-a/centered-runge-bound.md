# 中心化加权 Runge 上界：完整纸面核查

状态：2026-09-08 第九轮。主任务提出中心化与显式常数，A逐项独立核查并把系数majorant改写成有限组合数界，主任务再次复核。以下是双方纸面论证，未Lean化，不作新颖性声明。它改进旧统一粗上界，不声称对每个k都小于旧程序实际算出的N(k)。

## 与既有中心化诊断的关系

[第八轮独立记录§2](../../../round8/independent/README.md)已经研究中心平方根及真正的integer-valued格距，并用Lean证实k=10、n=k³时误差超过四个格距。中心化本身不是本轮新思路；本轮新增的是全k按次数加权的系数控制、明确的k^(k/2+1)统一包络，以及与canonical素因子质量的连接。

本界阈值远大于k³，完全不与旧反例冲突。下面使用一个显式清分母L保证整数差，既不把单项式分母冒称最大格距，也不声称在三次尺度上已达到取整精度。有限fixtures只核对本轮新常数与新阈值，不重做旧k³误差数表。

## 1. 精确结论与变量

设k=2r≥2，n,m为自然数，n+k≤m，且P_k(m)=4P_k(n)，其中P_k(t)=∏_{i=1}^k(t+i)。则

```text
n < 16 · 2^(4k) · k^(k/2+1)，
n+k < 20 · 2^(4k) · k^(k/2+1)。                         (C)
```

取X=2n+k+1、Y=2m+k+1、a_i=2i−1（1≤i≤r），令

```text
R(T)=∏_{i=1}^r(T²−a_i²)。
```

直接配对给R(X)=2^k P_k(n)、R(Y)=2^k P_k(m)，所以R(Y)=4R(X)，且Y>X>0。这里X和Y是中心变量；下文ℓ始终表示余项次数，不与原距离d=m−n混用。

## 2. 有限平方根部分与分母

在Q[[z]]中取常数项为1的唯一形式平方根

```text
sqrt(∏(1−a_i²z)) = ∑ c_j z^j。
```

只使用j≤J=floor(r/2)的有限系数。置

```text
Q(T)=∑_{j=0}^J c_j T^(r−2j)，L=2^(2J)，A=LQ，E=A²−L²R。
```

平方比较的递推为2c_j=f_j−∑_{1≤h<j}c_h c_(j−h)，f_j是整数。归纳得到2^(2j−1)c_j∈Z（j≥1），故A∈Z[T]且1≤L≤2^r。

Q²与R的前J+1个偶次系数相同，所以

```text
deg E ≤ r−1  （r奇），deg E ≤ r−2  （r偶）。
```

A只含与r同奇偶的幂，E只含偶次幂。E非零：R在T=1有简单根，因而不可能是Q[T]中某个多项式的平方。令ℓ=deg E、e=E_ℓ，则0≤ℓ<r、ℓ为偶数、e∈Z\{0}，特别|e|≥1。这一步不猜测首个可能出现的余项系数一定非零。

## 3. 按次数加权的统一系数界

对每个j≥0有|binom(1/2,j)|≤1。逐因子展开(1−a_i²z)^(1/2)，每个次数j的绝对系数至多k^(2j)。r个因子卷积时，次数j的弱组合数量为binom(r+j−1,j)。因此对j≤J，

```text
|c_j| ≤ binom(r+j−1,j) k^(2j) ≤ 2^(2r) k^(2j)。
```

此为有限系数估计，不依赖解析级数收敛。第二个不等式由j≤r及二项式系数≤2^(r+j−1)得到；j=0单独为1。

所以对0≤h≤r，

```text
|A_h| ≤ 2^(3r) k^(r−h)。                              (Acoef)
```

A²的每个系数至多r+1≤2^r项，故其h次系数绝对值≤2^(7r)k^(2r−h)。另一方面R的h次系数绝对值≤2^r k^(2r−h)，而L²≤2^(2r)。取

```text
B=2^(8r)=2^(4k)，
```

则2^(7r)+2^(3r)≤B，得到

```text
|E_h| ≤ B k^(2r−h)    （0≤h≤2r）。                    (Ecoef)
```

## 4. 加权余项估计

取整数阈值

```text
X0=32 B k^(r+1)。
```

对任意实数T≥X0，有T≥2k。置ρ=(k/T)²≤1/4。有限几何和满足∑_{j≥1}ρ^j≤2ρ、∑_{j≥0}ρ^j≤2（截断和也满足）。

由A只含同奇偶次幂、L≥1和(Acoef)，

```text
|A(T)−L T^r|/(L T^r) ≤ 2^(3r+1)(k/T)² < 1/8。         (Arel)
```

当ℓ=0，E相对领先项的误差为0。当ℓ≥2，用E仅含偶次及|e|≥1，

```text
|E(T)−eT^ℓ|/(|e|T^ℓ)
 ≤ 2B k^(2r−ℓ+2)/T²
 ≤ 2B k^(2r)/T² < 1/8。                              (Erel)
```

因此A(T)>0，且|E(T)|位于(7/8)|e|T^ℓ与(9/8)|e|T^ℓ之间。另由(Ecoef)整段求和，

```text
|E(T)| ≤ 2B k^(2r−ℓ)T^ℓ。
```

令q=r−ℓ≥1。因为k/T≤1，

```text
|E(T)|/A(T)
 ≤ (16/7) B k^(r+q)/T^q
 ≤ (16/7) B k^(r+1)/T
 ≤ 1/14 < 1/3。                                     (Gap)
```

这正是旧TwoScaleGap/平方夹逼需要的三项估计。关键节省来自相邻非零幂相差2，未把所有E系数无权相加。

## 5. 整数差与零值分支

反设原解的X≥X0，则Y≥X0，两点都满足上节估计。R(X)、R(Y)>0。由A²−L²R=E、A>0和(Gap)，

```text
|A(T)−L sqrt(R(T))| = |E(T)|/(A(T)+L sqrt(R(T))) < 1/3
```

在T=X,Y成立。R(Y)=4R(X)给

```text
|A(Y)−2A(X)| < 1。
```

左侧来自整数，故A(Y)=2A(X)，从定义立刻得到E(Y)=4E(X)。这一步亦可完全按旧数值判据交叉比较平方实现；没有假设辅助式在解点非零。

现在由(Arel)与(Erel)，

```text
(Y/X)^r ≤ 18/7，
(Y/X)^ℓ ≥ 28/9。
```

但Y/X>1、ℓ<r，故左侧第二项不大于第一项，而28/9>18/7，矛盾。ℓ=0也包括在内（亦可直接用非零常数E=4E矛盾）。因此X<X0。

由X=2n+k+1得到n<X0/2=16 B k^(r+1)。又k≤4B k^(r+1)，故n+k<20B k^(r+1)，即(C)。

## 6. 对后继全族路线的实际作用

旧统一粗包络为20(16k)^k=20·2^(4k)k^k；(C)将其改成20·2^(4k)k^(k/2+1)。两者比值为k^(1−k/2)，但旧程序实际N(k)是逐k系数算出的另一数值，未逐项声称本界更小。

若采用已给定canonical矩阵性质，s个非单位格异格互素，仍有(s+1)!≤P_k(n)≤(n+k)^k。代入(C)：

```text
log((s+1)!) ≤ (k²/2+k)log k + O(k²)。
```

由初等阶乘对数下界s log s−s+1，沿偶数k→∞得到

```text
limsup s/k² ≤ 1/4。
```

这是渐近密度约束，不是任意有限k都有s≤k²/4，也不是所有充分大偶k无解。它给后继沿曲线jet的次数/高度预算留下此前c=1/2时没有的余量；非消失、完整短基及小素数分母仍是独立义务。
