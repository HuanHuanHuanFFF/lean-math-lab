# Pick / Markov / Nikishin：直接适配失败的边界

状态：2026-09-08第九轮跨领域有界检查。主任务核查主逆一手定理，A核查多网格、缩放、乘积及Hermite–Padé接口。以下为纸面适配判断，未Lean化，没有新的全族排除。不把单个Pick事实说成Nikishin、Angelesco或AT系统。

## 1. 有效的一手输入与符号

令

```text
U(x)=binom(x+k,k)=P_k(x)/k!，
X_1(u)>−1，U(X_1(u))=u（u>0），
B_a(x)=binom(x+a,a)，F_a(u)=B_a(X_1(u))。
```

[Uchiyama 2003作者全文§2 Theorem A](https://www.researchgate.net/publication/344480567_Inverse_functions_of_polynomials_and_orthogonal_polynomials_as_operator_monotone_functions)适用于实根乘积的主逆及满足根前缀计数条件的复合。本题U的根为−1,...,−k，指数均1；B_a为根前缀，故主逆平移X_1+1和F_a（1≤a≤k）可用该正性结论，正缩放u→4u保留它。论文实际DOI为[10.1090/S0002-9947-03-03355-5](https://doi.org/10.1090/S0002-9947-03-03355-5)；不需要强行把这些相互含因子的B_a嵌入严格正交多项式序列。

[Fidalgo Prieto–López Lagomasino 2010](https://arxiv.org/pdf/1001.0554)的Def.1.2要求相邻生成测度区间分离；Nikishin系统的分量测度反而共有首个支持。Angelesco使用彼此分离的支持区间。其Thm1.1–1.2的AT/完美性适用于这些具体结构，不适用于任意Pick函数清单。

下面的障碍为本题自己的推导，未把论文摘要当作对应接口。

## 2. 所有原题高度上，多数grid逆支已非实

对x∈[-k,-1]，写x=−j−t，其中1≤j≤k−1、0≤t≤1。逐因子有

```text
|P_k(x)|≤j!(k−j)!，
|U(x)|≤1/binom(k,j)≤1/k。                              (R)
```

最后一项也可由binom(k,j)=(k/j)binom(k−1,j−1)及binom(k−1,j−1)≥j直接得到。

而每个原n≥0都给u=U(n)≥1。因此U(x)=u在[-k,-1]没有实根。在x>−1处U严格递增，恰有主实根；当k偶，x<−k处U由+∞严格递减到0，另有且仅有一个实根；当k奇，左外侧U<0，没有正u对应根。

于是：

- 偶k≥4在全部原题u≥1上仅两个逆根实，其余k−2个非实；
- 奇k≥3在全部原题u≥1上仅主根实，其余k−1个非实。

这统一了主任务的k=3临界值例子。这里不是说主逆Pick定理错误，而是它不同时提供所有grid支X_j的实正测度表示。将正目标区域放在那些支的割线上，也不能使用传统“支持之外”的零点结论。

## 3. 乘积不是普通正Markov分量

由U'(−1)=1/k和B_a'(−1)=1/a，有精确局部展开

```text
F_a(u)=(k/a)u+O(u²)，
F_a(u)F_b(4u)=4k²/(ab)·u²+O(u³)  （a,b≥1）。          (P)
```

取u=t exp(3πi/4)、t>0足够小，(P)主项虚部严格为负。因此这些乘积不是Pick函数；“两个因子都是Pick”在这里不能传给乘积。

矩不存在并非根本障碍。主支Stieltjes表示可经u=1/v改成紧支撑、有限同号测度的Markov表示。可是倒变量后的乘积满足

```text
F_a(1/v)F_b(4/v)=4k²/(ab)·v^(−2)+O(v^(−3))。
```

非零有限同号测度的普通Cauchy变换首项必是非零总质量/v，所以该乘积不能直接充当一个这种Markov分量。允许有符号测度、广义Stieltjes阶数或新的线性组合是另一种结构，不能沿用同号测度的完美性定理。

混合型Nikishin论文中的矩阵是对某个权函数外积再做Cauchy积分；它不是把两个已求出的Cauchy变换在目标变量处相乘。此区别不能省略。

## 4. 缩放主逆的支持：不是简单的“同cut所以失败”

只取F(u)=X_1(u)+1。设c_*∈(-2,-1)为U最右临界点，β=U(c_*)<0。实根交错保证U'在该点为简单零，所以主逆在β有非退化平方根分支点，并在(β,∞)实解析。

F/u的Stieltjes表示及F'(0)=k给倒变量

```text
G(v)=F(1/v)=∫ dν(t)/(v−t)
```

的有限正测度，总质量为k。主逆在β的分支和无穷处u^(1/k)增长，连同上述实解析区间，给

```text
Co(supp ν)=[1/β,0]。
```

缩放函数G_4(v)=F(4/v)=G(v/4)的测度为4倍推前，故其支持凸包为[4/β,0]。两个凸包有开区间重叠，但不相同。

所以直接用它们作Angelesco生成测度时，分离条件失败。直接用它们作同一个标准Nikishin系统的两个分量时，共同支持条件失败。后一句与“所有Nikishin测度都应分离”不同：分离的是生成层，相同的是分量层。

支持不等还可局部看出：在v=4/β附近，G实解析，而G_4有平方根跳跃；唯一正Stieltjes测度在这一小开段上，一者为零、另一者有非零密度。

### 常数可逆混合也没有自动修复

在上述仅G_4有密度的开段，任意实常数可逆混合若让两个新分量都有支持，其密度比是常数；若一个混合系数为零，则支持仍不同。标准非退化二函数Nikishin系统的密度比应是另一条分离区间上非零同号测度的Cauchy变换。该变换在首区间邻域解析，若在一个开段为常数，解析延拓和无穷处衰减迫使它恒零，矛盾。

这进一步阻止了最简单的常数换基。没有据此否定更一般有理变换、复杂轮廓、矩阵值测度或重新组织的系统；这些尚未给出合格构造。

## 5. 真实grid jets与标准HP问题还缺一整层对应

对每个j，令X_j(u)是u=0处的逆函数芽，X_j(0)=−j。取integer-valued坐标表示

```text
F(x,y)=∑_(0≤a,b<k) p_ab(U(x)) B_a(x)B_b(y)。
```

在原曲线U(y)=4U(x)的格(j,i)上，μ阶沿曲线jet条件实际为

```text
∑ p_ab(u) B_a(X_j(u))B_b(X_i(4u)) = O(u^μ)。
```

同一组p_ab必须对任意被canonical支持选中的多个(j,i)同时成立。这既涉及全部逆支，也涉及两族缩放支的纤维积；不是只在physical主支上做一次Padé逼近。

标准类型I/II或混合HP的未知多项式次数、近似阶以及所用Markov矩阵必须与这一稀疏支对约束明确对齐。即使另证physical主支某个函数清单为AT，也不能自动供应这些任意grid jets的整数值辅助式。还必须保留整除所需的分母控制、系数高度与正目标点非公共零。

高属或有环monodromy只能提示复杂性，本文没有把它单独用成“不可能Nikishin”的定理；上面采用的是实支、局部阶和实际支持这三类可直接检查的障碍。

## 6. 当前停止决定与可重启条件

直接套用Nikishin/Angelesco完美系统定理的路线停止。不再单独形式化operator-monotone事实或扩展纯Pick正性理论；没有新增全长度族排除。

主逆和前缀的正性仍是有效可复用工具。重新启动须有下列至少一项具体证据：

- 把实际多grid、缩放和次数约束变成某个已满足生成测度条件的正交/HP系统；
- 给出适合这些复支的轮廓或矩阵结构，并真正证明所需零点/非公共零结论；
- 同时保住integer-valued整除与合格高度，不能只证明分析上的正常性。

主任务已核对第2、3节及Nikishin支持层次的区别，并要求在来源与失败接口成文后停止本分支。所有判断均为纸面；已冻结的uniform证明包和两份Runge论文未改。
