## 锁定目标

对所有 `s n m : ℕ`，在 `1≤s`、`n<m` 和
`P_(4*s)(m)=4P_(4*s)(n)` 下证明

```
n < 2^s * (4*s)^(s+1)
n+4*s < 2^(s+1) * (4*s)^(s+1).
```

P 保持 `∏ i∈Finset.Icc 1 k, n+i`。不增加原题分离条件 `n+k≤m`。

## 新的整数配对观察与第一个检查点

相邻参数 `a,a+2` 满足

```
c=a²+2a+2, e=a+1,
(1−a²z)(1−(a+2)²z)=(1−cz)²−4e²z².
```

定义整数序列 G 的形式级数满足
`G=e²+czG+z²G²`，则 `F=1−cz−2z²G` 的平方恰等于上述两因子。
因此配成 s 组后，全平方根级数可直接在 ℤ 上构造，q 实际可取整数系数，
不需要纸面的 `L=2^(2s)`。这是本次推导，尚待 Lean 验证，不作新颖性声明。
它在误差常数上释放 `4^s` 余量，但并不单独关闭尾项符号问题。

第一个可证伪检查点：实现整数序列、级数平方恒等式、与 centered 截断的
一致性。随后检验整数配对是否能给尾部正性；若不能，保留此桥并明确
