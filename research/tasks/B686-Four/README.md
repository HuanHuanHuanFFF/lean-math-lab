# B686：连续整数乘积之比为 4

令 `P_k(t)=∏ i∈{1,…,k},(t+i)`。判断是否存在自然数 `k,n,m`，满足 `k≥2`、`n≥0`、`m≥n+k`、`P_k(m)=4P_k(n)`。两段长度相同且互不重叠。一个合法三元组可证明存在；否定方向需要覆盖所有合法参数。

[来源题面](https://conjectures.io/problems/erdos686-erdos-686-variants-four)。当前各批均没有完整解答；证据与剩余范围分别以各批记录为准。
