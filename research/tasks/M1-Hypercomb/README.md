## 精确目标与来源

对 Galvin–Sharpe 的均匀线性超梳 `C_{n,ℓ}`，`n ≥ 1`、`ℓ ≥ 3`，研究按大小计数的强独立集序列是否单峰；强独立集在每条超边中至多选一个顶点。单峰允许平台，即存在峰位置，使序列先不减、后不增。

[候选题面及递推](../../2026-09-06-中型数学研究候选.md)；[v5 原文](https://arxiv.org/html/2409.15555v5)；[期刊版](https://ajc.maths.uq.edu.au/pdf/94/ajc_v94_p093.pdf)；[已撤回完整对数凹论证的 v3](https://arxiv.org/html/2409.15555v3)。v5 说明 1.9 承认旧证明错误；不得依赖旧结论。论文的精确递推及初值用于实验，最终结论须与原超图对象连接。
