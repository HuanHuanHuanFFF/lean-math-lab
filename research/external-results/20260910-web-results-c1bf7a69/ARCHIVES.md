# 原 ZIP 的保存与恢复

原 ZIP 原字节保存在本轮交付附件 `B699-research-context-20260910.zip` 中。仓库收录解包后的文本报告、源码、证书和日志；本次新增的 ZIP 字节不经 GitHub 的 Base64 接口发布。旧已提交文件保持原样。

先解开附件。`originals/` 是网页研究的直接输入；`repository-archives/` 按仓库相对路径保存全部11个 ZIP 文件（9种不同内容），可将需要的文件复制回仓库同名路径。复制前后核对 [ARCHIVES.json](ARCHIVES.json) 的字节数和 SHA-256；已有同名文件只有哈希一致时才能复用，不能覆盖不同内容。

[MANIFEST.json](MANIFEST.json) 保存五份原包及全部449个解包成员的原始映射。正文、证书与历史日志没有改写。历史报告若引用 ZIP 路径，需要先从附件恢复；这一保存方式不提高数学证据等级。
