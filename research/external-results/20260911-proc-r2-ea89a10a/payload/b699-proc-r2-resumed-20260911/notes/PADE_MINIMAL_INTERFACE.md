# 比“先形式化精确 G”更轻的 Padé 接口

## 1. 最小归一化对象

对 e,d,f,m≥1，定义显式整数

    N(e,d,f,m)=∏_{p prime} p^{E_p},
    E_p=Σ_{h≥1}[(em mod p^h)+(dm mod p^h)+(fm mod p^h)≥2p^h+1].

只有 p^h≤((e+d+f)m−1)/2 可能贡献，故这是实际有限乘积。它就是本文的 C_2(em,dm,fm)，但**下面的消费链不需要先证明它等于任何 gcd**，也不需要运输表定理。

## 2. 直接的全幂共同整除引理

对任意非负 A,B,C、0≤r≤A，令

    q_r=C(A+C−r,C) C(B+r,r).

取任意 q=p^h。若

    A modq+B modq+C modq≥2q−1,

则这个系数的两项 Legendre 层贡献之和至少为1。反证：若两项该层贡献都为0，令 a=A modq、b=B modq、c=C modq、ρ=r modq，则无进位给

    ((a−ρ) modq)+c≤q−1,
    b+ρ≤q−1.

但 ((a−ρ) modq)+ρ≥a，合并得 a+b+c≤2q−2，与假设矛盾。其他层贡献非负。

现在代入 A=em−δ、B=fm−1+δ、C=dm−δ。δ=0 总计减1，δ=1 总计减2；每个减1造成的模回绕只会额外加q。因此 N 的每个贡献层都使实际三余数和≥2q−1。于是对每个素数

    E_p≤v_p(q_r),

故 N|q_r。这里逐层下界都针对**同一个任意系数**成立，不存在逐层挑选最优系数再交换求和的问题。这保留了所有 p^h，而不仅仅是首层素数积。

N 的定义对(e,d,f)对称，所以一次定义即可覆盖全部排列及δ=0,1。证明这一步无需精确 G 对称性、无需共同缺陷 gcd 公式，也无需运输算法。

## 3. 为什么足够替代旧 G 的角色

冻结 A 的 Padé 恒等式为

    P(z)−(1−z)^(B+C+1) Q(z)=z^(A+C+1) E(z),
    deg P≤C.

Q 的全部系数被 N 整除。比较次数≤C的系数，右侧为0，因此 P 的每个系数也是 Q 系数的整数线性组合，从而 N 同时整除 P 的全部系数。

于是可直接采用 P/N、Q/N 作为整数系数多项式。在相邻δ的非退化行列式中，同一个 N 只造成非零比例因子1/N²，不改变其非零性。所有随后需要的大小界只用到

    log N>g m,

而不是 N 恰好等于多项式内容，也不是 N 为最大可能公因子。分别清分母的细节仍按冻结 A 的正确版本保留，不能因为归一化更轻而把有理量擅称整数。

**因此 A 的可用最小前置链是：**

    显式素数幂乘积 N
      → 逐层无进位矛盾，N整除每个Q系数
      → Padé恒等式的低次系数，N整除P
      → N的有效指数下界
      → 旧A的非退化、大小界、分别清分母消费者。

精确运输/G/缺陷阶梯可以独立形式化，不应再作为这条 A 路径的强制启动前置。

## 4. 新的轻量接受器

`code/verify_pade_divisor_interface.py` 只接受本轮2923行桥接中实际需要的下界：对每个已提供素数幂 p^e，重新计算其合法贡献层数并要求 e 不超过该数，再以有理 log 下界检查乘积>exp(gm)。它不要求因子列表一定完整；遗漏因子只会削弱下界，不能造成伪通过。它不调用运输、G 赋值或任何 gcd 公式。

所以有限桥接有两种用途：

- `verify_thresholds.py` 核对精确共同内容、最后失败与全部六个实际 G 的关系；
- `verify_pade_divisor_interface.py` 验证较小且足够被 Padé 消费的整除下界，移除前一种精确等式的形式化依赖。

两者均为本会话的程序证据，不是 Lean。本轮没有估计节省了多少 Lean 行数或实际工时，也没有声称删掉旧 theta/有限块依赖。
