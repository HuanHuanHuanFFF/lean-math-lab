# 固定斜率的统一清分母高度：不用 EEES

设 i≥2，A,B正整数，gcd(A,B)=1，2A≤B，n=Bt，j=At，At>i。以下所有幂指数为完整素数赋值。

## 1. 零格点与非零行列式分开处理

对格点 0≤b≤a<i，令 Δ(a,b)=Bb−Aa，令 M 为所有非零 |Δ(a,b)| 的 lcm（空集取1）。定义

    K_{i,A,B}=∏_{p≥i} p^{max(0,v_p(M)−[p=i])}。

此处当 p=i 为素数，必须减去一层指数：它不是把素数集合当完整幂。M是只由i,A,B决定的有限整数。

记 z=ceil(i/B)。在 noCommon 下，

    V_i(n) | K_{i,A,B} C(t,z)，                          (R1)

其中 V_i(n) 是 C(n,i) 的完整 p≥i 部分。

证明：对每个 p≥i，e=v_p C(n,i)>0，令 Q=p^(e+[p=i])。完整分子定位与无进位给

    a=n modQ<i，b=j modQ≤a，Q|(n−a)，Q|(j−b)。

因此 Q|Bb−Aa。

若 Δ≠0，则 e+[p=i]≤v_p(M)，所以 p^e|K。

若 Δ=0，互素性给 a=Br、b=Ar，0≤r<z。Q同时整除A(t−r)、B(t−r)，由Bézout整除t−r。由于 p≥i>z，z!与p互素，故 p^e|C(t,z)。按素数合并即得(R1)。零格点没有被当成“非零有界差”，也不要求各素数采用同一格点。

## 2. 小素数部分的基本界

令 s=π(i−1)，σ_i=∏_{p<i}p^{v_p(i)}，所以 i 为素数时σ_i=1，否则σ_i=i。对任意原始 n≥i，

    σ_i U_i(n) ≤ n^s。                                  (R2)

逐p证明：从n,n−1,…,n−i+1中删除一个p赋值最大的项。对每层p^h，其余可整除项数至多floor((i−1)/p^h)，所以剩余乘积的p赋值≤v_p((i−1)!)。因此v_p C(n,i)+v_p(i)≤max_a v_p(n−a)。相乘并用每个最大p幂≤n即得(R2)。不同小素数允许在同一位置，不增加位置不交假设。

## 3. 精确阶乘消去与单调性

0,B,2B,…,(z−1)B恰为0≤a<i中B的倍数。因此

    C(Bt,i)/C(t,z)
      = (B^z z!/i!) ∏_{0≤a<i, B∤a}(Bt−a)。

结合C=UV、(R1)、(R2)，原反例必须满足

    σ_i B^z z! ∏_{0≤a<i, B∤a}(Bt−a)
      ≤ K_{i,A,B} i! (Bt)^s。                            (R3)

令 E=i−z−s。把左侧除右侧，得到正的常数倍

    (Bt)^E ∏_{0≤a<i, B∤a}(1−a/(Bt))。

在合法 t≥floor(i/A)+1 上所有因子为正。当 E≥0 时，此式不减；E>0时趋于无穷。E=0时，它趋于σ_iB^zz!/(Ki!)，若此极限>1，也有明确有限截点。只要在某个整数t₀实际核验(R3)严格失败，即可排除全部t≥t₀。程序使用二分只找最早截点；证明只需截点失败与单调性。

整个推导没有 EEES、Dusart、BFT、Matveev 或“不具体的充分大阈值”。

## 4. 已实际核验的统一消费者

对全部

    2≤i≤14，3≤B≤8，1≤A≤floor(B/2)，gcd(A,B)=1

共130个(i,A,B)格点，E≥0，并且都有上述有限截点。最大n上界100936，尾部归约后共有50330个合法t。

实际逐个核验这些t，证书每项给一个素数p≥i和h≥1，满足

    p|C(Bt,i)，(At) mod p^h>(Bt) mod p^h。

后一条件直接给p|C(Bt,At)。所有末端通过。

B=2对应A=1，即n=2j，由中心偏差核的d=0消费者覆盖。因此合并得到完整无界子族定理：

    2≤i≤14，i<j≤floor(n/2)，n/gcd(n,j)≤8
      ⇒ 存在同一个素数p≥i整除C(n,i)、C(n,j)。          (R4)

分母是j/n的**既约分母**，不是把n/j假定为整数。例如包括2/5、2/7、3/7和3/8。

i=1可独立加入：n/gcd(n,j)>1既整除n又整除C(n,j)，取它的任一素因子即可。

## 5. 对原证明链的作用与边界

(R1)统一了原n=3j和n=4j中“零格点+非零短差”机制；(R3)用精确阶乘消去与小素数基本界代替n=3j旧支线中的EEES平方输入。就2≤i≤14而言，n=3j、n=4j和其他分母≤8的斜率都由同一份纯整数消费者完成，且不使用任何其他低指标已经闭合的假设。

它没有消除全体任意n,j证明所需的所有外部依赖，也没有重证i≥15的已有成果。固定(i,A,B)的有效高度不等于对无界A,B的绝对高度；R9仍然不能因此删去整项。

## 6. 任意固定指标、任意固定有理比例的有效有限化

前述推导并不限于 i≤14。实际上，对**每一个固定 i≥2 和每一个既约 A/B∈(0,1/2]**，noCommon 的 t 均有可计算的有限上界。这是相对参数 (i,A,B) 的有效有限化，不是原题全参数的有效有限化。

### B≥3：除了一个可直接排除的小格点，次数恒正

当 i≥3，π(i−1)≤floor(i/2)：除2外的素数都在3,5,…,i−1中。故

    E=i−ceil(i/B)−π(i−1)
      ≥ceil(i/2)−ceil(i/3)≥1，i≥5。

i=2、3直接得到E≥1；i=4、B≥4也有E=1。唯一例外是(i,A,B)=(4,1,3)，此时z=2、s=2、K=1，(R3)变成

    72(n−1)(n−2)≤24n²，

即2n²−9n+6≤0；对合法n=3t≥15不可能。因此该例外没有反例，也不需要有限扫描。

当E≥1，合法n≥2i+2给每个n−a≥n/2。写r=i−z，(R3)推出显式界

    σ_i B^z z! · n^E ≤ 2^r K i!。                     (R5)

所以可取

    H(i,A,B)=floor((2^(i−z) K i!/(σ_i B^z z!))^(1/E))。

这里的floor正实根不依赖实数运算：它是满足

    σ_i B^z z! · H^E ≤ 2^(i−z) K i!

的最大非负整数，可用纯整数二分求出。若H小于最小合法n，整个比例立即闭合；否则仍需完整核验n=Bt≤H的有限末端。第4节证书使用更紧的(R3)截点，而不是较松的(R5)。

### B=2：同样有有限高度，少数零次数格点初等处理

B=2迫使A=1。此时所有非零|2b−a|≤i−1，因此K=1，并有

    E=floor(i/2)−π(i−1)。

对i≥10，除偶数之外，9也不是素数，所以π(i−1)≤floor(i/2)−1，E≥1，仍可用(R5)。i=2也有E=1。

i=3时，(R3)为8(n−1)≤6n，合法n≥8不可能。i=4时，中心偏差引理直接给n≤3+1=4，不合法。i=5,6,7,8,9时，中心偏差d=0引理分别给

    n≤9,6,13,10,11，

均小于2i+2，直接矛盾。这里仅消费已文字证明的支撑引理，不依赖任何中央条带的有限证书。

因此，对所有i≥2、所有既约A/B∈(0,1/2]都有明确高度；没有未定的解析阈值、没有超越数论输入。**有限高度不等于每个比例已经闭合**：除直接矛盾的格点及本轮完整证书消费者外，末端仍可能包含待核验输入。由于A、B仍无界，这个定理不能把R9删去任何一个完整指标。

## 7. 最终统一接口与末端优化

后续形成的MASTER_LINEAR_KERNEL.md给出所有B（不分奇偶）、所有i≥2、任意固定有理偏差h的统一有限化。因此，第6节的逐次数分析不是“固定比例有效有限化”结论的唯一基础；保留它是因为(R3)/(R5)能提供更紧高度。

最终完整闭合范围仍是(R4)，没有扩大B上限。使用主定理的精确必要筛，50330个高度末端缩为7391个证书候选，第二实现逐格点重建筛选与验证。原50330点证书保留作基线交叉检查；rational-kernel-certificate.json为优化消费者。
