# 规模判定与实测边界

数学上先证明只需检查有限指数矩形，不枚举到大n。第一版52×52的两个轴边产生787行；最终40×24的两个轴边只产生467行。所有行只计算C(n,4)，不计算巨大的C(n,j)。仅58个大小过滤残余进入因数见证生成，已观察最大n402653187；素数见证本身由另一检查器完全试除。

CRT状态最多4个，每步只将这几个类与至多4个余数组合。数学证书约0.1MB量级，具体字节由manifest与实际replay记录。源大ZIP只读；没有对ZIP做Base64、没有把大JSON灌入正文。

replay/frozen-acceptance/reproduction.json中记录真实命令耗时和整个子进程集合的峰值RSS。后者不是每个函数单独峰值，也不是Lean成本估计。
