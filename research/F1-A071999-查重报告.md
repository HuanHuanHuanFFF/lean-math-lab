# F1 / A071999 形式化先例查重报告

核查日期：2026-09-06。

## 结论

**本次未发现 A071999 行列式乘积公式的既有公开 Lean 形式化。不能据此确认“全球首次”。**

可以准确描述为：本项目完成了 A071999 的 Lean 4 形式化；截至 2026-09-06，在本报告覆盖的公开代码、文献和索引检索中，尚未发现同一结果的既有 Lean 实现。

数学公式本身已有证明。其定义及乘积公式见 [OEIS A071999](https://oeis.org/A071999)，条目将公式归于 Sela Fried，标注日期为 2026-02-03；[Fried 论文第 3.3 节、定理 3](https://arxiv.org/html/2606.09913v1#S3.SS3)给出证明。因此，本项目的贡献属于具体结果的形式化实现。

## 找到的相近材料及核对结果

1. **已有数列计算程序。** [jOEIS 的 Java 实现](https://github.com/archmageirvine/joeis/blob/ad8a64f339ca3b43349c5d29c8a676da6c3e99b4/src/irvine/oeis/a071/A071999.java)按矩阵定义计算行列式；[LODA 程序](https://github.com/loda-lang/loda-programs/blob/2cc61e99490ba169ad2f44760fc55a8fb983f05f/oeis/071/A071999.asm)用循环生成数列；[PARI 实现](https://github.com/gfis/OEIS-prog/blob/fb375daf77829667fb7d46a43f3856dbfc5e8702/prog/gp/a071/A071999.gp)调用 `matdet`。三份文件均已读取，没有 Lean 通式证明。不能把我们的工作称为首次用程序计算该数列。

2. **名称近似的 Lean 文件。** `near_cross` 查询得到两个 Lean 文件，全文定位后分别是 `collinear_cross_proof`（几何共线）与 `linear_cross_entropy`（机器学习损失函数）的子串命中，与 F1 无关。

3. **引用同一论文的项目报告。** [Trunkit 的 arXiv 扩展评估](https://github.com/Athena-Pro/Trunkit/blob/006d17650605b8d3e55897086e644c023cdff380/docs/reports/Trunkit_arXiv_Expansion_Review.md)引用了 Fried 的论文，但相关段落提出的是未来工作流建议，没有提供 F1 的 Lean 证明。

4. **mathlib 已有的通用基础。** 已阅读上述 `master` 提交中的 [Determinant/Basic.lean](https://github.com/leanprover-community/mathlib4/blob/5aedf732b6987e8c26ab3c9ebc855314f82b045f/Mathlib/LinearAlgebra/Matrix/Determinant/Basic.lean)、[Matrix/Block.lean](https://github.com/leanprover-community/mathlib4/blob/5aedf732b6987e8c26ab3c9ebc855314f82b045f/Mathlib/LinearAlgebra/Matrix/Block.lean)及 [Matrix/Permutation.lean](https://github.com/leanprover-community/mathlib4/blob/5aedf732b6987e8c26ab3c9ebc855314f82b045f/Mathlib/LinearAlgebra/Matrix/Permutation.lean)。行列重排、分块三角矩阵与分块对角矩阵的行列式定理早已存在。本项目复用这些基础，新增该矩阵族的配对索引、精确分块等式和最终乘积公式；未在这些文件中发现同一具体公式。

## 证据限制与成果表述

- GitHub 代码搜索主要覆盖其索引中的默认分支；未发布代码、未索引文件、其他分支和不同定义下的等价定理仍可能存在。
- 仅搜索数字 `071999` 会命中大量数值证书；本轮未穷尽该高噪声查询，未将它当作排除先例的证据。
- 旧仓库别名 `mathlib` 的一次查询返回不完整结果，已排除；随后解析到 `mathlib3` 并完成补查。失败的 API 请求未计作零命中。
- 本轮尚无原作者或 Lean 社区的反馈，也没有给本地证明建立公开发布的时间戳。

因此，当前适合保留“**未发现公开 Lean 先例**”的结论，不宜使用“已确认世界首次”或“解决了新的数学猜想”。若准备对外提出首次性主张，下一阶段需要公开固定版本的代码与准确题面，供作者和社区指出可能遗漏的先例。即便如此，也应使用有范围的“据我们所知”表述。
